# Associatività per gli addin

Secondo le nuove modifiche, l'associatività significa che, quando il modello viene aggiornato tramite gli add-in, viene aggiornata anche l'[assegnazione del lavoro](301.md).

Nota [NX™](10047.md) ✓ [Onshape™](10054.md) ✓ [SOLIDWORKS™](10050.md) ✓ [SpaceClaim™](10051.md) ✓
