# Interface de programação de aplicativos

A interface de programação de aplicativos (API) é um conjunto de classes, procedimentos, funções, estruturas e constantes predefinidos que o aplicativo disponibiliza para programas externos e programas do usuário. A API define as funcionalidades que um programa, módulo ou biblioteca oferece ao usuário.

A API para trabalhar com o sistema na linguagem ENCY PL está descrita na [documentação da API do ENCY](https://docs.encycam.com/ENCYPL/2/en/).
