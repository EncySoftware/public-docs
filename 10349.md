# Application Programming Interface

Application Programming Interface (API): insieme di classi, procedure, funzioni, strutture e costanti predefinite, messo a disposizione dall'applicazione per l'uso in programmi esterni e programmi utente. L'API definisce le funzionalità fornite da un programma (modulo, libreria) all'utente.

L'API per lavorare con il sistema tramite il linguaggio ENCY PL è disponibile nella [documentazione API del sistema ENCY](https://docs.encycam.com/ENCYPL/2/en/)
