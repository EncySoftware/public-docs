# Application Programming Interface

Application Programming Interface (API) - A set of predefined classes, procedures, functions, structures and constants that provided by the application for use in external programs and user programs. API defines the functionality that is provided by a program (module, library) for the user.

API for working with the system using ENCY PL language can be found in [ENCY system API documentation](https://docs.encycam.com/ENCYPL/2/en/)
