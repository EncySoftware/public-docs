# Programmierschnittstelle

Eine Programmierschnittstelle (Application Programming Interface, API) umfasst vordefinierte Klassen, Prozeduren, Funktionen, Strukturen und Konstanten, die eine Anwendung externen Programmen und Benutzerprogrammen bereitstellt. Sie legt fest, welche Funktionen eines Programms, Moduls oder einer Bibliothek darüber genutzt werden können.

Die API für den Zugriff auf das System mit ENCY PL ist in der [ENCY-API-Dokumentation](https://docs.encycam.com/ENCYPL/2/en/) beschrieben.
