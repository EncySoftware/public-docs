<strong>Draw.</strong> Switching the mode for entering new points or editing existing ones is done by pressing/releasing the <strong>Draw</strong> button.

In the editing mode, the selected point is circled, and its coordinates are displayed in separate input fields (X, Y, Z). <strong>Input method.</strong> The helical parameter of the curve can be set in four ways: <strong>By Pitch</strong>, <strong>By Angle</strong>, <strong>By Count</strong>.

When using the <strong>By Pitch</strong> option, the step is controlled by the <strong>Pitch</strong> parameter.

With the <strong>By Angle</strong> option, the length is controlled by the <strong>Total Angle</strong> parameter.

For the <strong>By Count</strong> option, the step is controlled by the <strong>Number of Threads (NB of Threads)</strong> parameter.

<strong>Sweep.</strong> Stretching the profile along the trajectory. The profile can be a closed or open outline sketch ( Profile ). The contours of a sketch, spatial curves, and edges of bodies can act as a <strong>Path</strong>

<details>
<summary>Click here to expand..</summary>

1.Call the <strong>Sweep</strong> command from the toolbar, then sequentially select the sweep profile with the mouse - the sketch outline (the Profile selection field is pressed) and one or more path segments (the Path selection field is pressed). As you add segments, the Path field displays the number of segments, and a preview of the 3D element is generated in the main window.

![images/download/attachments/157860860/image2025-5-26_15-4-11.png](assets/images/download/attachments/157860860/image2025-5-26_15-4-11.png) ![images/download/attachments/157860860/image2025-5-26_15-4-40.png](assets/images/download/attachments/157860860/image2025-5-26_15-4-40.png)
