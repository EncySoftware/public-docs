# Erweiterungs- und Integrationsmöglichkeiten

<a id="application-area"></a>

## Anwendungsbereich:

Die API ermöglicht externen Entwicklern die Erweiterung und Integration des Programms. Beispielsweise können eigene Menüeinträge ergänzt und Eigenschaften des aktiven Projekts gelesen werden.

Die API stellt außerdem Operations- und Werkzeuglisten bereit, auf deren Grundlage Plug-ins und Erweiterungen entwickelt werden können.

Postprozessoren können programmgesteuert gestartet und NC-Programme erzeugt werden.

Auch geometrische Modelle können über die API importiert werden.

Die hier beschriebene API befindet sich in der Alpha-Phase und wird weiterentwickelt. Berücksichtigen Sie dies bei ihrer Verwendung.

Damit stehen Schnittstellen zur Anpassung und Einbindung des Programms in eigene Abläufe zur Verfügung.

Die separate Entwicklerdokumentation finden Sie [hier](https://docs.encycam.com/CAMAPI/2/en/index.html).
