# Possibilidades de extensão e integração


## Área de aplicação:

A API permite que desenvolvedores externos integrem e ampliem o nosso programa de forma transparente, abrindo um mundo de possibilidades. Com a API, os desenvolvedores podem adicionar itens de menu personalizados, oferecendo aos usuários ainda mais controle e flexibilidade. Eles também podem ler as propriedades do projeto ativo, o que permite uma análise mais profunda e a manipulação dos dados do projeto.

Outro recurso excelente fornecido pela API é a capacidade de explorar a lista de operações e ferramentas disponíveis em nosso programa. Isso permite que os desenvolvedores criem plug-ins e extensões abrangentes que aprimoram a funcionalidade do nosso programa.

Além disso, os desenvolvedores podem aproveitar a API para executar pós-processadores e gerar código G de forma programática. Essa automação permite que os usuários otimizem seus fluxos de trabalho e gerem facilmente instruções de máquina.

Além disso, a API facilita a importação de modelos geométricos, tornando mais fácil do que nunca a incorporação de modelos externos em nosso programa.

Observe que a API está atualmente no estágio alfa e está sendo ativamente desenvolvida. Embora estejamos confiantes em sua funcionalidade, recomendamos usá-la com cuidado e precisão.

Aproveite o poder do nosso programa com a nova API e libere infinitas possibilidades de personalização e integração. Boa codificação!

A documentação separada da API para desenvolvedores pode ser encontrada [aqui](https://docs.encycam.com/CAMAPI/2/en/index.html).
