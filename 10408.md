# Stangenvorschub

![images/download/attachments/157866480/Bar.png](assets/images/download/attachments/157866480/Bar.png)

<a id="application-area"></a>

## Anwendungsbereich:

Die Operation **Bar feeding** automatisiert das Zuführen langer Stangen in die Maschine, insbesondere in CNC-Drehzentren und Drehmaschinen.

<a id="setup"></a>

## Einrichtung:

Auf **Setup** werden grundlegende Parameter wie Bauteillage und Werkstückkoordinatensystem festgelegt. [Details](1022.md)

<a id="strategy"></a>

## Strategie:

<a id="bar-overhang"></a>

### Stangenüberstand

Axialer Abstand zwischen Spindelbasispunkt und Werkzeugbezugspunkt.

<details>
<summary>Weitere Informationen anzeigen</summary>

![images/download/attachments/157866480/Bar_overhang.png](assets/images/download/attachments/157866480/Bar_overhang.png)

**BO –** Stangenüberstand

</details>

<a id="tool-touch-position"></a>

### Werkzeugkontaktposition

Kontaktposition der Werkzeugspitze im Werkstückkoordinatensystem G54.

<details>
<summary>Weitere Informationen anzeigen</summary>

**X, Y, Z.** Auswahl der als Drehachse verwendeten Achse des angegebenen Koordinatensystems.

</details>

<a id="start-with-target"></a>

### Start mit Ziel

<details>
<summary>Weitere Informationen anzeigen</summary>

**Aktiviert:** Das Koordinatensystem bleibt beim Verschieben des Werkstücks an seiner Position.

**Deaktiviert:** Das Koordinatensystem wird mit dem Werkstück verschoben.

</details>

<a id="wcs-use-canned-cycle"></a>

### WCS / Festzyklus verwenden

<details>
<summary>Weitere Informationen anzeigen</summary>

**Aktiviert:** Der Stangenvorschub wird als Zyklus zur weiteren Verarbeitung im Postprozessor ausgegeben.

**Deaktiviert:** Ausgabe als Folge elementarer Befehle.

</details>

<a id="physic-output"></a>

### Physische Ausgabe

<details>
<summary>Weitere Informationen anzeigen</summary>

**Aktiviert:** Verwendet **Physicgoto** und physische Maschinenkoordinaten.

**Deaktiviert:** Verwendet **Multigoto** oder **Goto** und die entsprechenden Koordinaten.

</details>

<a id="initial-clamp"></a>

### Ursprüngliches Spannmittel

Das Spannmittel, das das Werkstück anfangs hält. Die Befehle zum Spannen und Lösen werden automatisch ausgegeben. Die Parameter entsprechen denen der Werkstückübernahme. [Details](10406.md)
