# Alimentação de barras

![images/download/attachments/157866480/Bar.png](assets/images/download/attachments/157866480/Bar.png)

## Área de aplicação:

A operação de <em>alimentação de barras</em> é essencial na usinagem moderna para automatizar o processo de produção. Sua principal finalidade é alimentar de forma contínua e automática barras metálicas longas em uma máquina-ferramenta — geralmente um centro de torneamento CNC ou um torno.

## Setup:

A guia <strong>Setup</strong> é usada para configurar os parâmetros primários do projeto. Isso pode envolver o posicionamento da peça no equipamento, o sistema de coordenadas da peça, entre outros. [Detalhes](1022.md)

## Estratégia:

### Saliência da barra.

A distância axial entre o ponto de base do fuso e o ponto da ponta da ferramenta.

<details>
<summary>Clique aqui para expandir...</summary>

![images/download/attachments/157866480/Bar_overhang.png](assets/images/download/attachments/157866480/Bar_overhang.png)

<strong>BO</strong> - saliência da barra (Bar overhang)

</details>

### Posição de toque da ferramenta.

A posição de toque do ponto da ponta da ferramenta no sistema de coordenadas da peça (G54).

<details>
<summary>Clique aqui para expandir...</summary>

X,Y,Z. - O eixo X, Y ou Z do sistema de coordenadas especificado é o eixo de rotação.

</details>

### Start with target.

<details>
<summary>Clique aqui para expandir...</summary>

<strong>Ativado.</strong> Quando a peça é deslocada, o sistema de coordenadas permanece no lugar.

<strong>Desativado.</strong> Quando a peça é deslocada, o sistema de coordenadas se move com ela.

</details>

### WCS Use canned cycle.

<details>
<summary>Clique aqui para expandir...</summary>

<strong>Ativado.</strong> O processo de transferência da barra é formalizado como um ciclo para análise posterior no pós-processador.

<strong>Desativado.</strong> O processo de transferência da barra é emitido como uma sequência de comandos elementares.

</details>

### Physic output.

<details>
<summary>Clique aqui para expandir...</summary>

<strong>Ativado.</strong> O comando <strong>Physicgoto</strong> e coordenadas físicas são usados para mover os eixos da máquina.

<strong>Desativado.</strong> Comandos <strong>Multigoto</strong> ou <strong>Goto</strong> e coordenadas são gerados para mover os eixos da máquina.

</details>

### Grampo inicial

O dispositivo de fixação que segura inicialmente a peça. Comandos CLData especiais para fixar/soltar o dispositivo são emitidos automaticamente. <strong>O grupo de parâmetros funciona de forma semelhante às operações Turn take over</strong>. [Detalhes](10406.md)
