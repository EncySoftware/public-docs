# Atualização da estrutura do modelo geométrico

Na atualização, os [grupos](603.md) antigos do modelo são substituídos pelos novos, mantendo todas as [transformações espaciais](116.md) feitas anteriormente e os grupos criados opcionalmente pelo usuário (por exemplo, [seção](289.md)). A verificação de alteração do arquivo é realizada quando a janela do sistema CAM se torna ativa.

Se o arquivo importado tiver sido alterado, o nome do grupo é destacado em **negrito**, aparece na barra de ferramentas o botão "Model files update manager" ![images/download/attachments/157859447/Ico_Refresh_All.png](assets/images/download/attachments/157859447/Ico_Refresh_All.png) e o menu pop-up recebe mais um comando, **Update**.

![images/download/attachments/157859447/image2019-1-9_14-29-19.png](assets/images/download/attachments/157859447/image2019-1-9_14-29-19.png)

Há duas opções de atualização:

- a partir do sistema CAM:
  - pelo Model files update manager;
  - pelo comando **Update** do menu de contexto.

- a partir do sistema CAD em que esteja instalado um [suplemento do sistema CAM](10039.md).

## Atualização a partir do sistema CAM

### Model files update manager

Depois de importar o arquivo de modelo, o sistema CAM verifica periodicamente a data de modificação desse arquivo. Quando uma alteração é detectada, a seguinte janela é exibida:

![images/download/attachments/157859447/image2019-1-9_14-30-38.png](assets/images/download/attachments/157859447/image2019-1-9_14-30-38.png)

> Se você simplesmente fechar a janela <strong>Model files update manager</strong>, ela aparecerá novamente somente quando uma nova alteração for detectada.

Essa janela contém a lista dos arquivos de modelos importados que foram alterados. Aqui é possível atualizá-los.

> O Model files update manager também pode ser aberto com o botão ![images/download/attachments/157859447/Ico_Refresh_All.png](assets/images/download/attachments/157859447/Ico_Refresh_All.png), se ele estiver disponível no painel.

### Descrição da janela Model files update manager

![images/download/attachments/157859447/shot1.png](assets/images/download/attachments/157859447/shot1.png)

1. O botão **All** seleciona todos os arquivos; o botão **None** remove todas as marcações.

2. Nesta área há uma lista de todos os arquivos importados que foram alterados. A caixa de seleção marcada ao lado do arquivo indica que ele está selecionado e será atualizado após o clique no botão **Update**.

> Somente os arquivos selecionados serão atualizados.

A marca redonda verde indica que o arquivo pode ser atualizado:

![images/download/attachments/157859447/Model_update_manager_ListView_ItemReady.png](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemReady.png)

A marca redonda vermelha indica que não é possível atualizar o arquivo (os motivos podem ser diversos: o arquivo foi movido, o suplemento está desativado no [Addin Manager](900.md), o sistema CAD não está disponível etc.). Nesse caso, não é possível marcar a caixa de seleção.

![images/download/attachments/157859447/Model_update_manager_ListView_ItemNotReady.png](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemNotReady.png)

> Um clique duplo na linha abre a pasta que contém o arquivo.

3. O botão **Update** / **Close** funciona da seguinte forma:

- se pelo menos um arquivo estiver selecionado, é exibido o botão **Update**; caso contrário, o botão **Close**;
- ao clicar em **Update**, todos os arquivos selecionados são atualizados e a janela é fechada;
- ao clicar em **Close**, a janela é fechada (funciona da mesma forma que clicar em **X**).

## Atualização a partir do sistema CAD

A importação de arquivos é sempre feita no grupo ativo; portanto, o comportamento do sistema CAM depende de qual grupo está [ativo](1.md):

- se você quiser atualizar um modelo importado anteriormente, torne esse grupo ativo ou vá para o sistema CAM e atualize o modelo a partir dele;

![images/download/attachments/157859447/image2019-1-10_14-9-59.png](assets/images/download/attachments/157859447/image2019-1-10_14-9-59.png)

- se você quiser adicionar novamente um modelo importado anteriormente, torne ativo qualquer outro nó.

![images/download/attachments/157859447/image2019-1-10_14-11-2.png](assets/images/download/attachments/157859447/image2019-1-10_14-11-2.png)
