# Aggiornamento della struttura del modello geometrico

Durante l'aggiornamento, i [gruppi](603.md) precedenti nel modello vengono sostituiti da quelli nuovi; in questo modo vengono mantenute tutte le [trasformazioni spaziali](116.md) eseguite in precedenza e i gruppi eventualmente creati dall'utente (ad esempio, la [sezione](289.md)). La verifica della modifica del file viene eseguita quando la finestra del sistema CAM diventa attiva.

Se il file importato è stato modificato, il nome del gruppo viene evidenziato in **grassetto**, compare il pulsante della barra degli strumenti "Model files update manager" (gestione dell'aggiornamento dei file del modello) ![images/download/attachments/157859447/Ico_Refresh_All.png](assets/images/download/attachments/157859447/Ico_Refresh_All.png) e nel menu a comparsa viene aggiunto un altro comando, **Update** (aggiorna).

![images/download/attachments/157859447/image2019-1-9_14-29-19.png](assets/images/download/attachments/157859447/image2019-1-9_14-29-19.png)

Esistono due modalità di aggiornamento:

- dal sistema CAM:
  - tramite Model files update manager;
  - tramite il menu contestuale **Update**.

- dal sistema CAD in cui è installato il [componente aggiuntivo del sistema CAM](10039.md).

<a id="updating-from-cam-system"></a>

## Aggiornamento dal sistema CAM

<a id="model-files-update-manager"></a>

### Model files update manager

Dopo l'importazione del file del modello, il sistema CAM controlla periodicamente la data di modifica di tale file. Non appena viene rilevata una modifica, compare la seguente finestra:

![images/download/attachments/157859447/image2019-1-9_14-30-38.png](assets/images/download/attachments/157859447/image2019-1-9_14-30-38.png)

> Se si chiude semplicemente la finestra <strong>Model files update manager</strong>, questa ricompare la volta successiva solo quando viene rilevata una nuova modifica.

Questa finestra contiene l'elenco dei modelli importati, ossia dei file modificati. Da qui è possibile aggiornarli.

> Il Model files update manager può essere aperto anche con il pulsante ![images/download/attachments/157859447/Ico_Refresh_All.png](assets/images/download/attachments/157859447/Ico_Refresh_All.png), se è disponibile sulla barra.

<a id="description-of-the-window-model-files-update-manager"></a>

### Descrizione della finestra Model files update manager

![images/download/attachments/157859447/shot1.png](assets/images/download/attachments/157859447/shot1.png)

1. Il pulsante **All** (tutti) seleziona tutti i file, il pulsante **None** (nessuno) deseleziona tutte le caselle.

2. In questa sezione è presente l'elenco di tutti i file importati che sono stati modificati. La casella di controllo accanto al file indica che il file è contrassegnato e che, dopo aver premuto il pulsante **Update**, verrà aggiornato.

> Verranno aggiornati solo i file selezionati.

Il contrassegno tondo verde indica che il file è disponibile per l'aggiornamento:

![images/download/attachments/157859447/Model_update_manager_ListView_ItemReady.png](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemReady.png)

Il contrassegno tondo rosso indica che l'aggiornamento del file è impossibile (i motivi possono essere diversi: il file è stato spostato, il componente aggiuntivo nell'[Addin Manager](900.md) è disattivato, il sistema CAD non è disponibile, ecc.). In questo caso non è possibile selezionarlo (spuntare la casella)

![images/download/attachments/157859447/Model_update_manager_ListView_ItemNotReady.png](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemNotReady.png)

> Un doppio clic sulla riga apre la cartella contenente il file.

3. Il pulsante **Update** / **Close** funziona come segue:

- se è selezionato almeno un file, viene mostrato il pulsante **Update**, altrimenti il pulsante **Close**;
- facendo clic su **Update** — tutti i file selezionati vengono aggiornati e la finestra si chiude;
- facendo clic su **Close** — la finestra viene chiusa (equivale a fare clic su **X**).

<a id="updating-from-cad-system"></a>

## Aggiornamento dal sistema CAD

L'importazione dei file avviene sempre nel gruppo attivo, quindi il comportamento del sistema CAM dipende da quale gruppo è [attivo](1.md):

- Per aggiornare un modello importato in precedenza, occorre rendere attivo questo gruppo oppure passare al sistema CAM ed eseguire l'aggiornamento da lì;

![images/download/attachments/157859447/image2019-1-10_14-9-59.png](assets/images/download/attachments/157859447/image2019-1-10_14-9-59.png)

- Per aggiungere di nuovo un modello importato in precedenza, è necessario rendere attivo un altro nodo qualsiasi.

![images/download/attachments/157859447/image2019-1-10_14-11-2.png](assets/images/download/attachments/157859447/image2019-1-10_14-11-2.png)
