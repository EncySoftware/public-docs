# Aktualisierung der Struktur des geometrischen Modells

Bei der Aktualisierung werden die bisherigen [Gruppen](603.md) im Modell durch neue ersetzt. Bereits vorgenommene [räumliche Transformationen](116.md) und zusätzlich vom Benutzer erstellte Gruppen, beispielsweise für einen [Schnitt](289.md), bleiben erhalten. Das System prüft auf Dateiänderungen, sobald das Fenster des CAM-Systems aktiv wird.

Wenn eine importierte Datei geändert wurde, wird der Gruppenname **fett** dargestellt. In der Symbolleiste erscheint die Schaltfläche **Model files update manager** (Aktualisierungsmanager für Modelldateien) ![Aktualisierungsmanager öffnen](assets/images/download/attachments/157859447/Ico_Refresh_All.png), und das Kontextmenü wird um den Befehl **Update** (Aktualisieren) ergänzt.

![Aktualisierung eines importierten Modells](assets/images/download/attachments/157859447/image2019-1-9_14-29-19.png)

Für die Aktualisierung gibt es zwei Möglichkeiten:

- aus dem CAM-System:
  - über den Aktualisierungsmanager für Modelldateien;
  - über den Kontextmenübefehl **Update**;
- aus dem CAD-System, in dem ein [Add-in für das CAM-System](10039.md) installiert ist.

## Aktualisierung aus dem CAM-System

### Aktualisierungsmanager für Modelldateien

Nach dem Importieren der Modelldatei überprüft das CAM-System regelmäßig das Änderungsdatum dieser Datei. Sobald eine Änderung erkannt wird, erscheint das folgende Fenster:

![Aktualisierungsmanager für Modelldateien](assets/images/download/attachments/157859447/image2019-1-9_14-30-38.png)

> Wenn Sie das Fenster **Aktualisierungsmanager für Modelldateien** schließen, wird es erst wieder angezeigt, wenn eine weitere Änderung erkannt wird.

Dieses Fenster enthält eine Liste der importierten Modelle und Dateien, die geändert wurden. Hier können Sie sie aktualisieren.

> Der Aktualisierungsmanager für Modelldateien kann auch über die Schaltfläche ![Aktualisierungsmanager öffnen](assets/images/download/attachments/157859447/Ico_Refresh_All.png) geöffnet werden, sofern diese in der Symbolleiste verfügbar ist.

### Beschreibung des Fensters Aktualisierungsmanager für Modelldateien

![Bedienelemente des Aktualisierungsmanagers](assets/images/download/attachments/157859447/shot1.png)

1. Mit **All** (Alle) wählen Sie alle Dateien aus. Mit **None** (Keine) heben Sie die Auswahl aller Dateien auf.
2. Die Liste enthält alle importierten Dateien, die geändert wurden. Ein aktiviertes Kontrollkästchen neben einer Datei zeigt an, dass diese ausgewählt ist und beim Klicken auf **Update** aktualisiert wird.

> Nur die ausgewählten Dateien werden aktualisiert.

Die grüne runde Markierung zeigt an, dass die Datei aktualisiert werden kann:

![Datei kann aktualisiert werden](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemReady.png)

Die rote runde Markierung zeigt an, dass die Datei nicht aktualisiert werden kann. Mögliche Ursachen sind beispielsweise eine verschobene Datei, ein im [Addin Manager](900.md) deaktiviertes Add-in oder ein nicht verfügbares CAD-System. In diesem Fall kann das Kontrollkästchen nicht aktiviert werden.

![Datei kann nicht aktualisiert werden](assets/images/download/attachments/157859447/Model_update_manager_ListView_ItemNotReady.png)

> Ein Doppelklick auf die Zeile öffnet den Ordner, der die Datei enthält.

3. Die Schaltfläche **Update** / **Close** (Aktualisieren / Schließen) funktioniert wie folgt:

   - Wenn mindestens eine Datei ausgewählt ist, wird **Update** angezeigt, andernfalls **Close**.
   - Beim Klicken auf **Update** werden alle ausgewählten Dateien aktualisiert und das Fenster wird geschlossen.
   - Beim Klicken auf **Close** wird das Fenster geschlossen. Dies entspricht dem Klicken auf **X**.

## Aktualisierung aus dem CAD-System

Dateien werden immer in die aktive Gruppe importiert. Das Verhalten des CAM-Systems hängt daher davon ab, welche Gruppe [aktiv](1.md) ist:

- Um ein bereits importiertes Modell zu aktualisieren, aktivieren Sie dessen Gruppe. Alternativ wechseln Sie zum CAM-System und führen die Aktualisierung dort aus.

![Vorhandenes Modell aktualisieren](assets/images/download/attachments/157859447/image2019-1-10_14-9-59.png)

- Um ein bereits importiertes Modell erneut einzufügen, aktivieren Sie einen anderen Knoten.

![Modell erneut einfügen](assets/images/download/attachments/157859447/image2019-1-10_14-11-2.png)
