# Aba Adicionais

Para configurar o registro de eventos do sistema e as definições de atualização, use a página **Additional**.

Os registros são úteis quando você encontra problemas que são difíceis de explicar em palavras ou que ocorrem somente quando uma sequência específica de ações é executada.

![images/download/attachments/157859012/image2024-7-1_17-45-18.png](assets/images/download/attachments/157859012/image2024-7-1_17-45-18.png)

## Configurações de atualização:

- Para ativar as verificações automáticas de atualização, ative a opção **Check for updates**.
- Ative <strong>`Semi-automatic update`</strong> para iniciar o download das atualizações imediatamente após clicar na notificação "Updates found".

## Configurações de registro:

- Para ativar o registro, marque a opção **Use logs**. Os registros são úteis para diagnosticar problemas que são difíceis de descrever ou que ocorrem somente durante uma sequência específica de ações.
- O campo **Log folder** permite especificar o local onde o sistema salvará os arquivos de registro.
- Para enviar automaticamente relatórios de erros, marque a opção **Send report after incorrect application finish**.
- A opção **Check Program Compatibility Assistance items** exclui o sistema das verificações de compatibilidade com outros programas feitas pelo [Program Compatibility Assistant](https://msdn.microsoft.com/ru-ru/windows/compatibility/pca-scenarios-for-windows-8).
- Para registrar a interação do sistema com o interpretador (usado na [simulação de usinagem por programa NC](10291.md) e nas [operações baseadas em código G](10379.md)), ative a opção **Use log interaction with the interpreter**.

## Configurações do editor externo:

O painel <strong>`External STCX-editor`</strong> afeta a janela de [geração de programa NC](69.md) e permite que você selecione um editor externo para modificar os programas NC.
