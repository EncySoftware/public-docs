# Registerkarte Zusätzlich

Die Seite **Additional** (Zusätzlich) dient zur Konfiguration der Ereignisprotokollierung und der Aktualisierungseinstellungen.

Protokolle helfen bei der Diagnose von Problemen, die sich schwer beschreiben lassen oder nur nach einer bestimmten Abfolge von Aktionen auftreten.

![images/download/attachments/157859012/image2024-7-1_17-45-18.png](assets/images/download/attachments/157859012/image2024-7-1_17-45-18.png)

<a id="update-settings"></a>

## Aktualisierungseinstellungen:

- Aktivieren Sie **Check for updates** (Nach Updates suchen), um automatisch nach Aktualisierungen zu suchen.
- Aktivieren Sie **Semi-automatic update**, damit der Download unmittelbar nach dem Anklicken der Benachrichtigung über gefundene Updates beginnt.

<a id="logging-settings"></a>

## Protokollierung:

- **Use logs (Protokolle verwenden).** Aktiviert die Protokollierung zur Diagnose schwer beschreibbarer oder nur bei bestimmten Aktionsfolgen auftretender Probleme.
- **Log folder (Protokollordner).** Legt den Speicherort für Protokolldateien fest.
- **Send report after incorrect application finish.** Aktiviert das automatische Senden von Fehlerberichten nach einer fehlerhaften Programmbeendigung.
- **Check Program Compatibility Assistance items.** Nimmt das CAM-System von den Prüfungen des [Programmkompatibilitäts-Assistenten](https://msdn.microsoft.com/ru-ru/windows/compatibility/pca-scenarios-for-windows-8) aus.
- **Use log interaction with the interpreter.** Protokolliert die Zusammenarbeit mit dem Interpreter, der bei der [Simulation anhand eines NC-Programms](10291.md) und in [G-Code-basierten Operationen](10379.md) verwendet wird.

<a id="external-editor-settings"></a>

## Externer Editor:

Der Bereich **External STCX-editor** wirkt sich auf das Fenster zur [NC-Programmerzeugung](69.md) aus. Dort wählen Sie einen externen Editor zum Bearbeiten von NC-Programmen.

## Expertenwerkzeuge:

**Show expert tools** blendet erweiterte Werkzeuge für erfahrene Benutzer ein.
