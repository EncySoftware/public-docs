# Funzione di selezione multipla

Utilizzare la barra delle azioni mobile per selezionare gli elementi che hanno attributi comuni. Selezionare un elemento qualsiasi e attivare l'opzione di selezione multipla.

![images/download/attachments/157865926/image2024-7-17_14-42-33.png](assets/images/download/attachments/157865926/image2024-7-17_14-42-33.png)

Un pannello a comparsa mostra le proprietà dell'elemento selezionato. Utilizzare le caselle di controllo per filtrare la selezione in base ai valori delle proprietà dell'elemento selezionato. Se una proprietà è selezionata, vengono scelti solo gli elementi con lo stesso valore di tale proprietà. Ad esempio, per selezionare tutti gli elementi con sovrametallo pari a 0 mm, selezionare uno di essi e spuntare la proprietà **Profile stock** (sovrametallo del profilo).
