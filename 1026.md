# Bauteilkopie

<a id="application-area"></a>

## Anwendungsbereich:

**Copy of part** (Bauteilkopie) ist eine besondere Form der Bauteilgruppe für Projekte mit mehreren identischen Bauteilen. Üblicher Ablauf:

- Erstellen Sie das ursprüngliche **Bauteil** und fügen Sie die benötigten Bearbeitungsoperationen hinzu.
- Erstellen Sie eine **Bauteilkopie**. Enthält das Projekt mehrere Bauteile, dient das aktuell ausgewählte Bauteil als Vorlage.
- Legen Sie **Workpiece setup** und **Workpiece CS** für die Kopie fest.

Eine Bauteilkopie ist eine mit der Vorlage synchronisierte Operationsgruppe. In der Kopie können Operationen weder hinzugefügt noch gelöscht werden. Änderungen an der Operationsliste der Vorlage werden auf alle Bauteilkopien übertragen. Die enthaltenen Operationskopien berechnen keinen eigenen Werkzeugweg, sondern übertragen den Werkzeugweg der Vorlage an die Position der Bauteilkopie. Wird eine Vorlagenoperation zurückgesetzt, werden auch ihre Kopien zurückgesetzt. Deren Neuberechnung muss manuell gestartet werden.

Die Bearbeitung der Kopien kann als Folge von Unterprogrammaufrufen ausgegeben werden. Die Ausgabeart wird in den Parametern des ursprünglichen Bauteils festgelegt. Prüfen Sie vor der Verwendung, ob der Postprozessor Unterprogramme unterstützt.

Für jede Operation der Gruppe können eigene Kopierparameter festgelegt werden.

## Einrichtung:

Auf der Registerkarte **Setup** werden grundlegende Projektparameter festgelegt, beispielsweise die Bauteillage auf der Maschine und das Werkstückkoordinatensystem. [Details](1022.md)
