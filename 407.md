![images/download/attachments/157862109/image2025-10-13_16-13-12.png](assets/images/download/attachments/157862109/image2025-10-13_16-13-12.png)

## Área de aplicação:

No sistema CAM, é possível definir vários tipos de padrões de furos. Um padrão não precisa ter uma construção geométrica do furo.

### Tipos de padrão

Com base em determinadas regras, é possível definir os seguintes padrões:

- Linear
- Circular
- Angular
- Concêntrico
- Paralelogramo

O sistema usa cinco tipos de padrão: **Linear**, **Circular**, **Angular**, **Concentric** e **Parallelogram**.

### Uso de padrões para mergulho axial

O uso de padrões de furos em conjunto com a determinação automática dos níveis dos furos permite executar o desbaste da peça pela estratégia de mergulho axial.
