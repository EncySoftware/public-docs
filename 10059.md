# 3D-Modell exportieren

Die Funktion wird über das [Hauptmenü](51.md) oder **Save as** im Kontextmenü des [Modellstrukturfensters](718.md) aufgerufen. Im Dateidialog wählen Sie ein unterstütztes Format.

- **STL:** Räumliche Modelle als Dreiecksnetz. Die Datei *.stl wird als Text gespeichert.
- **DXF:** Vorwiegend ebene Zeichnungen und Vektorgeometrie. Räumliche Daten hängen von der Formatversion ab. Derzeit werden nur Kurven und Punkte exportiert. Dateiendung: *.dxf.
- **OpenGL-Stream-Daten:** Internes Format für 3D-Modelle einzelner Komponenten eines Maschinenschemas. Dateiendung: *.osd.
