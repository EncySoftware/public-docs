# Exportação do modelo 3D

A função pode ser ativada no [menu principal](51.md) ou no item **Salvar como** do menu pop-up da [janela de estrutura do modelo geométrico](718.md). Essa ação abre uma caixa de diálogo de arquivo em que o usuário pode selecionar um dos formatos suportados.

- O formato **STL** permite fornecer modelos volumétricos como uma coleção de triângulos planos. A extensão do arquivo é *.stl. O arquivo é salvo como texto.
- O formato **DXF** é usado basicamente para fornecer desenhos planos e desenhos vetoriais. Os modelos volumétricos também podem ser exportados, mas têm diferenças essenciais dependendo da versão. Neste momento, há suporte apenas para a exportação de curvas e pontos. A extensão do arquivo é *.dxf.
- O **OpenGL stream data** é um formato interno do sistema CAM. É usado para salvar modelos 3D de unidades individuais de esquemas cinemáticos de máquinas. A extensão do arquivo é *.osd.
