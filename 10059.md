# Esportazione del modello 3D

La funzione può essere attivata dal [menu principale](51.md) oppure con la voce **Save as** del menu contestuale della [finestra della struttura del modello geometrico](718.md). Questa azione apre una finestra di dialogo dei file in cui l'utente può selezionare uno dei formati supportati.

- Il formato **STL** consente di trasferire modelli volumetrici come insieme di triangoli piani. L'estensione del file è *.stl. Il file viene salvato in formato testo.
- Il formato **DXF** è utilizzato principalmente per trasferire disegni piani e disegni vettoriali. È possibile esportare anche modelli volumetrici, ma con differenze sostanziali a seconda della versione. Attualmente è supportata solo l'esportazione di curve e punti. L'estensione del file è *.dxf.
- Il formato **OpenGL stream data** è un formato interno del sistema CAM. Viene utilizzato per salvare i modelli 3D dei singoli componenti degli schemi cinematici delle macchine. L'estensione del file è *.osd.
