# Importazione di oggetti da file VRML

**VRML** (Virtual Reality Modeling Language) è un formato di file per oggetti tridimensionali interattivi e mondi virtuali. Il formato **VRML** è concepito per l'uso su Internet (ed è di fatto lo standard della grafica 3D in rete). I file VRML sono utilizzati anche nei sistemi locali.

Ogni file VRML è una descrizione di uno spazio 3D contenente oggetti grafici. La scena può essere modificata dinamicamente tramite diversi meccanismi del linguaggio.

Per progettare una tecnologia di lavorazione serve l'informazione sulla geometria dell'oggetto; attributi quali sorgente luminosa, colore dello sfondo, trasparenza o angolo di smussatura, elementi di animazione ed elaborazione degli eventi non sono rilevanti e vengono pertanto ignorati.

Nella versione corrente sono supportati i seguenti oggetti geometrici:

- **Box**;
- **Cone**;
- **Cylinder**;
- **ElevationGrid**;
- **Extrusion**;
- **IndexedFaceSet**;
- **IndexedLineSet**;
- **Sphere**;

Vengono importate le informazioni sul colore degli oggetti geometrici, sulla loro posizione e sulle trasformazioni spaziali. Sono supportati anche gli oggetti con nome.

<strong>Limitazioni:</strong>

- Non è possibile importare l'oggetto **TEXT**.
- Il blocco **Inline**, utilizzato per prelevare dati da altri file e da Internet, viene ignorato.
- Non è consigliato utilizzare file VRL con sezioni **PROTO** e **EXTERNPROTO**, a causa del loro supporto parziale.

<strong>Requisiti per i file VRML:</strong>

- I file vengono importati in formato `VRML 2.0`.
- La presenza dell'intestazione di file `#VRML V2.0 utf8` è obbligatoria, altrimenti il file viene considerato in un formato non corretto.
- Un file compresso deve prima essere decompresso.
