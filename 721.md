# Importação de objetos de arquivos VRML

**VRML** (Virtual Reality Modeling Language) - esse é um formato de arquivo para objetos tridimensionais interativos e mundos virtuais. O formato **VRML** foi projetado para uso na Internet (e é basicamente o padrão de gráficos 3D na rede). Os arquivos VRML também são usados em sistemas locais.

Cada arquivo VRML é uma descrição do espaço 3D que contém objetos gráficos. A cena pode ser alterada dinamicamente usando diferentes mecanismos de linguagem.

Para projetar uma tecnologia de usinagem, são necessárias informações sobre a geometria do objeto, e atributos como fonte de luz, cor de fundo, transparência ou ângulo de suavização, elementos de animação e processamento de eventos são irrelevantes e, portanto, serão ignorados.

Na versão atual, há suporte para os seguintes objetos geométricos:

- **Box**;
- **Cone**;
- **Cylinder**;
- **ElevationGrid**;
- **Extrusion**;
- **IndexedFaceSet**;
- **IndexedLineSet**;
- **Sphere**;

São importadas informações sobre a cor dos objetos geométricos, sua localização e transformações espaciais. Também há suporte para objetos nomeados.

<strong>Limitações:</strong>

- Não é possível importar o objeto **TEXT**.
- Ignora o bloco **Inline** para usar dados de outros arquivos e da Internet.
- Não é recomendável usar arquivos VRL com as seções **PROTO** e **EXTERNPROTO**, devido ao seu suporte parcial.

<strong>Requisitos para arquivos VRML:</strong>

- Os arquivos são importados no formato `VRML 2.0`.
- A presença de um cabeçalho de arquivo `#VRML V2.0 utf8` é obrigatória; caso contrário, o arquivo será considerado como estando em um formato incorreto.
- Um arquivo compactado deve ser descompactado primeiro.
