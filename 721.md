# Importieren von Objekten aus VRML-Dateien

**VRML** (Virtual Reality Modeling Language) ist ein Dateiformat für interaktive dreidimensionale Objekte und virtuelle Welten. Es wurde für die Verwendung im Internet entwickelt und wird auch in lokalen Systemen eingesetzt.

Eine VRML-Datei beschreibt einen dreidimensionalen Raum mit grafischen Objekten. Die Szene kann mithilfe verschiedener Sprachmechanismen dynamisch verändert werden.

Für die Erstellung eines Bearbeitungsprozesses wird die Objektgeometrie benötigt. Attribute wie Lichtquellen, Hintergrundfarbe, Transparenz, Glättungswinkel, Animationen und Ereignisverarbeitung werden daher ignoriert.

Die aktuelle Version unterstützt folgende geometrische Objekte:

- **Box**;
- **Cone**;
- **Cylinder**;
- **ElevationGrid**;
- **Extrusion**;
- **IndexedFaceSet**;
- **IndexedLineSet**;
- **Sphere**;

Farben, Positionen und räumliche Transformationen geometrischer Objekte werden importiert. Benannte Objekte werden ebenfalls unterstützt.

**Einschränkungen:**

- Das Objekt **TEXT** kann nicht importiert werden.
- Der Block **Inline** zum Einbinden von Daten aus anderen Dateien oder aus dem Internet wird ignoriert.
- Dateien mit Abschnitten **PROTO** und **EXTERNPROTO** werden wegen deren nur teilweiser Unterstützung nicht empfohlen.

**Anforderungen an VRML-Dateien:**

- Importiert werden Dateien im Format `VRML 2.0`.
- Der Dateikopf `#VRML V2.0 utf8` ist erforderlich. Fehlt er, wird das Format als ungültig eingestuft.
- Komprimierte Dateien müssen vor dem Import entpackt werden.
