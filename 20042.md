# Point Pick-and-Place

![images/download/attachments/157866405/image2024-7-30_15-2-25.png](assets/images/download/attachments/157866405/image2024-7-30_15-2-25.png)

It's based on the [Pick-and-place](10404.md) operation.

The <strong>job assignment ![images/download/thumbnails/157866405/image2022-5-20_10-9-9.png](assets/images/download/thumbnails/157866405/image2022-5-20_10-9-9.png)</strong> is built on nodal points. At points, a position is set for moving the machine. By adding and removing points, you can set the desired movement of the part.

A <strong>job assignment</strong> consists of several types of points:

1. ![images/download/thumbnails/157866405/1.png](assets/images/download/thumbnails/157866405/1.png) Start point
2. ![images/download/thumbnails/157866405/2.png](assets/images/download/thumbnails/157866405/2.png) Pick point
3. ![images/download/thumbnails/157866405/3.png](assets/images/download/thumbnails/157866405/3.png) Move point (relative to Pick point)
4. ![images/download/thumbnails/157866405/4.png](assets/images/download/thumbnails/157866405/4.png) Move point (relative to Place point)
5. ![images/download/thumbnails/157866405/5.png](assets/images/download/thumbnails/157866405/5.png) Place point
6. ![images/download/thumbnails/157866405/6.png](assets/images/download/thumbnails/157866405/6.png) End point These points can be used to construct a chain of trajectories.

![images/download/attachments/157866405/image2024-7-30_15-1-27.png](assets/images/download/attachments/157866405/image2024-7-30_15-1-27.png)

1. ![images/download/thumbnails/157866405/1.png](assets/images/download/thumbnails/157866405/1.png) Start point It is read-only. This is the end point of the previous operation
2. ![images/download/thumbnails/157866405/2.png](assets/images/download/thumbnails/157866405/2.png) Pick point The grip position of the part. Properties: ![images/download/attachments/157866405/image2024-7-30_15-11-57.png](assets/images/download/attachments/157866405/image2024-7-30_15-11-57.png) Pick position is defined in geometry coordinate system with <strong>additional transformations.</strong> if <strong>Pick only</strong> is selected, the trajectory stops at this point. ![images/download/thumbnails/157866405/image2022-5-20_9-56-39.png](assets/images/download/thumbnails/157866405/image2022-5-20_9-56-39.png) Axes - machine axis at the current point. When changing axes, two buttons appear: ![images/download/attachments/157866405/image2024-7-30_16-1-43.png](assets/images/download/attachments/157866405/image2024-7-30_16-1-43.png) ![images/download/attachments/157866405/ok.png](assets/images/download/attachments/157866405/ok.png) - moves the point to the tip of the machine ![images/download/thumbnails/157866405/cancel.png](assets/images/download/thumbnails/157866405/cancel.png) - returns previous values ![images/download/attachments/157866405/minus.png](assets/images/download/attachments/157866405/minus.png) ![images/download/thumbnails/157866405/Plus.png](assets/images/download/thumbnails/157866405/Plus.png) - 360/+360 ![images/download/thumbnails/157866405/image2022-5-16_17-36-18.png](assets/images/download/thumbnails/157866405/image2022-5-16_17-36-18.png) Flip - controls flips in the robot
3. ![images/download/thumbnails/157866405/3.png](assets/images/download/thumbnails/157866405/3.png) Move point (relative to Pick point) The page has buttons "Add position before" and Add position after" to add intermediate points. By default, points are added relative to the selected one. if you change the initial position of the part, then by default this point will also move. Properties: ![images/download/thumbnails/157866405/image2022-5-20_9-39-39.png](assets/images/download/thumbnails/157866405/image2022-5-20_9-39-39.png) Fix vX - enable 6 axis edit mode: ![images/download/attachments/157866405/image2022-5-16_17-21-45.png](assets/images/download/attachments/157866405/image2022-5-16_17-21-45.png) ![images/download/attachments/157866405/MultiGOTO.png](assets/images/download/attachments/157866405/MultiGOTO.png) Motion type - is set by what type to move to the point:
  - MultiGoto - Multi coordinate movement
  - ![images/download/attachments/157866405/PGoto.png](assets/images/download/attachments/157866405/PGoto.png) PhysicGoto - Physical machine axes movement
  - ![images/download/attachments/157866405/AvoidColls.png](assets/images/download/attachments/157866405/AvoidColls.png) Avoid collisions - Collision avoidance movement
4. ![images/download/thumbnails/157866405/4.png](assets/images/download/thumbnails/157866405/4.png) Move point (relative to Place point) Differs from the previous point in that the point moves with the end position of the part.
5. ![images/download/thumbnails/157866405/5.png](assets/images/download/thumbnails/157866405/5.png) Place point Position where the part should be placed. The position where the part is to be placed is defined by the [workpiece connector](54.md) and [workpiece setup](10066.md). All movements of the gripper is generated in the defined [workpiece coordinate system](726.md). ![images/download/attachments/157866405/image2024-7-30_16-9-9.png](assets/images/download/attachments/157866405/image2024-7-30_16-9-9.png)
6. ![images/download/thumbnails/157866405/6.png](assets/images/download/thumbnails/157866405/6.png) End point This is a return to the tool change point. If it is off, then the trajectory ends at a Place point.

<strong>Clearance point</strong>

Using these points you can define the length and the direction for the engage/retract movements to the pick and/or place positions.
