# Makroquellcode bearbeiten

<a id="application-area"></a>

## Anwendungsbereich:

Jedes Makro ist eine aus aufgezeichneten Schritten erzeugte Erweiterung. Die Aufzeichnung deckt übliche Abläufe ab; der generierte Quellcode ist eine vollständige Erweiterung.

Das Öffnen des Codes ist sinnvoll für:

- eigene Logik, Schleifen oder Bedingungen über die Aufzeichnung hinaus;

- das Erlernen der CAM-API anhand eines ausführbaren Beispiels;

- neue Erweiterungen auf Basis einer funktionierenden Vorlage.

<a id="net-and-spr"></a>

### .NET und Spr

Die Sprache wird beim Speichern gewählt und im Makro beibehalten. [Details](102459.md)

**.NET.** Der C#-Quellcode wird als Erweiterung gegen die CAM-API kompiliert. Dies eignet sich für C#-Entwicklung und die Verwendung weiterer .NET-Komponenten.

**Spr.** Der Code wird in der integrierten Skriptsprache erstellt und im Spr-Editor geöffnet.

Der Aufruf aus der Makroliste ist gleich; unterschiedlich ist der bearbeitete Quellcode.

<a id="opening-a-macro-in-an-editor"></a>

### Im Editor öffnen

1. Wählen Sie im Menü **…** des Makros **Open in editor**.

2. Das System öffnet C#-Quellcode für .NET oder das `.spr`-Skript im Spr-Editor.

3. Nehmen Sie die Änderungen vor und speichern Sie sie.

Bei .NET enthält der Ordner `Extension.cs` sowie Projektdateien wie `commands.json`, `manifest.json` und die `.csproj`-Datei:

<a id="how-edits-take-effect"></a>

### Änderungen wirksam machen

- **Spr:** Das Skript wird direkt ausgeführt; Speichern genügt.

- **.NET:** C#-Änderungen werden nach erneutem Erstellen des Makros wirksam. Dabei wird die Build-Umgebung wie beschrieben geprüft. [Details](102459.md)

<a id="source-code-location"></a>

### Speicherort

Quellcode und lesbare Schrittliste liegen gemeinsam im Makroordner unter `macros` im persönlichen CAM-Systemordner. Halten Sie diesen Ordner zusammen, damit Makro und Quellen synchron bleiben.
