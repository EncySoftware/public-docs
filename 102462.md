## Área de aplicação:

Cada macro é uma pequena extensão gerada pelo sistema a partir das etapas gravadas. A gravação atende aos casos comuns, e o código-fonte gerado constitui uma extensão totalmente funcional.

Abrir o código-fonte é útil para:

- acrescentar recursos além dos disponíveis na gravação, como lógica personalizada, laços ou condições;

- estudar a API do sistema CAM por meio de um exemplo concreto e executável;

- criar uma nova extensão a partir de um modelo comprovadamente funcional, em vez de um arquivo vazio.

### .NET e Spr

A linguagem é selecionada ao salvar a macro e permanece associada a ela. [Detalhes](102459.md)

**.NET.** A macro é gerada em **C#** e compilada como uma extensão .NET que utiliza a API do sistema CAM. Essa opção permite desenvolver a macro em C# e utilizar os recursos do ecossistema .NET.

**Spr.** A macro é gerada na linguagem de scripts **Spr**, integrada ao sistema CAM, e aberta no editor Spr integrado. Selecione essa opção para trabalhar nessa linguagem.

As duas opções são executadas da mesma forma pela lista de macros; a diferença está apenas no código-fonte editado.

### Abertura de uma macro no editor

1. Na lista de macros, abra o menu **…** da macro e selecione **Open in editor**.

2. O sistema abre o código-fonte gerado: o código C# para uma macro **.NET** ou o script `.spr` no editor **Spr**.

3. Faça as alterações e salve.

### Aplicação das alterações

- Uma macro **Spr** é executada diretamente a partir do script. Portanto, basta salvar o script editado.

- Uma macro **.NET** é executada a partir de um arquivo compilado. As alterações em C# passam a valer após a recompilação. Aplica-se a mesma verificação do ambiente de compilação descrita no salvamento da macro. [Detalhes](102459.md)

### Localização do código-fonte

O código-fonte e a lista legível das etapas são armazenados juntos na pasta da macro, no diretório `macros` da pasta pessoal do sistema CAM. Manter a pasta completa garante que a macro e seu código-fonte permaneçam sincronizados.
