# Soldagem

Essa operação está disponível como opção do sistema CAM.

Ela implementa o cálculo automático da geometria do cordão de solda sem vínculo com um tipo específico de equipamento de soldagem, ou seja, não gera os comandos específicos para laser, arco elétrico, maçaricos a gás, emissores ultrassônicos etc. A configuração da operação para trabalhar com um tipo específico de equipamento pode ser feita escrevendo no pós-processador os comandos apropriados para controlar o equipamento ou, se isso não for suficiente, adicionando uma operação especial com base na operação Welding 5D, adaptada para controlar o equipamento específico.

Observação: a opção deve ser licenciada separadamente.
