# Schweißen

Diese Operation ist als zusätzliche Option verfügbar.

Sie berechnet die Schweißnahtgeometrie unabhängig vom konkreten Schweißverfahren. Spezifische Befehle für Laser, Lichtbogen, Gasbrenner oder Ultraschall werden nicht automatisch festgelegt. Die Anpassung an die Anlage erfolgt über entsprechende Postprozessorbefehle oder, falls erforderlich, über eine spezialisierte Operation auf Grundlage von **Welding 5D**.

Hinweis: Die Option muss separat lizenziert werden.
