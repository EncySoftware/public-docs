## Anwendungsbereich:

Werkzeugbaugruppen beschreiben die Ausrüstung als verbundene Komponenten: ein Schneidwerkzeug mit einem oder mehreren Adaptern zur Aufnahme im Maschinenmagazin. Sie unterstützen die automatische Werkzeugauswahl als Voraussetzung für eine automatische Prozessgenerierung.

Dafür müssen zwei Bedingungen erfüllt sein:

- Das Werkzeug ist in der Benutzerdatenbank vorhanden.

- Ein geeigneter Adapter ermöglicht die korrekte Aufnahme im Maschinenmagazin.

<a id="tool-operation-modes"></a>

### Werkzeugmodi

Das CAM-System unterstützt zwei Modi:

- **Classic tools mode.** Klassischer Werkzeugmodus.

- **Advanced tools mode.** Arbeit mit Werkzeugbaugruppen. In diesem Modus erscheint die Schaltfläche **Equipment** auf der Technologieseite.
