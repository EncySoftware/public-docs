# Solução de problemas de autorização no gerenciador de licenças

## Problema: o botão Sign não está disponível na janela License Manager.

## Solução:

1. Verifique a acessibilidade dos recursos webservices.encycam.com e encycam.com usando os comandos de linha de comando: a) <em>ping webservices.encycam.com</em>; b) <em>ping encycam.com</em>. Se o teste for bem-sucedido, será exibido o tempo de resposta do serviço. Caso contrário, resolva o problema de conexão com esses serviços junto ao administrador do sistema local.
2. No navegador padrão, execute a solicitação <em>https://webservices.encycam.com/api/v1/status</em>. Se o serviço de licenciamento estiver acessível, a resposta deverá ser <em>{"status":"OK"}</em>. Qualquer outra resposta indica um erro de conexão com o serviço de licenciamento. Corrija-o com o administrador do sistema, de acordo com o erro retornado.
3. Repita a solicitação no navegador padrão (<strong>Edge</strong> ou <strong>Internet Explorer</strong>), que usa as configurações de proxy e rede do sistema, e não configurações próprias. O License Manager depende dessas configurações.
4. Execute na linha de comando: <em>curl "https://webservices.encycam.com/api/v1/status"</em>. Se o teste for bem-sucedido, a resposta deverá ser <em>{"status":"OK"}</em>. Se for retornado um código de erro, trabalhe com o administrador do sistema para ajustar as configurações de rede.
5. Verifique se o protocolo <strong>IPv4</strong> está ativo e se o <strong>IPv6</strong> está desabilitado nas configurações de rede.

## Problema: o License Manager não inicia.

## Solução:

Feche o License Manager e exclua o diretório <em>%temp%\.net</em>. Reinicie o License Manager e verifique se o problema persiste.

## Problema:

Não foi possível identificar o problema ou as soluções acima não resolveram a situação.

## Solução:

Envie uma mensagem ao suporte técnico em [support@encycam.com](mailto:support@encycam.com). Inclua uma descrição do problema, as etapas para reproduzi-lo, se possível, e anexe o arquivo compactado <em>"%temp%\SCLicenseManagerLog.txt"</em>.
