# Probleme bei der Anmeldung im Lizenzmanager

<a id="problem-the-sign-button-is-unavailable-in-the-license-manager-window"></a>

## Problem: Die Anmeldeschaltfläche ist nicht verfügbar

<a id="solution"></a>

## Anmeldung prüfen

1. Prüfen Sie die Erreichbarkeit mit `ping webservices.encycam.com` und `ping encycam.com`. Bei erfolgreicher Antwort wird die Antwortzeit angezeigt. Andernfalls klären Sie die Verbindung mit der lokalen Systemadministration.
2. Öffnen Sie im Browser `https://webservices.encycam.com/api/v1/status`. Die erwartete Antwort ist `{"status":"OK"}`. Andere Antworten weisen auf ein Verbindungsproblem hin; prüfen Sie die Netzwerkeinstellungen mit der Administration.
3. Wiederholen Sie den Aufruf in **Edge** oder **Internet Explorer**, die die systemweiten Proxy- und Netzwerkeinstellungen verwenden, auf die auch der Lizenzmanager zurückgreift.
4. Prüfen Sie zusätzlich mit `curl "https://webservices.encycam.com/api/v1/status"`. Erwartet wird ebenfalls `{"status":"OK"}`. Bei Fehlern passen Sie die Netzwerkeinstellungen gemeinsam mit der Administration an.
5. Prüfen Sie, dass **IPv4** aktiv und **IPv6** deaktiviert ist.

<a id="problem-the-license-manager-fails-to-start"></a>

## Problem: Der Lizenzmanager startet nicht

<a id="solution-1"></a>

## Startproblem beheben

Schließen Sie den Lizenzmanager und löschen Sie das Verzeichnis `%temp%\.net`. Starten Sie ihn erneut und prüfen Sie das Verhalten.

<a id="problem"></a>

## Problem: Ursache weiterhin unbekannt

Die bisherigen Schritte haben das Problem nicht behoben.

<a id="solution-2"></a>

## Support kontaktieren

Senden Sie eine Anfrage an [support@encycam.com](mailto:support@encycam.com). Beschreiben Sie das Problem und nach Möglichkeit reproduzierbare Schritte. Fügen Sie die Datei `%temp%\SCLicenseManagerLog.txt` als Archiv bei.
