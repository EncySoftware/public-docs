# Risoluzione dei problemi di autorizzazione nel gestore licenze

<a id="problem-the-sign-button-is-unavailable-in-the-license-manager-window"></a>

## Problema: il pulsante Sign non è disponibile nella finestra License Manager.

<a id="solution"></a>

## Soluzione:

1. Verificare l'accessibilità delle risorse web webservices.encycam.com e encycam.com tramite i comandi da riga di comando: a) <em>ping webservices.encycam.com</em> b) <em>ping encycam.com</em> In caso di esito positivo viene restituito il tempo di risposta del servizio. In caso contrario, risolvere il problema di connettività verso tali servizi con l'amministratore di sistema locale.
2. Nel browser predefinito, eseguire la richiesta: <em>https://webservices.encycam.com/api/v1/status</em> Se il servizio di licenze è raggiungibile, la risposta deve essere: <em>{"status":"OK"}</em> Qualsiasi altra risposta indica un errore di connessione al servizio di licenze. Correggere le impostazioni di rete con l'amministratore di sistema in base all'errore restituito.
3. Ripetere la richiesta nel browser predefinito (<strong>Edge</strong> o <strong>Internet Explorer</strong>), che utilizza le impostazioni proxy/di rete di sistema anziché configurazioni proprie, poiché anche il License Manager si basa su queste.
4. Eseguire il comando dalla riga di comando: <em>curl "https://webservices.encycam.com/api/v1/status"</em> In caso di esito positivo, la risposta deve essere: <em>{"status":"OK"}.</em> Se viene restituito un codice di errore, collaborare con l'amministratore di sistema per modificare di conseguenza le impostazioni di rete.
5. Verificare che nelle impostazioni di rete il protocollo <strong>IPv4</strong> sia attivo e <strong>IPv6</strong> sia disattivato.

<a id="problem-the-license-manager-fails-to-start"></a>

## Problema: il License Manager non si avvia.

<a id="solution-1"></a>

## Soluzione:

Chiudere il License Manager ed eliminare la seguente directory: <em>%temp%\.net</em> Riavviare il License Manager e verificare se il problema persiste.

<a id="problem"></a>

## Problema:

Impossibile individuare la causa, oppure le soluzioni precedenti non hanno risolto il problema.

<a id="solution-2"></a>

## Soluzione:

Inviare un messaggio al supporto tecnico all'indirizzo: [support@encycam.com](https://mailto:support@encycam.com/) Includere una descrizione del problema, i passaggi per riprodurlo (se possibile) e allegare il file archiviato: <em>"%temp%\SCLicenseManagerLog.txt"</em>
