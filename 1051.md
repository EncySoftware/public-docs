# Ebenes Slicing

![images/download/attachments/157866716/planar_1.png](assets/images/download/attachments/157866716/planar_1.png)

<a id="application-area"></a>

## Anwendungsbereich:

Diese Operation ermöglicht den 3D-Druck. Die Werkzeugbahn wird anhand der Berechnungen von Ultimaker Cura erzeugt.

<a id="setup"></a>

### Einrichtung:

Auf der Registerkarte **Setup** werden grundlegende Projektparameter festgelegt, beispielsweise die Lage des Bauteils auf der Maschine und das Werkstückkoordinatensystem. [Details](1022.md)

<a id="job-assignment"></a>

### Auftragszuweisung:

**Faces (Flächen).** Wählen Sie die Bauteilflächen für die Auftragszuweisung aus. Das System berechnet die Bahn anhand dieser Flächen.

**Properties (Eigenschaften).** Öffnet die Elementeigenschaften, beispielsweise zur Eingabe eines Aufmaßes. Der Dialog kann auch durch Doppelklick auf den Listeneintrag geöffnet werden.

**Delete (Löschen).** Entfernt ein Element aus der Liste.

<a id="strategy"></a>

### Strategie:

<a id="auto-tool-parameterization"></a>

#### Automatische Werkzeugparametrierung.

Passt Werkzeugdurchmesser und Arbeitslänge automatisch an die Cura-Parameter an.

<a id="general"></a>

#### Allgemeine Einstellungen.

Parameter zur Auswahl der Druckvorgaben:

<details>
<summary>Weitere Informationen anzeigen</summary>

**Manufacturer (Hersteller).** Druckerhersteller.

**Printers (Drucker).** Druckermodelle des ausgewählten Herstellers.

**Extruders (Extruder).** Extruder des ausgewählten Druckers.

**Material brand (Materialhersteller).** Hersteller des Druckmaterials.

**Materials (Materialien).** Materialien des ausgewählten Herstellers.

**Variants (Varianten).** Bei Extrudern enthalten Varianten Einstellungen zur Düsengröße und dazugehörige spezifische Parameter.

**Profiles (Profile).** Anwendungsprofile passen die Druckqualität an den jeweiligen Einsatzzweck an. Sie hängen von Material, Variante und Qualitäts- bzw. Auflösungseinstellung ab.

**Resolutions (Auflösungen).** Qualitätsprofile legen die Druckauflösung über die Schichthöhe fest.

**Show custom parameters (Benutzerdefinierte Parameter anzeigen).** Ermöglicht die individuelle Anpassung der Druckeinstellungen. Für erfahrene Anwender stehen zusätzliche Parameter bereit. Die Anzeigestufen sind **basic**, **advanced**, **expert** und **all**.

</details>
