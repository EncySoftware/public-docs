# Digital Machine Center

## Application area:

**Digital Machine Center** is a catalog of machine components: **Post Processor**, **Interpreter**, **Machine Schema**, and **Kit**. A kit groups components for use together.

## Opening the catalog

On the **Home Page**, select **Clouds** → **Digital Machine Center**. Account sign-in is required for **My Components**, **Favorites**, 3D viewing, and obtaining licenses. [Details](10201021.md)

## Finding components

Sort the catalog by **Recent**, **Popular**, **Name**, or **Access**. Use **All**, **My Components**, or **Favorites** to select the catalog scope. Multiple component types can be selected together.

Use search and **Filters** to narrow the catalog by:

- Machine manufacturer and series.
- CNC control manufacturer and series.
- Machine type, axes, access, units, and publisher.
- **Work area.** X, Y, and Z sliders, in millimeters or inches.

A component card shows an image, license state (**Licensed**, **In License manager**, **Activated**, or **Expired**), favorite star, name, CNC control, machine, component type, axes, work area, and access information.

**Can't find what you need?** Opens a component request form or an email to support.

## Component details

Click a card to view the component. Use the arrows or the Left and Right arrow keys to move between adjacent components. Esc closes the details. A link identifies the component.

**3D.** Displays the machine model, with full-screen viewing and access to model nodes.

The details include a description, kit contents, NC program examples, related components, and information about where the component will appear in the application. Requests for a postprocessor or machine schema and feedback are available from the details.

## Obtaining a component

- **Get Trial.** Requests a trial for a paid component.
- **Get License.** Obtains a license for a free component.
- **Upgrade to full license.** Requests a full license during the trial period.

The text below the button shows how many more licenses can be obtained within 30 days.

The license is activated automatically. The progress bar on **Clouds** shows delivery progress. Component delivery can take up to 20 minutes. Licenses can be inspected in the license manager. [Details](10025.md)
