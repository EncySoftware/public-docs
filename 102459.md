# Makro speichern

<a id="application-area"></a>

## Anwendungsbereich:

Hier werden die Speicherung eines aufgezeichneten oder bearbeiteten Makros, die Wahl der Sprache und die Prüfung der Build-Umgebung beschrieben.

<a id="the-save-panel"></a>

### Speicherpanel

Nach dem Beenden der Aufzeichnung oder Bearbeitung erscheint **Save** mit drei Feldern:

- **Name:** vorgeschlagener Makroname, beispielsweise Macro name 1. Verwenden Sie eine eindeutige Bezeichnung.

- **Language:** .NET oder Spr.

- **Comment:** optionale Beschreibung. Sie wird beim Überfahren des Kommentarsymbols angezeigt und sollte Zweck und geeignete Bauteile kurz erläutern.

![images/download/attachments/162957795/05-save-panel.png](assets/images/download/attachments/162957795/05-save-panel.png)

<a id="choosing-the-language"></a>

### Sprache wählen

- **.NET:** erstellt eine .NET-Erweiterung.

- **Spr:** erstellt ein Makro in der integrierten Skriptsprache Spr.

Beide Varianten werden gleich ausgeführt. Die Sprachwahl ist vor allem für spätere Quellcodeänderungen relevant. [Details](102462.md)

<a id="the-build-environment-check"></a>

### Build-Umgebung prüfen

Beim Öffnen des Panels und bei jedem Sprachwechsel wird geprüft, ob die benötigten Komponenten vorhanden sind. Fehlen sie:

- erscheint **Macro build environment is not ready**, und **Save** ist deaktiviert;

- startet ein Klick auf die Meldung mit Bestätigung von **Try to fix it?** die Einrichtung durch das System.

Anschließend wird erneut geprüft. Sobald die Umgebung bereit ist, wird **Save** freigegeben.

<a id="saving-or-cancelling"></a>

### Speichern oder abbrechen

**Save.** Erstellt das Makro und fügt es zur ausführbaren Liste hinzu. Es wird im persönlichen ENCY-Ordner unter `macros` gespeichert.

**Cancel.** Verwirft die Aufzeichnung ohne Speichern.
