# Controllo multiasse avanzato

Questo modulo amplia le funzioni di lavorazione di macchine/robot (6 o più assi).

Sono disponibili le seguenti funzioni:

- [Macchina interattiva](10009.md)
- [Pannello di controllo della macchina](10008.md)

Questo modulo è disponibile per la [configurazione](10390.md) del sistema CAM:

Per impostazione predefinita per le macchine:

- Cutting
- Wire EDM
- Lathe
- Machinist
- Universal
- 3x Mill
- Expert
- 5x Mill*
- Master*
- Pro*

Per impostazione predefinita per i robot:

- Robot

* - per il supporto dei robot è necessaria la licenza aggiuntiva '[Robot +](10368.md)'.
