# Controle avançado de múltiplos eixos

Esse módulo amplia os recursos de usinagem de máquinas/robôs (6 ou mais eixos).

Recursos disponíveis:

- [Máquina interativa](10009.md)
- [Painel de controle da máquina](10008.md)

Esse módulo está disponível para a seguinte [configuração](10390.md) do sistema CAM:

Por padrão, para máquinas:

- Cutting
- Wire EDM
- Lathe
- Machinist
- Universal
- 3x Mill
- Expert
- 5x Mill*
- Master*
- Pro*

Por padrão, para robôs:

- Robot

* - é necessária a licença adicional '[Robot +](10368.md)' para suporte a robôs.
