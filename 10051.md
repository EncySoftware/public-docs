# SpaceClaim™: Symbolleiste und Import-Add-in

![images/download/attachments/157859692/SpaceClaimFromAddinManager.png](assets/images/download/attachments/157859692/SpaceClaimFromAddinManager.png)

Über die Symbolleiste können Sie geometrische Daten aus SpaceClaim™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859692/image2022-3-30_15-42-57.png](assets/images/download/attachments/157859692/image2022-3-30_15-42-57.png)

Mit dem Add-In können Sie <strong>SpaceClaim™</strong>-Projektdateien importieren.

Unterstützte Dateierweiterungen: SLDASM, ASM, SLDPRT, PRT, SLDDRW, DRW, X_B, X_T, STP, STEP. Damit diese Option ordnungsgemäß funktioniert, muss die erforderliche Anwendung (SpaceClaim™) auf Ihrem Computer installiert sein.
