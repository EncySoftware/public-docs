# Barra de ferramentas e suplemento de importação do SpaceClaim™

![images/download/attachments/157859692/SpaceClaimFromAddinManager.png](assets/images/download/attachments/157859692/SpaceClaimFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do SpaceClaim™. É possível consultar a versão do sistema CAD suportado. [Detalhes](10039.md)

![images/download/attachments/157859692/image2022-3-30_15-42-57.png](assets/images/download/attachments/157859692/image2022-3-30_15-42-57.png)

O suplemento permite importar arquivos de projeto do **SpaceClaim™**.

Extensões suportadas: SLDASM, ASM, SLDPRT, PRT, SLDDRW, DRW, X_B, X_T, STP, STEP. O SpaceClaim™ deve estar instalado no computador para que o recurso funcione.
