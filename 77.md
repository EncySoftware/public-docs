# File di progetto

Un progetto è un file con estensione ".stcp" salvato su disco (in precedenza veniva usata l'estensione ".stc"). Memorizza al proprio interno le informazioni generate dall'utente durante il lavoro nel sistema, nella creazione di un programma per la lavorazione di un determinato pezzo, e che sono il minimo necessario per ripristinarlo successivamente nell'applicazione. Si tratta, ad esempio, di informazioni quali:

- Modelli geometrici del pezzo e del grezzo.
- Tecnologia di lavorazione: l'elenco delle operazioni in un ordine definito. Ogni operazione contiene tutte le informazioni necessarie per lavorare una singola zona del pezzo: riferimenti alle curve o alle facce geometriche, parametri della strategia di lavorazione (flag di sequenza, passi, tolleranze e così via).
- Informazioni sull'attrezzatura necessaria: impostazioni della macchina, elenco degli utensili.
- Il percorso utensile risultante sotto forma di CLDATA indipendente dalla macchina.

Il formato di memorizzazione dei dati all'interno del file *.stcp del progetto è una sorta di archivio multi-file. Grazie a ciò è possibile salvare all'interno del progetto alcuni file (oltre alle informazioni di base elencate sopra) necessari per lavorare pienamente con il progetto, ma che sono memorizzati separatamente sul computer. In questo modo il progetto può essere trasferito liberamente e aperto su qualsiasi altro computer. Può trattarsi di file quali i file degli schemi macchina e i file dei modelli 3D degli utensili. Durante il normale lavoro dell'utente sul proprio computer, il progetto fa riferimento ai corrispondenti file esterni e una loro copia viene scritta all'interno del file *.stcp. Tuttavia, se il progetto viene poi trasferito su un altro computer e il file esterno richiesto non è presente, il sistema passa a utilizzare la versione del file memorizzata all'interno del progetto. Poiché la memorizzazione di file aggiuntivi nel progetto può aumentarne le dimensioni, questa funzione può essere disattivata nelle impostazioni di sistema.

La modalità di salvataggio può essere modificata nella finestra [Impostazione del sistema](715.md).

- Short mode (modalità breve). Vengono salvati solo i dati sorgente minimi: modello geometrico, sistemi di coordinate, operazioni tecnologiche e relativi parametri. Qualsiasi informazione che può essere ricalcolata non viene salvata.
- First intermediate mode (prima modalità intermedia). Oltre ai dati precedenti viene salvato il percorso utensile calcolato.
- Second intermediate mode (seconda modalità intermedia). I file esterni utilizzati dal progetto vengono copiati al suo interno: modelli 3D delle attrezzature utilizzate e così via.
- Detailed mode (modalità dettagliata). Oltre a tutte le modalità precedenti vengono salvati gli stati intermedi del grezzo e i dati della cache della geometria.

Per creare/ripristinare il file di progetto, utilizzare i pulsanti Save e Open project nella barra degli strumenti principale. I progetti possono essere aperti anche con la funzione di trascinamento, cioè semplicemente trascinando il file di progetto (*.stcp) sulla finestra principale dell'applicazione. Un file di progetto può essere aperto anche aggiungendo il nome del file come parametro nella riga di comando della shell.
