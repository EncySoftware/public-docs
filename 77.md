# Projektdateien

Ein Projekt wird als Datei mit der Endung **.stcp** gespeichert; früher wurde **.stc** verwendet. Die Datei enthält die bei der Erstellung eines Bearbeitungsprogramms erzeugten Informationen, die mindestens erforderlich sind, um das Projekt später in der Anwendung wiederherzustellen. Dazu gehören beispielsweise:

- Geometrische Modelle von Bauteil und Rohteil.
- Der Bearbeitungsprozess als geordnete Liste von Operationen. Jede Operation enthält die Informationen für die Bearbeitung eines Bereichs: Verweise auf Kurven oder Flächen und Strategieparameter wie Reihenfolge, Zustellungen und Toleranzen.
- Informationen zur benötigten Ausrüstung, etwa Maschineneinstellungen und Werkzeugliste.
- Der berechnete Werkzeugweg als maschinenunabhängige CLDATA.

Die *.stcp-Datei ist ein Archiv, das mehrere Dateien aufnehmen kann. Zusätzlich zu den Projektdaten können darin extern gespeicherte Dateien abgelegt werden, die für die vollständige Nutzung erforderlich sind, beispielsweise Maschinenschemata und 3D-Werkzeugmodelle. So lässt sich das Projekt auf einen anderen Computer übertragen. Im normalen Betrieb verwendet das Projekt die externen Dateien; eine Kopie wird im Projektarchiv gespeichert. Fehlt eine externe Datei auf dem Zielcomputer, greift das System auf die eingebettete Kopie zurück. Da zusätzliche Dateien das Projekt vergrößern, kann ihre Einbettung in den Systemeinstellungen deaktiviert werden.

Der Speichermodus wird in den [Systemeinstellungen](715.md) festgelegt.

- **Kompakter Modus.** Speichert nur notwendige Ausgangsdaten: geometrisches Modell, Koordinatensysteme, Operationen und deren Parameter. Neu berechenbare Informationen werden nicht gespeichert.
- **Erster Zwischenmodus.** Speichert zusätzlich die berechneten Werkzeugwege.
- **Zweiter Zwischenmodus.** Bettet zusätzlich verwendete externe Dateien ein, beispielsweise 3D-Modelle der Ausrüstung.
- **Detaillierter Modus.** Speichert zusätzlich Rohteilzwischenstände und Geometrie-Cache-Daten.

Verwenden Sie **Projekt speichern** und **Projekt öffnen** auf der Hauptsymbolleiste zum Speichern bzw. Laden. Ein Projekt kann auch geöffnet werden, indem Sie die *.stcp-Datei auf das Hauptfenster ziehen. Alternativ kann der Dateiname als Parameter beim Programmstart über die Befehlszeile übergeben werden.
