# Arquivos de projetos

Um projeto é um arquivo com a extensão ".stcp" salvo no disco (anteriormente era usada a extensão ".stc"). Ele armazena dentro de si as informações que o usuário gerou enquanto trabalhava no sistema, ao criar um programa para a usinagem de uma peça específica, e que são minimamente necessárias para sua restauração posterior no aplicativo. Isso inclui, por exemplo, informações como

- Modelos geométricos da peça e do bruto.
- Tecnologia de usinagem - a lista de operações em uma ordem definida. Cada operação contém todas as informações necessárias para usinar uma região separada da peça - links para as curvas ou faces geométricas, parâmetros de estratégia de usinagem (sinalizadores de sequência, passos, tolerâncias e assim por diante).
- Informações sobre o equipamento necessário: configurações da máquina, lista de ferramentas.
- O percurso da ferramenta resultante na forma de CLDATA independente da máquina.

O formato de armazenamento de dados dentro do arquivo *.stcp do projeto é uma espécie de arquivo compactado com vários arquivos. Graças a isso, é possível salvar alguns arquivos dentro do projeto (além das informações básicas listadas acima) que são necessários para trabalhar completamente com o projeto, mas que são armazenados separadamente no computador. Como resultado, o projeto pode ser transferido e aberto livremente em qualquer outro computador. Podem ser, por exemplo, arquivos de esquema da máquina e arquivos de modelos 3D de ferramentas. Durante o trabalho normal do usuário em seu computador, o projeto faz referência aos arquivos externos correspondentes, e uma cópia deles é gravada dentro do arquivo *.stcp. No entanto, se o projeto for transferido para outro computador e o arquivo externo desejado não aparecer, o sistema passará a trabalhar com a versão do arquivo que está armazenada dentro do projeto. Como o armazenamento de arquivos adicionais no projeto pode aumentar seu tamanho, esse recurso pode ser desativado nas configurações do sistema.

O modo de salvamento pode ser alterado na janela [Configuração do sistema](715.md).

- Modo curto. Somente dados de origem mínimos são salvos: modelo geométrico, sistemas de coordenadas, operações tecnológicas e seus parâmetros. Qualquer informação que possa ser recalculada não é salva.
- Primeiro modo intermediário. Além dos dados anteriores, o percurso da ferramenta calculado é salvo.
- Segundo modo intermediário. Os arquivos externos que o projeto usa são copiados dentro dele: Modelos 3D de equipamentos usados e assim por diante.
- Modo detalhado. Além dos dados de todos os modos acima, são salvos os estados intermediários do bruto e os dados de cache da geometria.

Use os botões Salvar e Abrir projeto na barra de ferramentas principal para criar/restaurar o arquivo de projeto. Os projetos também podem ser abertos usando a função arrastar e soltar, ou seja, simplesmente soltando o arquivo de projeto (*.stcp) na janela principal do aplicativo. Um arquivo de projeto também pode ser aberto se o nome do arquivo for adicionado como um parâmetro na linha de comando do shell.
