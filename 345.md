# Sequências de usinagem padrão

Na prática, para fabricar peças semelhantes, muitas vezes são usadas as mesmas abordagens. Por exemplo, a sequência de usinagem de uma matriz típica pode consistir em três operações:

- Desbaste linha d´agua;
- Acabamento complexo;
- Fresamento complexo de material remanescente.

Se muitos parâmetros das operações, como ferramentas usadas, sobremetais, passos etc., forem os mesmos para várias peças, faz sentido criar uma sequência de usinagem padrão. Para isso, o sistema CAM oferece recursos para importar e exportar toda uma sequência de usinagem, bem como uma operação individual. Essas funções são acessadas pelo menu de contexto das operações:

O comando **Export operation** salva todos os parâmetros da operação selecionada no arquivo especificado com a extensão *.sto.

O comando **Import parameters** preenche os parâmetros da operação selecionada com os valores salvos anteriormente no arquivo *.sto.

O comando **Import operation** adiciona à sequência de usinagem uma ou mais operações do arquivo de operação do sistema CAM (*.sto) ou de qualquer arquivo de projeto do sistema CAM (*.stcp).
