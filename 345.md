# Sequenze di lavorazione standard

Nella pratica, per produrre pezzi simili si utilizzano spesso gli stessi approcci. Ad esempio, la sequenza di lavorazione di uno stampo tipico può essere composta da tre operazioni:

- Sgrossatura a Z costante;
- Finitura complessa;
- Ripresa complessa del materiale residuo.

Se molti parametri delle operazioni, come gli utensili utilizzati, i sovrametalli, i passi ecc., sono uguali per diversi pezzi, ha senso creare una sequenza di lavorazione standard. A tale scopo il sistema CAM offre la possibilità di importare ed esportare un'intera sequenza di lavorazione e una singola operazione. L'accesso a queste funzioni avviene tramite il menu contestuale delle operazioni:

Il comando **Export operation** (esporta operazione) salva tutti i parametri dell'operazione selezionata nel file specificato con estensione *.sto.

Il comando **Import parameters** (importa parametri) compila i parametri dell'operazione selezionata con i valori salvati in precedenza nel file *.sto.

Il comando **Import operation** (importa operazione) aggiunge alla sequenza di lavorazione una o più operazioni da un file di operazioni del sistema CAM (*.sto) o da un qualsiasi file di progetto del sistema CAM (*.stcp).
