# Standard-Bearbeitungsabläufe

Ähnliche Bauteile werden häufig mit derselben Verfahrensfolge hergestellt. Eine typische Formbearbeitung kann beispielsweise aus folgenden Operationen bestehen:

- Wasserlinien-Schruppen;
- kombiniertes Schlichten;
- kombinierte Restmaterialbearbeitung.

Sind Werkzeuge, Aufmaße, Zustellungen und weitere Parameter für mehrere Bauteile gleich, kann ein Standardablauf erstellt werden. Das CAM-System unterstützt den Import und Export ganzer Operationsfolgen sowie einzelner Operationen. Die Befehle befinden sich im Kontextmenü der Operationen.

**Export operation (Operation exportieren).** Speichert alle Parameter der ausgewählten Operation in einer Datei mit der Endung *.sto.

**Import parameters (Parameter importieren).** Übernimmt zuvor in einer *.sto-Datei gespeicherte Werte in die ausgewählte Operation.

**Import operation (Operation importieren).** Fügt eine oder mehrere Operationen aus einer *.sto-Datei oder einer Projektdatei (*.stcp) zur Bearbeitungsfolge hinzu.
