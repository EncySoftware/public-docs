# File importabili

Nel sistema CAM è possibile importare un modello geometrico da qualsiasi sistema di disegno o progettazione (CAD/modellazione) mediante file di scambio dati nei formati seguenti:

- [IGES (*.igs, *.iges)](266.md);
- [STEP (*.step, *.stp)](10030.md);
- [DXF (*.dxf)](802.md);
- [PostScript (*.ps, *.eps)](268.md);
- [STL (*.stl)](270.md);
- [PLY (*.ply)](10032.md);
- [AMF (*.amf)](10033.md);
- [VRML (*.vrl)](721.md);
- [SW (*.sldasm, *.sldprt)](10034.md);
- [SE (*.asm, *.par, *.psm, *.pwd)](10035.md);

oppure direttamente da

- [Rhinoceros (*.3dm)](265.md);
- [Parasolid (x_t; x_b)](267.md).

Il numero di file importabili dipende dalla configurazione del sistema e può essere modificato facoltativamente.

È possibile estendere l'elenco dei formati di importazione mediante componenti aggiuntivi (add-in). A tale scopo è disponibile l'[Addin Manager](900.md). Gli add-in servono a ottimizzare la collaborazione del sistema CAM con diversi sistemi CAD. In generale, gli add-in permettono al sistema CAM di aprire direttamente i file di progetto dei sistemi CAD.

Il modello geometrico di un pezzo da lavorare, di un grezzo e delle attrezzature di lavorazione può essere preparato in qualsiasi sistema CAD/di modellazione e importato nel sistema CAM con uno qualsiasi dei formati supportati. Il sistema CAM può essere integrato con qualsiasi sistema CAD. Il modello interno supporta diverse rappresentazioni di oggetti geometrici solidi, superficiali, mesh e curve. Pertanto la rappresentazione delle informazioni geometriche nel sistema CAM non differisce dalla rappresentazione interna della geometria in molti sistemi CAD, il che è molto utile per evitare modelli "danneggiati" durante il trasferimento da un sistema all'altro.
