# Arquivos importáveis

No sistema CAM, há a capacidade de importar um modelo geométrico de qualquer sistema de desenhista ou projetista (CAD/modelagem) por meio de arquivos de troca de dados formatados como:

- [IGES (*.igs, *.iges)](266.md);
- [STEP (*.step, *.stp)](10030.md);
- [DXF (*.dxf)](802.md);
- [PostScript (*.ps, *.eps)](268.md);
- [STL (*.stl)](270.md);
- [PLY (*.ply)](10032.md);
- [AMF (*.amf)](10033.md);
- [VRML (*.vrl)](721.md);
- [SW (*.sldasm, *.sldprt)](10034.md);
- [SE (*.asm, *.par, *.psm, *.pwd)](10035.md);

ou diretamente de

- [Rhinoceros (*.3dm)](265.md);
- [Parasolid (x_t; x_b)](267.md).

O número de arquivos importáveis depende da configuração do sistema e pode ser alterado opcionalmente.

É possível estender a lista de formatos de importação por meio de suplementos. Para isso, existe o [Addin Manager](900.md). Os suplementos têm o objetivo de ajustar a colaboração do sistema CAM com diferentes sistemas CAD. Em geral, os suplementos permitem que o sistema CAM abra diretamente os arquivos de projeto dos sistemas CAD.

O modelo geométrico da peça usinada, do bruto e do equipamento de usinagem pode ser preparado em qualquer sistema CAD/modelagem e importado para o sistema CAM usando qualquer um dos formatos suportados. O sistema CAM pode ser integrado a qualquer sistema CAD. O modelo interno suporta diferentes representações de objetos geométricos sólidos, de superfície, de malha e de curva. Portanto, a representação das informações geométricas no sistema CAM não difere da representação interna da geometria em muitos sistemas CAD, o que é muito útil para evitar modelos "danificados" durante a transmissão de um sistema para outro.
