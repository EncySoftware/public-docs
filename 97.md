# Importable files

In CAM system there is the ability to import a geometrical model from any draftsman's or designer's systems (CAD/modeling) via data exchange files formatted as:

- [IGES (*.igs, *.iges)](266.md);
- [STEP (*.step, *.stp)](10030.md);
- [DXF (*.dxf)](802.md);
- [PostScript (*.ps, *.eps)](268.md);
- [STL (*.stl)](270.md);
- [PLY (*.ply)](10032.md);
- [AMF (*.amf)](10033.md);
- [VRML (*.vrl)](721.md);
- [SW (*.sldasm, *.sldprt)](10034.md);
- [SE (*.asm, *.par, *.psm, *.pwd)](10035.md);

or directly from

- [Rhinoceros (*.3dm)](265.md);
- [Parasolid (x_t; x_b)](267.md).

The number of importable files depends on the system configuration and can be changed optionally.

It is possible to extend the import format list by add-ins supplement. There is [Addin Manager](900.md) to do that. The add-ins are aimed to tune up a collaboration of Cam system with different CAD-systems. Add-ins permit generally CAM system to open directly project files of the CAD-systems.

The geometrical model of a machined part, workpiece, machining equipment can be prepared in any CAD/modeling system and imported into CAM system using any of the supported formats. CAM system can be integrated with any CAD-system. The internal model supports different representations of solid, surface, mesh and curve geometrical objects. Therefore, the representation of the geometrical information in CAM system does not differ from the internal representation of geometry in many CAD-systems, which is very useful for avoiding "damaged" models during transmission from one system to another.
