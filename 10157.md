# Splinekurven zeichnen

Diese Funktion ist experimentell und befindet sich in Entwicklung. Im Grafikfenster steht im Bearbeitungsmodus eine Symbolleiste zum direkten Zeichnen von Hilfskurven zur Verfügung.

![images/download/attachments/157864828/image2024-7-24_16-7-2.png](assets/images/download/attachments/157864828/image2024-7-24_16-7-2.png)

Folgende Hilfskurven können gezeichnet werden:

- Geraden;
- Polygonzüge;
- Splines.

![images/download/attachments/157864828/image2018-12-29_9-37-20.png](assets/images/download/attachments/157864828/image2018-12-29_9-37-20.png)

![images/download/thumbnails/157864828/image2018-12-29_9-38-43.png](assets/images/download/thumbnails/157864828/image2018-12-29_9-38-43.png)

Die Kurven können direkt auf den sichtbaren Objektflächen erstellt werden. Ihre Knoten lassen sich mit der Maus verschieben, löschen und hinzufügen.

Drei Zeichenmodi stehen zur Verfügung:

1. **Frei.** Die Punkte werden nach folgenden Regeln festgelegt:
   1. Ohne Fangobjekt unter dem Mauszeiger besitzt der erste Punkt zunächst keinen definierten Z-Wert.
   2. Weitere Punkte ohne Fangobjekt übernehmen den Z-Wert des vorherigen Punkts; es wird in einer Ebene gezeichnet.
   3. Wird eine Fläche gefangen, wird der nächstgelegene Punkt auf ihr verwendet.
2. **Auf der Fläche.** Punkte werden ausschließlich auf Flächen festgelegt. ![Zeichnen auf einer Fläche](assets/images/download/attachments/157864828/embim39.gif)
3. **Auf der Ebene.** Punkte werden ausschließlich in einer Ebene festgelegt. Alle gezeichneten Kurven bleiben mit dieser Ebene verbunden und werden bei deren Verschiebung oder Drehung mittransformiert. ![Zeichnen auf einer Ebene](assets/images/download/attachments/157864828/embim40.gif)
