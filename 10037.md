# Importieren von Objekten mit CAM-Add-ins

Ein [Add-in](10039.md) ist eine Komponente oder ein kleines Programm, das in das CAM-System eingebunden werden kann.

Add-ins ermöglichen den Import von [CAD-Projektdateien](10040.md).

In der Regel muss das betreffende CAD-System auf dem Computer installiert sein, damit das Add-in verwendet werden kann.
