# Importazione di oggetti con gli add-in del sistema CAM

L'[Addin](10039.md) è un componente o un piccolo programma che può essere collegato al sistema CAM.

Gli add-in offrono la possibilità di importare i [file di progetto CAD](10040.md).

Regola generale per l'uso degli add-in: il sistema CAD deve essere installato sul PC.
