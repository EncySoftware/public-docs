# Abertura e salvamento de projetos em um sistema externo

Para gerenciar projetos em um sistema externo, use os botões **Open Project** e **Save Project** da barra de ferramentas da **janela principal**. Ao passar o ponteiro sobre esses botões, é exibido um menu suspenso com opções adicionais, incluindo a **opção relacionada ao PLM**. Ao selecionar esse item, é exibido um submenu com todas as conexões PLM disponíveis.

**Nota:** a **opção relacionada ao PLM** é exibida somente se pelo menos uma conexão PLM estiver configurada.

## Abertura de um projeto de um sistema externo

Passe o ponteiro sobre o botão **Open Project** e selecione **Open from PLM** → **Open from PLM** *[connection name]*.

![images/download/attachments/157867871/22.png](assets/images/download/attachments/157867871/22.png)

Será aberta uma janela com a árvore de objetos do sistema externo. Localize e selecione o projeto desejado e clique em **Open**. O projeto será aberto.

![images/download/attachments/157867871/23.png](assets/images/download/attachments/157867871/23.png)

## Salvamento de um projeto em um sistema externo

Passe o ponteiro sobre o botão **Save Project** e selecione **Save Project to PLM** → **Save Project to PLM** *[connection name]*.

![images/download/attachments/157867871/24.png](assets/images/download/attachments/157867871/24.png)

Será aberta uma janela com a árvore de objetos do sistema externo. Escolha o local para salvar o projeto, marque a caixa **Overwrite item**, se necessário, e clique em **Save**.

![images/download/attachments/157867871/25.png](assets/images/download/attachments/157867871/25.png)
