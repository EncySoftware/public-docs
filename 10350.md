# Operazione con script

Per un'operazione con script è possibile definire i metodi OnCreateMethod, ChangePropertyMethod e MakeWorkPathMethod.

- OnCreateMethod è un sottoprogramma <strong>ENCY PL</strong> che viene eseguito quando l'operazione viene creata.
- ChangePropertyMethod viene eseguito quando una proprietà dell'operazione viene modificata.
- MakeWorkPathMethod viene eseguito quando viene calcolato il percorso utensile dell'operazione.

Per creare un'operazione con script utilizzare il comando Create script operation.

![images/download/attachments/157867777/image2024-7-26_17-4-44.png](assets/images/download/attachments/157867777/image2024-7-26_17-4-44.png)

Selezionare innanzitutto l'operazione padre. Come operazione padre può essere selezionata qualsiasi operazione. L'operazione padre definisce le proprietà di base della nuova operazione con script.

![images/download/attachments/157867777/image2024-7-26_17-5-5.png](assets/images/download/attachments/157867777/image2024-7-26_17-5-5.png)

Inserire i parametri della nuova operazione:

- Caption o titolo: viene visualizzato nell'albero della tecnologia. Il titolo dell'operazione è il valore del nodo Comment nel descrittore xml dell'operazione.
- Name: questo valore sarà il nome della nuova operazione nelle finestre di dialogo e nei menu per l'aggiunta di nuove operazioni al progetto. Nodo Name nel descrittore xml dell'operazione.
- Type: tipo della nuova operazione. Attributo Id del descrittore xml dell'operazione.

Utilizzare il pannello Operation properties (proprietà dell'operazione) per selezionare quali proprietà ereditate saranno visibili nell'inspector.

Una volta impostati tutti i parametri, fare clic sul pulsante Create template per creare l'unità xml contenente il descrittore xml della nuova operazione e il progetto modello <strong>ENCY PL</strong>.

È inoltre possibile creare manualmente il file xml del descrittore dell'operazione e includerlo nella configurazione xml di ENCY.
