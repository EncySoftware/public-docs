# Skriptoperation

Eine Skriptoperation kann die Methoden OnCreateMethod, ChangePropertyMethod und MakeWorkPathMethod definieren.

- **OnCreateMethod:** ENCY-PL-Unterprogramm beim Erstellen der Operation.
- **ChangePropertyMethod:** Wird bei einer Parameteränderung ausgeführt.
- **MakeWorkPathMethod:** Wird bei der Werkzeugwegberechnung ausgeführt.

Verwenden Sie **Create script operation** zum Erstellen.

![images/download/attachments/157867777/image2024-7-26_17-4-44.png](assets/images/download/attachments/157867777/image2024-7-26_17-4-44.png)

Wählen Sie zunächst eine übergeordnete Operation. Sie legt die geerbten Grundeigenschaften der neuen Skriptoperation fest.

![images/download/attachments/157867777/image2024-7-26_17-5-5.png](assets/images/download/attachments/157867777/image2024-7-26_17-5-5.png)

Geben Sie die neuen Operationsdaten ein:

- Bezeichnung: Anzeige im Technologiebaum, entsprechend **Comment** im XML-Deskriptor.
- Name: Anzeige in Dialogen und Menüs zur Operationserstellung, entsprechend **Name**.
- Typ: **Id**-Attribut des XML-Deskriptors.

Wählen Sie im Eigenschaftenbereich, welche geerbten Parameter im Inspektor sichtbar sein sollen.

**Create template** erzeugt eine XML-Einheit mit dem Operationsdeskriptor und eine ENCY-PL-Projektvorlage.

Alternativ kann die Deskriptordatei manuell erstellt und in die ENCY-XML-Konfiguration eingebunden werden.
