# Operação com script

Uma operação com script pode ter os métodos OnCreateMethod, ChangePropertyMethod e MakeWorkPathMethod definidos.

- OnCreateMethod é um subprograma <strong>ENCY PL</strong> executado quando a operação é criada.
- ChangePropertyMethod é executado quando uma propriedade da operação é alterada.
- MakeWorkPathMethod é executado quando o percurso da ferramenta da operação é calculado.

Para criar uma operação com script, use Create script operation.

![images/download/attachments/157867777/image2024-7-26_17-4-44.png](assets/images/download/attachments/157867777/image2024-7-26_17-4-44.png)

Primeiro, selecione a operação pai. Qualquer operação pode ser selecionada como pai. A operação pai define as propriedades básicas da nova operação com script.

![images/download/attachments/157867777/image2024-7-26_17-5-5.png](assets/images/download/attachments/157867777/image2024-7-26_17-5-5.png)

Informe os parâmetros da nova operação:

- Caption ou título: será exibido na árvore tecnológica. A legenda da operação é o valor do nó Comment no descritor XML da operação.
- Name: este valor será o nome da nova operação nas caixas de diálogo e nos menus usados para adicionar uma nova operação ao projeto. Corresponde ao nó Name no descritor XML da operação.
- Type: tipo da nova operação. Corresponde ao atributo Id do descritor XML da operação.

Use o painel Operation properties para selecionar quais propriedades herdadas serão exibidas no inspetor.

Depois de definir todos os parâmetros, clique no botão Create template para criar uma unidade XML que contém o descritor XML da nova operação e um projeto modelo <strong>ENCY PL</strong>.

Também é possível criar manualmente o arquivo XML do descritor da operação e incluí-lo na configuração XML do ENCY.
