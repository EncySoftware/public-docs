# Drehwerkzeuge

Werkzeuge für Drehoperationen werden in Drehwerkzeuge und axiale Werkzeuge eingeteilt. Innerhalb dieser Kategorien erfolgt die Zuordnung nach dem jeweiligen Bearbeitungsverfahren.

Drehwerkzeuge:

- Ausdrehwerkzeuge;
- gerade Außendrehwerkzeuge;
- Außengewindewerkzeuge;
- Innengewindewerkzeuge;
- Außeneinstechwerkzeuge;
- Inneneinstechwerkzeuge;
- Planeinstechwerkzeuge.

Axiale Werkzeuge:

- Schaftfräser;
- Bohrer;
- Zentrierbohrer;
- Gewindebohrer;
- Flachsenker;
- Kegelsenker.

Ein Werkzeug besteht aus einer Schneidplatte und einem dazu passenden Halter. Alternativ kann für eine Schneidplatte ein Halter mit frei definierter Form ausgewählt werden. Dieser Haltertyp lässt sich mit jedem Plattentyp der betreffenden Gruppe kombinieren. Einer Schneidplatte kann jedoch jeweils nur ein Halter zugeordnet werden.

Zusätzlich zu den geometrischen Werkzeugparametern können Sie festlegen:

- Spindelposition, links oder rechts;
- Spindeldrehrichtung, im oder gegen den Uhrzeigersinn;
- Lage des Werkzeugbezugspunkts;
- Werkzeugausrichtung, radial, axial oder unter einem vorgegebenen Winkel;
- Supportposition, oben oder unten.
