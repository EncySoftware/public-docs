# Sägen

![images/download/attachments/157867041/Sawing.jpg](assets/images/download/attachments/157867041/Sawing.jpg)

Diese Operation verwendet eine Kreissäge auf 5-Achs-Fräsmaschinen oder Robotern mit Spindel. Sie basiert auf 5D-Konturieren, ergänzt um scheibenwerkzeugspezifische An- und Abfahrbewegungen. Ausgangsgeometrie ist ein Volumenmodell; reine Kurven, beispielsweise aus DXF, werden nicht unterstützt.

Vorgehensweise:

1. Erstellen Sie eine Sägeoperation.

![images/download/attachments/157867041/image2024-7-10_16-45-31.png](assets/images/download/attachments/157867041/image2024-7-10_16-45-31.png)

2. Legen Sie Werkzeugabmessungen und Schnittbedingungen wie bei anderen Operationen fest.

3. Wählen Sie eine Volumenkörperkante und klicken Sie auf **Edge/Curve on surface**. Die Kante wird zur Auftragszuweisung hinzugefügt. Eine angrenzende Fläche erscheint grün und kennzeichnet die entstehende Schnittfläche. Für die andere Seite klicken Sie erneut auf die Kante und wählen im Panel **Change the side**.

![images/download/attachments/157867041/image2024-7-10_16-46-46.png](assets/images/download/attachments/157867041/image2024-7-10_16-46-46.png)

4. Gegenüber [5D-Konturieren](10129.md) gibt es einen zusätzlichen Überlappungsparameter.

![images/download/attachments/157867041/image2024-7-10_16-47-31.png](assets/images/download/attachments/157867041/image2024-7-10_16-47-31.png) ![images/download/attachments/157867041/sawing3.jpg](assets/images/download/attachments/157867041/sawing3.jpg)
