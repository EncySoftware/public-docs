# Geometrieelemente erkennen

![images/download/attachments/157862205/image2026-4-17_12-38-16.png](assets/images/download/attachments/157862205/image2026-4-17_12-38-16.png)

<a id="application-area-1"></a>

## Anwendungsbereich:

**Recognize features** steht beim [6D-Konturieren](10129.md) zur Verfügung. Erkannt werden Kreise, Rechtecke, abgerundete Rechtecke, Langlöcher, Sechsecke und Schlüssellochformen. Einfache Bewegungsbefehle wie Geraden und Bögen können im NC-Programm durch übergeordnete Geometrieelemente ersetzt werden. Dies verbessert Lesbarkeit und Kompaktheit und ermöglicht erweiterte Postprozessorfunktionen.

<a id="recognize-features-1"></a>

### Geometrieelemente erkennen

**Feature Filter**

Wählt die zu erkennenden Elementtypen. Vorgabe ist **All**.

**Face Selection**

Wählt die Flächen für die Erkennung. Für eine ausschließlich individuelle Flächenauswahl deaktivieren Sie **Tangency Propagation**.

<details>
<summary>Flächen auswählen</summary>

Ausgewählte Flächen und die darauf erkannten Elemente werden farblich hervorgehoben.

![images/download/attachments/157862205/image2026-3-18_10-54-9.png](assets/images/download/attachments/157862205/image2026-3-18_10-54-9.png)

Aktivieren Sie die Auswahl und klicken Sie auf die gewünschten Flächen. Jeder Klick ergänzt die Liste; ein erneuter Klick auf eine bereits ausgewählte Fläche entfernt sie.

![images/download/attachments/157862205/image2026-3-18_10-54-92.png](assets/images/download/attachments/157862205/image2026-3-18_10-54-92.png) ![images/download/attachments/157862205/image2026-3-18_10-55-43.png](assets/images/download/attachments/157862205/image2026-3-18_10-55-43.png)

Erstreckt sich ein Element über mehrere Flächen, müssen alle zugehörigen Flächen ausgewählt werden.

![images/download/attachments/157862205/image2026-3-18_10-57-36.png](assets/images/download/attachments/157862205/image2026-3-18_10-57-36.png) ![images/download/attachments/157862205/image2026-3-18_10-58-35.png](assets/images/download/attachments/157862205/image2026-3-18_10-58-35.png)

**Tangency Propagation** ist standardmäßig aktiviert, um die Flächenauswahl zu erleichtern.

</details>

**Tangency Propagation**

Erweitert die Auswahl auf tangential bzw. innerhalb des eingestellten Winkels angrenzende Flächen.

<details>
<summary>Beispiele zur Auswahlfortsetzung</summary>

Bei der Vorgabe 0 entspricht das Verhalten der Auswahl glatt verbundener Flächen. [Details](10029.md)

![images/download/attachments/157862205/image2026-3-18_11-9-19.png](assets/images/download/attachments/157862205/image2026-3-18_11-9-19.png) ![images/download/attachments/157862205/image2026-4-17_12-38-51.png](assets/images/download/attachments/157862205/image2026-4-17_12-38-51.png)

Bei deaktivierter Option werden Elemente ausschließlich auf ausdrücklich ausgewählten Flächen erkannt.

![images/download/attachments/157862205/image2026-4-17_12-38-51.png](assets/images/download/attachments/157862205/image2026-4-17_12-38-51.png) ![images/download/attachments/157862205/image2026-3-18_11-11-31.png](assets/images/download/attachments/157862205/image2026-3-18_11-11-31.png)

Ein größerer Winkel ermöglicht auch die Auswahl nicht tangential angrenzender Flächen.

Winkel = 0

**Recognized Features**

Verfügbare Typen erkannter Geometrieelemente:

<details>
<summary>Erkannte Elementtypen</summary>

**Circle (Kreis).** Definiert einen Kreis mit veränderbarem Radius.

![images/download/thumbnails/157862205/image2026-4-24_12-36-20.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-36-20.png)

**Rectangle (Rechteck).** Definiert ein Rechteck mit oder ohne Eckenverrundung. Breite, Länge und Eckenradius können geändert werden.

![images/download/thumbnails/157862205/image2026-4-24_12-35-21.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-35-21.png) ![images/download/attachments/157862205/image2026-4-24_12-35-41.png](assets/images/download/attachments/157862205/image2026-4-24_12-35-41.png)

**Slot (Langloch).** Definiert eine Langlochform. Länge und Radius sowie die Radien der halbkreisförmigen Enden können angepasst werden.

![images/download/attachments/157862205/image2026-4-24_12-34-55.png](assets/images/download/attachments/157862205/image2026-4-24_12-34-55.png)

**Polygon (Vieleck).** Erkennt Vielecke mit drei bis sechs Seiten. Die Kantenlänge kann geändert werden.

![images/download/thumbnails/157862205/image2026-4-24_12-33-45.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-33-45.png) ![images/download/thumbnails/157862205/image2026-4-24_12-34-34.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-34-34.png)

**KeyHole (Schlüsselloch).** Definiert eine Schlüssellochform mit veränderbaren Abmessungen des kreisförmigen Bereichs und der schlitzförmigen Erweiterung.

![images/download/thumbnails/157862205/image2026-4-24_12-34-13.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-34-13.png)

Erkannte Elemente können außerdem innerhalb der ausgewählten Ebene verschoben werden. Ziehen Sie dazu den roten Bezugspunkt in der Elementmitte.

![images/download/attachments/157862205/image2026-3-18_11-0-37.png](assets/images/download/attachments/157862205/image2026-3-18_11-0-37.png) ![images/download/attachments/157862205/image2026-3-18_11-0-57.png](assets/images/download/attachments/157862205/image2026-3-18_11-0-57.png)

</details>
