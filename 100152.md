# Recognize features

![images/download/attachments/157862205/image2026-4-17_12-38-16.png](assets/images/download/attachments/157862205/image2026-4-17_12-38-16.png)

## Application Area:

The Recognize features option has been added for the 6D Contouring operation ([Details](10129.md)). It allows recognizing the following constructive elements: Circle, Rectangle, Rounded Rectangle, Slot, Hexagon, and Keyhole. This feature replaces primitive motion commands (line segments, arcs) in NC programs with high‑level constructive elements to improve code readability, compactness, and enable advanced post‑processing features

### Recognize features

**Feature Filter**

Allows you to select which **types of recognize elements** will be recognized. The default value is **All**.

**Face Selection**

Allows you to select the surface on which the feature will be recognized. (***To select specific surfaces, you need to disable Tangency Propagation.***)

<details>
<summary>Selecting faces</summary>

The selected surface is highlighted in the corresponding color. Additionally, any found elements are also highlighted.

![images/download/attachments/157862205/image2026-3-18_10-54-9.png](assets/images/download/attachments/157862205/image2026-3-18_10-54-9.png)

Click on Selection and choose the required surface. By selecting surfaces one by one, you build a list of surfaces. To remove a surface from the list, click on the surface that has already been selected.

![images/download/attachments/157862205/image2026-3-18_10-54-92.png](assets/images/download/attachments/157862205/image2026-3-18_10-54-92.png) ![images/download/attachments/157862205/image2026-3-18_10-55-43.png](assets/images/download/attachments/157862205/image2026-3-18_10-55-43.png)

If an element is located on multiple surfaces, all relevant surfaces must be selected.

![images/download/attachments/157862205/image2026-3-18_10-57-36.png](assets/images/download/attachments/157862205/image2026-3-18_10-57-36.png) ![images/download/attachments/157862205/image2026-3-18_10-58-35.png](assets/images/download/attachments/157862205/image2026-3-18_10-58-35.png)

To reduce the labor intensity of surface selection, the **Tangency** **Propagation** option is enabled by default.

</details>

**Tangency Propagation**

This feature allows selecting smoothed surfaces.

<details>
<summary>Tangency propagation examples</summary>

By default, the angle is set to 0. In this case, the function operates similarly to the **Smooth surface selection option**. [Details](10029.md)

![images/download/attachments/157862205/image2026-3-18_11-9-19.png](assets/images/download/attachments/157862205/image2026-3-18_11-9-19.png) ![images/download/attachments/157862205/image2026-4-17_12-38-51.png](assets/images/download/attachments/157862205/image2026-4-17_12-38-51.png)

**Recognized Features**

List the types of **recognize elements**.

<details>
<summary>Recognized feature types</summary>

**Circle.** Defines a circle (it is possible to change the **circle's radius**).

![images/download/thumbnails/157862205/image2026-4-24_12-36-20.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-36-20.png)

**Rectangle.** Allows defining a rectangle with or without corner rounding (It is possible to modify the **width**, **length** and **corner radius**.)

![images/download/thumbnails/157862205/image2026-4-24_12-35-21.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-35-21.png) ![images/download/attachments/157862205/image2026-4-24_12-35-41.png](assets/images/download/attachments/157862205/image2026-4-24_12-35-41.png)

**Slot.** Defines a slot (it is possible to change the slot's **length** and **radius**, as well as the radius of the semicircular ends).

![images/download/attachments/157862205/image2026-4-24_12-34-55.png](assets/images/download/attachments/157862205/image2026-4-24_12-34-55.png)

**Polygon.** The Polygon tool identifies all polygonal shapes having between 3 and 6 sides inclusive (**edge length** can be changed.).

![images/download/thumbnails/157862205/image2026-4-24_12-33-45.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-33-45.png) ![images/download/thumbnails/157862205/image2026-4-24_12-34-34.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-34-34.png)

**KeyHole.** Defines a keyhole shape (it is possible to adjust the dimensions of both the circular part and the slot‑like extension of the keyhole).

![images/download/thumbnails/157862205/image2026-4-24_12-34-13.png](assets/images/download/thumbnails/157862205/image2026-4-24_12-34-13.png)

In addition to modifying the **recognized elements**, all elements can be moved within the selected plane by grabbing the red reference point at the element's centre.

![images/download/attachments/157862205/image2026-3-18_11-0-37.png](assets/images/download/attachments/157862205/image2026-3-18_11-0-37.png) ![images/download/attachments/157862205/image2026-3-18_11-0-57.png](assets/images/download/attachments/157862205/image2026-3-18_11-0-57.png)

</details>

After the toolpath calculation, the **CLDATA** will contain commands corresponding to the **constructive** **elements**.

![images/download/attachments/157862205/image2026-4-24_12-41-41.png](assets/images/download/attachments/157862205/image2026-4-24_12-41-41.png)

The trajectory output method can be controlled on the **Parameters tab** in the **Features group**. [Details](100112.md)
