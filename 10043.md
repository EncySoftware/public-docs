# Barra degli strumenti e add-in di importazione per FreeCAD™

![images/download/attachments/157859600/FreeCADFromAddinManager.png](assets/images/download/attachments/157859600/FreeCADFromAddinManager.png)

La barra degli strumenti consente di esportare dati geometrici da FreeCAD™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859600/image2022-3-30_11-59-2.png](assets/images/download/attachments/157859600/image2022-3-30_11-59-2.png)

L'add-in consente di importare i file di progetto <strong>FreeCAD™</strong>.

Estensioni di file supportate: FCSTD, BREP, BRP, DAT, SVG, SVGZ, UNV, MED, BDF, IFC, IV, AST, BMS, OBJ, OFF, PLY, OCA, GCAD, CSG, ASC, POV, INC. Per il funzionamento di questa opzione è necessario che l'applicazione richiesta (FreeCAD™) sia installata sul computer.
