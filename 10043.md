# Barra de ferramentas e suplemento de importação do FreeCAD™

![images/download/attachments/157859600/FreeCADFromAddinManager.png](assets/images/download/attachments/157859600/FreeCADFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do FreeCAD™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859600/image2022-3-30_11-59-2.png](assets/images/download/attachments/157859600/image2022-3-30_11-59-2.png)

O suplemento permite importar arquivos de projeto do **FreeCAD™**.

Extensões suportadas: FCSTD, BREP, BRP, DAT, SVG, SVGZ, UNV, MED, BDF, IFC, IV, AST, BMS, OBJ, OFF, PLY, OCA, GCAD, CSG, ASC, POV, INC. O FreeCAD™ deve estar instalado no computador para que o recurso funcione.
