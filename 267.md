# Importieren von Objekten aus Parasolid™-Dateien

Parasolid™ ist ein Geometriemodellierkern, der folgende Modelltypen unterstützt:

- Drahtmodelle;
- Flächenmodelle;
- Volumenkörper;
- finite Elemente.

Das Parasolid™-Austauschformat ermöglicht die Übertragung sowohl von Modelldaten als auch von Beziehungen zwischen Modellen.

Die üblichen Dateiendungen sind x_t und x_b.

Für die Erstellung eines Bearbeitungsprozesses wird die Objektgeometrie benötigt. Attribute wie Lichtquellen, Hintergrundfarbe, Transparenz, Glättungswinkel, Animationen und Ereignisverarbeitung werden ignoriert.

Das **CAM-System** unterstützt das Parasolid™-Austauschformat bis Version 35.1.
