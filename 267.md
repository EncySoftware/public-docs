# Importação de objetos de arquivos Parasolid™

O Parasolid™ é o núcleo de um formato de modelagem geométrica que suporta os seguintes tipos de modelos:

- wireframe;
- superfície;
- corpos sólidos;
- elementos finitos.

O formato de transmissão de dados do Parasolid™ permite que o usuário transfira dados não apenas sobre o modelo, mas também sobre as relações entre os modelos.

As extensões padrão dos arquivos são x_t; x_b.

Para projetar uma tecnologia de usinagem, são necessárias informações sobre a geometria do objeto, e atributos como fonte de luz, cor de fundo, transparência ou ângulo de suavização, elementos de animação e processamento de eventos são irrelevantes e, portanto, serão ignorados.

O <strong>sistema CAM</strong> suporta o formato de transmissão de dados Parasolid™ até a versão 35.1.
