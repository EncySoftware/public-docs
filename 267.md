# Importazione di oggetti da file Parasolid™

Parasolid™ è il nucleo di un formato di modellazione geometrica che supporta i seguenti tipi di modello:

- wireframe;
- superfici;
- corpi solidi;
- elementi finiti.

Il formato di trasferimento dati Parasolid™ consente all'utente di trasferire non solo i dati del modello, ma anche le relazioni tra i modelli.

Le estensioni standard dei file sono x_t; x_b.

Per progettare una tecnologia di lavorazione sono necessarie le informazioni sulla geometria dell'oggetto, mentre attributi come sorgente luminosa, colore di sfondo, trasparenza o angolo di smoothing (levigatura delle normali), elementi di animazione e gestione degli eventi sono irrilevanti e vengono quindi ignorati.

Il <strong>sistema CAM</strong> supporta il formato di trasferimento dati Parasolid™ fino alla versione 35.1.
