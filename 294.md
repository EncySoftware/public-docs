## Anwendungsbereich:

Mit diesen Elementen definieren Sie [Bauteil](330.md), [Rohteil](738.md), [Bearbeitungsbegrenzungen](101231.md) und [Spannmittel](10283.md).

Jeder Listeneintrag legt eine Fläche, einen Körper oder ein anderes bei der Werkzeugwegberechnung zu berücksichtigendes Element fest. Die Beschriftung zeigt dessen vollständigen Pfad im Geometriebaum. Wird das Ausgangsobjekt gelöscht oder umbenannt, wird der Eintrag mit einem Fragezeichen markiert. Das Symbol links kennzeichnet den Typ bzw. die Ableitung aus der Ausgangsgeometrie. Zum Hinzufügen verwenden Sie die entsprechenden Schaltflächen.

**Face (Fläche).** Fügt ausgewählte Flächen zur Liste hinzu. Ist keine Fläche ausgewählt, wird ein Dialog mit dem Geometriebaum geöffnet.

<details>
<summary>Weitere Informationen anzeigen</summary>

Wählen Sie in diesem Dialog die benötigten Flächen, Netze und Gruppen. Bei einer Gruppe werden nur ihre 3D-Objekte berücksichtigt. Bei der Rohteildefinition erzeugt **Add Faces** aus den ausgewählten Flächen einen **Volumenkörper**, der einen geschlossenen Raum beschreibt und mit ![Volumenkörper](assets/images/download/attachments/157861298/Image008.png) gekennzeichnet wird.

Ein Volumenkörper kann auf zwei Arten erzeugt werden:

- Durch Vernähen der Flächen. Sie müssen einen oder mehrere geschlossene Körper bilden. Die Verbindungstoleranz wird im eingeblendeten Dialog festgelegt.
- Durch Schließen der Flächen bis zu einer angegebenen Z-Ebene.

**Primitive (Grundkörper).** Definiert ein Rohteil mithilfe verschiedener Grundkörpervorlagen.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Workpiece of the previous operation (Rohteil der vorherigen Operation).** Ein Verweiseintrag stellt die Beziehung zur vorherigen Operation her. Das referenzierte Objekt kann wiederum auf ein anderes Objekt verweisen. Änderungen am Ausgangsobjekt setzen die abhängigen Einträge zurück bzw. lösen deren Neuberechnung aus.

**Machining result of the previous operation (Bearbeitungsergebnis der vorherigen Operation).** Verwendet einen Verweis auf das vorherige Bearbeitungsergebnis. Änderungen des Ausgangsobjekts wirken sich auf die abhängigen Verweise aus und erfordern gegebenenfalls eine Neuberechnung.

**Restrictions of the previous operation (Begrenzungen der vorherigen Operation).** Übernimmt die Definition aus dem vorherigen Element, beispielsweise einer Operation, Aufspannung oder Bauteilgruppe.

**Empty workpiece (Leeres Rohteil).** Definiert ein leeres Rohteil; dies wird häufig beim Lackieren verwendet.

**Definition method (Definitionsmethode).**

**Extrude (Extrudieren).** Erzeugt ein Prisma.

<details>
<summary>Weitere Informationen anzeigen</summary>

Als Ausgangsobjekte können geschlossene Kurven oder Kurvengruppen verwendet werden, die geschlossene Profile bilden. Sie bestimmen die Grundfläche des Prismas. Zusätzlich werden obere und untere Ebene festgelegt.

Für ein Prisma mit Öffnungen und Inseln legen Sie die Ausgangskurven in einem Ordner ab und verwenden diesen als Prismengrundfläche. Üblicherweise definiert die äußere Kurve den Körper und die inneren Kurven die Öffnungen. Bei Spannmitteln kann die äußere Kurve als Öffnung verwendet werden; aktivieren Sie dazu **Throw hole**.
