# Definição da peça, do bruto e dos dispositivos de fixação

![images/download/thumbnails/157861298/image2025-4-18_16-10-30.png](assets/images/download/thumbnails/157861298/image2025-4-18_16-10-30.png) ![images/download/thumbnails/157861298/image2025-4-18_16-10-41.png](assets/images/download/thumbnails/157861298/image2025-4-18_16-10-41.png)

## Área de aplicação:

Estes elementos permitem especificar a [peça](330.md), o [bruto](738.md), as [restrições](101231.md) e o [dispositivo de fixação](10283.md).

Cada item da lista define uma superfície, um sólido etc. a ser considerado no cálculo do percurso da ferramenta. A legenda do item mostra o caminho completo até o item na árvore do modelo geométrico. Se o objeto de origem de um item for removido ou renomeado, o item é marcado com um ponto de interrogação. O ícone à esquerda do item indica o tipo do item ou a forma como ele foi obtido a partir do objeto de origem. Para adicionar à lista um item de determinado tipo, são usados os botões correspondentes.

<strong>Face.</strong> O botão adiciona as faces selecionadas à lista. Se nenhuma face estiver selecionada, aparece uma caixa de diálogo com a árvore do modelo geométrico.

<details>

Nessa caixa de diálogo, localize e selecione as faces, as malhas e os grupos a serem adicionados à lista. Se um grupo for adicionado, somente os objetos 3D do grupo serão considerados. Ao definir um bruto, o botão **Add Faces** é usado para criar um **sólido** a partir das faces selecionadas. O item sólido representa um espaço delimitado. Ele é marcado com o ícone ![images/download/attachments/157861298/Image008.png](assets/images/download/attachments/157861298/Image008.png).

Há duas maneiras de criar um sólido:

- Costurando as faces. As faces adicionadas precisam formar um ou mais sólidos. A tolerância com que as faces se ligam entre si é especificada na caixa de diálogo exibida.
- Fechando as faces até o nível Z indicado.

<strong>Workpiece of thr previous operation.</strong> São introduzidos itens de ligação especiais. Eles são usados para estabelecer relações entre operações e para definir recursos paramétricos simples. Nesse caso, um item de ligação é uma referência ao objeto de origem, que, por sua vez, pode ser uma referência a outro objeto. A alteração de um objeto de origem faz com que todos os itens de ligação sejam redefinidos e/ou recalculados.

<strong>Machining result of the previous operation.</strong> São introduzidos itens de ligação especiais. Eles são usados para estabelecer relações entre operações e para definir recursos paramétricos simples. Nesse caso, um item de ligação é uma referência ao objeto de origem, que, por sua vez, pode ser uma referência a outro objeto. A alteração de um objeto de origem faz com que todos os itens de ligação sejam redefinidos e/ou recalculados.

<strong>Restrictions of the previous operation.</strong> Permite definir uma primitiva a partir do elemento anterior (operações, etapas de setup, peças).

<strong>Empty workpiece.</strong> Permite especificar um bruto vazio. Frequentemente usado em pintura.

<strong>From center point.</strong> Permite especificar o bruto por pontos. A distância do bruto é determinada do ponto central (Pc) até as dimensões gerais da peça.

<strong>Extrude.</strong> A extrusão é usada para criar um prisma.

<details>
<summary>Clique aqui para expandir..</summary>

Curvas fechadas, bem como grupos de curvas que formam perfis fechados, podem ser usados como objetos de origem. As curvas especificadas são usadas como base do prisma. Além disso, é necessário especificar os níveis superior e inferior do prisma.

Para definir um prisma com furos e ilhas, coloque as curvas de origem em uma pasta e especifique essa pasta como base do prisma. Em regra, a curva externa define o corpo e as curvas internas definem os furos. Para os dispositivos de fixação, é possível definir a curva externa como um furo. Para isso, marque a caixa **Throw hole**.

</details>
