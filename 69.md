# Geração de código NC

A geração de programas NC é realizada por um pós-processador que transforma os comandos CLDATA de um caminho de ferramenta calculado no formato do sistema CNC selecionado. Os arquivos do pós-processador têm a extensão *.sppx. A saída do código CNC é realizada em um arquivo de texto padrão, de modo que pode ser facilmente transmitida do computador, onde o pacote de distribuição está instalado, para o controle CNC usando qualquer método padrão de cópia de arquivos e pastas.

Para gerar o código CNC, pressione o botão ![images/download/attachments/157861166/image2024-7-4_16-41-46.png](assets/images/download/attachments/157861166/image2024-7-4_16-41-46.png). O painel de geração do programa NC será exibido.

![images/download/attachments/157861166/image2024-7-4_16-42-11.png](assets/images/download/attachments/157861166/image2024-7-4_16-42-11.png)

Aqui você pode selecionar o pós-processador necessário e executá-lo para obter um programa NC. Se a lista não contiver o pós-processador desejado, tente selecionar outra **Folder** com arquivos de pós-processador usando os controles apropriados na parte superior do painel. As informações gerais sobre o pós-processador selecionado são exibidas no canto inferior esquerdo do painel.

No campo `Arquivo de saída`, digite o nome e o caminho do arquivo para o qual o programa NC deve ser enviado.

Use o botão suspenso para ver a lista de arquivos de programas NC anteriores ou selecione a saída do programa NC para a mesma pasta do projeto ou para a pasta padrão. A pasta padrão é definida na [janela de configurações do sistema](90.md).

![images/download/attachments/157861166/image2024-7-4_16-45-23.png](assets/images/download/attachments/157861166/image2024-7-4_16-45-23.png)

Para iniciar a geração do programa NC para o sistema CNC selecionado, pressione o botão **Executar**. Na versão completa do programa, o código NC é gravado no arquivo de saída e, se selecionado, na janela do pós-processador. Na versão de demonstração, a saída para um arquivo não será executada e somente as últimas cadeias de caracteres do programa NC serão exibidas na janela do pós-processador.

Observe que o pós-processador só cria código NC para as operações de usinagem calculadas que estão "ativadas" (ícone de status ![images/download/thumbnails/157861166/not_Simulated.png](assets/images/download/thumbnails/157861166/not_Simulated.png), ![images/download/thumbnails/157861166/Simulated.png](assets/images/download/thumbnails/157861166/Simulated.png) ou ![images/download/thumbnails/157861166/IsMachiningResultCalculated.png](assets/images/download/thumbnails/157861166/IsMachiningResultCalculated.png) na [janela da lista de processos de usinagem](293.md)) e que também têm a propriedade `Gerar código NC` definida no momento em que o pós-processador é executado (a árvore de operações abaixo da lista do pós-processador).

> Note:
>
> Para gerar vários programas NC para diferentes operações, use a árvore de operações para ativar ou desativar a geração de código NC para operações e, em seguida, execute o pós-processador para criar os programas NC separados. Observe que a propriedade "Gerar código NC" é uma propriedade da operação. Ela será salva no projeto e nas configurações padrão de **User operations**.

![images/download/attachments/157861166/image2024-7-4_16-50-42.png](assets/images/download/attachments/157861166/image2024-7-4_16-50-42.png)

Se algumas operações tiverem a propriedade `Gerar código NC` desativada, a indicação ![images/download/thumbnails/157861166/image2019-5-21_15-17-31.png](assets/images/download/thumbnails/157861166/image2019-5-21_15-17-31.png) ficará visível. O nó raiz ![images/download/thumbnails/157861166/image2019-5-21_15-18-13.png](assets/images/download/thumbnails/157861166/image2019-5-21_15-18-13.png) marca ou desmarca todas as operações habilitadas na árvore de tecnologia.

O sistema de pós-processamento é um módulo padrão separado e pode, se necessário, ser executado separadamente do sistema CAM.

. O nome do arquivo executável é - Inp.exe. Os [arquivos de ajuste do pós-processador para sistemas CNC](730.md) são criados e editados usando o `Gerador de pós-processadores` (INP.exe).
