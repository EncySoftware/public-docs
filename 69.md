# Generazione del codice NC

La generazione dei programmi NC viene eseguita da un postprocessore che trasforma i comandi CLDATA di un percorso utensile calcolato nel formato del sistema CNC selezionato. I file del postprocessore hanno l'estensione *.sppx. L'output del codice CNC avviene in un normale file di testo, per cui può essere facilmente trasferito dal computer su cui è installato il pacchetto di distribuzione al controllo CNC con qualsiasi metodo standard di copia di file e cartelle.

Per generare il codice CNC, premere il pulsante ![images/download/attachments/157861166/image2024-7-4_16-41-46.png](assets/images/download/attachments/157861166/image2024-7-4_16-41-46.png). Viene visualizzato il pannello di generazione del programma NC.

![images/download/attachments/157861166/image2024-7-4_16-42-11.png](assets/images/download/attachments/157861166/image2024-7-4_16-42-11.png)

Qui è possibile selezionare il postprocessore richiesto ed eseguirlo per ottenere un programma NC. Se l'elenco non contiene il postprocessore desiderato, provare a selezionare un'altra **Folder** (cartella) con i file dei postprocessori mediante i controlli appropriati nella parte superiore del pannello. Le informazioni generali sul postprocessore selezionato sono visualizzate nell'angolo inferiore sinistro del pannello.

Nel campo **Output file** (file di output) si immettono il nome e il percorso del file in cui deve essere emesso il programma NC.

Utilizzare il pulsante a discesa per visualizzare l'elenco dei file di programmi NC precedenti, oppure scegliere di emettere il programma NC nella stessa cartella del progetto o nella cartella predefinita. La cartella predefinita viene impostata nella [finestra delle impostazioni di sistema](90.md).

![images/download/attachments/157861166/image2024-7-4_16-45-23.png](assets/images/download/attachments/157861166/image2024-7-4_16-45-23.png)

Per avviare la generazione del programma NC per il sistema CNC selezionato, premere il pulsante **Run** (esegui). Nella versione completa del programma il codice NC viene scritto nel file di output e, se selezionato, nella finestra del postprocessore. Nella versione demo l'output su file non viene eseguito e nella finestra del postprocessore vengono visualizzate solo le ultime righe del programma NC.

Si noti che il postprocessore crea il codice NC solo per tutte le operazioni di lavorazione calcolate che sono 'abilitate' (icona di stato ![images/download/thumbnails/157861166/not_Simulated.png](assets/images/download/thumbnails/157861166/not_Simulated.png),![images/download/thumbnails/157861166/Simulated.png](assets/images/download/thumbnails/157861166/Simulated.png) o ![images/download/thumbnails/157861166/IsMachiningResultCalculated.png](assets/images/download/thumbnails/157861166/IsMachiningResultCalculated.png) nella [finestra dell'elenco dei processi di lavorazione](293.md)) e per le quali la proprietà <strong>Generate NC code</strong> (genera codice NC) è impostata al momento dell'esecuzione del postprocessore (albero delle operazioni sotto l'elenco dei postprocessori).

> Nota:
>
> Per generare più programmi NC per operazioni diverse, utilizzare l'albero delle operazioni per attivare o disattivare la generazione del codice NC per le operazioni, quindi eseguire il postprocessore per creare i singoli programmi NC. Si noti che la proprietà 'Generate NC code' è una proprietà dell'operazione. Viene salvata nel progetto e nelle impostazioni predefinite di **User operations** (operazioni utente).

![images/download/attachments/157861166/image2024-7-4_16-50-42.png](assets/images/download/attachments/157861166/image2024-7-4_16-50-42.png)

Se per alcune operazioni la proprietà <strong>Generate NC code</strong> è disattivata, al passaggio del puntatore sarà visibile il suggerimento ![images/download/thumbnails/157861166/image2019-5-21_15-17-31.png](assets/images/download/thumbnails/157861166/image2019-5-21_15-17-31.png). Il nodo radice ![images/download/thumbnails/157861166/image2019-5-21_15-18-13.png](assets/images/download/thumbnails/157861166/image2019-5-21_15-18-13.png) seleziona o deseleziona tutte le operazioni abilitate nell'albero tecnologico.

Il sistema dei postprocessori è un modulo standard separato e, se necessario, può essere eseguito separatamente dal sistema CAM.

. Il nome del file eseguibile è Inp.exe. I [file di configurazione dei postprocessori per i sistemi CNC](730.md) vengono creati e modificati con il **Postprocessors generator** (generatore di postprocessori) (INP.exe).
