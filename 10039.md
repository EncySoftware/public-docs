# Addins for CAM system

<strong>Application area:</strong>

Addin is a component or a small program, which may be attached to the program. It may be used to support extended CAM system abilities. (For example, importing a 3D model from an external CAD system).

Usually, it is dynamic library (DLL), macros or VBA/JS-scripts, COM-objects, etc.

Addin can be used to import geometry from CAM or to expand the CAD program user interface using the activation toolbar or the menu.
