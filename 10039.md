# Addin per il sistema CAM

<strong>Ambito di applicazione:</strong>

L'add-in è un componente o un piccolo programma che può essere collegato al programma principale. Può essere utilizzato per supportare le funzionalità estese del sistema CAM (ad esempio, l'importazione di un modello 3D da un sistema CAD esterno).

In genere si tratta di una libreria dinamica (DLL), di macro o script VBA/JS, oggetti COM e simili.

L'add-in può essere utilizzato per importare la geometria dal CAM oppure per estendere l'interfaccia utente del programma CAD tramite la barra degli strumenti di attivazione o il menu.
