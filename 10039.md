# Add-ins für das CAM-System

**Anwendungsbereich:**

Ein Add-in ist eine Komponente oder ein kleines Programm, das eine Anwendung um Funktionen erweitert. Im CAM-System kann es beispielsweise den Import eines 3D-Modells aus einem externen CAD-System ermöglichen.

Add-ins werden unter anderem als dynamische Bibliotheken (DLL), Makros, VBA- oder JS-Skripte und COM-Objekte bereitgestellt.

Ein Add-in kann zum Geometrieimport oder zur Erweiterung der CAD-Benutzeroberfläche um eine Symbolleiste oder Menüeinträge verwendet werden.
