# Suplementos do sistema CAM

**Área de aplicação:**

Um suplemento é um componente ou pequeno programa que pode ser conectado ao programa. Pode ser usado para oferecer recursos ampliados do sistema CAM (por exemplo, importar um modelo 3D de um sistema CAD externo).

Normalmente, trata-se de uma biblioteca dinâmica (DLL), macros ou scripts VBA/JS, objetos COM etc.

Um suplemento pode ser usado para importar geometria pelo sistema CAM ou para ampliar a interface do programa CAD com uma barra de ferramentas ou um menu de integração.
