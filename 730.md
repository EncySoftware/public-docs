# File di configurazione del postprocessore

I file di configurazione del postprocessore per uno specifico controllo CNC hanno l'estensione SPPX (*.sppx). Per ogni controllo CNC esiste un file di configurazione univoco. Il file di configurazione contiene tutti i dati relativi all'unità CNC e ai sottoprogrammi di elaborazione dei programmi di lavorazione. Il file è necessario al postprocessore per trasformare i comandi di lavorazione in un programma NC per questo controllo. I file vengono utilizzati dal postprocessore, ma vengono creati e modificati con il **Postprocessors Generator** (generatore di postprocessori).

<strong>In precedenza i file del postprocessore avevano l'estensione *.spp. Questi postprocessori sono supportati dalla versione corrente del sistema e, se necessario, possono essere convertiti nel formato *.sppx.</strong>

Le versioni precedenti del sistema CAM funzionano con postprocessori costituiti da due file collegati con nome identico ma estensione diversa (*.inp, *.ppp). Tutti i file ppp esistenti possono essere utilizzati dalla versione corrente per [generare programmi NC](69.md). Tuttavia, se il postprocessore deve essere modificato, è necessario il file inp associato. La coppia di file può essere aperta con il **Postprocessors Generator** e convertita nel nuovo formato sppx. Il file convertito può essere modificato con la stessa applicazione.

I file del postprocessore possono essere inseriti in [contenitori zip crittografati](10022.md) con estensione .stfc.
