# Arquivos de configuração do pós-processador

Os arquivos de ajuste do pós-processador para um sistema CNC específico têm a extensão SPPX (*.sppx). Há um arquivo de ajuste exclusivo para cada sistema CNC. O arquivo de ajuste contém todos os dados referentes à unidade CNC e aos subprogramas de processamento de programas de usinagem. O arquivo é exigido pelo pós-processador para a transformação dos comandos de usinagem em um programa NC para esse controle. Os arquivos são usados pelo pós-processador, mas são criados e alterados pelo **Postprocessors Generator**.

<strong>Os arquivos do pós-processador tinham anteriormente a extensão *.spp. Esses pós-processadores são compatíveis com a versão atual do sistema e, se necessário, podem ser convertidos para o formato *.sppx.</strong>

As versões anteriores do sistema CAM funcionam com pós-processadores projetados em dois arquivos vinculados com nomes idênticos, mas com extensões diferentes (*.inp, *.ppp). Todos os arquivos ppp existentes podem ser usados para [gerar programas NC](69.md) na versão atual. Mas se o pós-processador precisar ser editado, o arquivo inp associado será necessário. Os pares de arquivos podem ser abertos pelo **Postprocessors Generator** e convertidos no novo formato sppx. O arquivo convertido pode ser modificado pelo mesmo aplicativo.

Os arquivos do pós-processador podem ser colocados dentro de [contêineres zip criptografados](10022.md) com a extensão .stfc.
