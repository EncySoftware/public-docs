# PLM-Integration

Das CAM-System kann in PLM- und PDM-Systeme integriert werden. Über APIs lassen sich eigene Integrationsmodule entwickeln. Die vollständige Beschreibung steht in der [API-Dokumentation](https://docs.encycam.com/CAMAPI/2/en/api/CAMAPI.Extension.PLM.html).

Die Integration unterstützt das Speichern und Laden von Projekten, Maschinen, Postprozessoren und Werkzeugen sowie den Import geometrischer Modelle. Nach dem Verbinden über ein Integrationsmodul erscheinen zusätzliche Bedienelemente in Haupt- und Nebenfenstern.

Eine Beispielerweiterung steht unter den Assets auf der [GitHub-Releaseseite](https://github.com/EncySoftware/cam-api-examples/releases) bereit. Öffnen Sie das aktuelle Release und laden Sie die Erweiterungsdatei herunter.
