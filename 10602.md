# Integrações PLM

O sistema CAM pode ser integrado a sistemas PLM/PDM. Ele fornece interfaces de API para desenvolver módulos personalizados de integração com sistemas externos. A documentação completa está disponível [aqui](https://docs.encycam.com/CAMAPI/2/en/api/CAMAPI.Extension.PLM.html).

Atualmente, a integração PLM permite salvar e carregar projetos, máquinas, pós-processadores e ferramentas, além de importar modelos geométricos. Quando o CAM é conectado a um sistema externo por um módulo de integração, botões adicionais para interagir com esse sistema aparecem nas janelas principal e auxiliares.

A integração pode ser testada com uma extensão de exemplo disponível na seção de assets da [página de releases no GitHub](https://github.com/EncySoftware/cam-api-examples/releases). Abra a versão mais recente e baixe o arquivo de extensão fornecido.
