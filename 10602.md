# PLMIntegrations

The CAM system offers the capability to integrate with PLM/PDM systems. It provides API interfaces that enable the development of custom integration modules with external systems. Comprehensive documentation is available [here](https://docs.encycam.com/CAMAPI/2/en/api/CAMAPI.Extension.PLM.html).

Currently, the PLM integration functionality supports the saving and loading of projects, machines, postprocessors, tools, and the import of geometry models. When CAM is connected to an external system via an integration module, additional interface buttons for interacting with the system appear in the main and auxiliary windows.

You can try out the integration using an example extension, available in the assets section of the [GitHub releases page](https://github.com/EncySoftware/cam-api-examples/releases). Navigate to the latest release and download the provided extension file.
