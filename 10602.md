# PLMIntegrations

Il sistema CAM offre la possibilità di integrarsi con i sistemi PLM/PDM. Mette a disposizione interfacce API che consentono di sviluppare moduli di integrazione personalizzati con sistemi esterni. La documentazione completa è disponibile [qui](https://docs.encycam.com/CAMAPI/2/en/api/CAMAPI.Extension.PLM.html).

Attualmente la funzionalità di integrazione PLM supporta il salvataggio e il caricamento di progetti, macchine, postprocessori e utensili, nonché l'importazione di modelli geometrici. Quando il CAM è collegato a un sistema esterno tramite un modulo di integrazione, nella finestra principale e nelle finestre ausiliarie compaiono pulsanti di interfaccia aggiuntivi per l'interazione con il sistema.

È possibile provare l'integrazione utilizzando un'estensione di esempio, disponibile nella sezione degli asset della [pagina delle release su GitHub](https://github.com/EncySoftware/cam-api-examples/releases). Passare all'ultima release e scaricare il file di estensione fornito.
