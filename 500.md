# Werkzeugbahnvorlage

Die Werkzeugbahnvorlage definiert die Ausgabe der Steuerdaten. Sie kann gespeichert und wiederverwendet werden.

Die Eigenschaften einer Hilfsoperation werden im Fenster bearbeitet, das im Technologiemodus über **Parameters** geöffnet wird.

![images/download/attachments/157861430/image2024-7-8_16-26-31.png](assets/images/download/attachments/157861430/image2024-7-8_16-26-31.png)

Das Parameterfenster enthält fünf Hauptbereiche:

- Befehlsliste.
- Liste verfügbarer Befehle.
- Eigenschafteninspektor.
- Operationsparameter.
- Benutzerparameter.

**Command list** enthält die CLData-Technologiebefehle, die nach der Berechnung zur Operation gehören, beispielsweise Spindel- und Kühlmittelbefehle, Vorschubänderungen sowie Kreis- und Geradenbewegungen. Die Liste kann vollständig selbst aufgebaut werden oder bereits vom Ersteller der Operation vorgegebene Befehle enthalten.

**Possible commands** enthält die verfügbaren CLData-Befehle und den [Makrobefehl](10074.md) **MACRO**. Daraus wird die Vorlage aufgebaut. Ein Makro ist eine Prozedur, die eine vordefinierte Befehlsfolge in die Steuerdaten ausgibt.

Ziehen Sie den gewünschten Befehl aus der Liste an die passende Stelle in **Command list**. Auch das Wurzelelement **MCDTree** kann eingefügt werden und weitere CLData-Befehle aufnehmen. So lassen sich Befehle nach Bedarf gruppieren. Zur Bearbeitung steht außerdem die Symbolleiste zur Verfügung.

Jeder CLData-Befehl besitzt eigene Parameter, beispielsweise Vorschub, Koordinaten oder Kommentartext. Der Eigenschafteninspektor zeigt die Parameter des ausgewählten Befehls und ermöglicht deren Bearbeitung. Als Werte sind Zahlen, Zeichenfolgen, Auswahleinträge oder Ausdrücke mit Rechenoperationen und Funktionen wie `+`, `-`, `*`, `/`, **sin** und **cos** möglich. Neben Konstanten können benannte Parameter aus der im selben Fenster verwalteten **Parameter list** verwendet werden. Beispielsweise kann **Pause value** des Knotens **DELAY** wie folgt angegeben werden:

`[2*Parameters List(Pause)]`

Die eckigen Klammern kennzeichnen einen Ausdruck mit Verweisen auf die Parameterliste. Vor der Auswertung werden diese durch konkrete Werte ersetzt. Im Beispiel muss der Parameter **Pause** vorhanden sein. **ParametersList** ist das reservierte Schlüsselwort für den Zugriff auf die Parameterliste.

Jeder Parameter enthält **Name** als eindeutige Kennung und **Value** als Wert oder Ausdruck. Der Ausdruck kann Zahlen, Zeichenfolgen und Verweise auf andere Listenparameter enthalten. Die Symbolleiste dient zur Bearbeitung der Liste. Ein Parameterverweis kann manuell eingegeben oder durch Ziehen des Parameters auf den gewünschten Befehlsblock erstellt werden. Die Parameterwerte sind auch im allgemeinen Eigenschafteninspektor der Operation und im Technologieansichtsfenster zugänglich.

![images/download/attachments/157861430/image2024-7-8_16-35-6.png](assets/images/download/attachments/157861430/image2024-7-8_16-35-6.png) ![images/download/attachments/157861430/image2024-7-8_16-31-26.png](assets/images/download/attachments/157861430/image2024-7-8_16-31-26.png)

Die Werkzeugbahnvorlage ist somit eine parametrierbare Liste von CLData-Technologiebefehlen.

Die Schaltflächen des Parameterfensters haben folgende Funktionen.

Linke Symbolleiste:

- ![Befehl hinzufügen](assets/images/download/thumbnails/157861430/image2024-7-8_17-14-48.png) **Add new command.** Fügt den unter **Possible commands** markierten Befehl an der ausgewählten Stelle der Befehlsliste ein.
- ![Befehl kopieren](assets/images/download/thumbnails/157861430/image2024-7-8_17-15-33.png) **Copy command to clipboard.** Kopiert den Befehl in die Zwischenablage.
- ![Befehl einfügen](assets/images/download/thumbnails/157861430/image2024-7-8_17-16-17.png) **Paste command from clipboard.** Fügt hinter dem ausgewählten Befehl bzw. nach dem Ende der ausgewählten Gruppe ein.
- ![Befehl löschen](assets/images/download/thumbnails/157861430/image2024-7-8_17-16-50.png) **Delete command.** Entfernt den ausgewählten Befehl.
- ![Gruppe speichern](assets/images/download/thumbnails/157861430/image2024-7-8_17-17-33.png) **Save group.** Speichert die ausgewählte Befehlsgruppe.
- ![Ausdruck bearbeiten](assets/images/download/thumbnails/157861430/image2024-7-8_17-18-36.png) **Edit expression.** Öffnet den folgenden Dialog:

![images/download/attachments/157861430/image2024-7-8_17-19-14.png](assets/images/download/attachments/157861430/image2024-7-8_17-19-14.png)

Rechte Symbolleiste:

- ![Parameter hinzufügen](assets/images/download/thumbnails/157861430/image2024-7-8_17-20-0.png) **Add new parameter.** Fügt einen Parameter an der ausgewählten Stelle ein.
- ![Parameter löschen](assets/images/download/thumbnails/157861430/image2024-7-8_17-20-33.png) **Delete parameter.** Entfernt den Parameter aus der Liste.
- ![Parameter nach unten](assets/images/download/thumbnails/157861430/image2024-7-8_17-21-5.png) **Move parameter down.** Verschiebt den Parameter nach unten.
- ![Parameter nach oben](assets/images/download/thumbnails/157861430/image2024-7-8_17-21-44.png) **Move parameter up.** Verschiebt den Parameter nach oben.
- ![Parameter einsetzen](assets/images/download/thumbnails/157861430/image2024-7-8_17-22-18.png) **Insert parameter.** Übernimmt den ausgewählten Parameter als Eigenschaftswert in die Befehlsliste.

Eine fertige Vorlage kann über [benannte Operationsvorgaben](10069.md) für weitere Projekte gespeichert werden. Die Befehle zum Speichern und Laden stehen im Modus **Technology** im Kontextmenü der jeweiligen Operation zur Verfügung.

![images/download/attachments/157861430/image2024-7-8_16-32-30.png](assets/images/download/attachments/157861430/image2024-7-8_16-32-30.png)

**Save as User operation...** speichert den aktuellen Parametersatz unabhängig vom Projekt in einer eigenen Datei. Die Vorgabe steht danach beim Erstellen neuer Operationen sowohl im Erstellungsdialog als auch im entsprechenden Dropdown-Menü zur Verfügung.

![images/download/attachments/157861430/image2024-7-8_16-37-53.png](assets/images/download/attachments/157861430/image2024-7-8_16-37-53.png)

Mit **Load User operation...** im Kontextmenü können Vorgaben auch auf bereits vorhandene Operationen angewendet werden. Angezeigt werden die für den Operationstyp verfügbaren Vorgaben.

Über **Empty group** unter **Possible commands** kann eine Gruppe in **Command list** eingefügt werden. Legen Sie deren Namen und Parameteranzahl fest.

![images/download/attachments/157861430/image2024-7-8_16-50-36.png](assets/images/download/attachments/157861430/image2024-7-8_16-50-36.png)

Fügen Sie der Gruppe Befehle aus **Possible commands** hinzu, um eine Befehlsfolge für eine bestimmte Aufgabe zu bilden.

![images/download/attachments/157861430/image2024-7-8_16-52-33.png](assets/images/download/attachments/157861430/image2024-7-8_16-52-33.png)

Mit ![Befehlsgruppe speichern](assets/images/download/thumbnails/157861430/image2024-7-8_17-17-332.png) wird die zusammengestellte Gruppe gespeichert.

Der Speicherdialog wird geöffnet:

![images/download/attachments/157861430/image2024-8-5_17-40-47.png](assets/images/download/attachments/157861430/image2024-8-5_17-40-47.png)

Geben Sie den Gruppennamen an. Ein Namensraum ermöglicht eine eindeutige Benennung.

Es stehen drei Speicherarten zur Verfügung:

**Operation.** Speichert die Gruppe innerhalb der Operation und zeigt sie unter **Possible commands** an. Beim Speichern der Operationsvorlage wird die Gruppe mitgespeichert. In anderen Operationen ist sie nicht verfügbar.

**Project.** Speichert die Gruppe im Projekt. Beim erneuten Laden werden die Operationen und die Gruppe gemeinsam geladen.

**External file.** Speichert die Gruppe in einer externen Datei zur Verwendung in beliebigen Operationen und Projekten. Verweise auf Parameter der ursprünglichen **ParametersList** dürfen dabei nicht verwendet werden, da diese in anderen Operationen nicht verfügbar sind.

Erstellen Sie benötigte Parameter stattdessen direkt innerhalb der Gruppe. Legen Sie ihre Anzahl und Werte fest; sie werden mit der Gruppe gespeichert.

![images/download/attachments/157861430/image2024-7-8_16-57-15.png](assets/images/download/attachments/157861430/image2024-7-8_16-57-15.png)

Diese Parameter sind innerhalb der Gruppe verfügbar.

Befehlsgruppen können so auch auf einem anderen Computer verwendet werden. Zum Laden wählen Sie **Load group from file** im Kontextmenü der Liste verfügbarer Befehle.

![images/download/attachments/157861430/image2024-7-8_16-58-22.png](assets/images/download/attachments/157861430/image2024-7-8_16-58-22.png)

Beispiel für die Verwendung einer Gruppe:

Vor der Bearbeitung sollen die Spannbacken geschlossen werden. Im folgenden Beispiel wird dafür **M10** im NC-Programm ausgegeben.

Schritt 1: Erstellen Sie eine leere Gruppe in der Befehlsliste und nennen Sie sie **Closing jaws**.

![images/download/attachments/157861430/image2024-7-8_17-0-36.png](assets/images/download/attachments/157861430/image2024-7-8_17-0-36.png)

Schritt 2: Fügen Sie **INSERT** in die Gruppe ein und setzen Sie seinen Wert auf **"M10"**.

![images/download/attachments/157861430/image2024-7-8_17-0-58.png](assets/images/download/attachments/157861430/image2024-7-8_17-0-58.png)

Schritt 3: Speichern Sie die Gruppe in einer externen Datei.

![images/download/attachments/157861430/image2024-8-5_17-42-51.png](assets/images/download/attachments/157861430/image2024-8-5_17-42-51.png)

Die Gruppe steht nun unter **Possible commands** zur Verfügung.

Schritt 4: Wählen Sie die Operationsgruppe **Header** und fügen Sie die gespeicherte Gruppe **Closing jaws** hinzu, damit die Backen vor der Bearbeitung geschlossen werden.

![images/download/attachments/157861430/image2024-7-8_17-3-35.png](assets/images/download/attachments/157861430/image2024-7-8_17-3-35.png)

Der Befehl **M10** wird nun vor der Bearbeitung ausgegeben.

![images/download/attachments/157861430/image2024-7-23_15-53-34.png](assets/images/download/attachments/157861430/image2024-7-23_15-53-34.png)

Mit dieser Definition wird die Backenbewegung noch nicht grafisch simuliert. Dafür muss die Bewegung in die entsprechende Stellung zusätzlich durch **MULTIGOTO** beschrieben werden. Der Bewegungswert kann in **ParametersList** festgelegt werden. Soll die Gruppe jedoch extern gespeichert werden, muss der Parameter innerhalb der Gruppe angelegt werden.
