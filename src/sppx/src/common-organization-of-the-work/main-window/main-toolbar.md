# The main toolbar

![images/download/attachments/142668669/image2024-8-20_16-42-21.png](../../images/download/attachments/142668669/image2024-8-20_16-42-21.png)

- ![images/download/attachments/142668669/image2024-8-20_16-43-32.png](../../images/download/attachments/142668669/image2024-8-20_16-43-32.png) – Creates the new postprocessor's tuning file. The system resets its state before creation.
- ![images/download/attachments/142668669/image2024-8-20_16-44-23.png](../../images/download/attachments/142668669/image2024-8-20_16-44-23.png) – Opens the postprocessor's tuning file, which is saved earlier. The system resets its state before loading.
- ![images/download/thumbnails/142668669/image2024-8-20_16-45-10.png](../../images/download/thumbnails/142668669/image2024-8-20_16-45-10.png) – Saves the postprocessor's tuning file with the current name.
- ![images/download/thumbnails/142668669/image2024-8-20_16-45-51.png](../../images/download/thumbnails/142668669/image2024-8-20_16-45-51.png) – Requests new CLData files from CAM system.
- ![images/download/thumbnails/142668669/image2024-8-20_16-46-33.png](../../images/download/thumbnails/142668669/image2024-8-20_16-46-33.png) – Opens the technological commands file, generated by CAM system.
- ![images/download/thumbnails/142668669/image2024-8-20_16-47-18.png](../../images/download/thumbnails/142668669/image2024-8-20_16-47-18.png) – Runs the compilation of the command processing programs.
- ![images/download/thumbnails/142668669/image2024-8-20_16-59-52.png](../../images/download/thumbnails/142668669/image2024-8-20_16-59-52.png) – Runs the generation of the NC-program from the files of the tool motion trajectory. If the command processing programs aren't compiled, the compilation will be activated first.
- ![images/download/thumbnails/142668669/image2024-8-20_17-0-27.png](../../images/download/thumbnails/142668669/image2024-8-20_17-0-27.png) – Break NC-program generation.
- ![images/download/thumbnails/142668669/image2024-8-20_17-1-14.png](../../images/download/thumbnails/142668669/image2024-8-20_17-1-14.png) – Generate NC-program with stopping in subprograms.
- ![images/download/thumbnails/142668669/image2024-8-20_17-1-50.png](../../images/download/thumbnails/142668669/image2024-8-20_17-1-50.png) – Generate NC-program without stopping in subprograms.
- ![images/download/thumbnails/142668669/image2024-8-20_17-2-32.png](../../images/download/thumbnails/142668669/image2024-8-20_17-2-32.png) – Generate NC-program up to current position in a CLData.
- ![images/download/thumbnails/142668669/image2024-8-20_17-3-22.png](../../images/download/thumbnails/142668669/image2024-8-20_17-3-22.png) – Pause NC-program generation.
- ![images/download/thumbnails/142668669/image2024-8-20_17-4-25.png](../../images/download/thumbnails/142668669/image2024-8-20_17-4-25.png) – Add breakpoint in a handler of technological commands or CLData files.
- ![images/download/thumbnails/142668669/image2024-8-20_17-5-3.png](../../images/download/thumbnails/142668669/image2024-8-20_17-5-3.png) – Adds a new variable to the list of watches.
- ![images/download/thumbnails/142668669/image2024-8-20_17-5-39.png](../../images/download/thumbnails/142668669/image2024-8-20_17-5-39.png) – Compute variable or expressions. The evaluation is possible only in a debug mode.
- ![images/download/thumbnails/142668669/image2024-8-20_17-6-31.png](../../images/download/thumbnails/142668669/image2024-8-20_17-6-31.png) – Cancel the last change made in the program of a handler technological command or a mask.
- ![images/download/thumbnails/142668669/image2024-8-20_17-7-8.png](../../images/download/thumbnails/142668669/image2024-8-20_17-7-8.png) – Return the last change made in the program of a handler of a technological command or a mask.
- ![images/download/thumbnails/142668669/image2024-8-20_17-7-41.png](../../images/download/thumbnails/142668669/image2024-8-20_17-7-41.png) – Opens the window for the data about NC-machine and CNC-system.
- ![images/download/thumbnails/142668669/image2024-8-20_17-8-24.png](../../images/download/thumbnails/142668669/image2024-8-20_17-8-24.png) – Open transliteration properties dialog. Application toolbar placed on the top left panel of the main window. There are drop-down menus associated with 2 buttons.

![images/download/thumbnails/142668669/image2024-8-20_17-10-19.png](../../images/download/thumbnails/142668669/image2024-8-20_17-10-19.png)

- ![images/download/thumbnails/142668669/image2024-8-20_17-11-8.png](../../images/download/thumbnails/142668669/image2024-8-20_17-11-8.png) – Opens system setup window.
- ![images/download/thumbnails/142668669/image2024-8-20_17-11-53.png](../../images/download/thumbnails/142668669/image2024-8-20_17-11-53.png) – Information about Postprocessors generator.

Help menu consist of actions that allow to get answers to emerging questions.

![images/download/thumbnails/142668669/image2024-8-20_17-13-39.png](../../images/download/thumbnails/142668669/image2024-8-20_17-13-39.png)

- ![images/download/thumbnails/142668669/image2024-8-20_17-14-39.png](../../images/download/thumbnails/142668669/image2024-8-20_17-14-39.png) – Shows postprocessors generator help.
- ![images/download/thumbnails/142668669/image2024-8-20_17-15-11.png](../../images/download/thumbnails/142668669/image2024-8-20_17-15-11.png) – Prepare a message to the technical support service of the CAM system vendor.
