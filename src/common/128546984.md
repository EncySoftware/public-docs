# Simplifier(단순화 도구)

MachineMaker의 Simplifier는 복잡한 3D 모델을 단순화하기 위한 도구입니다. 단순화에는 불필요한 부품 제거, 곡면 병합, 모델 구조 최적화 및 기타 복잡도 감소 기법이 포함될 수 있습니다.

이 도구를 열려면 드롭다운 메뉴를 클릭하고 유틸리티 메뉴에서 **Simplifier**(단순화 도구)를 선택해야 합니다.

[![images/download/attachments/128546984/image2024-8-16_16-42-28.png](../assets/edbb6da52af6fc734cd4aad704d1049b2bedcfc0855647e7c5a48370b572cdcf.png)](../assets/edbb6da52af6fc734cd4aad704d1049b2bedcfc0855647e7c5a48370b572cdcf.png "전체 크기 이미지 열기")

이 유틸리티의 메인 메뉴는 다음과 같습니다.

[![images/download/attachments/128546984/image2024-2-27_11-51-58.png](../assets/a2a7e9026431873b035a6040a0cc803f94d5923609c5b499d5a40349001fad0c.png)](../assets/a2a7e9026431873b035a6040a0cc803f94d5923609c5b499d5a40349001fad0c.png "전체 크기 이미지 열기")

기본 창은 다음 영역으로 구성됩니다.

1. 새 프로젝트.
2. 가져오기.
3. 다른 이름으로 저장.
4. MachineMaker로 보내기.
5. 형상 변환.
6. 형상 단순화.
7. 유사 노드 찾기.
8. 삭제.

형상 변환은 객체를 이동하는 데 사용되며 CAM 시스템과 동일한 기능을 제공합니다.  
[![images/download/attachments/128546984/rotate.gif](../assets/88d6c16663e646543e6ebd14301976c1d2d27ca871d45a0e7de5e0da29633148.webp)](../assets/88d6c16663e646543e6ebd14301976c1d2d27ca871d45a0e7de5e0da29633148.webp "전체 크기 이미지 열기")

형상 단순화 - 이 유틸리티의 주요 기능 중 하나입니다. 여기에서 다양한 모델 단순화 모드를 선택할 수 있습니다. 템플릿은 4가지입니다.

1. **Default**(기본) - 모델에서 작은 객체를 제거하는 모드입니다.
2. **Middle**(중간) - 모델 표면에서 대부분의 객체를 제거하는 모드입니다.
3. **Maximum**(최대) - 모델의 큰 부분을 제외한 모든 것을 제거하는 모드입니다.
4. **Custom**(사용자 정의) - 슬라이더를 사용하여 모델 표면을 수동으로 편집하는 모드입니다.

예시 테스트에는 Kuka KR 120 R3100-2 로봇 모델을 사용합니다.

[![images/download/attachments/128546984/image2024-2-27_12-42-2.png](../assets/21cc0ad3ec89d227d0b3bb53443d5ed819b462703d1a67c38727ef302a918543.png)](../assets/21cc0ad3ec89d227d0b3bb53443d5ed819b462703d1a67c38727ef302a918543.png "전체 크기 이미지 열기")

로봇에서 불필요한 객체를 제거하기 전에 면 표시 기능을 사용하면 제거될 객체(빨간색으로 표시됨)를 미리 확인할 수 있습니다.

[![Simplifier(단순화 도구)](../assets/8134597a1ba32ee1eb143f596dfa611619a150f01caaae3c2ef8eb6cbb8fc90c.webp)](../assets/8134597a1ba32ee1eb143f596dfa611619a150f01caaae3c2ef8eb6cbb8fc90c.webp "전체 크기 이미지 열기")

Simplifier에는 **Find similar nodes**(유사 노드 찾기) 기능도 있습니다. 이 기능은 모델에서 유사한 부품을 검색한 다음 다음과 같은 여러 노드로 나누어 목록에 정렬합니다.

- 완전히 동일
- 유사
- 부분적으로 동일

[![Simplifier(단순화 도구)](../assets/2831b002dc0520859320191298117faa4e6c74593bb4913ad80bb62d15bdb8fb.webp)](../assets/2831b002dc0520859320191298117faa4e6c74593bb4913ad80bb62d15bdb8fb.webp "전체 크기 이미지 열기")

필요한 경우 삭제 버튼을 사용하여 노드를 삭제할 수 있습니다.
