# 애플리케이션 설정

설정 패널은 메인 메뉴에서 열 수 있습니다.[![images/download/attachments/128546673/image2024-8-12_12-23-22.png](../assets/5845ee620ec7945899ad0dcc3000439771084de029055c4ae8a63084d7e1b569.png)](../assets/5845ee620ec7945899ad0dcc3000439771084de029055c4ae8a63084d7e1b569.png "전체 크기 이미지 열기")

일반

- **Language**(언어). MachineMaker는 기본적으로 CAM 시스템 언어를 사용하지만 여기에서 언어를 변경할 수 있습니다.
- **Visualization quality**(시각화 품질). 비디오 메모리에 문제가 있거나 MachineMaker가 충분히 원활하게 작동하지 않으면 품질을 낮춥니다. High(높음) 품질을 유지하는 것을 권장합니다.
- **ENCY path**(ENCY 경로). MachineMaker는 설치된 CAM 시스템을 자동으로 감지합니다. 하지만 여기에서 ENCY 경로를 직접 지정할 수도 있습니다.
- **Constrained rotate**(제한 회전) 모드를 사용하면 회전 중에 Z축을 고정할 수 있습니다. 이 파라미터는 "도구 모음"에서도 변경할 수 있습니다.
- **Inverse mouse wheel zoom direction**(마우스 휠 확대/축소 방향 반전). 마우스 스크롤 시 확대/축소 동작을 반대로 하려면 이 파라미터를 변경합니다.
- **Simplify CAD models**(CAD 모델 단순화)를 사용하면 3D 모델의 크기를 줄일 수 있습니다. 자세한 내용은 "지원되는 3D 모델 형식" 페이지에서 확인할 수 있습니다.
- **Auto Align**(자동 정렬). MachineMaker가 가져온 3D 모델을 자동으로 검토하여 어셈블리에서 각 새 메커니즘의 최적 위치를 찾습니다.
