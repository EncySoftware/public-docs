# 어셈블리

## 커넥터

각 메커니즘 또는 객체에는 커넥터가 하나 이상 있습니다. 두 메커니즘은 각자의 커넥터를 사용하여 서로 연결할 수 있습니다.

로봇에는 항상 커넥터가 2개 있습니다. 첫 번째 커넥터는 기준 좌표계(3)에, 두 번째 커넥터는 플랜지(4)에 있습니다.

테이블에는 커넥터가 2개 이상 있습니다. 베이스(1)와 테이블 상판(2)에 있습니다.

엔드 이펙터에는 베이스에 커넥터가 1개(5) 있습니다.

로봇 커넥터(3)를 테이블 커넥터(2)에 연결하여 로봇을 테이블 위에 배치할 수 있습니다. 또한 엔드 이펙터 커넥터를 로봇 플랜지 커넥터에 연결하여 엔드 이펙터를 로봇 플랜지에 장착할 수도 있습니다.

[![images/download/attachments/150674458/image2021-5-6_15-38-13.png](../assets/b65c64d812e514058d79fbc9cf11e8bd54219ce9ca022196dd8c624dec9a4e7b.png)](../assets/b65c64d812e514058d79fbc9cf11e8bd54219ce9ca022196dd8c624dec9a4e7b.png "전체 크기 이미지 열기")

테이블에는 여러 메커니즘을 올려놓을 수 있습니다. 이 경우 테이블에 커넥터가 여러 개 있어야 합니다.

[![images/download/attachments/150674458/image2021-5-6_15-42-51.png](../assets/9a165e8c6e8b23b4c3abec7405c07757f22d773aa4ff3a568bba6671bf231e31.png)](../assets/9a165e8c6e8b23b4c3abec7405c07757f22d773aa4ff3a568bba6671bf231e31.png "전체 크기 이미지 열기")
비어 있는 커넥터는 모두 CAM 시스템에서 공작물 커넥터로 사용됩니다.

[![images/download/attachments/150674458/image2021-5-6_15-57-35.png](../assets/6d57ea7fc4cccd67564ce90207046869325d4677581e860d6841a4cde818ed43.png)](../assets/6d57ea7fc4cccd67564ce90207046869325d4677581e860d6841a4cde818ed43.png "전체 크기 이미지 열기")

## 테이블 커넥터 관리

커넥터는 여러 개 추가할 수 있습니다. 새 테이블을 만들거나 기존 테이블을 편집하고 [운동학 패널](../robots/131903495.md)을 엽니다. 커넥터는 **User coordinate systems**(사용자 좌표계) 패널에서 관리할 수 있습니다.

[![images/download/attachments/150674458/image2024-2-9_16-26-44.png](../assets/a9ed05084f116d85a6df309feb6eae0b76241ddafb4435ab1f60f3f6501200b7.png)](../assets/a9ed05084f116d85a6df309feb6eae0b76241ddafb4435ab1f60f3f6501200b7.png "전체 크기 이미지 열기")

![images/download/attachments/150674458/image2024-2-9_16-30-13.png](../assets/bc45d98d52242bda6d368488a873e758463debad1017ddb9f05593ca70847f52.png)
버튼을 사용하여 새 커넥터를 추가합니다.

[![images/download/attachments/150674458/image2024-2-9_16-28-49.png](../assets/a49ad33f1532dfb67a3c7d9b5c5d278859695f1be5a544aeaac968575c1d4254.png)](../assets/a49ad33f1532dfb67a3c7d9b5c5d278859695f1be5a544aeaac968575c1d4254.png "전체 크기 이미지 열기")

커넥터를 클릭하면 선택됩니다. 3D 뷰에서도 커넥터를 선택할 수 있습니다. 커넥터 이름을 변경하려면 이름을 두 번 클릭합니다. **Enter** 키를 누르면 새 이름이 확정되고 **Esc** 키를 누르면 취소됩니다.

[![images/download/attachments/150674458/manage_table_connectors_3.png](../assets/bccaa24ded7bc08f0df5e4480b14c7288c58ec38cc62d08e50a0df74a8dc6510.png)](../assets/bccaa24ded7bc08f0df5e4480b14c7288c58ec38cc62d08e50a0df74a8dc6510.png "전체 크기 이미지 열기")

![images/download/attachments/150674458/image2024-2-9_16-30-44.png](../assets/85e24db7bba7e9e1a95f4d802e9146772c9d9427663213b66290851fbc048572.png)
버튼을 사용하여 커넥터를 삭제합니다.

테이블에는 커넥터(사용자 좌표계)가 하나 이상 있어야 하므로 마지막 커넥터는 삭제할 수 없습니다.

[변환 패널, 치수 또는 끌어서 놓기](../robots/131903495.md)를 사용하여 커넥터 위치를 변경할 수 있습니다.

## 메커니즘을 어셈블리에 연결

어셈블리 뷰에서 **왼쪽 Ctrl** 키를 누르고 있으면 모든 커넥터가 표시됩니다. 비어 있는 커넥터는 빨간색 점으로, 사용 중인 커넥터는 녹색 점으로 표시됩니다.

[![images/download/attachments/150674458/image2023-10-27_14-37-9.png](../assets/0e60abe5d724bbae5b03d20cf1b8de2c632f3532a5d671790a695f366d5a2481.png)](../assets/0e60abe5d724bbae5b03d20cf1b8de2c632f3532a5d671790a695f366d5a2481.png "전체 크기 이미지 열기")

사용 중인 커넥터(녹색 점)를 클릭하면 메커니즘 간의 연결이 해제됩니다.

**왼쪽 Ctrl** 키를 누른 상태에서 메커니즘을 끌어 다른 메커니즘 위에 놓습니다. MachineMaker는 연결할 커넥터 사이에 달라붙는 화살표를 표시합니다.

[![어셈블리](../assets/49190c86f4d3855d6ca73c3ae898c4af2f24168e9b54d268db35e856864e56b6.webp)](../assets/49190c86f4d3855d6ca73c3ae898c4af2f24168e9b54d268db35e856864e56b6.webp "전체 크기 이미지 열기")

메커니즘끼리 스냅되지 않도록 하면서 끌어서 놓기 기능을 사용하려면 **왼쪽 Alt** 키를 사용합니다.

## 어셈블리 트리 사용

어셈블리 트리에는 모든 메커니즘과 커넥터가 표시됩니다.

[![images/download/attachments/150674458/image2023-10-27_14-46-20.png](../assets/c4510d9ace6fadb1c3c0803d04788aa8417ed19cc5727d77b331da45da2ea256.png)](../assets/c4510d9ace6fadb1c3c0803d04788aa8417ed19cc5727d77b331da45da2ea256.png "전체 크기 이미지 열기")

어셈블리 트리에서도 끌어서 놓기를 사용할 수 있습니다. Kuka Robot을 끌어 **Mechanisms**(메커니즘) 노드에 놓으면 Rail과의 연결이 해제됩니다.

[![어셈블리](../assets/83d0374f46ccf251de32629389113f67a9f7d3ea4577a7a75c4433fe9bf6c77e.webp)](../assets/83d0374f46ccf251de32629389113f67a9f7d3ea4577a7a75c4433fe9bf6c77e.webp "전체 크기 이미지 열기")

Kuka Robot을 끌어 Rail 노드에 놓으면 메커니즘이 다시 연결됩니다.

[![어셈블리](../assets/ada46de3a6ee8ed57e515ac12b69c6ffd2acebaeaa2cb694ae93a62bd409c689.webp)](../assets/ada46de3a6ee8ed57e515ac12b69c6ffd2acebaeaa2cb694ae93a62bd409c689.webp "전체 크기 이미지 열기")

![images/download/attachments/150674458/image2024-2-9_16-34-47.png](../assets/4942ec764d73c1258926647d326344a5612412b98cb04f23d8fa9bc6d346f363.png)
버튼을 사용하여 메커니즘 가시성을 전환합니다.

[![어셈블리](../assets/edfd92d4eb407525b18aa58b1ed785c04944f960e2bbb8691e95e5352894a0b5.webp)](../assets/edfd92d4eb407525b18aa58b1ed785c04944f960e2bbb8691e95e5352894a0b5.webp "전체 크기 이미지 열기")

![images/download/attachments/150674458/image2024-2-9_16-35-17.png](../assets/71c68c96a2208bcc8316fb7ad6a5de5ac652fafff63d0e7479597c52a0271abb.png)
버튼을 사용하여 메커니즘을 삭제합니다.

메커니즘을 삭제할 때는 주의해야 합니다. 연결된 모든 메커니즘도 함께 삭제됩니다. 메커니즘 하나만 삭제하려면 모든 하위 메커니즘의 연결을 해제합니다.

엔드 이펙터를 여러 개 추가하고 ![images/download/thumbnails/150674458/image2024-2-9_16-36-14.png](../assets/1c565a5181273ca4432533b8329f0b73b25200697d625ed1b36965a07f63284a.png)
버튼을 사용하여 활성 엔드 이펙터를 선택할 수 있습니다.
