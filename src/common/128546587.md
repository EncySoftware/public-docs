# 기본 창

[![images/download/attachments/128546587/image2024-8-3_9-37-39.png](../assets/1e16ef4e15a6e05b70de8c0c9011c57874de81b36cbcaedd55ff90da5faf5c06.png)](../assets/1e16ef4e15a6e05b70de8c0c9011c57874de81b36cbcaedd55ff90da5faf5c06.png "전체 크기 이미지 열기")

기본 창은 다음 영역으로 구성됩니다.

1. 도구 모음
2. 메커니즘 추가 버튼
3. 어셈블리 트리
4. 뷰 컨트롤
5. 변환 패널
6. 인터랙티브 뷰 좌표계
7. 버전 정보
8. AI 어시스턴트
9. 인터페이스 도움말

메커니즘을 선택하면 **Transformation Panel**(변환 패널)이 표시됩니다. 변환 패널을 사용하여 객체의 위치를 변경합니다. 로봇 셀에서는 이 패널을 테이블 캘리브레이션에도 사용할 수 있습니다.

**Transformation panel**에는 3가지 주요 기능이 있습니다.

1. 라이브러리에 저장. 선택한 메커니즘의 이름을 변경하고 **Save to library**(라이브러리에 저장) 버튼을 사용하여 로컬 메커니즘 라이브러리에 저장할 수 있습니다.
2. 메커니즘 뒤집기. ![기본 창](../assets/06a81f1717fb55eaee892972158e32975f77534933fc3194b2dc1af75c4492b1.png) 버튼을 사용하여 메커니즘의 위치를 뒤집습니다.
3. 값 재설정. **Reset**(재설정) 버튼을 사용하여 모든 필드를 0으로 설정합니다.

[![images/download/attachments/128546587/image2024-8-3_9-43-43.png](../assets/81e7e038f30552113f01920c9ab23fe25f20916a10bf49913fa30e87fc3c5032.png)](../assets/81e7e038f30552113f01920c9ab23fe25f20916a10bf49913fa30e87fc3c5032.png "전체 크기 이미지 열기")

메커니즘을 두 번 클릭하면 메커니즘 편집 모드로 전환됩니다.
