# 메커니즘 시뮬레이션 및 검증

**Simulation**(시뮬레이션) 탭을 선택하여 메커니즘의 운동학을 검증합니다. 트랙바를 사용하여 축 좌표를 변경하거나 입력 상자에 값을 직접 입력합니다.

[![images/download/attachments/129940423/Simulation.png](../assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png)](../assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png "전체 크기 이미지 열기")

 모든 노드를 확인하려면 **Demo**(데모) 버튼을 클릭합니다.

메커니즘을 홈 위치로 되돌리려면 **Home**(홈) 버튼을 클릭합니다. 현재 메커니즘 위치를 홈 위치로 저장하려면 **Set As Home**(홈으로 설정) 버튼을 사용합니다.
