# Mechanism Simulation and Validation

Select **Simulation** tab to validate the mechanism's kinematics. Use the trackbar to change the axis coordinates or enter values in the input box manually.

[![images/download/attachments/129940423/Simulation.png](../assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png)](../assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png "Open full-size image")

Click **Demo** button to check all nodes.

Click **Home** button to return the mechanism to the Home position. Use **Set As Home** button to save the current mechanism position as Home position.
