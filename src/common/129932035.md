# Mechanisms Library

Use ![Mechanisms Library](../assets/330eb16c8c0e06395f65174a23487602922443ff13fc11ece6b1ad2071b3fc2d.png) button to open Mechanisms library.

![Mechanisms Library](../assets/52db46eab47005046e2c949219134d8aa152b1f19ea23adb51410ceb25919a64.png)

It is possible to switch between a **Local** and **Online** libraries. Any mechanism can be saved to your local library. Select mechanism in assembly and click **Save to** **library** button.

![Mechanisms Library](../assets/3d3f0c8a9eb8ff891116c604ac3152c4f5b31ea5bd38f3ec901570d42a259cc7.png)

Use **Search** field and OEM field to find a desired machine/robot.

![Mechanisms Library](../assets/21b9823deda79cc9acba31d56f8416cf5b99b2b9c366a060d8038832169614b6.png)

It is also possible to specify the mechanism type.

![Mechanisms Library](../assets/a9737d105a05b3c10749578385b89c55e6f120d5218804e25a032935aff296dd.webp)

Finally, click the **Add** button to add selected the mechanism to your assembly.

![Mechanisms Library](../assets/7e887f5491506a8055b2679812a25f6e17679bb87b6d4f9afbebfc46012de521.webp)

It is possible to add MachineMaker mechanism file (.mmm) to your local library manually using ![Mechanisms Library](../assets/6c2f54290c5e828ac3db753234f80aa83545714c782007e409d3409290d9fcdb.png) menu.

![Mechanisms Library](../assets/61f0914983df7201971b535408cd3afb421ffdff0298726da279f23ce69b6bb8.png)
