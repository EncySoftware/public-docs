# 메커니즘 라이브러리

![메커니즘 라이브러리](../assets/330eb16c8c0e06395f65174a23487602922443ff13fc11ece6b1ad2071b3fc2d.png) 버튼을 사용하여 메커니즘 라이브러리를 엽니다.

![메커니즘 라이브러리](../assets/52db46eab47005046e2c949219134d8aa152b1f19ea23adb51410ceb25919a64.png)

**Local**(로컬) 라이브러리와 **Online**(온라인) 라이브러리 간에 전환할 수 있습니다. 모든 메커니즘은 로컬 라이브러리에 저장할 수 있습니다. 어셈블리에서 메커니즘을 선택하고 **Save to library**(라이브러리에 저장) 버튼을 클릭합니다.

![메커니즘 라이브러리](../assets/3d3f0c8a9eb8ff891116c604ac3152c4f5b31ea5bd38f3ec901570d42a259cc7.png)

원하는 기계/로봇을 찾으려면 **Search**(검색) 필드와 OEM 필드를 사용합니다.

![메커니즘 라이브러리](../assets/21b9823deda79cc9acba31d56f8416cf5b99b2b9c366a060d8038832169614b6.png)

메커니즘 유형을 지정할 수도 있습니다.

![메커니즘 라이브러리](../assets/a9737d105a05b3c10749578385b89c55e6f120d5218804e25a032935aff296dd.webp)

마지막으로 **Add**(추가) 버튼을 클릭하여 선택한 메커니즘을 어셈블리에 추가합니다.

![메커니즘 라이브러리](../assets/7e887f5491506a8055b2679812a25f6e17679bb87b6d4f9afbebfc46012de521.webp)

![메커니즘 라이브러리](../assets/6c2f54290c5e828ac3db753234f80aa83545714c782007e409d3409290d9fcdb.png) 메뉴를 사용하여 MachineMaker 메커니즘 파일(.mmm)을 로컬 라이브러리에 직접 추가할 수 있습니다.

![메커니즘 라이브러리](../assets/61f0914983df7201971b535408cd3afb421ffdff0298726da279f23ce69b6bb8.png)
