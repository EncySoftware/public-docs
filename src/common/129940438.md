# Machine equipment configuration

At the very beginning, before adding the machine equipment, we should prepare our machine and add the attachment points for our machine equipment.

To add connection points, click the plus button in the kinematics tab when editing your machine and select the desired connection.

[![images/download/attachments/129940438/image2024-2-1_12-24-32.png](../assets/5614a412f5adc0db7b35bc44888c673d1b78d0f89c8e5cc13793161f37889ff7.png)](../assets/5614a412f5adc0db7b35bc44888c673d1b78d0f89c8e5cc13793161f37889ff7.png "Open full-size image")

After that, in the kinematics tree, you need to attach the points to the desired axis and position them on the machine.

[![images/download/attachments/129940438/image2024-2-1_12-27-55.png](../assets/dd1ef6a3bd94f6aca8c09a14ca99d39fb393da02d9b8c63d9f805e1ee9c05d57.png)](../assets/dd1ef6a3bd94f6aca8c09a14ca99d39fb393da02d9b8c63d9f805e1ee9c05d57.png "Open full-size image")

Machine equipment has 2 types of axles:  
1) Rotary type;  
2) Linear type.

In this chapter we will briefly look at the settings of these two types

To add machine equipment use the **"Add Mechanism"** button.

[![images/download/attachments/129940438/image2024-8-13_11-42-28.png](../assets/18041d99304dc8c8a4bfc7c890e9481ff55e00260ede858920c164fc94b519d1.png)](../assets/18041d99304dc8c8a4bfc7c890e9481ff55e00260ede858920c164fc94b519d1.png "Open full-size image")

After importing machine equipment, select the appropriate template. Also mark the machine equipment elements with the correct color.

[![images/download/attachments/129940438/image2024-2-1_12-18-28.png](../assets/072e53d6f9c3577e4f2fcc615429acda7d465bad72d1f1238e8dd10f56beb2b1.png)](../assets/072e53d6f9c3577e4f2fcc615429acda7d465bad72d1f1238e8dd10f56beb2b1.png "Open full-size image")

Additionally, if necessary, correctly set the point through the Base CS edit mode to ensure that the machine equipment is properly secured on the machine in the future.

[![images/download/attachments/129940438/image2024-2-1_12-38-12.png](../assets/12b789344221c1022b889b92782d0381d56c9301648f344629bd15deae9e38bf.png)](../assets/12b789344221c1022b889b92782d0381d56c9301648f344629bd15deae9e38bf.png "Open full-size image")

In the **Kinematic** settings, it is important to correctly set the rotary axis.

[![images/download/attachments/129940438/Machine_equipment1.gif](../assets/45b3b8a8f353352c495c0f34c9a60298bb5ce8ea5c81ab8783ba6eec4c956e27.gif)](../assets/45b3b8a8f353352c495c0f34c9a60298bb5ce8ea5c81ab8783ba6eec4c956e27.gif "Open full-size image")

It's also crucial to provide the correct coordinates for the jaws.

[![images/download/attachments/129940438/Machine_equipment2.gif](../assets/a6a446f0f465663ae00dda9ad87e46f19905bf12d9d5e3e7c810340e1ca24a8c.gif)](../assets/a6a446f0f465663ae00dda9ad87e46f19905bf12d9d5e3e7c810340e1ca24a8c.gif "Open full-size image")

In the **Style** mode, you can adjust colors to match the machine or choose a custom color.

[![images/download/attachments/129940438/Machine_equipment3.gif](../assets/e264d593696d84400e4d09297798eff0f8adc2d4d157d05b08be2f9d5018a635.gif)](../assets/e264d593696d84400e4d09297798eff0f8adc2d4d157d05b08be2f9d5018a635.gif "Open full-size image")

After all settings have been applied, you will need to position the machine equipment on the previously set point.

[![images/download/attachments/129940438/image2024-8-13_11-43-39.png](../assets/2064af84464a6f7c7b33468699217adf15298f06762af355135ca6007aae298e.png)](../assets/2064af84464a6f7c7b33468699217adf15298f06762af355135ca6007aae298e.png "Open full-size image")

In the second case, let's consider an example of machine equipment with a linear axis. The settings are straightforward. You need to select the appropriate template and configure the motion coordinates of the linear axis.

[![images/download/attachments/129940438/image2024-2-1_12-55-22.png](../assets/9a86367232d0321116ebde47fa3e5f9064d4e69000dd8319321d16ebacb57fdc.png)](../assets/9a86367232d0321116ebde47fa3e5f9064d4e69000dd8319321d16ebacb57fdc.png "Open full-size image")

Also, if necessary, it is advisable to correctly set the point through the Base CS edit mode so that the machine equipment is securely attached to the machine in the future.

[![images/download/attachments/129940438/Machine_equipment4.gif](../assets/d8d1e400952638b191f778a11c47effdec308aea4664a737ce33949f7a9cb305.gif)](../assets/d8d1e400952638b191f778a11c47effdec308aea4664a737ce33949f7a9cb305.gif "Open full-size image")

The setting of the linear type is the same as that of the rotary type. You must also set the jaw movement limits.

[![images/download/attachments/129940438/image2024-2-1_13-1-40.png](../assets/af0b92febe9a0390ec2aee8426fd71fd2bddf409530dc85464b1f0c16b6c4dc6.png)](../assets/af0b92febe9a0390ec2aee8426fd71fd2bddf409530dc85464b1f0c16b6c4dc6.png "Open full-size image")

In simulation mode, check that everything is working correctly.

[![images/download/attachments/129940438/MachineEquipment5.gif](../assets/03d45f98f46fdc9738ac828706e113e3c4b5e01903fbda86609cbcdf8e523aea.gif)](../assets/03d45f98f46fdc9738ac828706e113e3c4b5e01903fbda86609cbcdf8e523aea.gif "Open full-size image")

In the end it was possible to assemble a machine with two machine equipment.
