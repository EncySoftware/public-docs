# 시작하기

이 장에서는 프로젝트를 만들고, 새 메커니즘을 추가하고, 3D 객체를 준비하여 가져오고, 요소를 노드로 그룹화하고, 메커니즘의 색상을 변경하고, 메커니즘을 모델링하고 검증하고, 메커니즘을 조립하고, 기계 장비를 구성하는 방법을 알아봅니다.

다양한 메커니즘의 운동학 구조 구성, 어셈블리 파라미터 구성, CAM 시스템으로 어셈블리 내보내기는 [밀링 기계](../machines/128546571.md), [로봇](../robots/129926358.md), [선삭-밀링 복합 기계](../turnmill/1.md) 섹션에서 설명합니다.
