# Getting Started

In this chapter, you will learn how to create a project, add a new mechanism, prepare and import 3D objects, group elements into nodes, change the color of a mechanism, model and validate mechanisms, assemble mechanisms and configure machine equipment.

Constructing kinematic schemes for different mechanisms, configuring assembly parameters and exporting assemblies to CAM system are described in the sections [Milling Machines](../machines/128546571.md), [Robots](../robots/129926358.md) and [Turn-Milling Machines](../turnmill/1.md).
