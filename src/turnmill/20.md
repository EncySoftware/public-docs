# 운동학 구조 만들기

***Kinematic***(운동학) 탭을 클릭하여 운동학 파라미터 패널을 엽니다.[![Click_kinematic](../assets/181002605c075db8b63d0e7db7a63eb394d78e67c907f73429e2b0fa5ef6f5fa.png)](../assets/181002605c075db8b63d0e7db7a63eb394d78e67c907f73429e2b0fa5ef6f5fa.png "전체 크기 이미지 열기")

## 운동학

MachineMaker는 현재 메커니즘의 3D 모델과 운동학 구조를 표시합니다. 커넥터의 위치를 지정하여 올바른 운동학적 연결을 구성해야 합니다.

"Model"(모델) 탭에서 미리 선택한 템플릿에 따라 메커니즘의 운동학 트리가 자동으로 구성됩니다. 메커니즘 트리를 변경해야 하는 경우에는 템플릿 이름이 "Custom"(사용자 정의) 값으로 바뀝니다.

[![선반 사용자 정의 템플릿](../assets/6d92b83e6e371f4ac6819eb7313dbaa0d22ac23705ba9a777db4799e165621a4.gif)](../assets/6d92b83e6e371f4ac6819eb7313dbaa0d22ac23705ba9a777db4799e165621a4.gif "전체 크기 이미지 열기")

처음부터 적절한 템플릿을 선택했으므로 이제 터렛 헤드 커넥터와 척 커넥터를 올바른 위치에 배치하기만 하면 됩니다. 또한 각 노드의 이동 한계를 설정합니다.

**왼쪽 Ctrl** 키를 누른 상태에서 **Turret head connector**(터렛 헤드 커넥터)와 **Chuck connector**(척 커넥터)를 원하는 위치로 끌어 옮깁니다.

[![선반 운동학](../assets/48a3353e7c70327a02020ac3468e3f3ed5d4ae7b06be8c0447d2c88e17bfd4f3.gif)](../assets/48a3353e7c70327a02020ac3468e3f3ed5d4ae7b06be8c0447d2c88e17bfd4f3.gif "전체 크기 이미지 열기")

선삭-밀링 복합 기계의 노드 이동 한계는 기계마다 다를 수 있습니다. 각 노드에 원래 기계의 값을 설정하는 것이 좋습니다.\
