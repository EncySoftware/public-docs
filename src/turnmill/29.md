# Tool block

The next step is to add two Tool blocks.

[![image2024-8-13_11-27-32](../assets/8824cdde6e1ac21006c41105eb4adc43cc8ce0363aa19fdbddbd160a35af127f.png)](../assets/8824cdde6e1ac21006c41105eb4adc43cc8ce0363aa19fdbddbd160a35af127f.png "Open full-size image")

The first to be added is the turning tool. For this purpose it is necessary to paint the upper area of the added model.

[![image2024-4-24_15-13-2](../assets/0d7092744043cce2dcf3e519ad69575a6a210599da4e69f7549bb26a9959ff60.png)](../assets/0d7092744043cce2dcf3e519ad69575a6a210599da4e69f7549bb26a9959ff60.png "Open full-size image")

It is important that the **Geometry CS** match the common coordinate system.

[![image2024-4-24_15-17-41](../assets/0518d3a39be17a120f0f708aa302f7b86fd72b0a04f65632c077467f97a4b62b.png)](../assets/0518d3a39be17a120f0f708aa302f7b86fd72b0a04f65632c077467f97a4b62b.png "Open full-size image")

Select the desired tool type

[![image2024-4-24_15-24-16](../assets/311d5eac86764767665c9cec5f45ad089445e635e0a08ad7aeef86c0e3606a59.png)](../assets/311d5eac86764767665c9cec5f45ad089445e635e0a08ad7aeef86c0e3606a59.png "Open full-size image")

On the Tool point tab, position the tool as shown in the picture:

[![image2024-4-24_15-26-23](../assets/26cb3b3f5d6055e96d08084ec77d356ef4c49e79e569f09eef783e94c135ba4c.png)](../assets/26cb3b3f5d6055e96d08084ec77d356ef4c49e79e569f09eef783e94c135ba4c.png "Open full-size image")

Add a second Tool block and paint the lower part of the model. Select the type of Mill tool.

[![image2024-4-24_15-34-18](../assets/2c936450daff2fc3b23904938e194b32c2643d26900db8fc89fd1d30389452dc.png)](../assets/2c936450daff2fc3b23904938e194b32c2643d26900db8fc89fd1d30389452dc.png "Open full-size image")

On the Tool point tab, position the tool as shown in the picture:

[![image2024-4-24_15-40-3](../assets/e9a58d51ad8a60b76af80d354640955efaa354a68ec27e0a5c4c9bad64fb893f.png)](../assets/e9a58d51ad8a60b76af80d354640955efaa354a68ec27e0a5c4c9bad64fb893f.png "Open full-size image")

Then click apply and this is the end of adding two tool blocks.
