# 공구 블록

다음 단계는 공구 블록 두 개를 추가하는 것입니다.

[![image2024-8-13_11-27-32](../assets/8824cdde6e1ac21006c41105eb4adc43cc8ce0363aa19fdbddbd160a35af127f.png)](../assets/8824cdde6e1ac21006c41105eb4adc43cc8ce0363aa19fdbddbd160a35af127f.png "전체 크기 이미지 열기")

먼저 선삭 공구를 추가합니다. 이를 위해 추가한 모델의 위쪽 영역을 색칠해야 합니다.

[![image2024-4-24_15-13-2](../assets/0d7092744043cce2dcf3e519ad69575a6a210599da4e69f7549bb26a9959ff60.png)](../assets/0d7092744043cce2dcf3e519ad69575a6a210599da4e69f7549bb26a9959ff60.png "전체 크기 이미지 열기")

**Geometry CS**(형상 좌표계)가 공통 좌표계와 일치하는 것이 중요합니다.

[![image2024-4-24_15-17-41](../assets/0518d3a39be17a120f0f708aa302f7b86fd72b0a04f65632c077467f97a4b62b.png)](../assets/0518d3a39be17a120f0f708aa302f7b86fd72b0a04f65632c077467f97a4b62b.png "전체 크기 이미지 열기")

원하는 공구 유형을 선택합니다.

[![image2024-4-24_15-24-16](../assets/311d5eac86764767665c9cec5f45ad089445e635e0a08ad7aeef86c0e3606a59.png)](../assets/311d5eac86764767665c9cec5f45ad089445e635e0a08ad7aeef86c0e3606a59.png "전체 크기 이미지 열기")

Tool point(공구 포인트) 탭에서 그림과 같이 공구를 배치합니다.

[![image2024-4-24_15-26-23](../assets/26cb3b3f5d6055e96d08084ec77d356ef4c49e79e569f09eef783e94c135ba4c.png)](../assets/26cb3b3f5d6055e96d08084ec77d356ef4c49e79e569f09eef783e94c135ba4c.png "전체 크기 이미지 열기")

두 번째 공구 블록을 추가하고 모델의 아래쪽 부분을 색칠합니다. 공구 유형은 Mill tool(밀링 공구)로 선택합니다.

[![image2024-4-24_15-34-18](../assets/2c936450daff2fc3b23904938e194b32c2643d26900db8fc89fd1d30389452dc.png)](../assets/2c936450daff2fc3b23904938e194b32c2643d26900db8fc89fd1d30389452dc.png "전체 크기 이미지 열기")

Tool point 탭에서 그림과 같이 공구를 배치합니다.

[![image2024-4-24_15-40-3](../assets/e9a58d51ad8a60b76af80d354640955efaa354a68ec27e0a5c4c9bad64fb893f.png)](../assets/e9a58d51ad8a60b76af80d354640955efaa354a68ec27e0a5c4c9bad64fb893f.png "전체 크기 이미지 열기")

그런 다음 Apply(적용) 버튼을 클릭하면 공구 블록 두 개의 추가가 완료됩니다.
