# Dual-row tool turret

In this chapter, we will look at setting up the dual-row tool turret.

[![image2025-6-9_14-53-52](../assets/069838abd4d3187232a1adbac3bb2b82e8482636502a482d6ca5ae711a4e8e8c.png)](../assets/069838abd4d3187232a1adbac3bb2b82e8482636502a482d6ca5ae711a4e8e8c.png "Open full-size image")

Now you can use button ![image2025-6-9_15-6-7](../assets/95662f9dfe2674eb3b977b55feca8d54be336d1d635c4fff99d71b77159a22b0.png) in the kinematic settings to add additional rows of connection points for tool placement on the turret.\
If needed, the added block can also be removed using button ![image2025-6-9_15-12-59](../assets/234a01b1f62dfaa5b953e8c0ee571a06186425f4e7921e91a78d5bcadff44f5a.png)

[![2row](../assets/3f00e280b7b7cae6adad1cf07d0765c04099345ca8fb5c1ddb2ee90a7ef73ac6.gif)](../assets/3f00e280b7b7cae6adad1cf07d0765c04099345ca8fb5c1ddb2ee90a7ef73ac6.gif "Open full-size image")

On the "**Tool Blocks"** tab, you may see that by default the added tool uses all connection points. If you want to use only some of the points, click the **"Set same tool block for all positions in row button"**. This will clear the turret, so you can place the tools as you need.
