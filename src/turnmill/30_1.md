# 2열 공구 터렛

이 장에서는 2열 공구 터렛을 설정하는 방법을 살펴봅니다.

[![image2025-6-9_14-53-52](../assets/069838abd4d3187232a1adbac3bb2b82e8482636502a482d6ca5ae711a4e8e8c.png)](../assets/069838abd4d3187232a1adbac3bb2b82e8482636502a482d6ca5ae711a4e8e8c.png "전체 크기 이미지 열기")

이제 운동학 설정에서 ![image2025-6-9_15-6-7](../assets/95662f9dfe2674eb3b977b55feca8d54be336d1d635c4fff99d71b77159a22b0.png) 버튼을 사용하여 터렛에 공구를 배치할 연결 포인트 행을 추가할 수 있습니다.\
필요한 경우 ![image2025-6-9_15-12-59](../assets/234a01b1f62dfaa5b953e8c0ee571a06186425f4e7921e91a78d5bcadff44f5a.png) 버튼을 사용하여 추가한 블록을 제거할 수도 있습니다.

[![2row](../assets/3f00e280b7b7cae6adad1cf07d0765c04099345ca8fb5c1ddb2ee90a7ef73ac6.gif)](../assets/3f00e280b7b7cae6adad1cf07d0765c04099345ca8fb5c1ddb2ee90a7ef73ac6.gif "전체 크기 이미지 열기")

**"Tool Blocks"**(공구 블록) 탭을 보면 기본적으로 추가한 공구가 모든 연결 포인트를 사용하는 것을 확인할 수 있습니다. 일부 연결 포인트만 사용하려면 **"Set same tool block for all positions in row button"**(행의 모든 위치에 같은 공구 블록 설정 버튼)을 클릭합니다. 그러면 터렛이 비워지므로 필요한 대로 공구를 배치할 수 있습니다.
