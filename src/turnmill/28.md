# 척 커넥터

기계를 만든 후 다음 단계는 Chuck connector(척 커넥터)를 추가하는 것입니다.

모델을 편집할 때는 회전축과 죠 조인트만 사용합니다.

[![image2024-4-24_13-26-44](../assets/f2097d831148d57237d38859440a99ddd3d63c71fe83f099cdaa834954a1b904.png)](../assets/f2097d831148d57237d38859440a99ddd3d63c71fe83f099cdaa834954a1b904.png "전체 크기 이미지 열기")

회전축은 처음부터 올바르게 설정되어 있으므로 죠의 이동 한계와 죠가 이동할 좌표만 편집하면 됩니다.

[![image2024-4-24_13-46-24](../assets/e54f2609d288782503f2efd330942d8ca5d6bc4a492af4378cdd6eb631739440.png)](../assets/e54f2609d288782503f2efd330942d8ca5d6bc4a492af4378cdd6eb631739440.png "전체 크기 이미지 열기")

다음 단계로 죠의 홈 위치를 설정하고, 시뮬레이션에서 메커니즘이 올바르게 작동하는지 테스트한 다음 적용합니다.
