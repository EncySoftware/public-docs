# 멀티 공구 헤드

Multi Tool Head(멀티 공구 헤드)는 원하는 수만큼 공구 블록을 장착할 수 있도록 만들어졌으며, 이 공구 블록은 쉽게 구성하고 조정할 수 있습니다.\
완전히 사용자 정의된 멀티 공구 헤드를 만들 수 있습니다.

멀티 공구 헤드를 추가하려면 밀링 기계가 포함된 프로젝트를 만들어야 합니다.

[![image2025-5-23_14-58-18](../assets/77b0e8e0b1eaf7d7b3de475aea6314308feae8b53996c5001d9d9a2ea369f7d7.png)](../assets/77b0e8e0b1eaf7d7b3de475aea6314308feae8b53996c5001d9d9a2ea369f7d7.png "전체 크기 이미지 열기")

**Multi Tool Head**의 뒷면에 장착 포인트를 연결하고 움직이는 구성 요소를 지정합니다.

[![image2025-5-23_15-6-50](../assets/440c5e25e26df14992ac84f312eff112035b0dbf86736f166d3b02b952a8428a.png)](../assets/440c5e25e26df14992ac84f312eff112035b0dbf86736f166d3b02b952a8428a.png "전체 크기 이미지 열기")

다음으로 밀링 기계에 장착 포인트를 만들고 **Workpiece**(공작물) 설정을 약간 조정합니다.

[![settingsto4kiformultitoolhead](../assets/eb0d747f25ef9866a3fc99e27fd1d39b432b8b8c3cbb2e8b14a2570e2cd05140.gif)](../assets/eb0d747f25ef9866a3fc99e27fd1d39b432b8b8c3cbb2e8b14a2570e2cd05140.gif "전체 크기 이미지 열기")

멀티 공구 헤드를 밀링 기계에 장착한 후 Tool Blocks View(공구 블록 보기) 창을 열고 이 창에서 장착할 새 공구를 추가합니다.

[![image2025-5-23_15-32-16](../assets/d985337691b622ffdb41d20aab127d7c98e86dbca061af0a05e9fa89ecbcc2df.png)](../assets/d985337691b622ffdb41d20aab127d7c98e86dbca061af0a05e9fa89ecbcc2df.png "전체 크기 이미지 열기")

공구를 추가할 때 Supported Applications(지원 응용 프로그램)에 나열된 모든 유형을 선택할 수 있습니다. 이 예에서는 Lathe Cutting(선반 커팅)을 사용합니다.

[![image2025-5-23_15-38-9](../assets/c83e22fc1e370391921afd90bd4957071ddb754fa4bd4b65568347d0562181ec.png)](../assets/c83e22fc1e370391921afd90bd4957071ddb754fa4bd4b65568347d0562181ec.png "전체 크기 이미지 열기")

여러 공구를 추가할 때는 각 공구가 올바르게 배치되었는지 확인합니다. 공구 위치를 변경하려면 해당 공구의 **Base Connector**(기준 커넥터) 위치를 조정합니다.

[![image2025-5-23_15-44-7](../assets/56e1e4f05e7a49746ef1da3a2facffd1155852f6cd6733e2c3db1d51bb5389ea.png)](../assets/56e1e4f05e7a49746ef1da3a2facffd1155852f6cd6733e2c3db1d51bb5389ea.png "전체 크기 이미지 열기")

프로젝트를 내보낸 후 **Multi Tool Head**가 장착된 기계를 테스트할 수 있습니다.

[![ExportMultiToolHead](../assets/d262aadf2a51f8f3938b186ec157c5d0de812caace88110c6153e8a969324a84.gif)](../assets/d262aadf2a51f8f3938b186ec157c5d0de812caace88110c6153e8a969324a84.gif "전체 크기 이미지 열기")

이 멀티 공구 헤드로 기계를 만드는 방법은 [링크](https://www.youtube.com/watch?v=EIswSr_5KuM&ab_channel=ENCYSoftware)에서 확인할 수 있습니다.
