# Protected interpreters

To ensure that the interpreter is used in accordance with the issued license, do the following:

1. The interpreter must be developed using the [protection interface](../../g-code-interpretation/interfaces/interpreter-interfaces/protection-interface/protection-interface.md).
2. The interpreter must be [placed in a container](https://docs.encycam.com/ENCY/3/en/10022.html).
3. The [file or files with secret data](../../g-code-interpretation/interfaces/interpreter-interfaces/protection-interface/protection-interface.md) must be placed in the container together with the interpreter.

After the container license is issued and activated, the user can use the interpreter, see [G-code based simulation](https://docs.encycam.com/ENCY/3/en/10291.html).
