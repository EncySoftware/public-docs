# Multi Tool Head

The Multi Tool Head is made to hold any number of tool blocks, which can be easily configured and adjusted.\
You can build fully custom Multi Tool Head.

To add it you need to create a project with a milling machine.

[![image2025-5-23_14-58-18](assets/77b0e8e0b1eaf7d7b3de475aea6314308feae8b53996c5001d9d9a2ea369f7d7.png)](assets/77b0e8e0b1eaf7d7b3de475aea6314308feae8b53996c5001d9d9a2ea369f7d7.png "Open full-size image")

Attach a mounting point to the rear of the **Multi Tool Head** and identify its moving components.

[![image2025-5-23_15-6-50](assets/440c5e25e26df14992ac84f312eff112035b0dbf86736f166d3b02b952a8428a.png)](assets/440c5e25e26df14992ac84f312eff112035b0dbf86736f166d3b02b952a8428a.png "Open full-size image")

Next, create a mounting point on the milling machine and slightly customize **Workpiece** settings.

[![settingsto4kiformultitoolhead](assets/eb0d747f25ef9866a3fc99e27fd1d39b432b8b8c3cbb2e8b14a2570e2cd05140.gif)](assets/eb0d747f25ef9866a3fc99e27fd1d39b432b8b8c3cbb2e8b14a2570e2cd05140.gif "Open full-size image")

After mounting the Multi-Tool Head on the milling machine, open the Tool Blocks View window and use it to add the new tool for installation

[![image2025-5-23_15-32-16](assets/d985337691b622ffdb41d20aab127d7c98e86dbca061af0a05e9fa89ecbcc2df.png)](assets/d985337691b622ffdb41d20aab127d7c98e86dbca061af0a05e9fa89ecbcc2df.png "Open full-size image")

When adding a tool, you may select any type listed under Supported Applications. In this case, Lathe Cutting will be used.

[![image2025-5-23_15-38-9](assets/c83e22fc1e370391921afd90bd4957071ddb754fa4bd4b65568347d0562181ec.png)](assets/c83e22fc1e370391921afd90bd4957071ddb754fa4bd4b65568347d0562181ec.png "Open full-size image")

When adding multiple tools, ensure proper placement of each tool. To reposition a tool, adjust the location of its **Base Connector.**

[![image2025-5-23_15-44-7](assets/56e1e4f05e7a49746ef1da3a2facffd1155852f6cd6733e2c3db1d51bb5389ea.png)](assets/56e1e4f05e7a49746ef1da3a2facffd1155852f6cd6733e2c3db1d51bb5389ea.png "Open full-size image")

After exporting the project, you can test the machine equipped with the **Multi Tool Head.**

[![ExportMultiToolHead](assets/d262aadf2a51f8f3938b186ec157c5d0de812caace88110c6153e8a969324a84.gif)](assets/d262aadf2a51f8f3938b186ec157c5d0de812caace88110c6153e8a969324a84.gif "Open full-size image")
