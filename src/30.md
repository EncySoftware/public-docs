# Turret head node

Next, you need to add a Turret head node.

[![image2024-5-2_10-29-5](assets/63d331499a1fe8b8552d51d0c51e684573ecca35e584aaa4122a7fb8744293f8.png)](assets/63d331499a1fe8b8552d51d0c51e684573ecca35e584aaa4122a7fb8744293f8.png "Open full-size image")

It is important to position the Base CS on the back of the mechanism.

[![CSTURRET](assets/cb9e93932f15b0d475bc0ca514c6ff8405b1623810283dd7f23826330b9c5bee.gif)](assets/cb9e93932f15b0d475bc0ca514c6ff8405b1623810283dd7f23826330b9c5bee.gif "Open full-size image")

Next, you need to position the connection points of the blocks. To do this, you can use Interactive mode, which helps you to perform this task quickly. By dragging 1 point it automatically sets other points as well.

[![interturret](assets/b1812f9dba50637ecfcb88a9e1ac693580b2747ddce1244b0d789cccb3e48aa3.gif)](assets/b1812f9dba50637ecfcb88a9e1ac693580b2747ddce1244b0d789cccb3e48aa3.gif "Open full-size image")

The next step is to place the tool blocks on the connecting points. You can add tools in 2 ways:\
1) Use the right mouse button;\
2) Select the desired tool from the drop-down menu.

[![nakonectoturretheadkrug](assets/3552e2bf79846e0d969fcbd70895e0af1ed68324f25b7c59e3b9adb5060715e1.gif)](assets/3552e2bf79846e0d969fcbd70895e0af1ed68324f25b7c59e3b9adb5060715e1.gif "Open full-size image")

On the Simulation tab make sure that the Turret head moves correctly and click apply.

[![applyturrethead](assets/c660044ee3adab7e210ccd088071eeab198d8d52a3b8fe2a25f5091f8ee32829.gif)](assets/c660044ee3adab7e210ccd088071eeab198d8d52a3b8fe2a25f5091f8ee32829.gif "Open full-size image")

At this point, the build of the lathe milling machine is complete.
