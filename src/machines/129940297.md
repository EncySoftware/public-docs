# Building a kinematic scheme

Click **Kinematic** tab to open kinematic parameters panel.[![images/download/attachments/129940297/Click_kinematic.PNG](../assets/181002605c075db8b63d0e7db7a63eb394d78e67c907f73429e2b0fa5ef6f5fa.png)](../assets/181002605c075db8b63d0e7db7a63eb394d78e67c907f73429e2b0fa5ef6f5fa.png "Open full-size image")

First of all it is necessary to build correct mechanism's kinematic tree, using grag and drop. MachineMaker will show Tool node as a sample tool and Workpiece node as a sample part.

[![images/download/attachments/129940297/graganddrop.gif](../assets/2fa40ca5bdd298e1cc625907a5061eed4590d9cd665ad7f4825439ccc4d7fc3d.gif)](../assets/2fa40ca5bdd298e1cc625907a5061eed4590d9cd665ad7f4825439ccc4d7fc3d.gif "Open full-size image")

In the **Tool** settings there is a function to select **Supported applications** and also additional options.

[![images/download/attachments/129940297/image2024-2-2_12-36-28.png](../assets/c8d0bdf9e2ebe355bbe5801d8bf6001bb8185f05f4208b6b244ebef8d5c7dee0.png)](../assets/c8d0bdf9e2ebe355bbe5801d8bf6001bb8185f05f4208b6b244ebef8d5c7dee0.png "Open full-size image")

**Workpiece** also has its own additional parameters.

[![images/download/attachments/129940297/image2024-2-2_12-44-25.png](../assets/2a627b3aa1979e7f2f53199a0dc36f10df608c90760645fe1352041971894932.png)](../assets/2a627b3aa1979e7f2f53199a0dc36f10df608c90760645fe1352041971894932.png "Open full-size image")

Next it is necessary to specify parameters of each node.

Set node name and type.

[![images/download/attachments/129940297/image2023-10-30_12-37-2.png](../assets/e91c4456777ce7b1c7f3556f2d03a61f04f58bbf36f6d3dca96c55a2e4c96afb.png)](../assets/e91c4456777ce7b1c7f3556f2d03a61f04f58bbf36f6d3dca96c55a2e4c96afb.png "Open full-size image")

Next it is necessary to specify node **Address** for Linear and Rotary nodes. It will be used in Postprocessors.

[![images/download/attachments/129940297/image2023-10-30_12-37-50.png](../assets/131aefbd634ed0d8bcd98d0d0060dfb6e36d5eb24df0d9410236ac167e57051b.png)](../assets/131aefbd634ed0d8bcd98d0d0060dfb6e36d5eb24df0d9410236ac167e57051b.png "Open full-size image")

Select linear axis direction. You can select X Y Z or custom. Use **Orientation** field to define **Custom** direction vector.

[![images/download/attachments/129940297/image2023-10-30_12-39-36.png](../assets/05b14d4ea71a0b879c0f3afc8b128110b752058d361937242e3006f89bb41e68.png)](../assets/05b14d4ea71a0b879c0f3afc8b128110b752058d361937242e3006f89bb41e68.png "Open full-size image")

[![images/download/attachments/129940297/limits.gif](../assets/90176240d731f1579031dee90a9a2a0d881d6b391125a96e1a15a1b3bd3ce7a5.gif)](../assets/90176240d731f1579031dee90a9a2a0d881d6b391125a96e1a15a1b3bd3ce7a5.gif "Open full-size image")

Next define **Has Brake, Increment** and **Scale** parameters. Change **Control** parameter if axis is Indexed or Manual. It is possible to **Invert Direction** of axis.

[![images/download/attachments/129940297/image2022-4-20_18-40-54.png](../assets/bb1d314c85e195ed8e869a522f2b7131004c0bafb20ea8674f33efcd00588b6e.png)](../assets/bb1d314c85e195ed8e869a522f2b7131004c0bafb20ea8674f33efcd00588b6e.png "Open full-size image")

For rotary axes it is necessary to specify point of rotation. Hold the **Left Mouse Button,** drag the bearing and drop it to the snap point. Use **Transformation Panel** to set position and rotation manually.

[![images/download/attachments/129940297/dmu50rotary2.gif](../assets/c06d0ef213ee50e49fdddff72f19d3298cf68728d6c872da96bed47f5e234694.gif)](../assets/c06d0ef213ee50e49fdddff72f19d3298cf68728d6c872da96bed47f5e234694.gif "Open full-size image")

Finally it is necessary to set **Tool Type** and specify positions of Tool and Workpiece. Place Tool and Workpiece to the correct position at the **Kinematic tree.** Then hold the **Left Mouse Button,** drag the bearing and drop it to the snap point. Use **Transformation Panel** to set position and rotation manually.

[![images/download/attachments/129940297/dmu502.gif](../assets/1306c56dccc43d2b21f0c3a5880d89addc487f30763575a85cf9f249e6acafe9.gif)](../assets/1306c56dccc43d2b21f0c3a5880d89addc487f30763575a85cf9f249e6acafe9.gif "Open full-size image")
