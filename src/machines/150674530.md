# Additional options

Click ![images/download/thumbnails/150674530/button.PNG](../assets/3a1791e7395011803de4fdaf8e44a5caf7762b3f78fab72ff1c7e95b71c72510.png)
button to open **Machine parameters panel**. Then go to the **Axes** tab. It is possible to specify

[![images/download/attachments/150674530/image2023-11-29_10-57-21.png](../assets/01c14dc3b1fdfe881b887869e7c9683c815b83fea06e366f0d3a24ed974702b1.png)](../assets/01c14dc3b1fdfe881b887869e7c9683c815b83fea06e366f0d3a24ed974702b1.png "Open full-size image")

- Address - axis designation.
- Control:

1. Countinuous.
2. Indexed - indicates that rotation will be carried out incrementally.
3. Manual - implies that the operation is entirely manual.

- Shortest path rotation - refers to the rotation around an axis or point using the most direct path between the initial and final positions in three-dimensional space.
- Scale is a setting with four positions. Each position corresponds to a specific angular increment. Position 1 equals 90 degrees, Position 2 equals 180 degrees, and so on.
