# Extension Store for authors

The Extension Store is the catalog of extensions for the CAM system. Users find extensions on the
store website or on the **Extensions** tab of the CAM system and install them in one click. This
guide takes an author from an empty project to an extension in the catalog, on sale if you wish,
and through every version after it.

Writing the extension code is covered by the API documentation and the examples; this guide links
to them rather than repeating them (see [External references](references.md)).

## Your path

1. **Become a developer.** Once, in your store account: who publishes, your details, the terms.
   See [Getting started](getting-started.md).
2. **Build and try it.** Start from the template and run the extension in your own CAM system.
   See [Build and test locally](local-testing.md).
3. **Publish.** From a GitHub repository, from an AI assistant, or by uploading a package. See
   [Publishing](publishing.md).
4. **Pass moderation.** A moderator reviews every version before users get it. See
   [Review, updates and visibility](review-and-updates.md).
5. **Sell, if you want to.** Set a price and receive your share through Stripe. See
   [Selling and payouts](paid-extensions.md).
6. **Keep it alive.** Ship new versions, support your users, keep pace with new releases of the
   CAM system.

Publishing for a company, or together with someone? See
[Organizations and collaborators](organizations.md). To see the store through your users' eyes,
read [What your users see](users.md).
