# Extension Store for authors

The Extension Store is the catalog of extensions for the CAM system. Users browse it on the
store website or on the **Extensions** tab of the CAM system, and install an extension in one
click. This guide is for authors: it takes you from an empty project to an extension published
in the store, and through its later versions.

Writing the extension code itself is covered by the API documentation and the examples; this
guide links to them instead of repeating them (see [External references](references.md)).

## The path in brief

1. Get the tools and a store account, register as a developer once, and read the store rules.
2. Start a project from the template or from an example.
3. Build the extension and try it in a local CAM system.
4. Publish it: from a GitHub repository, from an AI assistant, or by uploading a package.
5. Wait for the moderator to approve the first publication; later versions go live without
   review.
