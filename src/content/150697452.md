# 라이선스 활성화

![admin 프로필과 Open 버튼이 있는 ENCY Hyper 로그인 화면](../assets/a365577111d66a65bb1bddbac06dbbbab83a52d15dc946c38851e5371ec8e39b.png)

로그인 화면에서 **Log in as**(다음 사용자로 로그인) 아래에 표시된 사용자 프로필(이 예에서는 **admin**)을 확인한 다음 **Open**(열기)을 클릭하여 로그인합니다.  
ENCY Hyper는 라이선스가 없음을 감지하고 라이선스 활성화 페이지로 이동합니다. 이 과정에는 카메라가 있는 휴대폰이 필요합니다.

![라이선스 활성화](../assets/4f302148fd4e333b8d3db2b3e2098f7a9198803ebf1291977082e6f471d641f7.png)

QR 코드를 스캔하면 로그인 페이지로 이동합니다. 계정이 없으면 이 페이지에서 계정을 만들 수 있습니다.

로그인하면 라이선스 활성화가 자동으로 시작됩니다. 컴퓨터가 인터넷에 연결되어 있지 않으면 **Get activation code manually**(수동으로 활성화 코드 받기) 버튼을 사용하여 받은 CM 코드를 직접 입력해야 합니다.

![라이선스 활성화](../assets/a5b7be7452b082d3530a6e946952f3cc1d9cd46fdf01c56c35c3e218ac06e31f.jpg)

 

![라이선스 활성화](../assets/fd2399384685f7cdf88a0349c1f52a77254931426de931918a142038e58dea44.jpg)

라이선스가 정상적으로 활성화되어야 합니다. **OK**(확인) 버튼을 클릭하면 ENCY Hyper 기본 창이 실행됩니다.

![라이선스 활성화](../assets/d7a62419f3d38212b36cce22eeb7fe237dfcbff21c8364fa8d246541e10cef5f.png)
