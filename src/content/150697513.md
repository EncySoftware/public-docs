# 부품 모드

![부품 목록, 로봇 셀, 원기둥 속성이 표시된 부품 모드](../assets/38bdaaa308e1ead20bbbd11e3cd3bdb1709aeeffa01a790154e8e0bd1557bcb7.png)

## 적용 분야

부품 모드에서는 모델을 추가하거나 기본 요소로 모델을 만들고, 이를 **트레이**에 배치할 수 있습니다.

### 가져오기

**Import**(가져오기)를 사용하면 제품의 3D 모델을 불러올 수 있습니다.

**Type**(유형). 원기둥, 박스 또는 3D 모델입니다.

**Custom file**(사용자 정의 파일). 모델을 다시 선택할 수 있습니다.

**Stacking offset**(적층 오프셋). 쌓아 올린 부품 사이의 수직 정렬 관계를 결정하는 파라미터입니다.

값 = 0: 부품이 겹치지 않고 바로 위에 차례로 놓입니다.

값 > 0: 서로 맞물리는 부품의 삽입 깊이를 정의합니다(예: LEGO와 같이 맞물리는 구조에서는 연결 원기둥의 높이와 같습니다).

**Base point/ Pick point**(베이스 포인트 / 픽 포인트). 배치의 기준이 되는 점 / 부품을 잡는 점입니다.

- 픽 포인트와 베이스 포인트는 개수 제한 없이 만들 수 있습니다.
- 각 포인트는 편집, 삭제, 이름 변경이 가능합니다.
- 좌표는 직접 입력하거나 모델에서 선택하여 지정할 수 있습니다.
- 그리퍼가 시각적으로 표시되어 로봇의 실제 파지 자세를 보여 주므로 픽 포인트를 정의하는 데 도움이 됩니다.

**Name point**(포인트 이름). 기존 포인트에 이름을 지정합니다.

**Add/Delete a point**(포인트 추가/삭제). **포인트 목록**에 추가되는 포인트를 만들거나 삭제할 수 있습니다.

**List of points**(포인트 목록). 포인트 이름을 표시합니다.

![추가 및 삭제 버튼이 있는 베이스 포인트 목록](../assets/bfe2822d4a2f2b4aed2190de56d687ad914031b6a445c25e76e9608b41075091.png)

**X,Y,Z,Rx,Ry,Rz,A,B,C** - 포인트의 공간상 방향을 지정하는 필드입니다.

### 부품 추가

**Add part**(부품 추가)를 사용하면 기본 요소로 모델을 만들 수 있습니다. 이 템플릿의 일부 파라미터는 **Import - 3D model**의 파라미터와 같습니다.

**Cylinder**(원기둥).

**Diameter**(직경). 원형 밑면의 중심을 지나는 거리입니다.

**Height**(높이). 축 방향으로 두 밑면 사이의 거리입니다.

**Box**(박스).

**Width**(너비). 너비를 정의합니다.

**Depth**(깊이). 깊이를 정의합니다.

**Height.** 높이를 정의합니다.

### 트레이별 필터

**Filter by tray**(트레이별 필터)를 사용하면 작업할 특정 트레이를 선택할 수 있습니다.

### 부품 목록

이동할 부품의 목록을 표시하며 부품을 편집할 수 있습니다.

![부품 모드](../assets/56c51e3e3f51b8423dee174545618d5762c5d0a816378e64a9d841a4b70b3c20.png)

부품을 클릭하면 다음 작업을 할 수 있는 창이 열립니다.

1. 모델 이름 보기
2. 모델 편집
3. 모델 삭제
4. 베이스 포인트와 픽 포인트 표시
5. 모델 회전(미리 보기)

### 작업 특성

이 모드에서는 부품을 초기 위치에 배치합니다.

트레이에 부품을 배치하려면 다음과 같이 합니다.

- 부품 트리에서 필요한 부품을 선택합니다.
- 그래픽 창에서 부착 포인트를 선택합니다.
- 선택한 부품이 해당 위치에 나타납니다.

![부품 모드에서 트레이 부착 포인트에 배치된 원기둥](../assets/337b9b7c2e2688bb0bb05d4c7b9b57f86c2d54e60e8a1d14d41097a2b9b2b65b.png)

부품이 이미 장착된 위치(부착 포인트)는 색이 바뀌어 해당 슬롯이 사용 중임을 나타냅니다.

부품을 위치에서 **제거**하려면 부품이 있는 부착 포인트를 클릭하기만 하면 됩니다.

**여러 부품**을 한 번에 추가하려면 **마우스 왼쪽 버튼을 길게 누릅니다**. 그러면 이 부품을 트레이 전체에 추가할지 묻는 대화 상자가 나타납니다.

![부품 모드](../assets/dfed73c0ad7dd99459737121c7566cd23d7147236b35725cf6b2ca3a034c9c5c.png)

![빈 트레이 옆에 원기둥으로 채워진 트레이](../assets/bdc22c9d32a5e5f9ade92edb86eac65886f355a54d783684442edd373d30b7b3.png)

트레이에서 부품을 제거할 때도 같은 방식이 적용됩니다.
