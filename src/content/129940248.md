# Grouping elements into nodes

## Grouping elements

Equipment elements need to be grouped into nodes. Mark 3D model elements with specific colors to group them.

You can choose a template that suits your machine.

[![images/download/attachments/129940248/template.gif](../assets/696ec3948870981a38e8d037e413387964a131c0d8967c41110e79b5626f3dec.gif)](../assets/696ec3948870981a38e8d037e413387964a131c0d8967c41110e79b5626f3dec.gif "Open full-size image")

Select a node color from the right panel and mark desired elements on the 3D model. Each element marked with the same color will be added to the same group.

Use **Tab**, **↑**, **↓** keys to switch current color.

[![images/download/attachments/129940248/markeruyou.gif](../assets/bbe0cb2e77fa9eada357846fa6ae19eb7108cfdc77c5b890f8704138e44a4721.gif)](../assets/bbe0cb2e77fa9eada357846fa6ae19eb7108cfdc77c5b890f8704138e44a4721.gif "Open full-size image")

It is not necessary to mark each element. You can keep unnecessary elements unmarked to exclude them from mechanism. MachineMaker also saves source CAD file, so it is possible to change elements groups anytime.

Use right mouse button to unmark 3D model element. Note that you can unmark only currently selected node elements. You can also use the keyboard shortcut **"Ctrl + z"** to roll back changes.

[![images/download/attachments/129940248/unmark.gif](../assets/7b729f7e89cff0b4fbae2d3cbaf690620510f0b8fff4e8add32f7ce927b459c0.gif)](../assets/7b729f7e89cff0b4fbae2d3cbaf690620510f0b8fff4e8add32f7ce927b459c0.gif "Open full-size image")

It is possible to delete unnecessary elements from the 3D model using **Del** key. Use **Ctrl+Z** to undo element deletion.

MachineMaker stores all imported 3D models in the **CAD Files** folder. You can always reimport the 3D model using **Reimport** button. Turn off **Copy imported CAD files** checkbox to disable saving original CAD models.

[![images/download/attachments/129940248/image2024-2-9_15-31-9.png](../assets/fe9327db1bd79f05fab32b6fc6295a2352b296adf986ff8c9a85a4f5a6f3de17.png)](../assets/fe9327db1bd79f05fab32b6fc6295a2352b296adf986ff8c9a85a4f5a6f3de17.png "Open full-size image")

**Add file** - function for adding additional files.

[![images/download/attachments/129940248/image2024-2-9_15-32-6.png](../assets/e8b5d4c29583593559028eedeeb5241ea1a17c4d71416de2a2eed7fdb8d4deab.png)](../assets/e8b5d4c29583593559028eedeeb5241ea1a17c4d71416de2a2eed7fdb8d4deab.png "Open full-size image")

If MachineMaker can't group elements correctly, see how to [fix your CAD models](https://docs.encycam.com/ENCY/3/en/src/content/10401.html).

Mechanism name and type

It is necessary to enter Mechanism name. MachineMaker uses 3D model filename as default name.

[![images/download/attachments/129940248/image2023-10-30_11-39-58.png](../assets/0e9f9aa1f69100f92c55bffba8e51377e45f571f043f2068e7a519b1bb3a0229.png)](../assets/0e9f9aa1f69100f92c55bffba8e51377e45f571f043f2068e7a519b1bb3a0229.png "Open full-size image")

## World CS position

It is necessary to specify Machine CS position. Turn on **Machine CS editing mode**, then hold **Left Ctrl** key and drag you Machine CS into the correct position.

[![images/download/attachments/129940248/cs.gif](../assets/8948a38163753694d2061659ad9ff0fac376b8f64382e455eaf09bc944f8395c.gif)](../assets/8948a38163753694d2061659ad9ff0fac376b8f64382e455eaf09bc944f8395c.gif "Open full-size image")

## Tool and Workpiece position

Open the **Kinematic** tab. Hold down the **Left Ctrl** key and drag the **Tool** and **Workpiece** to the desired position.

[![images/download/attachments/129940248/worktool.gif](../assets/b3ae1989c71dcd80fe5ccbe4e3ea5da850d49dc17232b76521c76f5fae7d1c51.gif)](../assets/b3ae1989c71dcd80fe5ccbe4e3ea5da850d49dc17232b76521c76f5fae7d1c51.gif "Open full-size image")

MachineMaker will use the Mechanism name as the Project name by default.
