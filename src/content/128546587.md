# Main window

[![images/download/attachments/128546587/image2024-8-3_9-37-39.png](../assets/1e16ef4e15a6e05b70de8c0c9011c57874de81b36cbcaedd55ff90da5faf5c06.png)](../assets/1e16ef4e15a6e05b70de8c0c9011c57874de81b36cbcaedd55ff90da5faf5c06.png "Open full-size image")

Main window contains following areas:

1. Toolbar
2. Add mechanism button
3. Assembly tree
4. View controls
5. Transformation panel
6. Interactive View CS
7. Version info
8. AI Assistant
9. Interface help

Select any mechanism to show the **Transformation Panel**. Use the transformation panel to change the object's position.

It is possible to change the selected mechanism name and save it to the local Mechanisms Library using the **Save to library** button. The **Transformation panel** has 3 main functions:

1. Flip mechanism
2. Reset velues
