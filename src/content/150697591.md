# The navigation for robot movement in space

![Cell state panel with Joint, Frame, and Direct movement modes](../assets/0d9ddcbf89e019ff0385edf435e68cfe9cf4fbe6f54aee829f88796cd2c81f04.png)

**Application Area:**

Allows moving the robot in space in various ways.

## Joint Mode.

Allows moving the robot by controlling individual axes.

## Frame.

Frame mode provides three submodes for positioning the robot: **TCP**, **Base**, and **Point**.

**TCP.** Moves the robot relative to the Tool Center Point (TCP) coordinate system.

**Base.** Moves the robot relative to the robot base coordinate system.

**Point.** Moves the robot to a point selected in the graphics window. Click a point within the robot’s reachable workspace to move the robot to that point.

![Frame mode with the Point submode selected and a target point on the workpiece](../assets/94c7555d63b637bef8274c25ca998d4554c82a27e46e78a0f7517a27de93463b.png)

## Direct Mode.

Operates only when the robot is connected in real‑time mode. The robot can be moved either via remote control or manually.

## Precision mode

Сan be enabled for all operating modes. This reduces the movement step to prevent the robot from colliding with obstacles. ![The navigation for robot movement in space](../assets/0dd7a07bbcbc6dc53390e962ed67e6ee002c84dc3cf817d5f6992f32680d0d86.png)

**The movement step is set at the bottom as a slider.**
