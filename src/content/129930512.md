# Creating a project

## Starting MachineMaker

MachineMaker can be started directly from the CAM system utilities menu

![Creating a project](../assets/cdbbaff073af9d40f88252e273602bfebf53e0d170bfe547aa3fab081602d0d7.png)

## Creating a project

MachineMaker automatically creates a new project at startup. It is possible to create a new project any time using **Menu - File - New**

![Creating a project](../assets/a9ae258a70c6b54f49b0805e1e6fe874092cb50cb22b03a3574277cf5d8df6b4.png)
