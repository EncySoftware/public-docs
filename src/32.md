# Mechanism Simulation and Validation

Select *Simulation* tab to validate the mechanism's kinematics. Use the trackbar to change the axis coordinates or enter values in the input box manually.

[![Simulation](assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png)](assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png "Open full-size image") Click ***Demo***button to check all nodes.

[![SimulationStanok](assets/3edf158d8ff12af8c5e03a6142a622caf2c42bd31872401cca1e7e7e6cb8c294.gif)](assets/3edf158d8ff12af8c5e03a6142a622caf2c42bd31872401cca1e7e7e6cb8c294.gif "Open full-size image")

If something looks wrong in the simulation, please check the  "Building a kinematic scheme".

If you see nodes collisions, please check the "Grouping elements into nodes".

Use ![image2021-5-5_17-21-2](assets/e99feedf4a3d658647f9663d059f14b2c559fa5af79b297e31a8cd76940825e9.png) button on the "Toolbar" to validate whole assembly.
