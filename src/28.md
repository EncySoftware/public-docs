# Chuck connector

Once you have built the machine, the next step is to add the Chuck connector.

When editing the model, use only rotary axis and jaw joints.

[![image2024-4-24_13-26-44](assets/f2097d831148d57237d38859440a99ddd3d63c71fe83f099cdaa834954a1b904.png)](assets/f2097d831148d57237d38859440a99ddd3d63c71fe83f099cdaa834954a1b904.png "Open full-size image")

Since the Rotary axis is initially already set correctly, only the cam limits and the coordinates at which they will move should be edited.

[![image2024-4-24_13-46-24](assets/e54f2609d288782503f2efd330942d8ca5d6bc4a492af4378cdd6eb631739440.png)](assets/e54f2609d288782503f2efd330942d8ca5d6bc4a492af4378cdd6eb631739440.png "Open full-size image")

The next step is to set the home position of the jaws, test that the mechanism works correctly in the simulation and apply.
