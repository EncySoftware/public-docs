# Toolbar architecture

The Add-in consists of two parts — the Translator and the Toolbar — which interact with three external participants: the Add-in Wizard, the CAD system, and the CAM system. This section describes their composition and their operating scenarios.

- **[Component description](components.md)** — which parts the Add-in consists of, which files are included in the distribution, and what each component is responsible for.
- **[Interaction scenarios](scenarios.md)** — how the components interact with each other: installing and uninstalling the Add-in, as well as the two paths for transferring geometry into the CAM system.
