# Forming of the toolpath in geometric axes

**INCT_GeomCLData** - a CAM system interface that implements the commands of forming the tool path in geometric axes.

**Description of the interface methods:**

<table>
<thead>
<tr><th>Method</th><th>Method description</th><th>Description of use</th></tr>
</thead>
<tbody>
<tr><td><strong>SetSystemUnits</strong></td><td><p>The method sets the project units.</p><p>Input parameter: <strong>Units</strong> (<strong>TNCSystemMeasure</strong>):</p><p><strong>smMetrics</strong> - metric;<br><strong>smImperial</strong> - inch.</p></td><td>To interpret commands like G20, G21 in ISO code.</td></tr>
<tr><td><strong>SetFeedrateUnits</strong></td><td><p>The method sets the feed units.</p><p>Input parameter: <strong>Units</strong> (<strong>TNCFeedrateMeasure</strong>):</p><p><strong>fmMMPerMinute</strong> - mm per minute;<br><strong>fmInchPerMinute</strong> - inches per minute.</p></td><td>To interpret commands like G700, G710 for the Heidenhain controller.</td></tr>
<tr><td><strong>GetSystemUnits</strong></td><td>The function returns the project units (<strong>TNCSystemMeasure</strong>).</td><td></td></tr>
<tr><td><strong>GetFeedrateUnits</strong></td><td>The function returns the current feed units (<strong>TNCFeedrateMeasure</strong>).</td><td></td></tr>
<tr><td><strong>OutStandardFeed</strong></td><td><p>The method adds to the tool path a command that changes the feed to a standard one.</p><p>Input parameter: <strong>Feed</strong> (<strong>TNCFeedType</strong>) - feed type:</p><p><strong>ffWorking</strong> - working;<br><strong>ffRapid</strong> - rapid;<br><strong>ffFirst</strong> - first pass;<br><strong>ffEngage</strong> - engage;<br><strong>ffRetract</strong> - retract;<br><strong>ffPlunge</strong> - plunge;<br><strong>ffFinish</strong> - finishing pass;<br><strong>ffNext</strong> - transition;<br><strong>ffReturn</strong> - return;<br><strong>ffApproach</strong> - approach;<br><strong>ffRapid5D</strong> - rapid along the safe surface with axis limit control;<br><strong>ffTransitionOnSafe</strong> - transition along the safe surface;<br><strong>ffApproachFromSafe</strong> - approach from the safe surface;<br><strong>ffReturnToSafe</strong> - return to the safe surface;<br><strong>ffLongNext</strong> - long transition;<br><strong>ffThreadPitch</strong> - equal to the thread pitch.</p><p>The feed value of each type is set on the 'Feeds' tab of the operation in the CAM system.</p></td><td>To interpret commands like G00 (Rapid) / G01 (Working) in ISO code.</td></tr>
<tr><td><strong>OutFeed</strong></td><td><p>The method adds to the tool path a feed change command with the specified type and value.</p><p>Input parameters: <strong>Feed</strong> (<strong>TNCFeedType</strong>) - feed type (see <strong>OutStandardFeed</strong>); <strong>Value</strong> (real number) - feed value; <strong>MPM</strong> (boolean) - feed units flag: True - mm/min, False - mm/rev.</p></td><td>To interpret commands like F in ISO code.</td></tr>
<tr><td><strong>SetCurrentPlane</strong></td><td><p>The method adds to the tool path a command that changes the current plane to the specified one.</p><p>Input parameter: <strong>Plane</strong> (<strong>TNCPlaneType</strong>) - plane type:</p><p><strong>ptXY</strong> - XY plane;<br><strong>ptYZ</strong> - YZ plane;<br><strong>ptZX</strong> - ZX plane.</p></td><td>To interpret commands like G17-G19 in ISO code.</td></tr>
<tr><td><strong>AddSpindleSpeedOnRPM</strong></td><td><p>The method adds to the tool path a command that turns on the active spindle with the specified speed in revolutions per minute. If the spindle is already on, its speed is changed to the specified one.</p><p>Input parameters: <strong>RPM</strong> (real number) - spindle speed in revolutions per minute; <strong>Range</strong> (integer) - spindle speed range number; <strong>Direction</strong> (boolean) - rotation direction (True - clockwise CW, False - counterclockwise CCW).</p></td><td>To interpret commands like S in ISO code.</td></tr>
<tr><td><strong>AddSpindleSpeedOnCSS</strong></td><td><p>The method adds to the tool path a command that turns on the active spindle with constant cutting speed. If the spindle is already on, its mode and speed are changed to the specified ones.</p><p>Input parameters: <strong>CSS</strong> (real number) - constant cutting speed; <strong>MaxRPM</strong> (real number) - maximum spindle speed; <strong>Range</strong> (integer) - spindle speed range number; <strong>Direction</strong> (boolean) - rotation direction (True - clockwise CW, False - counterclockwise CCW).</p></td><td>To interpret commands like G96 for the Sinumerik controller.</td></tr>
<tr><td><strong>AddSpindleOff</strong></td><td><p>The method adds to the tool path a command that turns off the active spindle.</p><p>No input and output parameters.</p></td><td>To interpret commands like M05 in ISO code.</td></tr>
<tr><td><strong>AddSpindleOrient</strong></td><td><p>The method adds to the tool path an oriented stop command of the active spindle.</p><p>Input parameter: <strong>OrientationAngle</strong> (real number) - spindle rotation angle.</p></td><td></td></tr>
<tr><td><strong>AddOpStop</strong></td><td><p>The method adds to the tool path an optional stop command of the NC program. When the optional stop block is reached, the program execution is interrupted only if the corresponding mode is turned on in the CNC controller. If this mode is off, the program execution is not interrupted.</p><p>No input and output parameters.</p></td><td>To interpret commands like M01 in ISO code.</td></tr>
<tr><td><strong>AddCoolant</strong></td><td><p>The method adds to the tool path a command that turns the machine coolant systems on or off.</p><p>Input parameters: <strong>OnOff</strong> (boolean) - True - on, False - off; <strong>PipeNumber</strong> (integer) - number of the coolant pipe (1 - flood, 2 - mist, 3 - through the tool).</p></td><td>To interpret commands like M08/M09 in ISO code.</td></tr>
<tr><td><strong>AddDelay</strong></td><td><p>The method adds to the tool path a command that pauses the program execution for the specified time.</p><p>Input parameter: <strong>Value</strong> (real number) - dwell time in seconds.</p></td><td>To interpret commands like G04 in ISO code.</td></tr>
<tr><td><strong>AddLengthCompensation</strong></td><td><p>The method adds to the tool path a tool length compensation command with the specified parameters.</p><p>Input parameters: <strong>Mode</strong> (<strong>TNCLengthCompensationMode</strong>) - mode:</p><p><strong>lcOff</strong> - turn off the tool length compensation; <strong>lcOn</strong> - turn on the positive tool length compensation; <strong>lcOnNegative</strong> - turn on the negative tool length compensation.<br><strong>OffsetNumber</strong> (real number) - length offset number.</p></td><td>To interpret commands like G43, G44, G49, H in ISO code.</td></tr>
<tr><td><strong>AddLengthCompensationValue</strong></td><td><p>The method adds to the tool path a tool length compensation command with the specified parameters.</p><p>Input parameters: <strong>Mode</strong>, <strong>OffsetNumber</strong> (see <strong>AddLengthCompensation</strong>); <strong>Value</strong> (real number) - tool length offset value.</p><p><strong>Attention!</strong> In the current version the function works like <strong>AddLengthCompensation</strong>, without the possibility to set the value.</p></td><td></td></tr>
<tr><td><strong>AddLengthCompensationWithSpecifiedAxis</strong></td><td><p>The method adds to the tool path a tool length compensation command with the specified parameters.</p><p>Input parameters: <strong>Mode</strong>, <strong>OffsetNumber</strong> (see <strong>AddLengthCompensation</strong>); <strong>SpecifiedAxis</strong> (integer) - number of the axis along which the length compensation is made.</p><p><strong>Attention!</strong> In the current version the function works like <strong>AddLengthCompensation</strong>, without the possibility to select the axis.</p></td><td>To interpret commands like G43 (together with G17-G19) in ISO code.</td></tr>
<tr><td><strong>AddRadiusCompensation</strong></td><td><p>The method adds to the tool path a tool radius compensation command with the specified parameters.</p><p>Input parameters: <strong>Mode</strong> (<strong>TNCRadiusCompensationMode</strong>) - mode:</p><p><strong>rcOff</strong> - turn off the tool radius compensation; <strong>rcLeft</strong> - turn on the tool radius compensation on the left; <strong>rcRight</strong> - turn on the tool radius compensation on the right.<br><strong>OffsetNumber</strong> (real number) - offset number.</p></td><td>To interpret commands like G41, G42, D in ISO code.</td></tr>
<tr><td><strong>AddRadiusCompensationValue</strong></td><td><p>The method adds to the tool path a tool radius compensation command with the specified parameters.</p><p>Input parameters: <strong>Mode</strong>, <strong>OffsetNumber</strong> (see <strong>AddRadiusCompensation</strong>); <strong>Value</strong>, <strong>Value2</strong> (real number) - tool radius offset value.</p><p><strong>Attention!</strong> In the current version the function works like <strong>AddRadiusCompensation</strong>, without the possibility to set the value.</p></td><td></td></tr>
<tr><td><strong>CutTo3d</strong></td><td><p>The method adds to the tool path a command of linear tool movement to the specified point.</p><p>Input parameter: <strong>P</strong> (<strong>TNC3DPoint</strong>) - coordinates of the point.</p></td><td rowspan="3">To interpret commands like G00/G01 X Y Z A B C in ISO code.</td></tr>
<tr><td><strong>CutTo5d</strong></td><td><p>The method adds to the tool path a command of linear tool movement to the specified point with the specified tool direction.</p><p>Input parameters: <strong>P</strong> (<strong>TNC3DPoint</strong>) - coordinates of the point; <strong>N</strong> (<strong>TNC3DPoint</strong>) - tool normal vector in the part coordinate system.</p></td></tr>
<tr><td><strong>CutTo6d</strong></td><td><p>The method adds to the tool path a command of linear tool movement to the specified position with the specified tool orientation.</p><p>Input parameter: <strong>P</strong> (<strong>TNC3DMatrix</strong>) - tool position and orientation in the part coordinate system.</p><p><strong>TNC3DMatrix</strong> - homogeneous 4×4 matrix with the fields <strong>vX, A, vY, B, vZ, C, vT, D</strong>: <strong>vX</strong>, <strong>vY</strong>, <strong>vZ</strong> (<strong>TNC3DPoint</strong>) - directions of the tool coordinate system axes (<strong>vZ</strong> - tool axis); <strong>vT</strong> (<strong>TNC3DPoint</strong>) - tool position (X, Y, Z); <strong>A</strong>, <strong>B</strong>, <strong>C</strong> (real number) - 0; <strong>D</strong> (real number) - 1.</p></td></tr>
<tr><td><strong>ArcTo2d</strong></td><td><p>The method adds to the tool path a command of tool movement along a circular arc with the specified parameters.</p><p>Input parameters: <strong>Pe</strong> (<strong>TNC3DPoint</strong>) - arc end point (X, Y, Z); <strong>Pc</strong> (<strong>TNC3DPoint</strong>) - arc center (X, Y, Z); <strong>Plane</strong> (<strong>TNCPlaneType</strong>, see <strong>SetCurrentPlane</strong>) - arc plane; <strong>R</strong> (real number) - arc radius (greater than zero for counterclockwise rotation, less than zero for clockwise rotation); <strong>CanBeFull</strong> (boolean) - the arc can be a full circle.</p></td><td rowspan="4">To interpret commands like G02/G03 X Y Z I J K R in ISO code.</td></tr>
<tr><td><strong>ArcTo3d</strong></td><td><p>The method adds to the tool path a command of tool movement along a circular arc with the specified parameters.</p><p>Input parameters: <strong>Pe</strong> (<strong>TNC3DPoint</strong>) - arc end point (X, Y, Z); <strong>Pc</strong> (<strong>TNC3DPoint</strong>) - arc center (X, Y, Z); <strong>Nc</strong> (<strong>TNC3DPoint</strong>) - normal vector of the arc plane; <strong>R</strong> (real number) - arc radius (greater than zero for counterclockwise rotation, less than zero for clockwise rotation); <strong>CanBeFull</strong> (boolean) - the arc can be a full circle.</p></td></tr>
<tr><td><strong>ArcTo5d</strong></td><td><p>The method adds to the tool path a command of tool movement along a circular arc with the specified parameters.</p><p>Input parameters: <strong>Pe</strong> (<strong>TNC3DPoint</strong>) - arc end point (X, Y, Z); <strong>Ne</strong> (<strong>TNC3DPoint</strong>) - tool normal vector at the end point in the part coordinate system; <strong>Pc</strong> (<strong>TNC3DPoint</strong>) - arc center (X, Y, Z); <strong>Nc</strong> (<strong>TNC3DPoint</strong>) - normal vector of the arc plane; <strong>R</strong> (real number) - arc radius (greater than zero for counterclockwise rotation, less than zero for clockwise rotation); <strong>CanBeFull</strong> (boolean) - the arc can be a full circle.</p></td></tr>
<tr><td><strong>ArcTo6d</strong></td><td><p>The method adds to the tool path a command of tool movement along a circular arc with the specified parameters.</p><p>Input parameters: <strong>Pe</strong> (<strong>TNC3DMatrix</strong>) - tool position and orientation at the arc end point in the part coordinate system (for the type, see <strong>CutTo6d</strong>); <strong>Pc</strong> (<strong>TNC3DPoint</strong>) - arc center (X, Y, Z); <strong>Nc</strong> (<strong>TNC3DPoint</strong>) - normal vector of the arc plane; <strong>R</strong> (real number) - arc radius (greater than zero for counterclockwise rotation, less than zero for clockwise rotation); <strong>CanBeFull</strong> (boolean) - the arc can be a full circle.</p></td></tr>
<tr><td><strong>GetLastPosition</strong></td><td>The function returns the coordinates of the current tool position and the tool normal vector relative to the part coordinate system.</td><td>Used to get the current tool position.</td></tr>
<tr><td><strong>WasMovement</strong></td><td><p>The function returns the flag of whether the first movement has been made (boolean). True - the first movement has already been made, the current tool position can be obtained with <strong>GetLastPosition</strong>. False - no movements have been made yet.</p><p>During simulation by the NC program (including ENCY Tuner) the function always returns True.</p></td><td>See <strong>GetLastPosition</strong>.</td></tr>
<tr><td><strong>CreateLinearMotionFormer</strong></td><td><p>The function returns the interface of the linear movement generator (<strong><a href="../../toolpath-construction/linear-movements/linear-movements.md">INCT_GeomLinearMotionFormer</a></strong>). Using the generator in the interpreter simplifies forming a linear tool path. Working with the generator is described in the article <a href="../../toolpath-construction/linear-movements/linear-movements.md">Linear movements</a>.</p><p>No input parameters.</p></td><td>To interpret commands like G00/G01 X Y Z A B C in ISO code.</td></tr>
<tr><td><strong>CreateCircularMotionFormer</strong></td><td><p>The function returns the interface of the arc movement generator (<strong><a href="../../toolpath-construction/circular-movements/circular-movements.md">INCT_CircularMotionFormer</a></strong>). Using the generator in the interpreter simplifies forming a tool path along an arc. Working with the generator is described in the article <a href="../../toolpath-construction/circular-movements/circular-movements.md">Circular movements</a>.</p><p>No input parameters.</p></td><td>To interpret commands like G02/G03 X Y Z I J K R in ISO code.</td></tr>
<tr><td><strong>CreateDrillingCycleFormer</strong></td><td><p>Depending on the specified parameter, the function returns the interface of the generator of one of the drilling cycles. Working with the generators is described in the articles <a href="../../toolpath-construction/drilling-cycle/drilling-cycle.md">Drilling cycle</a>, <a href="../../toolpath-construction/drilling-cycle-with-shift/drilling-cycle-with-shift.md">Drilling cycle with shift</a>, <a href="../../toolpath-construction/drilling-cycle-with-chip-breaking/drilling-cycle-with-chip-breaking.md">Drilling cycle with chip breaking</a>.</p><p>Input parameter: <strong>CycleType</strong> (<strong>TNCDrillingCycleType</strong>) - cycle type.</p><p><strong>dctSimple</strong> - simple drilling cycle; the returned generator supports only one interface: <strong><a href="../../toolpath-construction/drilling-cycle/drilling-cycle.md">INCT_DrillingCycleFormer</a></strong>.<br><strong>dctWithShift</strong> - drilling cycle with shift; the returned generator supports two interfaces: <strong><a href="../../toolpath-construction/drilling-cycle/drilling-cycle.md">INCT_DrillingCycleFormer</a>, <a href="../../toolpath-construction/drilling-cycle-with-shift/drilling-cycle-with-shift.md">INCT_DrillingCycleWithShiftFormer</a></strong>.<br><strong>dctPeck</strong> - drilling cycle with chip breaking; the returned generator supports two interfaces: <strong><a href="../../toolpath-construction/drilling-cycle/drilling-cycle.md">INCT_DrillingCycleFormer</a>, <a href="../../toolpath-construction/drilling-cycle-with-chip-breaking/drilling-cycle-with-chip-breaking.md">INCT_PeckDrillingCycleFormer</a></strong>.</p></td><td>To interpret commands like G73, G74, G76, G80-89 for the Fanuc controller.</td></tr>
<tr><td><strong>CreateLatheCycleFormer</strong></td><td><p>Depending on the specified parameter, the function returns the interface of the generator of one of the turning cycles. Working with the generators is described in the articles <a href="../../toolpath-construction/turning-cycle-grooving/turning-cycle-grooving.md">Turning cycle grooving</a>, <a href="../../toolpath-construction/turning-cycle-threading/turning-cycle-threading.md">Turning cycle threading</a>, <a href="../../toolpath-construction/turning-machining-cycle/turning-machining-cycle.md">Turning machining cycle</a>.</p><p>Input parameter: <strong>CycleType</strong> (<strong>TNCLatheCycleType</strong>) - cycle type.</p><p><strong>lctGrooving</strong> - turning grooving cycle; the returned generator supports one interface: <strong><a href="../../toolpath-construction/turning-cycle-grooving/turning-cycle-grooving.md">INCT_LatheGroovingCycleFormer</a></strong>.<br><strong>lctThreadCutting</strong> - turning thread cutting cycle; the returned generator supports one interface: <strong><a href="../../toolpath-construction/turning-cycle-threading/turning-cycle-threading.md">INCT_LatheThreadCuttingCycleFormer</a></strong>.<br><strong>lctStockRemoval</strong> - turning cycle of rough and finish contour turning; the returned generator supports one interface: <strong><a href="../../toolpath-construction/turning-machining-cycle/turning-machining-cycle.md">INCT_LatheStockRemovalCycleFormer</a></strong>.</p></td><td>To interpret commands like CYCLE93, CYCLE95, CYCLE97 for the Sinumerik controller.</td></tr>
</tbody>
