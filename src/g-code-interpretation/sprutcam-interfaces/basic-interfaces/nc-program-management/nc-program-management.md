# NC program management

**INCT_ProgramManager** - an interface for working with the NC program text. The interface provides work with the NC program text and with the order in which the NC program texts are passed to the interpreter.

**Description of the interface methods:**

<table>
<thead>
<tr><th>Method</th><th>Method description</th><th>Description of use</th></tr>
</thead>
<tbody>
<tr><td><strong>Get_Count</strong></td><td><p>The function returns the number of NC program texts (files*) generated by the postprocessor for the current operation.</p><p>No input parameters.</p></td><td rowspan="3"><p>If the postprocessor generates several NC program texts (files*), it may be necessary to change the order in which the texts are passed to the interpreter.</p><p>To find out whether there are several NC program texts, use the <strong>Get_Count</strong> function.</p><p>In some cases the postprocessor can generate files* with unique names that contain auxiliary data (no NC program text) and must not be interpreted. Or, on the contrary, it can generate a header file from which the other NC program texts are called. The <strong>Get_Name</strong> function is intended for identifying such files by name.</p><p>If the order of processing the NC program texts generated by the postprocessor must be changed for the interpretation, use the function of adding an NC program text to the interpretation list (<strong>AddToOrderList</strong>). The NC program texts are passed to the interpreter in the order set in the list, from the first added to the last.</p></td></tr>
<tr><td><strong>Get_Name</strong></td><td><p>The function returns the name of the file* with the NC program text (string) by the index of the NC program text (file*) passed in the input parameter.</p><p>Input parameters: <strong>Index</strong> (integer) - number of the NC program text (file*) generated by the postprocessor for the current operation. Value from 0 to <strong>Get_Count</strong> - 1.</p></td></tr>
<tr><td><strong>AddToOrderList</strong></td><td><p>The method adds the NC program text (file*) with the specified index to the interpretation list. The NC program texts are passed to the interpreter in the order set in this list, from the first added to the last. NC program texts not added to the list are not passed to the interpreter. If no NC program text has been added to the list, all files are passed to the interpreter in the order generated by the postprocessor for the current operation.</p><p>Input parameters: <strong>Index</strong> (integer) - number of the NC program text (file*) generated by the postprocessor for the current operation. Value from 0 to <strong>Get_Count</strong> - 1.</p></td></tr>
<tr><td><strong>GetPartByIndex</strong></td><td><p>The function returns the NC program text (<strong>INCT_Program</strong> interface) by the index of the NC program text (file*) passed in the input parameter.</p><p>Input parameters: <strong>Index</strong> (integer) - number of the NC program text (file*) generated by the postprocessor for the current operation. Value from 0 to <strong>Get_Count</strong> - 1.</p></td><td>To set the order in which the interpreter processes the NC program texts (files*), it may be necessary to analyze the contents of one or several NC program texts of the current operation. Calling the function with the text number returns the <strong>INCT_Program</strong> interface; read the lines of the NC program text with its functions.</td></tr>
<tr><td><strong>GetPartByLabels</strong></td><td><p>The function returns the NC program text (<strong>INCT_Program</strong> interface) by the labels passed in the input parameters. The search is made from the beginning of the NC program text.</p><p>Input parameters: <strong>StartLabel</strong> (string), <strong>StopLabel</strong> (string) - start and end labels of the NC program text.</p></td><td>If the generator built into the kernel (<a href="../../toolpath-construction/turning-machining-cycle/turning-machining-cycle.md">Turning machining cycle</a>) is not enough to form the tool path of a turning contour cycle (like CYCLE95 for the Sinumerik controller), the NC program text with the cycle path can be obtained for its own analysis. The described function is intended for this.</td></tr>
</tbody>
</table>

**\*** - during postprocessing for interpretation, files with NC program texts are not created on disk. The NC program texts exist only in memory. File names and numbering are kept because of the existing technology and to set the order of processing the NC program texts.

**INCT_GetPartByUser** - an interface for working with the NC program text.

**Description of the interface methods:**

<table>
<thead>
<tr><th>Method</th><th>Method description</th><th>Description of use</th></tr>
</thead>
<tbody>
<tr><td><strong>GetPartByUser</strong></td><td><p>The function returns the <strong>INCT_Program</strong> interface for working with the NC program.<br>Input parameters:</p><p>The <strong>TNCGetPartOrigin</strong> type:</p><p><strong>gpoFromCurPos</strong> - search from the current position of the NC program;</p><p><strong>gpoEntireScope</strong> - search from the beginning of the NC program.</p></td><td rowspan="3"><p>The function allows determining the start and end of a subprogram by any specified labels.<br>1) Get the <strong>INCT_Program</strong> interface with <strong>GetPartByUser</strong>.</p><p>2) For example, the values of the subprogram start and end labels can be passed in <strong>INCT_InterpreterState</strong>, or registers can be used for this.</p><p>3) After the <strong>DoSubprogram</strong> procedure of the <strong>INCT_Kernel2</strong> interface is started, the subprogram is searched. If <strong>INCT_InterpreterState</strong> has been used, the previously saved labels can be obtained, or the required subprogram start label can be found in the <strong>TransLine</strong> method and <strong>IsStart</strong> called. The <strong>IsEnd</strong> procedure is used in the same way.</p></td></tr>
<tr><td><strong>IsStart</strong></td><td>The procedure marks the start of the subprogram.</td></tr>
<tr><td><strong>IsEnd</strong></td><td>The procedure marks the end of the subprogram.</td></tr>
</tbody>
</table>

**INCT_Program** - an interface for getting the NC program text. The interface provides work with the NC program text returned by some **INCT_ProgramManager** functions.

**Description of the interface methods:**

<table>
<thead>
<tr><th>Method</th><th>Method description</th><th>Description of use</th></tr>
</thead>
<tbody>
<tr><td><strong>EndOfFile</strong></td><td>The function returns the end-of-lines flag. True - the NC program text has ended. False - the NC program text has not been read completely.</td><td rowspan="2">After the interface is obtained, each next call of <strong>GetNextLine</strong> returns the next line of the NC program text, from the first to the last line. After the last line is obtained, <strong>EndOfFile</strong> returns <strong>True</strong>.</td></tr>
<tr><td><strong>GetNextLine</strong></td><td>The function returns the next line of the NC program.</td></tr>
</tbody>
</table>
