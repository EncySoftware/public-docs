# Protokoll der Interaktion mit dem Interpreter

Zum Protokollieren der Interpretation des NC-Programmtexts, einschließlich der Interaktion mit dem Interpreter, dient ein eigenes Protokoll. Das Protokoll wird im Formular der Systemeinstellungen gesteuert: Registerkarte &lt;[Zusätzlich](https://docs.encycam.com/ENCY/3/en/23.html)&gt;, Option &lt;**Protokoll der Interaktion mit dem Interpreter führen**&gt;.

Ist die Option eingeschaltet, wird bei jeder Berechnung im Modus „[Simulation anhand des NC-Programms](https://docs.encycam.com/ENCY/3/en/10291.html)“ sowie bei „[Operationen auf Basis des NC-Programms](https://docs.encycam.com/ENCY/3/en/10379.html)“ eine eigene Datei mit dem Protokoll der Interpretation des NC-Programms erzeugt.

Das Protokoll ist für das [Erstellen eines eigenen Interpreters](../../../index.md) gedacht.
