# Log interaction with the interpreter

A separate log is intended for recording the process of interpreting the NC program text, including the interaction with the interpreter. The log is managed on the system settings form, &lt; **[Additional](https://docs.encycam.com/ENCY/3/en/23.html)** > tab, &lt;**Use log interaction with the interpreter**> option.

If the logging option is enabled, then for each calculation in the “[G-code based simulation](https://docs.encycam.com/ENCY/3/en/10291.html)” mode, as well as of the “[G-code based operations](https://docs.encycam.com/ENCY/3/en/10379.html)”, a separate file with the log of the NC program text interpretation is generated.

The log is intended for [creating your own interpreters](../../../index.md).
