# Entry points in CAMAPI

CAMAPI includes various entry points. An entry point is a location within the system where extensions created by third-party developers can be integrated. These points allow the functionality of the system to be extended by adding new capabilities and enhancing existing ones. This opens the door for the creation of a wide range of extensions that can meet specific user needs. Thus, CAMAPI fosters the development of an ecosystem of applications and tools, supporting innovation and flexibility in usage.

Available entry points:
- [Utilitiy in main form](utility.md);
- [Executor for utility in main form](utility_runner.md);
- [New item to the operation's context menu](operation_popup.md).
