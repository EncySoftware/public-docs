# System extension Extension.Util.Common.Exe

The extension is designed for running EXE files. It launches the exe file in a separate process to avoid interrupting the operation of ENCY. Parameters can be passed if they are specified in the utility settings..

- Entry point - [utility_runner](../EntryPoints/utility_runner.md);
- Implemented interface - [IExtensionUtilityRunner](../../api/CAMAPI.Application.IExtensionUtilityRunner.yml).
