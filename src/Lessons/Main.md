# Tutorial lessons

The lessons are designed to simplify familiarization with CAMAPI - they are full-fledged in "how-to" style:
- The goal of each such lesson is to introduce new functionality;
- The lessons are structured to gradually increase in complexity, with each subsequent lesson building on the knowledge from the previous ones;
- Lessons can be completed in any order.

List of lessons:
- [Lesson 1 - general introduction to the extension ideology using the example of a C# project](Lesson1.md);
- [Lesson 2 - connecting the SDK to a Delphi project using the build system](Lesson2.md);
- [Lesson 3 - connecting the SDK to a C++ project using the build system](Lesson3.md);
- [Lesson 4 - demonstration of methods for unloading an extension during main application is running](Lesson4.md);
- [Lesson 5 - сreating a custom operation](Lesson5.md);
- [Lesson 6 - creating a C# application to interact with geometry in main application](Lesson6.md);
- [Lesson 7 - creating a C# application to connect to ENCY for managing it](Lesson7.md);
- [Lesson 8 - creating a C# extension to integrate with a PLM system](Lesson8.md).
