# Robots

This section describes how to create and configure robot cells in MachineMaker. Select the **Robot cell** context using **Application Mode Selector** (see [Introduction to MachineMaker](../common/128546572.md)).

The steps common to all mechanisms are described in [Interface](../common/128546586.md) and [Getting Started](../common/129940180.md): creating a project, adding a mechanism, preparing and importing 3D objects, grouping elements into nodes, coloring, simulation, assemblies and the mechanisms library.
