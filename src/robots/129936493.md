# Collision

If you are using inaccurate 3D models, CAM system can detect false-positive collisions between nodes. You can add these nodes to the ignore-list to prevent CAM system from detecting false-positive collisions.

Click ![Collision](../assets/89d0890fe866acfe3d9e802391d3b6ea8ebd0bb1198b4f8ea935919e65bb25b9.png) button to open the parameters panel. Then go to the **Collisions** tab.

![Collision](../assets/ba3f0bffcc5d1efb047195cdebce967e1dffe5b2bc6569eee535b0ebedbfd3dd.png)

Select first and second nodes and click **Add collisions** button. Use **with children** toggle to add node's children to the ignore-list. Use ![Collision](../assets/5d07911f0d929516a2b137d14f233704f14ef0edeea20c05f3e1941e89c4e373.png) button to delete a previously added collision from the ignore list.

![Collision](../assets/4f26a3a1647524fa2e37e8f484d473efdb90200754c84753e9c85c70e73b8a85.png)

In the custom collision tab, you can manually compute collisions using user-defined parameters.
This section allows you to specify the mesh resolution for each mechanism node used by the collision-detection algorithm.

![Collision](../assets/909e25df753e6234cc7dea39d459bca13d197c41f1fb51378c47fe7be252c2a5.png)

If you click **“Prepare collision meshes data”**, the application will calculate the number of mechanism positions required for collision detection.

![Collision](../assets/2883422db2cff2af757182d2d7250c01773dc7399a1263df71bc014ffc907aaa.webp)

After calculating the number of mechanism positions, you will be able to sort them by nodes and visually inspect collisions on the mechanisms.

![Collision](../assets/0815920435eeec68ea908e4a18eaa46cf92bcbd11ee3ee7e66cc4259ad24dd46.png)

CAM system always ignores collisions between sibling nodes. So it is not necessary to add them to the ignore list.
