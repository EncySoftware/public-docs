# 충돌

부정확한 3D 모델을 사용하는 경우 CAM 시스템이 노드 간의 오탐 충돌을 감지할 수 있습니다. 이러한 노드를 무시 목록에 추가하면 CAM 시스템이 오탐 충돌을 감지하지 않도록 할 수 있습니다.

![충돌](../assets/89d0890fe866acfe3d9e802391d3b6ea8ebd0bb1198b4f8ea935919e65bb25b9.png) 버튼을 클릭하여 파라미터 패널을 엽니다. 그런 다음 **Collisions**(충돌) 탭으로 이동합니다.

![충돌](../assets/ba3f0bffcc5d1efb047195cdebce967e1dffe5b2bc6569eee535b0ebedbfd3dd.png)

첫 번째 노드와 두 번째 노드를 선택하고 **Add collisions**(충돌 추가) 버튼을 클릭합니다. 노드의 하위 노드도 무시 목록에 추가하려면 **with children**(하위 노드 포함) 토글을 사용합니다. 이전에 추가한 충돌을 무시 목록에서 삭제하려면 ![충돌](../assets/5d07911f0d929516a2b137d14f233704f14ef0edeea20c05f3e1941e89c4e373.png) 버튼을 사용합니다.

![충돌](../assets/4f26a3a1647524fa2e37e8f484d473efdb90200754c84753e9c85c70e73b8a85.png)

사용자 정의 충돌 탭에서는 사용자가 정의한 파라미터를 사용하여 충돌을 직접 계산할 수 있습니다.
이 섹션에서는 충돌 감지 알고리즘이 사용하는 각 메커니즘 노드의 메쉬 해상도를 지정할 수 있습니다.

![충돌](../assets/909e25df753e6234cc7dea39d459bca13d197c41f1fb51378c47fe7be252c2a5.png)

**“Prepare collision meshes data”**(충돌 메쉬 데이터 준비)를 클릭하면 애플리케이션이 충돌 감지에 필요한 메커니즘 위치의 수를 계산합니다.

![충돌](../assets/2883422db2cff2af757182d2d7250c01773dc7399a1263df71bc014ffc907aaa.webp)

메커니즘 위치의 수가 계산되면 위치를 노드별로 정렬하고 메커니즘의 충돌을 시각적으로 검사할 수 있습니다.

![충돌](../assets/0815920435eeec68ea908e4a18eaa46cf92bcbd11ee3ee7e66cc4259ad24dd46.png)

CAM 시스템은 형제 노드 간의 충돌을 항상 무시합니다. 따라서 형제 노드를 무시 목록에 추가할 필요는 없습니다.
