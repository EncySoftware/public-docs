# Tables and Positioners

MachineMaker allows you to create static tables, 1-axis positioners and 2-axes positioners.

![Tables and Positioners](../assets/b4e733266325eb8ff073adc4c6aa539ad8f495d8318fb8392d105c7cb91a8623.png)

## Tables

Table is a fixed (static) object which can hold a workpiece or any another object (including robots or another table).

It is possible to add any number of connectors to the table using ![Tables and Positioners](../assets/51f53e8a9fe9625306d20db300972bf55d9d9e27f22adecfd008416defd01c85.png) button in the **User Coordinate Systems** panel. Use ![Tables and Positioners](../assets/e91fe9f7075ccc44b54141afb72e58dd9fd2acb61f44aa92a6aea74ab6714eca.png) button to delete the connector. Use double click to rename the coordinate system.

Hold down **Left Control** key and use drag&drop to place the connector in the correct position; it is also possible to specify the connector's position by changing dimensions or the date in the Transformation Panel, for details see "Transformation panel". You can also select the type of added connector assembly equipment or workpiece.

MachineMaker will use connectors to connect mechanisms with each other when building **Assemblies**. All empty connectors will be converted into Workpiece holders for CAM system.

![Tables and Positioners](../assets/84e9c57e0a1b21cd6972b8921dd09913d75d74223624c218e52c77711bc9c3bd.png)

There is a big difference between Fixed Tables and Fixed Objects. A Fixed Object is a standalone static object, it is impossible to place a robot on a Fixed Object. So, Fixed Objects do not have any connectors. Use Fixed Objects option for robot controllers, standalone boxes located in the robot cell, fences and so on. Use Fixed Tables for tables holding robots and workpieces, floors and so on.

![Tables and Positioners](../assets/943c53401ebd1d955b3a097ced819b6410ce76a3c429b1090a85c877617a98db.png)

## 1-axis positioner

1-axis positioner has one rotary joint and an unlimited number of connectors. It is possible to add new connectors using ![Tables and Positioners](../assets/b5ae5dbfa35f290f2c5d0e85446a0019d1942de630cd24c89efa108f045b8443.png) button in the **User Coordinate Systems** panel.

![Tables and Positioners](../assets/dc8fd6d60d6e9f1590f7a86bf7d765e67e7739c21b97b94a132f9fd27836bf03.png)

## 2-axes positioner

2-axes positioner has 2 rotary joints and an unlimited number of connectors. It is possible to add new connectors using ![Tables and Positioners](../assets/b5ae5dbfa35f290f2c5d0e85446a0019d1942de630cd24c89efa108f045b8443.png) button in the **User Coordinate Systems** panel.

![Tables and Positioners](../assets/1a1e5df075f8da1b1a5e38aa3cb125ea58ec388ea010df4f76f791c6c373130d.png)
