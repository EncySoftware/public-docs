# Rails and Portals

MachineMaker allows you to add linear rails, 2-axes portals and 3-axes portals.

It is possible to add any number of connectors to the table using ![Rails and Portals](../assets/b5ae5dbfa35f290f2c5d0e85446a0019d1942de630cd24c89efa108f045b8443.png) button in the **User Coordinate Systems** panel. Use ![Rails and Portals](../assets/7002433966b4fab58d121f9be39c45b846d4e602d938d59bbe3e0ccfea33f83b.png) button to delete the connector. Use double click to rename the coordinate system.

MachineMaker will use connectors to connect mechanisms with each other when building "Assemblies".

![Rails and Portals](../assets/330f566ea5cfca3ca5807888319e0461d97c9652132964c54df1e918179d9018.webp)

Click on **Limits** to specify Min and Max values. MachineMaker will show minimal and maximal positions of the 3D model.

It is possible to change linear axis direction using transformation panel in the right bottom corner.

![Rails and Portals](../assets/b9ca391c9d8c2ca4efbb428813f27d03b4deaaceb8797ddcd886c6446ea7ca1f.webp)
