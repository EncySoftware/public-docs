# Simulationsparameter des Rohteils

Öffnen Sie die Simulationseinstellungen mit ![Simulationseinstellungen](assets/images/download/thumbnails/157867271/image2024-8-6_15-40-32.png) im [Simulationsfenster](352.md).

![images/download/attachments/157867271/image2024-8-6_15-40-45.png](assets/images/download/attachments/157867271/image2024-8-6_15-40-45.png)

Die Simulationsgenauigkeit wird über den Regler **Low–High** oder bei aktiviertem **Use absolute tolerance** als absoluter Wert festgelegt. Sie betrifft Werkzeug, Ausgangsrohteil und Werkzeugweg. Eine geringere Qualitätseinstellung beschleunigt die Simulation, verringert jedoch die Detailgenauigkeit. Standardmäßig werden die absoluten Toleranzen anhand der Modellabmessungen automatisch bestimmt. Für anspruchsvolle Fälle kann eine gemeinsame absolute Toleranz vorgegeben werden.

Die Einstellung kann während der Simulation geändert werden, um einzelne Bereiche genauer zu betrachten.

**One model for all copies** spart bei Projekten mit vielen Bauteilkopien Arbeitsspeicher und kann dadurch die Simulation beschleunigen.

![images/download/attachments/157867271/OneModelForAllCopies.png](assets/images/download/attachments/157867271/OneModelForAllCopies.png)

**Hinweise:**

- Auf weniger leistungsfähigen Computern wird eine besonders hohe Simulationsqualität nicht empfohlen.
- Nach Änderungen setzen Sie das Simulationsrohteil mit ![Rohteil zurücksetzen](assets/images/download/attachments/157867271/Sim_Reset_Workpiece.png) zurück.
