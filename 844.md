# Grupo

O grupo é destinado à sistematização de diferentes operações com parâmetros semelhantes. A criação de um grupo não resulta em nenhum cálculo de percurso da ferramenta, mas os parâmetros podem ser definidos para todas as operações do grupo.

O grupo de operações pode incluir operações de qualquer tipo, inclusive grupos de operações. Ou seja, usando grupos de operações, é possível formar uma lista de tarefas com estrutura semelhante a uma árvore. A finalidade e o comportamento do grupo de operações são semelhantes aos de uma pasta no sistema de arquivos do computador.

Se alguns parâmetros do grupo forem alterados, os parâmetros semelhantes de todas as operações incluídas também serão alterados (se a operação do grupo contiver esses parâmetros).

É conveniente usar esta operação ao usinar peças com várias operações de parâmetros semelhantes. Nesse caso, é possível reduzir o tempo de configuração dos parâmetros de operação (evitando a configuração repetida de parâmetros).
