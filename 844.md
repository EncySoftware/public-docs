# Operationsgruppe

Eine Gruppe fasst Operationen mit ähnlichen Parametern zusammen. Sie berechnet keinen eigenen Werkzeugweg, kann jedoch gemeinsame Parameter für ihre Operationen vorgeben.

Gruppen können beliebige Operationen und weitere Gruppen enthalten. Dadurch entsteht ein hierarchischer Operationsbaum, ähnlich der Ordnerstruktur eines Dateisystems.

Wird ein Gruppenparameter geändert, wird die Änderung auf die enthaltenen Operationen übertragen, sofern sie diesen Parameter unterstützen.

Bei mehreren Operationen mit gemeinsamen Einstellungen reduziert dies den Einrichtungsaufwand und vermeidet wiederholte Parametereingaben.
