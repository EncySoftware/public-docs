# Funktionsprofil

![images/download/attachments/157860327/image2024-8-8_17-23-1.png](assets/images/download/attachments/157860327/image2024-8-8_17-23-1.png)

Erstellt eine Kurve durch Punkte, deren Koordinaten mit benutzerdefinierten Ausdrücken berechnet werden.

![images/download/attachments/157860327/image2024-8-8_17-32-43.png](assets/images/download/attachments/157860327/image2024-8-8_17-32-43.png)

Zur Berechnung der Punkte werden Werte von **Argument minimum** bis **maximum** für **t** in die Ausdrücke für **X** und **Y** eingesetzt. Zusätzlich können Sie einen Einfügepunkt für die Kurve und eine Drehung um diesen Punkt festlegen.

Klicken Sie auf die Schaltfläche ![Kurve abschließen](assets/images/download/attachments/157860327/image2024-8-8_17-33-34.png) oder in das Grafikfenster, um die Definition der Kurve abzuschließen.

In den Ausdrücken werden die üblichen mathematischen Funktionen unterstützt:

- sin(t) – Sinus von **t**
- cos(t) – Kosinus von **t**
- tan(t) – Tangens von **t**
- cotan(t) – Kotangens von **t**
- arctan(t) – Arkustangens von **t**

Für trigonometrische Funktionen wird das Argument im Bogenmaß angegeben. **Pi** bezeichnet die Zahl **π**.

- exp(t) – **e** hoch **t**
- ln(t) – natürlicher Logarithmus von **t**
- sqrt – Quadratwurzel von **t**
