# Standard-Ansichten

![Symbolleiste der Standardansichten](assets/images/download/thumbnails/157858275/image2024-6-27_16-4-52.png)

Die Standard-Ansichtsleiste im Hauptfenster kann je nach Maschinentyp variieren, beispielsweise für Dreh- oder Fräsmaschinen. Wenn eine der Schaltflächen ausgewählt wird, wird die entsprechende Blickrichtung im Grafikfenster eingestellt. Wenn die Blickrichtung auf andere Weise geändert wird, wird die Auswahl der Schaltfläche automatisch aufgehoben.

Durch Anklicken der **mittleren Maustaste** (Mausrad) wird eine der nächstgelegenen Standardansichten eingestellt.
