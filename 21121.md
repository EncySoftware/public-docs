## Application area:

The operation lets you do surfacing along curves you've set up beforehand. You can prepare the curves using any tool — for example, a third‑party CAD program. Basically, the operation turns a bunch of curves into a path for the tool to follow. It also automatically sorts and divides the work area into regions. You can choose between layer‑by‑layer and spiral processing modes.

##### Sort by.

Allows to set printing order of layers and features.

**Layers**. Allows to print all features layer by layer.

![images/download/attachments/157866720/Sorting_layers.png](assets/images/download/attachments/157866720/Sorting_layers.png)

**Features**. Allows to print all features one by one.

![images/download/attachments/157866720/Sorting_Wells.png](assets/images/download/attachments/157866720/Sorting_Wells.png)

**Split by layers.** This parameter allows you to split your features into a desired number of layers. It is available only when the **Sort by** parameter is set to **Features** option.

**Allow reverse direction.** Changes the processing direction of a single curve.

**Start point.** Allows to set custom rules for deciding starting point on print layers.

**Do not change.** The starting point is selected automatically.

**Nearest.** Selects the nearest point to the instrument

**Manually.** The user selects the starting point interactively

**Optimize order. If disabled:** the curves are selected from the add list.

**If enabled:** the curves are selected by the shortest distance

</details>

### Installation:

The operation is supplied as the **DirectCladding operation extensions** extension. To install it:

1. On the **Home page**, open the **Extension Store** tab and go to the **Store** page.
2. Find **DirectCladding operation extensions** and click **Install**.
3. The operation appears in the **Additive** group of the new operation window. If it does not, restart the CAM system.

You can also install the extension from the web storefront [apps.encycam.com](https://apps.encycam.com/). [Details](162964210.md)
