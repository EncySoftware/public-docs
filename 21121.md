<a id="application-area"></a>

## Ambito di applicazione:

L'operazione consente di eseguire il riporto lungo curve predisposte in precedenza. Le curve possono essere preparate con qualsiasi strumento, ad esempio un programma CAD di terze parti. In sostanza, l'operazione trasforma un insieme di curve in un percorso che l'utensile deve seguire. Inoltre ordina e suddivide automaticamente l'area di lavoro in regioni. È possibile scegliere tra le modalità di lavorazione strato per strato e a spirale.

<a id="setup"></a>

### Configurazione:

La scheda <strong>Setup</strong> (configurazione) serve a configurare i parametri principali del progetto. Ciò può comprendere il posizionamento del pezzo sull'attrezzatura, il sistema di coordinate del pezzo e altro. [Dettagli](1022.md)

<a id="job-assignment"></a>

### Assegnazione del lavoro:

<strong>Curve</strong> (curva). Imposta il percorso utensile lungo la curva selezionata. [Dettagli](707.md).

<strong>Properties</strong> (proprietà). Visualizza le proprietà di un elemento. È possibile aggiungere il sovrametallo. Questo menu può essere richiamato anche facendo doppio clic su una voce dell'elenco.

<strong>Delete</strong> (elimina). Rimuove una voce dall'elenco

<a id="strategy"></a>

### Strategia:

<a id="printing-strategy"></a>

#### Strategia di deposizione.

La scelta della strategia influisce sulla disponibilità dei parametri nel gruppo <strong>Sorting</strong> (ordinamento).

<details>
<summary>Fare clic qui per espandere..</summary>

<strong>Planar</strong> (planare). Consente di utilizzare le opzioni di deposizione per strati

<strong>Helical</strong> (elicoidale). Consente di utilizzare le opzioni di deposizione a spirale

</details>

<a id="sorting"></a>

#### Ordinamento.

Parametri di ordinamento e di collegamento del percorso utensile.

<details>
<summary>Fare clic qui per espandere..</summary>

<a id="sort-by"></a>

##### Ordina per.

Consente di impostare l'ordine di deposizione di strati e feature.

<strong>Layers</strong> (strati). Consente di depositare tutte le feature strato per strato.

![images/download/attachments/157866720/Sorting_layers.png](assets/images/download/attachments/157866720/Sorting_layers.png)

<strong>Features</strong>. Consente di depositare tutte le feature una per una.

![images/download/attachments/157866720/Sorting_Wells.png](assets/images/download/attachments/157866720/Sorting_Wells.png)

<strong>Split by layers</strong> (suddividi per strati). Questo parametro consente di suddividere le feature nel numero desiderato di strati. È disponibile solo quando il parametro <strong>Sort by</strong> è impostato sull'opzione <strong>Features</strong>.

<strong>Allow reverse direction</strong> (consenti direzione inversa). Modifica la direzione di lavorazione di una singola curva.

<strong>Start point</strong> (punto iniziale). Consente di impostare regole personalizzate per determinare il punto iniziale sugli strati di deposizione.

<strong>Do not change</strong> (non modificare). Il punto iniziale viene selezionato automaticamente.

<strong>Nearest</strong> (più vicino). Seleziona il punto più vicino all'utensile

<strong>Manually</strong> (manualmente). L'utente seleziona il punto iniziale in modo interattivo

<strong>Optimize order</strong> (ottimizza l'ordine). <strong>Se disattivato:</strong> le curve vengono selezionate nell'ordine dell'elenco di aggiunta.

<strong>Se attivato:</strong> le curve vengono selezionate in base alla distanza minima

</details>

<a id="transformations"></a>

### Trasformazioni:

Insieme di parametri dell'operazione che consentono di eseguire la conversione delle coordinate per il percorso utensile calcolato all'interno dell'operazione. [Dettagli](10168.md)

<a id="part"></a>

### Pezzo:

Il pezzo è un gruppo di elementi geometrici che definisce lo spazio in cui verificare le intaccature. [Dettagli](330.md)

<a id="workpiece"></a>

### Grezzo:

Il modello del grezzo di un'operazione definisce il materiale da lavorare. [Dettagli](738.md)

<a id="fixtures"></a>

### Attrezzature:

Come attrezzature si specificano in genere i mezzi di fissaggio quali mandrini autocentranti, griffe, staffe, ecc., nonché le zone di restrizione di qualsiasi altra natura. [Dettagli](10283.md)
