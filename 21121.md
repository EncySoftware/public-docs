<a id="application-area"></a>

## Anwendungsbereich:

Diese Operation trägt Material entlang zuvor definierter Kurven auf. Die Kurven können mit beliebigen geeigneten Werkzeugen erstellt werden, beispielsweise in einem externen CAD-Programm. Die Operation wandelt die Kurven in eine Werkzeugbahn um und übernimmt das Sortieren sowie die Aufteilung in Bereiche. Der Aufbau kann schichtweise oder schraubenförmig erfolgen.

<a id="setup"></a>

### Einrichtung:

Auf der Registerkarte **Setup** werden grundlegende Projektparameter festgelegt, beispielsweise die Lage des Bauteils auf der Maschine und das Werkstückkoordinatensystem. [Details](1022.md)

<a id="job-assignment"></a>

### Auftragszuweisung:

**Curve (Kurve).** Definiert die Werkzeugbahn entlang der ausgewählten Kurve. [Details](707.md).

**Properties (Eigenschaften).** Öffnet die Elementeigenschaften, beispielsweise zur Eingabe eines Aufmaßes. Der Dialog kann auch durch Doppelklick auf einen Listeneintrag geöffnet werden.

**Delete (Löschen).** Entfernt ein Element aus der Liste.

<a id="strategy"></a>

### Strategie:

<a id="printing-strategy"></a>

#### Druckstrategie.

Die gewählte Strategie bestimmt die verfügbaren Parameter im Bereich **Sorting**.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Planar (Eben).** Aktiviert die Einstellungen für schichtweisen Aufbau.

**Helical (Schraubenförmig).** Aktiviert die Einstellungen für schraubenförmigen Aufbau.

</details>

<a id="sorting"></a>

#### Sortierung.

Parameter zum Sortieren und Verbinden der Werkzeugbahnen.

<details>
<summary>Weitere Informationen anzeigen</summary>

<a id="sort-by"></a>

##### Sortieren nach.

Legt die Druckreihenfolge der Schichten und Elemente fest.

**Layers (Schichten).** Baut alle Elemente gemeinsam Schicht für Schicht auf.

![images/download/attachments/157866720/Sorting_layers.png](assets/images/download/attachments/157866720/Sorting_layers.png)

**Features (Elemente).** Baut die Elemente nacheinander auf.

![images/download/attachments/157866720/Sorting_Wells.png](assets/images/download/attachments/157866720/Sorting_Wells.png)

**Split by layers (Nach Schichten aufteilen).** Unterteilt den Aufbau der Elemente in Abschnitte mit der gewünschten Anzahl von Schichten. Nur verfügbar, wenn **Sort by** auf **Features** eingestellt ist.

**Allow reverse direction (Richtungsumkehr zulassen).** Erlaubt das Umkehren der Bearbeitungsrichtung einzelner Kurven.

**Start point (Startpunkt).** Legt die Regel zur Auswahl des Startpunkts einer Druckschicht fest.

**Do not change (Nicht ändern).** Der Startpunkt wird automatisch gewählt.

**Nearest (Nächstgelegener Punkt).** Wählt den zum Werkzeug nächstgelegenen Punkt.

**Manually (Manuell).** Der Startpunkt wird interaktiv festgelegt.

**Optimize order (Reihenfolge optimieren), deaktiviert:** Die Kurven werden in der Reihenfolge der Auftragsliste bearbeitet.

**Aktiviert:** Die Kurven werden anhand der kürzesten Verbindungswege ausgewählt.

</details>
