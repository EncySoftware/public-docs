# Holes sorting

![images/download/attachments/157862153/image2024-7-29_17-15-42.png](assets/images/download/attachments/157862153/image2024-7-29_17-15-42.png)

## Application Area:

The holes sorting window allows you select one of the type of sorting using some parameters to sort holes list.

### Sorting patterns

The system has four pattern of holes sorting: <strong>Rectangular</strong>, <strong>Circular (Rings)</strong>, <strong>Circular (Sectors)</strong>, <strong>Optimal</strong>.

### Rectangular

The pattern <strong>Rectangular</strong> allows you to sort the holes along XY rows. This type of sorting has the following parameters:

- ![images/download/thumbnails/157862153/image2020-10-22_9-30-52.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-30-52.png) — starting position of calculation rows
- ![images/download/thumbnails/157862153/image2020-10-22_9-30-18.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-30-18.png) — angle to rotate rows
- ![images/download/thumbnails/157862153/image2020-10-22_9-34-28.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-34-28.png) — distance between rows
- ![images/download/thumbnails/157862153/image2020-10-22_9-39-43.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-39-43.png) — direction to calculate drilling trajectories (Available values: <strong>Top-down</strong>, <strong>Bottom-up</strong>)
- ![images/download/thumbnails/157862153/image2020-10-22_9-59-20.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-59-20.png) — order of moving between rows (Available values: <strong>One way</strong>, <strong>ZigZag</strong>, <strong>Optimal</strong>)
- ![images/download/thumbnails/157862153/image2020-10-22_10-2-42.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-2-42.png) — change order in the opposite direction

If <strong>Start point</strong> is unchecked then the system will select first hole of drilling trajectories.

### Circular (Rings)

The pattern <strong>Circular (Rings)</strong> allows you to sort the holes along the rings located from specified center. T his type of sorting has the following parameters:

- ![images/download/thumbnails/157862153/image2020-10-22_10-20-24.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-20-24.png) — center of calculation rings
- ![images/download/thumbnails/157862153/image2020-10-22_10-28-42.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-28-42.png) — angle to set start position
- ![images/download/thumbnails/157862153/image2020-10-22_10-31-19.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-31-19.png) — distance between center and first ring
- ![images/download/thumbnails/157862153/image2020-10-22_10-33-32.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-33-32.png) — distance between rings
- ![images/download/thumbnails/157862153/image2020-10-22_10-34-48.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-34-48.png) — direction to calculate drilling trajectories (Available values: <strong>Clockwise</strong>, <strong>Counter-clockwise</strong>)
- ![images/download/thumbnails/157862153/image2020-10-22_10-36-2.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-36-2.png) — direction to calculate drilling trajectories (Available values: <strong>Outside to inside</strong>, <strong>Inside to outside</strong>)
- ![images/download/thumbnails/157862153/image2020-10-22_9-59-20.png](assets/images/download/thumbnails/157862153/image2020-10-22_9-59-20.png) — order of moving between rings (Available values: <strong>One way</strong>, <strong>ZigZag</strong>, <strong>Optimal</strong>)

- ![images/download/thumbnails/157862153/image2020-10-22_10-34-48.png](assets/images/download/thumbnails/157862153/image2020-10-22_10-34-48.png) — direction to calculate drilling trajectories (Available values: <strong>Clockwise</strong>, <strong>Counter-clockwise</strong>)
