# Criação do sistema de coordenadas pelo ponto de origem e dois vetores principais

A criação de um novo sistema de coordenadas dessa maneira é ativada pelo item de menu ![images/download/thumbnails/157858639/image2019-1-11_17-30-14.png](assets/images/download/thumbnails/157858639/image2019-1-11_17-30-14.png) no [painel de sistemas de coordenadas](753.md).

O novo sistema de coordenadas é definido pelo ponto de origem e dois vetores principais, X e Y. O ponto zero deve ser atribuído movendo o cursor na [janela gráfica](169.md) para o ponto desejado. Se for um ponto válido para ser usado como origem do sistema de coordenadas, ele será destacado. A seleção é confirmada clicando com o botão esquerdo sobre ele:

![images/download/attachments/157858639/f_clip0424_1.png](assets/images/download/attachments/157858639/f_clip0424_1.png)

Depois disso, a direção do eixo X deve ser especificada escolhendo um ponto na tela pelo qual o eixo X passará e clicando com o botão esquerdo do mouse:

![images/download/attachments/157858639/f_clip0424_2.png](assets/images/download/attachments/157858639/f_clip0424_2.png)

Em seguida, o processo é repetido para o eixo Y:

![images/download/attachments/157858639/f_clip0424_3.png](assets/images/download/attachments/157858639/f_clip0424_3.png)

Posteriormente, o sistema de coordenadas recém-criado torna-se ativo:

![images/download/attachments/157858639/f_clip0424_4.png](assets/images/download/attachments/157858639/f_clip0424_4.png)

A qualquer momento, o nome do sistema de coordenadas, sua cor e seu ponto de origem podem ser [alterados](403.md).
