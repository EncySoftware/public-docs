# Anforderungen an IGES-Dateien

Das Modul **IGES import** basiert auf der Spezifikation **IGES 5.3**. Das System importiert ausschließlich IGES-Dateien im **ASCII**-Format. Dateien im komprimierten ASCII-Format oder im Binärformat werden als ungültig eingestuft. DOS- und UNIX-Textdateien unterscheiden sich in ihren Zeilenenden; das System erkennt beide Varianten automatisch und lädt sie korrekt.
