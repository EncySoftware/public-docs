# Requisitos para arquivo IGES

O módulo **IGES import** foi desenvolvido com base nas especificações do **IGES** versão 5.3. O sistema importa apenas arquivos IGES no formato **ASCII**. Isso significa que os arquivos IGES, criados em formato ASCII compactado ou em formato binário, serão avaliados pelo sistema como incorretos. O sistema define automaticamente o tipo de arquivo de texto (tipo DOS ou tipo UNIX, que usam indicações diferentes de fim de linha) e carrega corretamente os dois tipos de arquivo.
