# Requisiti per i file IGES

Il modulo **IGES import** (importazione IGES) è stato sviluppato sulla base delle specifiche **IGES** versione 5.3. Il sistema importa solo file IGES in formato **ASCII**. Ciò significa che i file IGES creati in formato ASCII compresso o in formato binario verranno considerati dal sistema non corretti. Il sistema riconosce automaticamente il tipo di file di testo (tipo DOS o tipo UNIX, che usano indicazioni diverse per la fine della riga) e carica correttamente entrambi i tipi di file.
