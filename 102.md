# Requirements for IGES-file

The **IGES import** module has been developed based upon the specifications of **IGES** version 5.3. The system imports only IGES files in **ASCII** format. This means that IGES files, created in compressed ASCII-format or in binary format, will be evaluated by the system as incorrect. The system automatically defines the type of text file (DOS-type or UNIX-type, use different indications of the string end) and correctly loads both file types.
