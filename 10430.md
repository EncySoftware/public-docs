# Arquivos de configuração da máquina

O arquivo de configuração da máquina é um arquivo com a extensão .stms. Ele contém informações sobre a configuração da máquina para um determinado tipo de usinagem e se destina a criar rapidamente um projeto a partir de um modelo. O formato de armazenamento de dados dentro do arquivo de configuração da máquina é semelhante ao formato do projeto.

Para gerenciar arquivos de configuração da máquina, use no painel principal as opções **Save as a machine setup**, **Import from the machine setup file** e **New project from the machine setup file**.

Leia mais sobre os arquivos de configuração da máquina aqui: [Configuração da máquina (modelo de projeto)](10427.md).
