# Dateien zur Maschineneinrichtung

Eine Maschineneinrichtungsdatei besitzt die Endung .stms. Sie enthält die Einrichtung einer Maschine für eine bestimmte Bearbeitung und dient als Vorlage für die schnelle Projekterstellung. Ihr internes Speicherformat ähnelt dem Projektformat.

Zum Verwalten dieser Dateien stehen auf der Hauptleiste die Befehle zum Speichern als Maschineneinrichtung, zum Importieren aus einer Maschineneinrichtungsdatei und zum Erstellen eines neuen Projekts aus einer solchen Datei zur Verfügung.

Weitere Informationen finden Sie unter [Maschineneinrichtung (Projektvorlage)](10427.md).
