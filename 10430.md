# Machine setup files

The machine setup file is a file with an expansion.stms. Inside himself, it contains information about machine setup for a certain processing and is designed to quickly create a project on the template. The format of storage of data inside the machine setup file is similar to the format of the project.

To control the machine setup files, use the "Save as a machine setup", "Import from the machine setup file" and "New project from the machine setup file" on the main panel.

Read more about machine setup files here: [Machine setup (project template)](10427.md).
