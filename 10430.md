# File di configurazione macchina

Il file di configurazione macchina è un file con estensione .stms. Contiene al proprio interno le informazioni sulla configurazione della macchina per una determinata lavorazione ed è concepito per creare rapidamente un progetto a partire da un modello. Il formato di memorizzazione dei dati all'interno del file di configurazione macchina è simile al formato del progetto.

Per gestire i file di configurazione macchina, utilizzare le voci "Save as a machine setup", "Import from the machine setup file" e "New project from the machine setup file" nel pannello principale.

Maggiori informazioni sui file di configurazione macchina sono disponibili qui: [Configurazione macchina (modello di progetto)](10427.md).
