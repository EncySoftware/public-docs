# Regelflächen mit der Werkzeugflanke bearbeiten

![images/download/attachments/157864317/f97clip0149_zoom72.png](assets/images/download/attachments/157864317/f97clip0149_zoom72.png)

Setzen Sie **Contact tool type** auf **Flank**, um Regelflächen mit der Fräserflanke zu bearbeiten. **Inverse tool axis direction** kehrt die Werkzeugachse um. **Axial displacement** ergänzt einen Versatz entlang dieser Achse.

![images/download/attachments/157864317/image2024-7-29_16-57-17.png](assets/images/download/attachments/157864317/image2024-7-29_16-57-17.png)

Die Auftragszuweisung kann aus Bauteilkanten oder Kurven bestehen. Werden sie beim Überfahren nicht hervorgehoben, aktivieren Sie den entsprechenden Kanten- bzw. Kurvenfilter.

![images/download/attachments/157864317/image2024-7-29_16-58-1.png](assets/images/download/attachments/157864317/image2024-7-29_16-58-1.png)

Werden Kanten trotz aktivem Filter nicht hervorgehoben, [vernähen Sie die Flächen](1000.md).

![images/download/attachments/157864317/image2024-7-29_16-59-22.png](assets/images/download/attachments/157864317/image2024-7-29_16-59-22.png)

Für die gemeinsame Bearbeitung einer verbundenen Kantenfolge wählen Sie alle Kanten zusammen aus und fügen sie mit einem Klick auf `Edge\Curve on surface` hinzu. Sie werden zu einem Auftragselement verbunden. Einzeln hinzugefügte Kanten werden auch einzeln bearbeitet. Halten Sie zur Mehrfachauswahl **Strg** gedrückt.

Bearbeitungsrichtung und -seite werden im Eigenschaftendialog des ausgewählten Auftragselements geändert.
