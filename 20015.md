# Durch Zone oder Begrenzung

![images/download/attachments/157860290/image2024-8-8_17-8-16.png](assets/images/download/attachments/157860290/image2024-8-8_17-8-16.png)

Bei dieser Methode wird die Kontur aus bereits vorhandenen Elementen aufgebaut.

Wenn Sie einen Punkt innerhalb einer Gruppe von Elementen angeben, wird eine Kontur aus den Elementen dieses Bereichs erstellt.

![images/download/attachments/157860290/image2024-8-8_17-9-53.png](assets/images/download/attachments/157860290/image2024-8-8_17-9-53.png)

Wenn Sie die Konturbegrenzung auswählen, werden die Elemente automatisch entlang der zusammenhängenden Kette bis zum nächsten Schnittpunkt mit einem anderen Objekt übernommen.

![images/download/attachments/157860290/image2024-8-8_17-11-15.png](assets/images/download/attachments/157860290/image2024-8-8_17-11-15.png)

Um die Kontur fortzusetzen, wählen Sie das nächste Element aus. Ist das ausgewählte Element nicht mit dem zuletzt erstellten verbunden, versucht das System, die Verbindung entlang der Elementkette zu ergänzen.

![images/download/attachments/157860290/image2024-8-8_17-11-57.png](assets/images/download/attachments/157860290/image2024-8-8_17-11-57.png)
