# Annotations

The **Drawing annotation** button menu contains nine commands:

- **Text.** Creates a text object. [Details](20049.md)
- **Hatch.** Hatches or fills a closed area. [Details](20050.md)
- **Surface roughness.** Adds a surface roughness symbol. [Details](20051.md)
- **Leader.** Adds a pointer with text above and below a shelf. [Details](20052.md)
- **Item number.** Adds a numbered leader with the number on a shelf or in a circle. [Details](20052.md)
- **Geometric tolerance.** Adds a frame with a characteristic, tolerance value and datums. [Details](20053.md)
- **Datum feature.** Adds a datum symbol with a letter. [Details](20053.md)
- **Section.** Creates a section line, view arrow or detail. [Details](20054.md)
- **Section label.** Adds a view heading with a letter and scale. [Details](20054.md)

A surface roughness symbol, leader, tolerance frame, datum feature or section can be attached to an edge: a line, arc, circle or profile element. The annotation follows the edge when it is edited. Clicking empty space places a free symbol. Deleting the edge removes the link but keeps the annotation.

The last entered values become defaults for the next symbol of the same type.

Annotations are not transferred to CAM: text, dimensions, hatches and symbols are excluded. Only geometry is transferred. Text becomes geometry after splitting it into elements. [Details](20023.md)
