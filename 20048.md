# Annotations

- ![Text icon](assets/images/annotations/text.png) **Text.** Allows you to create custom text.
- ![Hatch icon](assets/images/annotations/hatch.png) **Hatch.** Fills a closed sketch area with hatch lines.
- ![Surface roughness icon](assets/images/annotations/surface-roughness.png) **Surface roughness.** Adds a surface roughness symbol.
- ![Leader icon](assets/images/annotations/leader.png) **Leader.** Adds explanatory text with a leader line.
- ![Geometric tolerance icon](assets/images/annotations/geometric-tolerance.png) **Geometric tolerance.** Adds a feature control frame to specify a geometric tolerance.
- ![Datum feature icon](assets/images/annotations/datum-feature.png) **Datum feature.** Marks a datum feature for specifying geometric tolerances.
