# Modus für die Auswahl von Objekten

Aktivieren Sie die Option **Select Objects Mode** (Objektauswahlmodus) im Dropdown-Menü des Ansichtsfensters, um die Objektauswahl im Grafikfenster zu aktivieren. Dieser Modus ist standardmäßig aktiviert. Der Mauszeiger nimmt dann seine gewohnte Form an: ![Mauszeiger im Objektauswahlmodus](assets/images/download/attachments/157858294/image2019-1-10_17-14-46.png). Danach können Objekte mit dem Mauszeiger im Grafikfenster ausgewählt werden. Wenn Sie den Mauszeiger über den Bildschirm bewegen, wird das darunterliegende Objekt hervorgehoben, sofern es ausgewählt werden kann. Ein Klick mit der **linken Maustaste** wählt das hervorgehobene Objekt aus.

![Objektauswahlmodus im Menü](assets/images/download/attachments/157858294/image2024-6-27_16-17-43.png)

Weitere Methoden zur Auswahl von Objekten auf dem Bildschirm finden Sie unter [Objektauswahl](10.md).
