# Geometrical model structure window

The model structure window consists of three panels: the **tools panel**, the **model tree** and a **list of available objects**.

![images/download/attachments/157859211/image2024-7-2_16-39-49.png](assets/images/download/attachments/157859211/image2024-7-2_16-39-49.png)

In the **model tree** panel above, the structure of the whole model is displayed. Three nodes make up the groups of the model, which are located at different levels. The [active groups](1.md) are highlighted. When selecting an inactive group using the mouse or keyboard, the group becomes active and the list of available objects changes accordingly.

> Below, commands from pop-up windows will be considered, repeated commands will be skipped.

Clicking the right mouse button on a normal group in **model tree** brings up the following pop-up window:

![images/download/attachments/157859211/image2024-7-2_16-40-39.png](assets/images/download/attachments/157859211/image2024-7-2_16-40-39.png)

Commands:

- **New group** - adds a new object the [active group](1.md).
- **Import DXF as sketch**, **Load sketch** - commands for work with [sketches](833.md).

Clicking the right mouse button on the node of the imported model in the **model tree** causes the following pop-up window:

![images/download/attachments/157859211/image2024-7-2_16-41-34.png](assets/images/download/attachments/157859211/image2024-7-2_16-41-34.png)

Commands:

- **Show in Explorer** - will open the folder, where contains the imported file;
- **Open in CAD** - file will be opened in the linked CAD, if not, then window selection appears.

> If the imported file has been changed, the name of the group will be allocated **bold**, the toolbar button appears "[Model files update manager](6231.md)" ![images/download/attachments/157859211/Ico_Refresh_All.png](assets/images/download/attachments/157859211/Ico_Refresh_All.png), and the **[Update](6231.md)** (update only selected group) command will appear in a pop-up window:
>
> ![images/download/attachments/157859211/image2019-1-10_14-55-35.png](assets/images/download/attachments/157859211/image2019-1-10_14-55-35.png)
>
> If the imported file has been renamed, moved or deleted, the **Set File Path...** (allows you to specify the new location of the imported file) command will appear in a pop-up window.
>
> ![images/download/attachments/157859211/image2024-7-2_16-45-0.png](assets/images/download/attachments/157859211/image2024-7-2_16-45-0.png)

Clicking the right mouse button on any group in the **list of available objects** causes the following pop-up window:

![images/download/attachments/157859211/image2024-7-2_16-50-30.png](assets/images/download/attachments/157859211/image2024-7-2_16-50-30.png)

Commands:

- **Rename** - allows you to edit the name of the selected object;
- **Copy**, **Cut**, **Paste** - [working with the exchange buffer](749.md);
- **Delete** - deletes selected objects;
- **Select All** - selects all geometric objects;
- **Select by color** - selects all objects in the tree that have the same color as the selected one:
- **Inverse Selection** - selects all other objects, and the selection of current cancels;
- **[Transform](116.md), [Join](400.md), [Project](401.md),** **[Triangulate](619.md)** - commands are duplicated on **tool panel** and described below;
- **[Inverse](34.md)** - inverting normals of surfaces;
- **Color** - allows you to change the color of the selected object;
- **Save as...** - offers to save the selected geometric objects in one of the supported formats;
- **[Save as tool...](10343.md)** - saves the selected object in the form of an arbitrary shaped tool;
- **Save as tool holder** - saves the selected object in the form of an arbitrary holder;
- **[Properties](57.md)** - calls the properties window of geometric objects.

In the **list of available objects**, all groups and geometrical objects, which are a part of the [active group](1.md), are displayed. That is, the objects which are currently available for selection and modification. Single left mouse clicking on any of the listed objects, selects that object.
