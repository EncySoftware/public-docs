# Barra de ferramentas e suplemento de importação do SOLIDWORKS™

![images/download/attachments/157859679/image2018-12-21_17-50-14.png](assets/images/download/attachments/157859679/image2018-12-21_17-50-14.png)

A barra de ferramentas permite exportar dados geométricos do SOLIDWORKS™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859679/image2022-3-30_12-30-51.png](assets/images/download/attachments/157859679/image2022-3-30_12-30-51.png)

O suplemento permite importar arquivos de projeto do SOLIDWORKS™.

Extensões suportadas: SLDASM, ASM, SLDPRT, PRT, SLDDRW, DRW, X_B, X_T, STP, STEP. A partir de julho de 2026, o uso do módulo SolidWorks exige uma licença separada. Consulte [Alterações no licenciamento da integração ENCY–SOLIDWORKS](https://encycam.com/news/ency-solidworks-integration-licensing/). O SOLIDWORKS™ deve estar instalado no computador para que o recurso funcione.
