# Werkzeugbaugruppe zusammenstellen

![images/download/attachments/162961520/1231.png](assets/images/download/attachments/162961520/1231.png)

<a id="application-area"></a>

## Anwendungsbereich:

Dieses Beispiel zeigt die Zusammenstellung einer einfachen Werkzeugbaugruppe im Fenster **Component libraries**: Ein Fräswerkzeug wird in einen Adapter eingesetzt, der wiederum im Maschinenmagazin aufgenommen wird. Der Aufbau erfolgt vom Schneidwerkzeug zur Maschinenaufnahme.

<a id="add-the-component-and-check-recognition"></a>

### Komponente hinzufügen und Erkennung prüfen.

Die Komponente wird aus einem 3D-Modell hinzugefügt. Das System versucht automatisch zu erkennen, ob es sich um ein Werkzeug oder einen Adapter bzw. Halter handelt, und bestimmt bei Werkzeugen den Typ. Das Ergebnis kann über die Registerkarten **Adapter**, **Turn tool** und **Mill tool** korrigiert werden. **Tool type** legt den Werkzeugtyp genauer fest. Die Vorschau zeigt die Komponente mit ihren Abmessungen.

![images/download/attachments/162961520/image2026-8-12_9-4-12.png](assets/images/download/attachments/162961520/image2026-8-12_9-4-12.png) ![images/download/attachments/162961520/image2026-8-12_9-7-34.png](assets/images/download/attachments/162961520/image2026-8-12_9-7-34.png)

<a id="assign-the-tool-plug"></a>

### Einsteckanschluss des Werkzeugs festlegen

Damit das Werkzeug in einen Adapter eingesetzt werden kann, benötigt es einen passenden Schaftanschluss. Geben Sie den Verbindungstyp unter **Plug** an. Wählen Sie einen vorgeschlagenen Eintrag oder definieren Sie einen neuen, im Beispiel **D8**. Bei einer Verbindung aus der Bibliothek werden die normgerechten Abmessungen übernommen.

![images/download/attachments/162961520/image2026-8-12_9-10-43.png](assets/images/download/attachments/162961520/image2026-8-12_9-10-43.png)

<a id="check-and-position-the-plug-connection"></a>

### Anschluss prüfen und positionieren.

Nach dem Festlegen des **Plug** ist der Bereich **Connector** verfügbar. Er zeigt den Anschluss, seine Position (**LOCATION**), Drehung (**ROTATION**) und die Steuerelemente für den Ursprung (**Origin**). Hinzu kommen die Verbindungseigenschaften, im Beispiel **Type: Cylinder**, **Height: 20 mm**, **Diameter: 8 mm** und **Axis: Z**. Der Anschluss wird in der Vorschau hervorgehoben. Positionieren Sie ihn mit **Origin** korrekt relativ zur Komponente. Verwenden Sie dafür **+Z / −Z** bzw. **Top / Bottom**, oder ziehen Sie das Koordinatensystem direkt in der Vorschau.

![images/download/attachments/162961520/image2026-8-12_9-13-29.png](assets/images/download/attachments/162961520/image2026-8-12_9-13-29.png)

<a id="create-the-adapter"></a>

### Adapter erstellen.

Klicken Sie erneut auf **Add (+)** und wählen Sie **Adapters**. Ein neuer Adapter wird in dieser Gruppe angelegt.

<a id="set-the-adapters-plug-and-add-a-socket"></a>

### Adapteranschluss und Werkzeugaufnahme festlegen

Der Adapter benötigt zwei Verbindungen: einen **Plug** zur Maschinenaufnahme und einen **Socket** zur Aufnahme des Werkzeugs. Wählen Sie unter **Plug** den Anschluss zum Maschinenmagazin, hier **HSK40**. Unter **Connections** weisen Sie **Socket 1** den Typ **D8** zu, passend zum Plug des Werkzeugs. Im Beispiel werden beide Verbindungstypen aus der Liste ausgewählt.

![images/download/attachments/162961520/image2026-8-12_9-22-41.png](assets/images/download/attachments/162961520/image2026-8-12_9-22-41.png)

<a id="automatic-assembly-in-the-operation"></a>

### Automatische Zusammenstellung in der Operation.

Sobald die Komponenten in den Bibliotheken vorhanden sind, versucht das System, daraus automatisch eine passende Werkzeugbaugruppe für die Operation zu bilden. Im Bereich **Tool assembly** werden Werkzeug (**D8**), Adapter (**HOLDER_D8**), Magazinposition (**Position**) und Korrektur (**Corrector: Auto**) angezeigt. Die zusammengestellte Baugruppe wird an der Maschine montiert und im Grafikfenster dargestellt.

![images/download/attachments/162961520/image2026-8-12_9-32-4.png](assets/images/download/attachments/162961520/image2026-8-12_9-32-4.png)

<a id="result"></a>

### Ergebnis.

Die Operation verwendet die vollständige Baugruppe: Das Werkzeug **D8** steckt über die gemeinsame D8-Verbindung im Adapter **HOLDER_D8**. Dieser ist über **HSK40** mit dem Maschinenmagazin verbunden. Das System stellt diese Verbindungskette automatisch aus den Komponenten der aktiven Bibliotheken zusammen.

<a id="manual-assembly-through-the-tool-window"></a>

### Manuelle Zusammenstellung im Werkzeugfenster.

Eine Werkzeugbaugruppe kann auch manuell erstellt werden. Die Plus-Schaltfläche im Bereich **Tool assembly** öffnet **Add new**. Dort werden für die Operation geeignete Baugruppen mit Name, Durchmesser, Arbeitslänge und Quellbibliothek angeboten, beispielsweise **8mm End mill — Examples**, **D8 — Machine** oder **7mm End mill — Examples**. Die ausgewählte Baugruppe wird an der Maschine montiert und im Grafikfenster angezeigt.

![images/download/attachments/162961520/image2026-8-12_9-41-55.png](assets/images/download/attachments/162961520/image2026-8-12_9-41-55.png) ![images/download/attachments/162961520/image2026-8-12_9-42-11.png](assets/images/download/attachments/162961520/image2026-8-12_9-42-11.png)

<a id="building-directly-from-the-machine"></a>

### Zusammenstellung direkt an der Maschine.

Der Aufbau ist auch direkt im Grafikfenster von der Maschine zum Werkzeug möglich. Freie Aufnahmeanschlüsse werden an der Maschine angezeigt. Klicken Sie auf einen Anschluss und anschließend auf das eingeblendete Pluszeichen, um Komponenten mit passendem Verbindungstyp auszuwählen. Fügen Sie zuerst den Adapter hinzu, im Beispiel **HOLDER_D8**. Klicken Sie danach auf das Pluszeichen an dessen freier Aufnahme und wählen Sie Werkzeugtyp und Modell, beispielsweise **Mill tools** oder **Hole machining tools** sowie **D8**, **7mm End mill** oder **8mm End mill**. Die fertige Baugruppe steht anschließend in der Liste **Tool assembly** der Operation zur Verfügung, etwa als **T#1 8mm End mill** oder **T#2 D8**.
