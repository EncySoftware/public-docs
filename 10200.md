# Tipos de ciclos de rosqueamento

O percurso da ferramenta das operações de rosqueamento pode ser gerado em vários formatos de saída. Vamos considerar cada um deles separadamente.

O ciclo de rosqueamento de múltiplas passadas (ISO G76) permite usar um único bloco do programa NC para definir todos os parâmetros necessários para que a máquina faça uma rosca de forma padrão. A profundidade necessária é atingida automaticamente com a geração de várias passadas. Entre os parâmetros do ciclo estão as coordenadas dos pontos inicial e final, o ângulo de conicidade (para roscas cônicas), o tamanho do chanfro para a saída da ferramenta, os ângulos do perfil, a profundidade da rosca, o número de passadas, a estratégia de penetração e outros. Consulte a documentação do comando NC para obter mais informações.

![images/download/attachments/157865478/embim45.png](assets/images/download/attachments/157865478/embim45.png)

```
                    Exemplo de programa NC
G01 X70 Z5.0 F1.0 M08            (Approach to start point)
G01 X70 Z5.0 F1.0 M08            (Approach to start point)
G76 P010060 
G76 X57.4 Z-24.0 P1.3 Q0.35 F2.0 (Calling G76 multipass thread cycle) 
G00 X200.0 Z150.0 M09            (Retract)
```

O ciclo de rosqueamento de passada única ISO G92 (pode ser G92, G78, G21 e outros, conforme o comando NC) gera um conjunto fechado de movimentos para uma passada de rosqueamento. A figura abaixo mostra o esquema de processamento. Antes da chamada desse ciclo, a ferramenta está no ponto Start. O ciclo é chamado por um bloco do programa NC, que define o ponto inicial da rosca, o passo, o tamanho da conicidade, o tamanho do chanfro e outros. Como resultado desse bloco, a ferramenta vai do ponto Start ao ponto TSP, rosqueia até o ponto TEP e retorna ao ponto Start. Normalmente, o rosqueamento é feito em várias passadas, de modo que o programa NC consiste em várias chamadas do ciclo com diferentes diâmetros de rosca. Portanto, ele pode ser usado tanto para roscas de forma padrão quanto para roscas de forma livre.

X28.9                 (Modal calling G92 cycle with another diameter value)
X28.5                 (Modal calling G92 cycle with another diameter value) 
X28.1                 (Modal calling G92 cycle with another diameter value)
X27.8                 (Modal calling G92 cycle with another diameter value)

O rosqueamento avançado (estendido) é feito com ISO G32/G33 (pode ser diferente em várias máquinas). Esse comando ativa o modo de rosqueamento contínuo cilíndrico, cônico ou frontal com passo constante. Nesse modo, a sincronização entre o movimento da ferramenta e a rotação do fuso fica ativada. Todos os movimentos da ferramenta serão executados no modo de rosqueamento até que seja detectada uma mudança de interpolação ou um comando de movimento rápido. Se a ferramenta se mover paralelamente ao eixo de rotação do fuso, será formada uma rosca cilíndrica. Se a ferramenta se mover simultaneamente paralela e perpendicularmente ao eixo de rotação do fuso, será formada uma rosca cônica. É possível formar uma rosca frontal especial se a ferramenta se mover perpendicularmente ao eixo de rotação do fuso. Nesse caso, será formada na face uma ranhura em forma de espiral de Arquimedes.

O comando G32/G33 não gera nenhum movimento; portanto, todos os movimentos de trabalho da ferramenta, aproximações, afastamentos e transições para as próximas passadas devem ser programados diretamente no programa NC. Ele pode ser usado tanto para roscas de forma padrão quanto para roscas de forma livre.
