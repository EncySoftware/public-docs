# 2D Geometry sketcher

A sketch (the **Sketch1** node) contains geometry, dimensions and annotations on planes.

The **2D Geometry sketcher** provides tools for creating and editing planar geometry in the CAM system. It supports lines, arcs, circles, rectangles, and contours, together with tools for adding chamfers, rounding corners, offsetting, trimming, and splitting elements.

This section explains the common building and editing workflow and the settings of individual sketching tools. [Details](20000.md) It also covers dimensions, geometric constraints, transformations, and reusable blocks. Use these topics to construct and modify sketches and profiles, either interactively or by entering coordinates and parameter values.

## Keyboard shortcuts

| Shortcut | Action |
|---|---|
| **[Ctrl+A]** | Select everything on the active plane, respecting the filter |
| **[Esc]** | Exit construction mode |
| **[Del]** | Delete the selection; in trim mode, delete the highlighted object; during construction, discard the unfinished object |
| **[Ctrl+Space]** | Switch between line and arc while creating a profile |
| **[Enter]** | Save a new block or finish a spline; confirm an entered value |
| **[Shift]** + click | Add or remove an object from the selection |
| **[Ctrl]** + click | Select a profile element rather than the entire profile |
| Double-click during selection | Select all objects connected by constraints |
| **[Ctrl+G]** | Toggle the grid |
| **[Ctrl+Z]**, **[Ctrl+Shift+Z]** | Undo and redo an action |
