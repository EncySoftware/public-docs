# Bibliotecas de componentes

## Área de aplicação:

A janela <strong>Component libraries</strong> é o editor das bibliotecas de componentes, isto é, o local onde são armazenados os elementos dos conjuntos de ferramentas: ferramentas de corte, adaptadores, magazines da máquina e as conexões que os unem. Cada componente tem uma representação visual, é definido por suas dimensões e possui uma haste de fixação (<strong>Plug</strong>) e, no caso de adaptadores e magazines, um ou mais alojamentos (<strong>Sockets</strong>) de um tipo de conexão específico.

A janela é usada para preparar e manter os dados de ferramental que tornam possíveis a seleção automática de ferramentas e a formação dos conjuntos de ferramentas.

A janela da biblioteca de componentes é aberta pelo botão correspondente da barra de ferramentas (no <strong>modo avançado</strong>).

### As bibliotecas de componentes são compostas pelos seguintes elementos:

<strong>Barra de ferramentas (canto superior esquerdo).</strong>

- <strong>Toggle panel.</strong> Mostra ou oculta o painel esquerdo <strong>Library</strong>.

- <strong>Save.</strong> Salva as alterações no arquivo da biblioteca no disco.

- <strong>Open.</strong> Abre um arquivo de biblioteca do disco.

- <strong>Undo.</strong> Cancela a última alteração.

- <strong>Redo.</strong> Repete a alteração cancelada anteriormente.

<strong>Painel Library.</strong>

- <strong>Add (+).</strong> Adiciona uma nova biblioteca (de usuário) ao painel.

- <strong>Category / library checkboxes.</strong> Alternam a visibilidade de uma categoria (<strong>All</strong>, <strong>Machine</strong>, <strong>Examples</strong>, <strong>System</strong>) ou de uma biblioteca individual na lista de componentes.

Uma biblioteca é armazenada no disco como um arquivo. As bibliotecas de componentes pertencem às seguintes categorias:

- <strong>All.</strong> Nó de nível superior que mostra todas as bibliotecas ao mesmo tempo: todas as categorias e suas bibliotecas são exibidas juntas.

- <strong>Machine.</strong> É formada durante a adaptação de um esquema da máquina para o trabalho no <strong>modo de ferramentas avançado (advanced tools mode).</strong> O arquivo da biblioteca da máquina sempre fica ao lado do <strong>arquivo do esquema da máquina</strong>. Essa biblioteca contém um tipo especial de componente chamado magazine. O magazine da máquina é um componente que tem alojamentos (sockets) com um tipo de conexão especificado e não tem haste de fixação (plug). Quando um esquema da máquina é ativado, a biblioteca localizada ao lado dele é ativada automaticamente.

- <strong>Examples.</strong> Bibliotecas de referência fornecidas com o software.

- <strong>System.</strong> Bibliotecas fornecidas e mantidas pelo sistema CAM.

<strong>Lista de componentes (painel central).</strong>

- <strong>Filter.</strong> Abre as opções de filtragem da lista de componentes (ícone de funil).
- <strong>Search.</strong> Filtra a lista pelo nome de componente informado.
- <strong>Type.</strong> Alterna o agrupamento da lista para exibição por tipo de componente (Magazines, Connections, Tools, …).
- <strong>Kit.</strong> Alterna o agrupamento da lista para exibição por kit (biblioteca de origem).
- <strong>Add (+).</strong> Cria um novo componente na biblioteca atual.

<strong>Propriedades do componente (painel inferior):</strong> <em>(campos, não botões)</em> <strong>Name</strong>, <strong>Units</strong>, <strong>Plug</strong>, <strong>CCMS</strong> e a lista <strong>Connections</strong> (<strong>Support (Z)</strong>, …).

<strong>Área de visualização.</strong>

<strong>Show dimensions.</strong> Alterna a exibição das dimensões do componente na visualização 3D.

<strong>Zoom to fit.</strong> O modelo é girado arrastando-o e ampliado com a roda do mouse (<em>drag to orbit · scroll to zoom</em>).

### Formação de bibliotecas.

O preenchimento de uma biblioteca de componentes abrange as seguintes atividades.

- <strong>Criação de componentes parametrizados integrados.</strong> Os campos <strong>Plug</strong> e <strong>Sockets</strong> devem ser preenchidos, de preferência com conexões padrão.

- <strong>Criação de objetos a partir de modelos 3D.</strong> Os campos usados pelos filtros devem ser preenchidos.

- <strong>Trabalho com filtros.</strong> Os campos de filtro orientam a busca por componentes adequados.
