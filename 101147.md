**Exit overlap.** An overlap is used to extend a toolpath beyond the contour itself. To change the overlap value you can either drag the yellow marker with the mouse or click on it and edit the dimension value which appears.

![images/download/attachments/157869153/Exit_overlap.png](assets/images/download/attachments/157869153/Exit_overlap.png)

**EXO** - Exit overlap

**Entry overlap.** An overlap is used to extend a toolpath beyond the contour itself. To change the overlap value you can either drag the yellow marker with the mouse or click on it and edit the dimension value which appears.

![images/download/attachments/157869153/Entry_overlap.png](assets/images/download/attachments/157869153/Entry_overlap.png)

**ENO** - Entry overlap

**Compensation on cut. Inlet segments** are automatically added to the main approach paths of the compensated contour when the **Compensation type** is not set to **Computer**. By default, input/output segments are not added directly to the straight feed paths, as this would be technically impractical.
