# Gravação de uma macro

![images/download/attachments/162957781/image2026-6-29_12-9-11.png](assets/images/download/attachments/162957781/image2026-6-29_12-9-11.png)

## Área de aplicação:

O botão **Record** inicia a gravação de uma macro; um segundo clique encerra a gravação. A gravação fica vinculada ao projeto ativo no momento em que é iniciada. Se o projeto ativo for alterado durante a gravação, ela será encerrada automaticamente. A gravação de uma nova macro e a edição de uma macro existente são mutuamente exclusivas: não é possível iniciar uma nova gravação enquanto uma macro estiver aberta para edição, e vice-versa.

### Registro do estado do projeto

Uma macro pode começar reproduzindo a configuração atual do projeto, para que uma execução posterior utilize as mesmas condições iniciais. Os dados a registrar devem ser selecionados antes de clicar em **Record**.

1. Abra a lista **Project state** na barra de ferramentas.
2. Selecione os itens necessários: **Machine setup**, **Setups workpiece**, **Operations parameters**, **Recognize feature** e **Ask CAM Agent**.

![images/download/thumbnails/162957781/image2026-9-7_15-46-12.png](assets/images/download/thumbnails/162957781/image2026-9-7_15-46-12.png)

### Gravação das ações

1. Clique em **Record**. O botão passa a exibir o ícone de parada, o cabeçalho mostra **Recording macro** e o contador é definido como **0 steps**.
2. Execute as ações necessárias no projeto. Cada ação reconhecida é acrescentada como uma etapa, e o contador é atualizado em tempo real. Entre as ações registradas estão:

   - criação de uma operação;

   - seleção de uma operação na árvore de operações;

   - configuração do bruto, incluindo a adição e edição de primitivas, como caixa, cilindro, fundido e prisma, e de seus sobremetais;

   - adição de dispositivos de fixação, como mandris, morsas, grampos e apoios, e edição de seus sobremetais, cores e nomes;

   - atribuição de geometria a uma operação, como faces, zonas de usinagem e de restrição, curvas, furos, superfícies-guia e áreas;

   - seleção de itens no modelo 3D e edição de suas propriedades.

3. Clique no mesmo botão, agora com a função **Stop**, para encerrar a gravação. O cabeçalho passa a mostrar **Recording complete**.

![images/download/attachments/162957781/image2026-6-29_12-33-34.png](assets/images/download/attachments/162957781/image2026-6-29_12-33-34.png)

Ao encerrar a gravação, o sistema sugere um nome, como **Macro name 1**, e abre o painel **Save**. Antes de salvar, é possível revisar e ajustar as etapas gravadas. [Detalhes](102458.md)
