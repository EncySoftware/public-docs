# Im CAM-Hauptfenster an einem externen System anmelden

Öffnen Sie im Hauptmenü **Connect to PLM**. Der Eintrag ist nur vorhanden, wenn mindestens eine PLM-Verbindung konfiguriert ist.

![images/download/attachments/157867796/5.png](assets/images/download/attachments/157867796/5.png)

Das Untermenü zeigt die verfügbaren Verbindungen. Wählen Sie die gewünschte Verbindung, um das Anmeldefenster zu öffnen.

![images/download/attachments/157867796/6.png](assets/images/download/attachments/157867796/6.png)

Geben Sie Ihre Zugangsdaten ein oder aktivieren Sie **Use domain authentication** (Domänenanmeldung).

Zum Trennen öffnen Sie erneut **Connect to PLM** und wählen **Disconnect from [connection name]** für die betreffende Verbindung.

![images/download/attachments/157867796/7.png](assets/images/download/attachments/157867796/7.png)
