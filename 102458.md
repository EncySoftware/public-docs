# Makroschritte bearbeiten

![images/download/attachments/162957789/image2026-6-29_14-36-41.png](assets/images/download/attachments/162957789/image2026-6-29_14-36-41.png)

<a id="application-area"></a>

## Anwendungsbereich:

Die meisten Bearbeitungsfunktionen stehen während der Aufzeichnung oder im Bearbeitungsmodus zur Verfügung. Gespeicherte Makros können auch nur für einen einzelnen Lauf angepasst werden.

<a id="the-step-list"></a>

### Schrittliste

Jede Zeile enthält:

- **Statuspunkt:** links; dient auch zum Setzen eines Haltepunkts.

- **Bezeichnung:** beschreibt den Schritt.

- **Bearbeitbare Parameter:** gegebenenfalls Dropdown-Listen oder Textfelder.

![images/download/attachments/162957789/image2026-9-8_14-50-26.png](assets/images/download/attachments/162957789/image2026-9-8_14-50-26.png)

<a id="changing-a-parameter-value"></a>

### Parameterwert ändern

Wählen Sie einen Listenwert oder geben Sie den Text ein. Der neue Wert wird mit dem Schritt gespeichert.

<a id="marking-a-field-as-an-input"></a>

### Feld als Eingabe kennzeichnen

Aufzeichnungen enthalten zunächst feste Werte. Für eine bei jedem Lauf erforderliche Eingabe markieren Sie das Feld als Pflichtfeld:

1. Bewegen Sie den Mauszeiger auf den Schritt und klicken Sie auf ![Eingabe festlegen](assets/images/download/thumbnails/162957789/image2026-6-29_14-39-21.png) neben dem Feld.
2. Das Feld wird hervorgehoben. Das Makro kann erst gestartet werden, wenn ein Wert angegeben ist.

Dies eignet sich für bauteilabhängige Werte wie Durchmesser, Ebenen und Aufmaße.

<a id="re-targeting-a-geometry-item"></a>

### Geometrie neu zuordnen

Schritte mit Geometrieverweisen können neu zugewiesen werden:

1. Klicken Sie auf das hervorgehobene Geometriefeld.
2. Wählen Sie das neue Element im 3D-Modell.

Der Schritt übernimmt die Auswahl. Dies ist sowohl beim Bearbeiten als auch vor einem einzelnen Lauf möglich.

<a id="removing-a-step"></a>

### Schritt entfernen

Klicken Sie während der Aufzeichnung oder Bearbeitung auf **×** am Zeilenende.

<a id="grouped-steps"></a>

### Gruppierte Schritte

Zusammengehörige Schritte stehen unter einer Gruppenüberschrift, beispielsweise **Edit hole (5)**. Der Pfeil klappt die Gruppe auf oder zu und erleichtert die Übersicht bei längeren Makros.
