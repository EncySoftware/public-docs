# Modifica delle fasi

![images/download/attachments/162957789/image2026-6-29_14-36-41.png](assets/images/download/attachments/162957789/image2026-6-29_14-36-41.png)

<a id="application-area"></a>

## Ambito di applicazione:

La maggior parte delle operazioni di modifica delle fasi è disponibile durante la <strong>registrazione</strong> di una macro o quando la macro è aperta per la <strong>modifica</strong>. Una macro salvata può inoltre essere adattata per una singola esecuzione.

<a id="the-step-list"></a>

### Elenco delle fasi

Ogni azione registrata è rappresentata da una riga di fase che contiene:

- <strong>Punto di stato.</strong> Si trova a sinistra della riga; serve anche a impostare un punto di interruzione (breakpoint)

- <strong>Didascalia</strong>. Descrive lo scopo della fase.

- <strong>Parametri modificabili.</strong> Se presenti, uno o più elenchi a discesa o campi di testo.

![images/download/attachments/162957789/image2026-9-8_14-50-26.png](assets/images/download/attachments/162957789/image2026-9-8_14-50-26.png)

<a id="changing-a-parameter-value"></a>

### Modifica del valore di un parametro

Per un elenco a discesa si seleziona il valore richiesto; per un campo di testo si digita il valore. Il nuovo valore viene conservato nella fase.

<a id="marking-a-field-as-an-input"></a>

### Contrassegno di un campo come dato di input

La registrazione acquisisce i valori effettivamente utilizzati. Per convertire un valore fisso in un <strong>dato di input</strong> da fornire a ogni esecuzione della macro, il relativo campo viene contrassegnato come <strong>obbligatorio</strong>:

1. Con il cursore sulla fase, premere il pulsante ![images/download/thumbnails/162957789/image2026-6-29_14-39-21.png](assets/images/download/thumbnails/162957789/image2026-6-29_14-39-21.png) accanto al campo.
2. Il campo diventa un dato di input (<em>il campo viene evidenziato</em>): la macro non può essere eseguita finché non viene fornito un valore.

Questo meccanismo si applica ai valori che cambiano da un pezzo all'altro: un diametro, un livello, un sovrametallo.

<a id="re-targeting-a-geometry-item"></a>

### Riassegnazione di un elemento geometrico

Le fasi che fanno riferimento a un elemento del modello (una faccia, una curva, un foro e così via) mostrano tale elemento come un campo che consente di selezionarlo nuovamente:

1. Fare clic sul campo (<em>il campo viene evidenziato</em>).
2. Selezionare il nuovo elemento nel modello 3D.

La fase viene aggiornata con l'elemento selezionato. Il meccanismo funziona sia durante la modifica sia per una macro salvata prima di un'esecuzione, il che consente di applicare una stessa macro a geometrie diverse.

<a id="removing-a-step"></a>

### Rimozione di una fase

Durante la registrazione o la modifica, con il cursore sulla fase, premendo la <strong>×</strong> alla fine della riga si rimuove la fase dalla macro.

<a id="grouped-steps"></a>

### Fasi raggruppate

Le fasi correlate sono raccolte sotto un'<strong>intestazione di gruppo</strong> che mostra il nome del gruppo, ad esempio <strong>Edit hole (5)</strong>. Facendo clic sulla freccia (chevron) dell'intestazione si espande o si comprime il gruppo. Il raggruppamento semplifica la revisione di una macro lunga.
