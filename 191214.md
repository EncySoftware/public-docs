## Anwendungsbereich:

Der Abschnitt **CDIgnoreList** des Maschinenschemas kann direkt im CAM-System bearbeitet werden. Früher waren dafür manuelle XML-Änderungen oder MachineMaker erforderlich.

Bei einer Kollision zeigt die Benachrichtigung das betroffene Knotenpaar und die Optionen **Ignore** sowie **Ignore only in current session**.

<a id="functionality"></a>

### Funktionsweise

1. **Ignore** übernimmt das kollidierende Knotenpaar in die Ignorierliste. Weitere Kollisionen zwischen genau diesen Knoten werden dann ignoriert.

<p><img src="assets/images/download/attachments/157861565/image2025-7-22_9-5-4.png" alt="images/download/attachments/157861565/image2025-7-22_9-5-4.png" width="300"></p>

Dabei wird neben der Maschinenkinematikdatei eine Datei mit der Endung **.cdil** erstellt bzw. aktualisiert.

Bei einem neuen Projekt wird die Ignorierliste aus dieser Datei geladen, falls sie vorhanden ist. Andernfalls gelten die Daten im Maschinenschema.

**Ignore only in current session** wirkt nur für die laufende Sitzung und erstellt keine Datei.

2. Die Datei kann über das Kontextmenü der Maschine auf der Technologieseite geleert werden.
