## Área de aplicação:

A seção <strong>CDIgnoreList</strong> do esquema da máquina pode ser editada diretamente no sistema CAM. Antes, era necessário inserir os dados manualmente no Notepad ou usar o MachineMaker.

Quando ocorre uma colisão durante a simulação, aparece uma notificação informando que houve uma colisão entre nós. Essa notificação contém os botões <strong>Ignore</strong> e <strong>Ignore only in curent session</strong>.

### Funcionalidade:

1. Quando uma colisão é detectada durante a simulação, uma notificação alerta o usuário e identifica os nós em conflito (por exemplo, o nó X e o nó Y). Essa notificação contém os botões <strong>Ignore</strong> e <strong>Ignore only in curent session</strong>. Clique em "Ignore" para adicionar o par de nós identificado à CDIgnoreList e ignorar futuras colisões entre esses nós.

<p><img src="assets/images/download/attachments/157861565/image2025-7-22_9-5-4.png" alt="images/download/attachments/157861565/image2025-7-22_9-5-4.png" width="300"></p>

<strong>No primeiro caso</strong>, um arquivo com a extensão ".cdil" é criado ao lado do arquivo de cinemática da máquina. Se o arquivo não existir, ele é criado.

Ao criar um novo projeto CAM, o sistema referencia uma máquina. Se houver um arquivo de lista de ignorados ao lado do arquivo da máquina, ele será carregado dele; caso contrário, os dados serão lidos diretamente do arquivo da máquina.

<strong>No segundo caso</strong>, nenhum arquivo é criado. A configuração funciona somente na sessão atual.

2. O arquivo pode ser limpo pelo menu de contexto da máquina (na aba <strong>technology</strong>).
