# Janela de modelos de medição

A janela exibe as bibliotecas com [ciclos prontos para o cálculo](1411.md). Aqui é possível adicionar uma descrição aos ciclos, especificar o nome de exibição do ciclo na janela, distribuí-los em grupos e adicioná-los à biblioteca necessária. Cada biblioteca é salva localmente e armazenada, por padrão, na pasta padrão de bibliotecas ($(Libraries_FOLDER)), na subpasta "ProbingCycles".

![images/download/attachments/157866921/image2024-7-18_17-20-15.png](assets/images/download/attachments/157866921/image2024-7-18_17-20-15.png)

## Árvore da biblioteca

Na parte esquerda da janela, há uma árvore com a lista de bibliotecas e modelos de ciclo. Aqui são exibidas todas as bibliotecas criadas anteriormente e as bibliotecas das pastas **Examples** e **Suppliers**. Se a pasta **Suppliers** não existir, crie-a no seguinte caminho: pasta padrão de bibliotecas ($(Libraries_FOLDER)), subpasta "ProbingCycles".

![images/download/attachments/157866921/image2024-7-18_17-21-17.png](assets/images/download/attachments/157866921/image2024-7-18_17-21-17.png)

As bibliotecas são ordenadas da seguinte forma: primeiro ficam as bibliotecas criadas pelo usuário, seguidas pelas bibliotecas das pastas **Examples** e **Suppliers**.

Os elementos são movidos arrastando e soltando. É possível mover da seguinte forma:

- as bibliotecas são movidas entre outras bibliotecas no mesmo nível;
- os grupos são movidos entre outros grupos no mesmo nível, de uma biblioteca para outra e também de um grupo para outro;
- os modelos de ciclo são movidos entre outros grupos no mesmo nível, de uma biblioteca para outra e também de um grupo para outro;
- é proibido mover itens para as bibliotecas das pastas **Examples** e **Suppliers**.

A janela também pode exibir o [**SubCode for postprocessor**](1411.md) de cada modelo de ciclo, que aparece entre colchetes após o nome. Para isso, ative o modo **Show expert tools**. Como fazer isso está descrito [aqui](1411.md).

Ao selecionar um elemento na árvore, seus parâmetros são exibidos na parte direita da janela e podem ser editados.

## Elementos de controle

O painel de controle dos elementos da árvore fica na parte superior esquerda da janela. Há 4 controles no painel:

1. ![images/download/thumbnails/157866921/image2024-7-18_17-22-51.png](assets/images/download/thumbnails/157866921/image2024-7-18_17-22-51.png) **Open library** é o botão para adicionar bibliotecas locais existentes. Depois de clicar no botão, é aberta uma caixa de diálogo para escolher o local da biblioteca existente;
2. ![images/download/thumbnails/157866921/image2024-7-18_17-22-15.png](assets/images/download/thumbnails/157866921/image2024-7-18_17-22-15.png) **Create new library** é o botão para criar uma nova biblioteca no computador e adicioná-la à janela. Depois de clicar no botão, é aberta uma caixa de diálogo para escolher o local da nova biblioteca;
3. ![images/download/thumbnails/157866921/image2024-7-18_17-23-17.png](assets/images/download/thumbnails/157866921/image2024-7-18_17-23-17.png) **New group** é o botão para criar um grupo para ordenar e reunir modelos de ciclo. Um grupo só pode ser criado dentro de uma biblioteca ou de outro grupo;
4. ![images/download/thumbnails/157866921/image2024-7-18_17-23-52.png](assets/images/download/thumbnails/157866921/image2024-7-18_17-23-52.png) **Remove** é o botão para remover o elemento selecionado da janela.

Também é possível fazer uma cópia da biblioteca e salvá-la em outro local do computador. Para isso, selecione a biblioteca necessária e clique com o botão direito do mouse. No menu de contexto, clique em **Save library as**. Depois de clicar no botão, é aberta uma caixa de diálogo para escolher o local da cópia da biblioteca. Em seguida, a cópia é salva no computador e adicionada à janela.

Observação: **New group** fica desativado para as bibliotecas das pastas **Examples** e **Suppliers**.

## Painel de parâmetros

O painel de parâmetros fica no lado direito da janela.

![images/download/attachments/157866921/image2024-7-18_17-25-51.png](assets/images/download/attachments/157866921/image2024-7-18_17-25-51.png)

Há dois parâmetros comuns a todos os elementos:

- **File name** - caminho da biblioteca no computador e nome do arquivo da biblioteca;
- **Caption** - nome do elemento na janela de modelos de medição.

Os demais parâmetros, incluindo os botões de controle da imagem, não estão disponíveis para os elementos de biblioteca e de grupo.

Dois parâmetros adicionais estão disponíveis para os elementos de modelo de ciclo:

- **Description** - indica a finalidade do ciclo, bem como quaisquer outras informações adicionais;
- **Image file** - imagem que representa o ciclo atual.

Observação: é proibido editar elementos das bibliotecas localizadas nas pastas **Examples** e **Suppliers**. Isso é indicado pela inscrição **Read only** na parte superior direita da janela.

## Salvando e usando ciclos

Todas as alterações feitas (criação de bibliotecas, mudança de posição dos elementos, edição de parâmetros etc.) são salvas quando a janela é fechada.

Para [usar um modelo de ciclo](1415.md), selecione o modelo necessário e clique no botão **Insert cycle to operation**. Em seguida, o modelo selecionado é inserido na **Job assignment** da operação de medição.
