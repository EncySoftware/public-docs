# Fenster für Messzyklusvorlagen

Das Fenster zeigt Bibliotheken mit [vorbereiteten Messzyklen](1411.md). Hier können Beschreibungen und Anzeigenamen ergänzt, Vorlagen gruppiert und Bibliotheken zugeordnet werden. Jede Bibliothek wird lokal gespeichert, standardmäßig im Unterordner **ProbingCycles** des Bibliotheksverzeichnisses `$(Libraries_FOLDER)`.

![images/download/attachments/157866921/image2024-7-18_17-20-15.png](assets/images/download/attachments/157866921/image2024-7-18_17-20-15.png)

<a id="library-tree"></a>

## Bibliotheksbaum

Links befindet sich der Baum der Bibliotheken und Zyklusvorlagen. Er enthält die zuvor erstellten Bibliotheken sowie Bibliotheken aus **Examples** und **Suppliers**. Falls **Suppliers** fehlt, erstellen Sie diesen Ordner unter `$(Libraries_FOLDER)` im Unterordner **ProbingCycles**.

![images/download/attachments/157866921/image2024-7-18_17-21-17.png](assets/images/download/attachments/157866921/image2024-7-18_17-21-17.png)

Zuerst werden die benutzerdefinierten Bibliotheken angezeigt, danach die Bibliotheken aus **Examples** und **Suppliers**.

Elemente lassen sich per Drag-and-drop verschieben. Dabei gelten folgende Regeln:

- Bibliotheken können innerhalb derselben Ebene umgeordnet werden.
- Gruppen können auf derselben Ebene umgeordnet sowie in andere Bibliotheken oder Gruppen verschoben werden.
- Zyklusvorlagen können umgeordnet sowie zwischen Bibliotheken und Gruppen verschoben werden.
- In Bibliotheken aus **Examples** und **Suppliers** dürfen keine Elemente verschoben werden.

Bei aktiviertem Expertenmodus kann der **[SubCode for postprocessor](1411.md)** jeder Vorlage in Klammern hinter ihrem Namen angezeigt werden. Die Aktivierung von **Show expert tools** ist [hier](1411.md) beschrieben.

Nach Auswahl eines Baumelements werden rechts dessen bearbeitbare Parameter angezeigt.

<a id="control-elements"></a>

## Bedienelemente

Die Symbolleiste oben links enthält vier Funktionen:

1. ![Bibliothek öffnen](assets/images/download/thumbnails/157866921/image2024-7-18_17-22-51.png) **Open library.** Fügt eine vorhandene lokale Bibliothek hinzu. Der Dateiauswahldialog dient zur Auswahl ihrer Datei.
2. ![Bibliothek erstellen](assets/images/download/thumbnails/157866921/image2024-7-18_17-22-15.png) **Create new library.** Erstellt eine Bibliothek auf dem Computer und nimmt sie in die Anzeige auf. Im Dialog wird der Speicherort festgelegt.
3. ![Gruppe erstellen](assets/images/download/thumbnails/157866921/image2024-7-18_17-23-17.png) **New group.** Erstellt eine Gruppe zum Ordnen und Zusammenfassen von Vorlagen. Gruppen können nur innerhalb einer Bibliothek oder einer anderen Gruppe angelegt werden.
4. ![Element entfernen](assets/images/download/thumbnails/157866921/image2024-7-18_17-23-52.png) **Remove.** Entfernt das ausgewählte Element aus dem Fenster.

Mit **Save library as** im Kontextmenü einer Bibliothek kann eine Kopie an einem anderen Speicherort angelegt werden. Wählen Sie im Dialog den Zielpfad. Die Kopie wird gespeichert und zusätzlich im Fenster angezeigt.

*Hinweis: **New group** ist für Bibliotheken aus **Examples** und **Suppliers** deaktiviert.*

<a id="parameters-panel"></a>

## Parameterbereich

Der Parameterbereich befindet sich rechts im Fenster.

![images/download/attachments/157866921/image2024-7-18_17-25-51.png](assets/images/download/attachments/157866921/image2024-7-18_17-25-51.png)

Alle Elemente besitzen zwei allgemeine Parameter:

- **File name.** Pfad und Dateiname der Bibliothek.
- **Caption.** Anzeigename des Elements im Vorlagenfenster.

Für Bibliotheken und Gruppen sind die übrigen Parameter und die Schaltflächen zur Bildverwaltung nicht verfügbar.

Zyklusvorlagen besitzen zusätzlich:

- **Description.** Beschreibung des Zykluszwecks und weiterer Informationen.
- **Image file.** Abbildung des Zyklus.

*Hinweis: Elemente aus Bibliotheken in **Examples** und **Suppliers** sind schreibgeschützt. Dies wird durch **Read only** oben rechts angezeigt.*

<a id="saving-and-using-cycles"></a>

## Zyklen speichern und verwenden

Alle Änderungen, beispielsweise neue Bibliotheken, umgeordnete Elemente und geänderte Parameter, werden beim Schließen des Fensters gespeichert.

Zum [Verwenden einer Zyklusvorlage](1415.md) wählen Sie diese aus und klicken auf **Insert cycle to operation**. Der Zyklus wird in die **Job assignment** der Messoperation eingefügt.
