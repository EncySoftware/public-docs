## Application Area:

The **Feeds/Speeds** calculator computes cutting parameters — cutting speed, spindle speed, feed per tooth and feed rate — from the selected tool, workpiece material and cut method. Computed values are written into the machining operation and can be fine-tuned manually before they are applied. **The calculation of cutting parameters is performed automatically in real-time upon modification of any parameter, without the need to press a dedicated Calculate button.**

The calculator panel is divided into four areas, top to bottom:

1. **Toolbar area.** It allows the user to manage custom tables for populating data used by the calculator.
2. **Input area.** Defines the tool, the workpiece material and the cutting conditions.
3. **Load sliders**. Set the cutting load relative to the recommended range.
4. **Result.** Shows the computed cutting parameters.

### Toolbar.

**Dataset selector.** Selects the active cutting data dataset. Defaults to **Default dataset**. These tables allow the user to define their own cutting parameters, tool materials, and workpiece materials.

**Open editor.** Opens the Edit dataset window for managing the tool and workpiece material databases.

### Input parameters.

**Workpiece material.** The material being machined, selected from the dataset (for example, unalloyed, Mn<1.65, <=0.25%C).

**Tool.** The tool the calculation applies to (for example, End Mill L70, D20). Taken from the active operation.

**Diameter.** Tool cutting diameter, mm.

**Overall length.** Total tool length, mm.

**Tool material.** Cutting material of the tool (for example, Uncoated carbide). The icon to the right switches the material preset.

**Construction.** Tool body type: Any, Solid or Indexable.

**Flutes.** Number of cutting edges. Adjust with the – / + buttons.

**Cut methods.** The milling strategy (for example, Milling shoulder).

**Depth of Cut (Ap).** Axial depth of cut, mm.

**Width (Ae).** Radial width of cut, mm.

### Load sliders.

Two sliders set the working load as a percentage of the recommended range. The caption above each slider shows the corresponding machining condition.

**Feed per tooth (fz).** Sets the feed load. The caption shows the regime, for example Normal roughing. Expressed as 0–100%.

**Cutting speed (Vc).** Sets the speed load. The caption shows the regime, for example Normal roughing/Semi-finishing. Expressed as 0–100%.

*Moving a slider re-evaluates the dependent result fields when you press **Calculate**.*

### Result.

| Parameter | Symbol | Unit | Example |
|---|---|---|---|
| Cutting speed | Vc | m/min | 153 |
| Feed per tooth | fz | mm/tooth | 0.115 |
| Spindle speed | S | RPM | 2435 |
| Feed rate | F | mm/min | 280 |
| Spindle power | P | kW | 0.15 |
| Feed per Rev | FPR | rev/min | 0.115 |

The computed values. Click **Modify result** to edit a value manually.

The **Apply** function enables the transfer of computed cutting parameters to a designated machining operation. Within this interface window, the user specifies the format for data output to the operation, including options to define parameters as cutting speed and feed rate in mm/min or as spindle speed and feed rate in mm/rev.
