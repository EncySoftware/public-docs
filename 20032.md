# Beziehungen in einem Block bearbeiten

Im Inspektor wird auf der Registerkarte **Constraints** (Zwangsbedingungen) eine Liste der Beziehungen des aktiven Elements angezeigt.

![images/download/attachments/157860495/image2024-8-10_17-6-33.png](assets/images/download/attachments/157860495/image2024-8-10_17-6-33.png)

Im Blockmodus können Sie eine Zwangsbedingung durch Klicken auf ihr Symbol deaktivieren oder aktivieren.

![images/download/attachments/157860495/image2024-8-10_17-8-10.png](assets/images/download/attachments/157860495/image2024-8-10_17-8-10.png)

Um im Blockmodus Beziehungen für **Parallelism** (Parallelität), **Tangency** (Tangentialität), **Perpendicularity** (Rechtwinkligkeit), **Coaxiality** (Koaxialität) oder **Equality** (Gleichheit) zu erstellen, aktivieren Sie die entsprechende Schaltfläche und wählen nacheinander zwei Objekte aus.

![images/download/attachments/157860495/image2024-8-10_17-9-33.png](assets/images/download/attachments/157860495/image2024-8-10_17-9-33.png)

Wenn Sie die Schaltfläche wieder deaktivieren, kehren Sie zum Modus für das Aktivieren und Deaktivieren von Beziehungen zurück. Nach dem Verlassen des Blockmodus bleiben aufgehobene Beziehungen dauerhaft deaktiviert.
