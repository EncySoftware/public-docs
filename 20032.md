# Editing links in a block

In the inspector, in the **Constraints** tab, a list of the active element's links is shown.

![images/download/attachments/157860495/image2024-8-10_17-6-33.png](assets/images/download/attachments/157860495/image2024-8-10_17-6-33.png)

Clicking a constraint icon in the inspector removes the constraint; hovering over it highlights it.

![images/download/attachments/157860495/image2024-8-10_17-8-10.png](assets/images/download/attachments/157860495/image2024-8-10_17-8-10.png)

To create links **Parallel**, **Tangential**, **Perpendicular**, **Equal** in block mode, press the corresponding button and sequentially select a pair of objects.

![images/download/attachments/157860495/image2024-8-10_17-9-33.png](assets/images/download/attachments/157860495/image2024-8-10_17-9-33.png)

A constraint that conflicts with locks is not created. Clicking a constraint symbol on the sketch removes constraints of that type from the object. [Details](20031.md)
