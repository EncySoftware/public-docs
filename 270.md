# Importazione di oggetti da file STL

Il formato consente di trasferire modelli volumetrici rappresentati mediante triangoli piani. I file hanno normalmente estensione *.stl. Il sistema importa sia il formato binario sia quello testuale.

Non esistono limitazioni sul tipo di oggetti importabili. In caso di problemi con l'importazione di file in formato binario, provare a importare tramite il formato testuale, poiché è indipendente dalla piattaforma.

<em>Nota: un modello trasferito tramite il formato **STL** è approssimato da molti triangoli. Pertanto, la trasmissione senza perdita di precisione è possibile solo per alcuni tipi di modelli geometrici. Per trasferire i modelli, è prassi comune impostare in esportazione una precisione di approssimazione non inferiore alla [tolleranza](100112.md) di lavorazione richiesta, oppure utilizzare un formato più accurato (ad es. [IGES](266.md)).</em>
