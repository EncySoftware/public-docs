# Importação de objetos de arquivos STL

O formato permite transferir modelos volumétricos representados por triângulos planos. Os arquivos normalmente têm a extensão *.stl. O sistema importa tanto o formato binário quanto o de texto.

Não há limitações quanto ao tipo de objetos importáveis. Se houver problemas na importação de arquivos em formato binário, tente importar pelo formato de texto, pois ele é independente de plataforma.

<em>Observação: um modelo transferido no formato **STL** é aproximado por muitos triângulos. Portanto, a transferência sem perda de precisão só é possível para alguns tipos de modelos geométricos. Ao exportar modelos, recomenda-se definir uma precisão de aproximação não inferior à [tolerância](100112.md) de usinagem necessária ou usar um formato mais preciso (por exemplo, [IGES](266.md)).</em>
