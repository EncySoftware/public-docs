# Importieren von Objekten aus STL-Dateien

Das Format überträgt räumliche Modelle als ebene Dreiecke. Die Dateien besitzen üblicherweise die Endung *.stl. Das System importiert sowohl Binär- als auch Textdateien.

Es bestehen keine Einschränkungen hinsichtlich der importierbaren Objekttypen. Falls Probleme beim Import einer Binärdatei auftreten, verwenden Sie das plattformunabhängige Textformat.

*Hinweis: Ein im **STL**-Format übertragenes Modell wird durch viele Dreiecke angenähert. Eine Übertragung ohne Genauigkeitsverlust ist deshalb nur bei bestimmten Geometrien möglich. Wählen Sie beim Export eine Approximationsgenauigkeit, die mindestens der erforderlichen Bearbeitungsgenauigkeit entspricht; die Abweichung darf also die vorgegebene [Toleranz](100112.md) nicht überschreiten. Alternativ verwenden Sie ein genaueres Format, beispielsweise [IGES](266.md).*
