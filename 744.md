# Eintauchen zulassen

![images/download/attachments/157862706/image2025-4-10_9-39-59.png](assets/images/download/attachments/157862706/image2025-4-10_9-39-59.png)

<a id="application-area"></a>

## Anwendungsbereich:

Kann der Bearbeitungsbereich nicht von außen angefahren werden, erzeugt das System automatisch eine Eintauchbewegung zum ersten Punkt der Arbeitsbahn. Der Eintauchabschnitt führt innerhalb des Rohteils in Z-Richtung nach unten. Der Ablauf ist:

- Anfahren der XY-Eintauchposition auf der [Sicherheitsebene](100117.md) der Operation.
- Senkrechte Bewegung im Eilgang bis zur Sicherheitshöhe oder zum Sicherheitsabstand vor dem Materialeingriff, abhängig von den Einstellungen. Die Sicherheitshöhe entspricht einer Z-Ebene des aktuellen Koordinatensystems; der Sicherheitsabstand wird zum Beginn der Eintauchbewegung gemessen.
- Senkrechtes Absenken mit Anfahrvorschub bis zum Beginn des definierten Eintauchens.
- Ausführen des gewählten Eintauchverfahrens mit Anfahrvorschub bis zum Anfahrpunkt.
- Beginn der anschließenden Anfahrbewegung.

<a id="the-following-plunge-methods-are-available-in-the-system"></a>

### Verfügbare Eintauchverfahren

**None (Keines).** Deaktiviert den Versuch, eine Eintauchbewegung zu erzeugen.

**Spiral (Helix).** Das Werkzeug bewegt sich schraubenförmig auf einem Kreis, dessen Endpunkt mit dem ersten Anfahrpunkt verbunden ist. Der Radius wird vorgegeben.

![images/download/attachments/157862706/Spiral.png](assets/images/download/attachments/157862706/Spiral.png)

**Zigzag (Zickzack).** Das Werkzeug bewegt sich auf einer geraden Strecke hin und her, die mit dem ersten Anfahrpunkt verbunden ist. Die Streckenlänge wird vorgegeben.

![images/download/attachments/157862706/Zigzag.png](assets/images/download/attachments/157862706/Zigzag.png)

**Along curve (Entlang einer Kurve).** Das Werkzeug taucht entlang der Anfahrkurve ein. Das Eintauchen endet am Ende der Anfahrbewegung.

![images/download/attachments/157862706/Along_curve.png](assets/images/download/attachments/157862706/Along_curve.png)

**Axial.** Senkrechtes Eintauchen entlang einer Geraden bis zum ersten Anfahrpunkt.

![images/download/attachments/157862706/Axial.png](assets/images/download/attachments/157862706/Axial.png)

**Ramp angle / Plunge Angle (Eintauchwinkel).** Bestimmt den Tiefenzuwachs während des Eintauchens. Ein größerer Winkel führt zu einem schnelleren Eindringen ins Material.

![images/download/attachments/157862706/Plunge_angle.png](assets/images/download/attachments/157862706/Plunge_angle.png)

**Min size (Mindestgröße)** legt fest:

- den kleinsten zulässigen Helixdurchmesser bei **Spiral**;

- die kleinste zulässige Bewegungsamplitude bei **Zigzag** und **Along Curve**.

Kann mit dieser Mindestgröße keine Bahn ohne unerwünschte Einschnitte erzeugt werden, versucht das System das nächste verfügbare Eintauchverfahren. Ist keines mehr verfügbar, bleibt die Tasche unbearbeitet.

![images/download/attachments/157862706/Plunge_size.png](assets/images/download/attachments/157862706/Plunge_size.png)

**Max size (Maximalgröße)** legt fest:

- den angestrebten Helixdurchmesser bei **Spiral**;

- die angestrebte Bewegungsamplitude bei **Zigzag** und **Along Curve**.

Ist mit der angestrebten Größe kein geeignetes Eintauchen möglich, verringert das System die Größe schrittweise um **Degression**, bis eine Bahn möglich ist oder die Mindestgröße erreicht wird. Anschließend wird ein anderes Verfahren versucht.

![images/download/attachments/157862706/Plunge_size.png](assets/images/download/attachments/157862706/Plunge_size.png)

**Degression (Verkleinerungsschritt).** Wert, um den die Eintauchgröße bei einem erfolglosen Berechnungsversuch reduziert wird. Die Reduzierung erfolgt bis zur möglichen kollisionsfreien Bahn oder bis zur Mindestgröße; danach wird das nächste Verfahren verwendet.

**Smooth radius (Übergangsradius).**

**Aktiviert:** Der Übergang von der Eintauchbewegung zur horizontalen Bewegung wird mit dem angegebenen Radius verrundet.

**Deaktiviert:** Die Eintauchbahn trifft unter dem Eintauchwinkel auf die erste horizontale Bewegung.
