# Contenitori crittografati .stfc

Un contenitore crittografato è un file con estensione .stfc, ovvero un archivio zip. Alcuni file di questo archivio possono essere crittografati. Per decrittografarli e utilizzarli, in genere è necessaria una licenza individuale per ciascun contenitore.

Il contenitore può includere qualsiasi file necessario per lavorare con il sistema, ad esempio:

- [postprocessori](730.md),
- [interpreti](10020.md),
- [schemi macchina](10021.md),
- file di [descrizione dei parametri delle operazioni aggiuntive](10382.md).

Per ottenere una licenza per il contenitore desiderato, rivolgersi al proprio rivenditore. Per attivare la licenza del contenitore, utilizzare il [gestore licenze](10025.md).
