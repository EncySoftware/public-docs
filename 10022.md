# Verschlüsselte Container .stfc

Ein verschlüsselter Container ist ein ZIP-Archiv mit der Endung .stfc. Einzelne Dateien darin können verschlüsselt sein. Für ihre Entschlüsselung und Verwendung ist in der Regel eine eigene Lizenz für den jeweiligen Container erforderlich.

Ein Container kann verschiedene für das System benötigte Dateien enthalten, beispielsweise:

- [Postprozessoren](730.md);
- [Interpreter](10020.md);
- [Maschinenschemata](10021.md);
- [Parameterbeschreibungen zusätzlicher Operationen](10382.md).

Eine Lizenz für den gewünschten Container erhalten Sie über Ihren Händler. Aktivieren Sie sie im [Lizenzmanager](10025.md).
