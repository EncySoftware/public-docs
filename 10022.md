# Contêineres criptografados .stfc

Um contêiner criptografado é um arquivo ZIP com a extensão .stfc. Alguns arquivos do contêiner podem ser criptografados. Para descriptografá-los e utilizá-los, normalmente é necessária uma licença individual para cada contêiner.

O contêiner pode conter quaisquer arquivos necessários ao funcionamento do sistema, por exemplo:

- [pós-processadores](730.md);
- [interpretadores](10020.md);
- [esquemas de máquina](10021.md);
- arquivos de [descrição dos parâmetros de operações adicionais](10382.md).

Entre em contato com o revendedor para obter a licença do contêiner desejado. Use o [gerenciador de licenças](10025.md) para ativá-la.
