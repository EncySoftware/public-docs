# Erweiterte Verbindungseinstellungen

<a id="application-area"></a>

## Anwendungsbereich:

Diese Parameter steuern die Bahnplanung, vorwiegend für 5-Achs-Operationen, unter Berücksichtigung günstiger Drehachsbewegungen.

<a id="approximate-safe-motions"></a>

## Sichere Bewegungen approximieren

Steuert die Aufteilung sicherer Bewegungen auf Zylinder- und Kugelflächen bei 5-Achs-Operationen mit Drehachsbewegungen.

<a id="advanced-axes-limits-control"></a>

## Erweiterte Achsgrenzenüberwachung

Diese Option behandelt zwei typische Probleme bei 5-Achs-Werkzeugwegen:

1. Ein notwendiger Achsumschlag wird möglichst aus der Arbeitsbahn in einen Abschnitt mit schnellen Bewegungen verlagert.

2. In Singularitätsbereichen wird ein gleichmäßiger Bahnverlauf erzeugt. Eine Singularität liegt vor, wenn eine Achskoordinate nicht eindeutig bestimmt werden kann. Beispielsweise kann C bei A = 0 unterschiedliche Werte annehmen.

<details>

**Singularität auf der Sicherheitsfläche vermeiden.**

**Zulässige Achsabweichung in einer Singularität.**

Legt den Winkel fest, um den Maschinen- oder Robotergelenke von der nominal berechneten Stellung abweichen dürfen, um einen Singularitätsbereich zu umgehen.

<a id="machine-optimized-transitions"></a>

## Maschinenoptimierte Verbindungen

Bei deaktivierter Option erfolgen Übergänge auf der durch **Rapid Distance** definierten Ebene auf dem kürzesten Weg im geometrischen Raum. Zwischen zwei Zuständen (X1, Y1, Z1, Nx1, Ny1, Nz1) und (X2, Y2, Z2, Nx2, Ny2, Nz2) werden Position und Werkzeugachsvektor linear interpoliert. Die Verbindung ist damit eine Gerade mit interpolierter Werkzeugausrichtung.

Bei aktivierter Option erfolgt die Interpolation im Maschinenachsraum. Zwischen (A1, C1, X1, Y1, Z1) und (A2, C2, X2, Y2, Z2) werden die Achswerte linear interpoliert. Die räumliche Form der Verbindungsbahn hängt dadurch von der Maschinenkinematik ab. Sie kann länger erscheinen, aber dennoch günstigere Maschinenbewegungen ergeben.
