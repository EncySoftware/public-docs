# An- und Rückfahrregelliste der Maschine

## Übersicht der Regelliste

Im Abschnitt **Leads** der Maschinen-XML-Datei können mehrere An- und Rückfahrregeln mit unterschiedlichen Namen gespeichert werden. Eine Änderung an einer Regel wirkt sich auf alle Operationen aus, die darauf verweisen. Zum Zuweisen wählen Sie die Regel im [Bearbeitungsfenster](10072.md) aus:

## Regelliste bearbeiten

Es gibt zwei Bearbeitungsmöglichkeiten:

1. Direkte Bearbeitung der Maschinen-XML-Datei, wie in diesem Artikel beschrieben.
2. Verwendung des [Bearbeitungsfensters](10072.md), das über die Schaltfläche mit den drei Punkten neben der An- bzw. Rückfahrregel geöffnet wird.

<a id="editing-machines-xml-file"></a>

## Maschinen-XML-Datei bearbeiten

Die Regelliste liegt im Abschnitt **Leads**, in dem früher nur eine einzelne Regel angegeben werden konnte. Die Unterabschnitte heißen **ApproachCommands** und **ReturnCommands**. Die Einträge verwenden folgende Felder:

1. **RuleID.** Eindeutige GUID, über die Operationen auf die Regel verweisen.
2. **Name.** Name der Regel.
3. **Command.** Die eigentliche Regel als Folge von Zwischenpunkten. Für die automatische Kollisionsvermeidung verwenden Sie **Auto**.
4. **Type.** Legt fest, unter welchen Bedingungen die Regel verwendet werden kann. Vier Typen stehen zur Verfügung:

- **LCS:** Nur bei aktiviertem lokalem Koordinatensystem.
- **TCPM:** Nur bei aktiviertem Tool Center Point Management. LCS und TCPM können nicht gleichzeitig aktiv sein.
- **General:** Nur wenn LCS und TCPM deaktiviert sind.
- **Undefined:** Unabhängig vom LCS- und TCPM-Zustand. Dies gilt auch, wenn kein Typ ausdrücklich angegeben wurde.

Beispielausschnitt einer XML-Datei:

```
                    MaxTurn65WithCounterSpindle
<SCType ID="MaxTurn65WithCounterSpindle" Caption="MaxTurn65 with Counter Spindle" type="MaxTurn65" Enabled="true">
	<GUID DefaultValue="{8E0CEF0A-8045-436D-89FD-BBE70D387AB1}"/>
	<Priority DefaultValue="172"/>
	<Name DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Comment DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Leads>
	<ApproachCommands>
		<SCArray>
			<Rule>
				<RuleID>{41D3BB1C-2F23-47AC-B5F9-5DAF7030A015}</RuleID>
				<Command>C;Z10;X;Z</Command>
				<Name>Left spindle approach</Name>
			</Rule>
			<Rule>
				<RuleID>{54FC19E5-8ACB-491A-8E94-FC9990FC8680}</RuleID>
				<Command>C2;Z-10;X;Z</Command>
				<Name>Right spindle approach</Name>
			</Rule>
		</SCArray>
	</ApproachCommands>
	<ReturnCommands>
		<SCArray>
			<Rule>
				<RuleID>{380D355A-6708-4C86-BA69-7521A0198A8E}</RuleID>
				<Command>Z10;X;Z;C</Command>
				<Name>Left spindle return</Name>
			</Rule>
			<Rule>
				<RuleID>{18B61D64-EEC9-4403-8922-CCFCC017E53E}</RuleID>
				<Command>Z-10;X;Z;C2</Command>
				<Name>Right spindle return</Name>
			</Rule>
		</SCArray>
	</ReturnCommands>
</Leads>
```

## Ältere Maschinen und Projekte übernehmen

Beim erstmaligen Öffnen einer älteren Maschine wird die Liste aus ihrer bisherigen An- bzw. Rückfahrregel erzeugt. Der Wurzelknoten verweist auf diese Regel, sofern dort keine benutzerdefinierte Regel festgelegt wurde. Operationen mit dem Typ „Vom Wurzelknoten“ verwenden dadurch dieselbe An- bzw. Rückfahrt wie zuvor.
