# Lista de aproximação/retorno da máquina

## Visão geral da lista de aproximação/retorno

Na seção "Leads" do arquivo xml da máquina, é possível especificar várias regras de aproximação/retorno para uso conveniente. Cada item da lista tem um nome que o distingue das outras regras. Se uma regra da lista for editada, a alteração afetará todas as operações que fazem referência a ela. Para atribuir uma regra a uma operação, selecione o item necessário no [Approach/return edit form](10072.md):

## Alternativa à lista de aproximação/retorno

Existe uma forma alternativa de ter várias regras de aproximação ou retorno: criar submáquinas para os pares porta-peça/porta-ferramenta usados no projeto e definir a regra de aproximação e retorno adequada para cada submáquina. Consulte [Definição da submáquina nos esquemas da máquina](10410.md) para obter mais informações sobre submáquinas no sistema CAM.

## Edição da lista de aproximação/retorno

Existem 2 formas de editar a lista de aproximação/retorno da máquina.

1. Edição direta do arquivo xml da máquina (mostrada neste artigo)
2. Uso do [approach/return edit form](10072.md). Para exibir o formulário, clique no botão de reticências no campo de edição de aproximação/retorno.

## Edição do arquivo xml da máquina

A lista de aproximação/retorno da máquina está localizada na seção <strong>Leads</strong> (antes, era possível especificar aqui apenas uma regra de aproximação/retorno). <strong>ApproachCommands</strong> e <strong>ReturnCommands</strong> são os nomes das respectivas subseções. Cada regra possui 3 campos:

1. <strong>RuleID</strong> - GUID exclusivo da regra. É usado pelas operações para fazer referência a uma regra específica. Veja o GUID da operação como exemplo.
2. <strong>Name</strong> - nome da regra.
3. <strong>Command</strong> - a regra em si, a sequência de pontos intermediários de aproximação/retorno. Para especificar a aproximação/retorno com prevenção de colisões, use a palavra-chave <strong>Auto</strong>.
4. <strong>Type</strong> - tipo da regra, que define o possível caso de uso da aproximação/retorno. Atualmente existem 4 tipos disponíveis:

- LCS - a aproximação/retorno pode ser usada somente se o sistema de coordenadas local estiver ativado para a operação.
- TCPM - pode ser usado somente se o gerenciamento do ponto central da ferramenta (TCPM) estiver ativado (LCS e TCPM não podem estar ativados ao mesmo tempo).
- General - a regra pode ser usada somente se LCS e TCPM estiverem desativados.
- Undefined - a regra não depende do estado de LCS ou TCPM. Se o tipo não tiver sido definido explicitamente, ele será considerado 'Undefined'.

Abaixo está um exemplo parcial do arquivo xml:

```
                    MaxTurn65WithCounterSpindle
<SCType ID="MaxTurn65WithCounterSpindle" Caption="MaxTurn65 with Counter Spindle" type="MaxTurn65" Enabled="true">
	<GUID DefaultValue="{8E0CEF0A-8045-436D-89FD-BBE70D387AB1}"/>
	<Priority DefaultValue="172"/>
	<Name DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Comment DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Leads>
	<ApproachCommands>
		<SCArray>
			<Rule>
				<RuleID>{41D3BB1C-2F23-47AC-B5F9-5DAF7030A015}</RuleID>
				<Command>C;Z10;X;Z</Command>
				<Name>Left spindle approach</Name>
			</Rule>
			<Rule>
				<RuleID>{54FC19E5-8ACB-491A-8E94-FC9990FC8680}</RuleID>
				<Command>C2;Z-10;X;Z</Command>
				<Name>Right spindle approach</Name>
			</Rule>
		</SCArray>
	</ApproachCommands>
	<ReturnCommands>
		<SCArray>
			<Rule>
				<RuleID>{380D355A-6708-4C86-BA69-7521A0198A8E}</RuleID>
				<Command>Z10;X;Z;C</Command>
				<Name>Left spindle return</Name>
			</Rule>
			<Rule>
				<RuleID>{18B61D64-EEC9-4403-8922-CCFCC017E53E}</RuleID>
				<Command>Z-10;X;Z;C2</Command>
				<Name>Right spindle return</Name>
			</Rule>
		</SCArray>
	</ReturnCommands>
</Leads>
```

## Conversão de máquinas/projetos de versões anteriores

Quando uma máquina de versão anterior é aberta pela primeira vez, é criada uma lista contendo a regra de aproximação/retorno anterior da máquina. Além disso, a operação raiz passa a fazer referência a essa regra (se nenhuma regra personalizada estiver atribuída a ela). Como resultado, as operações com o tipo de regra 'From root operation' usam a mesma aproximação/retorno de antes.
