# Elenco degli avvicinamenti/ritorni della macchina

<a id="approachreturn-list-overview"></a>

## Panoramica dell'elenco degli avvicinamenti/ritorni

Nella sezione "Leads" del file xml della macchina è possibile specificare diverse regole di avvicinamento/ritorno, per comodità d'uso. Ogni elemento dell'elenco ha un nome che lo distingue dalle altre regole. Se una regola dell'elenco viene modificata, la modifica si ripercuote su tutte le operazioni che fanno riferimento a tale regola. Per assegnare una regola a un'operazione, selezionare l'elemento desiderato nel [modulo di modifica dell'avvicinamento/ritorno](10072.md):

## Alternativa all'elenco degli avvicinamenti/ritorni

Esiste un modo alternativo per disporre di più regole di avvicinamento o ritorno: creare sottomacchine per le coppie portapezzo/portautensile utilizzate nel progetto e definire per ciascuna sottomacchina la regola di avvicinamento e ritorno appropriata. Per ulteriori informazioni sulle sottomacchine nel sistema CAM, vedere [Definizione delle sottomacchine negli schemi macchina](10410.md).

<a id="editing-approachreturn-list"></a>

## Modifica dell'elenco degli avvicinamenti/ritorni

Esistono 2 modi per modificare l'elenco degli avvicinamenti/ritorni della macchina.

1. Modifica diretta del file xml della macchina (illustrata in questo articolo)
2. Utilizzo del [modulo di modifica dell'avvicinamento/ritorno](10072.md). Per visualizzare il modulo, fare clic sul pulsante con i puntini di sospensione nel campo di modifica dell'avvicinamento/ritorno.

<a id="editing-machines-xml-file"></a>

## Modifica del file xml della macchina

L'elenco degli avvicinamenti/ritorni della macchina si trova nella sezione <strong>Leads</strong> (in precedenza qui era possibile specificare una sola regola di avvicinamento/ritorno). <strong>ApproachCommands</strong> e <strong>ReturnCommands</strong> sono i nomi delle rispettive sottosezioni. Ogni regola ha 3 campi:

1. <strong>RuleID</strong> - GUID univoco della regola. Viene utilizzato dalle operazioni per fare riferimento a una determinata regola. Come esempio, vedere il GUID dell'operazione.
2. <strong>Name</strong> - nome della regola.
3. <strong>Command</strong> - la regola vera e propria, ossia la sequenza dei punti intermedi dell'avvicinamento/ritorno. Per specificare l'avvicinamento/ritorno con prevenzione delle collisioni, utilizzare la parola chiave <strong>Auto</strong>.
4. <strong>Type</strong> - tipo della regola, che definisce il possibile caso d'uso dell'avvicinamento/ritorno. Attualmente sono disponibili 4 tipi:

- LCS - l'avvicinamento/ritorno può essere utilizzato solo se per l'operazione è abilitato il sistema di coordinate locale.
- TCPM - può essere utilizzato solo se è abilitata la gestione del centro utensile (TCPM) (LCS e TCPM non possono essere abilitati contemporaneamente).
- General - la regola può essere utilizzata solo se sia LCS sia TCPM sono disattivati.
- Undefined - la regola non dipende dallo stato di LCS o TCPM. Se il tipo non è stato definito esplicitamente, si assume 'Undefined'.

Di seguito è riportato un esempio parziale di file xml:

```
                    MaxTurn65WithCounterSpindle
<SCType ID="MaxTurn65WithCounterSpindle" Caption="MaxTurn65 with Counter Spindle" type="MaxTurn65" Enabled="true">
	<GUID DefaultValue="{8E0CEF0A-8045-436D-89FD-BBE70D387AB1}"/>
	<Priority DefaultValue="172"/>
	<Name DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Comment DefaultValue="MaxTurn 65 with Counter Spindle"/>
	<Leads>
	<ApproachCommands>
		<SCArray>
			<Rule>
				<RuleID>{41D3BB1C-2F23-47AC-B5F9-5DAF7030A015}</RuleID>
				<Command>C;Z10;X;Z</Command>
				<Name>Left spindle approach</Name>
			</Rule>
			<Rule>
				<RuleID>{54FC19E5-8ACB-491A-8E94-FC9990FC8680}</RuleID>
				<Command>C2;Z-10;X;Z</Command>
				<Name>Right spindle approach</Name>
			</Rule>
		</SCArray>
	</ApproachCommands>
	<ReturnCommands>
		<SCArray>
			<Rule>
				<RuleID>{380D355A-6708-4C86-BA69-7521A0198A8E}</RuleID>
				<Command>Z10;X;Z;C</Command>
				<Name>Left spindle return</Name>
			</Rule>
			<Rule>
				<RuleID>{18B61D64-EEC9-4403-8922-CCFCC017E53E}</RuleID>
				<Command>Z-10;X;Z;C2</Command>
				<Name>Right spindle return</Name>
			</Rule>
		</SCArray>
	</ReturnCommands>
</Leads>
```

## Conversione di macchine/progetti di versioni precedenti

Quando una macchina di una versione precedente viene aperta per la prima volta, viene creato un elenco contenente la precedente regola di avvicinamento/ritorno della macchina. Inoltre l'operazione radice fa riferimento a questa regola (se non le è stata assegnata una regola personalizzata). Di conseguenza, le operazioni con tipo di regola 'From root operation' utilizzano lo stesso avvicinamento/ritorno di prima.
