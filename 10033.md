# Importação de objetos de arquivos AMF

O *Additive Manufacturing File Format* (AMF) é um padrão aberto para descrever objetos destinados a processos de manufatura aditiva, como a impressão 3D. A norma oficial ISO/ASTM 52915:2013 define um formato baseado em XML, projetado para permitir que qualquer software CAD descreva a forma e a composição de qualquer objeto 3D a ser fabricado em qualquer impressora 3D.
