# Importazione di oggetti da file AMF

Additive Manufacturing File Format (AMF) è uno standard aperto per la descrizione di oggetti destinati a processi di produzione additiva, come la stampa 3D. Lo standard ufficiale ISO/ASTM 52915:2013 è un formato basato su XML, concepito per consentire a qualsiasi software di progettazione assistita da computer di descrivere la forma e la composizione di qualsiasi oggetto 3D da fabbricare su qualsiasi stampante 3D.
