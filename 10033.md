# Importieren von Objekten aus AMF-Dateien

Das Additive Manufacturing File Format (AMF) ist ein offener Standard zur Beschreibung von Objekten für additive Fertigungsverfahren wie den 3D-Druck. ISO/ASTM 52915:2013 beschreibt ein XML-basiertes Format, mit dem CAD-Software die Form und Zusammensetzung eines für den 3D-Druck vorgesehenen Objekts angeben kann.
