# Bauteilgruppe

![images/download/attachments/157862922/part_gr.png](assets/images/download/attachments/157862922/part_gr.png) ![images/download/attachments/157862922/part_grtt.png](assets/images/download/attachments/157862922/part_grtt.png)

<a id="application-area"></a>

## Anwendungsbereich:

Diese Gruppe dient zum Erstellen von **Projekten mit mehreren Bauteilen**. Dabei können unterschiedliche Bauteile oder gleiche Bauteile verwendet werden, deren Bearbeitung wie in einer Fertigungslinie nach Operationen aufgeteilt ist. Zum Sortieren der Operationen verwenden Sie den **Sequencing mode**. [Details](1029.md)

<a id="setup"></a>

## Einrichtung:

Auf der Registerkarte **Setup** werden grundlegende Projektparameter festgelegt, beispielsweise die Bauteillage auf der Maschine und das Werkstückkoordinatensystem. [Details](1022.md)

<a id="transformations"></a>

## Transformationen:

Diese Parameter ermöglichen Koordinatentransformationen des innerhalb einer Operation berechneten Werkzeugwegs. [Details](10168.md)
