# Peça (grupo)

![images/download/attachments/157862922/part_gr.png](assets/images/download/attachments/157862922/part_gr.png) ![images/download/attachments/157862922/part_grtt.png](assets/images/download/attachments/157862922/part_grtt.png)

## Área de aplicação:

Este grupo é necessário para criar <strong>projetos com várias peças</strong>. Podem ser várias peças diferentes (de projeto) ou peças iguais cuja tecnologia é dividida por operações, como em uma linha de produção. Para ordenar as operações, use o <strong>Sequencing mode.</strong> [Detalhes](1029.md)

## Setup:

A guia <strong>Setup</strong> é usada para configurar os parâmetros principais do projeto, como o posicionamento da peça no equipamento, o sistema de coordenadas da peça e outros. [Detalhes](1022.md)

## Transformações:

Conjunto de parâmetros da operação que permite transformar as coordenadas do percurso da ferramenta calculado na operação. [Detalhes](10168.md)
