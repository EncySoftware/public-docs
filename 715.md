# Scheda Folders

![images/download/attachments/157858956/image2024-7-1_17-41-41.png](assets/images/download/attachments/157858956/image2024-7-1_17-41-41.png)

In questa finestra l'utente può impostare i percorsi predefiniti per i file del sistema CAM.

- <strong>Project</strong>: la cartella predefinita per il caricamento e il salvataggio dei progetti.
- <strong>Import files</strong>: la cartella predefinita per il caricamento dei file dei modelli geometrici (IGES, DXF, ecc.).
- <strong>`CNC-programs`</strong>: la cartella predefinita per il salvataggio dei [programmi NC](69.md) generati dal postprocessore.
- <strong>Postprocessor</strong>: la cartella predefinita per il caricamento dei file dei postprocessori.
- <strong>Interpreter</strong>: la cartella predefinita per il caricamento dei file degli interpreti.

I percorsi possono essere inseriti manualmente oppure tramite la finestra di dialogo di selezione del percorso, a cui si accede facendo clic sul pulsante ![images/download/attachments/157858956/image2024-7-1_17-42-41.png](assets/images/download/attachments/157858956/image2024-7-1_17-42-41.png).

<a id="pre-defined-variables-for-defining-directories"></a>

## Variabili predefinite per la definizione delle directory:

- <strong>`$(ENCYDIR)`</strong>: la directory da cui è stato avviato il sistema CAM.
- <strong>`$(PRJDIR)`</strong>: la directory definita nel campo <strong>Project</strong>.
- <strong>`$(PROGRAM_PERSONAL)`</strong>: la directory creata durante l'installazione nella cartella dei documenti personali dell'utente <strong>My Documents</strong>.
- <strong>`$(PROGRAM_COMMON_DOCUMENTS)`</strong>: la directory creata durante l'installazione nella cartella dei documenti pubblici <strong>Public Documents</strong> del computer locale.

Nella definizione dei percorsi effettivi delle directory utilizzati dal sistema CAM, queste variabili verranno sostituite dai corrispondenti percorsi completi all'avvio del sistema o in base alle impostazioni definite dall'utente.

<a id="additional-settings"></a>

## Impostazioni aggiuntive:

- Le <strong>System languages</strong> (lingue del sistema) possono essere modificate nel pannello <strong>Languages</strong>. La modifica della lingua verrà applicata alla sessione corrente.
- <strong>Project save options</strong> (opzioni di salvataggio del progetto): queste opzioni controllano la dimensione dei file di progetto. Più sono dettagliate le informazioni salvate, maggiore è la dimensione del file di progetto. Sono disponibili i seguenti metodi, elencati dal salvataggio delle informazioni minime necessarie a quello più completo:
  1. Vengono salvati solo i dati di origine (modelli geometrici, sistemi di coordinate, operazioni e relativi parametri).
  2. Oltre a quanto sopra, vengono salvati i percorsi utensile delle operazioni.
  3. Oltre a quanto sopra, vengono salvati i modelli 3D dei file di schema della macchina e degli utensili.
  4. Oltre a quanto sopra, vengono salvati gli stati intermedi del grezzo.
- <strong>Autosaves and snapshots</strong> (salvataggi automatici e istantanee): un gruppo di opzioni che consente di configurare la creazione di versioni di backup dei progetti, tra cui <strong>Autosaves by timer</strong>, <strong>Autosaves by events</strong>, <strong>Manually saved snapshots count</strong>, <strong>Autosaved snapshots count</strong>, <strong>Long autosave time</strong> e <strong>Interval between long autosaves</strong>. Per ulteriori dettagli, consultare l'articolo [Salvataggi automatici e istantanee del progetto](10424.md).
- <strong>Confirmations</strong> (conferme): nel pannello <strong>Confirmation</strong> è possibile disabilitare il messaggio di conferma durante la generazione del file NC quando si sovrascrive un file esistente. È inoltre possibile configurare le conferme <strong>on warnings before generating NC programs</strong>, ottenendo un controllo aggiuntivo sulle fasi critiche del flusso di lavoro.
