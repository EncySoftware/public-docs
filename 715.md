# Folders tab

![images/download/attachments/157858956/image2024-7-1_17-41-41.png](assets/images/download/attachments/157858956/image2024-7-1_17-41-41.png)

In this window, the user can set default paths for the CAM system files.

- **Project**: The default folder for loading and saving projects.
- **Import files**: The default folder for loading geometrical model files (IGES, DXF, etc.).
- <strong>`CNC-programs`</strong>: The default folder for saving [NC-programs](69.md) generated by the postprocessor.
- **Postprocessor**: The default folder for loading postprocessor files.
- **Interpreter**: The default folder for loading interpreter files.

The paths can be entered manually or by using the path selection dialog, which can be accessed by clicking the ![images/download/attachments/157858956/image2024-7-1_17-42-41.png](assets/images/download/attachments/157858956/image2024-7-1_17-42-41.png) button.

## Pre-defined variables for defining directories:

- <strong>`$(ENCYDIR)`</strong>: The directory from which the CAM system was launched.
- <strong>`$(PRJDIR)`</strong>: The directory defined in the **Project** field.
- <strong>`$(PROGRAM_PERSONAL)`</strong>: The directory created in the user's personal documents folder **My Documents** during installation.
- <strong>`$(PROGRAM_COMMON_DOCUMENTS)`</strong>: The directory created in the public documents folder **Public Documents** on the local computer during installation.

When defining the actual directory paths used by the CAM system, these variables will be replaced by the corresponding full paths at system start-up or based on user-defined settings.

## Additional settings:

- **System languages** can be changed on the **Languages** panel. The language change will be applied to the current session.
- **Project save options**: These options control the size of the project files. The more detailed the information saved, the larger the project file. The following methods are available, listed from saving the minimum necessary information to the most complete:
  1. Only source data (geometrical models, coordinate systems, operations, and their parameters) are saved.
  2. In addition to the above, the toolpaths of operations are saved.
  3. In addition to the above, 3D models of the machine schema files and tools are saved.
  4. In addition to the above, intermediate workpiece states are saved.
- **Autosaves and snapshots**: A group of options that allows configuring the creation of backup versions of projects, including **Autosaves by timer**, **Autosaves by events**, **Manually saved snapshots count**, **Autosaved snapshots count**, **Long autosave time**, and **Interval between long autosaves**. See the [Autosaves and project snapshots](10424.md) article for more details.
- **Confirmations**: It is possible to disable the confirmation message during NC file generation when overwriting an existing file on the **Confirmation** panel. You can also configure confirmations **on warnings before generating NC programs**, providing additional control over critical steps in the workflow.
