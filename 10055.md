# Barra de ferramentas do CAXA 3D™

![images/download/attachments/157859722/image2020-1-24_11-14-11.png](assets/images/download/attachments/157859722/image2020-1-24_11-14-11.png)

A barra de ferramentas permite exportar dados geométricos do **CAXA 3D™** para o sistema CAM. É possível consultar a versão do sistema CAD suportado. [Detalhes](10039.md)

![images/download/attachments/157859722/image2025-4-11_12-16-51.png](assets/images/download/attachments/157859722/image2025-4-11_12-16-51.png)

Após a instalação, a barra de ferramentas pode não aparecer no **CAXA 3D™**. Nesse caso, clique em

![images/download/attachments/157859722/IronCADBtmAppAddin.png](assets/images/download/attachments/157859722/IronCADBtmAppAddin.png)

na caixa de diálogo para ativá-la:

Extensões de arquivo suportadas: ICS, IC3D, ICSW, EXB. O aplicativo necessário (**CAXA 3D™**) deve estar instalado no computador para que esta opção funcione.
