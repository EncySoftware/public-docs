# CAXA 3D™-Symbolleiste

![images/download/attachments/157859722/image2020-1-24_11-14-11.png](assets/images/download/attachments/157859722/image2020-1-24_11-14-11.png)

Mit der Symbolleiste können Sie geometrische Daten aus <strong>CAXA 3D™</strong> in das CAM-System exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859722/image2025-4-11_12-16-51.png](assets/images/download/attachments/157859722/image2025-4-11_12-16-51.png)

Nach der Installation wird die Symbolleiste möglicherweise nicht in <strong>CAXA 3D™</strong> angezeigt. Klicken Sie in diesem Fall auf die folgende Schaltfläche

![images/download/attachments/157859722/IronCADBtmAppAddin.png](assets/images/download/attachments/157859722/IronCADBtmAppAddin.png)

und aktivieren Sie die Symbolleiste im Dialogfenster:

Unterstützte Dateierweiterungen: ICS, IC3D, ICSW, EXB. Damit diese Option funktioniert, muss die erforderliche Anwendung (<strong>CAXA 3D™</strong>) auf Ihrem Computer installiert sein.
