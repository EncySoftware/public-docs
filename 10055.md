# Barra degli strumenti CAXA 3D™

![images/download/attachments/157859722/image2020-1-24_11-14-11.png](assets/images/download/attachments/157859722/image2020-1-24_11-14-11.png)

La barra degli strumenti consente di esportare i dati geometrici da <strong>CAXA 3D™</strong> al sistema CAM. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859722/image2025-4-11_12-16-51.png](assets/images/download/attachments/157859722/image2025-4-11_12-16-51.png)

Una volta installata, la barra degli strumenti potrebbe non comparire in <strong>CAXA 3D™</strong>. In tal caso è necessario premere

![images/download/attachments/157859722/IronCADBtmAppAddin.png](assets/images/download/attachments/157859722/IronCADBtmAppAddin.png)

nella finestra di dialogo per attivarla:

Estensioni di file supportate: ICS, IC3D, ICSW, EXB. Affinché questa opzione funzioni, l'applicazione richiesta (<strong>CAXA 3D™</strong>) deve essere installata sul computer.
