# Refazer visualização

O recurso <strong>Redo View</strong> permite restaurar os parâmetros da viewport ativa (escala, vetor de visualização etc.) para o estado que foi descartado anteriormente pelo recurso [Desfazer visualização](358.md). Para ativá-lo, use o <strong>menu pop-up</strong> da janela gráfica.
