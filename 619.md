# Flächen triangulieren

Das Fenster **Surface triangulation** (Flächen triangulieren) wird über das Kontextmenü des [Grafikfensters](45.md) oder die Schaltfläche ![Triangulieren](assets/images/download/thumbnails/157859899/image2024-7-3_16-14-35.png) geöffnet.

Die Funktion ermöglicht die Anpassung der Toleranz für die Darstellung ausgewählter Flächen als Dreiecksnetze. Sie wird verwendet, wenn die Bearbeitungstoleranz kleiner als die Toleranz der Fläche ist oder Fehler in der Modellkonstruktion die Bearbeitung verhindern, beispielsweise verdrehte Übergänge oder nadelförmige Flächen.

![images/download/attachments/157859899/image2024-7-3_16-14-47.png](assets/images/download/attachments/157859899/image2024-7-3_16-14-47.png)

Der Bereich **Source data** (Ausgangsdaten) zeigt Typ und Anzahl der zur Triangulation ausgewählten Objekte sowie weitere Ausgangsdaten.

- **Object name (Objektname).** Name des erzeugten Flächennetzes. Entstehen mehrere Netze, werden sie in einer neuen Gruppe mit diesem Namen abgelegt. Das neue Netz oder die Gruppe wird in der aktuell aktiven Gruppe erstellt.

- **Faces (Flächen).** Anzahl der ausgewählten Flächen.

- **Tolerance (Toleranz).** Maximale Abweichung des Ergebnisses von der Ausgangsfläche. Durch Anpassen dieses Werts legen Sie die gewünschte Genauigkeit fest.

Der Bereich **Result** (Ergebnis) zeigt Anzahl und Typ der neu erstellten Objekte. Bei komplexen Objekten kann die Triangulation länger dauern; in diesem Fall wird der Fortschritt gegebenenfalls in Prozent angezeigt.

- **Meshes (Netze).** Anzahl erzeugter Netze.
- **Triangles (Dreiecke).** Gesamtzahl der Dreiecke in den Netzen.

Wenn Sie die Triangulationstoleranz ändern, werden die Werte im Bereich **Result** automatisch neu berechnet.

**Delete sources (Ausgangsobjekte löschen).** Ist diese Option aktiviert, werden nach Abschluss der Triangulation alle Ausgangsobjekte gelöscht.

Wenn das Ergebnis den Anforderungen entspricht, schließen Sie das Fenster mit **OK**. Die erzeugten Netze werden in der [aktiven Gruppe](1.md) abgelegt. Die Ausgangsobjekte werden gelöscht, wenn **Delete sources** aktiviert ist.

Zum Abbrechen klicken Sie auf **Cancel** (Abbrechen).
