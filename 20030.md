# Block parameterization

Create a block and open it for editing. Set **Name** for the required dimensions; the field is available only in the block editor. A parameter name is one word containing letters, digits and `_`. Identical names define one parameter; its value must be greater than zero.

After saving the block, its parameters are available for editing in the insert inspector.

## Parameters and variables

**Formula.** An expression defining the parameter value.

**Hide in insert.** Hides the parameter in the insert.

**Hide on drawing in inserts.** Hides the corresponding dimension in block inserts on the sketch.

**Variables.** A block can contain **Number**, **Text** or **List** variables. **Caption** sets the displayed label. Separate list values with `;`. **Add** and **Delete** change the variable set.

**Test parameters.** Tests the block with specified values. **Keep as default** stores the tested values as defaults; **Restore** restores the default values.
