# Relatório de usinagem

O sistema contém um recurso integrado de relatório de usinagem. O relatório de usinagem resultante pode ser editado em qualquer editor de texto compatível com o formato .odt. O documento do relatório resultante pode ser salvo no formato <strong>ODT</strong> ou <strong>PDF</strong> (o PDF requer conexão com a Internet). O aplicativo para abrir o relatório de usinagem resultante é definido na janela de configuração.

Clique no botão ![images/download/thumbnails/157861216/image2024-7-4_17-4-23.png](assets/images/download/thumbnails/157861216/image2024-7-4_17-4-23.png) na guia Machining para abrir a janela de geração do **Machining report**.

![images/download/attachments/157861216/image2024-7-4_17-4-42.png](assets/images/download/attachments/157861216/image2024-7-4_17-4-42.png)

Por padrão, a maior parte da janela do relatório de usinagem é ocupada pela lista de modelos da pasta padrão. É possível selecionar vários modelos e gerar os relatórios com um único clique.

Na parte direita da janela estão os botões de controle para adicionar/remover modelos adicionais da lista e alterar a pasta padrão de modelos.

<strong>Save as PDF</strong> - altera o formato do relatório de saída para PDF (é necessária conexão com a Internet);

<strong>Expert mode</strong> - expande a janela para o modo completo, usado para criar/editar modelos de relatório ou ajustar alguns parâmetros do relatório.

![images/download/attachments/157861216/image2024-7-4_17-9-40.png](assets/images/download/attachments/157861216/image2024-7-4_17-9-40.png)

A janela completa do relatório de usinagem contém os seguintes elementos:

1 - Árvore com as informações do projeto que podem ser usadas para relatórios;

2 - Lista de parâmetros do item selecionado. Esse painel mostra os parâmetros do item selecionado que podem ser usados para a saída no relatório. (Usado para a criação de modelos);

3 - Os botões de controle para criar/modificar um modelo de relatório;

- ![images/download/thumbnails/157861216/image2023-8-18_19-6-22.png](assets/images/download/thumbnails/157861216/image2023-8-18_19-6-22.png) - cria o comando para inserir no modelo um parâmetro simples;

- ![images/download/thumbnails/157861216/image2023-8-18_19-6-40.png](assets/images/download/thumbnails/157861216/image2023-8-18_19-6-40.png) - cria o comando para inserir no modelo um parâmetro a ser exibido como matriz;

- ![images/download/thumbnails/157861216/image2023-8-18_19-7-12.png](assets/images/download/thumbnails/157861216/image2023-8-18_19-7-12.png) - menu com comandos adicionais;

- ![images/download/thumbnails/157861216/image2023-8-18_19-7-24.png](assets/images/download/thumbnails/157861216/image2023-8-18_19-7-24.png) - adiciona um parâmetro personalizado;

- ![images/download/thumbnails/157861216/image2023-8-18_19-22-54.png](assets/images/download/thumbnails/157861216/image2023-8-18_19-22-54.png) - remove um parâmetro personalizado;

4 - Botões de controle para ajustar as imagens exibidas no relatório.

O sistema seleciona automaticamente a vista e cria as cotas. As cotas podem ser mostradas somente nas vistas superior, inferior, esquerda, direita, frontal e traseira. São mostradas três distâncias até a origem e três dimensões totais.

5 - A janela gráfica principal, que mostra a imagem do item selecionado na árvore;

6 - Os botões de controle para criar/modificar modelos de relatório;

7 - Painel que define as opções dos desenhos. O desenho pode conter o bruto, o modelo de origem, o percurso da ferramenta, a origem e os eixos. Esses objetos aparecem quando os botões correspondentes do painel são pressionados;

8 - Lista de modelos.

Selecione os modelos na lista e clique em ![images/download/attachments/157861216/image2024-7-4_17-11-44.png](assets/images/download/attachments/157861216/image2024-7-4_17-11-44.png) para criar os relatórios de usinagem. O aplicativo para abrir o documento resultante é definido na janela de configuração (para o formato ODT).

<strong>Observação</strong>: <em>Se o documento for usado posteriormente, ele deverá ser salvo manualmente.</em>

## Criação/modificação de relatórios de usinagem.

Os relatórios podem ser criados usando uma variedade de modelos, oferecendo flexibilidade na formatação e no conteúdo.

O modelo é elaborado diretamente em um editor compatível com o formato ODT.

As variáveis para substituição são definidas somente no objeto de nota.

Para inserir uma variável, especifique o caminho completo até ela na estrutura do arquivo stcx. Para isso, use os botões de controle (partes 3 e 6 na imagem da janela completa).

Por exemplo, para exibir no relatório o valor do tipo de operação, crie uma nota no modelo (Ctrl + Shift + C) e execute a seguinte ação na janela do relatório:

![images/download/attachments/157861216/image2024-7-4_17-14-46.png](assets/images/download/attachments/157861216/image2024-7-4_17-14-46.png)

Como resultado do comando, o valor "Roughing waterline" será exibido no relatório.

Da mesma forma, são exibidos quaisquer outros valores.

O sistema de relatórios permite adicionar variáveis personalizadas aos relatórios usando esta sintaxe.

<strong>VAR</strong> (**Nome da variável**, **Título**, **Valor padrão**).

Exemplo:

<em>VAR (Detail, Detail, Case)</em>

Ao selecionar um modelo, a lista de variáveis disponíveis é exibida na janela RTK.

Uma variável pode ser descrita em qualquer parte do modelo. Formato da chamada da variável:

${Nome da variável}

Exemplo:

<em>$ {Detail}</em>

<em>Todos os comandos e variáveis devem estar somente nos objetos de nota.</em>

Também foram adicionados comandos separados para trabalhar com imagens.

<strong>Usando imagens de exemplo</strong>

Nesse caso, é inserida no documento uma imagem arbitrária, cujas propriedades e formato podem ser ajustados com precisão. Na substituição, a origem da imagem é trocada e as propriedades configuradas anteriormente permanecem inalteradas.

O comando para exibir a imagem é definido (usando o OpenOffice como exemplo) no campo <strong>Name</strong> da guia <strong>Settings</strong>.

Para visualizar as imagens adicionadas ao projeto, clique com o botão direito do mouse na janela gráfica e selecione <strong>Project Views</strong> no menu.

<strong>Add current view</strong> - forma a imagem de acordo com a vista atual e a adiciona à lista de imagens do projeto

<strong>Add from clipboard</strong> - cola a imagem da área de transferência e a adiciona à lista de imagens do projeto.

As imagens já adicionadas podem ser visualizadas e excluídas.

Ao excluir imagens, não ocorre deslocamento dos índices.

![images/download/attachments/157861216/image2024-7-4_17-16-56.png](assets/images/download/attachments/157861216/image2024-7-4_17-16-56.png)

Para entender melhor os princípios do trabalho com esse tipo de modelo, recomenda-se analisar os exemplos fornecidos na distribuição do software e explorar as lições incluídas sobre a criação de relatórios de usinagem.
