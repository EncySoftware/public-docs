# Transformationen

![images/download/attachments/157862731/image2024-3-25_11-51-57.png](assets/images/download/attachments/157862731/image2024-3-25_11-51-57.png)

<a id="application-area-1"></a>

## Anwendungsbereich:

Diese Operationsparameter ermöglichen Koordinatentransformationen der berechneten Werkzeugbahn.

<a id="main-settings-1"></a>

## Grundeinstellungen:

<a id="part-copying-1"></a>

### Bauteilkopien.

Ausgabeart für die Bearbeitung anhand eines Prototypbauteils.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Copying method (Kopiermethode).** Ausgabe des Bearbeitungscodes für eine Bauteilkopie.

**Using real copies.** Gibt die kopierten Bahnen als vollständige Befehlsfolgen aus.

**Using subroutines.** Verwendet Unterprogramme.

**Default.** Verwendet vollständige Kopien.

</details>

<a id="multiply-toolpath-by-axis-1"></a>

### Werkzeugbahn über eine Achse vervielfältigen.

Wiederkehrende Modellbereiche müssen nur einmal programmiert werden. Anzahl und Ausrichtung der Wiederholungen werden anschließend festgelegt. Diese Funktion verwendet die physischen Maschinenachsen.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Machining order (Bearbeitungsreihenfolge).**

**Consistently (Fortlaufend).** Ordnet die Kopien kreisförmig mit vorgegebener Anzahl und Winkelschritt an.

**Multiply Step.** Abstand bzw. Winkelschritt in der Einheit der gewählten Achse.

**Multiply Count.** Anzahl der Wiederholungen.

**Most distant (Größter Abstand).** Kreisförmige Anordnung mit vorgegebener Anzahl und Winkelschritt. Die Reihenfolge bevorzugt möglichst weit voneinander entfernte Elemente.

**Manually (Manuell).** Kreisförmige Anordnung mit individuell vorgegebenen Winkeln.

**Steps.** Anzahl der Wiederholungen mit eigenen Winkelwerten.

**Angle1..N.** Winkel der jeweiligen Wiederholung.

**Formalize as subroutine.** Gibt den wiederholten Block als Unterprogramm aus. Der Name kann zusätzlich festgelegt werden. Ohne diese Option wird der Block für jede Wiederholung mit umgerechneten Koordinaten in CLData eingefügt.

</details>

<a id="multiply-scheme-1"></a>

### Vervielfältigungsmuster.

Mit **Multiply scheme** wird die Bahn eines programmierten Elements über ein Muster auf weitere gleichartige Elemente übertragen. Anzahl und räumliche Anordnung werden im Muster definiert.

<details>
<summary>Weitere Informationen anzeigen</summary>

**None.** Keine Vervielfältigung.

**Two dimensional array.** Zweidimensionale Anordnung.

![images/download/attachments/157862731/%28Two_dimensional_array%29.png](assets/images/download/attachments/157862731/(Two_dimensional_array).png)

**Two dimensional array (manually).** Zweidimensionale Anordnung mit frei festgelegten Elementpositionen.

![images/download/attachments/157862731/%28Two_dimensional_array%29_manually.png](assets/images/download/attachments/157862731/(Two_dimensional_array)_manually.png)

**Round array.** Kreisförmige Anordnung mit fortlaufender Bearbeitungsreihenfolge.

![images/download/attachments/157862731/%28Round_array%29.png](assets/images/download/attachments/157862731/(Round_array).png)

**Round array (most distant).** Kreisförmige Anordnung; das nächste Element wird möglichst weit von der aktuellen Position gewählt.

![images/download/attachments/157862731/%28Round_array%29_most_distant.png](assets/images/download/attachments/157862731/(Round_array)_most_distant.png)

**Round array (manually).** Kreisförmige Anordnung mit eigenem Winkel für jedes Element.

![images/download/attachments/157862731/%28Round_array%29_manually.png](assets/images/download/attachments/157862731/(Round_array)_manually.png)

**Level array.** Kopiert die Bahn entlang der Werkzeugachse.

![images/download/attachments/157862731/%28Level_array%29.png](assets/images/download/attachments/157862731/(Level_array).png)

**Axis symmetry.** Spiegelung an einer Achse.

![images/download/attachments/157862731/Axis_simmetry.png](assets/images/download/attachments/157862731/Axis_simmetry.png)

**Point symmetry.** Punktspiegelung.

![images/download/attachments/157862731/Point_simmetry.png](assets/images/download/attachments/157862731/Point_simmetry.png)

![images/download/attachments/157862731/image2024-1-16_16-43-25.png](assets/images/download/attachments/157862731/image2024-1-16_16-43-25.png) ![images/download/attachments/157862731/image2024-1-16_16-43-35.png](assets/images/download/attachments/157862731/image2024-1-16_16-43-35.png)

**Base coordinate system.** Bezugssystem der Transformation: Tool CS, Workpiece CS, Global CS oder ein zuvor erstelltes Geometriekoordinatensystem. Zusätzliche Verschiebung und Drehung werden unter Additional transformation festgelegt.

**Additional transformation.** Zusätzliche Achsversätze.

</details>

<a id="rotary-transformations-1"></a>

### Rotationstransformationen.

Ersetzen bei der 3-Achsen-Fräsbearbeitung eine lineare Werkzeugbewegung durch eine Werkstückdrehung, sofern die Maschine dies ermöglicht.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Polar.** Ersetzt eine Linearachse durch eine Drehachse, beispielsweise beim Fräsen mit angetriebenen Werkzeugen auf einer Drehmaschine. Übliche Achsen sind X, Z und die Spindeldrehung C. [Details](10083.md)

![images/download/thumbnails/157862731/image2024-5-14_11-49-37.png](assets/images/download/thumbnails/157862731/image2024-5-14_11-49-37.png)

**Rotary axis.** Drehachse, die eine Linearachse ersetzt, beispielsweise Spindel oder Rundtisch.

**Radial Coordinate.** Linearachse senkrecht zur Werkstückdrehachse.

**Axial Coordinate.** Linearachse entlang der Werkstückdrehachse.

**Negative Radial Coordinate, aktiviert:** Gibt die Radialkoordinate mit positivem Vorzeichen aus.

**Deaktiviert:** Gibt die Radialkoordinate mit negativem Vorzeichen aus.

**CNC interpolation, aktiviert:** Gibt Steuerungsbefehle zum Ein- und Ausschalten der CNC-Interpolation aus. Die Steuerung führt die Koordinatentransformation durch.

**Deaktiviert:** Das CAM-System berechnet die Bahn direkt für Radial- und Drehachse.

**Rapid Motions.** Ausgabeart für Leerbewegungen innerhalb des Interpolationsblocks: G0 oder G1.

**Fast feed.** Verwendet Geradeninterpolation **G1** für Leerbewegungen im Interpolationsblock.

**Rapid feed.** Verwendet Positionierung **G0** für Leerbewegungen im Interpolationsblock.

**Fast feed.** Vorschubwert bei **Rapid Motions = Fast Feed**.

**Start from C=0, aktiviert:** Positioniert die Drehachse vor dem Einschalten der Interpolation auf null.

**Deaktiviert:** Wählt vor dem Einschalten eine geeignete Drehachsposition. Einige vor 2023 erstellte Postprozessoren unterstützen diese Option nicht. Wenden Sie sich in diesem Fall an den Postprozessoranbieter oder verwenden Sie die Nullposition.

**Tolerance.** Zulässige Abweichung der transformierten Bahn von der idealen Bahn in Millimetern bzw. Zoll.

**Cylindrical.** Bearbeitet Zylindermantelflächen anhand abgewickelter Kurven. Die programmierten [X,Y,Z]-Koordinaten werden in [X,C,Z] umgerechnet. [Details](10082.md)

![images/download/thumbnails/157862731/image2024-5-14_11-49-57.png](assets/images/download/thumbnails/157862731/image2024-5-14_11-49-57.png)

Ein Teil der Parameter entspricht der polaren Interpolation.

Für zylindrische Interpolation muss auf der Auftragsseite ein Zylinder als Grundfläche festgelegt und die Interpolation aktiviert werden.

**Off.** Keine Rotationstransformation.

</details>
