# Rhinoceros™: Symbolleiste und Import-Add-in

![images/download/attachments/157859652/image2018-12-26_14-31-4.png](assets/images/download/attachments/157859652/image2018-12-26_14-31-4.png)

Mit der Symbolleiste können Sie geometrische Daten aus Rhinoceros™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859652/image2022-3-30_12-25-26.png](assets/images/download/attachments/157859652/image2022-3-30_12-25-26.png)

Mit dem Add-In können Sie <strong>Rhinoceros™</strong>-Projektdateien importieren.

Unterstützte Dateierweiterungen: 3DM, RWS, 3DS, STP, STEP, RAW, WRL, VRML, AI, EPS, LWO, SPL, VDA, DWG, DXF, DGN, SLDPRT, SLDASM. Damit diese Option funktioniert, muss die erforderliche Anwendung (<strong>Rhinoceros™</strong>) auf Ihrem Computer installiert sein. Die Anwendung <strong>Rhinoceros™</strong> muss mindestens einmal ausgeführt und geschlossen werden, damit die Daten in der Registrierung aufgezeichnet werden. Andernfalls kann die Symbolleiste nicht installiert werden.
