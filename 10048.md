# Barra de ferramentas e suplemento de importação do Rhinoceros

![images/download/attachments/157859652/image2018-12-26_14-31-4.png](assets/images/download/attachments/157859652/image2018-12-26_14-31-4.png)

A barra de ferramentas permite exportar dados geométricos do Rhinoceros™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859652/image2022-3-30_12-25-26.png](assets/images/download/attachments/157859652/image2022-3-30_12-25-26.png)

O suplemento permite importar arquivos de projeto do **Rhinoceros™**.

Extensões suportadas: 3DM, RWS, 3DS, STP, STEP, RAW, WRL, VRML, AI, EPS, LWO, SPL, VDA, DWG, DXF, DGN, SLDPRT, SLDASM. O **Rhinoceros™** deve estar instalado no computador para que o recurso funcione. Antes de instalar a barra de ferramentas, abra e feche o Rhinoceros™ pelo menos uma vez para que seus dados sejam gravados no Registro do Windows. Caso contrário, a instalação da barra de ferramentas não será possível.
