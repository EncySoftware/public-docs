# Schweißen

![images/download/attachments/157866487/WeldingBox.png](assets/images/download/attachments/157866487/WeldingBox.png)

Für Schweißanlagen steht eine [universelle 5D-Schweißoperation](10271.md) zur Verfügung. Sie berechnet die Nahtgeometrie unabhängig vom Schweißverfahren und erzeugt keine gerätespezifischen Befehle für Laser, Lichtbogen, Gasbrenner oder Ultraschall.

Die aktive Maschine bzw. der Roboter muss Schweißen unterstützen. Aktivieren Sie dazu in den Einstellungen der Werkzeugaufnahme das entsprechende Kontrollkästchen.

![images/download/attachments/157866487/image2024-7-17_17-38-51.png](assets/images/download/attachments/157866487/image2024-7-17_17-38-51.png)

Alternativ kann die Werkzeugaufnahme im Maschinenschema entsprechend definiert werden:

```
<SCType ID="WeldingToolHolder" Caption="Welding tool holder" Type="TToolHolderNode">
<SupportedToolTypes>
<Welder DefaultValue="true"/>
</SupportedToolTypes>
</SCType>
```

Die Anpassung an eine konkrete Anlage erfolgt über Postprozessorbefehle oder über eine spezialisierte, von Welding 5D abgeleitete Operation.
