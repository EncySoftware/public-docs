# Alteração das propriedades visuais

O botão ![images/download/attachments/157859796/visibility_button.jpg](assets/images/download/attachments/157859796/visibility_button.jpg) permite gerenciar a visibilidade dos objetos selecionados na tela. Quando pressionado, se um grupo for selecionado e pelo menos um objeto do grupo estiver visível, todos os subgrupos e objetos geométricos do grupo ficarão invisíveis.

O botão ![images/download/attachments/157859796/color_select_button.jpg](assets/images/download/attachments/157859796/color_select_button.jpg) permite redefinir a cor dos objetos selecionados. Quando esse botão é pressionado, a caixa de diálogo de seleção de cores padrão é aberta.

As propriedades visuais dos objetos também podem ser alteradas na [janela de propriedades](57.md).
