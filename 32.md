# Changing visual properties

The ![images/download/attachments/157859796/visibility_button.jpg](assets/images/download/attachments/157859796/visibility_button.jpg) button allows the user to manage the visibility of the selected objects on the screen. When pressed, if a group is selected and at least one object of the group is visible, then all subgroups and geometrical objects of the group become invisible.

The ![images/download/attachments/157859796/color_select_button.jpg](assets/images/download/attachments/157859796/color_select_button.jpg) button allows the user to redefine the color of the selected objects. When this button is pressed, the standard color selection dialogue opens.

Visual properties of objects can be also changed in the [properties window](57.md).
