# Exportação para DXF

Os objetos geométricos do sistema CAM podem ser exportados para o arquivo no formato DXF. Na versão atual, só é permitida a exportação de [curvas e pontos](283.md). As splines são usadas para salvar o [texto](617.md) criado no sistema CAM. Os contornos da [geometria 2D](833.md) são salvos no plano XY, independentemente da orientação real dos [sistemas de coordenadas locais](753.md).
