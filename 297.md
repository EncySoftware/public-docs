# DXF export

The geometrical objects of CAM system can be exported into the DXF format file. [Curves and points](283.md) export only is allowed in the current version. The splines are used to save the [text](617.md) that was created in CAM system. Contours of [2D geometry](833.md) are saved in the XY-plane irrespective of the real orientation of the local [coordinate systems](753.md).
