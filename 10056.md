# Barra degli strumenti KeyCreator™

![images/download/attachments/157859743/image2021-7-28_15-37-29.png](assets/images/download/attachments/157859743/image2021-7-28_15-37-29.png)

La barra degli strumenti consente di esportare i dati geometrici da <strong>KeyCreator™</strong>. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859743/image2022-3-30_16-7-50.png](assets/images/download/attachments/157859743/image2022-3-30_16-7-50.png)

Estensioni di file supportate: CKD. Affinché questa opzione funzioni, l'applicazione richiesta (<strong>KeyCreator</strong><strong>™</strong>) deve essere installata sul computer.
