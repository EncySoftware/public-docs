# Geometrische Koordinatensysteme

Zur einfacheren Erstellung des Bearbeitungsprozesses können beliebig viele lokale geometrische Koordinatensysteme (CS) angelegt werden.

![images/download/attachments/157858574/image2024-7-1_16-49-53.png](assets/images/download/attachments/157858574/image2024-7-1_16-49-53.png)

Diese Systeme erleichtern die Arbeit mit der Geometrie, beispielsweise das [Zeichnen einer Kontur](833.md) in einer beliebigen Ebene oder das Prüfen von Objektabmessungen. Sie können auch für Operationsparameter verwendet werden, etwa das [Werkstückkoordinatensystem](10068.md), das [lokale Koordinatensystem](726.md), eine Drehachse oder die Ebene für die [Vervielfältigung des Werkzeugwegs](10168.md).

Das **Panel zur Verwaltung der Koordinatensysteme** befindet sich im unteren Bereich des Hauptfensters.

![images/download/attachments/157858574/image2024-7-2_16-9-15.png](assets/images/download/attachments/157858574/image2024-7-2_16-9-15.png)

Zu jedem Zeitpunkt kann nur ein Koordinatensystem **aktiv** sein. Sein Name wird im Panel angezeigt. Einige Funktionen berücksichtigen dieses aktive System, beispielsweise die Anzeige der Gesamtabmessungen geometrischer Objekte oder die Initialisierung einer neuen Skizzenebene.

Klicken Sie auf den Namen im Panel, um die Liste der Koordinatensysteme zu öffnen und ein anderes System zu aktivieren.

Die Schaltfläche neben dem Namen besitzt ein Dropdown-Menü mit folgenden Aktionen:

- ![Dialog zum Erstellen öffnen](assets/images/download/thumbnails/157858574/image2019-1-11_17-29-10.png) **[Create new CS dialog...](402.md)** öffnet ein Fenster zur direkten Eingabe der Parameter eines neuen Koordinatensystems. Ist ein geometrisches Element ausgewählt, wird stattdessen die [intelligente Koordinatensystemerstellung](10007.md) gestartet.
- ![Ursprung und Achsen](assets/images/download/thumbnails/157858574/image2019-1-11_17-30-14.png) **[Create new CS by starting point, X and Y axes](271.md)** definiert das neue System interaktiv durch Auswahl des Ursprungspunkts und zweier Richtungsvektoren für X und Y.
- ![Ursprung und Blickrichtung](assets/images/download/thumbnails/157858574/image2019-1-11_17-30-45.png) **[Create new CS by starting point and current view vector](805.md)** definiert das neue System interaktiv durch Auswahl des Ursprungspunkts und Verwendung der aktuellen Blickrichtung.
- ![Aktives Koordinatensystem löschen](assets/images/download/attachments/157858574/image2019-1-11_17-35-29.png) **Delete active CS** löscht das aktive Koordinatensystem. Alle darunter aufgeführten Systeme rücken um eine Position nach oben. Das globale Koordinatensystem kann nicht gelöscht werden.
- ![Aktives Koordinatensystem bearbeiten](assets/images/download/thumbnails/157858574/image2019-1-11_17-31-22.png) **[Edit active CS](403.md)** öffnet das Parameterfenster des aktiven Koordinatensystems.
