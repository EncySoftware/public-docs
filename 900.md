# Addin Manager

Addin Manager è un programma progettato per gestire gli [addin](10039.md) del sistema CAM e i traduttori CAD esterni.

È possibile avviare Addin Manager dal sistema CAM, utilizzando la voce di menu nel pannello principale.

Addin

Sequenza di lavoro per installare un add-in: selezionare l'add-in necessario dall'elenco superiore. Premere il pulsante **Install**. Modificare i parametri (facoltativo). Premere il pulsante **Apply** per salvare le modifiche (facoltativo). Premere il pulsante **Close** (facoltativo).

Sequenza di lavoro per disinstallare un add-in:

Selezionare l'add-in necessario dall'elenco superiore. Premere il pulsante **Uninstall**. Premere il pulsante **Close** (facoltativo).

Prima di installare/disinstallare la barra degli strumenti, è necessario chiudere il sistema per il quale verrà installato questo pannello; il programma di installazione lo segnalerà. In caso contrario, l'installazione/disinstallazione verrà annullata.

Gli add-in sono elencati nell'elenco superiore. Quando ne viene selezionato uno, nel pannello **Parameters** vengono visualizzate informazioni aggiuntive. Di solito si tratta del nome e della versione dell'applicazione con cui lavora l'add-in, della descrizione delle funzionalità dell'add-in, ecc. In questo pannello sono presenti anche i parametri modificabili (se esistenti).

Se l'add-in è già installato, è possibile attivarlo/disattivarlo con la casella di controllo **Enabled** senza perdere le modifiche ai suoi parametri predefiniti (la sequenza di pulsanti **Uninstall** **Install** reimposta tutte le modifiche e, di conseguenza, l'add-in verrà installato con i parametri predefiniti).

Il campo **Extensions** (estensioni) è evidenziato solo se l'add-in selezionato supporta diverse operazioni sui file con estensioni (tipi) specifiche, ad esempio l'importazione di file. In questo esempio l'utente può modificare i tipi di file che verranno importati dall'add-in selezionato.

**Default** compila le proprietà con i valori predefiniti per l'add-in selezionato. Ad esempio, se le estensioni dei file sono state modificate, premendo **Default** vengono reimpostate ai valori predefiniti dell'add-in.

**Apply** salva le modifiche per l'add-in selezionato.

**Install** / **Uninstall** – registra/annulla la registrazione dell'add-in selezionato per l'utilizzo.

**Close** – chiude Addin Manager del sistema CAM. Se sono state apportate modifiche, viene visualizzata la finestra di dialogo `Save/No/Cancel`.

**Refresh** – rilegge tutti gli add-in. Nota: tutte le modifiche andranno perse.

**Help** – visualizza questa guida. In alcuni casi, quando le proprietà dell'add-in vengono modificate, è necessario riavviare l'applicazione (host dell'add-in). Ad esempio, dopo l'installazione dell'add-in della barra degli strumenti del sistema CAM per SOLIDWORKS®, SOLIDWORKS® deve essere riavviato. Tutti gli add-in devono trovarsi nella cartella 'Addins' (la cartella di Addin Manager del sistema CAM) e/o nelle sue sottocartelle. Addin Manager del sistema CAM esegue la scansione di tali cartelle per cercare gli add-in e li elenca. È sufficiente collocare un qualsiasi add-in (del sistema CAM o di altra provenienza) in tali cartelle perché sia accessibile a Addin Manager del sistema CAM (premere il pulsante **Refresh** se Addin Manager del sistema CAM è in esecuzione).

Traduttori CAD esterni

È possibile utilizzare Addin Manager per collegare traduttori CAD esterni. Un traduttore CAD è un programma in grado di convertire un formato di file (ad es. CATIA, Pro/E, NX, ecc.) in altri formati nativi del sistema CAM (ad es. IGS, STL, 3DM, ecc.) e che supporta l'interfaccia a riga di comando (ad es. è possibile digitare convert.exe Model.CATIA Model.IGS nella riga di comando e il traduttore genererà un file IGS dal file CATIA). Dopo aver registrato un traduttore CAD in Addin Manager, sarà possibile importare senza difficoltà nel sistema CAM i file CAD supportati dal traduttore.

Quindi, per aggiungere un traduttore CAD esterno al sistema CAM, occorre aprire Addin Manager e fare clic sul pulsante **Add**. Compilare i parametri del traduttore.

![images/download/attachments/157859555/image2024-7-2_17-54-54.png](assets/images/download/attachments/157859555/image2024-7-2_17-54-54.png)

I parametri sono i seguenti: **Name** - questo nome comparirà nella finestra Import, nell'elenco dei formati supportati (ad es. Translator1 (external) (.model.ipt)). **Path** - è il percorso completo dell'eseguibile del traduttore. È possibile compilare questo campo premendo il pulsante con i puntini di sospensione accanto alla casella di testo e raggiungendo l'eseguibile con il normale Esplora file di Windows. **Input extensions** - qui occorre inserire le estensioni dei file di input supportate dal traduttore. Le estensioni devono essere separate da un punto, ad es. model.ipt.step.sat. **Output extension** - in questo campo occorre specificare l'estensione del file di output del traduttore. Deve essere uno dei formati supportati nativamente dal sistema CAM, ad es. IGS, 3dm, STL, STEP, X_T. **Command line** - in questa casella occorre specificare il comando che verrà passato al traduttore. Utilizzare la macro $(InFile) al posto del nome del file di input e la macro $(OutFile) al posto del nome del file di output. Ad es. -i $(InFile) -o $(OutFile)
