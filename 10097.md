# Parâmetros da operação de fresamento FBM

As operações do grupo FBM Mill são as operações especiais FBM Mill.

Uma operação FBM Mill permite usinar, em uma única operação, features situadas em planos diferentes, de tipos diferentes e até com ciclos de usinagem diferentes, desde que os ciclos usem a mesma ferramenta. A operação oferece as seguintes opções para gerar um percurso da ferramenta eficiente e sem colisões.

<strong>Métodos de ordenação das features</strong>

- By List,
- Optimal,
- Group by plane.

<strong>Métodos de processamento de features idênticas</strong>

- Independent,
- Copy,
- Formalize As Subroutine.

<strong>Sistemas de coordenadas locais das features</strong>

<strong>Métodos de transição entre percursos da ferramenta</strong>

- Short,
- Orthogonal,
- Via Safe Surface.
