# Parameter einer FBM-Mill-Operation

Die Operationen innerhalb einer FBM-Mill-Gruppe sind spezielle FBM-Fräsoperationen.

Eine FBM-Fräsoperation kann Merkmale in unterschiedlichen Ebenen, verschiedene Merkmalstypen und unterschiedliche Bearbeitungszyklen in einer Operation zusammenfassen, sofern sie dasselbe Werkzeug verwenden. Für die Werkzeugwegerzeugung stehen folgende Optionen zur Verfügung.

**Sortierverfahren für Merkmale**

- **By List (Nach Liste)**;
- **Optimal (Optimiert)**;
- **Group by plane (Nach Ebene gruppieren)**.

**Bearbeitung identischer Merkmale**

- **Independent (Unabhängig)**;
- **Copy (Kopieren)**;
- **Formalize As Subroutine (Als Unterprogramm ausgeben)**.

**Verbindungsbewegungen zwischen Werkzeugwegen**

- **Short (Kurz)**;
- **Orthogonal (Orthogonal)**;
- **Via Safe Surface (Über Sicherheitsfläche)**.
