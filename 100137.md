# Distances

**Distances** define the clearances and levels used during tool approaches, retracts, and links between working passes. Depending on the operation type, these parameters determine where the tool switches between rapid motion and feed motion, how far it retracts, and how linking moves are positioned relative to the workpiece.

This section explains the distance settings available for 3D machining, face milling, roughing waterline, advanced 3D/5D operations, and drilling. Refer to the corresponding topic to check how each distance is measured and how it affects the toolpath.
