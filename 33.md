# Estrutura do modelo geométrico

![images/download/attachments/157859176/image2024-7-2_16-19-27.png](assets/images/download/attachments/157859176/image2024-7-2_16-19-27.png)

Um modelo geométrico no sistema CAM é representado como uma árvore de pastas. Diferentes objetos geométricos são agrupados nas pastas. O trabalho com a estrutura do modelo geométrico é semelhante ao trabalho com a estrutura de arquivos usada no sistema operacional Windows.

<em>Observação: de acordo com a maioria dos sistemas de arquivos, todos os objetos dentro de um grupo devem ter nomes diferentes. Não é permitida a presença de vários objetos com o mesmo nome.</em>

A maioria das funções para a edição do modelo é encontrada na janela de estrutura do modelo geométrico. Ao criar um novo projeto, as pastas principais do modelo geométrico são geradas automaticamente. O **Modelo completo** está contido nessas pastas predefinidas: **Part**, **Workpiece**, **Fixtures**.

A pasta **Part** é a peça produzida para a sequência de usinagem completa por padrão. Portanto, recomenda-se importar e transferir para o grupo de modelos os objetos geométricos que definem a peça final produzida.

O modelo de bruto de forma livre deve ser colocado na pasta **Workpiece**. Se forem usados brutos de forma simples (caixa etc.), essa pasta deve ser deixada vazia.

A pasta **Fixtures** é destinada a modelos de grampos, apoios, morsas e outros dispositivos de fixação e equipamentos de usinagem.
