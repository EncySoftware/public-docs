# Importieren von Objekten aus PLY-Dateien

PLY ist ein Dateiformat, das auch als Polygon File Format oder Stanford Triangle Format bezeichnet wird. Es wurde vor allem zur Speicherung dreidimensionaler Daten von 3D-Scannern entwickelt.
