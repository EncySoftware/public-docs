# Modo de sequenciamento

## Área de aplicação:

As operações dentro do grupo de uma peça definem a sequência de usinagem apenas dessa peça. Na prática, elas definem o material residual do bruto para cada operação seguinte. Se o projeto contiver mais de uma peça, a sequência real de usinagem pode ser redefinida, por exemplo, para minimizar as trocas de ferramenta ou as rotações da torre de fixação (tombstone). Use o botão no painel principal para ativar o modo de sequenciamento. Nesse modo, é exibida a árvore de operações <strong>reordenada</strong>.

Por padrão, as operações são ordenadas automaticamente para minimizar as trocas de ferramenta. É possível alterar a ordem de usinagem manualmente, <strong>arrastando e soltando</strong> ou com os botões de seta do painel de sequenciamento. O <strong>botão de seta</strong> move a operação selecionada para antes/depois da operação anterior/seguinte. O <strong>botão Sort</strong> restaura a ordenação automática. As regras da ordenação automática são definidas no menu suspenso ao lado.

As ligações entre as operações não podem ser calculadas antes de definida a ordem real de usinagem. Por isso, o cálculo das ligações foi separado do processo de cálculo principal. O fluxo de trabalho completo para projetos com várias peças inclui as seguintes etapas:

- Posicionamento das peças no espaço de trabalho da máquina.
- Elaboração do processo de usinagem de cada peça. Cálculo do percurso da ferramenta sem as ligações (aproximações e retornos).
- Simulação do processo com o modo de sequenciamento desativado, para verificar a correção da troca do bruto etc.
- Reordenação das operações no <strong>modo de sequenciamento.</strong>
- Cálculo das ligações entre as operações.
- Simulação do processo no modo de sequenciamento para verificar as ligações e as trocas de ferramenta entre as operações.
- Geração do percurso da ferramenta.

## Elementos principais:

### Ordenar.

Este botão ordena automaticamente as operações com determinadas prioridades. <strong>A prioridade de ordenação é definida pela posição dos grupos na lista</strong>

<details>
<summary>Clique aqui para expandir...</summary>

<strong>Ferramenta.</strong> Grupo para ordenar por ferramenta.

<strong>Lado.</strong> Grupo para ordenar por lado.

<strong>Peça.</strong> Grupo para ordenar por peça.

<strong>Elemento.</strong> Grupo para ordenar por elemento da peça.

<strong>Por operações.</strong> Grupo para ordenar por operação.

<strong>Torno suíço.</strong> Grupo para ordenar por operação do tipo suíço.

<strong>Redefinir ordenação.</strong> Redefine a ordenação automática das operações.

<strong>Excluir grupo da árvore.</strong> Se um grupo estiver desativado, ele não é exibido na árvore de ordenação.

<strong>Aumentar prioridade de ordenação.</strong> Aumenta a prioridade.

<strong>Diminuir prioridade de ordenação.</strong> Diminui a prioridade.

</details>

### Mover para cima / Mover para baixo

Usados para a ordenação manual de uma operação específica.

### Ligar.

Calcula as operações selecionadas com ligações. As transições entre as operações são exibidas como linhas.

### Desligar.

Calcula as operações selecionadas sem ligações.
