## Anwendungsbereich:

Als **Fixtures** (Spannmittel) werden üblicherweise Spannfutter, Greifer, Spannpratzen und andere Befestigungsmittel sowie weitere Sperrbereiche definiert. Bei der Werkzeugwegberechnung dienen sie als Modelle, mit denen das Werkzeug während der Bearbeitung nicht kollidieren darf. Sie können aus Volumenkörpern, Flächen und aus Kurven erzeugten Geometrieelementen aufgebaut werden.

Schneidet eine Arbeitsbahn ein Spannmittel, wird der betreffende Bahnabschnitt entfernt und die Bahn bis zur Sicherheitsebene geführt. Dieses Verfahren wirkt ausschließlich auf **Arbeitsbahnen**.

Anders als eine [Bearbeitungsbegrenzung](101231.md) gilt ein Spannmittel für die gesamte [Aufspannung](1024.md).

**Spannmittel** können auf verschiedene Arten definiert werden:

1. Mit den Werkzeugen zur Definition von Bauteil, Rohteil und Begrenzungen. [Details](294.md)
2. Durch Erstellen eines neuen Spannmittels.

Wählen Sie zum Erstellen eine vorhandene Vorlage aus oder erzeugen Sie mit **New node** (Neuer Knoten) ein eigenes Spannmittel.

![images/download/attachments/157862845/image2024-7-18_16-25-21.png](assets/images/download/attachments/157862845/image2024-7-18_16-25-21.png)

Die erstellte Vorlage und ihre Knoten werden im Spannmittelbaum angezeigt.

![images/download/attachments/157862845/image2024-7-18_16-26-34.png](assets/images/download/attachments/157862845/image2024-7-18_16-26-34.png)

**Geometrie**

Wählen Sie zum Hinzufügen von Geometrie einen Spannmittelknoten und klicken Sie auf eine der Geometrieschaltflächen.

![images/download/attachments/157862845/image2024-7-18_16-35-22.png](assets/images/download/attachments/157862845/image2024-7-18_16-35-22.png)

**Knotenparameter einstellen**

Die Knotenparameter werden im Eigenschaftenfenster festgelegt. Dieses öffnen Sie durch Doppelklicken auf einen Baumknoten oder über die Eigenschaftenschaltfläche auf der Hauptleiste der Seite.

![images/download/attachments/157862845/image2024-7-18_16-38-46.png](assets/images/download/attachments/157862845/image2024-7-18_16-38-46.png)

Wesentliche Parameter wie maximale und minimale Position, Richtung und Drehachse können auch mit grafischen Bedienelementen festgelegt werden.

![images/download/attachments/157862845/image2021-4-29_14-24-36.png](assets/images/download/attachments/157862845/image2021-4-29_14-24-36.png)

<a id="working-with-fixtures"></a>

### Mit Spannmitteln arbeiten

**Komponenten einstellen**

Die Position einer Komponente wird mit einem grafischen Bedienelement angepasst.

![images/download/attachments/157862845/image2021-4-29_14-45-10.png](assets/images/download/attachments/157862845/image2021-4-29_14-45-10.png)

Dieses wird durch Doppelklicken auf den Knoten oder durch einfaches Anklicken im Komponentenbearbeitungsmodus ![Komponentenbearbeitung](assets/images/download/thumbnails/157862845/image2021-4-29_14-47-33.png) aufgerufen.

Ein Rechtsklick auf das grafische Bedienelement öffnet das Panel ![Komponentenaktionen](assets/images/download/thumbnails/157862845/image2021-4-29_14-53-34.png). Dort können Komponenten kopiert und gelöscht werden.

**Zuordnung zu Koordinatensystemen**

Ist das Spannmittel in einer Maschineneinheit definiert, ist es einer bestimmten Aufspannung zugeordnet und bewegt sich mit der Maschine.

![images/download/attachments/157862845/image2024-7-18_16-40-9.png](assets/images/download/attachments/157862845/image2024-7-18_16-40-9.png)

Ist es im Operationsknoten definiert, ist es der aktuellen Aufspannung zugeordnet und kann sich sowohl mit der Maschine als auch mit dem Bauteil bewegen.

**Speichern und Laden**

Ein Spannmittel kann über das Kontextmenü im Komponentenbaum oder über **Save** (Speichern) gespeichert werden.

![images/download/attachments/157862845/image2024-7-18_16-41-2.png](assets/images/download/attachments/157862845/image2024-7-18_16-41-2.png)

Zum Laden verwenden Sie das Kontextmenü im Komponentenbaum oder das Dropdown-Menü von **Load** (Laden).

![images/download/attachments/157862845/image2024-7-18_16-41-49.png](assets/images/download/attachments/157862845/image2024-7-18_16-41-49.png)
