# Projeção dos limites de superfícies

O botão ![images/download/attachments/157859868/image2024-7-3_16-12-3.png](assets/images/download/attachments/157859868/image2024-7-3_16-12-3.png) abre a janela **Surfaces boundary projection**. A função é usada para construir projeções envolventes externas das superfícies e malhas selecionadas no plano XY do [sistema de coordenadas](753.md) atual. Além das bordas das superfícies, a função permite projetar curvas comuns no plano. As curvas criadas podem ser usadas na definição de parâmetros das operações de usinagem.

![images/download/attachments/157859868/image2024-7-3_16-12-17.png](assets/images/download/attachments/157859868/image2024-7-3_16-12-17.png)

- **Object name** - o nome da curva resultante. Se várias curvas forem criadas como resultado da projeção, elas serão colocadas em um novo grupo com o nome definido nesse campo. A nova curva ou grupo será criado no [grupo ativo](1.md) no momento.

- **Approximation tolerance** - desvio externo máximo das curvas resultantes em relação às bordas das superfícies. Para curvas comuns, esse valor é usado como tolerância de aproximação por arcos.
- **Stock** - valor do deslocamento das curvas resultantes em relação às bordas das superfícies. Um valor positivo desloca a curva para fora da superfície; um valor negativo, para dentro (equivale à projeção de uma curva equidistante). Para curvas comuns, é construída uma curva deslocada pelo valor do sobremetal.
- **Slit width to ignore** - valor máximo das folgas entre as superfícies que serão ignoradas. Se as superfícies forem unidas com alta precisão, o contorno das superfícies será projetado; se for com baixa precisão, os espaços entre as superfícies vizinhas serão incluídos na curva projetada.

![images/download/attachments/157859868/image175.jpg](assets/images/download/attachments/157859868/image175.jpg) ![images/download/attachments/157859868/image176.jpg](assets/images/download/attachments/157859868/image176.jpg)

O painel **Selected** exibe o tipo e o número de objetos selecionados para a projeção de limites.

- **Faces** - número de superfícies selecionadas.
- **Meshes** - número de malhas selecionadas.
- **Curves** - número de curvas selecionadas.
- **Total** - número total de objetos geométricos selecionados.

O painel **Result** mostra o número de objetos selecionados para a operação de limite projetado e o número de curvas que serão criadas (se os objetos projetados forem muito complexos, o cálculo da projeção poderá levar algum tempo).

- **Curves** - número de curvas obtidas.
- **Processed objects** - número total de objetos processados.

Ao alterar qualquer parâmetro de projeção, os valores no painel **Result** serão automaticamente recalculados.

Se os resultados dos parâmetros definidos estiverem corretos, a janela deverá ser fechada usando o botão **Ok**. A projeção do limite dos objetos selecionados será colocada no [grupo ativo](1.md). Para cancelar a função de projeção, pressione o botão **Cancel**.
