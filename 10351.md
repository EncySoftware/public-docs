# Operação com eventos de script

Uma operação com comandos de percurso controlados por script é criada a partir de uma operação comum do ENCY, usando o editor de scripts.

No painel esquerdo do editor de scripts, selecione a aba **Events Handlers**. Selecione um item na árvore **Objects** para exibir, na árvore **Events**, os eventos disponíveis para esse objeto. Clique duas vezes em um evento para criar o modelo de código do método que será executado quando o ENCY processar esse objeto no percurso da ferramenta. Consulte [IDE de scripts](10348.md) para obter mais informações.
