# Operation with scripted events

Operation with scripted toolpath commands is created from a regular ENCY operation using Scripts Editor.

On Scripts Editor window's Left Panel select Events Handlers tab. Select an item in Objects tree and the Events tree will display available events for that object. Double-clicking on event will create a code template for method that will be executed when ENCY processes that object in toolpath. See [Scripts IDE](10348.md) for more information.
