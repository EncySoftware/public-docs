# Operation mit skriptgesteuerten Ereignissen

Eine Operation mit skriptgesteuerten Werkzeugwegbefehlen wird aus einer gewöhnlichen ENCY-Operation mithilfe des Skripteditors erstellt.

Wählen Sie links im Skripteditor die Registerkarte für Ereignisbehandlungen. Nach Auswahl eines Elements im Objektbaum zeigt **Events** dessen verfügbare Ereignisse. Ein Doppelklick erzeugt eine Methodenvorlage, die beim Verarbeiten dieses Objekts im Werkzeugweg ausgeführt wird. Weitere Angaben: [Skriptentwicklungsumgebung](10348.md).
