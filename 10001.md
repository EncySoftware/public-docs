# Standard package

The boxed package of [ENCY Robot](4.md) ® includes:

1. Physical media containing the [ENCY Robot](4.md) ® system.
2. Documentation (PDF file).
3. Electronic key to prevent unauthorized copying (optional – depends on [configuration](10390.md) and protection method).
4. License agreement.

The e-package of [ENCY Robot](4.md) ® includes:

- Executable file for installing the [ENCY Robot](4.md) ® system.
