# Pacchetto standard

Il pacchetto in confezione di [ENCY](4.md) ® comprende:

1. Supporto fisico contenente il sistema [ENCY](4.md) ®.
2. Documentazione (file PDF).
3. Chiave elettronica per impedire la copia non autorizzata (opzionale – dipende dalla [configurazione](10390.md) e dal metodo di protezione).
4. Contratto di licenza.

Il pacchetto elettronico di [ENCY](4.md) ® comprende:

- File eseguibile per l'installazione del sistema [ENCY](4.md) ®.
