# Standardpaket

Das physische Lieferpaket von [ENCY](4.md) ® umfasst:

1. Einen Datenträger mit dem [ENCY](4.md) ® System.
2. Dokumentation (PDF-Datei).
3. Einen elektronischen Schlüssel zum Schutz vor unbefugtem Kopieren (optional – abhängig von der [Konfiguration](10390.md) und der Schutzmethode).
4. Die Lizenzvereinbarung.

Das elektronische Lieferpaket von [ENCY](4.md) ® umfasst:

- Eine ausführbare Installationsdatei für das [ENCY](4.md) ® System.
