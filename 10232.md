# Linhas de sincronização

Na operação [Wire EDM 2d Contouring](10246.md), as linhas de sincronização são mostradas como dois pontos conectados por uma linha. As linhas de sincronização podem ser usadas para [definir o ângulo de conicidade](10230.md).

Na operação [Wire EDM 4d Contouring](10247.md), além de mover as linhas de sincronização, é possível alterar a posição dos pontos da linha. Para mover a linha, posicione o ponteiro do mouse no meio da linha (2) e, para mover os pontos, posicione o mouse no próprio ponto (1 ou 3).

![images/download/attachments/157865872/ans17clip0001.png](assets/images/download/attachments/157865872/ans17clip0001.png)

As linhas de sincronização podem ser copiadas e excluídas na janela gráfica.

Para copiar, selecione o item e, mantendo pressionados a tecla [Ctrl] e o botão esquerdo do mouse, arraste o item para a posição desejada.

Para excluir um item, selecione-o com um clique e pressione a tecla [Del].

Para criar uma nova linha de sincronização, posicione o ponteiro do mouse sobre um ponto de quebra do elemento da definição da tarefa e arraste a linha criada para a posição desejada.
