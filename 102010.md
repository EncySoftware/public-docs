## Anwendungsbereich:

Der Werkzeugweg nahezu jeder Operation kann in eine **6D Contour**-Operation umgewandelt werden. Der ursprüngliche Werkzeugweg wird dabei zur Auftragszuweisung. So können vor der Postprozessorverarbeitung kleinere Änderungen vorgenommen werden, beispielsweise an der Werkzeugausrichtung.

Klicken Sie mit der rechten Maustaste auf die betreffende Operation und wählen Sie **Convert toolpath to 6D Contour operation**.

Dabei wird auf der Registerkarte **Model** eine Gruppe von **Splines** erstellt.
