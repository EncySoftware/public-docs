<a id="interactive-editing-of-approachreturn"></a>

#### An- und Rückfahrt interaktiv bearbeiten

Im Dialog definieren Sie die An- bzw. Rückfahrbahn einer Operation oder bearbeiten die Regelliste der Maschine. Das Fenster ist in drei Bereiche gegliedert.

1. In der obersten Dropdown-Liste wählen Sie die eigene Regel der Operation oder eine Regel aus der Maschinenliste.

2. In der Mitte steht die Befehlsliste der ausgewählten Regel. Jede Zeile beschreibt einen Bahnpunkt. Beginnt sie mit G53, sind die folgenden Koordinaten Maschinenkoordinaten. Andernfalls beziehen sie sich auf die Werkzeugspitze im aktuellen Werkstückkoordinatensystem. Das Format lautet: Achsname, optionaler Wert in Klammern, Leerzeichen, nächster Achsname usw., beispielsweise `X1` oder `X1(30)`.

Fehlt nach einem Achsnamen ein Wert, berechnet das CAM-System ihn automatisch: Bei der Anfahrt wird er vom ersten Bearbeitungspunkt, bei der Rückfahrt von der Werkzeugwechselposition übernommen. Die Anfahrregel `X Y; A; C; Z` bewegt zuerst X und Y gleichzeitig, dann A, dann C und zuletzt Z. Mit ![Leeren Befehl hinzufügen](assets/images/download/thumbnails/157862452/Plus.png) fügen Sie einen leeren Befehl ein; mit ![Aktuellen Zustand übernehmen](assets/images/download/thumbnails/157862452/AddCurrentCmd4.png) übernehmen Sie die aktuelle Maschinenstellung. Das X-Symbol rechts löscht einen Befehl. Durch Ziehen ändern Sie die Reihenfolge. Ein Doppelklick stellt das Werkzeug entsprechend dem Befehl ein. Über das Kontextmenü oder Tastenkombinationen können Befehle ausgeschnitten, kopiert, eingefügt oder gelöscht werden. **Edit** bzw. **Strg+E** ermöglicht die direkte Textbearbeitung.

![images/download/attachments/157862452/image2024-7-8_16-19-33.png](assets/images/download/attachments/157862452/image2024-7-8_16-19-33.png)

3. Unten befindet sich die Achsliste. Für einen neuen Stützpunkt geben Sie die benötigten Koordinaten ein und/oder setzen einzelne Achsen über die Schaltfläche mit den drei Punkten auf **AUTO**. Zum Ändern eines vorhandenen Punkts wählen Sie ihn oben aus; die Achsliste wird entsprechend aktualisiert.

**Position type** legt den Koordinatenmodus fest. Bei aktivierter Option wird ein G53-Stützpunkt in Maschinenkoordinaten definiert und als PhysicGOTO ausgegeben. Gewöhnliche Stützpunkte beschreiben die Werkzeugspitze im aktuellen Werkstückkoordinatensystem und werden mit GOTO bzw. MULTIGOTO ausgegeben.

Da Achsen ohne ausdrückliche Koordinaten angegeben werden können, lassen sich allgemeine An- und Rückfahrfolgen für eine Maschine definieren. Für eine 5-Achs-Fräsmaschine kann die Anfahrt beispielsweise `XY; A C; Z` und die Rückfahrt `Z; XY; A C` lauten.

Zum Bearbeiten einer Maschinenregel wählen Sie deren Namen in der obersten Dropdown-Liste. Die Befehlsliste wird aktualisiert und kann wie die eigene Operationsregel bearbeitet werden. Im Eingabefeld der Dropdown-Liste lässt sich der Name ändern. Das beim Überfahren eines Eintrags angezeigte X-Symbol löscht die Regel. **Add new machine rule** fügt eine neue leere Maschinenregel hinzu. Mit **Edit operation custom rule..** kehren Sie zur eigenen Operationsregel zurück.
