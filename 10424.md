# Salvamento automático e instantâneos do projeto

O programa possui um sistema de backup automático de projetos que permite reverter qualquer projeto para uma versão anterior caso surjam problemas imprevistos.

O conceito-chave desse sistema é o <strong>instantâneo</strong> (snapshot), que representa o estado completo do projeto em um determinado momento. Cada vez que um projeto é salvo, o sistema gera um instantâneo. O instantâneo mais recente é sempre armazenado no arquivo *.stcp do projeto. Normalmente, o sistema mantém várias versões de backup ao mesmo tempo; os instantâneos mais antigos ficam em um arquivo de backup na subpasta de histórico ao lado do projeto: `projectfolder\__history\projectname.stcp.~back`.

- <strong>projectfolder</strong> é a pasta que contém o projeto atual.
- <strong>projectname</strong> é o nome do projeto atual.

Embora um instantâneo capture o estado completo do projeto, isso não significa que dois instantâneos ocupem o mesmo espaço que dois projetos completos. Ao salvar cada instantâneo subsequente, o sistema grava apenas os dados alterados desde o instantâneo anterior, reduzindo o uso de espaço em disco.

Novos instantâneos são criados em dois casos principais:

1. Quando o usuário salva o projeto manualmente (instantâneos manuais).
2. Quando o sistema salva o projeto automaticamente (instantâneos salvos automaticamente).

Esses dois tipos são gerenciados separadamente, e os salvamentos automáticos nunca substituem os instantâneos salvos manualmente. Ambos são armazenados em paralelo na lista de instantâneos.

As opções de salvamento automático e de instantâneos podem ser configuradas nas [configurações do sistema](715.md).

![images/download/attachments/157858086/AutosaveOptions_En.png](assets/images/download/attachments/157858086/AutosaveOptions_En.png)

O salvamento automático é opcional e pode ocorrer de duas maneiras:

- Por temporizador, em intervalos especificados (de acordo com o intervalo em minutos, se a opção <strong>Autosaves by timer</strong> estiver ativada).
- Em determinados eventos do sistema, por exemplo, antes de excluir uma operação tecnológica, antes do cálculo do percurso da ferramenta, imediatamente após o cálculo do percurso da ferramenta etc. (opção <strong>Autosaves by events</strong> nas configurações do sistema)

Durante um trabalho prolongado no projeto, muitos instantâneos podem se acumular. Para evitar o esgotamento do disco, o programa exclui automaticamente instantâneos quando seu número excede o limite especificado nas configurações do sistema. O sistema considera os instantâneos salvos manualmente mais importantes, por isso é possível definir dois limites diferentes:

- <strong>Manually saved snapshots count</strong>: número máximo de instantâneos salvos pelo usuário (o padrão é 5).
- <strong>Autosaved snapshots count</strong>: número máximo de instantâneos salvos automaticamente por temporizador ou por eventos (o padrão é 15).

Também é possível marcar qualquer instantâneo como <strong>persistente</strong>; nesse caso, ele não será excluído mesmo que o número máximo de instantâneos seja excedido. Os instantâneos persistentes só podem ser excluídos manualmente, o que permite manter versões alternativas do mesmo projeto.

Em projetos grandes, o salvamento pode demorar. Para reduzir as interrupções, o sistema executa salvamentos automáticos somente após um período especificado desde o salvamento anterior, definido pela opção <strong>Interval between long autosaves</strong> (o padrão é 5 minutos). O sistema considera um projeto grande se o último salvamento demorou mais do que o tempo especificado no parâmetro <strong>Long autosave time</strong> (o padrão é 20 segundos). Por exemplo, se o salvamento do instantâneo anterior levou mais de 20 segundos, o próximo salvamento automático ocorrerá no mínimo 5 minutos depois.

A interface permite carregar rapidamente os estados salvos do projeto. A lista de instantâneos é exibida em um menu suspenso ao lado do nome do projeto na lista de projetos recentes da [barra de ferramentas principal](51.md). Os instantâneos são exibidos em ordem cronológica inversa, com o mais recente no topo. O instantâneo atual é destacado em verde. O botão <strong>Pin</strong> permite marcar um instantâneo como persistente, impedindo sua exclusão automática.

![images/download/attachments/157858086/image2024-6-26_17-21-5.png](assets/images/download/attachments/157858086/image2024-6-26_17-21-5.png)

Para manter o menu compacto:

- Para o projeto atual, são exibidos até 10 instantâneos mais recentes, além de todos os persistentes.
- Para os demais projetos, são exibidos somente os instantâneos persistentes.

Para ver mais instantâneos, abra a janela <strong>Project Snapshots Manager</strong>.

![images/download/attachments/157858086/image2023-8-18_12-39-48.png](assets/images/download/attachments/157858086/image2023-8-18_12-39-48.png)

No <strong>Project Snapshots Manager</strong>, é possível:

- Ver a lista completa de instantâneos.
- Editar seus nomes ou descrições.
- Ver uma miniatura.
- Ver o usuário que salvou o instantâneo.
- Consultar a lista de operações associadas a cada instantâneo.
- Excluir instantâneos ou marcá-los como persistentes.
- Carregar um instantâneo.

Ao passar o mouse sobre a data de criação, uma dica de ferramenta exibe a data completa.
