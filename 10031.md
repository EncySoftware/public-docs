# Instalação da biblioteca Ghostscript

A biblioteca Ghostscript é necessária para importar arquivos PostScript. Desenvolvida pela [Artifex Software, Inc.](https://www.ghostscript.com/index.html), ela não é incluída na distribuição do sistema CAM devido a restrições de licenciamento. Pode ser baixada e instalada separadamente para uso pessoal.

O sistema CAM suporta a biblioteca Ghostscript a partir da versão 9.22.

**[Baixar o Ghostscript 9.22](https://github.com/ArtifexSoftware/ghostpdl-downloads/releases/tag/gs922)**

Na página do repositório do GitHub, selecione a versão compatível com o Windows de 64 bits:

*<strong>Nota:</strong> é necessário selecionar o Ghostscript de 64 bits.*

![images/download/attachments/157859509/image2019-3-4_15-35-1.png](assets/images/download/attachments/157859509/image2019-3-4_15-35-1.png)

Após a instalação, é necessário informar o caminho da biblioteca: gsdll32.dll ou gsdll64.dll (32 ou 64 bits). A biblioteca fica na subpasta **bin** do diretório de instalação do Ghostscript. Isso pode ser feito na aba **Import** da janela **System setup**:
