# Installieren der Ghostscript-Bibliothek

Für den Import von PostScript-Dateien ist Ghostscript erforderlich. Die Bibliothek wird von [Artifex Software, Inc.](https://www.ghostscript.com/index.html) entwickelt und ist aus Lizenzgründen nicht im Installationspaket des CAM-Systems enthalten. Sie kann separat heruntergeladen und für die eigene Verwendung installiert werden.

Das CAM-System unterstützt Ghostscript ab Version 9.22.

**[Ghostscript 9.22 herunterladen](https://github.com/ArtifexSoftware/ghostpdl-downloads/releases/tag/gs922)**

Auf der geöffneten GitHub-Seite wählen Sie eine passende Windows-Version mit 64 Bit aus:

*Hinweis: Wählen Sie die 64-Bit-Version von Ghostscript.*

![images/download/attachments/157859509/image2019-3-4_15-35-1.png](assets/images/download/attachments/157859509/image2019-3-4_15-35-1.png)

Geben Sie nach der Installation den Pfad zur Bibliothek an: gsdll32.dll für 32 Bit oder gsdll64.dll für 64 Bit. Die Datei befindet sich im Unterordner **bin** des Ghostscript-Installationsverzeichnisses. Der Pfad kann in **System setup** auf der Registerkarte **Import** festgelegt werden:

![images/download/attachments/157859509/image2024-7-2_17-51-36.png](assets/images/download/attachments/157859509/image2024-7-2_17-51-36.png)
