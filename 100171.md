# Advanced

## Application area:

The **Advanced** group contains operations for surface finishing, undercut machining, multi-axis roughing, and machining spatial contours. The individual topics describe the available toolpath strategies and tool orientation settings.

### Operations:

- **Combo finish.** Combines plane, waterline, and scallop finishing strategies. [Details](100126.md)

- **Surfacing.** Finishes surfaces using configurable strategies and tool orientations. [Details](10135.md)

- **Scallop.** Generates finishing passes with a consistent step-over across surfaces. [Details](10118.md)

- **Helical.** Generates a helical finishing toolpath. [Details](10119.md)

- **Morph.** Generates passes that morph between specified curves. [Details](10138.md)

- **Undercut waterline.** Machines undercut areas using waterline passes. [Details](100150.md)

- **Swarf.** Machines surfaces with the side of the tool. [Details](1040.md)

- **5D Roughing waterline.** Generates five-axis roughing toolpaths. [Details](102025.md)

- **5D by meshes.** Generates toolpaths for machining meshes. [Details](10142.md)

- **6D Contouring.** Machines spatial contours with control of tool orientation. [Details](10129.md)

- **Contour polishing.** Finishes part walls and edges along contours using a disc tool. [Details](164691982.md)
