# Advanced

## Application area:

The <strong>Advanced</strong> group contains operations for surface finishing, undercut machining, multi-axis roughing, and machining spatial contours. The individual topics describe the available toolpath strategies and tool orientation settings.

### Operations:

- <strong>Combo finish.</strong> Combines plane, waterline, and scallop finishing strategies. [Details](100126.md)

- <strong>Surfacing.</strong> Finishes surfaces using configurable strategies and tool orientations. [Details](10135.md)

- <strong>Scallop.</strong> Generates finishing passes with a consistent step-over across surfaces. [Details](10118.md)

- <strong>Helical.</strong> Generates a helical finishing toolpath. [Details](10119.md)

- <strong>Morph.</strong> Generates passes that morph between specified curves. [Details](10138.md)

- <strong>Undercut waterline.</strong> Machines undercut areas using waterline passes. [Details](100150.md)

- <strong>Swarf.</strong> Machines surfaces with the side of the tool. [Details](1040.md)

- <strong>5D Roughing waterline.</strong> Generates five-axis roughing toolpaths. [Details](102025.md)

- <strong>5D by meshes.</strong> Generates toolpaths for machining meshes. [Details](10142.md)

- <strong>6D Contouring.</strong> Machines spatial contours with control of tool orientation. [Details](10129.md)

- <strong>Contour polishing.</strong> Finishes part walls and edges along contours using a disc tool. [Details](164691982.md)
