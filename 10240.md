# Schneidwerkzeug Messer

![images/download/attachments/157866019/knife.jpg](assets/images/download/attachments/157866019/knife.jpg)

Die Messergeometrie wird durch sieben Parameter definiert:

**RD:** Abstand vom Werkzeugbezugspunkt zur rechten Schneide. **LD:** Abstand zur linken Schneide. **RA:** Neigungswinkel der rechten Schneide. **LA:** Neigungswinkel der linken Schneide. **D:** Klingenbreite. **L:** Klingenlänge. **H:** Standard-Schnitttiefe. Dieser Wert ist werkzeugspezifisch und wird in der Werkzeugdatenbank gespeichert.

Die Klingendicke wird bei der Bahnrechnung nicht verwendet. Für die Darstellung wird sie automatisch bestimmt.
