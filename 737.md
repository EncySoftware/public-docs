# Seitenwinkel

Der Seitenwinkel bestimmt bei Gravier- und Taschenoperationen die Neigung der seitlichen Fläche des aus Kurven aufgebauten Modells. Für die Schlichtbearbeitung beim Gravieren wählt das System ein [Gravierwerkzeug](37.md), dessen Kegelwinkel dem Seitenwinkel entspricht.

![images/download/attachments/162957233/image_5_4_15.gif](assets/images/download/attachments/162957233/image_5_4_15.gif)

Bei einem Seitenwinkel von 0° entspricht das Modell einer Extrusion, deren Grundkontur auf der oberen Bearbeitungsebene liegt. Bei einem größeren Winkel wird eine geradlinige Seitenfläche ergänzt; ihr Winkel zur Vertikalen entspricht dem Seitenwinkel.

Der Wert muss mindestens 0° und kleiner als 90° sein.

Der Seitenwinkel wird auf **Parameters** festgelegt.
