# Elementweise erstellen

![images/download/attachments/157860262/image2024-8-8_16-18-49.png](assets/images/download/attachments/157860262/image2024-8-8_16-18-49.png)

Die Kontur wird schrittweise aus Linien und Bögen aufgebaut. Die Punkte werden interaktiv oder im Inspektor festgelegt.

Legen Sie zunächst den Startpunkt der Kontur fest oder geben Sie seine Koordinaten im Inspektor ein.

![images/download/attachments/157860262/image2024-8-8_16-19-45.png](assets/images/download/attachments/157860262/image2024-8-8_16-19-45.png)

Legen Sie anschließend den nächsten Punkt fest oder geben Sie Länge und Winkel der Linie ein.

![images/download/attachments/157860262/image2024-8-8_16-20-33.png](assets/images/download/attachments/157860262/image2024-8-8_16-20-33.png)

Alternativ legen Sie einen Bogen fest. Der Inspektor zeigt die Koordinaten des nächsten Punkts und des Bogenmittelpunkts, den Radius sowie den Winkel zur Tangente des vorherigen Elements an.

![images/download/attachments/157860262/image2024-8-8_16-21-9.png](assets/images/download/attachments/157860262/image2024-8-8_16-21-9.png)

Um zwischen einem Liniensegment und einem Bogen zu wechseln, klicken Sie auf die entsprechende Schaltfläche:

![images/download/attachments/157860262/image2024-8-8_16-21-45.png](assets/images/download/attachments/157860262/image2024-8-8_16-21-45.png)

Alternativ drücken Sie **Strg+Leertaste** (**Ctrl+Space**).

Schließen Sie die Konturerstellung durch einen Doppelklick auf den letzten Punkt oder durch Klicken auf eine der folgenden Schaltflächen ab:

![images/download/attachments/157860262/image2024-8-8_16-22-1.png](assets/images/download/attachments/157860262/image2024-8-8_16-22-1.png)

![Kontur beenden](assets/images/download/thumbnails/157860262/image2024-8-8_16-22-56.png) beendet die Kontur mit dem zuletzt bestätigten Element. ![Kontur schließen](assets/images/download/attachments/157860262/image2024-8-8_16-23-30.png) erstellt eine geschlossene Kontur, indem der zuletzt bestätigte Punkt mit dem ersten Punkt verbunden wird. Dabei wird der aktuell ausgewählte Elementtyp verwendet.

Sie können die Konstruktion auch durch einen Doppelklick beim Erstellen des letzten Elements beenden.
