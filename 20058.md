# Import from model

**Import from model** copies selected model geometry into the sketch. Select the result type from the button menu; the button remembers the last choice.

**Contour on the plane.** Selected model edges become a planar profile in the active plane.

**Space curve.** Creates the boundary of a selected face (one curve per loop, with holes separate) or a chain of selected edges.

If the selection is unsuitable for the chosen result type, the button tries the other type. If neither is suitable, nothing happens.

The result is an independent copy and does not update when the model changes. Accuracy comes from the curve import tolerance setting in the application parameters.
