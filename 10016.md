# Aba Recursos on-line

![images/download/attachments/157859040/image2026-7-29_10-14-27.png](assets/images/download/attachments/157859040/image2026-7-29_10-14-27.png)

## Recursos on-line:

- **Usage Statistics.** Ativa ou desativa a coleta de estatísticas anônimas de uso. Quando ativada, a opção permite coletar dados sobre a utilização dos recursos para aprimorar o software. Não são coletadas informações pessoais ou sensíveis; os dados são utilizados para melhorar a experiência de uso e otimizar o desempenho do sistema.
- **Clouds.** Quando esta opção está ativada, concede acesso ao recurso Clouds. [Detalhes](100321.md).
- **AI-based operations.** Permite criar operações baseadas em inteligência artificial. Quando a opção está desativada, essas operações não aparecem na lista de operações disponíveis para criação.

## Informações de autenticação:

- **Save authorization.** Salva as credenciais de acesso, nome de usuário e senha, no gerenciador de licenças. Quando a opção está ativada, o sistema memoriza os dados do usuário, agilizando o acesso aos serviços on-line.
- **Login.** Campo para o nome de usuário utilizado no acesso a recursos on-line, como colaboração na nuvem e integrações externas.
- **Password.** Campo para a senha associada ao nome de usuário, utilizada na autenticação nos serviços on-line do sistema.
