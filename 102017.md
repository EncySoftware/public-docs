# Installazione e configurazione dei moduli di integrazione PLM

<a id="setting-up-the-integration-extension"></a>

## Configurazione dell'estensione di integrazione

Per configurare il modulo di integrazione del sistema PLM, aprire la finestra <strong>System Settings</strong> (impostazioni di sistema) e passare alla scheda <strong>Extensions</strong> (estensioni).

![images/download/attachments/157867814/1.png](assets/images/download/attachments/157867814/1.png)

Fare clic sul pulsante <strong>Install</strong> (installa). Nella finestra <strong>File Explorer</strong> che si apre, scegliere il file json o dext dell'estensione e aprirlo. Esempio di installazione riuscita:

![images/download/attachments/157867814/2.png](assets/images/download/attachments/157867814/2.png)

È anche possibile disattivare o disinstallare l'estensione: selezionarla nell'elenco delle estensioni e agire sull'interruttore <strong>Enabled</strong> (attivata) oppure fare clic sul pulsante <strong>Uninstall</strong> (disinstalla).

L'estensione può essere installata anche tramite l'interfaccia a riga di comando (CLI; il file ExtensionManagerCLI.exe si trova nella cartella di installazione del programma). A tale scopo, aprire il Prompt dei comandi di Windows e immettere il comando:

<strong>ExtensionManagerCLI.exe register-library --path "</strong><em>[percorso dell'estensione]</em><strong>"</strong> <strong>--storage stAllUsers</strong>

<a id="configuring-plm-connections"></a>

## Configurazione delle connessioni PLM

Per creare e configurare una connessione, aprire la finestra <strong>System Settings</strong> e passare alla scheda <strong>PLM connections</strong> (connessioni PLM).

![images/download/attachments/157867814/3.png](assets/images/download/attachments/157867814/3.png)

Scrivere il nome della connessione nel campo di testo <strong>Name</strong> (nome) e scegliere l'estensione PLM installata nel menu a discesa. Quindi fare clic sul pulsante <strong>Add</strong> (aggiungi).

![images/download/attachments/157867814/4.png](assets/images/download/attachments/157867814/4.png)

È possibile configurare la connessione selezionata modificando i valori dei parametri di connessione proposti o dei parametri di impostazione nelle tabelle sottostanti.

È inoltre possibile salvare le impostazioni in un file facendo clic sul pulsante <strong>Save to file</strong> (salva su file). Questo file può essere utilizzato per caricare le impostazioni facendo clic sul pulsante <strong>Load from file</strong> (carica da file).

È possibile rimuovere una connessione: selezionarla nell'elenco delle connessioni e fare clic sul pulsante <strong>Remove</strong> (rimuovi).

Per verificare la connessione, fare clic sul pulsante <strong>Test connection</strong> (verifica connessione) e immettere le credenziali del proprio account.

Fare clic sul pulsante <strong>Apply</strong> (applica) o <strong>Ok</strong> per applicare le modifiche.
