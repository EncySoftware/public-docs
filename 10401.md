# Simplificação do modelo geométrico

A função **Simplifying geometrical model** pode ser chamada no menu de contexto da [janela gráfica](169.md).

Essa função destina-se apenas à remoção de faces internas de uma casca fechada de um modelo geométrico. Isso pode ser útil se o projeto usar um modelo muito detalhado, o que pode afetar a velocidade do programa e o tamanho final do projeto.

Como resultado da função, obtém-se, com certa precisão, uma casca oca.

![images/download/attachments/157860052/image2024-8-5_12-7-10.png](assets/images/download/attachments/157860052/image2024-8-5_12-7-10.png)

Por padrão, os parâmetros de simplificação são definidos de forma ideal, mas, se desejar, você pode usar conjuntos de parâmetros prontos ou defini-los manualmente.

O bloco **Simplification modes** define os conjuntos de parâmetros.

**Solid size** - Define o tamanho mínimo das cascas que participarão do cálculo. Qualquer coisa abaixo disso é automaticamente marcada como um objeto interno.

**Face size** - Define o tamanho mínimo das faces individuais que participarão do cálculo. Qualquer coisa abaixo disso é automaticamente marcada como um objeto interno.

**Face area** - Define a área mínima das faces internas a partir da qual elas serão consideradas internas.

O bloco **Faces display** é responsável pelos modos de exibição de faces.

![images/download/thumbnails/157860052/image2022-4-6_12-9-48.png](assets/images/download/thumbnails/157860052/image2022-4-6_12-9-48.png) ![images/download/thumbnails/157860052/image2022-4-6_12-9-26.png](assets/images/download/thumbnails/157860052/image2022-4-6_12-9-26.png) ![images/download/thumbnails/157860052/image2022-4-6_12-9-32.png](assets/images/download/thumbnails/157860052/image2022-4-6_12-9-32.png) ![images/download/thumbnails/157860052/image2022-4-6_12-9-36.png](assets/images/download/thumbnails/157860052/image2022-4-6_12-9-36.png)

**Color** - Mostra as cores originais da geometria. Por padrão, as faces externas são verdes e as internas são vermelhas.

**Transparent** - Mostra um modelo de geometria transparente.

**Outer** - Mostra as faces externas.

**Inner** - Mostra as faces internas.
