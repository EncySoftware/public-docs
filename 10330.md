# Lackiersimulation

![images/download/attachments/157867347/image2024-6-25_14-39-31.png](assets/images/download/attachments/157867347/image2024-6-25_14-39-31.png)

<a id="application-area"></a>

## Anwendungsbereich:

Die Lackiersimulation zeigt, welche Bauteilbereiche beschichtet werden. Je nach Simulationsart lässt sich außerdem die voraussichtliche Schichtdicke beurteilen.

<a id="tips-for-creating-a-painting-project"></a>

## Hinweise zum Erstellen eines Lackierprojekts

<a id="1-recommendation-for-the-model"></a>

### 1. Modell vorbereiten

<details>
<summary>Weitere Informationen anzeigen</summary>

Bereiten Sie das Modell vor dem Import in das CAM-System vor. Entfernen Sie kleine, für die Lackierung nicht erforderliche Elemente und vereinfachen Sie die Geometrie soweit möglich.

Bei STL- oder PLY-Modellen empfiehlt sich ein möglichst gleichmäßiges Netz. Dieses kann mit geeigneter Software erzeugt werden, wie im folgenden Beispiel dargestellt.

![images/download/attachments/157867347/image2023-7-18_10-18-59.png](assets/images/download/attachments/157867347/image2023-7-18_10-18-59.png)

*Ein entsprechend vereinfachtes Modell ermöglicht eine flüssigere und schnellere Lackiersimulation.*

</details>

<a id="2-preparing-operation-for-painting"></a>

### 2. Lackieroperation vorbereiten

<details>
<summary>Weitere Informationen anzeigen</summary>

Laden Sie zunächst das Bauteil auf der Seite **Model** und erstellen Sie anschließend die Lackieroperation. Führen Sie danach folgende Schritte aus:

- Definieren Sie das zu lackierende Bauteil für die Operation.
- Legen Sie ein leeres Rohteil fest.
- Wählen Sie in den Operationsparametern den Simulationstyp **Painting simulation**.

</details>

<a id="3-choose-painting-type"></a>

### 3. Simulationsart auswählen

<details>
<summary>Weitere Informationen anzeigen</summary>

Es stehen zwei Arten der Lackiersimulation zur Verfügung:

- **Simple (Einfach).** Zeigt die beschichteten Modellbereiche. Berechnen Sie nach der Auswahl die Werkzeugbahn und betrachten Sie das Ergebnis auf der Seite **Simulation**.
- **Thickness measurement (Schichtdickenmessung).** Zeigt zusätzlich die ungefähre Schichtdicke. Legen Sie dafür folgende Werte fest:

1. Arbeitsvorschub.
2. Lackvolumenstrom.

Berechnen Sie anschließend die Operation und wechseln Sie zur Seite **Simulation**.

</details>

<a id="4-change-parameters-of-the-simulation"></a>

### 4. Simulationsparameter anpassen

<details>
<summary>Weitere Informationen anzeigen</summary>

Modellauflösung und Bahntoleranz können angepasst werden, um die Rechengeschwindigkeit oder Darstellungsqualität zu verbessern. Weitere Informationen finden Sie [hier](906.md).

</details>

<a id="5-control-thickness-of-your-painting-result"></a>

### 5. Schichtdicke prüfen

<details>
<summary>Weitere Informationen anzeigen</summary>

Klicken Sie zum Prüfen der simulierten Schichtdicke auf **Verify compare**; die Schaltfläche ist [hier](10006.md) beschrieben. Es öffnet sich der folgende Dialog:

![images/download/thumbnails/157867347/image2025-10-7_13-28-10.png](assets/images/download/thumbnails/157867347/image2025-10-7_13-28-10.png)

Der Dialog enthält die Einstellungen für die farbliche Beurteilung der Lackverteilung auf dem Modell.

Die Farbskala verläuft von transparent über die Farbe der aktuellen Operation zu Gelb und schließlich Rot.

Die Farbe der aktuellen Operation kennzeichnet den zulässigen Schichtdickenbereich. Geben Sie dafür einen unteren und einen oberen Grenzwert an. Bereiche mit einer Schichtdicke innerhalb dieses Intervalls werden in der vollständigen Operationsfarbe ohne Transparenz dargestellt.

Bei zu geringer Schichtdicke wird dieselbe Farbe mit Transparenz verwendet. Je stärker die Schichtdicke vom zulässigen Bereich abweicht, desto transparenter erscheint der Bereich.

Zu große Schichtdicken werden gelb bzw. rot dargestellt. Die zugehörigen Schwellenwerte werden als Prozentsatz der maximal zulässigen Schichtdicke angegeben, beispielsweise 150 % und 200 %.

Übernehmen Sie Änderungen mit **Enter** oder indem Sie in ein anderes Feld wechseln.

</details>
