# Atualização

O sistema CAM verifica a disponibilidade de atualizações a cada inicialização. Os arquivos necessários são baixados e verificados automaticamente. Não é necessário manter o aplicativo aberto: a verificação continua em segundo plano mesmo após seu encerramento.

Quando o sistema de atualização encontra e baixa os módulos com sucesso, é exibida uma solicitação de atualização:

![images/download/attachments/157859080/image2024-8-23_16-13-56.png](assets/images/download/attachments/157859080/image2024-8-23_16-13-56.png)

Clique em **Update** para iniciar a atualização.

Processo de atualização

A atualização do sistema CAM ocorre em três etapas:

![images/download/attachments/157859080/image2024-8-23_16-17-10.png](assets/images/download/attachments/157859080/image2024-8-23_16-17-10.png)

- **Close CAM system.** O atualizador aguarda que os projetos sejam salvos e que o sistema CAM seja fechado manualmente. Durante a atualização, a inicialização do sistema fica bloqueada. Nesta etapa, é possível cancelar o processo fechando a janela do atualizador.
- **Updating.** O sistema executa a atualização. Pode ser necessário utilizar uma conta com privilégios de administrador para concluir esta etapa.
- **Finish.** O sistema exclui os dados temporários utilizados na atualização.

Ao concluir essas etapas, a janela do atualizador é fechada e o sistema CAM é iniciado automaticamente.
