# Aktualisieren

Das CAM-System sucht bei jedem Start nach Aktualisierungen. Benötigte Dateien werden automatisch heruntergeladen und geprüft. Das CAM-System muss dafür nicht geöffnet bleiben: Die Aktualisierungssuche läuft auch nach dem Schließen im Hintergrund weiter.

Wenn Aktualisierungen gefunden und erfolgreich heruntergeladen wurden, erscheint eine entsprechende Aufforderung:

![images/download/attachments/157859080/image2024-8-23_16-13-56.png](assets/images/download/attachments/157859080/image2024-8-23_16-13-56.png)

Klicken Sie auf **Update** (Aktualisieren), um den Vorgang zu starten.

**Ablauf der Aktualisierung**

Die Aktualisierung umfasst drei Schritte:

![images/download/attachments/157859080/image2024-8-23_16-17-10.png](assets/images/download/attachments/157859080/image2024-8-23_16-17-10.png)

- **CAM-System schließen.** Das System wartet, bis alle Projekte gespeichert wurden und die Anwendung manuell geschlossen wurde. Während der Aktualisierung ist ein erneuter Start gesperrt. In diesem Schritt können Sie noch abbrechen, indem Sie das Aktualisierungsfenster schließen.
- **Aktualisieren.** Die Programmdateien werden aktualisiert. Dafür können Administratorrechte angefordert werden.
- **Abschließen.** Temporäre Daten der Aktualisierung werden entfernt.

Anschließend wird das Aktualisierungsfenster geschlossen und das CAM-System automatisch gestartet.
