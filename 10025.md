# Licence manager

## Application area:

The **License manager** is a page within the Home Page for managing application licenses and licenses for additional components.

## Opening the license manager

Select **License manager** at the bottom of the Home Page sidebar or in the logo menu in the main window title bar. The application opens the manager automatically when no license is available. [Details](10201021.md)

## Signing in

Before sign-in, a sign-in screen is displayed over the page, with a sign-in button and **Back**. Authentication takes place in a browser. If the browser does not open, a link and a copy button appear below. When a connected protection dongle contains users, select a dongle user to sign in.

## Header and license sources

**Offline.** Indicates that account licenses cannot be checked. License files and protection dongles remain usable.

The refresh button updates licenses and searches for connected dongles again. The header's three-dot menu contains:

- **Export dongle data.** Exports data from a connected protection dongle. Available only when a dongle is connected.
- **Load from file.** Loads a `*.stj` or `*.stjc` license file.
- **Request new license.** Requests a trial license from the dealer. Without a connection, opens activation by CM code.
- **Activate by CM code.** Available for software protection only.

## License tabs and current license

**Licenses.** Contains application licenses.

**Extensions.** Contains licenses for component containers, such as postprocessors, machines, and operations. To install or manage extensions themselves, use **Extensions** on the Home Page. [Details](162964210.md)

The **Current** card shows the active license ID, package, licensee, type, protection, validity period, and maintenance. Maintenance information opens a popup with the dealer's contact details. The first ten modules are displayed; a button reveals the remaining modules.

## License list

Use search to find a license. **Show expired** is off by default; enable it to include expired licenses.

Licenses are grouped by licensee. Licenses on the current computer are grouped under **This computer**. Categories select all licenses (**All**), CAM licenses, machines, postprocessors, operations, or other components.

The table shows ID, products, validity period, type, protection, maintenance, and status.

| Status | Meaning |
|---|---|
| **Active** | The license is activated. |
| **Inactive** | The license is not activated. |
| **Busy** | The license is in use. |
| **No dongle** | The required protection dongle is not connected. |
| **Invalid** | The license is not valid. |
| **Expired** | The license validity period has ended. |

## License actions

**Activate** activates a license; **Release** releases it. Double-clicking a row performs the same action. Releasing a license while signed out displays a warning that signing in or an internet connection will be needed to activate it again.

The row's three-dot menu offers actions according to the license state:

- **Renew maintenance.** Available when fewer than 30 days of maintenance remain.
- **Revert version.** For an eligible non-perpetual license, when maintenance has expired and the installed version is newer than the covered version, starts an installer for an earlier version.
- **Request renewal** and **Get a quote.** Available for expired trial licenses.

## Activation dialogs

### Activate license

**Activate license** accepts an activation code and provides a preview of the license file.

### NetLock activation

Enter the license server and port in **NetLock activation**. The default port is **10099**.

**Test connection.** Checks connection to the specified server.

**Find server.** Searches the local network for a license server.

### Generate CM code

Before generating a new CM code, the application warns that it cancels all software licenses activated on this computer. Proceed only when these licenses are intended to be replaced.

The next screen displays the code and a copy button. **Next** opens the license file selection dialog.
