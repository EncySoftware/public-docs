# Gestione delle librerie

Per gestire le librerie di utensili e gli utensili del progetto, utilizzare il pannello situato nella parte sinistra della [finestra Tools](38.md).

![images/download/attachments/157867481/image2024-7-22_15-40-23.png](assets/images/download/attachments/157867481/image2024-7-22_15-40-23.png)

Il pannello mostra tutte le librerie di utensili collegate al sistema e le suddivide in diversi gruppi:

- <strong>All</strong> (tutte) - un nodo radice che consente di visualizzare comodamente in un'unica volta gli utensili di tutte le sorgenti di interesse.
- <strong>[Project tools](10342.md)</strong> (utensili del progetto) - l'elenco degli utensili del progetto corrente.
- <strong>Suppliers</strong> (fornitori) - l'elenco delle librerie presenti nella cartella "$(CommonAppData)\Libraries\Tools\Suppliers" e installate dalla distribuzione. Le librerie di questo gruppo sono disponibili in sola lettura.
- <strong>Examples</strong> (esempi) - l'elenco delle librerie presenti nella cartella "$(CommonAppData)\Libraries\Tools\Examples" e installate dalla distribuzione come esempio. Le librerie di questo gruppo sono disponibili in sola lettura.
- <strong>Personal</strong> (personali) - l'elenco delle librerie situate in altre posizioni del file system. Se la libreria si trova nella cartella "$(CommonAppData)\Libraries\Tools", il sistema la aggiunge automaticamente a questo gruppo.

L'elenco degli utensili viene sempre visualizzato per le librerie annidate nel nodo selezionato e contrassegnate.

Esiste il concetto di <strong>Favorite library</strong> (libreria preferita): è una libreria che compare per prima nell'elenco, subito dopo Project tools. Quando si crea una nuova operazione, viene cercato automaticamente un utensile adatto. La ricerca viene eseguita dapprima nell'elenco degli utensili del progetto, poi nella libreria preferita. La libreria preferita è mostrata in grassetto e può essere cambiata dal menu a comparsa.

Al primo posto si trova sempre la voce <strong>Project tools</strong>. È l'elenco degli utensili del progetto corrente, memorizzato all'interno del file stcp, ma che può essere salvato in un file di testo separato (XML con estensione *.tom). Per maggiori informazioni, vedere il capitolo [Project tools](10342.md). La differenza fondamentale rispetto a una libreria è che, insieme all'elenco degli utensili, viene conservato lo stato della macchina, ovvero la corretta posizione dell'utensile nello schema cinematico della macchina e la disposizione dei blocchi della torretta. Si tratta quindi dell'elenco della configurazione degli utensili. Il file dell'elenco degli utensili del progetto non è destinato a contenere un numero eccessivo di utensili.

![images/download/attachments/157867481/image2024-7-30_18-11-58.png](assets/images/download/attachments/157867481/image2024-7-30_18-11-58.png)

Per l'elenco degli <strong>utensili del progetto</strong> sono disponibili dal menu a comparsa le seguenti <strong>azioni</strong>.

- Save project tools to file... - salvataggio in un file *.tom esterno. Il sistema memorizza il percorso del file selezionato e caricherà automaticamente gli utensili da questo file quando si crea un nuovo progetto con la stessa macchina.
- Load project tools from file... - caricamento da un file *.tom esterno. Il sistema memorizza il percorso del file selezionato e caricherà automaticamente gli utensili da questo file quando si crea un nuovo progetto con la stessa macchina.
- Reload from file - ricaricamento da un file *.tom salvato in precedenza (senza aprire la finestra di dialogo di apertura file).
- Clear project tools - rimozione di tutti gli utensili non utilizzati dal progetto e interruzione del collegamento al file *.tom esterno, se l'elenco degli utensili del progetto era stato salvato in precedenza in un file esterno.
- Show file in Windows explorer - apre Esplora risorse di Windows e seleziona il file *.tom, se il progetto fa riferimento a un file esistente.

Le voci successive dell'elenco sono le <strong>normali librerie di utensili</strong>. Una libreria è un file in formato database SQLite. Nelle librerie sono memorizzati solo gli utensili e nessuna informazione sulla macchina. Possono contenere con facilità un numero molto elevato di utensili (decine di migliaia).

![images/download/attachments/157867481/image2024-7-22_15-41-37.png](assets/images/download/attachments/157867481/image2024-7-22_15-41-37.png)

Per la libreria di utensili sono disponibili le seguenti <strong>azioni</strong>, dal menu a comparsa e dai pulsanti della barra degli strumenti superiore:

- Create new library... - apre una finestra di dialogo di salvataggio file in cui è possibile selezionare il nome e la posizione del file *.db della nuova libreria di utensili.
- Open library... - apre una finestra di dialogo di apertura file in cui è possibile selezionare un file *.db o *.csv di una libreria di utensili esistente; il sistema la aggiungerà all'elenco.
- Remove selected library - rimuove la libreria dall'elenco.
- Save selected library - salva le modifiche in un file. È necessario solo in casi particolari, poiché alla chiusura della finestra degli utensili tutte le modifiche alle librerie vengono salvate automaticamente. Se la libreria ha il vecchio formato *.csv, viene visualizzata una finestra di messaggio che propone di convertire il file nel nuovo formato *.db.
- Save all libraries - salva le modifiche nei file di tutte le librerie collegate (alla chiusura della finestra degli utensili tutte le modifiche alle librerie vengono salvate automaticamente).
- Reload from file - ricarica tutti i dati dal file e tutte le modifiche non salvate andranno perse.
- Mark as favorite library - imposta la libreria selezionata come preferita.
- Show file in Windows explorer - apre Esplora risorse di Windows e seleziona il file della libreria.

L'elenco delle librerie collegate, lo stato delle relative caselle di controllo e l'indicazione di quale sia la preferita vengono salvati nel file delle impostazioni di sistema (*.cfg).
