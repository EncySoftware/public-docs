# Desfazer visualização

O recurso <strong>Desfazer vista</strong> permite que o usuário restaure os parâmetros da viewport ativa (escala, vetor de visualização, etc.) para seu estado anterior. Use o menu pop-up da janela de gráfico para ativá-lo.
