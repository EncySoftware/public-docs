# Pasta ativa

![images/download/attachments/157859192/image2024-7-2_16-21-37.png](assets/images/download/attachments/157859192/image2024-7-2_16-21-37.png)

Apenas um grupo pode estar ativo por vez. O trabalho ([importação](772.md), detalhamento, transformações etc.) só é possível com os objetos localizados no grupo ativo no momento. O grupo ativo é tratado como um único objeto e é considerado indivisível. Para trabalhar separadamente com os elementos localizados dentro do grupo, é necessário "abrir" ou ativar esse grupo. Essas regras são semelhantes às de qualquer sistema de arquivos (por exemplo, o Windows): só é possível trabalhar com uma pasta ou um arquivo depois de "entrar" na pasta que o contém (abri-la).

A pasta ativa no momento é exibida na [janela de estrutura do modelo](718.md). Nessa janela também é exibida a lista de elementos geométricos e estruturais localizados dentro da pasta ativa. Esses elementos podem ser selecionados tanto diretamente na lista quanto na [janela gráfica](169.md). Para selecionar o grupo ativo, selecione o item correspondente na árvore da janela de estrutura do modelo ou selecione um objeto na janela gráfica.
