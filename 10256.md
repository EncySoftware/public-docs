# Seleção múltipla

Use a barra de ação flutuante para selecionar itens que tenham atributos comuns. Selecione qualquer item e ative a opção de seleção múltipla.

![images/download/attachments/157865926/image2024-7-17_14-42-33.png](assets/images/download/attachments/157865926/image2024-7-17_14-42-33.png)

O painel pop-up mostrará as propriedades do item selecionado. Use as caixas de seleção para filtrar a seleção com base nos valores das propriedades do elemento selecionado. Se uma propriedade estiver marcada, somente os itens com o mesmo valor dessa propriedade serão selecionados. Por exemplo, para selecionar todos os itens com sobremetal de 0 mm, selecione um desses itens e marque a propriedade **Profile stock**.
