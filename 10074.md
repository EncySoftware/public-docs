# Makrobefehle in der Werkzeugwegvorlage

Ein einfacher Befehl der Werkzeugwegvorlage wird direkt als entsprechender CLData-Befehl ausgegeben. Ein Makrobefehl ruft dagegen eine im CAM-System implementierte Unterroutine auf. Diese kann mehrere CLData-Befehle erzeugen; deren Typ und Reihenfolge hängen vom Makro ab. Die Liste der verfügbaren Unterroutinen wird bei der Auswahl des Makrotyps auf der Vorlagenseite geöffnet.

![images/download/attachments/157861506/image2024-7-8_17-25-35.png](assets/images/download/attachments/157861506/image2024-7-8_17-25-35.png)

Ein Makrobefehl besitzt außerdem einen Zustand, der seine Ausführung steuert. Standardmäßig gilt **Auto**: CLData-Befehle werden nur ausgegeben, wenn sie benötigt werden.

Bei deaktiviertem Zustand werden keine CLData-Befehle ausgegeben. So lassen sich unerwünschte Befehle ausschließen, ohne die Vorlage umfassend zu ändern. Über die Zustandssteuerung kann beispielsweise das Ausschalten des Kühlmittels gezielt vorgegeben werden, auch wenn es nicht manuell in der Operation deaktiviert wurde. Die Makrozustände können auf einer zusätzlichen Seite des Operationsinspektors bearbeitet werden.
