# Grupos (pastas)

Um **Group** (pasta) é um elemento do modelo geométrico. Destina-se ao agrupamento de objetos geométricos que são semelhantes por destino ou por qualquer outra afinidade. As pastas são muito úteis para fazer projetos adaptáveis. É possível definir uma vez as pastas como parâmetros geométricos das operações. Em seguida, basta alterar o conteúdo das pastas para ajustar o projeto para a geometria modificada. Nesse caso, a peça, o bruto, os dispositivos de fixação e a definição da tarefa das operações serão atualizados automaticamente quando o conteúdo das pastas associadas for alterado.

<strong>Observação</strong>: Ao importar, os grupos podem ser colocados automaticamente em pastas especiais, se você adicionar uma das seguintes chaves ao nome:

- **sc_f_** - o grupo será movido para a pasta **Fixtures**;
- <strong>sc_w_</strong> - o grupo será movido para a pasta **Workpiece**;.
