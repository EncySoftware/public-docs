# Gruppen (Ordner)

Eine **Gruppe** (Ordner) ist ein Element des geometrischen Modells. Sie dient dazu, geometrische Objekte nach ihrem Verwendungszweck oder anderen gemeinsamen Merkmalen zusammenzufassen. Ordner sind besonders hilfreich beim Erstellen anpassbarer Projekte: Sie können Ordner einmalig als Geometrieparameter von Operationen festlegen. Anschließend genügt es, ihren Inhalt zu ändern, um das Projekt an eine geänderte Geometrie anzupassen. Dabei werden das Bauteil, das Rohteil, die Spannmittel und die Auftragszuweisungen der Operationen automatisch aktualisiert, sobald sich der Inhalt der zugeordneten Ordner ändert.

**Hinweis:** Beim Import können Gruppen automatisch in spezielle Ordner eingeordnet werden, wenn Sie dem Namen eine der folgenden Kennungen hinzufügen:

- **sc_f_** – die Gruppe wird in den Ordner **Fixtures** (Spannmittel) verschoben;
- **sc_w_** – die Gruppe wird in den Ordner **Workpiece** (Rohteil) verschoben.
