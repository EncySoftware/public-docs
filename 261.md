# Configurations and options

<strong>Premium Configurations</strong>

Premium configurations include: 2D sketching, 3D modeling, dimensioning and geometry transformation; import of CAD formats such as IGES, STL, VRML, PostScript, DXF, Rhinoceros, Sprut Models, Parasolid, STEP, Sprut geometry format, SW, SE, PLY, AMF, JTOpen, PLMXML, 5DC, and OSD; add-ins for integration with popular CAD systems; high-end 3D machining simulation with G-code verification support; setup sheet generator; support for probing operations; tool library; equipment library; MachineMaker for importing, assembling, and configuring digital twins of machines and robots; postprocessor generator; a set of basic postprocessors and interpreters

## Bound Configurations

Bound license is tied to a specific machine or robotic cell and includes all the features of the Premium configurations, except for: MachineMaker, the postprocessor generator and the set of basic postprocessors and interpreters.

## ENCY Robot Welding SE

ENCY Robot Welding SE is a bound license designed for programming industrial robots used in welding applications. It includes operations for automated welding, specifically point welding and 6D welding. ENCY Robot Welding SE is a license designed for programming industrial robots used in welding applications. This license is limited to a single application and does not support the addition of other modules and features.

## ENCY Robot Woodworking SE

ENCY Robot Woodworking is a simplified robotic milling bound license designed for furniture manufacturers and woodworkers. It supports basic 3-axis roughing and finishing operations, along with 5D contouring. The license includes machining operations such as Hole Machining, Roughing (Waterline and Plane), Finishing (Waterline and Plane), and various contouring strategies: 2D, 2.5D, 3D, and 5D. This license is limited to a single application and does not support the addition of other modules and features.

## Applications

<strong>Robot Mill:</strong> A wide range of milling operations from 2.5-axis to 5-axis (operation set equivalent to the 5X Mill configuration for CNC)

<strong>Robot Mill Advanced:</strong>

Includes all features of Robot Mill plus Swarf, 5D Roughing waterline, Impeller machining operations

<strong>Cutting 2D:</strong>

2D cutting (Hole machining, FBM Mill, 2D contouring, 2.5D contouring, Jet cutting). Included in Robot Mill and Robot Mill Advanced.

<strong>Cutting 5D:</strong>

5D cutting (3D contouring, 6D contouring, Chamfering, Jet cutting 5D), includes all features of Cutting; 3+2 indexed multi-axis machining. Included in Robot Mill and Robot Mill Advanced.

<strong>Welding:</strong>

Automated welding (Point welding, Welding 6D)

<strong>Spraying/Painting:</strong>

Automated spraying/painting (Contour spraying, Morph spraying, Rotary spraying)

<strong>Additive Planar 3D:</strong>

3D additive manufacturing (Area cladding, Curve cladding, Cladding 3D, Planar slicing)

<strong>Additive Non-planar 5D:</strong>

5D additive manufacturing (Cladding 5D, Non-planar slicing). Note: Additive Planar 3D operations are NOT included.

### License settings

| Type | Descroption | Availability |
|---|---|---|
| Netlock | Local license server. Supports floating licenses. Useful for customers with restricted internet access | Not available with Online protection type |

| Block internet activity | Disables all online features, no data exchange with any servers. Important: Excluding work with network licenses and third-party modules. | Free for all license types |
| Enable Virtual PC | Enables the ability to run ENCY software on a virtual machine, for example when using Parallels on an Apple MacBook | Free for all license types |

#### License protection types

| Type | Description |
|---|---|
| Dongle | A hardware security dongle is required. Supported dongle types include HASP, Matrix, and Guardant. |
| Online | Access is provided through a username and password. An internet connection is required. |
| Software | Local License File; an internet connection is not required to run the software; is transferable via deactivation workflow. Delivery and Activation Process: - If the customer has an internet connection, the license file is downloaded automatically after the customer is authorized in the License Manager. - If the customer does not have an internet connection, the license file can be delivered via email or external storage. Offline activation is supported. Deactivation workflow: - If the customer has an internet connection, the deactivation process is performed online directly in the License Manager. The license is released automatically and becomes available for activation on another device. |

#### License duration

Perpetual: Perpetual license (license without time limitations)

Subscription: Software subscription for a period from 3 months to 1 year. After three years of active subscription, the user is entitled to convert the subscription into a perpetual license. The cost of maintenance is not included and must be paid separately. is deployed in single [configuration](10390.md).
