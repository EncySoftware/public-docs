# Configurations and options

## ENCY configurations

### Premium Configurations

Premium configurations include: 2D sketching, 3D modeling, dimensioning and geometry transformation; import of CAD formats such as IGES, STL, VRML, PostScript, DXF, Rhinoceros, Sprut Models, Parasolid, STEP, Sprut geometry format, SW, SE, PLY, AMF, JTOpen, PLMXML, 5DC, and OSD; add-ins for integration with popular CAD systems; high-end 3D machining simulation with G-code verification support; setup sheet generator; support for probing operations; tool library; equipment library; MachineMaker for importing, assembling, and configuring digital twins of machines and robots; postprocessor generator; a set of basic postprocessors and interpreters.

### Bound Configurations

Bound license is tied to a specific machine or robotic cell and includes all the features of the Premium configurations, except for: MachineMaker, the postprocessor generator and the set of basic postprocessors and interpreters.

### Applications

#### Cutting

Cutting 2D: 2D cutting (Hole machining, FBM Mill, 2D contouring, 2.5D contouring, Jet cutting). Nesting included.

Cutting 5D: Multi-axis cutting (3D contouring, 6D contouring, Chamfering, Jet cutting 5D), includes all features of Cutting 2D; 3+2 indexed multi-axis machining with local coordinate systems, TCPM supported. Nesting included.

Cutting 5D Advanced: Multi-axis cutting, includes all features of Cutting 5D plus the extended 6D contouring operation: Feature Recognition (Circle, Rectangle, Rounded Rectangle, Slot, Polygon, Keyhole), NC cycle output and Support Generator. Equivalent to Cutting 5D with the Laser Cutting PRO option. Nesting included.

#### Milling

2.5x Mill: 2.5-axis milling (Hole machining, FBM Mill, 2D contouring, Engraving, Pocketing, 2.5D contouring, Face milling, Roughing waterline limited to machining pockets with vertical walls only, Flat land, Chamfering, Jet cutting). 3+2 indexed multi-axis machining with local coordinate systems. Nesting included.

3x Mill: 3-axis milling (Roughing waterline, Finishing waterline, Roughing plane, Finishing plane, 3D contouring, Combo Finish offering Plane and Waterline strategies and their combination, without Scallop machining), includes all features of 2.5x Mill. 3+2 indexed multi-axis machining with local coordinate systems. Nesting included.

3x Mill Advanced: 3-axis advanced milling (Scallop, Morph, 3D Helical, 5D surfacing (limited to generate only 3-axis toolpath), Undercut waterline, Combo Finish), includes all features of 2.5x Mill, 3x Mill. 3+2 indexed multi-axis machining with local coordinate systems. Combo Finish is a 3D finishing operation offering Plane, Waterline, and Scallop machining strategies, as well as their combinations, for efficient machining of complex surfaces. Nesting included.

Rotary: 4-axis continuous milling (Rotary waterline, Rotary roughing, Rotary finishing, 4D surfacing, Morph 4D, 4D contouring), includes all features of 2.5x Mill, 3x Mill, and 3x Mill Advanced. 3+2 indexed multi-axis machining with local coordinate systems. Nesting included.

5x Mill: 5-axis continuous milling (5D surfacing, 6D contouring, 5D by meshes, Morph 5D, Jet cutting 5D), includes all features of 2.5x Mill, 3x Mill, 3x Mill Advanced, and Rotary. 3+2 indexed multi-axis machining with local coordinate systems, TCPM supported. Adaptive Tilting and Nesting included.

5x Mill Advanced: 5-axis advanced continuous milling (Swarf, 5D Roughing waterline, Turbomachinery PRO), includes all features of 2.5x Mill, 3x Mill, 3x Mill Advanced, Rotary, and 5x Mill. 3+2 indexed multi-axis machining with local coordinate systems, TCPM supported. Turbomachinery PRO (Impeller Machining and Blade Machining operations), Adaptive Tilting and Nesting included.

#### Turning

Lathe: 2-axis turning (Lathe facing, OD roughing, ID roughing, OD finishing, ID finishing, OD grooving, ID grooving, Face grooving, OD adaptive turning, OD threading, ID threading, Profile threading, Lathe part-off, Part-off with takeover, Lathe hole machining), bar feeding and part transfer operations (Bar feeding, Sub spindle working, Turn take over).

#### WireEDM

Wire EDM: 2-axis, tilted, and 4-axis wire EDM
