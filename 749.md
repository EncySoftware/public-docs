# Trabalho com a área de transferência

No painel de ferramentas da [janela da estrutura do modelo](718.md), você também encontrará os botões para trabalhar com o buffer de troca (cortar, copiar e colar).

- ![images/download/attachments/157859473/88-24-cut.png](assets/images/download/attachments/157859473/88-24-cut.png) - Mover objetos selecionados para a área de transferência.
- ![images/download/thumbnails/157859473/89-24-Copy.png](assets/images/download/thumbnails/157859473/89-24-Copy.png) - Copiar objetos selecionados para a área de transferência.
- ![images/download/thumbnails/157859473/90-24-Paste.png](assets/images/download/thumbnails/157859473/90-24-Paste.png) - Insere os objetos da área de transferência no grupo atual.

Os objetos copiados ou cortados podem ser inseridos repetidamente na pasta ativa no momento.

As funções são duplicadas no menu de contexto (clique com o botão direito do mouse) na [janela gráfica](169.md). O acesso às funções também é possível com o uso das teclas de atalho: [Ctrl+X], [Ctrl+C], [Ctrl+V].
