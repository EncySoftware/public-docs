# Working with the exchange buffer

On the tool panel in the [model structure window](718.md) you will also find the buttons for working with the exchange buffer (cut, copy & paste).

- ![images/download/attachments/157859473/88-24-cut.png](assets/images/download/attachments/157859473/88-24-cut.png) – Move selected objects to the clipboard.
- ![images/download/thumbnails/157859473/89-24-Copy.png](assets/images/download/thumbnails/157859473/89-24-Copy.png) – Copy selected objects to the clipboard.
- ![images/download/thumbnails/157859473/90-24-Paste.png](assets/images/download/thumbnails/157859473/90-24-Paste.png) – Insert the objects from the clipboard to the current group.

Copied or cut objects can be repeatedly inserted into the currently active folder.

The functions are duplicated in the context menu (right mouse click) in the [graphic window](169.md). Access to the functions is also possible by using the shortcut keys: [Ctrl+X], [Ctrl+C], [Ctrl+V].
