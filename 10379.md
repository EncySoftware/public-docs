**G-code based** **operation** ![images/download/thumbnails/157867906/NCBasedMilling_Ico.bmp](assets/images/download/thumbnails/157867906/NCBasedMilling_Ico.bmp) and **G-code based lathe operation** ![images/download/thumbnails/157867906/NCBasedLathe_Ico.png](assets/images/download/thumbnails/157867906/NCBasedLathe_Ico.png) operations located in **Auxiliary** list. It can be also used for indexed and continuous processing at 4 and 5 coordinate machining centers. All available simulation types are supported, including additive manufacturing to simulate material layer buildup.

> Note:
>
> - ![images/download/thumbnails/157867906/NCBasedMilling_Ico.bmp](assets/images/download/thumbnails/157867906/NCBasedMilling_Ico.bmp) **G-code based operation** does not support the turning tool.
> - ![images/download/thumbnails/157867906/NCBasedLathe_Ico.png](assets/images/download/thumbnails/157867906/NCBasedLathe_Ico.png) **G-code based lathe operation** supports only turning tool.
> - <strong>Both operations</strong> do not support Wire EDM machining.

These operations allow you to perform:

- direct control of the machine simulation using G-codes;
- check and optimize the NC program;
- convert the text of the NC from one controller to another (for machines with identical kinematic scheme);
- debug your own interpreter during its creation.

The toolpath is formed on the basis of the following operation parameters:

- **Specified NC text** on the ![images/download/thumbnails/157867906/image2024-7-30_13-41-35.png](assets/images/download/thumbnails/157867906/image2024-7-30_13-41-35.png) [Job assignment](301.md) parameters panel;
- <strong>Selected interpreter</strong> on the ![images/download/thumbnails/157867906/image2024-7-30_13-41-56.png](assets/images/download/thumbnails/157867906/image2024-7-30_13-41-56.png) **Strategy** parameters panel;
- <strong>Assigned tool</strong> on the ![images/download/thumbnails/157867906/image2024-7-30_13-42-19.png](assets/images/download/thumbnails/157867906/image2024-7-30_13-42-19.png) [Tool](37.md) parameters panel.

![images/download/thumbnails/157867906/NCFile.png](assets/images/download/thumbnails/157867906/NCFile.png) **The NC text** can be written manually or can be loaded from an external file and edited, if necessary. The built-in text editor supports syntax highlighting of the main key structures of the CNC programming language, as well as a wide range of [keyboard shortcuts for working with text](10381.md).

> More detailed information about the possibilities of working with the NC text is described in the section [Job assignment for G-code based operation, G-code based lathe operation](10380.md)

![images/download/thumbnails/157867906/SNCIFile.png](assets/images/download/thumbnails/157867906/SNCIFile.png) [<strong>Interpreter file (*.snci)</strong>](10020.md) defines the format of recognition of the controller commands in blocks of the NC program. The corresponding parameter specifies the full path to the selected interpreter. The parameter value can be entered manually as well as by using the file selection dialogue, which is accessed by using the ![images/download/attachments/157867906/image2024-7-30_14-0-53.png](assets/images/download/attachments/157867906/image2024-7-30_14-0-53.png) entered button. During the selection process, selection process, a preview of the interpreter information is available (description, purpose, CNC system, authors, etc.):

![images/download/attachments/157867906/image2024-7-30_13-50-59.png](assets/images/download/attachments/157867906/image2024-7-30_13-50-59.png)

The ability to select an interpreter from the container is [supported](10291.md).

![images/download/thumbnails/157867906/MCD2CLDConversion.bmp](assets/images/download/thumbnails/157867906/MCD2CLDConversion.bmp) **Use advanced toolpath transformation**- this parameter converts the NC toolpath from machine to geometric. Which, in turn, makes it possible to correct the toolpath using the robot axes map. If the setting is disabled, then the final toolpath is formed (as closely as possible repeating the one specified in the NC program), without the possibility of changing it.

![images/download/thumbnails/157867906/PhysicGOTOStep.bmp](assets/images/download/thumbnails/157867906/PhysicGOTOStep.bmp) **Step of physic movements dividing** - available only when using **Use advanced toolpath transformation** (see above). In this mode, at the first stage, the tool path is converted into a geometric curve. At the next stage, machine movements are rasterized with the step specified in the current parameter to ensure maximum similarity with the original toolpath. The smaller the value of the rasterization step, the higher the accuracy of construction and, accordingly, the similarity with the original toolpath.

![images/download/thumbnails/157867906/InsertUnknown.bmp](assets/images/download/thumbnails/157867906/InsertUnknown.bmp) **Add unrecognized commands in the trajectory** - this parameter adds all commands of the control program not recognized by the interpreter to the toolpath. Unrecognized commands are added to the tool path description as a technology command parameter **INSERT** before the recognized commands.

When creating G-code based operations, it is assigned a default tool for appropriate processing (milling or turning).
