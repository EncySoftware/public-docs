# File dell'interprete

I file dell'interprete per i singoli sistemi CNC hanno l'estensione SNCI (*.snci). Per ogni sistema CNC esiste un file di configurazione specifico. Il file di configurazione contiene tutti i dati relativi all'unità CNC e i sottoprogrammi per l'elaborazione del programma di lavorazione. Il file di configurazione contiene informazioni sul sistema CNC e un riferimento alla libreria software che implementa l'interpretazione del programma NC in un insieme di comandi di lavorazione per questo sistema.

Il file dell'interprete viene utilizzato quando è attivata la modalità di [simulazione della lavorazione tramite programma NC](10291.md) e nelle [operazioni basate su codice G](10379.md).

I file dell'interprete possono essere inseriti in [contenitori zip crittografati](10022.md) con estensione .stfc.
