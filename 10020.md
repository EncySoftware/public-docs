# Arquivos de interpretador

Os arquivos de interpretador para comandos CNC específicos têm a extensão SNCI (*.snci). Existe um arquivo de configuração exclusivo para cada comando CNC. O arquivo de configuração contém todos os dados do comando CNC e as sub-rotinas de processamento do programa de usinagem. O arquivo de configuração contém informações sobre o comando CNC e uma referência à biblioteca de software que interpreta o programa NC e o converte em um conjunto de comandos de usinagem para esse sistema.

O arquivo de interpretador é utilizado quando o modo de [simulação da usinagem pelo programa NC](10291.md) está ativado e nas [operações baseadas em código G](10379.md).

Os arquivos de interpretador podem ser armazenados em [contêineres ZIP criptografados](10022.md) com a extensão .stfc.
