# Arquivos do sistema

Principais arquivos executáveis de um sistema:

- <strong>ency.exe</strong> — módulo de sistema executável.
- <strong>InP.exe</strong> — módulo executável do **Postprocessors generator**.
- <strong>SCUpdater.exe</strong> — módulo executável de atualização do programa.

Arquivos desse tipo podem ser importados para ENCY:

- [*.igs, *.iges](266.md) — formato de arquivo Initial Graphics Exchange Specification;
- [*.dxf](802.md) — formato Drawing Exchange Format da Autodesk™;
- [*.stl](270.md) — formato de arquivo CAD nativo de estereolitografia;
- [*.vrl](721.md) — formato de arquivo Virtual Reality Modeling Language;
- [*.ps](268.md) — formato de arquivo PostScript;
- [*.eps](268.md) — formato de arquivo Encapsulated PostScript;
- [*.x_t, *x_b](267.md) — formato de arquivo do kernel Parasolid™;
- [*.sldasm, *.sldprt](10034.md) — formato de arquivo de projeto nativo do SolidWorks™;
- [*.asm, *.par, *.psm, *.pwd](10035.md) — formato de arquivo de projeto nativo do SolidEdge™;
- [*.3dm](265.md) — formato de arquivo de projeto nativo do Rhinoceros™;
- [*.step, *.stp](10030.md) — STEP, um padrão moderno para troca de dados 3D;

- <strong>*.stcp</strong> — arquivos de projeto do sistema contendo todas as informações sobre o projeto, como modelos geométricos, operações de usinagem, percursos da ferramenta etc. A extensão <strong>*.stc</strong> usada anteriormente também é suportada;
- <strong>*.stcx</strong> — arquivos de projeto no formato XML. O projeto também é salvo no formato <strong>*.stcp</strong>;
- <strong>*.sto</strong> — arquivos que contêm informações sobre operações, incluindo a estrutura e os parâmetros das operações dentro de um projeto;
- <strong>*.dxf, *.eps, *.ps</strong> — arquivos contendo informações de geometria 2D;
- <strong>*.stl</strong> — arquivos contendo resultados de simulação;
- <strong>*.xml</strong> — arquivos contendo informações do percurso da ferramenta para simuladores externos;
- <strong>*.spp, *.inp, *.sppx</strong> — arquivos de configuração de pós-processadores para vários comandos CNC, usados pelo ENCY e pelo **Postprocessors generator**.
- <strong>*.stfc</strong> — arquivo de contêiner zip que pode conter quaisquer outros arquivos do sistema (pós-processadores, esquemas de máquina, projetos etc.). O conteúdo pode ser criptografado e assinado digitalmente;
- <strong>*.snci</strong> — arquivos de configuração de interpretadores para vários comandos CNC, usados pelo ENCY no modo de [simulação da usinagem pelo programa NC](10291.md) e nas [operações baseadas em código G](10379.md).
- <strong>*.dsk, *.cfg</strong> — arquivos contendo dados sobre as configurações da tela do sistema. Eles são gerados automaticamente se estiverem ausentes.

Outros arquivos e pastas criados durante a instalação são essenciais para o bom funcionamento do programa. Modificar ou excluir esses arquivos pode impedir que o programa funcione corretamente. A substituição de arquivos só deve ser feita durante as atualizações de versão e deve ser executada em estrita conformidade com as instruções de atualização fornecidas.
