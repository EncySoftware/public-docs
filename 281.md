# File di sistema

File eseguibili principali del sistema:

- <strong>ency.exe</strong> — modulo eseguibile del sistema.
- <strong>InP.exe</strong> — modulo eseguibile **Postprocessors generator** (generatore di postprocessori).
- <strong>SCUpdater.exe</strong> — modulo eseguibile per l'aggiornamento del programma.

In ENCY è possibile importare file dei seguenti tipi:

- [*.igs, *.iges](266.md) — formato file Initial Graphics Exchange Specification;
- [*.dxf](802.md) — Drawing Exchange Format di Autodesk™;
- [*.stl](270.md) — formato file CAD nativo di stereolitografia;
- [*.vrl](721.md) — formato file Virtual Reality Modeling Language;
- [*.ps](268.md) — formato file PostScript;
- [*.eps](268.md) — formato file Encapsulated PostScript;
- [*.x_t, *x_b](267.md) — formato file del kernel Parasolid™;
- [*.sldasm, *.sldprt](10034.md) — formato file di progetto nativo di SolidWorks™;
- [*.asm, *.par, *.psm, *.pwd](10035.md) — formato file di progetto nativo di SolidEdge™;
- [*.3dm](265.md) — formato file di progetto nativo di Rhinoceros™;
- [*.step, *.stp](10030.md) — STEP, uno standard moderno per lo scambio di dati 3D;

- <strong>*.stcp</strong> — file di progetto del sistema contenenti tutte le informazioni sul progetto, quali modelli geometrici, operazioni di lavorazione, percorsi utensile e così via. È supportata anche l'estensione <strong>*.stc</strong> utilizzata in precedenza;
- <strong>*.stcx</strong> — file di progetto in formato XML. Il progetto viene salvato anche nel formato <strong>*.stcp</strong>;
- <strong>*.sto</strong> — file che contengono informazioni sulle operazioni, inclusi la struttura e i parametri delle operazioni all'interno di un progetto;
- <strong>*.dxf, *.eps, *.ps</strong> — file contenenti informazioni sulla geometria 2D;
- <strong>*.stl</strong> — file contenenti i risultati della simulazione;
- <strong>*.xml</strong> — file contenenti informazioni sul percorso utensile per simulatori esterni;
- <strong>*.spp, *.inp, *.sppx</strong> — file di configurazione dei postprocessori per vari sistemi CNC, utilizzati da ENCY e dal **Postprocessors generator**.
- <strong>*.stfc</strong> — file contenitore zip che può contenere qualsiasi altro file di sistema (postprocessori, schemi macchina, progetti e così via). Il contenuto può essere cifrato e firmato digitalmente;
- <strong>*.snci</strong> — file di configurazione dell'interprete per vari sistemi CNC, utilizzati da ENCY nella modalità [Simulazione della lavorazione tramite programma NC](10291.md) e nelle [operazioni basate su codice G](10379.md).
- <strong>*.dsk, *.cfg</strong> — file contenenti i dati sulle impostazioni dello schermo del sistema. Vengono generati automaticamente se mancanti.

Gli altri file e cartelle creati durante l'installazione sono essenziali per il corretto funzionamento del programma. La modifica o l'eliminazione di questi file può impedire il corretto funzionamento del programma. La sostituzione dei file deve essere eseguita solo durante gli aggiornamenti di versione e in stretta conformità con le istruzioni di aggiornamento fornite.
