<a id="application-area"></a>

## Anwendungsbereich:

Dieses Kapitel beschreibt Start, Pflichteingaben, Fortschritt, Pausen, Haltepunkte und vorübergehende Parameteränderungen.

<a id="running-a-macro"></a>

### Makro starten

- Suchen Sie das Makro in der Liste, bei Bedarf mit **Search**.

- Klappen Sie es auf und passen Sie gegebenenfalls Werte für diesen Lauf an.

- Klicken Sie auf **Run**. Die Schritte werden nacheinander auf das aktuelle Projekt angewendet.

<a id="required-inputs-before-a-run"></a>

### Pflichteingaben

Bei leeren Pflichtfeldern startet das Makro nicht. Es wird aufgeklappt und das erste leere Feld rot umrandet. Geben Sie einen Wert ein oder wählen Sie die Geometrie neu und klicken Sie erneut auf **Run**.

<a id="following-progress"></a>

### Fortschritt verfolgen

Während der Ausführung:

- markiert ein grüner Punkt den aktuellen Schritt;

- kennzeichnet ein grünes Häkchen abgeschlossene Schritte, während noch nicht erreichte Schritte abgeblendet sind;

- zeigt der Zähler den Fortschritt als aktuell/gesamt, beispielsweise **9/17**.

<a id="pausing-and-continuing"></a>

### Anhalten und fortsetzen

Während der Ausführung hält **Run** nach dem aktuellen Schritt an. In der Pause zeigt die Schaltfläche **Continue** zum Fortsetzen. **Break** bricht die Ausführung ab.

<a id="stopping-at-a-breakpoint"></a>

### Haltepunkte

Für eine Pause an einem bestimmten Schritt:

1. Klicken Sie auf dessen Statuspunkt. Ein weiterer Klick entfernt den Haltepunkt. Am gerade laufenden Schritt kann kein Haltepunkt gesetzt werden.

2. Beim Erreichen wird pausiert und **Continue** angezeigt.

3. Prüfen Sie das Ergebnis und setzen Sie mit **Continue** fort oder brechen Sie mit **Break** ab.

Haltepunkte eignen sich zur schrittweisen Prüfung eines neuen Makros.

<a id="overriding-values-for-one-run"></a>

### Werte für einen Lauf ändern

Klappen Sie das gespeicherte Makro auf, ändern Sie seine Felder und starten Sie es. Die Werte gelten nur für diesen Lauf. Dauerhafte Änderungen werden im Bearbeitungsmodus gespeichert.

> Ein laufendes Makro kann nicht gelöscht werden.
