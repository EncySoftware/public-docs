# Getting trial license

Before purchasing our software, we offer you a trial license so that you can test our product on your device and machine.

## Step-by-step guide

1. First you need to go to the main page of the site [encycam.com](https://encycam.com/)
2. Next, click the <strong>Sign in</strong> button located in the upper-right corner of the site.
3. Follow the appropriate link to fill out the registration form.
4. Fill out the registration form by providing the following information:
  - First name
  - Last name
  - Email
  - Country
  - Password
5. Check the correctness of the entered data and click the <strong>Register</strong> button.
6. After successful registration, you will be automatically redirected to the main page of the site [encycam.com](https://encycam.com/). ![images/download/thumbnails/157868036/MyAccount_En.png](assets/images/download/thumbnails/157868036/MyAccount_En.png) icon should appear in the upper right corner of the site.
7. To download the program distribution, you need to go to the <strong>Downloads</strong> → <strong>Software Products</strong>.
8. And click the <strong>Download (.exe)</strong> button.
9. Once the download is complete, run the downloaded file to begin the program installation process.
10. Complete the installation of the program by following the on-screen prompts provided.
11. After installation is complete, click the <strong>Run</strong> button in the program installer window.
12. Click the <strong>Sign In</strong> button in the License Manager window that opens.
13. Enter the email address and password you specified during registration and click the <strong>Sign In</strong> button.
14. Wait a few seconds while authorization occurs.
15. Complete the login in your browser by clicking the <strong>Open in desktop app</strong> button.
16. Close the browser tab and return to the application.
17. The trial license should appear in the License Manager list.
18. Click the <strong>Run ENCY</strong> button.
