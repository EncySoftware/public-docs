# Testlizenz erhalten

Mit einer Testlizenz können Sie die Software vor dem Kauf auf Ihrem Computer und für Ihre Maschine erproben.

<a id="step-by-step-guide"></a>

## Vorgehensweise

1. Öffnen Sie [encycam.com](https://encycam.com/).
2. Klicken Sie rechts oben auf **Sign in**.
3. Öffnen Sie den Link zur Registrierung.
4. Geben Sie Vorname, Nachname, E-Mail-Adresse, Land und Passwort ein.
5. Prüfen Sie die Angaben und klicken Sie auf **Register**.
6. Nach der Registrierung erscheint auf [encycam.com](https://encycam.com/) rechts oben das Kontosymbol ![Benutzerkonto](assets/images/download/thumbnails/157868036/MyAccount_En.png).
7. Öffnen Sie **Downloads → Software Products**.
8. Klicken Sie auf **Download (.exe)**.
9. Starten Sie die heruntergeladene Installationsdatei.
10. Folgen Sie den Installationsanweisungen.
11. Klicken Sie nach Abschluss auf **Run**.
12. Klicken Sie im Lizenzmanager auf **Sign In**.
13. Geben Sie Ihre registrierte E-Mail-Adresse und Ihr Passwort ein und bestätigen Sie mit **Sign In**.
14. Warten Sie auf den Abschluss der Anmeldung.
15. Bestätigen Sie im Browser mit **Open in desktop app**.
16. Schließen Sie die Browserregisterkarte und kehren Sie zur Anwendung zurück.
17. Die Testlizenz sollte in der Lizenzliste erscheinen.
18. Klicken Sie auf **Run ENCY**.

> **Lizenzinformationen**
>
> Klicken Sie oben links auf das Programmsymbol und wählen Sie **Version**. Das Fenster zeigt Lizenz-ID, Schutzart, verbleibende Laufzeit und Händlerinformationen.
