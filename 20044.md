# Ottenere la licenza di prova

Prima di acquistare il nostro software, offriamo una licenza di prova per poter testare il prodotto sul proprio dispositivo e sulla propria macchina.

<a id="step-by-step-guide"></a>

## Guida passo-passo

1. Accedere innanzitutto alla pagina principale del sito [encycam.com](https://encycam.com/)
2. Fare quindi clic sul pulsante <strong>Sign in</strong> (accedi) nell'angolo superiore destro del sito.
3. Seguire il collegamento appropriato per compilare il modulo di registrazione.
4. Compilare il modulo di registrazione fornendo le seguenti informazioni:
  - Nome
  - Cognome
  - E-mail
  - Paese
  - Password
5. Verificare la correttezza dei dati inseriti e fare clic sul pulsante <strong>Register</strong> (registrati).
6. Dopo la registrazione riuscita, si verrà reindirizzati automaticamente alla pagina principale del sito [encycam.com](https://encycam.com/). Nell'angolo superiore destro del sito dovrebbe comparire l'icona ![images/download/thumbnails/157868036/MyAccount_En.png](assets/images/download/thumbnails/157868036/MyAccount_En.png).
7. Per scaricare il programma di installazione, accedere a <strong>Downloads</strong> → <strong>Software Products</strong>.
8. Fare quindi clic sul pulsante <strong>Download (.exe)</strong>.
9. Al termine del download, eseguire il file scaricato per avviare il processo di installazione del programma.
10. Completare l'installazione del programma seguendo le istruzioni visualizzate a schermo.
11. Al termine dell'installazione, fare clic sul pulsante <strong>Run</strong> (esegui) nella finestra del programma di installazione.
12. Fare clic sul pulsante <strong>Sign In</strong> (accedi) nella finestra License Manager che si apre.
13. Inserire l'indirizzo e-mail e la password specificati durante la registrazione e fare clic sul pulsante <strong>Sign In</strong>.
14. Attendere alcuni secondi durante l'autorizzazione.
15. Completare l'accesso nel browser facendo clic sul pulsante <strong>Open in desktop app</strong> (apri nell'app desktop).
16. Chiudere la scheda del browser e tornare all'applicazione.
17. La licenza di prova dovrebbe comparire nell'elenco di License Manager.
18. Fare clic sul pulsante <strong>Run ENCY</strong> (avvia ENCY).

> Informazioni sulla licenza
>
> Per ottenere maggiori informazioni sulla licenza del sistema CAM
>
> 1. Fare clic sull'icona del programma nell'angolo superiore sinistro dello schermo
> 2. Selezionare la voce di menu <strong>Version</strong> (versione) dall'elenco a discesa
>
> Nella nuova finestra vengono visualizzate le seguenti informazioni:
>
> - ID licenza
> - Protezione
> - Tempo rimanente
> - Informazioni sul rivenditore
