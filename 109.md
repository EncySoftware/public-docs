# Importação de objetos geométricos

A importação de modelos de arquivos CAD externos é realizada clicando no botão ![images/download/thumbnails/157859482/image2024-7-2_17-48-56.png](assets/images/download/thumbnails/157859482/image2024-7-2_17-48-56.png) ou simplesmente arrastando o arquivo do modelo para a janela do aplicativo. A função também está disponível no [menu principal](51.md), em File –> Import, e pela tecla de atalho [ Ctrl+I ].

Na janela de seleção de arquivos, é possível especificar filtros de extensão de arquivo. O conjunto de formatos de arquivo suportados depende da configuração do sistema CAM e dos [suplementos](10039.md) instalados.

Durante o processo de importação de arquivos CAD externos, as informações atuais sobre o progresso do processo de leitura do arquivo e a criação de objetos geométricos são exibidas na janela. Um indicador de processo reflete a porcentagem da função de importação concluída. Ao importar de arquivos com uma estrutura simples, o sistema usa um algoritmo de passagem única, ou seja, a leitura do arquivo e a formação do modelo geométrico são realizadas simultaneamente. Ao importar de arquivos com uma estrutura de dados complexa, o sistema usa um algoritmo de dupla passagem. No primeiro estágio, o sistema lê o arquivo e analisa a estrutura do modelo e, no segundo, cria o modelo geométrico.

![images/download/attachments/157859482/image2024-7-2_17-50-31.png](assets/images/download/attachments/157859482/image2024-7-2_17-50-31.png)

O painel **Loaded from file** mostra dados estatísticos sobre a leitura do arquivo:

- **Entities** - contador de entidades carregadas;
- **Solids** - contador de sólidos carregados;
- **Faces** - contador de faces carregadas (superfícies delimitadas);
- **Surfaces** - contador de superfícies carregadas;
- **Curves** - contador de curvas carregadas;
- **Ignored** - contador de entidades ignoradas (insignificantes, incorretas ou sem suporte);
- **Total** - número total de entidades carregadas.

O painel **Convertido em modelo** exibe dados estatísticos sobre a conversão dos dados lidos no modelo interno:

- **Analyzed** - o contador de entidades convertidas;
- **Solids** - o contador de sólidos convertidos;
- **Faces** - o contador de faces convertidas;
- **Curves** - o contador de curvas convertidas;
- **Ignored** - o contador de entidades ignoradas.

Todas as referências topológicas entre os objetos são analisadas exatamente no estágio de criação do modelo interno. Além disso, a partir de um grande número de componentes, os objetos complexos são formados (Sólidos, Faces). Todos os objetos simples (curvas/pontos etc.) dentro dos objetos mais complexos são duplicados adicionalmente na forma de objetos independentes. Portanto, o número total de objetos carregados do arquivo é, na verdade, maior do que os convertidos em um modelo.

Por exemplo, uma face consiste em uma superfície ilimitada e várias curvas restritivas. Ao ler o arquivo, a face e todo o seu conteúdo são contados nos campos apropriados do contador. No entanto, ao criar o modelo interno, todos esses elementos são contados como uma única face.

Clicar no botão **Stop** durante a importação interromperá o processo de carregamento.

Durante o processo de importação, o sistema analisa o modelo importado e, se houver erros ou registros inadequados ou tipos de dados não suportados, é criada uma mensagem de relatório correspondente. As mensagens de erro são exibidas em uma janela auxiliar, que é aberta quando se clica no botão **Errors**. O botão fica disponível somente se houver erros durante o processo de importação. Se ocorrerem erros fatais, o carregamento do arquivo será encerrado. Se ocorrerem erros, é recomendável estudar mais detalhadamente os recursos específicos de importação desse formato de arquivo e seguir as recomendações sobre como evitar tais erros.

Se a caixa **Close the window automatically** estiver marcada e não houver erros, a janela será fechada automaticamente após a conclusão do processo de importação. Se a marca de verificação estiver desativada ou se houver erros durante a importação, o sistema aguardará o pressionamento do botão **Ok** para prosseguir.

<em>Observação: Somente serão importados os tipos de objetos definidos na janela de [configurações do sistema](90.md), na aba [**Import**](264.md). Os elementos de outros tipos são ignorados.</em>

<em>Observação: Se for necessário transformar tipos de curvas, o desvio máximo durante a aproximação será menor do que o valor definido no campo **Curves approximation tolerance** na mesma janela.</em>
