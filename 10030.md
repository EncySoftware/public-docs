# Importazione di oggetti da file STEP

**STEP** - Standard for Exchange of Product model data. Il formato di un file **STEP** è definito dalla norma ISO 10303-21 (parte 21 - rappresentazione della forma geometrica). Il formato **STEP** consente il trasferimento di numerosi tipi diversi di oggetti geometrici. Per questo motivo è possibile trasferire dati tra sistemi diversi praticamente senza distorsioni. Il formato **STEP** è ampiamente utilizzato, in particolare nei settori in cui è richiesta un'elevata precisione nella trasmissione dei dati a causa di modelli geometrici tridimensionali molto complessi.

Supporta i seguenti tipi di modello

- wireframe (modelli a fil di ferro);
- superfici;
- solidi.

File di schema

- CONFIG_CONTROL_DESIGN;
- AUTOMOTIVE_DESIGN.

Le estensioni standard dei file sono.<em>step</em>;.<em>stp</em>.
