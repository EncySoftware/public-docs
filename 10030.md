# Importação de objetos de arquivos STEP

**STEP** significa *Standard for Exchange of Product model data*, padrão para intercâmbio de dados de modelos de produto. O formato de arquivo **STEP** é definido na ISO 10303-21 (parte 21 – representação da forma geométrica). O formato **STEP** permite transferir uma grande variedade de tipos de objetos geométricos. Por isso, é possível transferir dados entre diferentes sistemas praticamente sem distorções. O formato **STEP** é amplamente utilizado, sobretudo em áreas em que modelos geométricos tridimensionais muito complexos exigem alta precisão na transmissão de dados.

São suportados os seguintes tipos de modelo:

- aramados;
- de superfícies;
- corpos sólidos.

Esquemas suportados:

- CONFIG_CONTROL_DESIGN;
- AUTOMOTIVE_DESIGN.

As extensões padrão são .step e .stp.
