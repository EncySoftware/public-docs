# Scripts no ENCY

O ENCY pode ser estendido e personalizado por meio de scripts.

O ENCY utiliza um [mecanismo de scripts](10347.md).

Há três formas de usar scripts no ENCY:

- Criar operações com script. O código fornecido pelo usuário modifica os parâmetros do percurso da ferramenta ou gera o percurso completo.
- Inserir scripts no processo de cálculo de uma operação. Esses scripts são executados quando um comando é adicionado ao percurso.
- Executar um script na inicialização do ENCY.
