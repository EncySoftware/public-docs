# Skripte in ENCY

ENCY kann durch Skripte erweitert und angepasst werden.

ENCY verwendet eine [Skript-Engine](10347.md).

Skripte können auf drei Arten eingesetzt werden:

- Als skriptgesteuerte Operationen, die Werkzeugwegparameter ändern oder den gesamten Werkzeugweg erzeugen.
- Als Bestandteil der Operationsberechnung. Diese Skripte werden ausgeführt, wenn ein Befehl zum Werkzeugweg hinzugefügt wird.
- Beim Start von ENCY.
