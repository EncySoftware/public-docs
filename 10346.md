# Script in ENCY

ENCY può essere esteso e personalizzato mediante script.

ENCY utilizza un [motore di script](10347.md).

Esistono tre modi per utilizzare gli script in ENCY.

- Creare operazioni con script. Le operazioni con script utilizzano una programmazione fornita dall'utente per modificare i parametri del percorso utensile o per creare l'intero percorso utensile.
- Inserire script nel processo di calcolo dell'operazione. Questi script vengono eseguiti quando un comando viene aggiunto al percorso utensile.
- Eseguire uno script all'avvio di ENCY.
