# Struktur der Operationsgruppen

<a id="application-area"></a>

## Anwendungsbereich:

Operationsgruppen strukturieren den Bearbeitungsprozess.

<a id="die-besonderheiten-der-arbeit"></a>

## Aufbau

Der Operationsbaum bildet die Bearbeitungsstruktur hierarchisch ab. Unter **Structures group** liegen Knoten vom Typ **Part** oder **Part Copy**. Darunter können **Multiply Group**-Knoten angeordnet werden.

Die Operationen befinden sich innerhalb dieser Gruppen.

![images/download/attachments/157862904/image2024-7-8_17-43-12.png](assets/images/download/attachments/157862904/image2024-7-8_17-43-12.png)

Die Registerkarten der Gruppen entsprechen den Einstellungen der Anlagenstruktur. Wird eine Untergruppe hinzugefügt, übernimmt sie einen Teil der Parameter der übergeordneten Gruppe. Diese Parameter werden dann in der übergeordneten Gruppe ausgeblendet.

![images/download/attachments/157862904/image2024-7-8_17-47-56.png](assets/images/download/attachments/157862904/image2024-7-8_17-47-56.png)
