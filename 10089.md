# FBM Mill

**Feature Based Machining – merkmalsbasierte Bearbeitung**

Ein Fertigungsmerkmal ist ein Bauteilelement, das mit einem standardisierten Verfahren hergestellt werden kann, beispielsweise eine Bohrung, Tasche, Nut oder Fase.

Die merkmalsbasierte Bearbeitung (FBM) erkennt solche Merkmale und erzeugt Bearbeitungsprozesse automatisch oder mit Benutzerunterstützung anhand ihrer Eigenschaften und einer Bearbeitungswissensbasis.

**FBM-Mill-Gruppe**

FBM Mill ist eine Gruppenoperation für die merkmalsbasierte Bearbeitung.

Beim Erstellen erkennt das System die bekannten Merkmale des Bauteils. Anschließend wählen Sie vordefinierte oder gespeicherte Verfahren aus der FBM-Bibliothek. Das System erzeugt die benötigten Operationen und sortiert sie nach den aktuellen Regeln, beispielsweise zur Verringerung von Werkzeugwechseln.
