# FBM Mill

Feature Based Machining (lavorazione basata su feature)

Una feature di fabbricazione è un componente di un pezzo che può essere realizzato con un processo di lavorazione standard. Esempi di feature sono fori, tasche, cave, gole e smussi.

La Feature Based Machining (FBM) è un approccio CAM basato sul riconoscimento delle feature e sulla generazione, automatica o semiautomatica, di processi di lavorazione a partire dalle informazioni ricavate dalle feature riconosciute e da una base di conoscenze di lavorazione (Machining Knowledge Base).

Gruppo FBM Mill

Il gruppo FBM Mill è un'operazione di gruppo del sistema CAM che consente di eseguire la lavorazione basata su feature.

Quando si crea una nuova operazione di gruppo FBM Mill, il sistema CAM riconosce automaticamente tutte le feature note presenti nel pezzo. In seguito è possibile selezionare facilmente, dalla libreria di procedure FBM (FBM Procedure Library), procedure di lavorazione predefinite o memorizzate per le feature; il sistema CAM genera automaticamente le operazioni necessarie per lavorare le feature e le ordina in base alle regole correnti (una strategia consiste nell'ordinare le operazioni in modo da ridurre al minimo i cambi utensile).
