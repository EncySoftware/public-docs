# FBM Mill

Usinagem baseada em recursos

Um recurso de fabricação é um componente de uma peça que pode ser fabricado com um processo de usinagem padrão. Exemplos de recursos incluem furos, bolsões, rasgos, ranhuras e chanfros.

A usinagem baseada em recursos (FBM) é uma abordagem CAM baseada no reconhecimento de recursos e na geração automática ou automatizada de processos de usinagem com base nas informações extraídas dos recursos reconhecidos e de uma base de conhecimento de usinagem.

Grupo FBM Mill

O FBM Mill Group é uma operação de grupo no sistema CAM que permite realizar a usinagem baseada em recursos.

Ao criar uma nova operação FBM Mill Group, o sistema CAM reconhece automaticamente todos os recursos conhecidos na peça. Depois disso, é possível selecionar facilmente, na FBM Procedure Library, procedimentos de usinagem predefinidos ou armazenados para os recursos, e o sistema CAM gerará automaticamente as operações necessárias para usinar os recursos e as ordenará com base nas regras atuais (uma estratégia é ordenar as operações de modo a minimizar as trocas de ferramenta).
