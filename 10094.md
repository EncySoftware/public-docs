# Interface de atribuição de procedimentos aos recursos

Para selecionar um procedimento de usinagem para um recurso:

- Clique no ícone ![images/download/attachments/157863291/embim31.png](assets/images/download/attachments/157863291/embim31.png) na árvore. Esse ícone aparece quando um nó da árvore é destacado;

- Ou clique na lista Machining procedure na barra de ações.

![images/download/attachments/157863291/fbmp0009.png](assets/images/download/attachments/157863291/fbmp0009.png)

- Em seguida, passe o cursor sobre o menu Add Operation… para ver a lista dos procedimentos de usinagem aplicáveis aos recursos selecionados.

![images/download/thumbnails/157863291/fbmp0010.png](assets/images/download/thumbnails/157863291/fbmp0010.png)

- Passe o cursor sobre um procedimento no menu para ver a lista das operações que o compõem, junto com as ferramentas selecionadas para elas.

![images/download/attachments/157863291/fbmp0011.png](assets/images/download/attachments/157863291/fbmp0011.png)

Também são exibidas informações adicionais sobre a origem do procedimento sugerido: o autor, a data de criação, a peça para a qual foi criado, o projeto em que foi usado e a máquina usada nesse projeto.

As operações para as quais o sistema CAM não encontra ferramentas são colocadas em um submenu separado, Operations with a missing tool… Ao selecionar uma sequência de usinagem nesse menu, as ferramentas que faltam na Tool Library são criadas.

Para criar uma nova sequência de usinagem em vez de usar uma existente, escolha o comando New Machining Sequence.

Depois de selecionar o procedimento de usinagem para um recurso ou criar um novo, o recurso é movido para a pasta Job, e o sistema CAM atualiza a lista de operações resultante; o procedimento selecionado fica disponível para edição.

É possível atribuir automaticamente regras de usinagem a um grupo de furos em um plano específico.
