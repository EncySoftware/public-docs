# Direct Modeling

![images/download/attachments/157861022/image2025-8-5_9-28-50.png](assets/images/download/attachments/157861022/image2025-8-5_9-28-50.png) ![images/download/attachments/157861022/image2025-8-5_9-28-32.png](assets/images/download/attachments/157861022/image2025-8-5_9-28-32.png)

## Application area:

Editing a CAD model directly (<strong>moving</strong>, <strong>deleting</strong> faces) without considering the design history or parametric dependencies.

<strong>Example:</strong> creating a stock blank from an external file for subsequent machining

1. Converting the 3D Model to a CAM System Format. This requires right-clicking the model in the model tree and choosing <strong>Convert to design</strong>.

![images/download/attachments/157861022/image2025-6-3_17-19-34.png](assets/images/download/attachments/157861022/image2025-6-3_17-19-34.png) ![images/download/attachments/157861022/image2025-8-5_9-28-50.png](assets/images/download/attachments/157861022/image2025-8-5_9-28-50.png)

2. After the model opens in <strong>Design</strong> mode, right-click on the model in the construction tree and select <strong>Recognize</strong>.

![images/download/attachments/157861022/image2025-8-5_9-29-59.png](assets/images/download/attachments/157861022/image2025-8-5_9-29-59.png)

3. After this, typical features such as holes, pockets, and others will be highlighted in the construction tree.

![images/download/thumbnails/157861022/image2025-8-5_9-31-12.png](assets/images/download/thumbnails/157861022/image2025-8-5_9-31-12.png)

4.Using the <strong>delete</strong> or <strong>offset</strong> tools, you can create a blank according to your criteria.

![images/download/attachments/157861022/image2025-8-5_9-32-52.png](assets/images/download/attachments/157861022/image2025-8-5_9-32-52.png) ![images/download/attachments/157861022/image2025-8-5_9-33-57.png](assets/images/download/attachments/157861022/image2025-8-5_9-33-57.png)

You can also select a separate surface to simplify it. Use the <strong>remove surface</strong> functionality.

![images/download/attachments/157861022/image2025-8-5_9-36-30.png](assets/images/download/attachments/157861022/image2025-8-5_9-36-30.png) ![images/download/attachments/157861022/image2025-8-5_9-36-43.png](assets/images/download/attachments/157861022/image2025-8-5_9-36-43.png)

If you also need to offset the surface, use the <strong>offset</strong> function.
