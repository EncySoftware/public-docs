# Robot +

Consente di aggiungere funzioni che permettono di controllare robot a 6 assi (antropomorfi) quando si dispone soltanto della configurazione per macchine normali (fresatura, ecc.).

Queste funzioni sono:

- [Advanced robot](10266.md)
- [Advanced multi axis robot control](10371.md)

Questo modulo è disponibile per le [configurazioni](10390.md):

Per impostazione predefinita:

- Robot

Come opzione:

- 5x Mill*
- Master*
- Pro*

* – per il supporto dei robot è necessaria una licenza aggiuntiva.
