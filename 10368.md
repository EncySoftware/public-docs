# Robot +

Dieses Modul ergänzt eine Konfiguration für herkömmliche Maschinen, beispielsweise Fräsmaschinen, um Funktionen zur Steuerung von 6-Achs-Gelenkrobotern.

Enthaltene Funktionen:

- [Erweiterte Robotersteuerung](10266.md)
- [Erweiterte Mehrachsensteuerung](10371.md)

Verfügbarkeit nach [Konfiguration](10390.md):

Standardmäßig enthalten:

- Robot

Als Option:

- 5x Mill*
- Master*
- Pro*

* Für die Roboterunterstützung ist eine zusätzliche Lizenz erforderlich.
