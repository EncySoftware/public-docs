# Robot +

It allows adding features that make it possible to control 6-axis (articulated) robots when you have only the configuration for normal machines (milling etc.).

These features:

- [Advanced robot](10266.md)
- [Advanced multi axis robot control](10371.md)

This module is available for [configuration](10390.md):

By default:

- Robot

As option:

- 5x Mill*
- Master*
- Pro*

* – an additional license for support robots is needed.
