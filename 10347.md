# Breve introduzione agli script in ENCY

Sprut4 è un linguaggio di programmazione di uso generale. I programmi Sprut4 vengono compilati in byte-code e interpretati dalla macchina virtuale Sprut4. La descrizione del linguaggio si trova nella [documentazione del linguaggio Sprut4](https://docs.encycam.com/Sprut4/en/index.html)
