# 4D-Konturieren beim Drahterodieren

Die Operation **Wire EDM 4d Contouring** erzeugt die Drahtbahn gleichzeitig entlang zweier ebener Konturen. Die untere Kontur beschreibt die Drahtlage in der Arbeitsebene XY und bestimmt damit die Bewegung der unteren Drahtführung. Die obere Führungskontur UV bestimmt die Bewegung der oberen Drahtführung. Dadurch können sich die beiden Drahtenden entlang unterschiedlicher Bahnen bewegen.

![images/download/attachments/157866043/edm3_1.png](assets/images/download/attachments/157866043/edm3_1.png)

Die operationsspezifischen Einstellungen befinden sich auf der Seite **Parameters** im Operationsparameterfenster.

![images/download/attachments/157866043/image2024-7-25_17-6-46.png](assets/images/download/attachments/157866043/image2024-7-25_17-6-46.png)

Folgende Eigenschaften stehen zur Verfügung:

- **Working levels (Arbeitsebenen):**

- **Rapid Level.** Z-Höhe der Eilgangbewegungen. Sie muss oberhalb aller Arbeitsebenen und möglicher Hindernisse wie Spannmittel liegen.
- **Upper Guide Level.** Z-Höhe der oberen Drahtführung.
- **Lead curve level.** Z-Höhe der oberen Führungskontur UV.
- **Work curve level.** In der Regel die Z-Höhe der Arbeits- bzw. Programmierkontur.
- **Lower Guide Level.** Z-Höhe der unteren Drahtführung.

- **Stock (Aufmaß).** Zusätzliches Aufmaß für alle Konturen der Operation. Seine Berücksichtigung hängt von **[Compensation type](10238.md)** auf der Seite **Strategy** ab. Der Korrekturwert jedes Durchgangs ist die Summe aus **[Offset Value](10237.md)** auf **Feeds/Speeds** und **Stock**. Bei **[Computer](10238.md)**, **[Both](10238.md)** und **[Reverse Both](10238.md)** berechnet das System daraus eine äquidistante Bahn. Bei **[Control](10238.md)** wird der Wert in das Register mit der unter **[Offset Code](10237.md)** angegebenen Nummer eingetragen.

- **Tolerance (Toleranz).** Maximal zulässige Abweichung der angenäherten Drahtbahn von der idealen Bahn. Eine engere Toleranz erhöht den Berechnungsaufwand. Eine zu große zulässige Abweichung kann unerwünschte Einschnitte verursachen.

- **NC Format (NC-Format).** Ermöglicht die Auswahl zwischen zwei Ausgabeformaten:

- **Only Lines (Nur Geraden).** Alle Kreisbögen der Ausgangskonturen werden durch lineare Segmente angenähert. Das NC-Programm enthält ausschließlich Geradenbewegungen. Jeder NC-Satz enthält gleichzeitig die Koordinaten der unteren Kontur (X, Y) und der oberen Kontur (U, V), beispielsweise:

```
G01 X65.852 Y-89.422 U-3.902 V19.616
```

- **Lines and Arcs (Geraden und Kreisbögen).** Das NC-Programm kann lineare Segmente und Kreisbögen enthalten. Ein NC-Satz besteht üblicherweise aus zwei durch einen Doppelpunkt getrennten Teilen: links die Bewegung der unteren und rechts die Bewegung der oberen Kontur, beispielsweise:

```
G03 X60. Y90. I-30. J0. : G03 X60. Y70. I-10. J0.
```
