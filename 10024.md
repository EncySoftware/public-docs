# Gestore dei container

Nel sistema CAM è stato aggiunto un gestore dei container. Scarica e aggiorna automaticamente i file dei container (.stfc), a condizione che siano disponibili le licenze per i rispettivi container.

Il sistema verifica la presenza di container non installati e di aggiornamenti dei file dei container a ogni avvio del sistema CAM e durante l'installazione delle licenze tramite il gestore delle licenze.

Facendo clic su un messaggio o su un'icona nell'area di notifica (tray), viene visualizzata una finestra con l'elenco dei container disponibili per il download o l'aggiornamento:

![images/download/attachments/157859100/image2018-12-27_16-23-51.png](assets/images/download/attachments/157859100/image2018-12-27_16-23-51.png)

- Il pulsante <strong>Update</strong> avvia il download e l'aggiornamento del container selezionato.
- Il pulsante <strong>Update all</strong> avvia il download e l'aggiornamento di tutti i container dell'elenco.
- Il pulsante <strong>Not now</strong> annulla il download/aggiornamento e riduce il gestore dei container nell'area di notifica. Il sistema proporrà l'aggiornamento la volta successiva.
- Il pulsante <strong>Ignore</strong> annulla il download/aggiornamento e riduce il gestore dei container nell'area di notifica. Il sistema non mostrerà più notifiche di aggiornamento finché non verrà attivata l'opzione <strong>Notify about updates</strong> nel pannello delle impostazioni del gestore dei container.
- L'opzione <strong>Autoupdate containers</strong> attiva il download/aggiornamento automatico dei container senza notifica all'utente.
- Il pulsante <strong>Settings</strong> mostra o nasconde il pannello delle impostazioni del gestore dei container:

![images/download/attachments/157859100/image2018-12-27_17-45-32.png](assets/images/download/attachments/157859100/image2018-12-27_17-45-32.png)

- La casella di controllo <strong>Notify about updates</strong> attiva o disattiva le notifiche sugli aggiornamenti dei container. Facendo clic sul pulsante <strong>Ignore</strong>, questa casella viene deselezionata.
- Il campo <strong>Max number of active downloads</strong> imposta il numero di download simultanei dei container. In caso di connessione Internet lenta, si consiglia di impostare il valore "1".
- Il campo <strong>Temporary file storage folder</strong> imposta la directory per l'archiviazione temporanea dei file dei container scaricati.

All'avvio del download, i file dei container vengono salvati nella directory temporanea specificata nel pannello delle impostazioni. Al termine del download, il gestore dei container attende la chiusura del sistema CAM prima di spostare i file scaricati nella directory di archiviazione dei container del sistema.

![images/download/attachments/157859100/ContainersUpdatesAreAvailable.png](assets/images/download/attachments/157859100/ContainersUpdatesAreAvailable.png)

Al termine del processo, il gestore dei container del sistema CAM si chiude automaticamente.

Per forzare la chiusura del gestore dei container, fare clic con il tasto destro del mouse sull'icona nell'area di notifica e selezionare <strong>Exit</strong> dal menu contestuale:

![images/download/attachments/157859100/image2018-12-27_17-44-42.png](assets/images/download/attachments/157859100/image2018-12-27_17-44-42.png)

Se il gestore dei container viene chiuso forzatamente, tutti i download attivi vengono interrotti e i container già scaricati non vengono spostati nella directory di archiviazione dei container del sistema CAM. All'avvio successivo, il sistema scaricherà di nuovo automaticamente tutti i container il cui aggiornamento è stato interrotto.
