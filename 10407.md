# Arbeiten mit der Gegenspindel

<a id="operation-overview"></a>

#### Übersicht

**Sub spindle working** ist eine angepasste Pick-and-Place-Operation für Drehfräsmaschinen mit Gegenspindel. Sie synchronisiert Haupt- und Gegenspindel, übernimmt das Werkstück für eine weitere Bearbeitung in beiden Spindeln oder verschiebt es innerhalb der Haupt- bzw. Gegenspindel.

Der Werkzeugweg besitzt entsprechend dieselben grundlegenden Abschnitte wie eine Pick-and-Place-Operation.

<a id="spindle-position"></a>

###### Spindelposition

Anfangsposition der Hauptspindel in physischen Koordinaten für Drehmaschinen oder Langdrehautomaten mit zwei Spindeln. Sie wird im Rückfahrabschnitt der vorherigen Operation ausgegeben.

<a id="pick-position"></a>

###### Greifposition

Position der Gegenspindel, in der sie das Werkstück greift.

<a id="pick-feed-distance"></a>

###### Vorschubweg vor der Übernahme

Länge der Vorschubbewegung vor dem Greifen.

<a id="do-place"></a>

###### Werkstück neu positionieren

Bei aktiviertem **Do place** wird eine neue Werkstückposition in der aktiven Spindel festgelegt, als Abstand zwischen WCS und Spindelbasispunkt. Andernfalls bleibt die Position unverändert.

<a id="swiss-type-place"></a>

###### Positionieren nach Langdrehprinzip

Bei aktiviertem **Swiss type place** wird die aktive Spindel ohne Werkstück bewegt. Andernfalls bewegt sich die Gegenspindel mit dem gespannten Werkstück.

<a id="make-return"></a>

###### Rückfahrt ausführen

Bei aktiviertem **Make return** wird die Synchronisation aufgehoben und die Spindeln kehren in ihre Ausgangsstellungen zurück. Bei deaktivierter Option bleiben sie verbunden und synchronisiert; nachfolgende Operationen erfolgen dann mit beiden Spindeln.

<a id="return-feed-distance"></a>

###### Vorschubweg der Rückfahrt

Länge der Rückzugsbewegung mit Vorschub nach der Übernahme.

<a id="clamp-parameters"></a>

###### Spannmittelparameter

Definiert die Spannmittel von Haupt- und Gegenspindel. Weitere Angaben stehen unter [Spannmittelsteuerung](10403.md).

<a id="wait-for-other-channel"></a>

###### Auf anderen Kanal warten

Bei aktivierter Option wird vor der Anfahrt ein **Wait**-Befehl in CLData eingefügt. Die Operation beginnt erst, wenn die vorherige Operation des anderen Kanals abgeschlossen ist.

Der Parameter ist nur sichtbar, wenn das Maschinenschema mindestens zwei Kanäle besitzt und die vorherige Operation in einem anderen Kanal liegt.
