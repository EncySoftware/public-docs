# Chanfro e arredondamento

Esses dois objetos são criados automaticamente. Basta mover o cursor até a interseção de dois objetos, inserir o valor do tamanho e clicar no botão do mouse para concluir a construção. Se, por algum motivo, o sistema não puder criar o elemento necessário, os elementos deverão ser selecionados sequencialmente.
