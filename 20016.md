# Fase und Verrundung

Diese beiden Elemente werden automatisch konstruiert. Bewegen Sie den Mauszeiger zum Schnittpunkt der beiden Objekte, geben Sie die gewünschte Größe ein und klicken Sie, um die Konstruktion abzuschließen. Wenn das System das gewünschte Element nicht automatisch erstellen kann, wählen Sie die beteiligten Elemente nacheinander aus.
