# Chamfer and Rounding

These two objects are built automatically. You just need to move the cursor to the intersection of two objects, enter the size value and click the mouse button to complete the construction. If for some reason the system cannot build the required element, then the elements must be sequentially selected.

It is also possible to build chamfers and roundings between arcs.

![images/download/attachments/157860349/image2024-8-8_17-43-48.png](assets/images/download/attachments/157860349/image2024-8-8_17-43-48.png)

If you double-click on a rectangle or contour, then all corners of such element will be rounded.

![images/download/attachments/157860349/image2024-8-8_17-45-26.png](assets/images/download/attachments/157860349/image2024-8-8_17-45-26.png)

The button menu provides **Round chamfer with 2 elements** and **Chamfer with 2 elements**. Select a command, then select the two base elements in sequence.

**Modify.** **ON** by default: both base elements are trimmed to the chamfer or rounding and linked to it. When **OFF**, only a line or arc is created; the base elements remain unchanged.

![1](assets/images/editor/20016/a480ac6f2a2d47e08256b47ae72037f7.png)

![2](assets/images/editor/20016/26577c418ff1472cbdc9d912fc2575c5.png)

**Check line type.** **OFF** by default. When creating a chamfer or rounding by clicking a corner, enabling this option restricts the base elements to the current line type selected above the inspector.

![1](assets/images/editor/20016/a7812328cfcf4c9a8ee184e13ca3e7cf.png)
