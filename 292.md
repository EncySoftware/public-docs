# Schnittbedingungen bei Drehoperationen

Vorschübe und Spindeldrehzahl der aktuellen Drehoperation werden auf der Vorschubseite des Parameterfensters festgelegt:

![images/download/attachments/157865588/image2024-7-15_16-13-36.png](assets/images/download/attachments/157865588/image2024-7-15_16-13-36.png)

**Spindeldrehzahl**

Die Spindel kann mit konstanter Drehzahl in Umdrehungen pro Minute (**RPM**) oder mit konstanter Schnittgeschwindigkeit (**CSS**) betrieben werden. Im CSS-Modus berechnet die CNC-Steuerung die Drehzahl anhand des aktuellen Bearbeitungsdurchmessers. Dabei wird sie durch die maximale Drehzahl begrenzt. Vorschübe und Geschwindigkeiten können auch mit dem [Rechner](100142.md) ermittelt werden.

**RPM before CSS**

Befindet sich das Werkzeug an der Werkzeugwechselposition weit von der Werkstückachse entfernt, läuft die Spindel im CSS-Modus zunächst langsam. Beim ersten Eilgang zur Achse kann eine starke Beschleunigung erforderlich werden. Einige Maschinenhersteller empfehlen deshalb den Start mit konstanter Drehzahl und die Umschaltung auf CSS am ersten Bearbeitungspunkt. **RPM before CSS** startet die Spindel mit der Drehzahl dieses ersten Punkts und schaltet nach der Anfahrt auf CSS um.

**Range (Drehzahlbereich)**

Legt den maschinenspezifischen Drehzahlbereich fest, beispielsweise bei einem mechanischen Getriebe.

**Vorschub**

Für unterschiedliche Werkzeugwegabschnitte können unterschiedliche Vorschübe festgelegt werden. Welche Abschnitte und Vorschubarten verfügbar sind, hängt vom Operationstyp ab.

Die Vorschubarten sind in der folgenden Tabelle aufgeführt:

| Symbol | Vorschubart |
|---|---|

|   |   |
| ![Arbeitsvorschübe](assets/images/download/attachments/157865588/Image125.jpg) | **All work feeds.** Alle Bewegungen mit Materialabtrag. |
|   |   |
| ![Eilgang](assets/images/download/attachments/157865588/Image126.jpg) | **Rapid feed.** Bewegungen über Sicherheitsebenen. Diese Bahnabschnitte erscheinen rot. Die Umschaltung erfolgt in CLData mit RAPID. |
|   |   |
| ![Schnittvorschub](assets/images/download/attachments/157865588/Image127.jpg) | **Cut feed.** Hauptvorschub für Arbeitsbewegungen. Andere Vorschübe können als Prozentsatz dieses Werts angegeben werden. |
|   |   |
| ![Anfahrvorschub](assets/images/download/attachments/157865588/Image128.jpg) | **Approach feed.** Vorschub vom Startpunkt bis zum Beginn der ersten Anfahrbewegung an die Bearbeitungszone. |
|   |   |
| ![Rückfahrvorschub](assets/images/download/attachments/157865588/Image129.jpg) | **Return feed.** Vorschub vom letzten Bahnpunkt bis zum Endpunkt. |
|   |   |
| ![Einfahrvorschub](assets/images/download/attachments/157865588/Image130.jpg) | **Engage feed.** Vorschub beim Einfahren zum ersten Punkt der Arbeitsbahn; standardmäßig gleich dem Arbeitsvorschub. |
|   |   |
| ![Abfahrvorschub](assets/images/download/attachments/157865588/Image131.png) | **Retract feed.** Vorschub beim Entfernen von der Fläche nach einer Arbeitsbahn; standardmäßig gleich dem Arbeitsvorschub. |
|   |   |
| ![Erster Schnitt](assets/images/download/attachments/157865588/Image132.png) | **First cut feed.** Vorschub für die erste Materialschicht. Bei einer harten Randschicht wird er gegenüber dem normalen Schnittvorschub verringert. |
|   |   |
| ![Schlichtschnitt](assets/images/download/attachments/157865588/Image133.png) | **Finish cut feed.** Vorschub entlang der Bearbeitungsfläche innerhalb einer Schruppoperation zur Erreichung der gewünschten Oberflächengüte. |

Vorschubwerte können wie folgt angegeben werden:

- `mm/min`: Weg pro Minute.
- `mm/rev`: Werkzeugweg pro Spindelumdrehung.
- `in % of the cut feed`: Prozentsatz des Schnittvorschubs. 100 % entspricht dem Schnittvorschub, 50 % dessen Hälfte.

*Hinweis: Bei einer Änderung des Schnittvorschubs ändern sich alle davon prozentual abhängigen Vorschübe entsprechend.*
