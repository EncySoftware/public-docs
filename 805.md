# Koordinatensystem anhand der aktuellen Blickrichtung erstellen

Diese Konstruktionsmethode wird über den Menüeintrag ![Koordinatensystem nach Blickrichtung](assets/images/download/thumbnails/157858651/image2019-1-11_18-19-27.png) auf dem [Koordinatensystempanel](753.md) aktiviert.

Stellen Sie zunächst die gewünschte [Blickrichtung](20.md) ein oder wählen Sie eine [Standardansicht](728.md). Bewegen Sie anschließend den Mauszeiger im [Grafikfenster](169.md) zum gewünschten Ursprungspunkt. Ein geeigneter Punkt wird hervorgehoben. Bestätigen Sie ihn durch Klicken mit der linken Maustaste:

![images/download/attachments/157858651/f_clip0425_1.png](assets/images/download/attachments/157858651/f_clip0425_1.png)

Danach wird das neu erstellte Koordinatensystem aktiv:

![images/download/attachments/157858651/f_clip0425_2.png](assets/images/download/attachments/157858651/f_clip0425_2.png)

Name, Farbe und Ursprungspunkt können jederzeit [geändert](403.md) werden.
