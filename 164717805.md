# Nesting

![images/download/attachments/164717805/image2026-9-8_8-56-14.png](assets/images/download/attachments/164717805/image2026-9-8_8-56-14.png) ![images/download/attachments/164717805/image2026-9-8_8-57-33.png](assets/images/download/attachments/164717805/image2026-9-8_8-57-33.png)

## Application area ENCY:

On the **Model** tab, select a folder (group) containing curves or a SCAD sketch in the model tree and click **Nesting** on the geometry toolbar. Alternatively, right-click the folder and select **Create nesting**. To reopen a saved layout, right-click its **Nesting 1** node and select **Edit nesting**.

The Nesting tool automatically arranges selected parts on a sheet to optimize material usage and reduce waste. Configure sheet dimensions, spacing, margins, part copies, rotation, mirroring, and placement rules before generating the layout.

### Window layout.

<details>
<summary>Click here to expand..</summary>

**1. Options tab.** Contains settings that define the nesting calculation.

**2. Parts tab.** Displays nestable parts, calculated sheets, unnested parts, and ignored parts. It is used to define the quantity and individual placement rules for each part.

**3. Run button.** Starts the nesting calculation using the current settings. The arrow next to the button opens additional calculation commands.

**4. Sheet navigation.** Switches between sheets. **+** adds an empty sheet; its arrow opens **Sheet stock**.

**5. Sheet parameters.** Define the length, width, gap, and margins of the current sheet.

**6. Manual editing.** Allows you to manually edit the nesting layout.

**7. Settings button.** Opens nesting settings.

**8. Nesting layout.** Displays the calculated arrangement of parts on the current sheet. The layout is generated according to the selected sheet parameters, material requirements, and placement rules.

**9. Undo/Redo.** **Undo (Ctrl+Z)** - reverses the last change. **Redo (Ctrl+Y)** - restores an undone change. After a new change is made, previously undone steps can no longer be redone.

### Preparing parts.

<details>
<summary>Click here to expand..</summary>

**Source geometry.** Select a folder with its subfolders or a SCAD sketch. A single curve is not a valid selection. Lines, arcs, circles, polylines and splines are collected; text is collected letter by letter. Points, surfaces and solids are not collected. Earlier nesting results and SCAD sketches inside a folder are skipped: select a sketch itself to nest it. Hidden curves and curves in hidden folders appear in **Ignored** as *hidden*.

**Plane and grouping.** Only X and Y are used. Curves are combined within one folder, so an outer contour and its holes must be in the same folder. Open curves whose ends meet within the system precision are joined into closed contours.

**Part name.** Taken from the outer contour curve. A SCAD part alone on its plane takes the plane name; an unnamed SCAD contour is shown as *Contour* followed by its ID. To rename a part, slowly click its name a second time on its **Nestable** row, or use the pencil button beside the name. Empty names are rejected; entering the source name removes the custom name. The name is saved with the nesting and used for copy groups in the model; the source curve keeps its name. Renaming is an undo step. Switching **Combine parts** or repairing in **Ignored** restores source names; Part manual edit restores them for changed parts.

**Copies.** Set each part's quantity in **Nestable**; 0 excludes it from nesting. The read-only total is the quantity multiplied by **Copies multiplier**. A part that cannot fit on the sheet at any angle stays in the list with its copies in **Unnested**.

</details>

### Ignored contours and repair.

<details>
<summary>Click here to expand..</summary>

**Ignored.** The **Parts** tab lists contours that cannot become parts, with their reasons.

| Reason | Meaning and action |
|---|---|
| **hidden** | The curve or its folder is hidden. Show it in the model if it is needed. |
| **open contour** | The contour does not close. Join its curves in the model or repair it here for a SCAD sketch. |
| **self-crossing** | The contour crosses itself. Repair it here or in the model. |
| **intersecting** | Contours in the same folder touch or cross; both are ignored when **Combine parts** is on. Separate them in the model. |
| **duplicate** | Contours in the same folder coincide in the same place, with **Combine parts** on. Delete the extra curve. Identical contours in different positions are ordinary parts. |
| **degenerate** | Zero length or area. Fix or delete the contour. |
| **nested too deep** | A SCAD island with holes lies inside a hole. Move the island to its own plane. |
| **empty** | Nothing remains after repair. No part can be made from it. |

Single SCAD lines and arcs, including chamfers and fillets, also appear as open contours and can travel as passengers in Part manual edit. *Skipped contours* appears when creating nesting if ignored contours include more than single lines and arcs. It is not shown when an envelope is used.

**Repair.** A repairable row shows a repair button when selected or under the pointer; it is disabled if no repair is available. The menu offers suitable fixes with their sizes: **Trim ends**, **Cut loop**, **Join**, **Move end**, **Move start**, **Close**. **Join** uses other open ignored contours. Select a fix to preview it, then click **Apply**; **Esc** closes the menu without applying. While the menu is open, use the wheel to zoom and the left or middle mouse button to pan the preview.

A repaired contour becomes a part and resets the layout. **Ctrl+Z** restores the former contours, parts and layout. Repair inside Part manual edit affects only that edit and is described below.

Contours assigned a role in Part manual edit leave **Ignored**, except hidden contours and contours rejected during collection, such as open SCAD contours and self-crossing contours. These keep their reason even when travelling as passengers.

</details>

### Part manual edit.

<details>
<summary>Click here to expand..</summary>

**Part manual edit.** Defines which inner contours are cut and which only travel with the part. It is available only with **Combine parts** on.

1. Select a part in **Nestable** or one of its copies in **Sheets**.
2. Click **Edit** on the **Preview** header. It becomes **Save**. The expand button beside it opens the same edit in its own view and keeps the roles already selected.
3. Select contours in the list or preview and set their roles.
4. Click **Save** to apply. **Esc** cancels and asks whether to discard changes if any were made.

**Contour roles.** The first row is **Outer** or a frame role. Inner contours are indented by their nesting level.

| Role | Effect |
|---|---|
| **Hole**, **Part**, **Unassigned** | Automatic role: a hole, a separate island, or an unused contour. On a marked contour the item becomes **Auto**, which removes the mark. |
| **Passenger** | Travels with every copy, takes no nesting room and is not cut. It is saved with the part. |
| **Ignored** | Neither cut nor nested. |
| **Passenger, inside too**, **Ignored, inside too**, **Auto, inside too** | Applies the role to the contour and everything inside it. Available when inner contours exist. |

**Examples.** Mark a circle around a mounting hole as **Passenger**: the inner hole becomes a hole of the plate rather than a separate round part. Mark only a box around text as **Passenger** to cut the letters as holes; choose **Passenger, inside too** to keep the box and all text as markings.

**Contour display.** Passengers are blue, ignored contours dashed, holes solid, islands lighter and unused contours dashed and lighter. Frames use long dashes. The selected contour is amber; the contour under the pointer is pale amber.

**Separate view.** The contour list fills the left column and the part replaces the sheet in the main view. The edit card provides **Auto**, **Passenger**, **Ignored**, **Inside too**, **Repair...**, **Frame**, previous/next contour, zoom-to-fit, **?**, **Save** and **Cancel**. **Frame** changes the outer contour to a frame regardless of the selected row; pressing it again restores **Outer**. The header provides **Save** and **Cancel**; the status line shows the part size. Zooming and panning work as usual. Leaving the edit restores the sheet and its view.

**Repair inside the edit.** An unused open SCAD contour or a self-crossing contour can be repaired with the row button; in the separate view, **Repair...** or **R** does the same. Only fixes that stay inside the part are offered. **Apply** adds the repair as a step of this edit and restores automatic roles for the repaired contour and its inner levels. **Ctrl+Z** and **Ctrl+Y** undo and redo roles and repairs; cancelling reverts them all. A join with geometry outside the part must be made in **Ignored**.

**Saving the edit.** Parts are rebuilt. Copies of changed or removed parts return to **Unnested**; unchanged parts keep their copies on the sheets. Changing a frame role also changes the part. Applying the entire edit is one undo step. Passengers are drawn in blue on every copy and follow it during layout editing.

During an edit, the other settings, **Run**, sheet commands and **OK** are locked. The edit has its own undo history. Marks and repairs are saved with nesting. With **Combine parts** off, marks are kept but not used; enabling it restores their effect.

| Keys in the separate view | Action |
|---|---|
| **A** / **P** / **I** | **Auto** / **Passenger** / **Ignored**; hold **Shift** to apply inside too. |
| **R** | Repair the selected contour. |
| **↑** / **↓** | Previous / next contour. |
| **F** | Fit the part into the view. |
| **Enter** / **Esc** | Save / cancel the edit. |
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo a role or repair, also available on the Preview panel. |

Keys work when focus is outside an input field. Their meanings differ from the layout editing shortcuts.

</details>

### Frames.

<details>
<summary>Click here to expand..</summary>

**Frame.** Keeps several pieces together, such as letters of a sign or rings of a gasket. The closed frame contour is nested but is not cut; the pieces inside it are cut and keep their relative positions.

1. Draw a closed contour around the pieces in the same folder, or on the same SCAD plane. A frame around model text must be in the text's folder.
2. Create nesting and open Part manual edit for this contour.
3. Select **Frame** in the outer row's role list, or use **Frame** on the separate-view edit card.
4. Check the pieces and holes, then click **Save**.

**Copies and placement.** The frame is one part in **Nestable**, after ordinary parts. Its copy count means complete sets. Rotation, mirroring and priority apply to the whole set. The gap is kept around the frame, and other parts are not placed between its pieces. A closely drawn frame uses less material. **Parts in holes** allows other parts in the holes of its pieces, unless a hole already holds a piece or passenger.

**Roles and limits.** Passengers travel with the frame without being cut; ignored contours are not used. A frame can contain passengers only, reserving space for markings. It works as a top-level outer contour or as an island in another part's hole. Inside another frame or a part's material it is neither cut nor nested; the contour list explains why. With **Combine parts** off, the role is kept but the frame contour becomes an ordinary part.

**Display and changes.** The frame uses long dashes and has an **i** hint in **Nestable**. Its pieces are solid; passengers are blue. Changing the frame role returns its copies to **Unnested** and clears their sheet figures until the next run. Other parts stay in place. **Ctrl+Z** restores the previous state. Utilization figures count the cut pieces, not the frame area.

**Frame, as drawn.** Keeps the same grouping but does not assemble parts inside the frame. All unmarked contours are cut as drawn, including open, touching and crossing contours. Their rows read **As drawn**; passenger and ignored roles still apply. Nothing else is placed inside this frame. Closed contours are filled by alternating material and holes; overlapping enclosed areas are counted twice. The result contains a **Profiles** group rather than piece groups. The frame contour itself is never written to the model.

</details>

### Envelope.

<details>
<summary>Click here to expand..</summary>

**Envelope.** If no part can be made from the selected drawing, **Create nesting** uses its convex outline: one per folder or SCAD plane. The outline follows drawing arcs where possible and uses straight segments elsewhere. Hidden, empty and ignored contours are excluded. Parts are named **Envelope**, **Envelope 1**, and so on.

The drawing becomes passengers inside the envelope, shown in blue and saved with it without being cut. The envelope itself is cut as the outer profile. Its convex outline can bridge recesses and be larger than the intended part: check it before cutting.

**Notifications.** The empty sheet explains that the envelope is being nested. The **Nestable** row has an **i** hint, and Part manual edit identifies the envelope. There is no *Skipped contours* notification. **Auto** returns a wrapped contour to automatic processing; **Ignored** excludes it. Contours rejected during collection can remain in **Ignored** and be repaired. Repaired parts coexist with the envelope; set its copies to 0 if only the repaired parts are needed.

**Envelope as a frame.** Set **Frame** to nest the envelope without cutting it; only repaired contours or contours restored with **Auto** become cut pieces. **Frame, as drawn** cuts the wrapped drawing as drawn and removes the passenger marks that the envelope assigned. Changing that role again in the same edit restores those marks. The sheet and hints explain that the envelope is used as a frame.

**Nothing to nest.** If even an envelope cannot be made, for example from hidden, absent or collinear geometry, the window does not open. *Nothing to nest* lists the skipped reasons and counts. **Edit nesting** never creates an envelope: it uses only geometry already saved in the nesting.

</details>

### Options tab.

<details>
<summary>Click here to expand..</summary>

**General.**

**Quality.** Selects calculation depth. The default is **Balanced**.

| Level | Calculation |
|---|---|
| **Fastest** | One quick pass per sheet. |
| **Balanced** | Searches variants sheet by sheet. Repeated runs give the same result. |
| **High** | As **Balanced**, followed by compaction of all sheets: 20 seconds plus 10 per additional sheet, up to 5 minutes. |
| **Maximum** | The same compaction until **Stop**, 5 minutes without improvement, or one hour in total. |

Compaction times are nominal amounts of work; a slow or busy computer can take longer by the clock.

**Coordinate system.** Selects the coordinate system used for the sheet layout. A new nesting starts in the active coordinate system.

**Copies multiplier.** An integer of 1 or greater that multiplies the copy count of each part. Set individual copy counts on part rows in **Nestable** on the **Parts** tab. The default multiplier is 1.

**Placement.**

**Combine parts.** When **ON**, a closed outer contour and the contours inside it form a part with holes. A contour inside a hole becomes a separate part. When **OFF**, each closed contour is a separate part. The default is **ON**. Changing this option rebuilds the parts, clears the layout and removes every sheet except the first. The change can be undone.

**Parts in holes.** Allows parts inside suitable holes of other parts. **ON** by default.

**Nesting result.**

**Parts selected.** Shows the number of parts selected for nesting.

**Nestable.** Shows the number of selected parts that meet the current nesting conditions.

**Ignored.** Shows the number of parts excluded from the calculation.

**Unnested copies.** Shows the number of requested part copies that could not be placed.

### Parts tab.

<details>
<summary>Click here to expand..</summary>

![images/download/attachments/164717805/image2026-9-17_10-18-11.png](assets/images/download/attachments/164717805/image2026-9-17_10-18-11.png)

**Nestable.** Lists the parts that can be included in the nesting. The field next to each part defines its required quantity. **Copies multiplier** multiplies these quantities.

**Fill with color.** The switch on the **Nestable** row enables color filling on the sheet. It changes the display only.

**Sheets.** Lists each **Sheet N** with material utilization, copy count and calculation time; expand it to see parts and their copies. Selecting a row shows its sheet and highlights the relevant copies. Selecting another group keeps the current sheet in view.

**Unnested.** Contains parts that could not be placed on the available sheets under the current conditions.

**Ignored.** Contains parts excluded from the calculation.

**Preview.** Shows the selected part and its size. **Edit** starts Part manual edit on the panel; the expand button opens its separate view. Clicking a part on the sheet selects its row. Frames and envelopes have an **i** hint in **Nestable**.

**Allow rotation.** When **ON**, uses **Rotation step**; when **OFF**, keeps the part at its drawn angle.

**Allow mirror.** When **ON**, permits a mirrored placement of the selected part.

**Priority.** Sets **Low**, **Normal**, or **High** placement priority. Higher-priority parts are placed first, but priority does not guarantee that a part will fit.

</details>

**W.** Width of the current sheet along X.

**Gap.** Minimum distance between parts. It does not apply at sheet edges; only **Margin** applies there.

### Run.

<details>
<summary>Click here to expand..</summary>

**Run.** Calculates from scratch, filling sheets from the first. Copies marked **Placed by hand** stay in place and the rest is nested around them.

**Auto-add sheets.** **ON** by default and remembered between sessions. Adds sheets from the template while copies remain and removes empty sheets at the end. When **OFF**, only existing sheets are used and the remaining copies stay in **Unnested**. With sheet stock enabled, suitable stock remnants are tried before template sheets.

**Abort.** Replaces **Run** during sheet calculation and stops the run, including subsequent compaction. Progress follows the current sheet. Settings are locked, but tabs, zoom-to-fit and sheet navigation remain available.

**Run menu.** Open the arrow beside **Run** or right-click it.

| Command | Action |
|---|---|
| **Re-run active sheet** | Recalculates the visible sheet. |
| **Nest remaining on active sheet** | Keeps its copies and adds unnested copies. If it contains **Placed by hand** copies, only those are kept. |
| **Clear sheet** | Clears the visible sheet without calculation, including hand-placed copies. |

With **Auto-add sheets** on, the first two commands also remove empty sheets throughout the nesting.

**Compaction.** At **High** and **Maximum**, **Run** compacts all sheets together after filling them. Parts can move to earlier sheets and the last sheet can shorten or empty. Hand-placed copies remain fixed. **Stop** ends compaction and keeps the best layout found; figures update as improvements appear. The single-sheet commands compact only their own sheet, and skip compaction when copies must stay in place.

**Last sheet across.** The calculation can try the last sheet across and keep the variant using less material or giving a larger remnant. This is automatic, with stricter selection at **High** and **Maximum**; it is skipped at **Fastest**, with fixed copies, with mirroring allowed, or when a square sheet and 90° rotation make it unnecessary.

**Undo and redo.** Use the top-bar buttons or **Ctrl+Z** / **Ctrl+Y** outside input fields. History covers runs, sheets, sizes, quantities, rules, options and edits, up to 64 steps. Up to eight steps that rebuild parts are kept; dropping the oldest also drops earlier history. Part manual edit has its own history until it finishes. If an undo affects another sheet, the first press shows it and the second undoes the change. A new change clears redo history.

</details>

### Result.

<details>
<summary>Click here to expand..</summary>

**MUR.** Part area divided by the used strip area: usable width multiplied by used length. Shown beside the middle of the shaded strip. When the strip fills at least 95% of the usable length, only **Total sheet area** is shown.

**Total sheet area.** Part area divided by the whole usable sheet area; shown beside its top edge. The status line shows both percentages and the sheet calculation time. Before calculation it reads *Click Run to calculate nesting*. On a sheet nested across, the strip starts at the right and figures appear above the sheet. For non-rectangular stock remnants, the notch is excluded from sheet area. Frames count the cut pieces or the enclosed areas of contours drawn as-is, rather than the frame area.

**Remnant.** The largest empty rectangle exceeding 10% of usable sheet area is outlined with dashes and labelled with its dimensions. It is measured outside the copies' bounding boxes enlarged by the gap; part recesses and holes are not included. Everything except the remnant is shaded. With sheet stock enabled, several free zones can be shown and joined or given to stock.

| Mark | Meaning |
|---|---|
| Red border | The gap between copies is violated by more than 0.2 mm. |
| White diagonal hatching | **Placed by hand**. |
| Amber outline | Selected copy; pale amber means under the pointer. |
| Dashed sheet outline | **Make sheet profile** is off: the sheet rectangle will not be saved. |
| Long-dashed contour | A frame: nested but not cut. |
| Note on an empty sheet | The input is being nested as envelopes. |

</details>

### Nesting manual edit.

<details>
<summary>Click here to expand..</summary>

**Nesting manual edit.** Click the pencil on the top bar to show the edit card. An existing selection becomes the edit selection. **?** toggles its tooltips. Switching sheets, running, clearing or resizing a sheet, adding or removing sheets, undo and redo clear the selection.

![Manual editing controls for a nesting layout](assets/images/editor/164717805/6a3a568548354ff28064d98dec9f6b20.png)

**Selection.** Click a copy; **Shift**+click adds or removes it. Drag on empty space from left to right to select fully enclosed copies, or right to left to select all touched copies. **Shift**+drag adds to the selection. Click empty space or press **Esc** to clear. Double-click a copy to show its row on **Parts**.

**Moving.** Drag the selection along neighbours and the sheet margin, keeping the gap. Parallel straight edges snap at the gap and align ends or corners. **Ctrl**+drag moves freely without snapping, can leave the sheet and pushes neighbours aside. Copies outside the sheet are excluded from figures. Parts inside holes move, rotate, mirror and are removed with their containing part; a frame and its contents also behave as one copy.

**Push arrows.** Move the selection to a neighbour or the margin. With nothing selected, pack the whole sheet to that side. **Ctrl**+arrow pushes neighbours aside; **Shift**+arrow compacts the selection within its own extent.

**Rotation.** Card buttons use the angle field, 90° by default; a negative angle reverses direction. Hold **R** and turn the wheel to rotate about the pointer, 5° per notch; **Shift** changes the step to 1°, **Alt** to 90°. **E**+wheel rotates each copy about its own centre. Over an unselected copy, that copy is selected first.

**Mirroring and Each part.** **M** mirrors left to right; **Shift+M** mirrors top to bottom. With **Each part** pressed, the rotate and mirror controls and **R**+wheel act about each copy's centre. A transformation causing a collision is refused; **Ctrl** bypasses collision checks.

**Angle like a sample.** With copies selected, press **A**, then click a sample copy. Selected copies of that same part take its angle and mirroring, each about its own centre. Copies that would collide stay unchanged; **Ctrl**+click bypasses checks. **A**, **Esc** or a click off the copies cancels the command.

**Remove from the sheet.** **Del** returns selected copies to **Unnested** on **Parts**.

**Place onto this sheet.** **Ctrl+Ins** places the item selected on **Parts** onto the current sheet: **Nestable** or **Unnested** adds a copy; a row from another sheet moves that copy here. It is placed at the pointer at 0°, without collision checks, and selected.

**Placed by hand.** **P** marks the selection; if all selected copies are marked, it removes the mark. White hatching identifies fixed copies. **Run** and both single-sheet calculation commands keep them in place. **Clear sheet**, resizing or removing the sheet removes them too.

Shortcuts work in this mode with focus outside input fields, except **Ctrl+Z** / **Ctrl+Y**, which also work elsewhere. With focus in the part list, arrows move between rows; click the sheet to return focus.

| Keys / gesture | Action |
|---|---|
| **Ctrl+Z** / **Ctrl+Y** | Undo / redo. |
| Click / double-click | Select a copy / show its **Parts** row. |
| **Shift**+click | Add to or remove from the selection. |

### Settings button.

### Sheet stock.

<details>
<summary>Click here to expand..</summary>

The stock stores standard sheet formats and numbered remnants for reuse. The list is filtered by the nesting's material and thickness.

**Opening and choosing a sheet.**

1. Open the arrow beside **+** and enable **Use sheet stock**.
2. Set **Material** and **Thickness** for the nesting.
3. Click an entry in **Remnants** or **Formats**. It replaces the empty current sheet, or adds a new sheet if the current one contains parts.

**Stock records.** Use **Add format...**, **Add remnant...** or **Add material...** to create a record. The **⋮** menu opens an existing record for editing or deletion. Choose the stock file in the last row of the card; a shared network file can be used.

**Automatic choice.** With **Auto-add sheets** on, the calculation first tries suitable stock remnants with a metal area at least that of the first sheet. When these run out, sheets are added from the template.

**Returning a remnant.** Free zones on a calculated sheet have dashed outlines. **Join** combines adjacent zones into one remnant. Hover the required zone, click **To stock**, add a note if needed, then click **Give to stock**. Alternatively, **Remnant to stock...** in **Sheet i / n** takes the largest zone.

**Saving.** **OK** writes the prepared remnants to stock and writes off used input remnants. Empty remnant sheets and formats are not written off. Cancelling the nesting leaves stock unchanged. Changing the layout removes prepared remnant marks; recalculating after a remnant was saved asks whether to delete it from stock.

**Shaped remnants.** Missing metal is hatched; parts keep the margin from its edges. Changing the sheet's **L** or **W** makes it rectangular.

*The separating cut is not added to the NC program. Cut the remnant to the displayed outline and dimensions.*

</details>

### Saving the result.

<details>
<summary>Click here to expand..</summary>

**OK.** Saves the current layout to the model, with or without running the calculation.

**Cancel.** Closes without saving. If changes were made, the window close button asks *Save the nesting result?*: **Yes** saves, **No** discards, **Cancel** or **Esc** stays in the window. During calculation, closing first aborts the run and then asks the same question.

**Result structure.** A **Nesting 1** group is created in the source folder, or beside the source SCAD sketch. Each sheet with parts has a **Sheet N** group. It contains a group per copy named after the part, with **Outer profile**, **Holes** and, when passengers exist, **Auxiliary profiles**. **Make sheet profile** also adds the sheet rectangle.

**Frame result.** A frame copy contains a group per piece, each with **Outer profile** and **Holes**, plus **Auxiliary profiles** for the frame's passengers. **Frame, as drawn** contains **Profiles** with the original curves instead of piece groups. The frame contour is not saved. An envelope saves its outline as **Outer profile** and its drawing as **Auxiliary profiles**.

**Edit nesting.** Select the saved **Nesting 1** node and click **Nesting**, or choose **Edit nesting**. It uses curves saved inside nesting and does not pick up later changes to the source model; create a new nesting to use them. Roles and part names are retained.

**Sheet stock.** Saving writes prepared remnants to stock and writes off the used input remnants. Cancelling does neither.

</details>
