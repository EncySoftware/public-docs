# Program installation and launch

<strong>ENCY</strong> uses the Internet for installation. The setup program scans the ENCY web server for available modules and downloads them. You can install only required modules, skipping others. Subsequent runs use previously downloaded modules to accelerate the process. There is a "local" installer based on the same technology, which uses local modules for installation.

There is also a "local" installer based on the same technology, which uses local modules for installation.

<strong>ENCY</strong> installation on a computer with Internet connection:

1. Download an installable file from the Website.
2. Run the installation program on Windows. In the **Run** dialogue, type the **Path** and click **OK** or hit **Enter**.
3. The Installation program will guide you through various dialogue boxes, which will require some input during the installation process, including:
  1. End user license confirmation.
  2. Choose default, minimal, or custom installation (can exclude example project files, importable files, and other auxiliary files).
  3. Specify the installation directory.
  4. Specify the main menu directory for shortcuts.

To proceed to the next step, click the **Next** button.

After installation, a confirmation window will appear. Close it by clicking the **Done** button. If you have a CAM system with electronic key protection, insert the key into a USB port before running the system.

<strong>ENCY</strong> installation from a physical media:

1. Insert the physical media.
2. Run the installation program from it. In the **Run** dialogue, type the `Drive_letter` and click **OK** or hit **Enter**.
3. The Installation program will guide you through various dialogue boxes, which will require some input during the installation process, including:
  1. End user license confirmation.
  2. Choose default, minimal, or custom installation (can exclude example project files, importable files, and other auxiliary files).
  3. Specify the installation folder.
  4. Specify the main menu folder for shortcuts.

To proceed to the next step, click the **Next** button.

After installation, a confirmation window will appear. Close it by clicking the **Done** button. If you have a CAM system with electronic key protection, insert the key into a USB port before running the system.

<strong>Note 1:</strong> The <strong>ENCY</strong> installation must be performed with administrator rights. This version requires administrator rights for add-ins setup. If you don't have these rights, create a link to run <strong>ENCY</strong> with administrator rights or consult support.

<strong>Note 2:</strong> I n some cases, when installing <strong>ENCY</strong> with an electronic key, the user may need to additionally install the electronic key driver. To do so, after the installation process, select in Program menu key drivers' setup.

<strong>Note 3:</strong> If "Electronic key not found!" appears, check that the key is connected. If this occurs on first run, install the electronic key driver.
