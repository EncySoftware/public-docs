# Instalação e inicialização do programa

O <strong>ENCY</strong> usa a Internet para a instalação. O programa de instalação verifica no servidor web do ENCY os módulos disponíveis e os baixa. É possível instalar apenas os módulos necessários, ignorando os demais. As execuções seguintes usam os módulos baixados anteriormente para acelerar o processo. Existe um instalador "local" baseado na mesma tecnologia, que usa módulos locais para a instalação.

Há também um instalador "local" baseado na mesma tecnologia, que usa módulos locais para a instalação.

Instalação do <strong>ENCY</strong> em um computador com conexão à Internet:

1. Baixe o arquivo de instalação do site.
2. Execute o programa de instalação no Windows. Na caixa de diálogo **Run**, digite o **Path** e clique em **OK** ou pressione **Enter**.
3. O programa de instalação guiará você por várias caixas de diálogo, que exigirão algumas informações durante o processo de instalação, incluindo:
  1. Confirmação da licença do usuário final.
  2. Escolha da instalação padrão, mínima ou personalizada (é possível excluir arquivos de projetos de exemplo, arquivos importáveis e outros arquivos auxiliares).
  3. Especificação do diretório de instalação.
  4. Especificação do diretório do menu principal para os atalhos.

Para passar à etapa seguinte, clique no botão **Next**.

Após a instalação, será exibida uma janela de confirmação. Feche-a clicando no botão **Done**. Se o seu sistema CAM tiver proteção por chave eletrônica, insira a chave em uma porta USB antes de executar o sistema.

Instalação do <strong>ENCY</strong> a partir de uma mídia física:

1. Insira a mídia física.
2. Execute o programa de instalação a partir dela. Na caixa de diálogo **Run**, digite `Drive_letter` e clique em **OK** ou pressione **Enter**.
3. O programa de instalação guiará você por várias caixas de diálogo, que exigirão algumas informações durante o processo de instalação, incluindo:
  1. Confirmação da licença do usuário final.
  2. Escolha da instalação padrão, mínima ou personalizada (é possível excluir arquivos de projetos de exemplo, arquivos importáveis e outros arquivos auxiliares).
  3. Especificação da pasta de instalação.
  4. Especificação da pasta do menu principal para os atalhos.

Para passar à etapa seguinte, clique no botão **Next**.

Após a instalação, será exibida uma janela de confirmação. Feche-a clicando no botão **Done**. Se o seu sistema CAM tiver proteção por chave eletrônica, insira a chave em uma porta USB antes de executar o sistema.

<strong>Observação 1:</strong> A instalação do <strong>ENCY</strong> deve ser executada com direitos de administrador. Esta versão requer direitos de administrador para a configuração de suplementos. Se você não tiver esses direitos, crie um atalho para executar o <strong>ENCY</strong> com direitos de administrador ou consulte o suporte.

<strong>Observação 2:</strong> Em alguns casos, ao instalar o <strong>ENCY</strong> com chave eletrônica, pode ser necessário instalar adicionalmente o driver da chave eletrônica. Para isso, após a instalação, selecione no menu Programa a instalação dos drivers da chave.

<strong>Observação 3:</strong> Se aparecer a mensagem "Electronic key not found!", verifique se a chave está conectada. Se isso ocorrer na primeira execução, instale o driver da chave eletrônica.
