# Installation und Programmstart

Der ENCY-Online-Installer sucht auf dem Webserver nach verfügbaren Modulen und lädt die ausgewählten Komponenten herunter. Nicht benötigte Module können ausgelassen werden. Bei späteren Durchläufen werden bereits geladene Dateien wiederverwendet.

Ein lokales Installationspaket verwendet dieselbe Technik mit bereits bereitgestellten Modulen.

**Installation mit Internetverbindung:**

1. Laden Sie das Installationsprogramm von der Website herunter.
2. Starten Sie es unter Windows, beispielsweise durch Eingabe des Pfads im Dialog **Ausführen** und Bestätigung mit **OK** oder **Enter**.
3. Folgen Sie den Dialogen:
   1. Lizenzvereinbarung bestätigen.
   2. Standard-, Minimal- oder benutzerdefinierte Installation wählen. Beispielprojekte, Importdateien und weitere Zusatzdateien können abgewählt werden.
   3. Installationsverzeichnis festlegen.
   4. Startmenüordner für Verknüpfungen festlegen.

Mit **Next** wechseln Sie zum nächsten Schritt.

Schließen Sie die Abschlussmeldung mit **Done**. Bei Schutz durch einen elektronischen Schlüssel stecken Sie diesen vor dem Programmstart in einen USB-Anschluss.

**Installation von einem Datenträger:**

1. Legen Sie den Datenträger ein bzw. schließen Sie ihn an.
2. Starten Sie dessen Installationsprogramm. Der Datenträger kann über seinen Laufwerksbuchstaben im Dialog **Ausführen** geöffnet werden.
3. Bestätigen Sie die Lizenzvereinbarung, wählen Sie den Installationsumfang und legen Sie Installations- und Startmenüordner fest.

Mit **Next** wechseln Sie zum nächsten Schritt.

Schließen Sie die Abschlussmeldung mit **Done**. Bei Schutz durch einen elektronischen Schlüssel stecken Sie diesen vor dem Programmstart in einen USB-Anschluss.

**Hinweis 1:** Die Installation erfordert Administratorrechte. Diese Version benötigt sie auch für die Einrichtung von Add-ins. Verwenden Sie gegebenenfalls eine entsprechend konfigurierte Startverknüpfung oder wenden Sie sich an den Support.

**Hinweis 2:** Bei Verwendung eines elektronischen Schlüssels kann zusätzlich dessen Treiber erforderlich sein. Starten Sie die Treiberinstallation nach der Programminstallation über den entsprechenden Menüeintrag.

**Hinweis 3:** Bei der Meldung *Electronic key not found!* prüfen Sie den Anschluss des Schlüssels. Tritt sie beim ersten Start auf, installieren Sie den Schlüsseltreiber.
