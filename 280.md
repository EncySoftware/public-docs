# Installazione e avvio del programma

<strong>ENCY</strong> utilizza Internet per l'installazione. Il programma di installazione analizza il server web di ENCY alla ricerca dei moduli disponibili e li scarica. È possibile installare solo i moduli necessari, omettendo gli altri. Le esecuzioni successive utilizzano i moduli scaricati in precedenza per accelerare il processo. Esiste un programma di installazione "locale" basato sulla stessa tecnologia, che utilizza moduli locali per l'installazione.

Installazione di <strong>ENCY</strong> su un computer con connessione a Internet:

1. Scaricare un file di installazione dal sito web.
2. Eseguire il programma di installazione in Windows. Nella finestra di dialogo **Run** (Esegui), digitare il **Path** (percorso) e fare clic su **OK** oppure premere **Invio**.
3. Il programma di installazione guida l'utente attraverso varie finestre di dialogo che richiedono alcuni dati durante il processo di installazione, tra cui:
  1. Conferma della licenza per l'utente finale.
  2. Scelta dell'installazione predefinita, minima o personalizzata (è possibile escludere i file di progetto di esempio, i file importabili e altri file ausiliari).
  3. Specifica della directory di installazione.
  4. Specifica della directory del menu principale per i collegamenti.

Per passare al passo successivo, fare clic sul pulsante **Next**.

Al termine dell'installazione compare una finestra di conferma. Chiuderla facendo clic sul pulsante **Done**. Se si dispone di un sistema CAM con protezione a chiave elettronica, inserire la chiave in una porta USB prima di avviare il sistema.

Installazione di <strong>ENCY</strong> da supporto fisico:

1. Inserire il supporto fisico.
2. Eseguire da esso il programma di installazione. Nella finestra di dialogo **Run** (Esegui), digitare `Drive_letter` e fare clic su **OK** oppure premere **Invio**.
3. Il programma di installazione guida l'utente attraverso varie finestre di dialogo che richiedono alcuni dati durante il processo di installazione, tra cui:
  1. Conferma della licenza per l'utente finale.
  2. Scelta dell'installazione predefinita, minima o personalizzata (è possibile escludere i file di progetto di esempio, i file importabili e altri file ausiliari).
  3. Specifica della cartella di installazione.
  4. Specifica della cartella del menu principale per i collegamenti.

Per passare al passo successivo, fare clic sul pulsante **Next**.

Al termine dell'installazione compare una finestra di conferma. Chiuderla facendo clic sul pulsante **Done**. Se si dispone di un sistema CAM con protezione a chiave elettronica, inserire la chiave in una porta USB prima di avviare il sistema.

<strong>Nota 1:</strong> l'installazione di <strong>ENCY</strong> deve essere eseguita con diritti di amministratore. Questa versione richiede i diritti di amministratore per l'installazione degli add-in. Se non si dispone di tali diritti, creare un collegamento per avviare <strong>ENCY</strong> con diritti di amministratore oppure rivolgersi al supporto.

<strong>Nota 2:</strong> in alcuni casi, quando si installa <strong>ENCY</strong> con una chiave elettronica, può essere necessario installare separatamente il driver della chiave elettronica. A tale scopo, al termine dell'installazione, selezionare nel menu del programma la configurazione dei driver della chiave.

<strong>Nota 3:</strong> se compare il messaggio "Electronic key not found!", verificare che la chiave sia collegata. Se ciò accade al primo avvio, installare il driver della chiave elettronica.
