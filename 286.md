# Lista dos comandos CLData básicos

Os comandos CLDATA gerados pelo sistema CAM estão listados na tabela. A lista completa dos comandos CLDATA está na parte 3 deste manual, **Postprocessors generator**.

| Comando | Descrição |
|---|---|
| AXESBRAKE | Controle de freios dos eixos da máquina |
| CIRCLE | Movimento por arco de círculo |
| COMMENT | Comentários |
| COOLNT | Liga/desliga o refrigerante |
| CUTCOM | Compensação do raio e do comprimento da ferramenta |
| DELAY | Atraso de tempo |
| EDMMOVE | Movimento EDM |
| EXTCYCLE | Ciclo estendido (ciclo de furação, ciclo de torneamento, ciclo de fresamento) |
| FEDRAT | Avanço |
| FROM | Ponto inicial do percurso da ferramenta |
| GOHOME | Retorno à posição inicial (home) |
| GOTO | O movimento linear |
| INSERT | Inserção de uma cadeia de caracteres no código NC |
| INTERPOLATION | Ativação/desativação de diferentes tipos de modo de interpolação |
| LOADTL | Carregamento da ferramenta |
| MULTIARC | Movimento circular multiaxial |
| MULTIGOTO | Movimento em várias coordenadas |
| OPSTOP | Parada opcional da execução do código NC |
| ORIGIN | Definição do sistema de coordenadas |
| PhysicGOTO | Movimento dos eixos físicos da máquina |
| PLANE | O plano de trabalho (XY/YZ/ZX) |
| PPFUN | Função do pós-processador |
| RAPID | Avanço rápido |
| SELWORKPIECE | Seleção do porta-peça ativo |
| SINGLETHREAD | Comando de thread único |
| SPINDL | Liga/desliga o fuso |
| STOP | Parada da execução do código NC |
| TAKEOVER | Transferência da peça para outro fuso |
| WAIT | Espera pelo ponto de sincronização |
