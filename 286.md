# Elenco dei comandi CL-data di base

I comandi CLDATA generati dal sistema CAM sono elencati nella tabella. L'elenco completo dei comandi CLDATA è riportato nella parte 3 di questo manuale, **Postprocessors generator** (generatore di postprocessori).

| Comando | Descrizione |
|---|---|
| AXESBRAKE | Controllo dei freni degli assi della macchina |
| CIRCLE | Movimento su arco di cerchio |
| COMMENT | Commenti |
| COOLNT | Attivazione/disattivazione del refrigerante |
| CUTCOM | Compensazione del raggio e della lunghezza dell'utensile |
| DELAY | Sosta (tempo di sosta) |
| EDMMOVE | Movimento EDM |
| EXTCYCLE | Ciclo esteso (ciclo di foratura, ciclo di tornitura, ciclo di fresatura) |
| FEDRAT | Velocità di avanzamento |
| FROM | Punto iniziale del percorso utensile |
| GOHOME | Ritorno alla posizione di home |
| GOTO | Movimento lineare |
| INSERT | Inserimento di una stringa nel codice NC |
| INTERPOLATION | Attivazione/disattivazione di diversi tipi di modalità di interpolazione |
| LOADTL | Caricamento dell'utensile |
| MULTIARC | Movimento circolare multiasse |
| MULTIGOTO | Movimento multicoordinata |
| OPSTOP | Arresto opzionale dell'esecuzione del codice NC |
| ORIGIN | Definizione del sistema di coordinate |
| PhysicGOTO | Movimento fisico degli assi della macchina |
| PLANE | Il piano di lavoro (XY/YZ/ZX) |
| PPFUN | Funzione del postprocessore |
| RAPID | Movimento rapido |
| SELWORKPIECE | Selezione del dispositivo di serraggio del grezzo attivo |
| SINGLETHREAD | Comando di filettatura a principio singolo |
| SPINDL | Attivazione/disattivazione del mandrino |
| STOP | Arresto dell'esecuzione del codice NC |
| TAKEOVER | Presa del grezzo da parte di un altro mandrino |
| WAIT | Attesa del punto di sincronizzazione |
