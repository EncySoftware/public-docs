# Grundlegende CLDATA-Befehle

Die Tabelle zeigt grundlegende vom CAM-System erzeugte CLDATA-Befehle. Die vollständige Liste befindet sich in der Dokumentation des Postprozessorgenerators.

| Befehl | Beschreibung |
|---|---|
| AXESBRAKE | Maschinenachsbremsen steuern |
| CIRCLE | Kreisbewegung |
| COMMENT | Kommentar |
| COOLNT | Kühlmittel ein-/ausschalten |
| CUTCOM | Werkzeugradius- und Längenkorrektur |
| DELAY | Verweilzeit |
| EDMMOVE | Erodierbewegung |
| EXTCYCLE | Erweiterter Bohr-, Dreh- oder Fräszyklus |
| FEDRAT | Vorschub |
| FROM | Werkzeugweg-Ausgangspunkt |
| GOHOME | Referenzpunktfahrt |
| GOTO | Lineare Bewegung |
| INSERT | Text in NC-Code einfügen |
| INTERPOLATION | Interpolationsmodi umschalten |
| LOADTL | Werkzeug laden |
| MULTIARC | Mehrachsige Kreisbewegung |
| MULTIGOTO | Mehrkoordinatenbewegung |
| OPSTOP | Optionaler Programmhalt |
| ORIGIN | Koordinatensystem definieren |
| PhysicGOTO | Bewegung in physischen Maschinenachskoordinaten |
| PLANE | Arbeitsebene XY/YZ/ZX |
| PPFUN | Postprozessorfunktion |
| RAPID | Eilgang |
| SELWORKPIECE | Aktive Werkstückaufnahme wählen |
| SINGLETHREAD | Einzelpass-Gewindezyklus |
| SPINDL | Spindel steuern |
| STOP | Programmhalt |
| TAKEOVER | Werkstück an andere Spindel übergeben |
| WAIT | Auf Synchronisationspunkt warten |
