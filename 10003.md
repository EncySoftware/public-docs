## General improvements

### Interface.

#### The Home Page has been updated.

The appearance of the <strong>Home Page</strong> has been revised. You can now organize your projects into <strong>collections</strong> — grouping related projects together as large color-coded cards at the top of the page, while individual project cards are shown below in a redesigned grid. The left navigation panel has been reorganized for quicker access to <strong>Recent, Clouds, Local, Extensions, Favorites</strong> sections. [Details](10201021.md)

In addition, the <strong>License manager</strong> is now built directly into the Home Page window instead of opening as a separate window.

#### The context menu of the inspector has been update.

The appearance of elements in the <strong>inspector</strong> (including dropdown lists, switches, etc.) has been revised. Additionally, parameters on the <strong>Setup tab</strong> for machines and robots have been reorganized. [Details](1022.md)

<p><img src="assets/images/download/attachments/157868164/image2026-5-20_15-47-50.png" alt="images/download/attachments/157868164/image2026-5-20_15-47-50.png" width="731"></p>

#### The Machine limits group has been added.

The <strong>Machine limits group</strong> belongs to the <strong>Setup panel</strong> and defines reduced per-axis travel limits that are applied when the toolpath and maps are calculated. These values narrow the axis ranges taken from the machine to a smaller working envelope, so that motion is planned strictly within the range acceptable for the current operation. [Details](1022.md)

![images/download/attachments/157868164/image2026-7-21_14-42-28.png](assets/images/download/attachments/157868164/image2026-7-21_14-42-28.png)

#### Toolpath recalculation has been optimized.

When parameter <strong>changes</strong> do not require a full recalculation, the <strong>calculated toolpath is preserved</strong>. Recalculation updates only the parts affected by the changes, such as transitions, approaches, and retracts.

<strong>Changed parameter indicators have been added</strong>. The CAM system saves the operation's parameter state when the toolpath is calculated. If subsequent edits cause the current settings to differ from those used for the calculated toolpath, the operation receives a <strong>yellow warning status</strong>. The inspector marks changed parameters, their groups, and the corresponding pages, making it easier to locate changes that require recalculation.

<em>Before recalculating</em>, the parameter values used to calculate the current toolpath can be restored.

To hide the hints, open <strong>System setup</strong> → <strong>Additional</strong> → Auto-reset toolpath. [Details](201112.md)

![images/download/attachments/157868164/image2026-9-14_12-5-3.png](assets/images/download/attachments/157868164/image2026-9-14_12-5-3.png)

#### User defaults have been implemented in the inspector.

The inspector's context menu (opened via the three‑dot button) now includes the following menu items: <strong>Save as User default</strong>, <strong>Forget user default</strong>, <strong>Reset to User default</strong>, <strong>Reset to System default</strong>, <strong>Copy property name</strong>, and <strong>Edit defaults</strong>. [Details](100159.md)

![images/download/attachments/157868164/image2026-6-11_8-21-58.png](assets/images/download/attachments/157868164/image2026-6-11_8-21-58.png)

#### Redesigned the Utilities button of main panel for quick access to built-in and custom tools.

The Utilities button of main panel provides quick access to built-in and user-defined tools directly from the main application window. It combines search, sorting, launching, management of custom utilities, and access to the extensions manager in a single panel. [Details](10012.md)

It allows you to interactively build a tool assembly in setup mode on the <strong>Machining tab</strong> — from the mounting seat in the spindle or another machine mounting system to the tool, including various toolholders. <strong>Strategies:</strong>

<em>Advantages:</em>

- Support for generating helices for waterline passes (helical machining).

- In combined strategies, gentle and steep areas are processed using different strategies. This ensures a uniform scallop pattern on the surface and improves cutting conditions.

- Combined strategies feature smoothing/merging of machining zones based on the Smooth distance parameter. This helps produce a more solid toolpath with fewer unnecessary passes and transitions.

- Intelligent toolpath merging for combined strategies has been implemented.

- The calculation process is fully parallelized.

This operation can replace outdated legacy operations and address associated issues. [Details](100126.md)

The <strong>Combo Finish</strong> operation with the <strong>Plane+Waterline strategy</strong> replaces the legacy <strong>Complex operation</strong>, offering improved surface quality and reduced machining time.

#### The Recognize features option has been added for the 6D Contouring operation.

The <strong>Recognize features</strong> option has been added for the <strong>6D Contouring operation</strong> ( [Details](10129.md) ). It allows recognizing the following constructive elements: <strong>Circle, Rectangle, Rounded Rectangle, Slot, Hexagon, and Keyhole</strong>. #### The Smart Motion option has been improved.

<strong>Smart Motion</strong> enables robot trajectory generation for 5D and 6D points without requiring a robot <strong>axes map</strong>. The resulting trajectory stays within axis limits and includes singularity and collision avoidance. Additionally, the trajectory can be fine-tuned using the robot axes map.

#### The Feeds/Speeds calculator has been redesigned and enhanced.

In previous software versions, the calculator provided basic automatic calculation of cutting conditions. For instance, users could input the cutting speed and feed per tooth to automatically derive the spindle speed and table feed rate. The new version of the calculator introduces a comprehensive suite of tools for automated cutting condition calculation. [Details](100128.md)

The system now accounts for critical machining parameters, including:

- tool type (Solid or Indexable);

- workpiece material;

- and other relevant factors.

This enhanced functionality enables users to build and maintain a custom library of cutting conditions. By default, calculations are performed using established industry databases from leading manufacturers: Walter, Kennametal, and Sandvik.

![images/download/attachments/157868164/image2026-6-25_14-21-23.png](assets/images/download/attachments/157868164/image2026-6-25_14-21-23.png)

#### Improvings in Corner control.

Added new Action Type options: <strong>Adjust Feed</strong>, <strong>Adjust Power</strong>, and <strong>Adjust Feed & Power</strong>. Feed adjustment now supports values above 100%, enabling corner acceleration. Power can be controlled independently or alongside feed. [Details](100144.md)

![images/download/attachments/157868164/image2026-5-5_14-26-0.png](assets/images/download/attachments/157868164/image2026-5-5_14-26-0.png)

#### Pullback option has been added to the Welding 6D.

Available for several welding types. When enabled, the tool travels back along the finished weld by a configurable distance before it lifts off, so residual energy stays over already-welded material and does not mark the clean surface — useful for laser welding, where the beam may not switch off instantly. [Details](10271.md)

#### New precise format for exporting simulation result

Simulation results can now be saved in the new precise.camsr format and loaded into another project as a workpiece, preserving the exact model instead of losing detail through STL. Find it in the simulation result export dialog and via the new Sim result button on the Workpiece tab. [Details](10289.md)

Support Generator is a new extension that builds custom fixtures for holding parts during machining, straight from a 3D model. A single click turns it into ready-to-manufacture geometry — complete with the flat-sheet nesting layout for laser cutting. ### Additive manufacturing updates

#### Improvings in Non-planar slicing operation

##### Radial slicing strategy

Added a new <strong>Radial</strong> slicing strategy — slicing is performed by cylindrical surfaces around a specified rotary axis with a constant radial step between layers. The strategy supports parts with any angular extent around the rotary axis:

- <strong>fully closed (360°)</strong> — rings, cylindrical sleeves, shells;

- <strong>with an angular gap (<360°)</strong> — turbine blades, propellers, impellers;

- <strong>helical (>360°)</strong> — augers, spiral parts.

![images/download/attachments/157868164/image2026-5-22_14-31-31.png](assets/images/download/attachments/157868164/image2026-5-22_14-31-31.png)

In a Non-planar slicing operation, you can now specify a gap at the seam of closed contours to prevent line overlap, using <strong>Gap to prevent overlapping.</strong> [Details](1052.md)

#### Zig Zag infill pattern.

Added a new <strong>Zig Zag infill pattern</strong>. Each model layer is divided into regions that can be filled with a continuous zigzag toolpath. A separate toolpath is generated for each region: a contour containing five regions produces five zigzag toolpaths, while a single-region contour produces one continuous toolpath. [Details](1052.md)

#### Power function

Added a <strong>Power function</strong> option to the Non-planar slicing operation. It works the same as in the Cladding 5D operation. [Details](202012.md)

#### Maximum layer time

Added a <strong>Maximum layer time</strong> parameter for additive operations that automatically scales up the working feed when a layer takes too long — useful for concrete 3D printing to avoid cold joints. [Details](100113.md)

### 3D View Controls

#### Added an interactive linear axis ruler.

It appears when you drag a machine node along a linear axis in the 3D view. The ruler displays the current axis coordinate, its travel limits, and provides precise position control. [Details](100167.md)

![images/download/attachments/157868164/image2026-8-27_8-43-26.png](assets/images/download/attachments/157868164/image2026-8-27_8-43-26.png)

#### Updated Machine Display Settings in the 3D view.

The <strong>Machine Visibility Settings popup</strong> helps keep the working area visible and convenient during setup and simulation. It lets you select a machine surface material, such as Gunmetal or Industrial, and keep a selected machine component visually stationary while the remaining components move relative to it. You can adjust the opacity of machine nodes to reveal internal mechanisms or the machining area, and control the visibility of individual nodes in a tree where hovering over a node highlights it in the 3D view. [Details](359.md#machine-display-settings)

#### Updated Toolpath Display Settings in the 3D view.

The new <strong>Toolpath Display Settings popup</strong> makes the machining trajectory easier to inspect during preparation and simulation. You can enable feed-type coloring or use a single toolpath color, and adjust the line width to keep the trajectory readable at any zoom level. [Details](359.md#toolpath-display-settings)

During simulation, select which part of the current operation's toolpath is shown: the full trajectory, the path already completed, the remaining path, or a configurable segment before, after, or around the current tool position. The rest of the program remains visible as a ghost layer. You can also <strong>hide rapid, approach/return, and link moves to focus on cutting passes</strong>. Surface normals and toolpath point markers can be displayed to verify the orientation and structure of multi-axis toolpaths. These overlays follow both the selected move visibility settings and the current playback trace.

The <strong>Simulation tab</strong> now includes additional options for visualizing the toolpath. Configure which parts of the trajectory are displayed to focus on the current machining stage and inspect the operation more clearly.

- <strong>Current layer</strong> — shows the current toolpath layer.

- <strong>Full toolpath</strong> — displays the entire toolpath.

- <strong>From start</strong> — shows the toolpath from the beginning to the current tool position.

- <strong>To end</strong> — shows the remaining toolpath from the current position to the end.

- <strong>Tail</strong> — displays a limited toolpath segment around the current position.

- <strong>Tail ahead</strong> — displays a segment ahead of the current tool position.

- <strong>Tail both ways</strong> — displays segments before and after the current tool position.

#### Updated Display Mode Settings in the 3D view.

The <strong>Display Mode popup</strong> provides quick control over the visual presentation of the 3D scene. You can switch between shaded, shaded-with-edges, and wireframe rendering modes to choose the most convenient way to inspect the machine, part, and surrounding geometry.

The popup also lets you enable ambient occlusion for improved depth perception and a ground plane for clearer scene orientation. Equipment color schemes can be applied to highlight the machine kinematics: each kinematic link receives a distinct contrasting color, while static components remain neutral. Project Colors preserves the original model colors, while Gunmetal and Restrained provide alternative industrial palettes. Robot manipulators retain their native manufacturer colors in every scheme. [Details](169.md#display-mode-settings)

### Added a new navigation mode for view rotation.

<strong>Rotation Mode</strong> — a new toolbar button that switches between free <strong>Trackball rotation</strong> and constrained <strong>Orbit rotation</strong>, in which a chosen local axis (X, Y or Z) is kept vertical on screen.
