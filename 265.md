# Importing objects from 3dm files (Rhinoceros™)

CAM system performs direct reading of project files from the Rhinoceros CAD system versions 4.0 - 7.0 (*.3dm).

All types of geometrical data are imported. Information regarding elements layers and visual properties, except for color, are ignored.

<em>Note:</em> <em>it is not need installed software Rhinoceros for import Rhinoceros file.</em>

<em>Note:</em> <em>it is possible import 3dm files with CAM system addin "Rhinoceros Toolbar & import addin".</em>
