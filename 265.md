# Importação de objetos de arquivos 3dm (Rhinoceros™)

O sistema CAM realiza a leitura direta de arquivos de projeto do sistema CAD Rhinoceros versões 4.0 - 7.0 (*.3dm).

Todos os tipos de dados geométricos são importados. As informações sobre camadas de elementos e propriedades visuais, exceto a cor, são ignoradas.

<em>Observação: não é necessário instalar o software Rhinoceros para importar o arquivo Rhinoceros.</em>

<em>Observação: é possível importar arquivos 3dm com o suplemento do sistema CAM "Rhinoceros Toolbar & import addin".</em>
