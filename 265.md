# Importieren von Objekten aus 3dm-Dateien (Rhinoceros™)

Das CAM-System liest Projektdateien (*.3dm) aus dem CAD-System Rhinoceros der Versionen 4.0 bis 7.0 direkt ein.

Alle Geometrietypen werden importiert. Informationen zu Ebenen und Darstellungseigenschaften werden mit Ausnahme der Farbe ignoriert.

*Hinweis: Rhinoceros muss für den Import von Rhinoceros-Dateien nicht installiert sein.*

*Hinweis: 3dm-Dateien können auch über das Add-in „Rhinoceros Toolbar & import addin“ importiert werden.*
