# Importazione di oggetti da file 3dm (Rhinoceros™)

Il sistema CAM esegue la lettura diretta dei file di progetto del sistema CAD Rhinoceros, versioni 4.0 - 7.0 (*.3dm).

Vengono importati tutti i tipi di dati geometrici. Le informazioni sui layer degli elementi e sulle proprietà visive, ad eccezione del colore, vengono ignorate.

<em>Nota:</em> <em>per importare un file Rhinoceros non è necessario che il software Rhinoceros sia installato.</em>

<em>Nota:</em> <em>è possibile importare file 3dm con il componente aggiuntivo del sistema CAM "Rhinoceros Toolbar & import addin".</em>
