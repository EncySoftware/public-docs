# Polare Interpolation

![images/download/thumbnails/157862768/f_clip0145.png](assets/images/download/thumbnails/157862768/f_clip0145.png)

Polare Interpolation steht für Fräsoperationen zur Verfügung, sofern die Maschine sie unterstützt.

Polare Interpolation ersetzt bei einer 3-Achsen-Fräsbewegung eine Linearachse durch eine Drehachse. Dies wird häufig bei Drehmaschinen mit angetriebenen Werkzeugen benötigt, ist aber auch bei anderen Maschinen möglich. Eine gewöhnliche Drehmaschine besitzt zwei Linearachsen, üblicherweise X und Z, sowie die Spindeldrehung als C-Achse.

![images/download/attachments/157862768/f_clip0146.png](assets/images/download/attachments/157862768/f_clip0146.png)

Ohne Transformation erzeugt das CAM-System die Bahn in [X,Y,Z]-Koordinaten. Mit polarer Transformation wird dieselbe Geometrie in [X,C,Z] ausgegeben. Die Transformation lautet somit [X,Y,Z] => [X,C,Z].

Für polare Interpolation muss die Maschine folgende Voraussetzungen erfüllen:

1. Eine Drehachse, beispielsweise Rundtisch oder Drehspindel, dreht das Werkstück.
2. Diese Drehachse liegt parallel zur Werkzeugdrehachse.
3. Eine Radialachse bewegt das Werkzeug in der Ebene senkrecht zur Drehachse.
4. Eine Axialachse bewegt das Werkzeug entlang der Drehachse.

Sind diese Bedingungen erfüllt und ist **Machine → Control parameters → Rotary transformations → Polar interpolation is available** aktiviert, steht der Bereich für Rotationstransformationen auf der Transformationsseite zur Verfügung.

![images/download/attachments/157862768/image2024-7-9_17-21-49.png](assets/images/download/attachments/157862768/image2024-7-9_17-21-49.png)

**Mode** wählt keine, polare oder zylindrische Transformation. Die Toleranz bestimmt die zulässige Abweichung der transformierten Bahn von der idealen Bahn in Millimetern bzw. Zoll.

Die polare Transformation verwendet folgende Berechnungen:

![images/download/thumbnails/157862768/embim22.gif](assets/images/download/thumbnails/157862768/embim22.gif)

![Winkelberechnung der polaren Transformation](assets/images/download/thumbnails/157862768/embim23.gif)

Dabei bezeichnet:

**R** die Position der Radialachse,

**A** die Position der Drehachse,

**X** die Position der ersten Linearachse,

**Y** die Position der zweiten Linearachse.

Die entsprechenden Felder ordnen die Maschinenachsen als Drehachse, Radialachse usw. zu. Die Vorgaben stammen aus dem Maschinenschema.

Unterstützt die CNC-Steuerung polare Interpolation, kann die Transformation dort erfolgen. Das NC-Programm enthält dann [X,Y,Z]-Koordinaten; die Steuerung wandelt sie in [X,C,Z] um. Der Ablauf ist üblicherweise:

1. Startpunkt mit den realen Maschinenachsen anfahren.
2. Polare Interpolation einschalten.
3. Profil in [X,Y,Z]-Koordinaten abfahren.
4. Polare Interpolation ausschalten.

Beispiele für die zugehörigen Steuerungsbefehle:

| CNC-Steuerung | Polare Interpolation einschalten | Polare Interpolation ausschalten |
|---|---|---|
| FANUC, Mori Seiki, HAAS usw. | G112 | G113 |
| Sinumerik | TRANSMIT | TRAOFF |
| Heidenhain | - | - |

Die Option **CNC interpolation** ist verfügbar, wenn **Machine → Control parameters → Rotary transformations → CNC supports polar interpolation** aktiviert ist. Bei Verwendung dieser Option werden die Befehle zum Ein- und Ausschalten der polaren Interpolation ausgegeben. Andernfalls enthält das NC-Programm direkt [X,C,Z]-Koordinaten.
