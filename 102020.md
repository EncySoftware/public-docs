# Werkzeuge aus externen Systemen laden und dort speichern

Öffnen Sie das Fenster **Tools**. Oben stehen **Load tool from PLM** und **Save tool to PLM** zur Verfügung.

![images/download/attachments/157867860/26.png](assets/images/download/attachments/157867860/26.png)

<a id="loading-tools-from-an-external-system"></a>

## Werkzeuge laden

Klicken Sie auf **Load tool from PLM** und wählen Sie die Verbindung.

![Verbindung auswählen](assets/images/download/attachments/157867860/27.png) Im Objektbaum wählen Sie den Werkzeugsatz und klicken auf **Open**. Die Werkzeuge werden importiert und im Werkzeugfenster angezeigt.

![images/download/attachments/157867860/28.png](assets/images/download/attachments/157867860/28.png)

<a id="saving-tools-to-an-external-system"></a>

## Werkzeuge speichern

Wählen Sie ein Werkzeug, klicken Sie auf **Save tool to PLM**, wählen Sie die Verbindung und den Zielort im externen System.

![images/download/attachments/157867860/29.png](assets/images/download/attachments/157867860/29.png)

Zum Überschreiben aktivieren Sie **Overwrite item**. Klicken Sie anschließend auf **Save**.

![images/download/attachments/157867860/30.png](assets/images/download/attachments/157867860/30.png)
