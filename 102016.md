# Importação de um modelo geométrico de um sistema externo

Os modelos geométricos de peças e brutos podem ser importados diretamente de um sistema PLM pelo botão **Import** da barra de ferramentas da **janela principal**. Esse botão possui uma pequena seta que abre um menu suspenso com opções adicionais de importação:

- **Import model from PLM**;
- **Import workpiece from PLM**.

Cada opção possui um submenu no qual é possível selecionar uma conexão PLM configurada.

**Nota:** as opções relacionadas ao PLM são exibidas somente quando pelo menos uma conexão PLM está configurada.

![images/download/attachments/157867803/31.png](assets/images/download/attachments/157867803/31.png)

## Importação de um modelo geométrico de um sistema externo

Clique na seta ao lado de **Import** e selecione **Import model from PLM** → *[connection name]*.

![images/download/attachments/157867803/32.png](assets/images/download/attachments/157867803/32.png)

Será aberta uma janela com a árvore dos modelos geométricos disponíveis no sistema externo. Selecione o modelo desejado e clique em **Open**. O modelo será importado para o projeto atual.

![images/download/attachments/157867803/33.png](assets/images/download/attachments/157867803/33.png)

## Importação de um bruto de um sistema externo

Clique na seta ao lado de **Import** e selecione **Import workpiece from PLM** → *[connection name]*.

![images/download/attachments/157867803/34.png](assets/images/download/attachments/157867803/34.png)

Navegue pela estrutura de objetos do sistema externo até localizar o bruto necessário e clique em **Open**. O bruto selecionado será importado para o projeto atual.

![images/download/attachments/157867803/35.png](assets/images/download/attachments/157867803/35.png)
