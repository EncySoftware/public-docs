# Geometrie aus einem externen System importieren

Über den Pfeil an **Import** in der Hauptsymbolleiste können Bauteil- und Rohteilmodelle direkt aus einem PLM-System geladen werden:

- **Import model from PLM** – Modell importieren;
- **Import workpiece from PLM** – Rohteil importieren.

Das jeweilige Untermenü enthält die eingerichteten Verbindungen.

**Hinweis:** Die PLM-Einträge erscheinen nur, wenn mindestens eine Verbindung konfiguriert ist.

![images/download/attachments/157867803/31.png](assets/images/download/attachments/157867803/31.png)

<a id="importing-a-geometry-model-from-an-external-system"></a>

## Geometriemodell importieren

Wählen Sie **Import model from PLM** und die Verbindung.

![Modellimport](assets/images/download/attachments/157867803/32.png) Wählen Sie im Objektbaum das Modell und klicken Sie auf **Open**. Es wird in das aktuelle Projekt importiert.

![images/download/attachments/157867803/33.png](assets/images/download/attachments/157867803/33.png)

<a id="importing-a-workpiece-from-an-external-system"></a>

## Rohteil importieren

Wählen Sie **Import workpiece from PLM** und die Verbindung.

![Rohteilimport](assets/images/download/attachments/157867803/34.png) Wählen Sie das Rohteil im externen Objektbaum und klicken Sie auf **Open**. Es wird in das aktuelle Projekt übernommen.

![images/download/attachments/157867803/35.png](assets/images/download/attachments/157867803/35.png)
