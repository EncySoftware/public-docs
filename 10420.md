# Import-API für Bearbeitungswerkzeuge

Die Programmierschnittstelle ermöglicht eigene Programme zum Importieren von Bearbeitungswerkzeugen aus externen Systemen, beispielsweise TDM-, PDM- oder PLM-Systemen. Ein solches Programm kann etwa:

- ein neues Werkzeug des gewünschten Typs erstellen, beispielsweise Dreh-, Fräs- oder benutzerdefiniertes Werkzeug;
- geometrische Abmessungen und Parameter festlegen;
- das Werkzeug einer Bibliothek hinzufügen und diese als Datei speichern. Anschließend kann die Bibliothek wie gewohnt im [Werkzeugfenster](615.md) verwendet werden.

Die vollständige Beschreibung finden Sie in der [API-Dokumentation](https://docs.encycam.com/CAMAPI/1/en/src/MachiningToolsImport/MTIStartPage.html).
