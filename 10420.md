# API de importação de ferramentas de usinagem

Há uma interface de programação de aplicativos (API) com a qual você pode escrever seu próprio programa para importar ferramentas de usinagem para o sistema CAM a partir de qualquer sistema externo que desejar (como sistemas TDM/PDM/PLM). Ela permite criar um programa simples (como o mostrado na figura abaixo) no qual você pode, por exemplo:

- criar uma nova ferramenta do tipo desejado (torneamento, fresamento ou tipo personalizado);
- especificar suas próprias dimensões geométricas e parâmetros dessa ferramenta;
- adicionar essa ferramenta a um armazenamento (biblioteca de ferramentas) e salvá-la em um arquivo no disco rígido. Em seguida, você pode usar essa biblioteca na [janela de ferramentas do CAM](615.md) da maneira usual.

Para obter informações completas sobre o uso dessa API, visite [esta página](https://docs.encycam.com/CAMAPI/1/en/src/MachiningToolsImport/MTIStartPage.html).
