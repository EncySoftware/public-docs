# Constraints

Constraints are created during the build process and are removed during editing when the link conditions are lost. For example, the line has ceased to be parallel or the touch has disappeared.

In the process of editing a block, the constraints are preserved and the objects change in accordance with them. That is, tangency, parallelism of lines, etc. is saved.

Constrain types:

- **Tangential**

During construction, while pressing **[Ctrl]**, select the object to which this c onstrain will be applied. For example: a circle touches a line, or a line segment touches a circle or arc.

![Circle tangent to a line segment](assets/images/download/attachments/162968042/tangent_circle_to_line.gif)

When constructing a line, in addition to tangency, it is set that the point lies on the circle.

![Line segment tangent to a circle](assets/images/download/attachments/162968042/tangent_line.gif)

- Point on a circle, line, arc.

When constructing, if the point is on the object, then the corresponding connection is created. If the point during construction coincides with the point of another object, then 2 joint connections are created and the point becomes common when editing the block.

![Point on an object](assets/images/download/attachments/162968042/point_on_object.gif)

- Parallel, perpendicular

If during the construction process with pressed **[Ctrl]** move the cursor to the line, then auxiliary lines for construction will appear and a link will be set. You can also set the link in the inspector on the **Constraints** tab, and if the lines did not meet this criterion, they will be adjusted.

- Axes

If, when constructing a line, by double-clicking on an arc or a circle, axes will be drawn that will follow the change in this element.

![images/download/attachments/157860476/image2024-8-9_17-57-54.png](assets/images/download/attachments/157860476/image2024-8-9_17-57-54.png)

- Equality

The equality of segments, radii of arcs, circles is set when copying with replication. You can also set such a link in the inspector on the **Constraints** tab.

- Linear size

A binding of a linear dimension is created when it is assigned to a line. Subsequent editing of the segment will also adjust the size.

- Point coincide

Such a connection is created during construction, when the points of the objects coincide. You can also set such a link in the inspector on the **Constraints** tab.

- Object-forming links

They are used to connect created complex objects, such as a contour, a radial dimension, an angular dimension, a rectangle, a fillet, a chamfer, a script. The link persists as long as the original object exists.

## Managing constraints

Select a constraint button, then select the first and second objects following the prompts. Available buttons include **Parallel**, **Tangential**, **Perpendicular** and **Equal**.

A constraint conflicting with locks is not created; the application reports that locks or unselected objects prevent it. Clicking a constraint symbol on the sketch removes constraints of that type from the object. Clicking its inspector icon removes the constraint; hovering highlights it.

## Locks

Locks hold values independently of geometric constraints. Length, radius, point coordinates X and Y (separately or together), width, height, angle, offset distance and dimension value can be locked. Click a lock icon in the inspector to toggle it.
