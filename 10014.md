# Hilfemenü der Hauptleiste

Das Menü **Help** bietet Zugriff auf Dokumentation, Lernmaterial und Support.

![images/download/attachments/157858817/image2024-7-1_17-22-4.png](assets/images/download/attachments/157858817/image2024-7-1_17-22-4.png)

| Schaltfläche | Funktion |
|---|---|
| ![Handbuch](assets/images/download/thumbnails/157858817/image2022-3-22_15-9-52.png) | **User manual:** Öffnet die Hilfe des CAM-Systems. |
| ![Willkommensseite](assets/images/download/thumbnails/157858817/image2022-3-22_15-10-32.png) | **Welcome page:** Zeigt aktuelle Informationen der Produktwebsite. |
| ![Support](assets/images/download/thumbnails/157858817/image2022-3-22_15-10-48.png) | **Support request:** Bereitet eine Anfrage an ENCY SOFTWARE LTD., support@encycam.com, vor. |
| ![Lernprogramm](assets/images/download/thumbnails/157858817/image2022-3-22_15-11-0.png) | **Tutorial:** Startet das Lernprogramm. |
| ![Aktualisierungen](assets/images/download/thumbnails/157858817/image2022-3-22_15-10-7.png) | **Updates:** Sucht nach Aktualisierungen. |
| ![Version zurücksetzen](assets/images/download/attachments/157858817/image2022-3-22_15-10-19.png) | **Rollback updates:** Kehrt bei Bedarf zu einer früheren Programmversion zurück. |
| ![KI-Assistent](assets/images/download/thumbnails/157858817/AIAssistant_En.png) | **[AI Assistant](10428.md):** Unterstützt bei verschiedenen Aufgaben im CAM-Arbeitsablauf. |
