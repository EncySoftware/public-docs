# Maschinenanforderungen für Werkstückbewegungen

Operationen zum Bewegen von Werkstücken können auf unterschiedlichen Maschinen verwendet werden, beispielsweise auf Bearbeitungszentren, Drehmaschinen mit Gegenspindel und Industrierobotern. Voraussetzung ist ein spezieller Werkzeughalter, der als **Gripper** (Greifer) gekennzeichnet ist. Ohne Greifer im aktuellen Maschinenschema stehen diese Operationen nicht zur Verfügung.

Die Option kann auf der Seite **Machine setup** oder in der Datei mit der Beschreibung des Maschinenschemas aktiviert werden.

![images/download/attachments/157866370/image2024-7-23_16-52-10.png](assets/images/download/attachments/157866370/image2024-7-23_16-52-10.png)

Das folgende Beispiel zeigt die Werkzeughalterdefinition im Maschinenschema. Innerhalb von **SupportedToolTypes** ist **Gripper** aktiviert.

```
<SCType ID="MillSpindle" Caption="Mill Spindle" Type="TToolHolderNode">
   <VisualProperties>
       <Metallic DefaultValue="True"/>
   </VisualProperties>
   <XAxisID DefaultValue="AxisX"/>
   <YAxisID DefaultValue="AxisY"/>
   <ZAxisID DefaultValue="AxisZ"/>
   <SupportedToolTypes>
      <MillTool DefaultValue="true"/>
      <LatheCutter DefaultValue="true"/>
      <Gripper DefaultValue="true"/>
   </SupportedToolTypes>
</SCType>
```

## Dreh-Fräs-Maschinen mit Gegenspindel anpassen

Mit einer Pick-and-Place-Operation kann das Werkstück zwischen Haupt- und Gegenspindel einer Dreh-Fräs-Maschine übergeben werden. Dazu muss die Gegenspindel als Werkzeughalter mit Greiferfunktion definiert sein. Bei älteren Maschinenschemas ist gegebenenfalls eine Anpassung der Maschinenbeschreibung erforderlich. Die folgende Abbildung zeigt das bisherige Schema links und das angepasste Schema rechts.

![images/download/attachments/157866370/image2021-5-25_16-33-18.png](assets/images/download/attachments/157866370/image2021-5-25_16-33-18.png)

1. In der Definition der Gegenspindel wird **TWorkpieceHolderNode** durch **TToolHolderNode** ersetzt.

2. **XAxisID**, **YAxisID** und **ZAxisID** werden ergänzt. Sie geben die Namen der Achsen an, die für die Werkzeugbewegung in der jeweiligen Richtung zuständig sind.

3. Unter **SupportedToolTypes** wird **Gripper** hinzugefügt.
