# Fenster für Halter (*.osd)

Dieses Fenster dient zum Öffnen und Hinzufügen von 3D-Haltermodellen im Format *.osd.

Bereits vorbereitete Haltermodelle können vom Computer hinzugefügt werden.

Die Liste der hinzugefügten Halter wird in der Konfigurationsdatei gespeichert und automatisch wieder geladen.

![images/download/attachments/157867722/image2021-4-29_16-16-39.png](assets/images/download/attachments/157867722/image2021-4-29_16-16-39.png)

Das Fenster kann an folgenden Stellen geöffnet werden:

1. Im Inspektor auf der Registerkarte **Tool** (Werkzeug). ![Werkzeugregisterkarte](assets/images/download/attachments/157867722/image2024-7-22_16-50-18.png)
2. In den Operationsparametern auf der Registerkarte **Holder** (Halter). ![Halterregisterkarte](assets/images/download/attachments/157867722/image2024-7-22_16-52-18.png)
3. Im Halterauswahlfenster. ![Halterauswahl](assets/images/download/attachments/157867722/image2024-7-30_15-25-11.png)
