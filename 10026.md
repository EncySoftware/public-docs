# Systemprotokolle

Das System kann eine Liste der wichtigsten Ereignisse anzeigen, die seit dem Start der Anwendung aufgetreten sind.

Die Ereignisse werden in einem eigenen Fenster angezeigt, das über **Utilities → System logs** (Dienstprogramme → Systemprotokolle) geöffnet wird.

![images/download/attachments/157859158/image2024-7-1_17-56-41.png](assets/images/download/attachments/157859158/image2024-7-1_17-56-41.png)

Jedes Ereignis enthält einen Zeitpunkt und eine Beschreibung. Ist die Beschreibung zu lang für eine Zeile, erscheint am Zeilenanfang eine Schaltfläche zum Aufklappen. Die Farbe kennzeichnet den Ereignistyp: Rot steht für Fehler, Gelb für Warnungen und Weiß für normale Ereignisse.

Das Fenster unterstützt die Fehlersuche, indem es Ereignisse und ihre Einzelheiten nachvollziehbar macht und damit Hinweise auf mögliche Ursachen liefert.
