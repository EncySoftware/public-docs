# Basic

## Application area:

The <strong>Basic</strong> group contains face milling, waterline and plane machining, contouring, and flat-area finishing operations. These topics describe the common milling strategies and their operation settings.

### Operations:

- <strong>Face milling.</strong> Machines planar faces. [Details](10117.md)

- <strong>Roughing waterline.</strong> Removes stock in horizontal layers. [Details](736.md)

- <strong>Finishing waterline.</strong> Finishes surfaces using waterline passes. [Details](841.md)

- <strong>Roughing plane.</strong> Removes stock using plane passes. [Details](735.md)

- <strong>2.5D contouring.</strong> Machines contours at different levels. [Details](10115.md)

- <strong>Flat land.</strong> Finishes flat areas of the model. [Details](759.md)

- <strong>3D contouring.</strong> Machines spatial curves. [Details](700.md)
