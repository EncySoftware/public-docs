# Basic

<a id="application-area"></a>

## Ambito di applicazione:

Il gruppo <strong>Basic</strong> (operazioni di base) comprende le operazioni di spianatura, di sgrossatura e finitura a Z costante, di lavorazione per piani, di contornatura e di finitura delle aree piane. Questi argomenti descrivono le strategie di fresatura più comuni e le relative impostazioni dell'operazione.

<a id="operations"></a>

### Operazioni:

- <strong>Face milling.</strong> Lavora le facce piane. [Dettagli](10117.md)

- <strong>Roughing waterline.</strong> Asporta il sovrametallo per strati orizzontali. [Dettagli](736.md)

- <strong>Finishing waterline.</strong> Esegue la finitura delle superfici con passate a Z costante. [Dettagli](841.md)

- <strong>Roughing plane.</strong> Asporta il sovrametallo con passate per piani. [Dettagli](735.md)

- <strong>2.5D contouring.</strong> Lavora contorni a livelli diversi. [Dettagli](10115.md)

- <strong>Flat land.</strong> Esegue la finitura delle aree piane del modello. [Dettagli](759.md)

- <strong>3D contouring.</strong> Lavora curve spaziali. [Dettagli](700.md)
