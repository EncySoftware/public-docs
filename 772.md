# Tipos de objetos importáveis

Todos os objetos, conforme definido no padrão **IGES**, são divididos em grupos. Abaixo estão listados os grupos e objetos IGES, atualmente importáveis pelo sistema.

Os seguintes tipos são importados do grupo **Curves and Surfaces**:

- **Circular Arc**, tipo 100;
- **Composite Curve**, tipo 102;
- **Conic Arc**, tipo 104;
- **Copious Data**, tipo 106;
- **Plane**, tipo 108;
- **Line**, tipo 110;
- **Parametric Spline Curve**, tipo 112;
- **Parametric Spline Surface**, tipo 114;
- **Point**, tipo 116;
- **Ruled Surface**, tipo 118;
- **Surface of Revolution**, tipo 120;
- **Tabulated Cylinder**, tipo 122;
- **Transformation Matrix**, tipo 124;
- `NURBS-curve Rational B-Spline Curve`, tipo 126;
- `NURBS-surface Rational B-Spline Surface`, tipo 128;
- **Offset Curve**, tipo 130;
- **Offset Surface**, tipo 140;
- **Boundary**, tipo 141;
- **Curve on a Parametric Surface**, tipo 142;
- **Bounded Surface**, tipo 143;
- **Trimmed Surface**, tipo 144;

Os seguintes tipos são importados do grupo `B-Rep Solids`:

- **Face**, tipo 510;
- **Loop**, tipo 508;
- **Edge**, tipo 504;
- **Vertex**, tipo 502;

Isso permite que o programa trabalhe com `Manifold Solid B-Rep Object`, tipo 186, como um conjunto de superfícies delimitadas.

Do grupo **Annotation Entities**, nenhum tipo é importado. Essas entidades não são significativas para fins de usinagem.

Do grupo **Structure Entities**, somente as entidades **Color Definition**, tipo 314, são importadas. Isso significa que as cores do modelo no sistema CAM são idênticas às cores usadas no programa de modelagem.
