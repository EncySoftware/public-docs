# Alibre Design™: Symbolleiste und Import-Add-in

![images/download/attachments/157859610/image2018-12-21_17-2-54.png](assets/images/download/attachments/157859610/image2018-12-21_17-2-54.png)

Über die Symbolleiste können Sie geometrische Daten aus Alibre Design™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859610/image2022-3-30_12-8-59.png](assets/images/download/attachments/157859610/image2022-3-30_12-8-59.png)

Mit dem Add-In können Sie <strong>Alibre</strong> <strong>Design™</strong>-Projektdateien importieren.

Unterstützte Dateierweiterungen: AD_PRT, AD_ASM, AD_SMP. Damit diese Option funktioniert, muss die erforderliche Anwendung (Alibre Design™) auf Ihrem Computer installiert sein.
