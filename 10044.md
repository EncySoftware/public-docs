# Barra degli strumenti e add-in di importazione per Alibre Design™

![images/download/attachments/157859610/image2018-12-21_17-2-54.png](assets/images/download/attachments/157859610/image2018-12-21_17-2-54.png)

La barra degli strumenti consente di esportare i dati geometrici da Alibre Design™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859610/image2022-3-30_12-8-59.png](assets/images/download/attachments/157859610/image2022-3-30_12-8-59.png)

L'add-in consente di importare i file di progetto di <strong>Alibre</strong> <strong>Design™</strong>.

Estensioni di file supportate: AD_PRT, AD_ASM, AD_SMP. Per il funzionamento di questa opzione, l'applicazione richiesta (Alibre Design™) deve essere installata sul computer.
