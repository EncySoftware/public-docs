# Barra de ferramentas e suplemento de importação do Alibre Design™

![images/download/attachments/157859610/image2018-12-21_17-2-54.png](assets/images/download/attachments/157859610/image2018-12-21_17-2-54.png)

A barra de ferramentas permite exportar dados geométricos do Alibre Design™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859610/image2022-3-30_12-8-59.png](assets/images/download/attachments/157859610/image2022-3-30_12-8-59.png)

O suplemento permite importar arquivos de projeto do **Alibre Design™**.

Extensões suportadas: AD_PRT, AD_ASM, AD_SMP. O Alibre Design™ deve estar instalado no computador para que o recurso funcione.
