# Drahteinfädelpunkte

Drahterodierbahnen beginnen üblicherweise an vorgebohrten Startlöchern. Sind sie im Rohteilmodell enthalten, erkennt das System materialfreie Eintrittspositionen automatisch. Bei einem massiven Rohteil ohne Löcher können sie ausdrücklich angegeben werden. Wählen Sie die Drahterodieroperation und unten links den Bereich **Holes**.

![images/download/attachments/157866070/image2024-7-17_15-13-13.png](assets/images/download/attachments/157866070/image2024-7-17_15-13-13.png)

Bohrungen können über Koordinaten, geometrische Elemente oder automatische 3D-Erkennung hinzugefügt werden. Die Bedienung entspricht der [Bohrungsliste der Bohrungsbearbeitung](705.md).

Wird bei der Berechnung kein geeigneter Startpunkt gefunden, kann das System eine neue vorzubohrende Startbohrung erzeugen und zur Liste hinzufügen. Diese Liste kann als DXF exportiert und in einem anderen Projekt oder Programm zur Rohteilvorbereitung verwendet werden.

Exportieren Sie über das Kontextmenü oder `File / Export / Export holes`.
