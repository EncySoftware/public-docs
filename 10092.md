# Interfaccia dell'albero delle feature

Dopo che il sistema CAM ha riconosciuto le feature, le ordina e le organizza in una struttura ad albero gerarchica. Al livello più alto l'albero delle feature (Feature Tree) è composto da quattro gruppi:

- Job;
- Due;
- Ready;
- Trash.

![images/download/attachments/157863284/FBMp0006.png](assets/images/download/attachments/157863284/FBMp0006.png)

Le feature del gruppo Job sono quelle lavorate nel gruppo di fresatura FBM (FBM Mill Group) corrente. Nella vista grafica si distinguono facilmente grazie al contorno luminoso color lime.

La cartella Due contiene le feature che non sono ancora lavorate in alcun gruppo di fresatura FBM.

La cartella Ready contiene le feature che sono già lavorate in altre operazioni di gruppi di fresatura FBM del progetto.

La cartella Trash contiene le feature eliminate.

Quando una di queste cartelle è compressa, le feature in essa contenute non vengono visualizzate nella vista grafica. Per impostazione predefinita le cartelle Job e Due sono espanse, mentre le cartelle Ready e Trash sono compresse. Sullo schermo si vedono quindi soltanto le feature che devono essere lavorate.

<strong>Conteggio delle feature. Feature alternative</strong>

Accanto a ogni nodo dell'albero delle feature è indicato tra parentesi il numero di feature del nodo. Si può notare che il numero di feature mostrato nell'albero è maggiore di quello atteso. Si può notare anche che alcune feature compaiono due volte nell'albero. Non si tratta di un errore, ma di una caratteristica: accade perché alcune feature hanno feature alternative. Ad esempio, un foro passante può essere forato da due lati. In questo caso il sistema CAM riconosce non uno ma due fori: uno con la direzione positiva dell'asse e l'altro con la direzione negativa dell'asse. Sono feature distinte, ma collegate tra loro: quando si lavora una delle due feature alternative, il sistema CAM contrassegna automaticamente l'altra come Ready.

<strong>Modifica dello schema di raggruppamento</strong>

Il sistema CAM raggruppa le feature in base allo schema di raggruppamento corrente. È possibile raggruppare le feature in base a:

- tipo;
- piano (orientamento principale);
- livelli superiore e inferiore;
- colore.

Inoltre, alle feature simili o identiche viene assegnato lo stesso colore distinto e vengono raggruppate insieme.

Per modificare lo schema di raggruppamento dell'albero delle feature, fare clic sull'elenco a discesa Grouping Scheme nella barra degli strumenti Features. Selezionare o deselezionare le voci dello schema per abilitarle o disabilitarle e trascinarle per cambiarne l'ordine. Tutte le modifiche si riflettono immediatamente nell'albero.

<strong>Selezione delle feature</strong>

Esistono due modi per selezionare le feature.

1. Facendo clic su un nodo nell'albero.
2. Facendo clic su una feature nella vista grafica.

Per selezionare più feature tenere premuto il tasto Ctrl oppure Maiusc.

<strong>La barra delle azioni</strong>

![images/download/attachments/157863284/FBMp0008.png](assets/images/download/attachments/157863284/FBMp0008.png)

Quando si seleziona una feature nella vista grafica anziché nell'albero, la barra delle azioni delle feature (Feature Action Bar) compare sotto il cursore. La barra delle azioni contiene i comandi più usati per le feature:

1. L'elenco combinato Feature Machining Procedure (procedura di lavorazione della feature).
2. L'interruttore di visibilità (Visibility).
3. Il comando Filter (filtro).
4. Il pulsante Delete (elimina).

<strong>Visualizzazione e nascondimento delle feature</strong>

Per mostrare o nascondere le feature selezionate si può fare clic sull'icona della feature nell'albero oppure premere il pulsante corrispondente nella barra delle azioni.

<strong>Filtro delle feature</strong>

È possibile filtrare le feature per piano. È sufficiente selezionare una feature che giace nel piano di interesse e premere il pulsante Filter By Plane (filtra per piano). Di conseguenza verranno visualizzate solo le feature con lo stesso orientamento di piano della feature selezionata, mentre le altre feature verranno escluse sia dall'albero sia dalla vista grafica. Questo comando è utile quando si lavora con una macchina utensile a 3 assi e si vogliono vedere soltanto le feature che giacciono nel piano orizzontale.

<strong>Eliminazione delle feature</strong>

Quando si seleziona una feature nell'albero o nella vista grafica, accanto al primo nodo selezionato nell'albero compare una piccola icona a croce. Premere questa icona per eliminare le feature selezionate. È anche possibile eliminare una feature premendo il pulsante Delete nella barra delle azioni.

L'operazione Delete Features dipende dal contesto.

- Quando si elimina una feature dal gruppo Job, la feature non viene eliminata, ma solo spostata dalla cartella Job alla cartella Due.
- Quando si elimina una feature dalla cartella Due o Ready, essa viene spostata nella cartella Trash.
- Quando si elimina una feature dalla cartella Trash, in realtà non viene eliminata ma ripristinata: ricompare nella cartella Due.
