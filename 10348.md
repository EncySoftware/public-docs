# IDE de scripts

A janela Scripts IDE pode ser aberta no submenu "Utilities" selecionando ![images/download/attachments/157867746/159-28-ScriptsIde.png](assets/images/download/attachments/157867746/159-28-ScriptsIde.png). O Scripts IDE permite criar, excluir e editar módulos de script e atribuir manipuladores de eventos (procedimentos) a alguns objetos do sistema.

![images/download/attachments/157867746/image2024-7-22_17-8-36.png](assets/images/download/attachments/157867746/image2024-7-22_17-8-36.png)

![images/download/attachments/157867746/scripts_ide.png](assets/images/download/attachments/157867746/scripts_ide.png)

No lado esquerdo da janela há três painéis principais para gerenciar scripts e procedimentos de tratamento de eventos: o painel "Objects", o painel "Events" e o painel "Scripts".

O painel "Script units" mostra uma lista de arquivos, chamados unidades de script. Cada um desses arquivos pode conter código escrito na linguagem ENCY PL. As unidades de script podem ser armazenadas de diferentes maneiras.

- Como arquivos externos, armazenados normalmente no sistema de arquivos do computador. Esse método de armazenamento permite usar o mesmo código de programação em vários projetos.
- Como arquivos incorporados ao arquivo de projeto *.stcp. Esse arquivo pode conter código de programação relativo a um único projeto, que pode ser usado a partir de diferentes locais do projeto.
- Como arquivos armazenados dentro da operação tecnológica. Dessa forma, deve ser mantido o código de programação que se aplica apenas a uma única operação. Depois disso, essa operação pode ser salva como parâmetros padrão.

Na parte central da janela há um editor de código, no qual é possível visualizar e editar o código das unidades de script. Para visualizar o código de uma unidade, clique duas vezes no nome da unidade na lista do painel "Scripts". Cada unidade é aberta em uma guia separada do editor de código. Assim, é possível editar vários arquivos simultaneamente.

Para gerenciar unidades e guias, use os botões da barra de ferramentas na parte superior da janela.

O botão "Create script" ![images/download/thumbnails/157867746/embim60.png](assets/images/download/thumbnails/157867746/embim60.png) permite criar uma nova unidade de script vazia. Dependendo do item selecionado na lista "Scripts", a nova unidade será armazenada dentro da operação, dentro do projeto ou como arquivo externo. Após clicar no botão, é aberta uma caixa de diálogo na qual é necessário especificar um nome exclusivo para a unidade (o nome do arquivo, no caso de um arquivo externo).

O botão "Open script" ![images/download/thumbnails/157867746/embim61.png](assets/images/download/thumbnails/157867746/embim61.png) permite abrir um arquivo externo no Scripts IDE e adicioná-lo à lista de unidades de script do sistema. Após clicar no botão, é aberta a caixa de diálogo padrão de seleção de arquivos.

O botão "Save script" ![images/download/thumbnails/157867746/embim62.png](assets/images/download/thumbnails/157867746/embim62.png) salva no arquivo as alterações feitas no editor de código no texto do script ativo (guia ativa). Se o script estiver armazenado dentro de uma operação ou projeto, as alterações serão salvas somente dentro da operação (projeto). Nesse caso, para gravar as alterações no disco, também é necessário salvar o projeto.

O botão "Delete active script" ![images/download/attachments/157867746/scripts_ide_del_btn.png](assets/images/download/attachments/157867746/scripts_ide_del_btn.png) remove fisicamente a unidade de script ativa.

O painel "Objects" contém os objetos que podem ter manipuladores de eventos. A lista de eventos disponíveis para o objeto selecionado é mostrada no painel "Events", abaixo.

Um evento é uma mensagem que ocorre em vários pontos do cálculo do percurso da ferramenta. Os eventos foram projetados para permitir que o usuário influencie de alguma forma a geração do percurso da ferramenta. Toda vez que o evento é disparado para um objeto, a rotina de tratamento atribuída é chamada.

No ENCY, os principais objetos que podem conter eventos são as operações tecnológicas. Por isso, a lista de objetos do editor de scripts é muito semelhante à lista de operações do processo tecnológico. As operações, por sua vez, podem ter objetos filhos que podem ter eventos.

O manipulador de eventos é uma rotina <strong>ENCY PL</strong> (função ou procedimento) na qual o usuário pode descrever, na linguagem de programação, a execução de determinadas ações quando o evento ocorre. No ENCY, para atribuir um procedimento ao tratamento de um determinado evento de um objeto, selecione o objeto desejado na lista de objetos e escolha o evento desejado na lista de eventos. Em seguida, no campo "Script unit", ao lado do nome do evento, defina (selecione na lista) o nome da unidade de script na qual o procedimento de tratamento deve ser procurado. No campo "Method name", especifique o nome do procedimento. Se o procedimento de tratamento do evento ainda não tiver sido escrito, é possível criar automaticamente um protótipo vazio do manipulador. Para isso, clique duas vezes no evento desejado na lista ou clique no botão ![images/download/thumbnails/157867746/embim63.png](assets/images/download/thumbnails/157867746/embim63.png) ao lado do nome do evento. Se o campo "Script unit" contiver o nome de uma unidade existente, o novo procedimento será adicionado a essa unidade; caso contrário, ele será adicionado à unidade aberta no momento no editor de código.

Painel do menu de controle

![images/download/attachments/157867746/scripts_ide_ctrls.png](assets/images/download/attachments/157867746/scripts_ide_ctrls.png)

O menu "Control" contém ferramentas que ajudam a editar, verificar a sintaxe e depurar scripts.

O botão "Compile" ![images/download/attachments/157867746/scripts_ide_compile.png](assets/images/download/attachments/157867746/scripts_ide_compile.png) permite verificar o código quanto a erros de sintaxe.

O botão "Run" ![images/download/attachments/157867746/scripts_ide_run.png](assets/images/download/attachments/157867746/scripts_ide_run.png) é usado para continuar a execução do script após uma pausa.

O botão "Reset" ![images/download/attachments/157867746/scripts_ide_reset.png](assets/images/download/attachments/157867746/scripts_ide_reset.png) é usado para interromper a execução do script e o cálculo do percurso da ferramenta.

O botão "Run to line" ![images/download/attachments/157867746/scripts_ide_runtoline.png](assets/images/download/attachments/157867746/scripts_ide_runtoline.png) executa o script até que a execução atinja a linha atual do editor.

O botão "Pause" ![images/download/attachments/157867746/scripts_ide_pause.png](assets/images/download/attachments/157867746/scripts_ide_pause.png) pausa a execução do script.

O botão "Step over" ![images/download/attachments/157867746/scripts_ide_stepover.png](assets/images/download/attachments/157867746/scripts_ide_stepover.png) executa o comando atual do script sem entrar no subprograma chamado (procedimento ou função).

O botão "Step in" ![images/download/attachments/157867746/scripts_ide_stepin.png](assets/images/download/attachments/157867746/scripts_ide_stepin.png) executa o comando atual do script e entra no código do subprograma chamado.

O botão "Step out" ![images/download/attachments/157867746/scripts_ide_stepout.png](assets/images/download/attachments/157867746/scripts_ide_stepout.png) executa o código do subprograma atual e pausa quando a execução retorna ao subprograma que o chamou.

O botão "Add breakpoint" ![images/download/attachments/157867746/scripts_ide_breakpoint.png](assets/images/download/attachments/157867746/scripts_ide_breakpoint.png) marca uma linha do código na qual a execução deve ser pausada.

Na parte inferior do Scripts IDE ficam os painéis "Messages", "Execution Log" e "Breakpoints". O painel "Messages" contém diversas mensagens do sistema e do compilador. O painel "Execution Log" contém a saída do sistema e dos comandos de impressão. O painel "Breakpoints" mostra a lista de pontos de interrupção.
