# Werkzeugaufnahmen einrichten

Die Kinematik einer Maschine kann sich durch Umrüsten ändern. Für einen schnellen und kontrollierten Wechsel enthält das Maschinenschema spezielle Umschaltknoten.

![images/download/attachments/157865629/embim47.gif](assets/images/download/attachments/157865629/embim47.gif)

Umschaltknoten im Maschinenschema

Ein Umschaltknoten verbindet einen von mehreren alternativen Knoten mit dem übergeordneten Maschinenknoten. Die verfügbaren Varianten werden in einer baumartigen Dropdown-Liste angezeigt.

An einem Revolverplatz können beispielsweise unterschiedliche Aufnahmen für axiale oder radiale, stehende oder angetriebene Werkzeuge eingesetzt werden. Auch ihre Abmessungen können variieren.

![images/download/attachments/157865629/embim48.gif](assets/images/download/attachments/157865629/embim48.gif)

Beispiel für die Beschreibung eines Werkzeugblocks

Die Auswahl wird im Maschinenfenster eingestellt, das durch Doppelklicken auf die Maschine oder über **Parameters** geöffnet wird.
