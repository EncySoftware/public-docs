# Löschen

Mit der Schaltfläche ![Löschen](assets/images/download/attachments/157859805/delete_item_button.jpg) werden die [ausgewählten](10.md) Objekte gelöscht. Wenn die zu löschenden Objekte in einer Bearbeitungsoperation verwendet werden, wird eine Bestätigung angefordert. Die Funktion ist auch über die Taste **Entf** (**Del** auf einer englischen Tastatur) verfügbar.
