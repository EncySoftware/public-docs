# Räumliche Transformationen

Das Fenster **Spatial transformations** (Räumliche Transformationen) bietet verschiedene Methoden zum Transformieren ausgewählter geometrischer Objekte. Es wird über die Schaltfläche ![Räumliche Transformationen](assets/images/download/attachments/157859810/image2024-7-3_16-9-34.png) geöffnet.

- Auf der Seite **Move** (Verschieben) definieren Sie eine Parallelverschiebung. Die Felder **X**, **Y** und **Z** enthalten die Verschiebungen entlang der jeweiligen Achsen. Ist **Make copies** (Kopien erstellen) deaktiviert, werden die ausgewählten Objekte verschoben. Ist die Option aktiviert, werden an den Zielpositionen Kopien erstellt. Sie können die Anzahl der Kopien festlegen. Bei zwei Kopien wird beispielsweise die zweite um denselben Abstand gegenüber der ersten verschoben.

![images/download/attachments/157859810/image2024-7-3_16-9-50.png](assets/images/download/attachments/157859810/image2024-7-3_16-9-50.png)

- Auf der Seite **Rotate** (Drehen) drehen Sie ausgewählte Objekte um die gewählte Achse um den angegebenen Winkel in Grad. Kopien werden schrittweise erzeugt: Jede weitere Kopie entsteht durch Drehen der vorherigen Kopie um denselben Winkel um die festgelegte Achse.

![images/download/attachments/157859810/image2024-7-3_16-10-4.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-4.png)

- Auf der Seite **Scale** (Skalieren) vergrößern oder verkleinern Sie ausgewählte Objekte. Unter **Scale center** werden die Koordinaten des Skalierungsmittelpunkts festgelegt. Als **Scale factor** stehen **mm to inch** (Millimeter in Zoll), **inch to mm** (Zoll in Millimeter) oder ein frei wählbarer Wert unter **Other** zur Verfügung. Ein Faktor größer als 1 vergrößert die Objekte; ein Faktor kleiner als 1 verkleinert sie entsprechend.

![images/download/attachments/157859810/image2024-7-3_16-10-14.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-14.png)

- Auf der Seite **Mirror** (Spiegeln) erzeugen Sie ein zum ausgewählten Objekt symmetrisches Objekt bezüglich einer Achse, Ebene oder eines Punkts.

![images/download/attachments/157859810/image2024-7-3_16-10-23.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-23.png)

- Auf der Seite **Locate Zero** (Nullpunkt ausrichten) verschieben Sie ein Objekt anhand seiner räumlichen Abmessungen. Die Verschiebungen entlang der Achsen werden so gewählt, dass das Objekt gemäß den festgelegten Parametern relativ zum aktuellen [Koordinatensystem](753.md) ausgerichtet ist.

![images/download/attachments/157859810/image2024-7-3_16-10-33.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-33.png)

- Auf der Seite **Coordinate System** (Koordinatensystem) können Sie ein Objekt so drehen, dass die ausgewählten Kanten oben liegen. Das Modell kann auch so transformiert werden, dass eine konstruierte Ebene mit der XY-Ebene des globalen Koordinatensystems zusammenfällt.

![images/download/attachments/157859810/image2024-7-3_16-10-42.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-42.png)

- Auf der Seite **CS to CS** (Koordinatensystem zu Koordinatensystem) transformieren Sie ein Objekt aus dem Ausgangskoordinatensystem **Base CS** in das Zielkoordinatensystem **Final CS**.

![images/download/attachments/157859810/image2024-7-3_16-10-52.png](assets/images/download/attachments/157859810/image2024-7-3_16-10-52.png)

Mit **OK** wird die gewählte Transformation angewendet und das Fenster geschlossen. **Cancel** (Abbrechen) schließt das Fenster, ohne die eingestellten Transformationen anzuwenden. **Apply** (Übernehmen) wendet alle Transformationen auf die ausgewählten Objekte an; das Fenster bleibt geöffnet.
