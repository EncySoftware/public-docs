# Alteração das propriedades de um sistema de coordenadas existente

Para abrir a janela de propriedades do sistema de coordenadas, selecione o item de menu ![images/download/thumbnails/157858659/image2019-1-11_18-21-31.png](assets/images/download/thumbnails/157858659/image2019-1-11_18-21-31.png) <strong>Edit active CS...</strong> no [painel de sistemas de coordenadas](753.md).

A janela de propriedades do sistema de coordenadas é mostrada abaixo:

![images/download/attachments/157858659/image2024-7-1_16-53-33.png](assets/images/download/attachments/157858659/image2024-7-1_16-53-33.png)

Nesta janela, é possível alterar o nome do CS (<strong>CS name</strong>), assim como sua cor (<strong>Color</strong>) e o comentário (<strong>Comment</strong>).

Para mover ou girar o sistema de coordenadas, defina o valor de deslocamento para os eixos <strong>X</strong>, <strong>Y</strong> e <strong>Z</strong> ou os ângulos de rotação correspondentes. Esses valores são relativos ao sistema de coordenadas <strong>Parent</strong> (pai) ou <strong>Global</strong> (global), dependendo da guia ativa.
