# Linie

![images/download/attachments/157860153/image2024-8-7_16-56-58.png](assets/images/download/attachments/157860153/image2024-8-7_16-56-58.png)

Eine **Linie** wird durch zwei Endpunkte definiert und besitzt einen Mittelpunkt. Zur Konstruktion können Sie die Koordinaten der Endpunkte im **Property inspector** (Eigenschafteninspektor) eingeben. Durch Ziehen am Mittelpunkt verschieben Sie die Linie, ohne ihre Länge oder ihren Drehwinkel zu ändern. Durch Ziehen an einem Endpunkt ändern Sie Länge und Drehwinkel dynamisch. Halten Sie dabei **Umschalt** (**Shift**) gedrückt, wird die Linie stattdessen ohne Änderung ihrer Länge und ihres Winkels verschoben. Ein Doppelklick auf einen Kreis oder Bogen erstellt dessen Achslinien.

Linienparameter im **Property inspector**:

![images/download/attachments/157860153/image2024-8-7_16-47-12.png](assets/images/download/attachments/157860153/image2024-8-7_16-47-12.png)

Beim Bearbeiten einer Linie können Sie diese Parameter fixieren, indem Sie auf das Schlosssymbol im Inspektor oder auf das entsprechende Symbol an der Linie klicken.

![images/download/attachments/157860153/image2024-8-7_16-48-26.png](assets/images/download/attachments/157860153/image2024-8-7_16-48-26.png)

Beim Erstellen und Bearbeiten einer Linie können Sie Hilfslinien nutzen. Standardmäßig werden Hilfslinien bei 0°, 45° und 90° angeboten. Im Bearbeitungsmodus wird zusätzlich der bisherige Winkel des Liniensegments berücksichtigt.

Darüber hinaus können Sie Hilfslinien erzeugen, indem Sie den Mauszeiger über einen Punkt eines bereits erstellten Objekts bewegen:

![images/download/attachments/157860153/image2024-8-7_16-49-29.png](assets/images/download/attachments/157860153/image2024-8-7_16-49-29.png)

Halten Sie beim Zeichnen einer Linie **Strg** (**Ctrl**) gedrückt und bewegen Sie den Mauszeiger über eine vorhandene Linie. Zusätzlich werden dann senkrechte und parallele Hilfslinien sowie eine Hilfslinie in Verlängerung dieser Linie angeboten.

![images/download/attachments/157860153/image2024-8-7_16-52-29.png](assets/images/download/attachments/157860153/image2024-8-7_16-52-29.png)

![images/download/attachments/157860153/image2024-8-7_16-54-2.png](assets/images/download/attachments/157860153/image2024-8-7_16-54-2.png)

Wenn Sie bei gedrückter **Strg**-Taste einen Bogen oder Kreis auswählen, wird eine Tangente an diesen Bogen oder Kreis konstruiert. Dies gilt sowohl für den ersten als auch für den zweiten Punkt der Linie.

![images/download/attachments/157860153/image2024-8-7_16-55-37.png](assets/images/download/attachments/157860153/image2024-8-7_16-55-37.png)
