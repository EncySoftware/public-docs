# Barra degli strumenti e add-in di importazione per SolidCAM™

<img src="assets/images/download/attachments/157859753/image2022-12-7_16-45-30.png" width="150">

La barra degli strumenti consente di esportare i dati geometrici da SolidCAM™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859753/image2022-12-7_16-41-24.png](assets/images/download/attachments/157859753/image2022-12-7_16-41-24.png)

L'add-in consente di importare i file di progetto SolidCAM™.

Estensioni di file supportate: SLDASM, ASM, SLDPRT, PRT, SLDDRW, DRW, X_B, X_T, STP, STEP. Per il corretto funzionamento di questa opzione, sul computer deve essere installata l'applicazione richiesta (SolidCAM™).
