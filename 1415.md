# Vorbereitete Messzyklen verwenden

Erstellen Sie zunächst eine Operation aus der Gruppe **Probing**. Für Fräsmaschinen und Roboter stehen **Mill part probing** und **Mill tool probing** zur Verfügung, für Drehmaschinen **Turn part probing** und **Turn tool probing**. Bei Dreh-Fräs-Maschinen können alle vier Operationen verwendet werden.

![images/download/attachments/157866880/image2024-7-18_17-1-38.png](assets/images/download/attachments/157866880/image2024-7-18_17-1-38.png)

<a id="part-probing"></a>

## Werkstück messen

Fügen Sie eine Werkstückmessoperation hinzu und wechseln Sie zu **Job assignment**. Über **Probing cycles** wird ein vorhandener Zyklus hinzugefügt. **Show more** öffnet das Fenster **[Probing templates](1412.md)** mit Bibliotheken vorbereiteter Zyklen. Die Bibliotheken sind auch direkt im Menü von **Probing cycles** verfügbar.

![images/download/attachments/157866880/image2024-7-18_17-2-52.png](assets/images/download/attachments/157866880/image2024-7-18_17-2-52.png)

Das folgende Beispiel beschreibt das Messen einer Bohrung mit **Hole probing**.

Fügen Sie aus der Standardbibliothek **Renishaw**, Gruppe **Report**, den Zyklus **Hole P9814** hinzu.

Die Eigenschaften des eingefügten Zyklus erscheinen unten im Bereich **Job assignment**.

Unter **Measuring geometry** werden die Geometrieparameter für die Zyklusberechnung festgelegt.

![images/download/attachments/157866880/image2024-7-18_17-4-32.png](assets/images/download/attachments/157866880/image2024-7-18_17-4-32.png)

Klicken Sie zum Festlegen von **Geometry item** oder **Top side** auf den Pfeil rechts im jeweiligen Feld und wählen Sie eine Fläche im Grafikfenster aus. Sie wird automatisch in das aktive Feld übernommen.

![images/download/attachments/157866880/image2024-7-18_17-5-46.png](assets/images/download/attachments/157866880/image2024-7-18_17-5-46.png)

Die übrigen Parameter werden in den entsprechenden Feldern eingegeben. Einige Werte können sowohl im Inspektor als auch im Grafikfenster geändert werden.

![images/download/attachments/157866880/image2024-7-18_17-6-29.png](assets/images/download/attachments/157866880/image2024-7-18_17-6-29.png)

<a id="transitions"></a>

## Verbindungen

Auf der Registerkarte **Links** werden die Verbindungen zwischen den Messzyklen eingestellt.

![images/download/attachments/157866880/image2024-7-18_17-7-2.png](assets/images/download/attachments/157866880/image2024-7-18_17-7-2.png)

Zusätzlich zu den allgemeinen Einstellungen stehen folgende Parameter für Messoperationen zur Verfügung:

- **First approach.** Anfahrbewegung zum ersten Zyklus der Operation.
- **Last return.** Rückfahrbewegung nach dem letzten Zyklus.
- **Transition (intermediate).** Verbindungen zwischen den Zyklen.
- **Safe distance.** Abstand für An- und Rückfahrbewegungen, angegeben in Millimetern oder als Prozentsatz des Werkzeugdurchmessers.

Für die genannten Verbindungen stehen drei gemeinsame Arten zur Verfügung:

- **Short.** Direkte Verbindung.
- **Safe distance.** Verbindung mit Rückzug um den unter **Safe distance** angegebenen Abstand.
- **Safe surface.** Verbindung mit Rückzug zur Sicherheitsfläche.

Für **Transition (intermediate)** steht außerdem **Orthogonal** zur Verfügung. Bei gleicher Z-Höhe von Start- und Endpunkt erfolgt die Verbindung direkt. Liegt der Startpunkt tiefer, wird zunächst auf die Höhe des Endpunkts angehoben und dann direkt verbunden. Liegt der Endpunkt tiefer, erfolgt zunächst die Bewegung auf der Starthöhe über den Endpunkt und anschließend das Absenken.

Unter **Movements protection mode** wird der Bewegungsmodus gewählt:

- **Rapid.** Eilgang.
- **Non protected.** Vorschub für lange Verbindungen.
- **Protected.** Vorschub für kurze Verbindungen.

<a id="cycle-format"></a>

## Zyklusformat

Auf der Registerkarte **Strategy** wird die Ausgabe der Zyklen in CLData eingestellt.

![images/download/attachments/157866880/image2024-7-18_17-7-46.png](assets/images/download/attachments/157866880/image2024-7-18_17-7-46.png)

**Cycle format** bietet zwei Möglichkeiten:

- **Without internal movements (EXTCYCLE only).** Ausgabe des Zyklus über einen separaten **EXTCYCLE**-Befehl mit Unterprogrammaufruf (**callsub**). ![Ausgabe als EXTCYCLE](assets/images/download/attachments/157866880/image2022-4-1_9-44-16.png)
- **With internal movements.** Ausgabe der Zyklusbewegungen ohne separaten **EXTCYCLE**-Befehl. ![Ausgabe einzelner Bewegungen](assets/images/download/attachments/157866880/image2022-4-1_9-44-51.png)

<a id="tool-probing"></a>

## Werkzeug messen

Die Parameter und Verbindungen der Werkzeugmesszyklen werden wie bei der Werkstückmessung eingestellt.

Ein Messtaster kann als Werkzeug oder als fest an einem bestimmten Platz auf dem Maschinentisch montierte Vorrichtung ausgeführt sein. An einem stationären Taster wird das Werkzeug beispielsweise zur Erstvermessung oder Bruchkontrolle gemessen.

Fügen Sie für diesen Ablauf eine Gruppe **Part** hinzu.

![images/download/attachments/157866880/image2024-7-18_17-9-47.png](assets/images/download/attachments/157866880/image2024-7-18_17-9-47.png)

Erstellen Sie innerhalb dieser Gruppe für jedes Werkzeug eine separate Messoperation.

![images/download/attachments/157866880/image2024-7-18_17-10-49.png](assets/images/download/attachments/157866880/image2024-7-18_17-10-49.png)

Legen Sie auf der Registerkarte **Setup** die **Part number** fest. Diese Nummer kann als Taster-ID verwendet werden.

![images/download/attachments/157866880/image2024-7-18_17-11-12.png](assets/images/download/attachments/157866880/image2024-7-18_17-11-12.png)

Ein Beispiel enthält das mitgelieferte Projekt **Tool probing** im Ordner **Probing**.
