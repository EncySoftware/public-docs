# Postprozessoren aus externen Systemen laden und dort speichern

Öffnen Sie das Fenster **NC-program generation**.

![images/download/attachments/157867844/16.png](assets/images/download/attachments/157867844/16.png)

Die Schaltfläche **PLM** öffnet folgende Befehle:

- **Load postprocessor from PLM** – Postprozessor laden;
- **Load postprocessor from machine in PLM** – einer Maschine zugeordneten Postprozessor laden;
- **Save postprocessor to PLM** – Postprozessor speichern;
- **Save postprocessor to machine in PLM** – Postprozessor einer Maschine zuordnen;
- **Save postprocessor with source files to PLM** – einschließlich Quelldateien speichern.

Eine zusätzliche Verbindungsauswahl erscheint nur, wenn mehrere PLM-Verbindungen eingerichtet sind.

![images/download/attachments/157867844/17.png](assets/images/download/attachments/157867844/17.png)

<a id="loading-a-postprocessor-from-an-external-system"></a>

## Postprozessor laden

Wählen Sie **PLM → Load postprocessor from PLM** und die Verbindung.

![images/download/attachments/157867844/18.png](assets/images/download/attachments/157867844/18.png)

Suchen Sie den Postprozessor im Objektbaum oder über seinen Namen und klicken Sie auf **Open**. Er erscheint unter **Recent postprocessors** mit einer Bezeichnung, die seine Herkunft kennzeichnet.

![images/download/attachments/157867844/19.png](assets/images/download/attachments/157867844/19.png)

Zum Laden des Postprozessors einer Maschine verwenden Sie **Load postprocessor from machine in PLM**, wählen die Maschine und bestätigen mit **Open**.

<a id="saving-a-postprocessor-to-an-external-system"></a>

## Postprozessor speichern

Wählen Sie den Postprozessor und anschließend **PLM → Save postprocessor to PLM** sowie die Verbindung.

![images/download/attachments/157867844/20.png](assets/images/download/attachments/157867844/20.png)

Wählen Sie den Zielort im Objektbaum. Zum Überschreiben aktivieren Sie **Overwrite item** und klicken auf **Save**.

**Save postprocessor with source files to PLM** speichert die kompilierte Datei und ein Archiv ihrer Quellen. Die Option ist nur für *.dll-Postprozessoren mit zugehörigen Quelldateien verfügbar.

Zum Zuordnen zu einer Maschine verwenden Sie **Save postprocessor to machine in PLM** und wählen die Verbindung.

Wählen Sie anschließend den Zielort, gegebenenfalls **Overwrite item**, und bestätigen Sie mit **Save**.

Ist im externen System eine neuere Version verfügbar, erscheint beim Starten des geladenen Postprozessors ein Hinweis.

- **Yes** lädt und verwendet die neue Version.
- **Cancel** verwendet die bereits geladene Version weiter.
