# Carregamento e salvamento de pós-processadores em um sistema externo

Para gerenciar pós-processadores em um sistema externo, abra a janela **NC-program generation**.

![images/download/attachments/157867844/16.png](assets/images/download/attachments/157867844/16.png)

No painel superior da janela há um botão **PLM**. Clique nele para abrir o menu suspenso com as seguintes opções:

- **Load postprocessor from PLM**
- **Load postprocessor from machine in PLM**
- **Save postprocessor to PLM**
- **Save postprocessor to machine in PLM**
- **Save postprocessor with source files to PLM**

Cada opção apresenta um submenu para selecionar a conexão PLM *somente quando mais de uma conexão está configurada*.

![images/download/attachments/157867844/17.png](assets/images/download/attachments/157867844/17.png)

## Carregamento de um pós-processador de um sistema externo

Para carregar um pós-processador de um sistema externo, clique em **PLM** → **Load postprocessor from PLM** → *[connection name]*. Será aberta uma janela com a árvore de objetos disponíveis no sistema externo.

![images/download/attachments/157867844/18.png](assets/images/download/attachments/157867844/18.png)

Localize o pós-processador na árvore de objetos ou pela pesquisa por nome e clique em **Open**. O pós-processador selecionado será carregado e exibido na lista **Recent postprocessors**, com um nome que indica sua origem no sistema externo.

![images/download/attachments/157867844/19.png](assets/images/download/attachments/157867844/19.png)

Para carregar um pós-processador associado a uma máquina específica no sistema externo, clique em **PLM** → **Load postprocessor from machine in PLM** → *[connection name]*. Na janela aberta, localize a máquina que contém o pós-processador, selecione-o e clique em **Open** para carregá-lo no aplicativo.

## Salvamento de um pós-processador em um sistema externo

Para salvar uma máquina em um sistema externo, selecione o pós-processador que deseja salvar e clique em **PLM** → **Save postprocessor to PLM** → *[connection name]*.

![images/download/attachments/157867844/20.png](assets/images/download/attachments/157867844/20.png)

Será aberta uma janela com a árvore de objetos do sistema externo. Selecione o elemento de destino no qual o pós-processador deve ser salvo. Para substituir arquivos existentes, marque **Overwrite item** e clique em **Save**.

Para salvar o pós-processador compilado e seus arquivos de origem, selecione **PLM** → **Save postprocessor with source files to PLM** → *[connection name]*. Essa opção só está disponível quando o pós-processador tem a extensão **.dll** e arquivos de origem associados. Os arquivos de origem serão salvos como um arquivo compactado junto com o arquivo compilado.

Para associar um pós-processador a uma máquina específica, clique em **PLM** → **Save postprocessor to machine in PLM** → *[connection name]*.

Em seguida, siga as mesmas etapas do salvamento comum: selecione o local de destino, marque **Overwrite item** se necessário e clique em **Save**.

Se o pós-processador tiver sido atualizado no sistema externo desde o último carregamento, uma caixa de diálogo informativa será exibida ao tentar executá-lo. Ela informa que há uma versão mais recente. Escolha uma das ações:

- Clique em **Yes** para baixar e aplicar a versão atualizada do pós-processador.
- Clique em **Cancel** para continuar usando a versão carregada, sem atualizá-la.
