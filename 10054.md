# Onshape™ connector

**Onshape™** is a new generation of full-cloud CAD designed specifically for modern agile design teams. You can view the version of the supported CAD system. [Details](10039.md)

To use the **Onshape connector plugin**, it must first be enabled in the **Configure utilities** window.

![images/download/attachments/157859717/Onshape_connector_En.png](assets/images/download/attachments/157859717/Onshape_connector_En.png)

Once enabled, the plugin can be launched by clicking the **Onshape** icon on the toolbar.

![images/download/attachments/157859717/image2018-12-25_17-36-50.png](assets/images/download/attachments/157859717/image2018-12-25_17-36-50.png)

After signing into your Onshape account, the plugin will display a list of available models. Selecting a model from this list will initiate the import process. If the imported model is later updated in Onshape, the connector plugin will prompt you to reimport the model. The **Onshape connector plugin** maintains model [associativity](10057.md), ensuring updates are reflected in your workspace.
