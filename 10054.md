# Conector do Onshape™

O **Onshape™** é um CAD de nova geração, totalmente em nuvem, projetado especificamente para equipes de projeto modernas e ágeis. Consulte a versão suportada do sistema CAD. [Detalhes](10039.md)

Para utilizar o **Onshape connector plugin**, ative-o primeiro na janela **Configure utilities**.

![images/download/attachments/157859717/Onshape_connector_En.png](assets/images/download/attachments/157859717/Onshape_connector_En.png)

Após a ativação, clique no ícone **Onshape** da barra de ferramentas para iniciar o conector.

![images/download/attachments/157859717/image2018-12-25_17-36-50.png](assets/images/download/attachments/157859717/image2018-12-25_17-36-50.png)

Após a autenticação na conta do Onshape, o conector exibe a lista de modelos disponíveis. Selecione um modelo para iniciar a importação. Se o modelo for alterado posteriormente no Onshape, o conector solicitará uma nova importação. O **Onshape connector plugin** preserva a [associatividade](10057.md) do modelo, garantindo que as alterações sejam refletidas no seu ambiente de trabalho.
