# Importação de objetos de arquivos IGES

Os arquivos de troca de dados geométricos no formato **IGES** normalmente têm uma extensão *.igs ou *.iges. O formato **IGES** permite a transferência de uma infinidade de tipos diferentes de objetos geométricos. É por isso que é possível realizar a transferência de dados entre sistemas diferentes praticamente sem distorção. O formato **IGES** é amplamente utilizado, especialmente em áreas em que é necessária alta precisão na transmissão de dados devido a modelos geométricos tridimensionais muito complexos.

Há um módulo integrado para importar **IGES** no sistema CAM.
