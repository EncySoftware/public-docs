# Importieren von Objekten aus IGES-Dateien

Geometrische Austauschdateien im Format **IGES** haben üblicherweise die Endung *.igs oder *.iges. Das Format unterstützt zahlreiche Typen geometrischer Objekte und ermöglicht dadurch eine weitgehend unverfälschte Übertragung zwischen verschiedenen Systemen. Es wird insbesondere dort verwendet, wo komplexe dreidimensionale Modelle eine hohe Übertragungsgenauigkeit erfordern.

Das CAM-System besitzt ein integriertes Modul für den **IGES**-Import.
