# Importing objects from IGES files

Geometrical data exchange files in the **IGES** format normally have an *.igs or *.iges extension. **IGES** format allows the transfer of a multitude of different types of geometrical objects. This is why one can achieve data transfer between different systems with virtually no distortion. The **IGES** format is widely used, especially in areas where high data transmission accuracy is required due to very complex three-dimensional geometrical models.

There is build-in module for import **IGES** at CAM system.
