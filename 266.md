# Importazione di oggetti da file IGES

I file di scambio di dati geometrici nel formato **IGES** hanno normalmente l'estensione *.igs o *.iges. Il formato **IGES** consente il trasferimento di numerosi tipi diversi di oggetti geometrici. Per questo motivo è possibile trasferire dati tra sistemi diversi praticamente senza distorsioni. Il formato **IGES** è ampiamente utilizzato, in particolare nei settori in cui è richiesta un'elevata precisione nella trasmissione dei dati a causa di modelli geometrici tridimensionali molto complessi.

Il sistema CAM dispone di un modulo integrato per l'importazione di file **IGES**.
