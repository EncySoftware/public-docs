# Machine axes control panel

The <strong>Machine Axes Control</strong> window allows you to monitor and modify the current values for all machine/robot coordinates. To display this window, click the ![images/download/thumbnails/157858667/MachineControlPanel_En.png](assets/images/download/thumbnails/157858667/MachineControlPanel_En.png) corresponding button on the main toolbar. It is helpful when analyzing toolpaths in simulation mode, constructing manual approaches, or determining the initial machine position to calculate the technological operation.

![images/download/attachments/157858667/image2024-7-1_16-55-42.png](assets/images/download/attachments/157858667/image2024-7-1_16-55-42.png)

Visually, the window is divided into several areas. The number of panels and their content may vary depending on the particular machine configuration. The toolbar at the top or left side controls the visibility of these panels.

- ![images/download/thumbnails/157858667/image2024-7-1_16-57-16.png](assets/images/download/thumbnails/157858667/image2024-7-1_16-57-16.png) <strong>Switch layout: vertical/horizontal:</strong> toggles the layout of panels between vertical and horizontal.

- ![images/download/thumbnails/157858667/image2024-7-1_16-58-28.png](assets/images/download/thumbnails/157858667/image2024-7-1_16-58-28.png) <strong>Physical axes panel visibility:</strong> shows/hides the panel with the list of physical machine axes.

- ![images/download/thumbnails/157858667/image2024-7-1_16-59-12.png](assets/images/download/thumbnails/157858667/image2024-7-1_16-59-12.png) <strong>Channel panel visibility:</strong> shows/hides the panel with information about the machine's control channels. There may be several such buttons, depending on the number of channels a machine has. The icon color indicates the unique color associated with each channel. All related information will be displayed in this color when referring to that channel.

- ![images/download/thumbnails/157858667/image2024-7-1_16-59-51.png](assets/images/download/thumbnails/157858667/image2024-7-1_16-59-51.png) <strong>States panel visibility:</strong> shows/hides the panel that displays a list of stored machine states.

The <strong>Channel panel</strong> displays the following values:

- Color, index, and name of the channel
- Active tool number and name of the channel
- Active WCS number combo, where you can select additional coordinate systems to display tool coordinates
- Tool coordinates and orientation angles, shown as vectors or quaternions in the specified spatial CS. The type of orientation angles can vary depending on the machine schema settings.
- Current feed value and measurement units (type of feed, e.g., mm/min, mm/rev or "max" for rapid feed).
- Current spindle name, speed, rotation direction (M3, M4, M5), and rotation mode (e.g., rev/min for RPM or m/min for CSS)

The <strong>Physical axes panel</strong> displays information for each machine axis, including:

- Axis name
- Current physical value of the axis, which does not depend on the current WCS, but rather on how the axis is defined in the machine schema. This value may turn red if the axis is out of range.
- Minimum and maximum limits of the axis
- Axis brake status, if applicable:
  - ![images/download/thumbnails/157858667/image2023-8-16_12-2-49.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-2-49.png) Brake is off
  - ![images/download/thumbnails/157858667/image2023-8-16_12-3-32.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-3-32.png) Brake is on
- Quick modification buttons for the axis value, based on axis properties:
  - ![images/download/thumbnails/157858667/image2023-8-16_12-6-51.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-6-51.png) Returns the axis to its home position
  - ![images/download/thumbnails/157858667/image2023-8-16_12-8-55.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-8-55.png) Moves the axis to its minimum limit
  - ![images/download/thumbnails/157858667/image2023-8-16_12-9-51.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-9-51.png) Moves the axis to its maximum limit
  - ![images/download/thumbnails/157858667/image2023-8-16_12-10-58.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-10-58.png) Subtracts one period for a rotary periodic axis (if within limits)
  - ![images/download/thumbnails/157858667/image2023-8-16_12-10-37.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-10-37.png) Adds one period for a rotary periodic axis (if within limits)
  - ![images/download/thumbnails/157858667/image2023-8-16_12-13-3.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-13-3.png) Switches the machine axes to an alternative solution if the same tool-workpiece relative position can be achieved in multiple ways

![images/download/attachments/157858667/image2024-7-1_17-12-7.png](assets/images/download/attachments/157858667/image2024-7-1_17-12-7.png)

The State panel shows stored machine states and includes the following buttons:

- ![images/download/thumbnails/157858667/image2023-8-16_12-29-25.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-29-25.png) <strong>Add new state</strong>: Saves the current machine state to the list
- ![images/download/thumbnails/157858667/image2023-8-16_12-29-50.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-29-50.png) <strong>Delete selected state</strong>: Removes the selected state from the list
- ![images/download/thumbnails/157858667/image2023-8-16_12-30-17.png](assets/images/download/thumbnails/157858667/image2023-8-16_12-30-17.png) <strong>Delete all states</strong>: Clears the entire list of stored states

You can double-click on a state in the list to quickly switch the machine to that state. Using the **Remember state** feature is helpful when [constructing manual transitions](10267.md) on machines with complex axis configurations, such as 6-axis articulated robots.
