# Interfaccia della libreria delle procedure FBM

![images/download/attachments/157863263/image2024-7-25_16-40-56.png](assets/images/download/attachments/157863263/image2024-7-25_16-40-56.png)

La FBM Procedure Library (libreria delle procedure FBM) è l'archivio delle procedure di lavorazione. La libreria contiene quattro cartelle:

- System (sistema);
- All users (tutti gli utenti);
- Personal (personale);
- History (cronologia).

La cartella System è di sola lettura: viene fornita insieme all'installazione del sistema CAM e mette a disposizione le procedure complete e atomiche di uso più universale.

La cartella All Users contiene le procedure accessibili a tutti gli utenti del PC.

La cartella Personal è destinata alle procedure personali dell'utente.

La cartella History contiene le procedure salvate automaticamente con ogni progetto. Durante il lavoro con il sistema CAM FBM Mill, l'utente crea dinamicamente nuove procedure direttamente nell'interfaccia, semplicemente modificando i parametri delle procedure esistenti e inserendovi o rimuovendone operazioni. Quando l'utente salva il progetto, tutte le procedure nuove e modificate vengono salvate automaticamente nella cartella History per un eventuale riutilizzo futuro. Questa funzione consente all'utente di ampliare senza sforzo la propria base di conoscenze di lavorazione.

Apertura della libreria

Per aprire la libreria, premere il pulsante Procedures library sulla barra degli strumenti Features.

![images/download/attachments/157863263/image2024-7-25_16-29-50.png](assets/images/download/attachments/157863263/image2024-7-25_16-29-50.png)

Filtraggio delle procedure

![images/download/attachments/157863263/image2024-7-25_16-41-50.png](assets/images/download/attachments/157863263/image2024-7-25_16-41-50.png)

Utilizzare l'elenco a discesa Libraries per passare da una libreria all'altra.

Utilizzare il selettore Feature Type per filtrare le procedure in base al tipo di feature

Digitare il testo nella casella Search per filtrare le procedure per nome.

Creazione, eliminazione e copia delle procedure

![images/download/attachments/157863263/image2024-7-25_16-42-9.png](assets/images/download/attachments/157863263/image2024-7-25_16-42-9.png)

- Per creare una nuova procedura, premere il pulsante New.
- Per eliminare una procedura, selezionarla e premere il pulsante Delete.
- Per copiare una procedura, premere il pulsante Copy, quindi premere il pulsante Paste.

Modifica di una procedura

La modifica di una procedura viene eseguita nell'Inspector (ispettore). L'ispettore si comporta però in modo leggermente insolito: la consueta espansione/compressione dei nodi funziona qui in modo diverso:

- quando il nodo è espanso, vengono visualizzati tutti i nodi interni. Nulla di nuovo in questo caso.
- quando invece il nodo è compresso, i nodi interni con valori sovrascritti restano comunque visibili.

Per impostazione predefinita tutti i nodi sono compressi, quindi sono visibili solo i parametri sovrascritti. Ciò è logico, poiché sono proprio i parametri sovrascritti a definire la procedura.

- Per modificare un parametro, espandere il nodo corrispondente nell'ispettore, immettere il valore e quindi comprimere il nodo.
- Per ripristinare il valore predefinito del parametro, è sufficiente cancellarne il valore selezionando tutto e premendo il tasto Backspace o Canc sulla tastiera, quindi premere Invio

I campi dei valori dei parametri con valori predefiniti sono di colore grigio.

I parametri con valori non validi sono contrassegnati in rosso.

Modifica della libreria di una procedura

È possibile cambiare la libreria della procedura selezionandola dall'elenco a discesa Library nell'ispettore.

Modifica del tipo di una procedura

Per passare dal tipo di procedura atomica a quello completa e viceversa, selezionare/deselezionare la casella Complete machining nell'ispettore.

Modifica dei vincoli della feature

1. Selezionare il Feature Type (tipo di feature).
2. Espandere il Feature Type
3. Specificare i vincoli per i parametri della feature. Il valore predefinito di un vincolo è Any. Significa che il parametro non è soggetto ad alcun vincolo.

Modifica delle query degli utensili

- Per modificare il numero di utensili nell'elenco Tool query, immettere il valore nel campo Tools e premere Invio.
- Per fare riferimento a un parametro della feature nella query dell'utensile, è sufficiente digitare #. Dovrebbe comparire il pannello di completamento dei parametri. Selezionare il parametro desiderato con il mouse oppure con i tasti Freccia su/Freccia giù.

![images/download/attachments/157863263/image2024-7-25_16-53-10.png](assets/images/download/attachments/157863263/image2024-7-25_16-53-10.png)

Modifica delle operazioni

- Per modificare il numero di operazioni nell'elenco, è sufficiente immettere il valore nel campo Operations e premere Invio.
- Per ogni operazione occorre impostare Tool Number (numero utensile), Cycle type (tipo di ciclo) e Cycle parameters (parametri del ciclo). Il numero utensile predefinito dell'operazione coincide con il suo numero d'ordine.

Applicazione/annullamento delle modifiche

Le procedure modificate sono contrassegnate in grassetto nell'elenco.

- Per applicare le modifiche, premere il pulsante Apply in basso.
- Per applicare le modifiche e chiudere la FBM Procedure Library, fare clic su Ok in basso.
- Per annullare le modifiche e chiudere la FBM Procedure Library, fare clic su Cancel in basso.
