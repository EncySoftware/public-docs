# Interface de edição de procedimentos

![images/download/attachments/157863301/FBMp0014.png](assets/images/download/attachments/157863301/FBMp0014.png)

A edição dos procedimentos de usinagem é feita nesse pequeno painel que você pode ver acima.

<strong>O seletor de procedimento de usinagem</strong>

Na parte superior do painel, há o seletor de procedimento de usinagem (Hole for a bolt na imagem). É uma caixa de combinação. Com ela, é possível selecionar rapidamente outro procedimento para o recurso. No campo de edição interno dessa caixa de combinação, também é possível alterar o nome do procedimento atual.

![images/download/attachments/157863301/FBMp0015.png](assets/images/download/attachments/157863301/FBMp0015.png) ![images/download/attachments/157863301/FBMp0016.png](assets/images/download/attachments/157863301/FBMp0016.png)

<strong>O botão Edit in the Library</strong>

À direita do seletor de procedimentos, há o botão Edit in the Library. Clicar nele salva a sequência de usinagem atual na Biblioteca de procedimentos e abre a Biblioteca com o procedimento selecionado.

![images/download/attachments/157863301/FBMp0017.png](assets/images/download/attachments/157863301/FBMp0017.png)

<strong>A lista de operações</strong>

Abaixo do cabeçalho, há uma lista das operações que constituem a sequência de usinagem.

![images/download/attachments/157863301/FBMp0018.png](assets/images/download/attachments/157863301/FBMp0018.png)

Cada entrada na lista consiste nos seguintes campos.

1. O número de sequência. Você pode arrastar e soltar operações por esse número.
2. O ícone.
3. O prefixo do sub-recurso (presente somente se uma operação usinar um sub-recurso dentro de um recurso composto).
4. O nome da operação. É um campo de edição; o nome da operação pode ser alterado a qualquer momento.
5. O seletor de número de ferramenta. Esta é uma caixa de combinação. Com ela, você seleciona a ferramenta da Lista de ferramentas usadas para a operação da sequência de usinagem. Somente as ferramentas aplicáveis que satisfazem a consulta de ferramentas estão disponíveis para seleção. A mesma ferramenta pode ser usada em várias operações. Nesse caso, o número de operações em que a ferramenta é usada é exibido entre parênteses.

![images/download/attachments/157863301/FBMp0019.png](assets/images/download/attachments/157863301/FBMp0019.png)

Para adicionar uma nova ferramenta à Lista de ferramentas usadas, selecione o comando Create new tool.

6. O seletor de ferramenta. Nessa caixa de combinação, você altera a ferramenta selecionada no campo anterior. Se a ferramenta for usada em várias operações, todas elas serão afetadas.

![images/download/attachments/157863301/FBMp0020.png](assets/images/download/attachments/157863301/FBMp0020.png)

7. O botão Delete.

<strong>O menu Add Operation…</strong>

Abaixo da lista de operações, há o menu Add Operation….

![images/download/attachments/157863301/FBMp0021.png](assets/images/download/attachments/157863301/FBMp0021.png)

Nesse menu, você pode adicionar uma nova operação à sequência de usinagem. Apenas as operações aplicáveis são sugeridas nesse menu. As operações com ferramentas ausentes são colocadas em um submenu separado. Se o recurso tiver sub-recursos, as operações para os sub-recursos também estarão disponíveis em submenus separados.

<strong>O inspetor de parâmetros de operação</strong>

Os parâmetros da operação selecionada são exibidos no inspetor, prontos para edição. O primeiro parâmetro é o tipo de ciclo. Você pode selecionar o tipo de ciclo na lista de ciclos disponíveis para o recurso selecionado. O restante dos parâmetros são os parâmetros do ciclo.

![images/download/attachments/157863301/FBMp0022.png](assets/images/download/attachments/157863301/FBMp0022.png)

<strong>Uso da interface de edição de procedimentos para criar novos procedimentos FBM</strong>

A interface de edição de procedimentos é uma maneira muito simples e eficiente de adicionar novos procedimentos de usinagem à biblioteca. Basta selecionar um recurso, selecionar uma sequência de usinagem aplicável ou criar uma nova para ele, editar o processo de usinagem, clicar no botão Edit in the Library e fazer alguns ajustes no procedimento já na biblioteca: o novo procedimento está pronto.

Com o recurso History, o processo de expansão da sua base de conhecimento de usinagem fica ainda mais simples. Quando você salva um projeto com operações do grupo FBM Mill, todas as sequências de usinagem do projeto são salvas automaticamente na biblioteca, na pasta History.
