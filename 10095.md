# Bearbeitungsverfahren bearbeiten

![images/download/attachments/157863301/FBMp0014.png](assets/images/download/attachments/157863301/FBMp0014.png)

Das gezeigte Panel dient zum Bearbeiten von Verfahrensfolgen.

**Verfahrensauswahl**

Oben wählen Sie ein anderes Verfahren für das Merkmal. Das Eingabefeld der Liste kann auch zum Umbenennen des aktuellen Verfahrens verwendet werden.

![images/download/attachments/157863301/FBMp0015.png](assets/images/download/attachments/157863301/FBMp0015.png) ![images/download/attachments/157863301/FBMp0016.png](assets/images/download/attachments/157863301/FBMp0016.png)

**In der Bibliothek bearbeiten**

Die Schaltfläche rechts speichert die aktuelle Folge in der Verfahrensbibliothek und öffnet diese mit dem ausgewählten Verfahren.

![images/download/attachments/157863301/FBMp0017.png](assets/images/download/attachments/157863301/FBMp0017.png)

**Operationsliste**

Unterhalb der Kopfzeile stehen die Operationen der Folge.

![images/download/attachments/157863301/FBMp0018.png](assets/images/download/attachments/157863301/FBMp0018.png)

Jeder Eintrag enthält:

1. Laufende Nummer; sie dient auch als Anfasser zum Umordnen.
2. Symbol.
3. Untermerkmalpräfix bei zusammengesetzten Merkmalen.
4. Bearbeitbarer Operationsname.
5. Werkzeugnummernauswahl. Sie enthält nur Werkzeuge, die der Abfrage entsprechen. Wird ein Werkzeug mehrfach verwendet, steht die Anzahl der zugeordneten Operationen in Klammern.

![images/download/attachments/157863301/FBMp0019.png](assets/images/download/attachments/157863301/FBMp0019.png)

Mit **Create new tool** ergänzen Sie die Liste der verwendeten Werkzeuge.

6. Werkzeugauswahl: Ändert das unter der gewählten Nummer verwendete Werkzeug. Bei gemeinsamer Verwendung wirkt sich dies auf alle zugehörigen Operationen aus.

![images/download/attachments/157863301/FBMp0020.png](assets/images/download/attachments/157863301/FBMp0020.png)

7. Löschschaltfläche.

**Menü Add operation...**

Unterhalb der Liste befindet sich das Menü zum Hinzufügen von Operationen.

![images/download/attachments/157863301/FBMp0021.png](assets/images/download/attachments/157863301/FBMp0021.png)

Es bietet nur geeignete Operationen an. Einträge mit fehlenden Werkzeugen stehen in einem eigenen Untermenü. Bei zusammengesetzten Merkmalen gibt es auch Untermenüs für die einzelnen Untermerkmale.

**Operationsinspektor**

Der Inspektor zeigt die Parameter der ausgewählten Operation. Zuerst wird der Zyklustyp aus der Liste der für das Merkmal verfügbaren Zyklen gewählt; danach folgen dessen Parameter.

![images/download/attachments/157863301/FBMp0022.png](assets/images/download/attachments/157863301/FBMp0022.png)

**Neue FBM-Verfahren erstellen**

Wählen Sie ein Merkmal und eine vorhandene Bearbeitungsfolge oder erstellen Sie eine neue. Bearbeiten Sie die Folge, klicken Sie auf **Edit in library** und ergänzen Sie die Verfahrenseinstellungen in der Bibliothek.

Beim Speichern eines Projekts mit FBM-Mill-Gruppen werden dessen Bearbeitungsfolgen automatisch im Bibliotheksordner **History** abgelegt.
