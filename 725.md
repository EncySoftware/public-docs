# Registerkarte Allgemein

![images/download/attachments/157859768/image2024-7-3_9-23-56.png](assets/images/download/attachments/157859768/image2024-7-3_9-23-56.png)

Auf der Registerkarte für allgemeine Eigenschaften kann der Name eines ausgewählten Objekts geändert werden. Außerdem werden die minimalen und maximalen Koordinaten der ausgewählten Objekte entlang jeder Achse angezeigt.

**Object Name (Objektname).** Name des ausgewählten Objekts. Bei mehreren ausgewählten Objekten bleibt das Feld leer.

**Object dimensions (Objektabmessungen).** Gesamtabmessungen des ausgewählten Objekts.
