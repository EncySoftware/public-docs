# Estender superfície

![images/download/attachments/157860076/image2025-2-26_15-13-8.png](assets/images/download/attachments/157860076/image2025-2-26_15-13-8.png) ![images/download/attachments/157860076/image2025-2-26_15-13-23.png](assets/images/download/attachments/157860076/image2025-2-26_15-13-23.png)

## Área de aplicação:

A ferramenta permite estender as superfícies originais e prolongar as arestas ao longo das quais as superfícies são completadas. Ela está disponível no modo de modelo, no painel superior. Selecione as arestas das superfícies que deseja estender.

<strong>Extension distance.</strong> Valor até o qual a superfície deve ser estendida.

![images/download/attachments/157860076/Extension_distance.png](assets/images/download/attachments/157860076/Extension_distance.png)

<strong>Extension type.</strong> Método de extensão.

<strong>Equidistant to edges.</strong> As superfícies originais são estendidas. Como algumas superfícies são torcidas, a extensão pode ser impossível.

![images/download/attachments/157860076/Mode_%28by_edges%29.png](assets/images/download/attachments/157860076/Mode_(by_edges).png)

<strong>Interpolation of tangent edges.</strong> Primeiro, as arestas são estendidas; depois, a superfície é completada ao longo delas.

![images/download/attachments/157860076/Mode_%28by_faces%29.png](assets/images/download/attachments/157860076/Mode_(by_faces).png)

<strong>Surface UV Box.</strong> Permite criar o espaço UV da superfície. Essa superfície possui elementos interativos para alterar sua área. É necessário selecionar uma superfície.

Opções não disponíveis: <strong>Alternate from side, With source face.</strong>

![images/download/attachments/157860076/Surface_UV_Box.png](assets/images/download/attachments/157860076/Surface_UV_Box.png)

<strong>Alternate front side.</strong> Seleciona o lado da aresta a partir do qual a superfície será estendida.

![images/download/attachments/157860076/Alternate_front_side_%28off%29.png](assets/images/download/attachments/157860076/Alternate_front_side_(off).png) ![images/download/attachments/157860076/Alternate_front_side_%28on%29.png](assets/images/download/attachments/157860076/Alternate_front_side_(on).png)

<strong>With source face.</strong> A superfície estendida forma uma única superfície com uma cópia da superfície original.

![images/download/attachments/157860076/With_source_faces_%28off%29.png](assets/images/download/attachments/157860076/With_source_faces_(off).png) ![images/download/attachments/157860076/With_source_faces_%28on%29.png](assets/images/download/attachments/157860076/With_source_faces_(on).png)

<strong>Hole capping.</strong> Fecha, na superfície original, os furos cujo raio seja inferior ao valor especificado.

![images/download/attachments/157860076/With_source_faces_%28on%29.png](assets/images/download/attachments/157860076/With_source_faces_(on).png) ![images/download/attachments/157860076/Hole_capping.png](assets/images/download/attachments/157860076/Hole_capping.png)
