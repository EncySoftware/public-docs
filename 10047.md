# NX™: Symbolleiste und Import-Add-in

![images/download/attachments/157859635/image2018-12-21_18-15-55.png](assets/images/download/attachments/157859635/image2018-12-21_18-15-55.png)

Mit der Symbolleiste können Sie geometrische Daten aus <strong>NX™</strong> exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859635/image2022-3-30_12-15-40.png](assets/images/download/attachments/157859635/image2022-3-30_12-15-40.png)

Mit dem Add-In können Sie <strong>NX™</strong>-Projektdateien importieren.

Unterstützte Dateierweiterungen: PRT. Damit diese Option funktioniert, muss die erforderliche Anwendung (NX™) auf Ihrem Computer installiert sein.
