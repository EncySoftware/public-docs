# Barra degli strumenti e add-in di importazione per NX™

![images/download/attachments/157859635/image2018-12-21_18-15-55.png](assets/images/download/attachments/157859635/image2018-12-21_18-15-55.png)

La barra degli strumenti consente di esportare dati geometrici da <strong>NX™</strong>. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859635/image2022-3-30_12-15-40.png](assets/images/download/attachments/157859635/image2022-3-30_12-15-40.png)

L'add-in consente di importare file di progetto <strong><strong>NX™</strong></strong>.

Estensioni di file supportate: PRT. Per il funzionamento di questa opzione, l'applicazione richiesta (NX™) deve essere installata sul computer.
