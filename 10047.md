# Barra de ferramentas e suplemento de importação do NX™

![images/download/attachments/157859635/image2018-12-21_18-15-55.png](assets/images/download/attachments/157859635/image2018-12-21_18-15-55.png)

A barra de ferramentas permite exportar dados geométricos do **NX™**. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859635/image2022-3-30_12-15-40.png](assets/images/download/attachments/157859635/image2022-3-30_12-15-40.png)

O suplemento permite importar arquivos de projeto do **NX™**.

Extensão suportada: PRT. O NX™ deve estar instalado no computador para que o recurso funcione.
