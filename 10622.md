# Instalação de extensões pela linha de comando

As extensões podem ser instaladas por um utilitário de linha de comando. Isso é conveniente para instalações em lote, quando é necessário repetir rapidamente o processo em vários computadores.

Para instalar extensões pela linha de comando, siga estas etapas:

- Localize o utilitário ExtensionManagerCLI.exe na pasta de instalação do sistema CAM.

Observação: o utilitário ExtensionManagerCLI.exe é usado para registrar e remover extensões do sistema CAM pela linha de comando.

- Abra a linha de comando na pasta de instalação do sistema CAM. A execução do utilitário sem parâmetros não faz nada: apenas exibe a ajuda sobre os argumentos de linha de comando válidos.

![images/download/attachments/157867885/image2025-11-18_15-52-23.png](assets/images/download/attachments/157867885/image2025-11-18_15-52-23.png)

- Execute o comando:

```text
ExtensionManagerCLI.exe register-library --path "ExtensionFolder\ExtensionSettings.json" --storage stAllUsers
```

Em vez de "ExtensionFolder\ExtensionSettings.json", especifique o caminho do arquivo JSON da extensão.

Em vez do parâmetro --path, também é possível especificar o caminho do arquivo dext da extensão.

Com o parâmetro --storage (valores possíveis: stAllUsers, stCurrentUser), é possível definir se a extensão ficará disponível para todos os usuários ou somente para o usuário atual.

Abaixo está um exemplo de execução do comando.

Observação: dependendo do tipo de extensão, as alterações podem ser aplicadas somente após reiniciar o sistema CAM.
