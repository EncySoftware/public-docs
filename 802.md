# Importação de objetos de arquivos DXF

O formato **DXF** é usado para transferir desenhos planos e imagens vetoriais. A transferência de modelos volumétricos é suportada, mas depende da versão usada. Esses arquivos têm a extensão *.dxf.

<em>Limitações: a seção **HEADER** deve estar presente no arquivo DXF. Um arquivo sem cabeçalho é considerado defeituoso.</em>

Atualmente, apenas objetos geométricos podem ser importados de arquivos DXF. A geometria dos objetos tem grande influência na tecnologia de usinagem; características como espessura e estilo dos objetos não são necessárias e, por isso, são ignoradas.

<em>Observação: a versão atual não importa texto (objeto **TEXT**). Para importar um texto, ele deve primeiro ser convertido em curvas.</em>

Tipos de objetos importáveis:

- **POINT**;
- **LINE**;
- **CIRCLE**;
- **ARC**;
- **POLYLINE**;
- **SPLINE**;
- **BLOCK**, **INSERT** – todos os tipos acima são importados sem blocos (explodidos).
