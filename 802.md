# Importazione di oggetti da file DXF

Il formato **DXF** viene utilizzato per la trasmissione di disegni piani e immagini vettoriali. Il trasferimento di modelli volumetrici è supportato, ma dipende dalla versione utilizzata. Questi file hanno l'estensione *.dxf.

<em>Limitazioni: la sezione **HEADER** deve essere presente nel file DXF. Un file senza intestazione è considerato difettoso.</em>

Attualmente dai file DXF possono essere importati solo oggetti geometrici. La geometria degli oggetti influisce in modo considerevole sulla tecnologia di lavorazione, mentre caratteristiche quali lo spessore e lo stile degli oggetti non sono necessarie e vengono quindi ignorate.

<em>Nota: la versione corrente non importa il testo (oggetto **TEXT**). Per poter importare il testo, esso deve prima essere convertito in curve.</em>

Tipi di oggetti importabili:

- **POINT**;
- **LINE**;
- **CIRCLE**;
- **ARC**;
- **POLYLINE**;
- **SPLINE**;
- **BLOCK**, **INSERT** – tutti i tipi sopra indicati verranno importati senza blocchi (esplosi).
