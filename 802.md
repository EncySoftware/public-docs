# Importieren von Objekten aus DXF-Dateien

Das Format **DXF** dient zur Übertragung ebener Zeichnungen und Vektorgrafiken. Die Übertragung räumlicher Modelle wird ebenfalls unterstützt, hängt jedoch von der verwendeten Formatversion ab. Die Dateien haben die Endung *.dxf.

*Einschränkung: Die DXF-Datei muss einen Abschnitt **HEADER** enthalten. Eine Datei ohne diesen Abschnitt wird als fehlerhaft eingestuft.*

Derzeit werden nur geometrische Objekte aus DXF-Dateien importiert. Für den Bearbeitungsprozess ist deren Geometrie maßgeblich. Darstellungsattribute wie Linienstärke und Stil werden daher ignoriert.

*Hinweis: Textobjekte vom Typ **TEXT** werden in der aktuellen Version nicht importiert. Wandeln Sie Text vor dem Import in Kurven um.*

Importierbare Objekttypen:

- **POINT**;
- **LINE**;
- **CIRCLE**;
- **ARC**;
- **POLYLINE**;
- **SPLINE**;
- **BLOCK**, **INSERT** – die enthaltenen Objekte der oben genannten Typen werden importiert; die Blöcke werden dabei aufgelöst.
