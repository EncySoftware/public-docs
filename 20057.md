# Exporting the sketch to CAM

The sketch inspector has four tabs: **Plane**, **Properties**, **Constraints** and **Export**. **Export** groups the objects transferred to CAM. Surfaces and space curves appear in **Space objects**.

## Export mode

**Automatic export.** All visible exportable objects are transferred to CAM after each edit.

**Deferred export.** Only the accepted state is transferred. Edits remain visible in the sketch but are not transferred until **Accept** is clicked. Switching to this mode accepts everything already being exported. A new object is not transferred until accepted.

## Export objects

Each object row has an **Export** checkbox, an **Accept** button (deferred mode only) and a status: **new**, **up to date** or **changed**. Hovering over a row highlights the object in the view.

Points, lines, arcs, circles, boxes, chamfers and roundings, profiles (including splines, spirals and function profiles), block inserts, surfaces and space curves are transferred. Annotations are not transferred. [Details](20048.md)

**Exportable.** The checkbox in the object's **Attributes** group corresponds to its checkbox on **Export**. A hidden object is excluded immediately, including in deferred mode.
