# Extensões do sistema CAM

As extensões são módulos auxiliares que podem ser desativados e que ampliam as funções do sistema CAM, permitindo executar ações não incluídas no módulo básico. Podem ser desenvolvidas pelos programadores do sistema ou pelos próprios usuários.

Uma extensão normalmente consiste em vários arquivos, com extensões como *.dll, *.json, *.exe e *.xml. O sistema CAM identifica a extensão por meio de um arquivo de descrição textual com a extensão *.json.

O conjunto completo de arquivos pode ser empacotado em um arquivo ZIP com a extensão *.dext.

Consulte a documentação oficial da API para obter informações sobre o desenvolvimento de extensões: [docs.encycam.com/CAMAPI/3/en/](https://docs.encycam.com/CAMAPI/3/en/).

Os exemplos de extensões estão disponíveis no repositório de exemplos de uso da API: [https://github.com/EncySoftware/cam-api-examples/tree/v3/main/docs](https://github.com/EncySoftware/cam-api-examples/tree/v3/main/docs).

Modelo de extensão do sistema CAM, com instruções para criar o projeto, compilar e publicar na loja: [https://github.com/EncySoftware/ency-extension-template](https://github.com/EncySoftware/ency-extension-template).

Ferramentas para desenvolvimento com IA, incluindo a criação e publicação de extensões com um assistente: [https://github.com/EncySoftware/ency-extension-mcp](https://github.com/EncySoftware/ency-extension-mcp).
