# Estensioni del sistema CAM

Le estensioni sono moduli software ausiliari e disattivabili che possono ampliare le funzionalità del sistema CAM ed eseguire azioni non incluse nel modulo CAM di base. Le estensioni possono essere sviluppate sia dai programmatori del sistema CAM sia dagli utenti stessi.

Le estensioni sono in genere costituite da diversi file, che possono avere estensioni come *.dll, *.json, *.exe, *.xml e altre. Il file principale tramite il quale il sistema CAM identifica un'estensione è un file di descrizione testuale con estensione *.json.

L'intero insieme dei file di un'estensione può essere raccolto in un archivio zip con estensione *.dext.

Ulteriori informazioni sullo sviluppo delle estensioni sono disponibili nella documentazione ufficiale dell'API per sviluppatori ([docs.encycam.com/CAMAPI/3/en/](https://docs.encycam.com/CAMAPI/3/en/)).

Esempi di estensioni sono disponibili nel relativo repository del codice sorgente con esempi di utilizzo dell'API ([https://github.com/EncySoftware/cam-api-examples/tree/v3/main/docs](https://github.com/EncySoftware/cam-api-examples/tree/v3/main/docs)).

Modello di estensione del sistema CAM: creazione del progetto, compilazione e pubblicazione nello Store - [https://github.com/EncySoftware/ency-extension-template](https://github.com/EncySoftware/ency-extension-template).

Strumenti di sviluppo basati sull'IA: creazione e pubblicazione di estensioni con un assistente IA - [https://github.com/EncySoftware/ency-extension-mcp](https://github.com/EncySoftware/ency-extension-mcp).
