# Scheda Import

In questa sezione è possibile impostare i parametri generali di [importazione](109.md).

![images/download/attachments/157859000/image2024-7-1_17-44-17.png](assets/images/download/attachments/157859000/image2024-7-1_17-44-17.png)

- Nel gruppo di oggetti <strong>Import types</strong> (tipi di importazione), l'utente può definire i [tipi di oggetti geometrici](283.md) che possono essere importati dai file CAD. Se la casella accanto a un tipo specifico non è selezionata, l'oggetto corrispondente verrà ignorato durante il processo di importazione.
- Se una curva deve essere trasformata durante l'importazione, verrà eseguita un'approssimazione utilizzando il valore specificato nel campo <strong>Curves approximation tolerance</strong> (tolleranza di approssimazione delle curve).
- L'opzione <strong>Scale</strong> (scala) serve a controllare l'aspetto degli oggetti importati.
- **Ghost script dll** serve per importare i [file PostScript](268.md).
