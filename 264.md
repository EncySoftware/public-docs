# Aba Importação

Nessa seção, é possível definir os parâmetros gerais de [importação](109.md).

![images/download/attachments/157859000/image2024-7-1_17-44-17.png](assets/images/download/attachments/157859000/image2024-7-1_17-44-17.png)

- No grupo de objetos **Import types**, o usuário pode definir os [tipos de objetos geométricos](283.md) que podem ser importados de arquivos CAD. Se a caixa ao lado de um tipo específico não estiver selecionada, o objeto correspondente será ignorado durante o processo de importação.
- Se uma curva precisar ser transformada durante a importação, a aproximação será realizada usando o valor especificado no campo **Curves approximation tolerance**.
- A opção **Scale** é usada para controlar a aparência dos objetos importados.
- **Ghost script dll** é usado para importar [arquivos PostScript](268.md).
