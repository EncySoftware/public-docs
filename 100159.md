# Benutzervorgaben im Inspektor

## Anwendungsbereich:

Diese Menübefehle speichern, entfernen und übernehmen Eigenschaftsvorgaben. Außerdem können Eigenschaftsnamen zur Verwendung an anderer Stelle kopiert werden.

**Save as User default (Als Benutzervorgabe speichern).** Erstellt eine Datei mit der Erweiterung **.usrdef** im Ordner `%userprofile%\Documents\ENCY NB\Version 3\Operations\Defaults`. Sie enthält die neuen Vorgabewerte für alle Parameter der aktuellen Inspektorzeile.

*Beispiel: Aktivieren Sie **Helical machining** in einer Operation **2D Contouring** und speichern Sie den Wert als Benutzervorgabe.*

**Forget user default (Benutzervorgabe entfernen).** Löscht die Vorgabewerte aller Parameter der aktuellen Inspektorzeile aus der .usrdef-Datei. Enthält diese danach keine Vorgaben mehr, wird die Datei entfernt. Die aktuellen Werte im Inspektor bleiben unverändert.

<details>
<summary>Weitere Informationen anzeigen</summary>

*Die zuvor gespeicherte Regel kann auf diese Weise wieder entfernt werden.*

<em>![Entfernen bestätigen](assets/images/download/thumbnails/157858426/image2026-5-25_15-30-59.png)</em>

*Die nächste Operation wird dann ohne diese Vorgabe erstellt.*

**Reset to User default (Auf Benutzervorgabe zurücksetzen).** Ersetzt den aktuellen Eigenschaftswert durch den gespeicherten Benutzerwert.

<details>
<summary>Weitere Informationen anzeigen</summary>

*Mit diesem Befehl kann eine gespeicherte Vorgabe auf eine bereits vorhandene Operation angewendet werden. Die Änderung betrifft nur den ausgewählten Parameter.*

<em>![Benutzervorgabe anwenden](assets/images/download/attachments/157858426/image2026-5-25_15-39-43.png)</em>

<em>![Angewendeter Vorgabewert](assets/images/download/attachments/157858426/image2026-5-25_15-40-50.png)</em>

**Reset to System default (Auf Systemvorgabe zurücksetzen).** Ersetzt den aktuellen Eigenschaftswert durch den ursprünglichen Systemvorgabewert.

<details>
<summary>Weitere Informationen anzeigen</summary>

*Mit diesem Befehl wird der ausgewählte Parameter einer vorhandenen Operation auf die Systemvorgabe zurückgesetzt. Andere Parameter bleiben unverändert.*

![images/download/attachments/157858426/image2026-5-25_16-8-1.png](assets/images/download/attachments/157858426/image2026-5-25_16-8-1.png)

![images/download/attachments/157858426/image2026-5-25_16-8-40.png](assets/images/download/attachments/157858426/image2026-5-25_16-8-40.png)

**Copy property name (Eigenschaftsname kopieren).** Kopiert den eindeutigen Eigenschaftsnamen in die Zwischenablage. Er kann in Ausdrücken anderer Eigenschaften, in Postprozessoren und beim API-Zugriff aus Erweiterungen verwendet werden. Enthält eine Zeile mehrere Eigenschaften, werden ihre Namen durch Kommas getrennt kopiert.

**Edit defaults (Vorgaben bearbeiten).** Öffnet den Dialog zum Anzeigen und Bearbeiten des Ausdrucks für die ausgewählte Eigenschaft.

<details>
<summary>Weitere Informationen anzeigen</summary>

![images/download/attachments/157858426/image2026-6-8_11-15-16.png](assets/images/download/attachments/157858426/image2026-6-8_11-15-16.png)

**Set Values (Werte zuweisen).** Übernimmt die bearbeiteten Werte in die aktuellen Eigenschaften und schließt das Fenster. **Reopen Customize** kann es anschließend erneut öffnen.

**Save Defaults (Vorgaben speichern).** Speichert die zugewiesenen Werte zusätzlich als neue Vorgaben gemäß **New default**, damit sie auch künftig verwendet werden.

**Reopen Customize (Anpassungsdialog erneut öffnen).** Öffnet den Dialog nach der Wertzuweisung erneut, sodass die Bearbeitung fortgesetzt werden kann.

**Save All (Alle speichern).** Speichert die aktuellen Werte aller Eigenschaften als Vorgaben.

**Revert All (Änderungen verwerfen).** Verwirft ungespeicherte Änderungen und stellt den zuletzt gespeicherten Stand wieder her.

**Reset All (Alle zurücksetzen).** Setzt alle Eigenschaften auf die Systemvorgaben zurück.

**OK.** Übernimmt die Änderungen und schließt den Dialog.

**Cancel (Abbrechen).** Schließt den Dialog ohne Übernahme der Änderungen.

</details>

Einstellungen im Format **.usrdef** können ähnlich wie Benutzeroperationsdateien exportiert und importiert werden. Die Funktionen stehen im Dialog zum Erstellen einer neuen Operation im Modus **Customize** zur Verfügung. [Details](91.md)
