## Ambito di applicazione:

Queste voci di menu consentono di salvare, ripristinare o personalizzare le impostazioni delle proprietà e di copiare i nomi delle proprietà per utilizzarli altrove.

<strong>Save as User default</strong> (salva come valore predefinito utente) - Nella cartella (%userprofile%\Documents\ENCY NB\Version 3\Operations\Defaults) viene creato un file separato con estensione *.usrdef. Questo file contiene i nuovi valori predefiniti per tutti i parametri visualizzati nella riga dell'inspector.

<details>
<summary>Fare clic qui per espandere..</summary>

<em>Ad esempio, se si imposta <strong>Helical machining</strong> su <strong>true</strong> in un'operazione <strong>2D Contouring.</strong></em>

![images/download/attachments/157858426/image2026-5-25_15-23-21.png](assets/images/download/attachments/157858426/image2026-5-25_15-23-21.png)

![images/download/thumbnails/157858426/image2026-5-25_15-24-38.png](assets/images/download/thumbnails/157858426/image2026-5-25_15-24-38.png)

<em>La successiva operazione <strong>2D contouring</strong> avrà già <strong>Helical machining</strong> impostato su <strong>true.</strong></em>

![images/download/attachments/157858426/image2026-5-25_15-26-0.png](assets/images/download/attachments/157858426/image2026-5-25_15-26-0.png)

</details>

<strong>Forget user default</strong> (elimina valore predefinito utente) — elimina il valore predefinito utente. Il valore di tutti i parametri della riga corrente dell'inspector viene rimosso dal file *.usrdef. Se nel file non rimane alcun valore predefinito, l'intero file viene eliminato. Il valore corrente nell'inspector rimane invariato.

<details>
<summary>Fare clic qui per espandere..</summary>

<em>Ad esempio, è anche possibile scegliere di eliminare questa regola.</em>

<em>![images/download/attachments/157858426/image2026-5-25_15-30-37.png](assets/images/download/attachments/157858426/image2026-5-25_15-30-37.png)</em>

<em>In questo caso, la successiva operazione verrà creata senza applicare questa impostazione.</em>

<strong>Reset to User default</strong> (ripristina al valore predefinito utente) — ripristina il valore predefinito utente. Il valore corrente della proprietà viene sostituito con il valore salvato nelle impostazioni predefinite utente.

<details>
<summary>Fare clic qui per espandere..</summary>

<em>Ad esempio, per applicare le proprie regole personalizzate a un'operazione esistente, utilizzare <strong>Reset to User default</strong> — l'operazione adotterà i valori predefiniti salvati. <strong>Importante: ciò vale solo per un singolo parametro specifico.</strong></em>

<em>![images/download/attachments/157858426/image2026-5-25_15-39-43.png](assets/images/download/attachments/157858426/image2026-5-25_15-39-43.png)</em>

</details>

<strong>Reset to System default</strong> (ripristina al valore predefinito di sistema) — ripristina il valore predefinito di sistema. Il valore corrente della proprietà viene sostituito con il valore salvato nelle impostazioni predefinite di sistema.

<details>
<summary>Fare clic qui per espandere..</summary>

<em>Ad esempio, per ripristinare le impostazioni predefinite di sistema di un'operazione esistente, utilizzare <strong>Reset to System default</strong> — il parametro dell'operazione verrà riportato ai valori originali di fabbrica. <strong>Importante: ciò vale solo per un singolo parametro specifico.</strong></em>

![images/download/attachments/157858426/image2026-5-25_16-8-1.png](assets/images/download/attachments/157858426/image2026-5-25_16-8-1.png)

![images/download/attachments/157858426/image2026-5-25_16-8-40.png](assets/images/download/attachments/157858426/image2026-5-25_16-8-40.png)

</details>

<strong>Copy property name</strong> (copia nome proprietà) — copia il nome della proprietà. Il nome univoco della proprietà viene copiato negli appunti. È possibile utilizzare questo nome per fare riferimento alla proprietà nelle espressioni di altre proprietà, nei postprocessori e nelle estensioni tramite l'API. Se nella riga sono visualizzate più proprietà, i loro nomi vengono copiati separati da virgole.

<strong>Edit defaults</strong> (modifica valori predefiniti). Si apre una finestra in cui è possibile visualizzare e modificare l'espressione della proprietà selezionata.

<details>
<summary>Fare clic qui per espandere..</summary>

![images/download/attachments/157858426/image2026-6-8_11-15-16.png](assets/images/download/attachments/157858426/image2026-6-8_11-15-16.png)

<strong>Set Values.</strong> Se abilitata, i valori assegnati vengono scritti anche come nuovo valore predefinito (il campo "New default" sopra), in modo da rimanere disponibili per usi futuri — non solo per questa istanza.

<strong>Save Defaults.</strong> Se abilitata, i valori assegnati vengono scritti anche come nuovo valore predefinito (il campo "New default" sopra), in modo da rimanere disponibili per usi futuri — non solo per questa istanza.

<strong>Reopen Customize.</strong> Se abilitata, dopo l'impostazione dei valori la finestra Customize viene riaperta invece di rimanere chiusa, in modo da poter continuare la modifica.

<strong>Save All.</strong> Salva i valori correnti di tutte le proprietà come valori predefiniti.

<strong>Revert All.</strong> Annulla le modifiche non salvate e ripristina tutte le proprietà agli ultimi valori salvati.

<strong>Reset All.</strong> Ripristina tutte le proprietà ai valori predefiniti di sistema

<strong>OK.</strong> Conferma e applica le modifiche, quindi chiude la finestra di dialogo.

<strong>Cancel.</strong> Chiude la finestra di dialogo senza applicare alcuna modifica.

</details>

La funzionalità di <strong>esportazione e importazione</strong> delle impostazioni (file in formato <strong>*.usrdef</strong>) è realizzata in modo analogo al meccanismo di gestione dei file delle operazioni utente. È accessibile dalla finestra di creazione di una <strong>nuova operazione in modalità Customize</strong>. [Dettagli](91.md)
