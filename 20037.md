# Kontur bearbeiten

Die ausgewählte Kontur kann durch Verschieben ihrer Punkte im Grafikfenster bearbeitet werden. Die Eigenschaften der Konturelemente können Sie im Inspektor ändern.

Im Bearbeitungsmodus wird die Kontur als Folge von Linien und Bögen dargestellt.

![images/download/attachments/157860300/image2024-8-8_17-14-57.png](assets/images/download/attachments/157860300/image2024-8-8_17-14-57.png)

Wenn Sie bei gedrückter **Strg**-Taste (**Ctrl**) eine Seite der Kontur auswählen, wird nur dieses Konturelement ausgewählt. Wenn Sie ein Element aus der Kontur herauslösen, wird die Kontur in ihre Einzelelemente zerlegt.
