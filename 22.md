# Registerkarte Maßeinheiten

![images/download/attachments/157858969/image2024-7-1_17-43-12.png](assets/images/download/attachments/157858969/image2024-7-1_17-43-12.png)

Unter **Measurement Units** (Maßeinheiten) legen Sie die Maßeinheiten des Systems fest.

Die Maße beziehen sich auf die Einheiten des importierten Modells. Die NC-Ausgabe verwendet dieselben Einheiten. Soll ein NC-Programm für eine CNC-Fräsmaschine in Millimetern oder Zoll erzeugt werden, müssen daher auch die Modellmaße in Millimetern bzw. Zoll vorliegen.

**Winkelmaße** werden in Grad mit Dezimalstellen angegeben.

<a id="additional-settings"></a>

## Zusätzliche Einstellungen:

- **Tolerance (digits).** Legt die Anzahl der Nachkommastellen für Werte der NC-Ausgabe fest. Empfohlen wird mindestens eine zusätzliche Nachkommastelle gegenüber der von der CNC-Maschine verarbeiteten Genauigkeit bzw. der Anzahl der Nachkommastellen im NC-Programm.
- **Time format (Zeitformat).** Legt das Ausgabeformat von Zeitwerten fest, beispielsweise der Bearbeitungszeit.
- **Use vulgar fraction (Gemeine Brüche verwenden).** Ermöglicht die Darstellung von Werten als gewöhnliche Brüche, sofern dies zweckmäßig ist.
