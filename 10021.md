# File dello schema macchina

Il sistema CAM utilizza lo schema macchina per descrivere il modello cinematico dell'apparecchiatura (macchina CNC, robot e così via), il suo nome, il sistema CNC, il file del postprocessore utilizzato e alcune altre impostazioni. In genere lo schema è costituito da un file xml principale e da diversi file aggiuntivi che contengono il modello 3D di ciascun nodo della macchina. Questi file possono avere l'estensione.osd e.stl e trovarsi accanto al file xml oppure in una sottocartella. I file dello schema macchina possono anche essere inseriti in [contenitori zip cifrati](10022.md) con l'estensione.stfc oppure all'interno del file di progetto.stcp.

Per selezionare il file dello schema macchina desiderato, utilizzare la [finestra Machines library](341.md) (libreria delle macchine).
