# Home Page

## Application area:

The **Home Page** is the starting point for opening recent projects, working with cloud projects and collections, sharing projects, and finding project files on disk. It also provides access to extensions, licenses, and machine components.

## Opening the Home Page

The page opens when the application starts. **Recent** is displayed first if recent projects are available; otherwise, **Local** is displayed. Selecting **License manager** from the logo menu in the main window title bar opens the Home Page directly at the license manager.

## Window layout

The navigation sidebar is on the left. It is narrow when idle and expands when the pointer is over it. The pin button on **Recent**, with the tooltip *Pin or unpin sidebar*, keeps it expanded. This setting is remembered.

- **Recent.** Recently opened projects.
- **Clouds.** Cloud projects and machine components. Sign-in and an internet connection are required. A dot on the icon indicates pending invitations.
- **Local.** Project files on disk.
- **Extensions.** Extension catalog and management. Sign-in and an internet connection are required.

**Favorites.** Shows up to ten favorite collections and ten favorite projects. Clicking a collection opens it; clicking a project opens its information panel. The section is hidden when there are no favorites.

The bottom of the expanded sidebar contains:

- **What's new**, **Documentation**, and **Self-paced learning** links, available with an internet connection.
- **Active license** and **Licensee** information.
- **Connection.** Displays **Online** or **Offline · no internet**. When disconnected, use the reconnect button with the tooltip *No server connection — click to reconnect*.
- **License manager.** Opens license management.
- The account row. **Sign in** is shown before sign-in; afterwards, the user name and email are shown. Clicking the row opens an account card with **Sign out**. Signing out requires confirmation.

The back and forward mouse buttons navigate through page history.

The progress bar at the bottom shows project uploads and downloads, including size, speed, remaining transfer, and a cancel button. Notifications appear at the lower right and disappear automatically. Error notifications remain longer and have a **Copy** button.

## Recent

**Recent** lists recently opened projects whose files still exist. When signed in and connected, cloud and library projects use their cloud image and a source label; library projects are marked **Project library**.

**Search.** Filters projects by name. Sort by **Recent** (the default) or **Alphabetical**, and change direction with **Sort order**. **Show hidden** appears when there are hidden projects.

A card shows an image, name, modification date, and the path for a local file. Hover over a card to show **Open project** and **Preview**. **Preview** opens the information panel and is unavailable for local files. Use the buttons or menu to open a project; double-clicking is not used here.

The three-dot menu contains **Open**, **Preview**, **Hide from Recent** or **Unhide**, and **Delete**, as applicable. **Hide from Recent** hides the project on the Home Page only; it does not change the recent-project list in the application.

## Clouds

**Clouds** contains the **Projects** and **Digital Machine Center** tabs. **Projects** is used to store and share machining projects. **Digital Machine Center** provides machine components. [Details](10201022.md)

### Projects

**Upload project.** Uploads one or more `*.stc` or `*.stcp` files. Newly uploaded projects appear at the beginning of the list.

Use **All**, **My projects**, and **Shared with me** to select projects. The archive icon opens archived items; the star selects favorites.

**Search** and **Filters** narrow the results. The filter panel contains **Machine type**, **Machine model**, **Provided by**, **Operations**, **Tools**, **Axes**, **Tags**, and **Clear all**. Signing in or out resets the filters.

**Compact** and **Extensive** change the card layout; the selection is remembered. Sort by **Popular**, **Alphabetical**, **Created** (the default), **Updated**, **Size**, or **Recently viewed**, and use the direction button to reverse the order.

The page contains three sections:

- **Pending invites.** Invitations show the sender, **Expires in** or **Expired**, and **Accept** and **Decline** actions. Accepting an invitation opens **Shared with me**.
- **Collections.** Initially shows eight collections. **Show** and **Collapse** expand or collapse the full list.
- **Projects.** Loads more projects as the page is scrolled.

A project card shows an image, name, visibility icon, and date. The favorite star appears on hover or when the project is already a favorite. Hovering also shows **Open project** and **Preview**.

The three-dot menu provides **Open**, **Preview**, **Download**, **Edit**, **Archive**, **Duplicate to My Projects**, **Share**, **Add to collection**, and **Delete**. Available actions depend on access rights. **Delete** is highlighted in red.

**Open.** Downloads the project to a temporary folder and opens it in the application.

**Download.** Saves the file to the selected location and shows it in File Explorer.

### Collections

To create a collection:

1. Open a project's **Add to collection** menu and select **New collection**. A personal collection is created without a name.
2. Open the collection and select **Edit** to enter its name and description.
3. Select **Save** to apply the changes or **Cancel** to discard them.

**Add to collection.** Use **Find collection** to search, then click a collection to add the project. A dot identifies collections that already contain the project. If a collection has wider visibility than the project, a warning explains that the project's visibility will be extended. Select **Continue** or **Cancel**.

Collection colors are assigned automatically. Projects cannot be dragged into collections.

A collection card shows its name, visibility, author, number of projects, and date. Clicking it opens the collection. Its menu contains **Open**, **Edit**, **Archive**, **Share**, and **Remove**.

The collection page header contains **Back**, name, visibility, author, dates, **Description**, **Share**, **Edit**, and a favorite star. In **Edit**, change the name, description, and **Public** or **Personal** visibility, then use **Save** or **Cancel**. Changing visibility also changes the visibility of the collection's projects; the application warns before applying this change.

Below the header are search, sorting, filters, and the collection's projects. Use **Remove from collection** in a project's menu to remove it from that collection.

### Archive

Select the archive icon to view archived items. Project actions are **Preview**, **Restore**, and **Delete**; collection actions are **Open**, **Restore**, and **Remove**. Restoration does not require confirmation. Archiving and deleting require confirmation.

### Share

Open **Share** for a project or collection to manage invitations and access.

**Copy Link.** Available for projects only. The link grants viewing access, so the button is unavailable while editing access is enabled.

**Invite by email.** Accepts multiple email addresses separated by commas. Use the arrow keys to select a suggested colleague. Press Enter or select **Invite** to send the invitation.

**Expiration.** Sets the invitation lifetime to 1, 7, 15, or 30 days; the default is 30 days.

**Collaboration.** For a project, **Chat** enables chat and **Update project** grants editing access. For a collection, use **Update collection**.

**Members.** Lists participants with **Can View** or **Can Edit** roles, **Owner** and **Pending** labels, and a removal button. Removing a member requires confirmation.

## Project information panel

**Preview**, or a project in **Favorites**, opens the information panel over the window.

The header contains **Back**, the project name, an **Official** label where applicable, **Edit** (tooltip *Edit project info*), and **Open**. Archived projects have **Restore**.

The menu provides:

- **Download.** Unavailable when the panel is opened from **Recent** or the project is archived.
- **Reupload.** Uploads a new version of the project file. Uploading the same file is rejected with a message.
- **Archive** and **Delete**.

**Summary.** Shows **Visibility**, **Provided by**, ID, **Date**, **Machine type**, **Machine model**, **Size**, a **Tutorial** link, **Description**, **Axes**, **Tags**, and **Members**. Select **Edit** to change project information. Visibility can be **Public** or **Personal**; tags use suggestions and are entered with Enter. Finish with **Save** or **Cancel**.

**Operations.** Lists machining operations. Clicking an operation displays its toolpath. **View options** contains **Show part** and **Show toolpath**.

In the 3D view, drag with the right mouse button to rotate, with the middle button to pan, and use the wheel to zoom. Ctrl+E fits everything into the view. B, F, U, D, L, and R select back, front, top, bottom, left, and right views. The view cube in the corner also changes the viewing direction.

## Local

**Local** browses project files on disk and initially opens the desktop folder.

The toolbar contains back, forward, up, refresh, **Open in explorer**, **Cut**, **Copy**, **Paste**, **Rename**, **Delete**, and **Upload project**. **Upload project** uploads the selected file and opens **Clouds**.

Click a segment of the path to open that folder. Click the path bar to enter a path; Enter navigates to it and Esc cancels editing.

Search finds projects by part of their name in all subfolders. If no folder is selected, it searches all drives. Progress is shown at the bottom and the search can be cancelled.

The left pane contains **Desktop**, **Downloads**, **Documents** (the application's documents folder), **Examples** when the examples folder exists, pinned folders, and the drive tree. Hover over a folder to display its pin button.

The table shows folders and project files, with **Name**, **Location**, **Type**, **Size**, and **Last update** columns. Multiple rows can be selected. Double-click a project to open it or a folder to enter it.

The three-dot row menu contains **Open**, **Open in explorer**, **Upload project**, **Cut**, **Copy**, **Paste**, **Rename**, and **Delete**.

Use Ctrl+X, Ctrl+C, Ctrl+V, F2, and Delete for file operations. **Delete** asks for confirmation and moves files to the Recycle Bin. Copying is compatible with File Explorer. The list updates automatically when the folder contents change.

## Extensions

**Extensions** opens the extension catalog and tools for managing installed extensions. The sidebar item appears after the store module loads and is available when signed in and connected to the internet. [Details](162964210.md)

## License manager

**License manager** manages application and module licenses. Open it from the bottom of the sidebar to view licenses and activate or release them. [Details](10025.md)

## When projects cannot be opened

Opening a project requires an activated, unexpired license. When **Open** is unavailable, its tooltip explains the reason: *Sign in to open a project*, *An activated license is required to open a project*, or *The active license has expired…*.

An expired license displays a banner with *License #N expired on [date]. Preview only* and **Open License manager**. Projects can only be previewed; opening, creating, and uploading are unavailable until renewal.

**Clouds** and **Extensions** require account sign-in and an internet connection. When the connection is lost, the application switches to **Recent**.
