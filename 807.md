# Aba Cores

![images/download/attachments/157858989/image2024-7-1_17-43-49.png](assets/images/download/attachments/157858989/image2024-7-1_17-43-49.png)

No campo <strong>Color scheme</strong>, é possível selecionar um dos esquemas de cores predefinidos. Ao clicar no botão ![images/download/thumbnails/157858989/image2024-7-1_17-43-57.png](assets/images/download/thumbnails/157858989/image2024-7-1_17-43-57.png), é possível restaurar os valores de cor padrão ou, se o esquema de cores <strong>Another</strong> estiver selecionado, carregar os valores de outro esquema de cores.

Abaixo do esquema de cores, uma estrutura em forma de árvore mostra os valores de cores para elementos individuais. Esses elementos são agrupados da seguinte forma: <strong>Graphic window</strong>, <strong>Coordinate systems axes</strong>, <strong>`3D Model`</strong>, <strong>`2D Geometry`</strong>, <strong>Machining</strong>. Ao expandir o grupo necessário, é possível editar os valores de cor de qualquer elemento. A cor do elemento selecionado é definida no campo <strong>Color</strong>, escolhendo o valor desejado na lista suspensa. O controle deslizante <strong>Transparence</strong> permite ajustar a transparência do elemento selecionado.

Também é possível escolher o plano de fundo da janela gráfica:

- <strong>Plain</strong>: fundo de cor única. A cor é definida em <strong>Graphic window -> First background color</strong>.
- <strong>Gradient</strong>: fundo em gradiente. As cores são definidas em <strong>Graphic window -> First background color</strong> e <strong>Second background color</strong>. O campo <strong>Gradient angle</strong> permite definir o ângulo do gradiente em relação ao eixo vertical.
- <strong>Image file</strong>: usa uma imagem como plano de fundo. Os formatos compatíveis são <strong>BMP</strong> e <strong>JPEG</strong>.
- <strong>Shiny lighting</strong>: ativa uma fonte de luz adicional para melhorar a visualização.
