# Löcher schließen

Die Funktion zum Schließen von Löchern erzeugt eine Triangulation für ausgewählte Kanten oder Netze. Sie wird auf der Registerkarte **Model** über die Schaltfläche ![Löcher schließen](assets/images/download/thumbnails/157860013/image2024-7-3_16-36-20.png) aufgerufen. Die Schaltfläche ist zunächst deaktiviert. Wählen Sie im Grafikfenster oder Modellbaum die Kanten oder Netze aus, deren Löcher geschlossen werden sollen, um sie zu aktivieren.

Die Funktion arbeitet für Kanten und Netze unterschiedlich:

1. **Kanten.** Zunächst werden geschlossene und offene Kanten ermittelt. Für geschlossene Kanten wird die Triangulation sofort erzeugt. Aus den übrigen Kanten wird eine geschlossene Begrenzung gebildet, für die ebenfalls eine Triangulation erstellt wird. ![Löcher anhand von Kanten schließen](assets/images/download/attachments/157860013/Patch_holes_edges_EN.png)
2. **Netze.** Zunächst wird die Topologie geprüft. Aus gefundenen offenen Kanten werden geschlossene Konturen gebildet. Anschließend wird für jede Kontur eine Triangulation erstellt. Zusätzlich zu den neuen Netzen werden die verwendeten geschlossenen Konturen in den Modellbaum eingefügt. ![Löcher in Netzen schließen](assets/images/download/attachments/157860013/Patch_holes_mesh_EN.png)
