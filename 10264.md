# Programmazione della posizione delle guide

![images/download/attachments/157866170/clip0006.jpg](assets/images/download/attachments/157866170/clip0006.jpg)

Spesso, per ampliare la zona di lavoro di un robot industriale, il robot viene montato su guide. Il sistema CAM consente il controllo simultaneo fino a 3 posizionatori su guida.

Se lo schema cinematico di una cella robotizzata contiene una o più guide, nei parametri dell'operazione diventano disponibili i seguenti parametri per ciascuna guida.

1. La posizione iniziale della guida per l'operazione (E1 (posizione dell'asse esterno 1) nella figura).

2. La casella di controllo della modalità Move Up dell'asse guida (casella Move up E1 nella figura)

![images/download/attachments/157866170/image2024-7-17_15-41-31.png](assets/images/download/attachments/157866170/image2024-7-17_15-41-31.png)

Move Up **dell'asse guida**

Se questa modalità è attivata, durante la lavorazione il robot viene spostato automaticamente sulla guida in modo che il punto centrale utensile (TCP) di programmazione corrente si trovi sotto il punto zero della base del robot (o il più vicino possibile ad esso).

Attenzione!

Avere il punto centrale utensile esattamente sotto il punto zero della base del robot non è sempre la condizione ottimale. Questa posizione può causare singolarità del primo giunto. In tal caso è necessario regolare la posizione della guida nella Robot Axes Map (mappa degli assi del robot), aggiungendo uno spostamento supplementare.
