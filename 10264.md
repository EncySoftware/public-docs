# Position der Roboterverfahrachse programmieren

![images/download/attachments/157866170/clip0006.jpg](assets/images/download/attachments/157866170/clip0006.jpg)

Zur Vergrößerung des Arbeitsbereichs wird ein Industrieroboter häufig auf einer Verfahrachse montiert. Das CAM-System kann bis zu drei solche Linearpositionierer gleichzeitig steuern.

Enthält das kinematische Schema eine oder mehrere Verfahrachsen, stehen für jede Achse folgende Operationsparameter zur Verfügung:

1. Ausgangsposition für die Operation, im Beispiel **E1** als Position der ersten externen Achse.

2. Modus **Move Up** für die Verfahrachse, im Beispiel das Kontrollkästchen **E1 Move up**.

![images/download/attachments/157866170/image2024-7-17_15-41-31.png](assets/images/download/attachments/157866170/image2024-7-17_15-41-31.png)

**Move Up für die Verfahrachse**

Bei aktivierter Option wird der Roboter während der Bearbeitung automatisch so auf der Verfahrachse positioniert, dass der programmierte Werkzeugmittelpunkt unter dem Basisnullpunkt des Roboters oder möglichst nahe daran liegt.

**Achtung:**

Eine Werkzeugposition unmittelbar unter dem Roboterbasisnullpunkt ist nicht immer günstig und kann zu einer Singularität des ersten Gelenks führen. In diesem Fall muss die Verfahrachsposition in der Roboterachskarte durch einen zusätzlichen Versatz angepasst werden.
