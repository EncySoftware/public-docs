# Extension Store

![images/download/attachments/162964210/image2026-8-17_15-58-55.png](assets/images/download/attachments/162964210/image2026-8-17_15-58-55.png)

## Application area:

The **Extension Store** is the place where optional add-ons for the CAM system are discovered, installed, updated, and removed. It connects a web catalog with the CAM application: the web storefront lists extensions and can start an installation, while the in-application tab performs the actual download, registration, and removal on the local machine.

The store is used for the following scenarios:

- Browsing extensions by category, publisher, tag, or price.

- Installing free extensions directly into the CAM system.

- Starting a free 14-day trial for paid extensions.

- Updating installed extensions to newer versions.

- Removing extensions that are no longer needed.

- Managing extension sources and locally registered libraries.

> Note
>
> The **Extension Store** interface is displayed in **English regardless of the language selected in the CAM system**.

### Ways to Work with Extensions in the CAM Ecosystem:

- **Web storefront - [https://apps.encycam.com/](https://apps.encycam.com/)** ( Browsing the catalog, viewing extension details, publishing extensions, and starting installation from a browser. )

- **In-application tab -** Home page ([Details](10201021.md)) → **Extension Store**. ( Installing, updating, enabling, disabling, and removing extensions on the local machine. )

- **ExtensionManagerCLI -** Command-line utility next to the CAM application ( Packaging and local registration of extensions by authors and administrators. )

### Main components:

The Extension Store consists of two linked parts:

- **Web storefront**. The catalog is visible to any visitor. Signed-in users can add extensions to favorites, request trials, and publish extensions. Authors and administrators access moderation and configuration screens.

**Extension card in the Store page.**

The card shows a cover, icon, name, publisher, version, description or "No description", Paid badge, extension type, download count, and a favorite star. The action button changes according to state: Install, Update, Uninstall, View, or Installed.

When you click on the card, you can read the extension description and how to use it.

Each card displays the following:

- **Cover.** A screenshot provided by the author, or a solid color derived from the category, or an entry-point icon when neither screenshot nor category is present.

-  **Name, version, and publisher.**

-  **Description.** If the author left it empty, the text *"No description"* appears in italics.

-  **Tags.** Up to three tags are shown, followed by an indicator for additional tags. The tag that duplicates the category name is hidden.

-  **Paid badge.** Appears when the extension requires a license.

-  **On moderation badge.** Visible to the author for new extensions that are awaiting approval.

-  **Download count and category name.**

-  **Favorite star.** Visible only to signed-in users.

### Installing an extension.

There are three starting points for installation, all of which converge to the same in-application process.

<details>
<summary>Click here to expand..</summary>

**From the web storefront.** Press Install in CAM system (v **version**) on the extension page.

**From the in-application catalog.** Press Install on the card, or open the detail view and press Install **version**.

**From a file.** On the **Manage page**, press Install from file… or drag a **.nupkg** or **.dext** file onto the tab.

**After installation starts**, the button becomes a progress indicator and passes through the stages: "Looking in the store…", "Searching the feeds…", "Checking compatibility…", "Downloading…", "Reading package…", "Installing…", "Registering…".

</details>

**Location of Installed Extensions in the CAM System Interface.**

The store copies files and registers the extension, but does not start it. Where the extension appears depends on its entry point, which is defined by the extension author.

<details>
<summary>Click here to expand..</summary>

**Utility.** Utilities palette, opened with the Utilities button on the top toolbar or the Ctrl+Shift+E shortcut.

**Operation Popup.** Right-click menu on an operation in the technology tree.

**Geometry Node Popup.** Right-click menu on a node in the geometric model tree.

**Operation Solver.** As an operation in the project. The extension computes the operation and its toolpath.

**Global**, **CLData Converter**, **Utility Runner.** No visible location. The code runs automatically on startup, during toolpath calculation, or when a utility is launched.

If an installed extension does not appear where expected, the library or its entry point may be disabled on the **Manage** page, or the CAM system may need a restart.
