# Extension Store

<a id="application-area"></a>

## Ambito di applicazione:

L'<strong>Extension Store</strong> è il luogo in cui i componenti aggiuntivi opzionali per il sistema CAM vengono individuati, installati, aggiornati e rimossi. Collega un catalogo web con l'applicazione CAM: la vetrina web elenca le estensioni e può avviare un'installazione, mentre la scheda nell'applicazione esegue il download, la registrazione e la rimozione effettivi sul computer locale.

Lo store viene utilizzato negli scenari seguenti:

- Consultazione delle estensioni per categoria, editore, tag o prezzo.

- Installazione di estensioni gratuite direttamente nel sistema CAM.

- Avvio di una prova gratuita di 14 giorni per le estensioni a pagamento.

- Aggiornamento delle estensioni installate a versioni più recenti.

- Rimozione delle estensioni non più necessarie.

- Gestione delle origini delle estensioni e delle librerie registrate localmente.

> Nota
>
> L'interfaccia dell'<strong>Extension Store</strong> viene visualizzata in <strong>inglese indipendentemente dalla lingua selezionata nel sistema CAM</strong>.

<a id="ways-to-work-with-extensions-in-the-cam-ecosystem"></a>

### Modi di lavorare con le estensioni nell'ecosistema CAM:

- <strong>Vetrina web - [https://apps.encycam.com/](https://apps.encycam.com/)</strong> ( Consultazione del catalogo, visualizzazione dei dettagli delle estensioni, pubblicazione delle estensioni e avvio dell'installazione da un browser. )

- <strong>Scheda nell'applicazione -</strong> Home page ([Dettagli](10201021.md)) → <strong>Extension Store</strong>. ( Installazione, aggiornamento, abilitazione, disabilitazione e rimozione delle estensioni sul computer locale. )

- <strong>ExtensionManagerCLI -</strong> Utilità da riga di comando accanto all'applicazione CAM ( Creazione dei pacchetti e registrazione locale delle estensioni da parte di autori e amministratori. )

- <strong> Stella dei preferiti.</strong> Visibile solo agli utenti autenticati.

<a id="installing-an-extension"></a>

### Installazione di un'estensione.

Esistono tre punti di partenza per l'installazione, che convergono tutti nello stesso processo all'interno dell'applicazione.

<details>
<summary>Fare clic qui per espandere..</summary>

<strong>Dalla vetrina web.</strong> Premere Install in CAM system (v **version**) nella pagina dell'estensione.

<strong>Dal catalogo nell'applicazione.</strong> Premere Install sulla scheda, oppure aprire la vista di dettaglio e premere Install **version**.

<strong>Da file.</strong> Nella <strong>pagina Manage</strong>, premere Install from file… oppure trascinare un file <strong>.nupkg</strong> o <strong>.dext</strong> sulla scheda.

<strong>Dopo l'avvio dell'installazione</strong>, il pulsante diventa un indicatore di avanzamento e attraversa le fasi: "Looking in the store…", "Searching the feeds…", "Checking compatibility…", "Downloading…", "Reading package…", "Installing…", "Registering…".

![images/download/attachments/162964210/image2026-8-18_9-16-39.png](assets/images/download/attachments/162964210/image2026-8-18_9-16-39.png)

</details>

<strong>Posizione delle estensioni installate nell'interfaccia del sistema CAM.</strong>

Lo store copia i file e registra l'estensione, ma non la avvia. La posizione in cui l'estensione compare dipende dal suo punto di ingresso, definito dall'autore dell'estensione.

<details>
<summary>Fare clic qui per espandere..</summary>

<strong>Utility.</strong> Palette Utilities, aperta con il pulsante Utilities nella barra degli strumenti superiore o con la scorciatoia Ctrl+Maiusc+E.

<strong>Operation Popup.</strong> Menu del tasto destro del mouse su un'operazione nell'albero tecnologico.

<strong>Geometry Node Popup.</strong> Menu del tasto destro del mouse su un nodo nell'albero del modello geometrico.

<strong>Operation Solver.</strong> Come operazione nel progetto. L'estensione calcola l'operazione e il relativo percorso utensile.

<strong>Global</strong>, <strong>CLData Converter</strong>, <strong>Utility Runner.</strong> Nessuna posizione visibile. Il codice viene eseguito automaticamente all'avvio, durante il calcolo del percorso utensile oppure all'avvio di una utility.

Se un'estensione installata non compare dove previsto, la libreria o il relativo punto di ingresso potrebbe essere disabilitato nella pagina <strong>Manage</strong>, oppure potrebbe essere necessario riavviare il sistema CAM.

A titolo di esempio, viene installata l'estensione <strong>Support Generator</strong>. La descrizione sulla scheda fornisce le istruzioni per richiamarla.
