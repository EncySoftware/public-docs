# Empfehlungen für den IGES-Export im Modellierungsprogramm

Nahezu alle modernen 3D-Modellierungssysteme bieten einen **IGES**-Export mit konfigurierbaren Optionen. Beachten Sie beim Vorbereiten von IGES-Dateien folgende Empfehlungen:

- Ist eine Genauigkeitseinstellung vorhanden, wählen Sie eine ausreichend hohe Genauigkeit. Dadurch können die Flächen des Modells präziser miteinander verbunden und bearbeitet werden. Die Exportgenauigkeit sollte mindestens der geforderten Bearbeitungsgenauigkeit entsprechen; die Abweichung darf die vorgegebene [Toleranz](100112.md) nicht überschreiten.
- Ersetzen Sie nicht unterstützte Objekttypen durch importierbare Typen. Ein im Modellierungssystem verwendeter Kugelvolumenkörper kann beispielsweise nicht als IGES-Element **Sphere**, Typ 158, importiert werden. Er kann jedoch durch eine Kombination anderer Elementtypen, etwa 144, 143 oder 510, dargestellt werden.
- Sind Begrenzungskurven nur im räumlichen Modell definiert, erzeugt der Import die entsprechenden Begrenzungskurven im parametrischen UV-Raum automatisch. Dabei können zusätzliche Abweichungen entstehen. Deshalb sollten parametrische Begrenzungskurven vorhanden sein. Dies betrifft **Boundary**, Typ 141, und **Loop**, Typ 508. Aktivieren Sie bei Importproblemen die Erzeugung parametrischer Begrenzungen in den IGES-Exportoptionen des Modellierungsprogramms. Ist dies nicht möglich, ersetzen Sie **Bounded Surface**, Typ 143, und **Face**, Typ 510, durch **Trimmed Parametric Surface**, Typ 144.
