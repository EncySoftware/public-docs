# Raccomandazioni per la configurazione del modulo di esportazione IGES nel programma di modellazione

Praticamente tutti i moderni sistemi di modellazione 3D dispongono di un modulo di esportazione nel formato **IGES**. Questo modulo di norma offre opzioni di regolazione e configurazione. Di seguito sono riportate alcune raccomandazioni da seguire nella preparazione dei file IGES.

- Se nel menu di configurazione dell'esportazione IGES è presente un controllo della precisione, esso va impostato su un valore relativamente alto. Ciò consente al sistema di collegare con maggiore accuratezza le superfici che formano il modello e, di conseguenza, di lavorarlo con maggiore precisione. Non è raccomandato esportare il modello con una precisione inferiore alla [tolleranza](/pages/createpage.action?spaceKey=SCUM20ENRC&title=Tolerance&linkCreation=true&fromPageId=157859500) di lavorazione richiesta.
- Si consiglia di sostituire i tipi di oggetti che il sistema non può importare con tipi che può importare. Ad esempio, il progettista che lavora nel programma di modellazione può utilizzare un'entità sfera solida. Importarla nel sistema come entità IGES **Sphere** (tipo 158) è impossibile, ma è corretto sostituire le entità di questo tipo con una combinazione di entità di altri tipi (ad es. 144, 143, 510).
- Se nello spazio 3D di modellazione sono definiti insiemi di curve di contorno (bound, loop), durante l'importazione vengono create automaticamente le corrispondenti curve di contorno nello spazio parametrico (UV). In teoria ciò può introdurre ulteriori errori nel modello. Pertanto è richiesta la presenza di curve di contorno parametriche. Ciò riguarda le entità **Boundary** (tipo 141) e **Loop** (tipo 508). Se durante l'importazione degli oggetti geometrici si presentano problemi, provare ad attivare la generazione dei contorni parametrici nelle opzioni di esportazione IGES del programma di modellazione. Se ciò non è possibile, sostituire le entità **Bounded Surface** (tipo 143) e **Face** (tipo 510) con **Trimmed Parametric Surface** (tipo 144).
