# Recomendações para configurar a exportação IGES no programa de modelagem

Praticamente todos os sistemas modernos de modelagem 3D têm um módulo de exportação no formato **IGES**. Esse módulo normalmente tem opções para ajuste e configuração. Aqui estão algumas recomendações que você deve usar ao preparar arquivos IGES.

- Se no menu de configuração da exportação IGES houver um controle de precisão, ele deverá ser definido como relativamente alto. Isso permitirá que o sistema una as superfícies que formam o modelo com mais precisão e, consequentemente, processe-o com mais precisão. Não é recomendável exportar o modelo com precisão menor que a [tolerância](/pages/createpage.action?spaceKey=SCUM20ENRC&title=Tolerance&linkCreation=true&fromPageId=157859500) de usinagem necessária.
- É aconselhável substituir os tipos de objetos que não podem ser importados pelo sistema por aqueles que podem. Por exemplo, o desenhista, trabalhando no programa de modelagem, pode usar uma entidade de esfera sólida. É impossível importar isso para o sistema como uma entidade IGES **Sphere** (tipo 158), mas é correto alterar as entidades desse tipo para uma combinação de entidades de outros tipos (por exemplo, 144, 143, 510).
- Se os conjuntos de curvas de contorno (bound, loop) forem definidos no espaço 3D de modelagem, as curvas de contorno correspondentes no espaço paramétrico (UV) serão criadas automaticamente durante a importação. Teoricamente, isso pode trazer erros adicionais ao modelo. Portanto, é necessária a presença de curvas de contorno paramétricas. Isso se refere às entidades **Boundary** (tipo 141) e **Loop** (tipo 508). Se houver problemas durante a importação de objetos geométricos, tente permitir a geração de limites paramétricos nas opções de exportação IGES do programa de modelagem. Se isso não for possível, altere as entidades **Bounded Surface** (tipo 143) e **Face** (tipo 510) para **Trimmed Parametric Surface** (tipo 144).
