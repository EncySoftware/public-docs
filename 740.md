<a id="operations-sequence-behavior"></a>

## Comportamento della sequenza delle operazioni:

Il pannello <strong>Operations sequence behavior</strong> consente di controllare il comportamento delle operazioni quando il loro stato passa a calcolato/azzerato:

- <strong>Reset all associated operations when operation parameters are changed</strong>: azzera automaticamente il percorso utensile delle operazioni quando cambiano i dati di ingresso provenienti dalle operazioni precedenti del processo.
- <strong>Start computation of the machining result just after the toolpath calculation</strong>: avvia automaticamente una simulazione in background subito dopo il calcolo del percorso utensile.

<a id="tools-list"></a>

## Elenco utensili:

L'elenco utensili (Tools list) serve a configurare i parametri della [generazione dell'elenco utensili](13.md).

L'elenco utensili può essere creato nei formati <strong>ODT</strong> e <strong>PDF</strong>.

Per generare un elenco utensili, il sistema utilizza dei modelli. Il pacchetto di installazione include diversi modelli, tra cui è possibile scegliere quello desiderato. È inoltre possibile creare nuovi modelli con qualsiasi editor di testo che supporti il formato ODT. Per ulteriori informazioni, rivolgersi al [servizio di assistenza](811.md).

Una volta creato, il documento può essere salvato immediatamente oppure, se necessario, visualizzato e modificato. Per salvare un elenco utensili senza visualizzarlo, deselezionare <strong>Show tools list</strong>.

Per visualizzare il file dell'elenco utensili creato, è possibile utilizzare il programma predefinito per quel tipo di file oppure un programma definito dall'utente. Per assegnare un programma diverso per la modifica, specificare il percorso completo del file dell'applicazione.

<a id="external-nc-editor-panel"></a>

## Pannello External NC-Editor:

Il pannello <strong>`External NC-editor`</strong> serve a specificare un'applicazione esterna per la visualizzazione dei programmi NC. Il sistema riconosce specifici parametri della riga di comando:

- <strong>`$NCOUTPUTNAME$`</strong>: il nome del file del programma NC generato dal postprocessore.
- <strong>`$CD.**ItemName**$`</strong>: parole chiave dei dati personalizzati (Custom data), che verranno sostituite dal valore della voce corrispondente.

Se la casella di controllo <strong>`Autorun NC-editor`</strong> è selezionata, l'editor NC specificato viene avviato automaticamente dopo che il postprocessore ha generato il programma NC.

<a id="postprocessor-compatibility-settings"></a>

## Impostazioni di compatibilità dei postprocessori:

Per la compatibilità con le versioni precedenti dei postprocessori, il sistema consente di modificare il formato di output del ciclo di foratura (quando per l'[operazione di lavorazione dei fori](10100.md) si utilizza il metodo di output del percorso utensile non espanso). Il parametro <strong>Drilling cycle format</strong> può assumere i seguenti valori:

- <strong>`EXTCYCLE (recommended)`</strong>: è il nuovo formato, che include un insieme esteso di parametri, supporta tutte le strategie di lavorazione implementate nel sistema e consente una simulazione realistica dei movimenti dell'utensile secondo la strategia scelta.
- <strong>`CYCLE (for old postprocessors)`</strong>: questo vecchio formato è necessario per la compatibilità con i postprocessori meno recenti. Non supporta alcune strategie (ad esempio la svuotatura di fori o la lavorazione a spirale) e simula qualsiasi strategia come un semplice movimento fino al livello inferiore del foro.

<a id="performance-options"></a>

## Opzioni prestazionali:

<strong>Leave one core free</strong>: consente di lasciare libero un core durante il calcolo multi-core (richiede il riavvio).
