## Comportamento da sequência de operações:

O painel <strong>Operations sequence behavior</strong> permite controlar o comportamento das operações quando seu status muda para calculado/redefinido:

- <strong>Reset all associated operations when operation parameters are changed</strong>: redefine automaticamente o percurso da ferramenta das operações quando os dados de entrada provenientes de operações anteriores do processo são alterados.
- <strong>Start computation of the machining result just after the toolpath calculation</strong>: inicia automaticamente uma simulação em segundo plano logo após o cálculo do percurso da ferramenta.

## Lista de ferramentas:

A lista de ferramentas é usada para configurar os parâmetros da [geração da lista de ferramentas](13.md).

A lista de ferramentas pode ser criada nos formatos <strong>ODT</strong> e <strong>PDF</strong>.

Ao gerar uma lista de ferramentas, o sistema usa modelos. Vários modelos estão incluídos no pacote de instalação, e é possível escolher o desejado entre eles. Também é possível criar novos modelos em qualquer editor de texto com suporte ao formato ODT. Para obter mais informações, entre em contato com a [central de suporte](811.md).

Depois de criado, o documento pode ser salvo imediatamente ou visualizado e editado, se necessário. Para salvar uma lista de ferramentas sem visualizá-la, desmarque <strong>Show tools list</strong>.

Para visualizar o arquivo da lista de ferramentas criado, é possível usar o programa padrão para esse tipo de arquivo ou um programa definido pelo usuário. Para atribuir outro programa como ferramenta de edição, especifique o caminho completo do arquivo do aplicativo.

## Painel do editor NC externo:

O painel <strong>`External NC-editor`</strong> é usado para especificar um aplicativo externo para visualizar programas NC. O sistema reconhece parâmetros de linha de comando específicos:

- <strong>`$NCOUTPUTNAME$`</strong>: nome do arquivo do programa NC gerado pelo pós-processador.
- <strong>`$CD.**ItemName**$`</strong>: palavras-chave de dados personalizados, que serão substituídas pelo valor do item correspondente.

Se a caixa de seleção <strong>`Autorun NC-editor`</strong> estiver marcada, o editor NC especificado será iniciado automaticamente depois que o programa NC for gerado pelo pós-processador.

## Configurações de compatibilidade do pós-processador:

Para compatibilidade com versões mais antigas de pós-processadores, o sistema permite alterar o formato de saída do ciclo de furação (quando o método de saída do percurso da ferramenta não expandido é usado na [operação de usinagem de furos](10100.md)). O parâmetro <strong>Drilling cycle format</strong> pode ter os seguintes valores:

- <strong>`EXTCYCLE (recommended)`</strong>: formato novo, que inclui um conjunto ampliado de parâmetros, suporta todas as estratégias de usinagem implementadas no sistema e permite simular de forma realista os movimentos da ferramenta de acordo com a estratégia escolhida.
- <strong>`CYCLE (for old postprocessors)`</strong>: formato antigo, necessário para compatibilidade com pós-processadores mais antigos. Ele não suporta algumas estratégias (por exemplo, usinagem de bolsão em furo ou usinagem em espiral) e simula qualquer estratégia como um simples movimento até o nível inferior do furo.

## Opções de desempenho:

<strong>Leave one core free</strong>: mantém um núcleo livre durante a computação em vários núcleos (requer reinicialização).
