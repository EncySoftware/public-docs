# Tool motion controlling

The simulation process can be started by one of the buttons in the next list. The last three buttons start the fast simulation i.e. the screen will be updated once - at the end of the formation of the model. Other buttons start the step-by-step simulation, i.e. the graphical view will be updated over and over again depends on the tool movement method.

- ![images/download/thumbnails/157867155/image2024-7-19_16-56-48.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-56-48.png) – simulates the node before current ones. The screen updating depends on the tool movement method;
- ![images/download/thumbnails/157867155/image2024-7-19_16-56-14.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-56-14.png) – stops the simulation process;
- ![images/download/thumbnails/157867155/image2024-7-19_16-57-19.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-57-19.png) – runs the simulation of the current node. The process stops after the next node arrival;
- ![images/download/thumbnails/157867155/image2024-7-19_16-57-57.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-57-57.png) – runs the step-by-step simulation from the current node to the end of the list. The screen updating depends on the tool movement method;
- ![images/download/thumbnails/157867155/image2024-7-19_16-58-47.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-58-47.png) – runs the fast simulation of the selected operation (tool path node). All CLDATA commands inside the selected node are run. The simulation stops when the next operation (node) attained. Screen performs once upon completion of the simulation;
- ![images/download/thumbnails/157867155/image2024-7-19_16-59-13.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-59-13.png) – runs the fast simulation till the current operation. Work off all technological commands from the beginning of technological process and up to the selected node path or operation. Screen performs once upon completion of the simulation;
- ![images/download/thumbnails/157867155/image2024-7-19_16-59-49.png](assets/images/download/thumbnails/157867155/image2024-7-19_16-59-49.png) – runs the fast simulation all operations at once. Screen performs once upon completion of the simulation.

<em>Note: If you need to simulate only some part of machining (some operation) you can go to this operation (or some command of this operation at CLDATA view )and press ![images/download/thumbnails/157867155/image2022-4-18_16-4-40.png](assets/images/download/thumbnails/157867155/image2022-4-18_16-4-40.png) button to prepare workpiece for this operation. Then you can use **Smooth** or `By-block` simulate.</em>

One of two modes can be selected while machining simulation: **Smooth** or **By block**.

![images/download/attachments/157867155/image2024-7-19_17-0-48.png](assets/images/download/attachments/157867155/image2024-7-19_17-0-48.png)

- When the **Smooth** method is selected (checked ![images/download/thumbnails/157867155/127-20-Smooth_simulation.png](assets/images/download/thumbnails/157867155/127-20-Smooth_simulation.png) option), the tool will move smoothly with constant speed. In this mode, user can control the visual speed of the tool by altering the tool speed slide. The far left position is the slowest movement speed, the far right – the fastest.
- If **By block** is selected (unchecked ![images/download/thumbnails/157867155/128-20-RapidFeed.png](assets/images/download/thumbnails/157867155/128-20-RapidFeed.png) option), then the tool will move block-by-block, with drawing at intermediate points only.

Changing the method and movement speed is possible during the simulation process.
