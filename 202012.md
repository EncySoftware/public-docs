# Power

![images/download/attachments/157862385/Power.png](assets/images/download/attachments/157862385/Power.png)

<strong>Cerchio verde</strong> — materiale estruso reale, <strong>cerchio</strong> <strong>nero</strong> — materiale estruso teorico.

<strong>S</strong> - passo orizzontale

<strong>d</strong> - passo sul piano

<a id="application-area"></a>

## Ambito di applicazione:

Questa opzione regola la velocità dell'estrusore in base all'altezza dello strato, modificando il parametro <strong>Power (material feed)</strong> (alimentazione del materiale). Tramite il collegamento è possibile scoprire come lavorare con il comando <strong>POWER</strong> nel postprocessore. [Dettagli](https://docs.encycam.com/Inp/2/en/1020.html)

Il calcolo è il seguente:

<strong>Power = d/S*100%</strong>

Pertanto, la funzione <strong>Power</strong> consente di aumentare l'alimentazione del materiale in funzione del passo variabile. In altre parole, quanto maggiore è il passo, tanto più materiale deve essere estruso.
