# Postprocessors generator (sppx postprocessors)

The **Postprocessors generator** is the subsystem for building postprocessors in the built-in Pascal-like language — the `.sppx` postprocessors. This section documents the generator, its masks and registers model, and the language. External links and example resources are listed in [references](references.md).
