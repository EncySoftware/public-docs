# The files set of the postprocessors generator

- Inp.exe – executable module of postprocessors generator.
- InpD.dll – executable system of the postprocessor.
- CLDImport.dll - CAM system projects import library.
- *.sppx – the file with a data about concrete NC-system and with the sources of programs to process technological commands.
- *.stcx – CAM system XML project files.
- *.stc – CAM system project files.
- *.mcd – temporary files of technological commands, linked with CAM system project files.
- *.spp, *.inp – the postprocessor adjustment files for the previous version of the postprocessor generator.
