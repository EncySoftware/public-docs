# PPFUN WEDMPassItem(57) - Wire EDM pass properties

Wire EDM pass properties command WEDMPassItem(57) is generated by EDM operations of CAM system. It is used to transfer information to the postprocessor about which contour and pass of toolpath the nested CLData commands belong to. It appears at the start of contour movements and before the end of contour movements for each separate pass.

## Parameters

| Parameters | CLD array | CLD name | Description |
|---|---|---|---|
| Command SubCode | CLD[1] | CLD.SubCode | WEDMPassItem(57) – the type of PPFun command - Wire EDM pass properties. |
| On/Off | CLD[2] |   | Contour start-stop flag: On(71) - start of contour, Off(72) - end of contour. |
| Contour type | CLD[3] |   | The type of contour - general type pass (0) or coreless pocketing pass (1). |
| Item index | CLD[4] |   | Index of this contour in the list of Job assignment items of the operation. |
| Pass index | CLD[5] |   | Offset pass index |
| Pass type | CLD[6] |   | The type of pass: 0 - Rough, 1 - Rough with bridge, 2 - bridge, 3 - finish together, 4 - finish separate. |

## Access from sppx

**PPFUN** has no sub-code-specific handler in sppx. All PPFUN sub-codes are processed in the single `program PPFun` handler, dispatching on `cld[1]` (`CLD.SubCode`); handle `WEDMPassItem` by adding a branch there. See [Postprocessor function (PPFUN)](ppfun.md) for the full handler.

Example:

```pascal
program PPFun
  case cld[1] of
    57: begin        ! WEDMPassItem
      ! wire-EDM pass properties
    end
  end
end
```

## Access from .NET

This sub-code has no dedicated handler - it is delivered through the base `OnPPFun` (dispatch on `cmd.SubCode`). See [Postprocessor function (PPFUN)](ppfun.md).
