<h1 class="heading"><span>Application Area:</span></h1>
<p>Project library for storing and accessing projects.</p>
<p><strong class="">Buttons located at the top of the screen:</strong></p>
<p><strong class="">All.</strong> Displays all projects combined.<br/><strong class="">Examples.</strong> Contains all default projects preinstalled with the application.<br/><strong class="">My Projects.</strong> Includes all user-created or imported projects.<br/><strong class="">Starred.</strong> Shows favorite projects marked with a star.</p>
<p><strong class="">Navigating the Project Library.<br/></strong></p>
<p>The image located at the top-right corner of the project window displays the workpiece being processed.</p>
<p><img alt="images/download/attachments/150697469/image2025-11-12_10-10-5.png" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697469/image2025-11-12_10-10-5.png" width="366"/>
</p>
<p><strong class="">User projects have a three-dot menu for:</strong></p>
<ul class=""><li class=""><p>Edit the project name;</p>
</li><li class=""><p>Duplicate the project;</p>
</li><li class=""><p>Delete the project.</p>
