<h1 class="heading"><span>Application Area:</span></h1>
<p>The home page provides the following functionalities:</p>
<ul class="">
<li><p>project library management;</p></li>
<li><p>access to standard example projects;</p></li>
<li><p>creation of new projects;</p></li>
<li><p>import of existing projects;</p></li>
<li><p>access to the system’s basic settings and user profile;</p></li>
<li><p>access to tutorials and documentation;</p></li>
<li><p>switching between light and dark themes.</p></li>
</ul>
<p>The project library occupies the main area of the home page. The <strong>All</strong>, <strong>Examples</strong>, <strong>My projects</strong>, and <strong>Starred</strong> filters are located above the project cards. The <strong>Search projects...</strong> field is in the upper-right corner. For details about the library, see <a href="project-library.md">Project library</a>.</p>
<p><strong>Buttons on the left navigation panel.</strong></p>
<p>The main buttons are arranged vertically on the left side of the screen, from top to bottom:</p>
<p><strong>Settings.</strong> Allows you to access the system’s basic settings.</p>
<p><strong>Import.</strong> Allows you to open an existing project.</p>
<p><strong>New project.</strong> Opens a page with two options for creating a project:</p>
<ul>
<li><p><strong>Create in MachineMaker.</strong> Launches MachineMaker, where you can prepare the machine assembly and then import it into ENCY Hyper.</p></li>
<li><p><strong>Load .mma file.</strong> Allows you to select an existing assembly file in <strong>.mma</strong> format. The file can be prepared by the supplier or created in MachineMaker. <a class="external-link" href="https://docs.encycam.com/MachineMaker/1/robots/en/1.html">See more</a></p></li>
</ul>
<p><strong>In MachineMaker, use «Save assembly to file» to save the assembly.</strong></p>
<p><img alt="New project page with Create in MachineMaker and Load .mma file options" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697466/new-project-2026-09-16.png" width="800"/></p>
<p>The <strong>Back to projects</strong> button in the lower-left corner of the main area returns you to the project library.</p>
<p><strong>Profile.</strong> Opens the user profile. Depending on the system configuration, some features may be unavailable to certain user roles. If a feature is grayed out or missing, your user role may not have the required permissions.</p>
<p><strong>Help.</strong> Opens a page with two options:</p>
<ul>
<li><p><strong>Tutorials.</strong> Opens the page with ENCY Hyper training videos.</p></li>
<li><p><strong>Documentation.</strong> Opens the reference documentation.</p></li>
</ul>
<p><img alt="Help page with Tutorials and Documentation options" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697466/help-2026-09-16.png" width="800"/></p>
<p><strong>Button at the bottom of the left navigation panel.</strong></p>
<p><strong>Theme.</strong> Switches the interface between light and dark themes.</p>
<p><img alt="Theme button at the bottom of the left navigation panel" class="confluence-embedded-image manual-image manual-screenshot" src="images/download/attachments/150697466/theme-2026-09-16.png" width="110"/></p>
<p><strong>License and version information.</strong></p>
<p><strong>License information.</strong> Displays the remaining number of days on your license.</p>
<p><strong>Version info.</strong> This information may be useful when demonstrating the app’s capabilities to others or when contacting technical support.</p>
