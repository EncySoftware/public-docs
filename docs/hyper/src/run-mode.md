<h1 class="heading"><span>Application Area:</span></h1>
<p> <span style="color: #000000;">
The <strong class="">Run</strong> tab is responsible for launching the already generated robot program.<br/> </span>
</p>
<p><strong class="">Time.</strong> Indicates the total execution time of the program.</p>
<p><strong class="">Information window.</strong> Displays what is currently being executed in your program.</p>
<p><strong class="">Parts information window</strong>. This window displays information about the number of parts and how many of them have been processed.</p>
<p><strong class="">Speed slider.</strong> When starting the program using the large Start button, the speed must be adjusted using this slider. It affects the movement speed of the mechanisms.</p>
<p>The <strong class="">Start</strong>,<strong class=""> End</strong>, and other icons at the bottom indicate which command is currently being executed when the program is running.</p>
<div class="section section-2" id="src-150697599_id-.RunModev1-Programcontrolbuttons.">
<h2 class="heading"><span>Program control buttons.</span></h2>
<p><strong class="">Start.</strong> Launches the program you created on the Programming tab.</p>
<p><strong class="">Pause.</strong> Pauses the program.</p>
<p><strong class="">Resume.</strong> Resumes the program.</p>
<p><strong class="">Stop.</strong> Completely stops the program and resets it to the initial position.</p>
<p>Monitoring mode. This mode hides interface elements and allows you to manually adjust the robot and see the changes on your screen. It is enabled when you are already connected to your robot and online.</p>
