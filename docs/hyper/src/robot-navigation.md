<p><strong class="">Application Area:</strong></p>
<p>Allows moving the robot in space in various ways.</p>
<div class="section section-1" id="src-150697591_id-.Thenavigationforrobotmovementinspacev1-JointMode.">
<h1 class="heading"><span>Joint Mode. </span></h1>
<p>Allows moving the robot by controlling individual axes.</p>
</div>
<div class="section section-1" id="src-150697591_id-.Thenavigationforrobotmovementinspacev1-TCPMode.">
<h1 class="heading"><span>Frame.</span></h1>
<p>Frame mode provides three submodes for positioning the robot: <strong>TCP</strong>, <strong>Base</strong>, and <strong>Point</strong>.</p>
<p><strong>TCP.</strong> Moves the robot relative to the Tool Center Point (TCP) coordinate system.</p>
<p><strong>Base.</strong> Moves the robot relative to the robot base coordinate system.</p>
<p><strong>Point.</strong> Moves the robot to a point selected in the graphics window. Click a point within the robot’s reachable workspace to move the robot to that point.</p>
<p><a href="images/download/attachments/150697591/frame-point-2026-09-16.png" rel="noopener" target="_blank"><img alt="Frame mode with the Point submode selected and a target point on the workpiece" class="confluence-embedded-image manual-image manual-screenshot" src="images/download/attachments/150697591/frame-point-2026-09-16.png" width="500"/></a></p>
</div>
<div class="section section-1" id="src-150697591_id-.Thenavigationforrobotmovementinspacev1-DirectMode.">
<h1 class="heading"><span>Direct Mode.</span></h1>
<p>Operates only when the robot is connected in real‑time mode. The robot can be moved either via remote control or manually.</p>
</div>
<div class="section section-1" id="src-150697591_id-.Thenavigationforrobotmovementinspacev1-Precisionmode">
<h1 class="heading"><span>Precision mode </span></h1>
<p>Сan be enabled for all operating modes. This reduces the movement step to prevent the robot from colliding with obstacles. <img alt="images/download/thumbnails/150697591/image2025-12-16_11-42-38.png" class="confluence-embedded-image confluence-thumbnail manual-image manual-icon" src="images/download/thumbnails/150697591/image2025-12-16_11-42-38.png" width="30"/>
</p>
<p><strong class="">The movement step is set at the bottom as a slider.</strong></p>
</div>
