<div id="ht-wrap-container"><div class="ht-content"><div class="ht-content-header"><h1 id="src-150697452"> <span>License activation</span></h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p><img alt="ENCY Hyper login screen with the admin profile and Open button" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697452/login-screen-2026-09-16.png" width="800"/>
</p>
<p>On the login screen, check the user profile shown under <strong class="">Log in as</strong> (<strong class="">admin</strong> in this example), then click <strong class="">Open</strong> to log in.<br/>ENCY Hyper will detect that you don’t have a license and redirect you to the license activation page. You will need a phone with a camera for this process.</p>
<p><img alt="images/download/attachments/150697452/image2025-11-13_10-21-44.png" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697452/image2025-11-13_10-21-44.png" width="800"/>
</p>
<p>Once you scan the QR code, you will be redirected to the login page. If you don’t have an account, you can create one there.</p>
<p>After logging in, the license activation will start automatically. If your computer is not connected to the internet, you will need to manually enter the received CM code using the <strong class="">Get activation code manually </strong>button.</p>
<p><img alt="images/download/attachments/150697452/1.jpg" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697452/1.jpg" width="271"/>
<img alt="images/download/attachments/150697452/photo_2025-11-13_10-33-59.jpg" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697452/photo_2025-11-13_10-33-59.jpg" width="271"/>
</p>
<p>The license should activate successfully. After clicking the <strong class="">OK</strong> button, the main ENCY Hyper window will launch.</p>
<p><img alt="images/download/attachments/150697452/image2025-11-13_10-27-5.png" class="confluence-embedded-image confluence-content-image-border manual-image manual-screenshot" src="images/download/attachments/150697452/image2025-11-13_10-27-5.png" width="387"/>
</p>
