# Introduction

The CAM system has two independent postprocessing systems now.

1. Postprocessors generator. This is an integrated postprocessor development environment, which has its own format, programming language and debugger.
2. New open postprocessing system based on the [.NET platform](https://dotnet.microsoft.com/), using `C#` as a programming language and [Visual Studio Code](https://code.visualstudio.com/) as an environment of development and code debugger.

Both systems are actual and can be used by your choice.

Here you will find the documentation only for the Postprocessors generator. Documentation for the second (.NET based) system is available [here](../../dotnet/readme-dotnet.md).
