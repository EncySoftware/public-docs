# Quaternion4d

Quaternion – the group of rotations about a fixed point in four-dimensional Euclidean space.

## Parameters

- **cX**, **cY**, **cZ**, **cW**: real – coordinates of quaternion

## Methods

- **Init** – create quaternion object
- **q_mul_q** – get dot product of quaternions
- **q_x_q** – get vector product of quaternions
- **s_x_q** – scale quaternion coordinates
- **q_add_q** – add quaternion
- **q_sub_q** – subtract quaternion
