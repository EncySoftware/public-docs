# The transformation of a mask to the subprogram

The situation is possible then the mask possibility is not enough. To use more powerful and flexible subprograms without manual mask programming, there is the function **Transform the mask to the subprogram**. Use the ![images/download/thumbnails/142668919/image2024-8-21_16-27-43.png](../../images/download/thumbnails/142668919/image2024-8-21_16-27-43.png) button to transform the mask. The button is located near the mask switches.

To undo the transformation it is necessary to move by clipboard the mask line from the subprogram editor to the mask editor and to set the switches.
