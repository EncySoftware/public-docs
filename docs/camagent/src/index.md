# CAM Agent

CAM Agent is an AI assistant for the CAM system. You control CAM through chat — toolpath
calculation, tool setup, geometry management, NC program generation — while the agent drives
the CAM system for you through a set of dedicated tools.

The assistant works with several AI providers, understands the project that is currently open,
can look at the 3D scene, and reports every action it takes so you can approve or reject it.
