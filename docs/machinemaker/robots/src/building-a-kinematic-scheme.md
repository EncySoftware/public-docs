<div class="section section-1" id="src-131903495_id-.Buildingakinematicschemev18-Kinematics">
<h1 class="heading"><span>Kinematics</span></h1>
<p>MachineMaker shows the current mechanism's 3D model and kinematic scheme. It is necessary to build correct kinematic linkage by specifying connector's positions.</p>
<p><a class="doc-image-link" href="images/download/attachments/131903495/image2022-4-4_11-33-14.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903495/image2022-4-4_11-33-14.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-standard" height="712" src="images/download/attachments/131903495/image2022-4-4_11-33-14.png" style="--doc-image-width:640px" width="1480"/></a>
</p>
<p><a class="doc-image-link" href="images/download/attachments/131903495/image2022-4-4_11-40-48.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903495/image2022-4-4_11-40-48.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-standard" height="746" src="images/download/attachments/131903495/image2022-4-4_11-40-48.png" style="--doc-image-width:640px" width="1315"/></a>

<h2 class="heading"><span>Drag&amp;Drop and snap points</span></h2>
<p>Hold <i class=""><strong class="">Left Ctrl</strong></i><strong class=""> </strong>key to enter Drag&amp;Drop mode. Drag any connector (blue bearing for rotary joints and blue dot for "assemblies"). MachineMaker will show small red snap points nearby. Release mouse button to drop object.</p>

<div class="section section-1" id="src-131903495_id-.Buildingakinematicschemev18-ModelPosition">
<h1 class="heading"><span>Model Position</span></h1>
<p>Use <i class=""><strong class="">Model Position</strong></i><strong class=""> </strong>to set joint values for current position of imported 3D model. These fields allows you to use CAD files of mechanisms, saved in non-zero positions.</p>
<p>For example here is the zero position of Kuka robots:</p>
<p><a class="doc-image-link" href="images/download/attachments/131903495/image2021-5-4_23-35-25.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903495/image2021-5-4_23-35-25.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-standard" height="376" src="images/download/attachments/131903495/image2021-5-4_23-35-25.png" style="--doc-image-width:640px" width="803"/></a>
</p>
<p>But <a class="external-link" href="https://www.kuka.com/en-de/services/downloads">Kuka download center</a> provides only 3D models for non-zero robot position:</p>
<p style="text-align:center;"><a class="doc-image-link" href="images/download/attachments/131903495/image2021-5-4_23-37-37.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903495/image2021-5-4_23-37-37.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="713" src="images/download/attachments/131903495/image2021-5-4_23-37-37.png" style="--doc-image-width:640px" width="753"/></a>
</p>
<p>So we can just specify <i class=""><strong class="">Model Position</strong></i><strong class=""> </strong>values and use 3D models provided by Kuka. It is not necessary to change them on CAD system.</p>
<p><a class="doc-image-link" href="images/download/attachments/131903495/image2023-10-25_15-1-43.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903495/image2023-10-25_15-1-43.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-standard" height="501" src="images/download/attachments/131903495/image2023-10-25_15-1-43.png" style="--doc-image-width:640px" width="692"/></a>
</p>
<p><i class=""><strong class="">Model Position</strong></i> function is also useful for mechanisms with linear axes. For example, when editing rail limits.</p>
