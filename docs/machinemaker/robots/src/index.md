<p>MachineMaker is a standalone application which allows you to create robot cells and CNC machines for CAM system.<br/><br/>Latest version of MachineMaker carries robots from the following OEMs: ABB, Annin, AUBO, Borunte, Comau, Dobot, Doosan, Efort, Eidos, Epson, EVS, Fanuc, Han's, Hyundai, IIMT, Jaka, Kuka, Kawasaki, LNC, Mitsubishi, Motoman, Nachi, Newker, Regal, Siasun, Staubli, STEP, Tormach, uFactory, Universal, Simple.<br/><br/>You can launch MachineMaker directly from the CAM system utilities menu.</p>
