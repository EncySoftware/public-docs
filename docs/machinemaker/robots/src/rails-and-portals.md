<p>MachineMaker allows you to add linear rails, 2-axes portals and 3-axes portals.</p>
<p>It is possible to add any number of connectors to the table using<strong class=""> <img alt="images/download/attachments/131903688/image2022-4-5_15-45-7.png" class="confluence-embedded-image doc-inline" src="images/download/attachments/131903688/image2022-4-5_15-45-7.png" style="--doc-image-width:16px"/>
</strong>button in the <i class=""><strong class="">User</strong></i> <i class=""><strong class="">Coordinate Systems</strong></i><strong class=""> </strong>panel. Use <img alt="images/download/attachments/131903688/image2022-4-5_15-45-32.png" class="confluence-embedded-image doc-inline" src="images/download/attachments/131903688/image2022-4-5_15-45-32.png" style="--doc-image-width:19px"/>
 button to delete the connector. Use double click to rename the coordinate system.</p>
<p>MachineMaker will use connectors to connect mechanisms with each other when building "Assemblies".</p>
<p><a class="doc-image-link" href="images/download/attachments/131903688/railgif.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903688/railgif.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="522" src="images/download/attachments/131903688/railgif.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>Click on <i class=""><strong class="">Limits</strong></i><strong class=""> </strong>to specify Min and Max values. MachineMaker will show minimal and maximal positions of the 3D model.</p>
<p>It is possible to change linear axis direction using transformation panel in the right bottom corner.</p>
