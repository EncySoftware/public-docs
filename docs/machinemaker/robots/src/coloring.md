<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-131903745">Coloring</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>By default, MachineMaker uses the 3D model's color. Using the 3D model's colors gives a detailed representation. It is also possible to define the node's (machine element) color manually.</p>
<p><a class="doc-image-link" href="images/download/attachments/131903745/image2021-9-6_16-22-43.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903745/image2021-9-6_16-22-43.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-standard" height="553" src="images/download/attachments/131903745/image2021-9-6_16-22-43.png" style="--doc-image-width:537px" width="537"/></a>
</p>
<p>Use the <i class=""><strong class="">Style</strong></i><strong class=""> </strong>tab to open the Color parameters. You can select a predefined color set or specify node colors manually.</p>
<a class="doc-image-link" href="images/download/attachments/131903745/Coloring_2.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903745/Coloring_2.png" class="confluence-embedded-image image-center doc-image doc-detail" height="498" src="images/download/attachments/131903745/Coloring_2.png" style="--doc-image-width:413px" width="413"/></a>

<i class=""><strong class="">Mouse wheel scroll</strong></i> <span style="color: #333333;">
 with the mouse cursor on the combobox to switch between styles    </span>
</p>
</div>

<p>Select the <i class=""><strong class="">3D Models colors </strong></i>style to reset the colors of all the nodes to the 3D model's values. Select <strong class=""><i class="">Current</i> </strong>style to reset the colors of all the nodes to the saved values.</p>
<p><a class="doc-image-link" href="images/download/attachments/131903745/color.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131903745/color.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/131903745/color.webp" style="--doc-image-width:800px" width="800"/></a>
<br/>Click on the color hex code input field on the right to open the color selector. It is possible to copy and paste hex codes manually.</p>
