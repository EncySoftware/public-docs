<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-129926359">Introduction to MachineMaker</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>MachineMaker is a standalone application which allows you to create robot cells and CNC machines for CAM system.</p>
<p>Latest version of MachineMaker carries robots from the following OEMs: ABB, Annin, AUBO, Borunte, Comau, Dobot, Doosan, Efort, Eidos, Epson, EVS, Fanuc, Han's, Hyundai, IIMT, Jaka, Kuka, Kawasaki, LNC, Mitsubishi, Motoman, Nachi, Newker, Regal, Siasun, Staubli, STEP, Tormach, uFactory, Universal, Simple.</p>
<p>You can launch MachineMaker d    <span style="color: #003366;">
irectly from the CAM system utilities menu.    </span>
