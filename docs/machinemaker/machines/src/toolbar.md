<h1 class="heading"><span>Main menu (1)</span></h1>
<p> <span style="color: #262626;">
<i class=""><strong class="">Main Menu (1)</strong> </i> <span style="color: #262626;">
contains the following items:    </span>
<br/> </span>
</p>
<p><a class="doc-image-link" href="images/download/attachments/128546624/image2024-8-12_12-1-9.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/128546624/image2024-8-12_12-1-9.png" class="confluence-embedded-image image-center doc-image doc-detail" height="443" src="images/download/attachments/128546624/image2024-8-12_12-1-9.png" style="--doc-image-width:440px" width="540"/></a>
</p>
<p><i class=""><strong class="">File</strong></i> opens a submenu for project operations:</p>
<ul class=""><li class=""><p><i class=""><strong class="">New</strong></i><strong class=""> </strong>- create a new project. It is also possible to use <i class=""><strong class="">New (1)</strong></i><strong class=""> </strong>button in the toolbar.</p>
</li><li class=""><p><i class=""><strong class="">Open</strong></i><strong class=""> </strong>- open an existing project. It is also possible to use <i class=""><strong class="">Open (3)</strong></i><strong class=""> </strong>button in toolbar.</p>
</li><li class=""><p><i class=""><strong class="">Open recent</strong></i><strong class=""> </strong>- show latest projects. Keep mouse over <i class=""><strong class="">Open (3)</strong></i><strong class=""> </strong>button to show recent projects.</p>
</li><li class=""><p><i class=""><strong class="">Save</strong></i><strong class=""> </strong>- save current project. MachineMaker will ask for project destination folder when saving the file for the first time. It is also possible to use <i class=""><strong class="">Save (4)</strong></i><strong class=""> </strong>button located in the toolbar.</p>
</li><li class=""><p><i class=""><strong class="">Save as</strong></i><strong class=""> </strong>- save current project to another folder</p>
</li><li class=""><p class="auto-cursor-target"><i class=""><strong class="">Export</strong></i><strong class=""> </strong>- open CAM system with the current Machine. It is also possible to use <i class="">CAM system </i>button located in the toolbar</p>
<div class="confbox admonition admonition-note">
<span class="admonition-icon confluence-information-macro-icon"></span>
<div class="admonition-body">
<p> <span style="color: #333333;">
It is necessary to add a robot to the assembly to save the project    </span>
</p>
</div>
</div>
</li></ul> </div>
<div class="section section-1" id="src-128546624_safe-id-VG9vbGJhci1NZWNoYW5pc21zTGlicmFyeSg1KQ">
<h1 class="heading"><span>Mechanisms Library (5)</span></h1>
<p> <span style="color: #262626;">
Opens a library of mechanisms. The library is categorized into different categories. For robots, milling machines and lathe-milling machines    </span>
</p>
</div>

<p>Use double click on project name to change it. Entered project name will be used by CAM system. It is also possible to change project name in settings panel.</p>

<h1 class="heading"><span>Feedback and help</span></h1>
<p>Use <strong class=""><i class="">Feedback (11)</i> </strong>button to provide your feedback or ask for assistance.</p>
<p><a class="doc-image-link" href="images/download/attachments/128546624/image2024-8-12_12-21-44.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/128546624/image2024-8-12_12-21-44.png" class="confluence-embedded-image image-center doc-image doc-detail" height="550" src="images/download/attachments/128546624/image2024-8-12_12-21-44.png" style="--doc-image-width:440px" width="600"/></a>
