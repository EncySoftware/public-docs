<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-129940383">Tool block</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>The next step is to add two Tool blocks.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-8-13_11-27-32.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-8-13_11-27-32.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-overview" height="878" src="images/download/attachments/129940383/image2024-8-13_11-27-32.png" style="--doc-image-width:800px" width="960"/></a>
</p>
<p>The first to be added is the turning tool. For this purpose it is necessary to paint the upper area of the added model.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-13-2.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-13-2.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="488" src="images/download/attachments/129940383/image2024-4-24_15-13-2.png" style="--doc-image-width:640px" width="813"/></a>
</p>
<p>It is important that the <strong class="">Geometry CS</strong> match the common coordinate system.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-17-41.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-17-41.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="574" src="images/download/attachments/129940383/image2024-4-24_15-17-41.png" style="--doc-image-width:640px" width="726"/></a>
</p>
<p>Select the desired tool type</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-24-16.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-24-16.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-detail" height="453" src="images/download/attachments/129940383/image2024-4-24_15-24-16.png" style="--doc-image-width:433px" width="433"/></a>
</p>
<p>On the Tool point tab, position the tool as shown in the picture:</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-26-23.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-26-23.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="615" src="images/download/attachments/129940383/image2024-4-24_15-26-23.png" style="--doc-image-width:640px" width="844"/></a>
</p>
<p>Add a second Tool block and paint the lower part of the model. Select the type of Mill tool.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-34-18.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-34-18.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="574" src="images/download/attachments/129940383/image2024-4-24_15-34-18.png" style="--doc-image-width:640px" width="885"/></a>
</p>
<p>On the Tool point tab, position the tool as shown in the picture:</p>
<p><a class="doc-image-link" href="images/download/attachments/129940383/image2024-4-24_15-40-3.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940383/image2024-4-24_15-40-3.png" class="confluence-embedded-image confluence-content-image-border doc-image doc-standard" height="459" src="images/download/attachments/129940383/image2024-4-24_15-40-3.png" style="--doc-image-width:640px" width="784"/></a>
</p>
<p>Then click apply and this is the end of adding two tool blocks.</p>
