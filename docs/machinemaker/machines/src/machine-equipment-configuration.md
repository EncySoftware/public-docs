<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-129940438">Machine equipment configuration</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>At the very beginning, before adding the machine equipment, we should prepare our machine and add the attachment points for our machine equipment.</p>
<p>To add connection points, click the plus button in the kinematics tab when editing your machine and select the desired connection.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_12-24-32.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_12-24-32.png" class="confluence-embedded-image image-center doc-image doc-overview" height="820" src="images/download/attachments/129940438/image2024-2-1_12-24-32.png" style="--doc-image-width:800px" width="1033"/></a>
</p>
<p>After that, in the kinematics tree, you need to attach the points to the desired axis and position them on the machine.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_12-27-55.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_12-27-55.png" class="confluence-embedded-image image-center doc-image doc-overview" height="820" src="images/download/attachments/129940438/image2024-2-1_12-27-55.png" style="--doc-image-width:800px" width="1033"/></a>
</p>
<p>You can download examples of machine and machine equipment here:</p>
<ol class=""><li class=""><p><a href="https://github.com/EncySoftware/public-docs/releases/download/machinemaker-examples-2026-09-22/Machine_equipment_1-6623c43908.rar">Machine equipment 1.rar</a></p>
</li><li class=""><p><a href="https://github.com/EncySoftware/public-docs/releases/download/machinemaker-examples-2026-09-22/Machine_equipment_2-e22c4bff05.rar">Machine equipment 2.rar</a></p>
</li><li class=""><p><a href="https://github.com/EncySoftware/public-docs/releases/download/machinemaker-examples-2026-09-22/Milling_machine-62966e00df.rar">Milling machine.rar</a></p>
</li></ol><p>Machine equipment has 2 types of axles:<br/>1) Rotary type;<br/>2) Linear type.</p>
<p>In this chapter we will briefly look at the settings of these two types</p>
<p>To add machine equipment use the <strong class="">"Add Mechanism"</strong> button.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-8-13_11-42-28.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-8-13_11-42-28.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-detail" height="371" src="images/download/attachments/129940438/image2024-8-13_11-42-28.png" style="--doc-image-width:440px" width="538"/></a>
</p>
<p>After importing machine equipment, select the appropriate template. Also mark the machine equipment elements with the correct color.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_12-18-28.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_12-18-28.png" class="confluence-embedded-image image-center doc-image doc-overview" height="820" src="images/download/attachments/129940438/image2024-2-1_12-18-28.png" style="--doc-image-width:800px" width="1033"/></a>
</p>
<p>Additionally, if necessary, correctly set the point through the Base CS edit mode to ensure that the machine equipment is properly secured on the machine in the future.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_12-38-12.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_12-38-12.png" class="confluence-embedded-image image-center doc-image doc-overview" height="844" src="images/download/attachments/129940438/image2024-2-1_12-38-12.png" style="--doc-image-width:800px" width="1004"/></a>
</p>
<p>In the <strong class="">Kinematic</strong> settings, it is important to correctly set the rotary axis.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/Machine_equipment1.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/Machine_equipment1.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/129940438/Machine_equipment1.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>It's also crucial to provide the correct coordinates for the jaws.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/Machine_equipment2.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/Machine_equipment2.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/129940438/Machine_equipment2.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>In the <strong class="">Style</strong> mode, you can adjust colors to match the machine or choose a custom color.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/Machine_equipment3.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/Machine_equipment3.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/129940438/Machine_equipment3.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>After all settings have been applied, you will need to position the machine equipment on the previously set point.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-8-13_11-43-39.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-8-13_11-43-39.png" class="confluence-embedded-image image-center doc-image doc-overview" height="844" src="images/download/attachments/129940438/image2024-8-13_11-43-39.png" style="--doc-image-width:800px" width="1004"/></a>
</p>
<p>In the second case, let's consider an example of machine equipment with a linear axis. The settings are straightforward. You need to select the appropriate template and configure the motion coordinates of the linear axis.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_12-55-22.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_12-55-22.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="773" src="images/download/attachments/129940438/image2024-2-1_12-55-22.png" style="--doc-image-width:800px" width="973"/></a>
</p>
<p>Also, if necessary, it is advisable to correctly set the point through the Base CS edit mode so that the machine equipment is securely attached to the machine in the future.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/Machine_equipment4.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/Machine_equipment4.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/129940438/Machine_equipment4.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>The setting of the linear type is the same as that of the rotary type. You must also set the jaw movement limits.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/image2024-2-1_13-1-40.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/image2024-2-1_13-1-40.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="906" src="images/download/attachments/129940438/image2024-2-1_13-1-40.png" style="--doc-image-width:800px" width="1141"/></a>
</p>
<p>In simulation mode, check that everything is working correctly.</p>
<p><a class="doc-image-link" href="images/download/attachments/129940438/MachineEquipment5.webp" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/129940438/MachineEquipment5.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-overview" height="636" src="images/download/attachments/129940438/MachineEquipment5.webp" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>In the end it was possible to assemble a machine with two machine equipment.</p>
