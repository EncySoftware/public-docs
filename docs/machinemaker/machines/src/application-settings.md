<p>Settings panel can be opened from Main menu.<a class="doc-image-link" href="images/download/attachments/128546673/image2024-8-12_12-23-22.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/128546673/image2024-8-12_12-23-22.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image doc-detail" height="598" src="images/download/attachments/128546673/image2024-8-12_12-23-22.png" style="--doc-image-width:440px" width="529"/></a>
<span style="color: #2c2c2c;">
General    </span>
</p>
<ul class=""><li class=""><p><i class=""><strong class="">Language.</strong></i> MachineMaker uses CAM system language by default but it is possible to change it here.<i class=""><strong class=""><br/></strong></i></p>
</li><li class=""><p><i class=""><strong class="">Visualization quality.</strong></i> Reduce quality if you have any problems with video memory or MachineMaker does not work smoothly enough. We recommend keeping High quality.</p>
</li><li class=""><p><i class=""><strong class="">CAM-system path.</strong></i><strong class=""> </strong>MachineMaker detects installed CAM system automatically. But it is also possible to specify CAM-system path here.<i class=""><strong class=""><br/></strong></i></p>
</li><li class=""><p><i class=""><strong class="">Constrained rotate</strong></i><strong class=""> </strong>mode allows fixing Z axis during rotation. It is also possible to change this parameter from "Toolbar".</p>
</li><li class=""><p><i class=""><strong class="">Inverse mouse wheel zoom direction.</strong></i><strong class=""> </strong>Change this parameter to inverse zoom behavior on mouse scroll.</p>
</li><li class=""><p><i class=""><strong class="">Simplify CAD models</strong></i><strong class=""> </strong>allows you to reduce 3D model size. See "Prepare 3D models" page for details.</p>
</li><li class=""><p><i class=""><strong class="">Auto Align.</strong></i> MachineMaker will automatically go through the imported 3D models and try to find optimal position for each new mechanism in assembly.</p>
</li></ul>
