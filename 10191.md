# Ciclo de deslocamento (ISO G73)

O ciclo de deslocamento gera o ciclo fixo G73 com base no perfil definido. Os parâmetros do ciclo podem ser definidos na janela de propriedades.

![images/download/attachments/157865332/image2024-7-15_15-39-19.png](assets/images/download/attachments/157865332/image2024-7-15_15-39-19.png)

Se a caixa de seleção "Finish pass" estiver marcada, o ciclo de acabamento ISO G70 será gerado logo após o ciclo de desbaste.

O extrato do manual do operador Fanuc sobre o ciclo G73 é mostrado abaixo.

Esse recurso permite executar a usinagem repetida ao longo de um contorno, deslocando o contorno gradualmente. Com esse ciclo de corte, é possível usinar com eficiência um bruto cuja forma aproximada já foi obtida por desbaste, forjamento, fundição etc.
