# Maschine für den erweiterten Werkzeugmodus anpassen

## Anwendungsbereich:

Ob der erweiterte Werkzeugmodus verfügbar ist, hängt vom verwendeten Maschinenschema ab. Ein Schema im klassischen Format kann Werkzeugbaugruppen nicht direkt verwenden und muss zunächst angepasst werden.

Die Anpassung erfolgt über **Adapt machine for advanced tools** im Werkzeugmenü. Der Befehl ist verfügbar, solange das aktive Maschinenschema noch nicht angepasst wurde. Dabei entsteht eine Maschinenbibliothek (**Machine Kit**). Ihre Datei liegt neben der Maschinenschemadatei und enthält einen besonderen Komponententyp: das Magazin. Dieses besitzt Aufnahmeanschlüsse eines festgelegten Verbindungstyps, aber keinen eigenen Einsteckanschluss.

![images/download/attachments/162961507/adapt-machine.png](assets/images/download/attachments/162961507/adapt-machine.png)

Nach der Anpassung öffnet sich **Component libraries**. Das Fenster enthält bereits die Maschinenknoten als Magazinkomponenten mit den Befestigungspunkten für Werkzeugbaugruppen. Anfangs besitzt ein Knoten eine Standardverbindung, im Beispiel **Cylindrical tool connection**. Diese erscheint unter **Connections** und ist dem Knoten als **Support (Z)** zugewiesen.

![images/download/attachments/162961507/image2026-8-11_15-31-51.png](assets/images/download/attachments/162961507/image2026-8-11_15-31-51.png)

**Verbindung zuweisen.** Eine Verbindung muss nicht über die Plus-Schaltfläche ausgewählt werden. Ihr Name kann direkt in das Verbindungsfeld eingegeben werden. Wählen Sie einen vorgeschlagenen Wert aus oder geben Sie einen neuen Namen ein. Bei einem neuen Namen wird ein neuer Verbindungstyp angelegt.

Wird eine Verbindung aus der Bibliothek gewählt, werden ihre normgerechten Abmessungen berücksichtigt.

![images/download/attachments/162961507/image2026-8-11_15-56-40.png](assets/images/download/attachments/162961507/image2026-8-11_15-56-40.png) ![images/download/attachments/162961507/image2026-8-11_15-58-18.png](assets/images/download/attachments/162961507/image2026-8-11_15-58-18.png) ![images/download/attachments/162961507/image2026-8-11_15-58-59.png](assets/images/download/attachments/162961507/image2026-8-11_15-58-59.png)

> Hinweis
>
> Beim Schließen des Fensters wird neben der Maschinendatei eine **.mKIT**-Datei mit den Einrichtungsdaten erstellt. Sie enthält alle dieser Maschine zugeordneten Werkzeuge.

Zum Zurückkehren in den klassischen Werkzeugmodus wählen Sie im selben Menü **Activate classic tools**.
