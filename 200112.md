# Adattamento di una macchina alla modalità utensili avanzata.

## Ambito di applicazione:

La possibilità di passare alla modalità avanzata dipende dallo schema della macchina in uso. Uno schema di macchina nel vecchio formato (classico) non può lavorare direttamente con i gruppi utensile: deve prima essere adattato al nuovo formato.

L'adattamento viene eseguito con il comando <strong>Adapt machine for advanced tools</strong> (adatta la macchina per utensili avanzati), disponibile nel menu degli utensili quando lo schema attivo della macchina non è ancora stato adattato. Durante l'adattamento viene creata una <strong>libreria della macchina (machine kit)</strong>. Il file del <strong>machine kit</strong> si trova sempre accanto al file dello <strong>schema della macchina</strong> e contiene un tipo speciale di componente: il magazzino utensili (un componente che dispone di alloggiamenti con un tipo di collegamento specificato e privo di spina).

![images/download/attachments/162961507/adapt-machine.png](assets/images/download/attachments/162961507/adapt-machine.png)

Dopo l'adattamento della macchina si apre la finestra Component libraries (librerie di componenti). Essa contiene già i nodi della macchina (componenti magazzino) che ospitano il punto di montaggio del gruppo utensile. Inizialmente un nodo della macchina ha un collegamento standard, in questo caso un collegamento Cylindrical tool (utensile cilindrico), mostrato sotto Connections (collegamenti) e assegnato come collegamento Support (Z) del nodo.

![images/download/attachments/162961507/image2026-8-11_15-31-51.png](assets/images/download/attachments/162961507/image2026-8-11_15-31-51.png)

<strong>Assegnazione di un collegamento.</strong> Non è necessario richiamare un collegamento dal menu tramite il pulsante +. Il suo nome può essere digitato direttamente nel campo del collegamento. Il valore può essere scelto tra le opzioni proposte oppure definito come nuovo. Dopo aver inserito un nuovo nome nel campo, viene creato un nuovo tipo di collegamento.

Se un collegamento viene selezionato dalla libreria, tutte le sue dimensioni vengono prese in considerazione in conformità allo standard

> Nota
>
> Alla chiusura della finestra viene creato accanto alla macchina un file *<strong>.mKIT</strong>, il file di configurazione. Questo file contiene tutti gli utensili associati a quella macchina.

Il ritorno alla <strong>modalità classica</strong> si esegue dallo stesso menu con il comando <strong>Activate classic tools</strong> (attiva utensili classici).
