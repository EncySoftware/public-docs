## Área de aplicação:

A ferramenta Extrair isolinhas extrai isolinhas de uma superfície. Ela é ativada após a seleção de uma face na <strong>Model tab</strong>. O painel de edição permite criar um spline, alterar a direção da isolinha ou dividir a face. Use a <strong>Measure tool</strong> para posicionar o spline com precisão.

- ![images/download/thumbnails/157860026/Add_spline_24.png](assets/images/download/thumbnails/157860026/Add_spline_24.png) para formar um spline a partir da isolinha.

![images/download/attachments/157860026/image2026-4-14_9-10-29.png](assets/images/download/attachments/157860026/image2026-4-14_9-10-29.png) ![images/download/attachments/157860026/image2026-4-14_9-10-11.png](assets/images/download/attachments/157860026/image2026-4-14_9-10-11.png)

- ![images/download/thumbnails/157860026/Change_direction_24.png](assets/images/download/thumbnails/157860026/Change_direction_24.png) para alterar a direção de uma isolinha.

- ![images/download/thumbnails/157860026/Split_faces_24.png](assets/images/download/thumbnails/157860026/Split_faces_24.png) para dividir uma face em duas, preservando ou não a face comum (não dividida).

- Use a <strong>Measure tool</strong> para definir o spline com precisão. Você pode mover o ponto para qualquer local da peça para vinculá-lo a uma posição específica. Depois que o ponto final estiver ancorado, você poderá modificar a posição do spline.
