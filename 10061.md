## Anwendungsbereich:

**Extract isolines** erzeugt Isolinien aus einer Fläche. Die Funktion wird verfügbar, sobald auf **Model** eine Fläche ausgewählt ist. Im Bearbeitungspanel können daraus Splines erstellt, die Isolinienrichtung gewechselt oder Flächen geteilt werden. Das Messwerkzeug ermöglicht eine genaue Positionierung des Splines.

- ![Spline erzeugen](assets/images/download/thumbnails/157860026/Add_spline_24.png) Erstellt einen Spline aus der Isolinie.

![images/download/attachments/157860026/image2026-4-14_9-10-29.png](assets/images/download/attachments/157860026/image2026-4-14_9-10-29.png) ![images/download/attachments/157860026/image2026-4-14_9-10-11.png](assets/images/download/attachments/157860026/image2026-4-14_9-10-11.png)

- ![Richtung wechseln](assets/images/download/thumbnails/157860026/Change_direction_24.png) Wechselt die Isolinienrichtung.

![images/download/attachments/157860026/image2026-4-14_9-12-5.png](assets/images/download/attachments/157860026/image2026-4-14_9-12-5.png) ![images/download/attachments/157860026/image2026-4-14_9-12-35.png](assets/images/download/attachments/157860026/image2026-4-14_9-12-35.png)

- ![Fläche teilen](assets/images/download/thumbnails/157860026/Split_faces_24.png) Teilt eine Fläche in zwei Teilflächen. Die ursprüngliche ungeteilte Fläche kann wahlweise erhalten bleiben.

![images/download/attachments/157860026/image2026-4-14_9-14-9.png](assets/images/download/attachments/157860026/image2026-4-14_9-14-9.png) ![images/download/attachments/157860026/image2026-4-14_9-13-24.png](assets/images/download/attachments/157860026/image2026-4-14_9-13-24.png)

- Mit dem Messwerkzeug kann die Splineposition präzise festgelegt werden. Verschieben Sie den Referenzpunkt auf eine gewünschte Stelle des Bauteils und binden Sie ihn dort an. Anschließend kann die Splineposition relativ dazu angepasst werden.
