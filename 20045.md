# Empfehlungen für Fehlerberichte

Prüfen Sie vor einem Fehlerbericht, ob die aktuelle Version des CAM-Systems verwendet wird.

Aktualisieren Sie das System gegebenenfalls zuerst.

Tritt das Problem auch in der aktuellen Version auf, sind möglichst vollständige Informationen hilfreich.

Eine nachvollziehbare Beschreibung erleichtert die Fehlerbehebung und vermeidet zusätzliche Rückfragen.

<a id="die-beste-praxis-für-fehlerberichte-besteht-also-darin"></a>

## Inhalt eines Fehlerberichts

- Aktualisieren Sie zunächst das CAM-System.
- Beschreiben Sie das Problem und die Schritte, mit denen es auftritt.
- Fügen Sie aussagekräftige Screenshots hinzu.
- Ergänzen Sie bei Bedarf eine Bildschirmaufnahme. Größere Dateien können über einen Cloud-Speicher mit Downloadlink bereitgestellt werden.
- Fügen Sie nach Möglichkeit Projekt und Protokolle bei. Bei einem direkt im Programm erstellten Ticket werden diese automatisch angehängt.

Prüfen Sie anschließend Ihre E-Mails auf Rückfragen des Supports.
