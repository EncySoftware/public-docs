# Bug report best practice

Before making a bug report, make sure that you are using the available latest CAM system version.

If not, update first.

If the problem occurs with the latest version, then giving is as much information as possible is highly appreciated.

More info means more probability that we will be able to fix the problem. And avoid time waste on the email correspondence.

## So, bug report best practice consists of:

- Update CAM system first!
- Text description of the problem: what exactly it is, and what steps lead to its occurrence.
- Screenshots showing the problem.
- Video screencast (if screencast is large, use Google Docs, Dropbox or any other cloud storage service and provide a URL)
- Attach CAM system project and logs if possible (attached automatically when creating a ticket from the program window).

Check your email from time to time. If we need additional information, the service desk will send you a notification.
