# AI providers and your own model server

CAM Agent can use CAM GPT, a provider account or API key, or your own model server.
Select the provider and model in the CAM Agent toolbar. The sign-in screen has
**Claude**, **Codex**, **Qwen**, **DeepSeek**, **Gemini**, **Kimi**, and **Router** tabs.

In the settings, the model connection section shows the current provider and its
fields. The button for changing the connection saves the settings and opens the
sign-in screen. The other providers control displays the remaining providers' fields.

## Providers

| Provider | Connection |
|---|---|
| CAM GPT | The default provider, first in the list. Uses the CAM system account; no personal API key is required. |
| Claude | Browser sign-in with **Continue with Claude**, or an API key from `console.anthropic.com`. |
| OpenAI (Codex) | The **Codex** tab offers **Continue with Codex** for browser sign-in, or an API key from `platform.openai.com`. |
| DeepSeek | Browser sign-in with **Continue with DeepSeek**, or an API key from `platform.deepseek.com`. |
| Qwen | An Alibaba Cloud Model Studio (DashScope) API key. Keys from any region are accepted; the region is detected during validation. Qwen OAuth sign-in closed on April 15, 2026. |
| Gemini | An API key from `aistudio.google.com/apikey`. Free Google sign-in has ended. Gemini Flash is available on the free tier. |
| Kimi | A Moonshot Open Platform key from `platform.kimi.ai`, or a Kimi Code subscription key. |
| Router | Your own model server; see the instructions below. |

Provider API keys are validated before saving. They are stored locally in
`%APPDATA%\CamAgent3\settings.json`, encrypted for the Windows user account.

## Your own model server (Router)

Router connects CAM Agent to a server with an Anthropic-compatible or
OpenAI-compatible API. This can be an organization's model router, LiteLLM, vLLM,
Ollama, or a similar server running on your own hardware or in your chosen cloud.
Connection by server address and key is available from version 3.0.17-dev.4.

### Connect from the sign-in screen

1. Open the **Router** tab.
2. Enter the server address. It usually ends in `/v1`. For example, an Ollama server
   on the same computer may use `http://localhost:11434/v1`.
3. Enter the key if the server requires one. Leave it empty for a server that does
   not require a key.
4. Connect. CAM Agent detects the server API and displays a connection confirmation,
   identifying the OpenAI API when applicable. The server's models become available
   in the model selector.

The localhost address is an example; this connection has not been tested in CAM Agent.

### Import a configuration block

Instead of entering the address and key separately, use the configuration block
option on the **Router** tab to paste an Anthropic-compatible API server configuration.
The following formats are accepted:

- A Claude Code `settings.json` document with an `env` section.
- An `env` object without the surrounding document.
- Lines in `KEY=value` format.

The block supplies these values:

| Variable | Purpose |
|---|---|
| `ANTHROPIC_BASE_URL` | Server address. Required. |
| `ANTHROPIC_AUTH_TOKEN` or `ANTHROPIC_API_KEY` | Server key. Required when importing a block. |
| `ANTHROPIC_MODEL`, `ANTHROPIC_DEFAULT_OPUS_MODEL`, `ANTHROPIC_DEFAULT_SONNET_MODEL`, `ANTHROPIC_DEFAULT_HAIKU_MODEL` | Models for the selector, in this order. |

A block without an address or key is rejected. For a server without a key, use the
address fields instead. Replace the placeholders in this example with your values:

```json
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://models.example.com",
    "ANTHROPIC_AUTH_TOKEN": "<your key>",
    "ANTHROPIC_MODEL": "<model identifier>"
  }
}
```

### Configure Router in the settings

Open the model connection section of the settings, then the Router server fields.
If another provider is current, expand the other providers' fields.

- **Address.** The server address, usually ending in `/v1`.
- **Key.** The key required by the server.
- **Models.** One model identifier per line, exactly as returned by the server.
  If empty, CAM Agent requests the list from the server.
- **Check.** Detects the server API and fills in the models. The result identifies
  the API, reports the number of models, and asks you to save the settings.
- **Save.** Saves the connection settings.

Expand the configuration import options to paste a block and fill the fields,
or import the local Claude CLI configuration from `~/.claude-router/settings.json`
or `~/.claude/settings.json`. These import actions only fill the fields; click
**Save** to retain the changes.

### Connection errors

When the server refuses a request, the chat reports the error:

- **401.** The key was not accepted. Check it in the settings or paste the
  configuration block again.
- **403.** Access is denied.
- **429.** The limit has been reached. Try again later.

You can also select another provider in the toolbar.

## Organization settings (Group Policy)

Administrators can configure CAM Agent for all users through Group Policy.
Settings are read from `HKLM\SOFTWARE\Policies\Ency Software\CamAgent`, followed
by `HKCU\SOFTWARE\Policies\Ency Software\CamAgent`. When both define the same
value, HKLM takes precedence. Managed settings are marked as set by your organization.

| Value | Type | Effect |
|---|---|---|
| `Enabled` | DWORD | `0` prevents CAM Agent from starting and displays a message that the organization disabled it. |
| `AllowedProviders` | List | Available providers: `camgpt`, `claude`, `router`, `openai`, `qwen`, `deepseek`, `gemini`, `kimi`. |
| `RouterBaseUrl` | Address | Model server address. Read-only on the sign-in screen; configuration block import is unavailable. Users can enter their own key if the server requires one. |
| `AutoUpdate` | DWORD | Enforces whether automatic update installation is enabled or disabled. |
| `UpdateCheck` | DWORD | `0` disables update checks entirely. |
| `Screenshots` | DWORD | `0` disables screenshots. |
| `AllowedSpeechModes` | List | Speech recognition modes: `local`, `server`, `deepgram`. An empty string disables dictation. |
| `SpeechServerUrl` | Address | Speech recognition server address. |
| `UsageStatistics` | DWORD | `0` disables sending usage statistics. |
| `BugReport` | DWORD | `0` removes the **Report a bug** menu item. |

Lists are comma-separated in `REG_SZ`, or contain one item per line in
`REG_MULTI_SZ`. Values in these lists are case-insensitive.

Run `CamAgent.exe --policy-template <folder>` to generate the Group Policy editor
templates: `CamAgent.admx`, `en-US\CamAgent.adml`, and `ru-RU\CamAgent.adml`.
Run `CamAgent.exe --policy-check` to see which policies were applied.
