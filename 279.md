# NC program files

NC programs are [created](69.md) by the postprocessor by conversion of the machining commands sequence into a sequence of commands for the CNC unit following the rules described in the postprocessor tuning file [(*.sppx)](730.md).

NC code is output by the postprocessor into a standard text file. The name can be defined in the postprocessor before generation. The extension of the output file is defined in the postprocessor tuning file [(*.sppx)](730.md). NC programs for different CNC controls can have different extensions therefore, different tuning files are used.

Transfer of the NC program from the computer, where CAM system is installed, to the CNC unit can be performed by any available method.
