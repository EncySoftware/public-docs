# Arquivos de programas NC

Os programas NC são [criados](69.md) pelo pós-processador por meio da conversão da sequência de comandos de usinagem em uma sequência de comandos para a unidade CNC, seguindo as regras descritas no arquivo de ajuste do pós-processador [(*.sppx)](730.md).

O código NC é gerado pelo pós-processador em um arquivo de texto padrão. O nome pode ser definido no pós-processador antes da geração. A extensão do arquivo de saída é definida no arquivo de ajuste do pós-processador [(*.sppx)](730.md). Os programas NC para diferentes controles CNC podem ter extensões diferentes, portanto, são usados arquivos de ajuste diferentes.

A transferência do programa NC do computador, onde o sistema CAM está instalado, para a unidade CNC pode ser realizada por qualquer método disponível.
