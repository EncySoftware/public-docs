# File dei programmi NC

I programmi NC vengono [creati](69.md) dal postprocessore convertendo la sequenza dei comandi di lavorazione in una sequenza di comandi per il controllo CNC, secondo le regole descritte nel file di configurazione del postprocessore [(*.sppx)](730.md).

Il codice NC viene emesso dal postprocessore in un file di testo standard. Il nome può essere definito nel postprocessore prima della generazione. L'estensione del file di output è definita nel file di configurazione del postprocessore [(*.sppx)](730.md). I programmi NC per controlli CNC diversi possono avere estensioni diverse, per cui vengono utilizzati file di configurazione diversi.

Il trasferimento del programma NC dal computer su cui è installato il sistema CAM al controllo CNC può essere eseguito con qualsiasi metodo disponibile.
