# Durch Seite und Höhe

![images/download/attachments/157860240/image2024-8-8_16-9-29.png](assets/images/download/attachments/157860240/image2024-8-8_16-9-29.png)

Zunächst wird eine Seite des Rechtecks festgelegt, anschließend seine Höhe. Auf diese Weise können Sie Rechtecke im gewünschten Winkel erstellen.

![images/download/attachments/157860240/image2024-8-8_16-11-54.png](assets/images/download/attachments/157860240/image2024-8-8_16-11-54.png)

Sie können auch eine vorhandene Linie auswählen. Die Rechteckseite wird dann von dieser Linie übernommen.
