# Barra degli strumenti e add-in di importazione per SolidEdge™

![images/download/attachments/157859676/SolidEdgeFromAddinManager.png](assets/images/download/attachments/157859676/SolidEdgeFromAddinManager.png)

La barra degli strumenti consente di esportare i dati geometrici da SolidEdge™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859676/SolidEdgeToolbar.png](assets/images/download/attachments/157859676/SolidEdgeToolbar.png)

L'add-in consente di importare i file di progetto <strong>SolidEdge™</strong>.

Estensioni di file supportate: ASM, DFT, PAR, PSM, MDS, PWD, DGN, DXF, DWG, PRT, SAT, STP, STEP, X_B, X_T.

Affinché questa opzione funzioni, l'applicazione richiesta (SolidEdge™) deve essere installata sul computer.
