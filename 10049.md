# Barra de ferramentas e suplemento de importação do SolidEdge™

![images/download/attachments/157859676/SolidEdgeFromAddinManager.png](assets/images/download/attachments/157859676/SolidEdgeFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do SolidEdge™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859676/SolidEdgeToolbar.png](assets/images/download/attachments/157859676/SolidEdgeToolbar.png)

O suplemento permite importar arquivos de projeto do **SolidEdge™**.

Extensões suportadas: ASM, DFT, PAR, PSM, MDS, PWD, DGN, DXF, DWG, PRT, SAT, STP, STEP, X_B, X_T.

O SolidEdge™ deve estar instalado no computador para que o recurso funcione.
