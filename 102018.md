# Caricamento e salvataggio delle macchine in un sistema esterno

Per gestire le macchine con un sistema esterno, aprire la finestra <strong>Parameters</strong> e passare alla scheda <strong>Machines</strong>. Nel pannello superiore di questa scheda sono presenti i pulsanti <strong>Load machine from PLM</strong> e <strong>Save machine to PLM</strong>, che consentono l'interazione con il sistema esterno.

![images/download/attachments/157867824/8.png](assets/images/download/attachments/157867824/8.png)

<a id="loading-a-machine-from-an-external-system"></a>

## Caricamento di una macchina da un sistema esterno

Per caricare una macchina da un sistema esterno, fare clic sul pulsante <strong>Load from PLM</strong>. Nel menu a discesa selezionare <em>[nome della connessione]</em> per aprire una finestra che mostra l'albero degli oggetti disponibili nel sistema esterno.

![images/download/attachments/157867824/9.png](assets/images/download/attachments/157867824/9.png)

Individuare la macchina CAM desiderata espandendo gli oggetti nidificati nell'albero oppure usando la ricerca per nome. Quindi fare clic sul pulsante <strong>Open</strong>.

![images/download/attachments/157867824/10.png](assets/images/download/attachments/157867824/10.png)

La macchina selezionata viene caricata e impostata come macchina attiva nella finestra principale.

![images/download/attachments/157867824/11.png](assets/images/download/attachments/157867824/11.png)

<a id="saving-a-machine-to-an-external-system"></a>

## Salvataggio di una macchina in un sistema esterno

Per salvare una macchina in un sistema esterno, selezionare la macchina da salvare, fare clic sul pulsante <strong>Save to PLM</strong> e scegliere <em>[nome della connessione]</em> dal menu a discesa per aprire una finestra che mostra l'albero degli oggetti disponibili nel sistema esterno.

![images/download/attachments/157867824/12.png](assets/images/download/attachments/157867824/12.png)

Selezionare l'elemento di destinazione in cui salvare i file della macchina. Per sovrascrivere i file esistenti, selezionare la casella di controllo <strong>Overwrite item</strong>, quindi fare clic sul pulsante <strong>Save</strong>.

![images/download/attachments/157867824/13.png](assets/images/download/attachments/157867824/13.png)

Se un elemento della macchina è stato modificato nel sistema esterno, nella finestra principale compare una notifica.

![images/download/thumbnails/157867824/14.png](assets/images/download/thumbnails/157867824/14.png)

Espandere la notifica e fare clic sul pulsante <strong>Update</strong> per caricare la versione aggiornata della macchina.

![images/download/thumbnails/157867824/15.png](assets/images/download/thumbnails/157867824/15.png)

È possibile verificare la presenza di aggiornamenti nella finestra <strong>Parameters</strong> facendo clic con il tasto destro del mouse sulla macchina e selezionando <strong>Check for updates in PLM</strong> dal menu contestuale.
