# Maschinen aus externen Systemen laden und dort speichern

Öffnen Sie **Parameters → Machines**. Die Schaltflächen **Load machine from PLM** und **Save machine to PLM** ermöglichen den Datenaustausch.

![images/download/attachments/157867824/8.png](assets/images/download/attachments/157867824/8.png)

<a id="loading-a-machine-from-an-external-system"></a>

## Maschine laden

Klicken Sie auf **Load from PLM** und wählen Sie die Verbindung. Der Objektbaum des externen Systems wird geöffnet.

![images/download/attachments/157867824/9.png](assets/images/download/attachments/157867824/9.png)

Suchen Sie die Maschine im Baum oder über die Namenssuche und klicken Sie auf **Open**.

![images/download/attachments/157867824/10.png](assets/images/download/attachments/157867824/10.png)

Die Maschine wird geladen und als aktive Maschine im Hauptfenster eingestellt.

![images/download/attachments/157867824/11.png](assets/images/download/attachments/157867824/11.png)

<a id="saving-a-machine-to-an-external-system"></a>

## Maschine speichern

Wählen Sie die Maschine, klicken Sie auf **Save to PLM** und wählen Sie die Verbindung.

![images/download/attachments/157867824/12.png](assets/images/download/attachments/157867824/12.png)

Wählen Sie das Zielelement. Aktivieren Sie bei Bedarf **Overwrite item** und klicken Sie auf **Save**.

![images/download/attachments/157867824/13.png](assets/images/download/attachments/157867824/13.png)

Wird die Maschine im externen System geändert, erscheint im Hauptfenster eine Benachrichtigung.

![images/download/thumbnails/157867824/14.png](assets/images/download/thumbnails/157867824/14.png)

Klappen Sie die Benachrichtigung auf und klicken Sie auf **Update**, um die neue Version zu laden.

![images/download/thumbnails/157867824/15.png](assets/images/download/thumbnails/157867824/15.png)

Alternativ wählen Sie im Kontextmenü der Maschine im Parameterfenster **Check for updates in PLM**.
