# Carregamento e salvamento de máquina em um sistema externo

Para gerenciar máquinas com um sistema externo, abra a janela <strong>Parameters</strong> e acesse a aba <strong>Machines</strong>. No painel superior dessa aba, estão os botões <strong>Load machine from PLM</strong> e <strong>Save machine to PLM</strong>, que permitem interagir com o sistema externo.

![images/download/attachments/157867824/8.png](assets/images/download/attachments/157867824/8.png)

## Carregamento de uma máquina de um sistema externo

Para carregar uma máquina de um sistema externo, clique no botão <strong>Load from PLM</strong>. No menu suspenso, selecione <em>[connection name]</em> para abrir uma janela com a árvore de objetos disponíveis no sistema externo.

![images/download/attachments/157867824/9.png](assets/images/download/attachments/157867824/9.png)

Localize a máquina CAM desejada expandindo os objetos aninhados da árvore ou usando a pesquisa por nome. Em seguida, clique no botão <strong>Open</strong>.

![images/download/attachments/157867824/10.png](assets/images/download/attachments/157867824/10.png)

A máquina selecionada será carregada e definida como a máquina ativa na janela principal.

![images/download/attachments/157867824/11.png](assets/images/download/attachments/157867824/11.png)

## Salvamento de uma máquina em um sistema externo

Para salvar uma máquina em um sistema externo, selecione a máquina que deseja salvar, clique no botão <strong>Save to PLM</strong> e escolha <em>[connection name]</em> no menu suspenso para abrir uma janela com a árvore de objetos disponíveis no sistema externo.

![images/download/attachments/157867824/12.png](assets/images/download/attachments/157867824/12.png)

Selecione o elemento de destino no qual os arquivos da máquina devem ser salvos. Para substituir arquivos existentes, marque a caixa de seleção <strong>Overwrite item</strong> e clique no botão <strong>Save</strong>.

![images/download/attachments/157867824/13.png](assets/images/download/attachments/157867824/13.png)

Se um elemento da máquina for alterado no sistema externo, uma notificação será exibida na janela principal.

![images/download/thumbnails/157867824/14.png](assets/images/download/thumbnails/157867824/14.png)

Expanda a notificação e clique no botão <strong>Update</strong> para carregar a versão atualizada da máquina.

![images/download/thumbnails/157867824/15.png](assets/images/download/thumbnails/157867824/15.png)

Também é possível verificar se há atualizações na janela <strong>Parameters</strong>: clique com o botão direito na máquina e selecione <strong>Check for updates in PLM</strong> no menu de contexto.
