# Beispiel für die Erstellung einer Zeichnung mit Zwangsbedingungen

Als Beispiel dient dieselbe Zeichnung wie zuvor:

![images/download/attachments/157860674/image2024-8-13_17-36-50.png](assets/images/download/attachments/157860674/image2024-8-13_17-36-50.png)

Erstellen Sie zunächst drei Kreise mit Mittelpunkt bei (0; 0) und vorläufigen Radien, die ungefähr den Größenverhältnissen der Zeichnung entsprechen. Zeichnen Sie vom Mittelpunkt aus eine Linie mit vorläufigem Winkel für den Kreis R4. Die genauen Maße werden später eingestellt. Erstellen Sie den Kreis und vervielfältigen Sie ihn durch Drehen um 41°. Legen Sie vorher den Drehmittelpunkt bei (0; 0) fest. Fügen Sie den entstandenen Kreisen Achslinien sowie Winkel- und Radialbemaßungen hinzu:

![images/download/attachments/157860674/image2024-8-14_17-9-39.png](assets/images/download/attachments/157860674/image2024-8-14_17-9-39.png)

Trimmen Sie die überflüssigen Abschnitte:

![images/download/attachments/157860674/image2024-8-14_17-10-45.png](assets/images/download/attachments/157860674/image2024-8-14_17-10-45.png)

Wählen Sie die gesamte Zeichnung mit **Strg+A** (**Ctrl+A**) aus. Ändern Sie den Kreisradius auf 4 und anschließend den Winkel auf 30. Fixieren Sie danach die Winkel der Liniensegmente und die Winkelbemaßungen von 41°. Wählen Sie erneut alle Elemente im Block aus und stellen Sie die Durchmesser gemäß der Zeichnung ein:

![images/download/attachments/157860674/image2024-8-14_17-24-32.png](assets/images/download/attachments/157860674/image2024-8-14_17-24-32.png)

Fixieren Sie die Radien der zuvor erstellten Kreise und der entstandenen Bögen. Verlängern Sie die Kreisachse nach rechts so weit, dass Platz für weitere Konstruktionen bleibt. Erstellen Sie einen zunächst ausreichend großen Kreis mit Mittelpunkt auf dieser Linie, trimmen Sie die überflüssigen Abschnitte und bemaßen Sie ihn:

![images/download/attachments/157860674/image2024-8-14_17-29-16.png](assets/images/download/attachments/157860674/image2024-8-14_17-29-16.png)

Fixieren Sie den Mittelpunkt des Bogens Ø30, fassen Sie die Elementgruppe zu einem Block zusammen und aktivieren Sie darin den neuen Kreis. Fügen Sie im Inspektor auf der Registerkarte **Constraints** die Bedingung **Tangential to the circle** (Tangential zum Kreis) hinzu. Wählen Sie den Abschnitt des Kreises Ø30 aus, stellen Sie den Radius gemäß der Zeichnung ein und fixieren Sie ihn:

![images/download/attachments/157860674/image2024-8-14_17-48-25.png](assets/images/download/attachments/157860674/image2024-8-14_17-48-25.png)

Fixieren Sie bei Bedarf den Mittelpunkt des entstandenen Kreises. Erstellen Sie auf der Achse einen kleinen Kreis mit dem Durchmesser 3,5 und eine lineare Bemaßung vom Nullpunkt zu seinem Mittelpunkt. Stellen Sie im Block das Maß gemäß der Zeichnung ein und fixieren Sie den Mittelpunkt. Erstellen Sie für den Kreis 3,5 eine vertikale Achse und dazu eine Parallele im Abstand von 1,5, um einen Punkt innerhalb eines Bogens mit dem Durchmesser 5,7 festzulegen und dessen Winkel zu fixieren:

![images/download/attachments/157860674/image2024-8-15_16-13-7.png](assets/images/download/attachments/157860674/image2024-8-15_16-13-7.png)

Erstellen Sie vom Nullpunkt aus eine Hilfslinie für das Maß 50,1, passen Sie das Maß an und erstellen Sie einen Hilfskreis mit dem Radius 3,5:

![images/download/attachments/157860674/image2024-8-15_16-18-12.png](assets/images/download/attachments/157860674/image2024-8-15_16-18-12.png)

Erstellen Sie eine vertikale Bemaßung, fixieren Sie den oberen Punkt und stellen Sie das Maß im Block auf 7,2 ein. Erstellen Sie eine Tangente an den Hilfskreis mit Radius 3,5, die die Hilfslinie knapp oberhalb der Achse schneidet. Trimmen Sie die Hilfslinie. Erstellen Sie einen Kreis mit Mittelpunkt im entstandenen Punkt, der durch den Schnittpunkt der Tangente mit der Vertikalen bei 65,4 verläuft. Bemaßen Sie diesen Kreis:

![images/download/attachments/157860674/image2024-8-15_16-25-48.png](assets/images/download/attachments/157860674/image2024-8-15_16-25-48.png)

Stellen Sie im Block den Radius auf 11,71 ein. Erstellen Sie anschließend einen Bogen mit Radius 7, der die Kreise R10,5 und R11,71 tangential berührt, und trimmen Sie die überflüssigen Abschnitte.

![images/download/attachments/157860674/image2024-8-15_16-46-9.png](assets/images/download/attachments/157860674/image2024-8-15_16-46-9.png)

Zum Erstellen der Bögen R5,7 und R0,4 verlängern Sie die geneigte Linie. Erstellen Sie dazu eine Parallele im Abstand von 5,7 und von dieser aus eine weitere im Abstand von 0,8. Verbinden Sie die ersten beiden Linien durch eine Linie und fügen Sie dazwischen einen Bogen ein. Erstellen Sie eine Hilfslinie durch den Mittelpunkt des kleinen Kreises parallel zur dritten Linie. Erstellen Sie dazu eine versetzte Linie und fügen Sie auch hier einen kleinen Bogen ein. Bemaßen Sie die entstandenen Elemente, löschen Sie nicht benötigte Elemente und trimmen Sie überflüssige Abschnitte.

![images/download/attachments/157860674/image2024-8-15_16-56-5.png](assets/images/download/attachments/157860674/image2024-8-15_16-56-5.png)

Fixieren Sie die Winkel der Linien und die im Kreismittelpunkt liegenden Bemaßungspunkte. Ändern Sie die Maße im Block auf die Werte der Zeichnung.

![images/download/attachments/157860674/image2024-8-15_17-14-42.png](assets/images/download/attachments/157860674/image2024-8-15_17-14-42.png)

Trimmen Sie überflüssige Abschnitte oder ändern Sie den Linientyp.

![images/download/attachments/157860674/image2024-8-15_17-17-32.png](assets/images/download/attachments/157860674/image2024-8-15_17-17-32.png)

Verbinden Sie den Bogen R0.4 und den linken Kreis R30 durch einen tangential anschließenden Bogen R50. Trimmen Sie den überflüssigen Abschnitt des Bogens R0.4.

![images/download/attachments/157860674/image2024-8-15_17-23-24.png](assets/images/download/attachments/157860674/image2024-8-15_17-23-24.png)

Erstellen Sie drei äquidistante Bögen zu R50, R10,5 und R30. Fixieren Sie ihre Mittelpunkte, verbinden Sie die Bögen durch passende Übergangsbögen, bemaßen Sie sie und trimmen Sie überflüssige Abschnitte.

![images/download/attachments/157860674/image2024-8-15_17-34-10.png](assets/images/download/attachments/157860674/image2024-8-15_17-34-10.png)

Stellen Sie die Maße im Block gemäß der Zeichnung ein. Stellen Sie zunächst die Radien der großen Bögen ein und fixieren Sie jeden Radius nach der Änderung. Legen Sie anschließend die Verrundungsradien fest:

![images/download/attachments/157860674/image2024-8-15_18-15-50.png](assets/images/download/attachments/157860674/image2024-8-15_18-15-50.png)

Damit ist die gewünschte Zeichnung erstellt.

![images/download/attachments/157860674/image2024-8-13_17-37-1.png](assets/images/download/attachments/157860674/image2024-8-13_17-37-1.png)
