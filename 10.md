# Objektauswahl

Alle sichtbaren Elemente des geometrischen Modells können auf dem Bildschirm ausgewählt werden. Auswählbare Elemente werden hervorgehoben, wenn Sie den Mauszeiger darüber bewegen. Die Auswahl erfolgt durch Klicken mit der linken Maustaste. Im geometrischen Modellbaum ist stets ein Ordner aktiv. Wenn ein geometrisches Objekt ausgewählt wird, wird dessen übergeordneter Ordner automatisch aktiviert. Durch einen Doppelklick mit der linken Maustaste im [Grafikfenster](169.md) wechseln Sie zur übergeordneten Gruppe und damit zur nächsthöheren Ordnerebene. So können Sie direkt im Grafikfenster durch die Modellhierarchie navigieren.

Änderungen an Objekten werden ausschließlich auf ausgewählte Objekte angewendet.

Um einen Teil des Modells oder einzelne Elemente auszuwählen, aktivieren Sie zunächst die Gruppe, die diese geometrischen Objekte oder Gruppen enthält. Wählen Sie anschließend die gewünschten Objekte aus der [Liste der verfügbaren Objekte](718.md) oder im [Grafikfenster](169.md) aus. Für die Auswahl im Grafikfenster muss der [Objektauswahlmodus](325.md) im Dropdown-Menü des Ansichtsfensters aktiviert sein. Alternativ halten Sie während der Auswahl die Taste **S** gedrückt.

Ein Element im Grafikfenster kann durch einen einfachen Klick mit der linken Maustaste oder mithilfe eines rechteckigen Auswahlrahmens ausgewählt werden. Für den Auswahlrahmen drücken Sie die linke Maustaste, halten sie gedrückt und ziehen die Maus. Bei der Auswahl durch Anklicken können in der aktuellen Ansicht mehrere Objekte gleichzeitig ausgewählt werden. Alternativ wählen Sie das Objekt aus der Liste im Modellstrukturfenster aus.

Mit der normalen Auswahlmethode werden Objekte einzeln ausgewählt. Um mehrere Objekte auszuwählen, halten Sie **Strg** (**Ctrl** auf einer englischen Tastatur) gedrückt. Ein noch nicht ausgewähltes Objekt wird dadurch zur Auswahl hinzugefügt; erneutes Anklicken hebt seine Auswahl auf. Wenn Sie stattdessen **Umschalt** (**Shift**) gedrückt halten, werden angeklickte Objekte stets ausgewählt.

Weitere Möglichkeiten zur Mehrfachauswahl:

- Halten Sie **Umschalt** und die linke Maustaste gedrückt und bewegen Sie den Mauszeiger über die gewünschten Objekte.
- Verwenden Sie **Strg + Umschalt + Doppelklick**, um tangential aneinander anschließende Flächen auszuwählen.

Für die Auswahl von Objekten eines bestimmten Typs verwenden Sie den [Objektauswahlfilter](127.md). Dadurch werden nur Objekte des gewünschten Typs im [Modellstrukturfenster](718.md) angezeigt und können im [Grafikfenster](169.md) ausgewählt werden.
