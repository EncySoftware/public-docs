# Text

Creates a text object. Set the text, font and height. **Align** selects **Left** or **Right** alignment.

**Rendering.** **Filled** (default) fills the letters; **Outline** displays only their outlines. The last selected mode is used for new text objects.

**Split complex object into elements** converts each letter and each hole in it into a closed profile made of lines and arcs. The conversion is one undo step. The resulting geometry can be exported to CAM. [Details](20023.md)
