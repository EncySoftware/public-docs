# Scorciatoie da tastiera per lavorare con il testo NC

È supportato il seguente insieme di scorciatoie da tastiera per lavorare con il testo:

| Combinazione di tasti | Azione eseguita |
|---|---|
| ← | Sposta il cursore a sinistra di un carattere |
| → | Sposta il cursore a destra di un carattere |
| ↑ | Sposta il cursore in alto di una riga |
| ↓ | Sposta il cursore in basso di una riga |
| <strong>Ctrl + ←</strong> | Sposta il cursore a sinistra di una parola |
| <strong>Ctrl + →</strong> | Sposta il cursore a destra di una parola |
| <strong>Home</strong> | Sposta il cursore all'inizio della riga |
| <strong>End</strong> | Sposta il cursore alla fine della riga |
| <strong>Page Up</strong> | Sposta il cursore in alto di una pagina |
| <strong>Page Down</strong> | Sposta il cursore in basso di una pagina |
| <strong>Ctrl + Page</strong> <strong>Up</strong> | Sposta il cursore all'inizio della pagina |
| <strong>Ctrl + Page Down</strong> | Sposta il cursore alla fine della pagina |
| <strong>Ctrl + Home</strong> | Sposta il cursore all'inizio assoluto |
| <strong>Ctrl + End</strong> | Sposta il cursore alla fine assoluta |
| <strong>Shift + ←</strong> | Sposta il cursore a sinistra di un carattere selezionando il testo |
| <strong>Shift + →</strong> | Sposta il cursore a destra di un carattere selezionando il testo |
| <strong>Shift + ↑</strong> | Sposta il cursore in alto di una riga selezionando il testo |
| <strong>Shift + ↓</strong> | Sposta il cursore in basso di una riga selezionando il testo |
| <strong>Shift + Ctrl + ←</strong> | Sposta il cursore a sinistra di una parola selezionando il testo |
| <strong>Shift + Ctrl + →</strong> | Sposta il cursore a destra di una parola selezionando il testo |
| <strong>Shift + Home</strong> | Sposta il cursore all'inizio della riga selezionando il testo |
| <strong>Shift + End</strong> | Sposta il cursore alla fine della riga selezionando il testo |
| <strong>Shift + Page Up</strong> | Sposta il cursore in alto di una pagina selezionando il testo |
| <strong>Shift + Page Down</strong> | Sposta il cursore in basso di una pagina selezionando il testo |
| <strong>Shift + Ctrl + Page Up</strong> | Sposta il cursore all'inizio della pagina selezionando il testo |
| <strong>Shift + Ctrl + Page Down</strong> | Sposta il cursore alla fine della pagina selezionando il testo |
| <strong>Shift + Ctrl + Home</strong> | Sposta il cursore all'inizio assoluto selezionando il testo |
| <strong>Shift + Ctrl + End</strong> | Sposta il cursore alla fine assoluta selezionando il testo |
| <strong>Ctrl + A</strong> | Seleziona l'intero contenuto dell'editor, cursore alla fine |
| <strong>Ctrl + C</strong> <strong>Ctrl + Insert</strong> | Copia la selezione negli appunti |
| <strong>Ctrl + ↑</strong> | Scorre in alto di una riga lasciando invariata la posizione del cursore |
| <strong>Ctrl + ↓</strong> | Scorre in basso di una riga lasciando invariata la posizione del cursore |
| <strong>Insert</strong> | Alterna la modalità inserimento/sovrascrittura |
| <strong>Shift + Ctrl + N</strong> | Modalità di selezione normale |
| <strong>Shift + Ctrl + C</strong> | Modalità di selezione a colonna |
| <strong>Shift + Ctrl + L</strong> | Modalità di selezione a righe |
| <strong>Shift + Ctrl + B</strong> | Va alla parentesi corrispondente |
| <strong>Backspace</strong> <strong>Shift + Backspace</strong> | Elimina l'ultimo carattere |
| <strong>Delete</strong> | Elimina il carattere in corrispondenza del cursore |
| <strong>Ctrl + T</strong> | Elimina dal cursore alla fine della parola |
| <strong>Ctrl</strong> <strong>+ Backspace</strong> | Elimina dal cursore all'inizio della parola |
| <strong>Shift + Ctrl + Y</strong> | Elimina dal cursore alla fine della riga |
| <strong>Ctrl + Y</strong> | Elimina la riga corrente |
| <strong>Enter</strong> <strong>Shift + Enter</strong> <strong>Ctrl + M</strong> | Interrompe la riga nella posizione corrente e sposta il cursore sulla nuova riga |
| <strong>Ctrl + N</strong> | Interrompe la riga nella posizione corrente lasciando il cursore dov'è |
| <strong>Ctrl + Z</strong> <strong>Alt + Backspace</strong> | Esegue l'annullamento, se disponibile |
| <strong>Shift + Ctrl + Z</strong> <strong>Shift + Alt + Backspace</strong> | Esegue il ripristino, se disponibile |
| <strong>Ctrl + X</strong> <strong>Shift + Delete</strong> | Taglia la selezione negli appunti |
| <strong>Ctrl + V</strong> <strong>Shift + Insert</strong> | Incolla il contenuto degli appunti nella posizione corrente |
| <strong>Shift + Ctrl + I</strong> | Aumenta il rientro della selezione |
| <strong>Shift + Ctrl + U</strong> | Riduce il rientro della selezione |
| <strong>Tab</strong> | Aggiunge un rientro |
| <strong>Shift + Tab</strong> | Rimuove un rientro |
