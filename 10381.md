# Keyboard shortcuts for working with NC text

The following set of keyboard shortcuts for working with text is supported:

| Key strokes | Perform action |
|---|---|
| ← | Move cursor left one char |
| → | Move cursor right one char |
| ↑ | Move cursor up one line |
| ↓ | Move cursor down one line |
| <strong>Ctrl + ←</strong> | Move cursor left one word |
| <strong>Ctrl + →</strong> | Move cursor right one word |
| <strong>Home</strong> | Move cursor to beginning of line |
| <strong>End</strong> | Move cursor to end of line |
| <strong>Page Up</strong> | Move cursor up one page |
| <strong>Page Down</strong> | Move cursor down one page |
| <strong>Ctrl + Page</strong> <strong>Up</strong> | Move cursor to top of page |
| <strong>Ctrl + Page Down</strong> | Move cursor to bottom of page |
| <strong>Ctrl + Home</strong> | Move cursor to absolute beginning |
| <strong>Ctrl + End</strong> | Move cursor to absolute end |
| <strong>Shift + ←</strong> | Move cursor left one char with text selection |
| <strong>Shift + →</strong> | Move cursor right one char with text selection |
| <strong>Shift + ↑</strong> | Move cursor up one line with text selection |
| <strong>Shift + ↓</strong> | Move cursor down one line with text selection |
| <strong>Shift + Ctrl + ←</strong> | Move cursor left one word with text selection |
| <strong>Shift + Ctrl + →</strong> | Move cursor right one word with text selection |
| <strong>Shift + Home</strong> | Move cursor to beginning of line with text selection |
| <strong>Shift + End</strong> | Move cursor to end of line with text selection |
| <strong>Shift + Page Up</strong> | Move cursor up one page with text selection |
| <strong>Shift + Page Down</strong> | Move cursor down one page with text selection |
| <strong>Shift + Ctrl + Page Up</strong> | Move cursor to top of page with text selection |
| <strong>Shift + Ctrl + Page Down</strong> | Move cursor to bottom of page with text selection |
| <strong>Shift + Ctrl + Home</strong> | Move cursor to absolute beginning with text selection |
| <strong>Shift + Ctrl + End</strong> | Move cursor to absolute end with text selection |
| <strong>Ctrl + A</strong> | Select entire contents of editor, cursor to end |
| <strong>Ctrl + C</strong> <strong>Ctrl + Insert</strong> | Copy selection to clipboard |
| <strong>Ctrl + ↑</strong> | Scroll up one line leaving cursor position unchanged |
| <strong>Ctrl + ↓</strong> | Scroll down one line leaving cursor position unchanged |
| <strong>Insert</strong> | Toggle insert/overwrite mode |
| <strong>Shift + Ctrl + N</strong> | Normal selection mode |
| <strong>Shift + Ctrl + C</strong> | Column selection mode |
| <strong>Shift + Ctrl + L</strong> | Line selection mode |
| <strong>Shift + Ctrl + B</strong> | Go to matching bracket |
| <strong>Backspace</strong> <strong>Shift + Backspace</strong> | Delete last char |
| <strong>Delete</strong> | Delete char at cursor |
| <strong>Ctrl + T</strong> | Delete from cursor to end of word |
| <strong>Ctrl</strong> <strong>+ Backspace</strong> | Delete from cursor to start of word |
| <strong>Shift + Ctrl + Y</strong> | Delete from cursor to end of line |
| <strong>Ctrl + Y</strong> | Delete current line |
| <strong>Enter</strong> <strong>Shift + Enter</strong> <strong>Ctrl + M</strong> | Break line at current position, move caret to new line |
| <strong>Ctrl + N</strong> | Break line at current position, leave caret |
| <strong>Ctrl + Z</strong> <strong>Alt + Backspace</strong> | Perform undo if available |
| <strong>Shift + Ctrl + Z</strong> <strong>Shift + Alt + Backspace</strong> | Perform redo if available |
| <strong>Ctrl + X</strong> <strong>Shift + Delete</strong> | Cut selection to clipboard |
| <strong>Ctrl + V</strong> <strong>Shift + Insert</strong> | Paste clipboard to current position |
| <strong>Shift + Ctrl + I</strong> | Indent selection |
| <strong>Shift + Ctrl + U</strong> | Unindent selection |
| <strong>Tab</strong> | Add indent |
| <strong>Shift + Tab</strong> | Remove indent |
