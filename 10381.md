# Atalhos de teclado para trabalhar com texto NC

Há suporte para o seguinte conjunto de atalhos de teclado para trabalhar com texto:

| Toques de tecla | Executar ação |
|---|---|
| ← | Mover o cursor um caractere para a esquerda |
| → | Mover o cursor um caractere para a direita |
| ↑ | Mover o cursor uma linha para cima |
| ↓ | Mover o cursor uma linha para baixo |
| <strong>Ctrl + ←</strong> | Mover o cursor uma palavra para a esquerda |
| <strong>Ctrl + →</strong> | Mover o cursor uma palavra para a direita |
| <strong>Home</strong> | Mover o cursor para o início da linha |
| <strong>End</strong> | Mover o cursor para o final da linha |
| <strong>Page Up</strong> | Mover o cursor para uma página acima |
| <strong>Page Down</strong> | Mover o cursor para baixo em uma página |
| <strong>Ctrl + Page</strong> <strong>Up</strong> | Mover o cursor para o topo da página |
| <strong>Ctrl + Page Down</strong> | Mover o cursor para a parte inferior da página |
| <strong>Ctrl + Home</strong> | Mover o cursor para o início absoluto |
| <strong>Ctrl + End</strong> | Mover o cursor para o final absoluto |
| <strong>Shift + ←</strong> | Mover o cursor um caractere para a esquerda com a seleção de texto |
| <strong>Shift + →</strong> | Mover o cursor um caractere para a direita com a seleção de texto |
| <strong>Shift + ↑</strong> | Mover o cursor uma linha acima com a seleção de texto |
| <strong>Shift + ↓</strong> | Mover o cursor para baixo em uma linha com a seleção de texto |
| <strong>Shift + Ctrl + ←</strong> | Mover o cursor uma palavra para a esquerda com a seleção de texto |
| <strong>Shift + Ctrl + →</strong> | Mover o cursor uma palavra para a direita com a seleção de texto |
| <strong>Shift + Home</strong> | Mover o cursor para o início da linha com a seleção de texto |
| <strong>Shift + End</strong> | Mover o cursor para o final da linha com a seleção de texto |
| <strong>Shift + Page Up</strong> | Mover o cursor uma página para cima com a seleção de texto |
| <strong>Shift + Page Down</strong> | Mover o cursor para baixo em uma página com seleção de texto |
| <strong>Shift + Ctrl + Page Up</strong> | Mover o cursor para o topo da página com seleção de texto |
| <strong>Shift + Ctrl + Page Down</strong> | Mover o cursor para a parte inferior da página com a seleção de texto |
| <strong>Shift + Ctrl + Home</strong> | Mover o cursor para o início absoluto com a seleção de texto |
| <strong>Shift + Ctrl + End</strong> | Mover o cursor para o final absoluto com a seleção de texto |
| <strong>Ctrl + A</strong> | Selecionar todo o conteúdo do editor, com o cursor no final |
| <strong>Ctrl + C</strong> <strong>Ctrl + Insert</strong> | Copiar seleção para a área de transferência |
| <strong>Ctrl + ↑</strong> | Rolar uma linha para cima, deixando a posição do cursor inalterada |
| <strong>Ctrl + ↓</strong> | Rolar uma linha para baixo, deixando a posição do cursor inalterada |
| <strong>Insert</strong> | Alternar o modo de inserção/sobregravação |
| <strong>Shift + Ctrl + N</strong> | Modo de seleção normal |
| <strong>Shift + Ctrl + C</strong> | Modo de seleção de coluna |
| <strong>Shift + Ctrl + L</strong> | Modo de seleção de linha |
| <strong>Shift + Ctrl + B</strong> | Ir para o colchete correspondente |
| <strong>Backspace</strong> <strong>Shift + Backspace</strong> | Excluir o último caractere |
| <strong>Delete</strong> | Excluir caractere no cursor |
| <strong>Ctrl + T</strong> | Excluir do cursor até o final da palavra |
| <strong>Ctrl</strong> <strong>+ Backspace</strong> | Excluir do cursor até o início da palavra |
| <strong>Shift + Ctrl + Y</strong> | Excluir do cursor até o final da linha |
| <strong>Ctrl + Y</strong> | Excluir a linha atual |
| <strong>Enter</strong> <strong>Shift + Enter</strong> <strong>Ctrl + M</strong> | Quebrar a linha na posição atual e mover o cursor para a nova linha |
| <strong>Ctrl + N</strong> | Quebrar a linha na posição atual, mantendo o cursor |
| <strong>Ctrl + Z</strong> <strong>Alt + Backspace</strong> | Desfazer, se disponível |
| <strong>Shift + Ctrl + Z</strong> <strong>Shift + Alt + Backspace</strong> | Refazer, se disponível |
| <strong>Ctrl + X</strong> <strong>Shift + Delete</strong> | Cortar a seleção para a área de transferência |
| <strong>Ctrl + V</strong> <strong>Shift + Insert</strong> | Colar a área de transferência na posição atual |
| <strong>Shift + Ctrl + I</strong> | Aumentar o recuo da seleção |
| <strong>Shift + Ctrl + U</strong> | Diminuir o recuo da seleção |
| <strong>Tab</strong> | Adicionar recuo |
| <strong>Shift + Tab</strong> | Remover recuo |
