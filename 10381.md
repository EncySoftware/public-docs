# Tastenkombinationen im NC-Texteditor

Der NC-Texteditor unterstützt folgende Tastenkombinationen:

| Tastenkombination | Aktion |
|---|---|
| ← | Cursor um ein Zeichen nach links bewegen |
| → | Cursor um ein Zeichen nach rechts bewegen |
| ↑ | Cursor um eine Zeile nach oben bewegen |
| ↓ | Cursor um eine Zeile nach unten bewegen |
| <strong>Ctrl + ←</strong> | Cursor um ein Wort nach links bewegen |
| <strong>Ctrl + →</strong> | Cursor um ein Wort nach rechts bewegen |
| <strong>Home</strong> | Cursor an den Zeilenanfang bewegen |
| <strong>End</strong> | Cursor an das Zeilenende bewegen |
| <strong>Page Up</strong> | Cursor um eine Seite nach oben bewegen |
| <strong>Page Down</strong> | Cursor um eine Seite nach unten bewegen |
| <strong>Ctrl + Page</strong> <strong>Up</strong> | Cursor an den Anfang der sichtbaren Seite bewegen |
| <strong>Ctrl + Page Down</strong> | Cursor an das Ende der sichtbaren Seite bewegen |
| <strong>Ctrl + Home</strong> | Cursor an den Textanfang bewegen |
| <strong>Ctrl + End</strong> | Cursor an das Textende bewegen |
| <strong>Shift + ←</strong> | Cursor um ein Zeichen nach links bewegen und den Text markieren |
| <strong>Shift + →</strong> | Cursor um ein Zeichen nach rechts bewegen und den Text markieren |
| <strong>Shift + ↑</strong> | Cursor um eine Zeile nach oben bewegen und den Text markieren |
| <strong>Shift + ↓</strong> | Cursor um eine Zeile nach unten bewegen und den Text markieren |
| <strong>Shift + Ctrl + ←</strong> | Cursor um ein Wort nach links bewegen und den Text markieren |
| <strong>Shift + Ctrl + →</strong> | Cursor um ein Wort nach rechts bewegen und den Text markieren |
| <strong>Shift + Home</strong> | Cursor an den Zeilenanfang bewegen und den Text markieren |
| <strong>Shift + End</strong> | Cursor an das Zeilenende bewegen und den Text markieren |
| <strong>Shift + Page Up</strong> | Cursor um eine Seite nach oben bewegen und den Text markieren |
| <strong>Shift + Page Down</strong> | Cursor um eine Seite nach unten bewegen und den Text markieren |
| <strong>Shift + Ctrl + Page Up</strong> | Cursor an den Anfang der sichtbaren Seite bewegen und den Text markieren |
| <strong>Shift + Ctrl + Page Down</strong> | Cursor an das Ende der sichtbaren Seite bewegen und den Text markieren |
| <strong>Shift + Ctrl + Home</strong> | Cursor an den Textanfang bewegen und den Text markieren |
| <strong>Shift + Ctrl + End</strong> | Cursor an das Textende bewegen und den Text markieren |
| <strong>Ctrl + A</strong> | Gesamten Editorinhalt markieren und den Cursor ans Ende setzen |
| <strong>Ctrl + C</strong> <strong>Ctrl + Insert</strong> | Auswahl in die Zwischenablage kopieren |
| <strong>Ctrl + ↑</strong> | Ansicht um eine Zeile nach oben verschieben; Cursorposition beibehalten |
| <strong>Ctrl + ↓</strong> | Ansicht um eine Zeile nach unten verschieben; Cursorposition beibehalten |
| <strong>Insert</strong> | Zwischen Einfüge- und Überschreibmodus wechseln |
| <strong>Shift + Ctrl + N</strong> | Normale Textauswahl aktivieren |
| <strong>Shift + Ctrl + C</strong> | Spaltenauswahl aktivieren |
| <strong>Shift + Ctrl + L</strong> | Zeilenauswahl aktivieren |
| <strong>Shift + Ctrl + B</strong> | Zur zugehörigen Klammer springen |
| <strong>Backspace</strong> <strong>Shift + Backspace</strong> | Zeichen vor dem Cursor löschen |
| <strong>Delete</strong> | Zeichen an der Cursorposition löschen |
| <strong>Ctrl + T</strong> | Vom Cursor bis zum Wortende löschen |
| <strong>Ctrl</strong> <strong>+ Backspace</strong> | Vom Cursor bis zum Wortanfang löschen |
| <strong>Shift + Ctrl + Y</strong> | Vom Cursor bis zum Zeilenende löschen |
| <strong>Ctrl + Y</strong> | Aktuelle Zeile löschen |
| <strong>Enter</strong> <strong>Shift + Enter</strong> <strong>Ctrl + M</strong> | Zeile an der Cursorposition teilen und den Cursor in die neue Zeile setzen |
| <strong>Ctrl + N</strong> | Zeile an der Cursorposition teilen und die Cursorposition beibehalten |
| <strong>Ctrl + Z</strong> <strong>Alt + Backspace</strong> | Letzte Änderung rückgängig machen, sofern verfügbar |
| <strong>Shift + Ctrl + Z</strong> <strong>Shift + Alt + Backspace</strong> | Rückgängig gemachte Änderung wiederherstellen, sofern verfügbar |
| <strong>Ctrl + X</strong> <strong>Shift + Delete</strong> | Auswahl ausschneiden und in die Zwischenablage übernehmen |
| <strong>Ctrl + V</strong> <strong>Shift + Insert</strong> | Inhalt der Zwischenablage an der Cursorposition einfügen |
| <strong>Shift + Ctrl + I</strong> | Auswahl einrücken |
| <strong>Shift + Ctrl + U</strong> | Einzug der Auswahl verringern |
| <strong>Tab</strong> | Einzug hinzufügen |
| <strong>Shift + Tab</strong> | Einzug entfernen |
