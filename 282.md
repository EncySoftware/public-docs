# Arbeitsprinzip von ENCY

ENCY® bietet einen hohen Automatisierungsgrad und zahlreiche erweiterte Funktionen.

Beim Erstellen eines Bearbeitungsprozesses werden zunächst das Modell des herzustellenden [Bauteils](330.md), das Ausgangs[rohteil](738.md) und die [Spannmittel](10283.md) [definiert](294.md). Anschließend wird die [Bearbeitungsfolge](1029.md) aus einzelnen Operationen aufgebaut. Für jede Operation wird festgelegt, welcher Bereich mit welchem Verfahren bearbeitet werden soll. Dazu werden beispielsweise Rautiefe, maximaler Eingriffswinkel und Einfahrverfahren vorgegeben. Das System berechnet anhand dieser Parameter die Werkzeugbahn. Standardmäßig übernimmt eine nachfolgende Operation Bauteil und Spannmittel der vorherigen Operation. Als Rohteil verwendet sie deren Bearbeitungsergebnis. So wird das Ausgangsrohteil schrittweise zum Fertigteil.

Die Erstellung eines NC-Programms umfasst im Allgemeinen folgende Schritte:

- [Geometriemodell importieren](109.md).
- [Bauteil](330.md), Ausgangs[rohteil](738.md) und [Spannmittel](10283.md) im Wurzelknoten des Operationsbaums definieren.
- Eine [Folge von Bearbeitungsoperationen](1029.md) erstellen, deren Parameter festlegen und die Bahnen berechnen.
- [NC-Programm erzeugen](69.md).

Beim Erstellen einer Operation setzt das System passende Vorgabewerte anhand des Bearbeitungsverfahrens und der Bauteilgeometrie. Dadurch kann die Werkzeugbahn berechnet werden, ohne zuvor sämtliche Parameter manuell einzugeben. Operationsreihenfolge und Parameter lassen sich während der gesamten Prozessplanung ändern.

Ein Grundprinzip von ENCY® ist der Schutz der Bauteilgeometrie vor unerwünschten Einschnitten bei Arbeitsbahnen, Verbindungen, Anfahrbewegungen, Schnitten und Bohrungen, unabhängig von Werkzeugtyp und Bearbeitungsverfahren. Die Fertigungsplanung legt das Verfahren fest; das System erzeugt ein NC-Programm zum Abtragen des Rohteilmaterials außerhalb der Bauteilgeometrie.

Parameter können in der jeweils benötigten Reihenfolge geändert werden. Die interaktiven Abbildungen vieler Dialoge passen sich automatisch an die gewählte Operation und deren Einstellungen an. Dies erleichtert die Einarbeitung und das Verständnis der Parameter.

ENCY entwickelt seine Software kontinuierlich weiter, um die Bedienung und Wirtschaftlichkeit zu verbessern. Der [technische Support](811.md) beantwortet Fragen und nimmt Anregungen sowie Verbesserungsvorschläge entgegen.
