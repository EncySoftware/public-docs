# Importazione di oggetti da file PostScript

Il formato **PostScript** consente di trasferire figure piane vettoriali e raster. I file hanno normalmente estensione *.ps o *.eps (**Encapsulated PostScript**). Il formato è ampiamente utilizzato nell'editoria e nel trasferimento di informazioni alle stampanti che supportano l'interfaccia PostScript.

<em>Limitazioni: il sistema CAM importa dai file PostScript soltanto le informazioni vettoriali. Non importa le immagini raster inserite nel file PostScript. La versione attuale non importa il testo. Per importare correttamente il testo, è necessario convertirlo in curve.</em>

Per l'importazione viene utilizzata la libreria GhostScript ([istruzioni di installazione](10031.md)). Alla prima importazione verrà richiesto di caricare la libreria e di specificarne il percorso. È inoltre possibile farlo nella finestra System Settings (impostazioni di sistema), scheda **Import**.

Raccomandazioni per l'esportazione in un file PostScript in CorelDraw:

- Attivare la modalità **Curves** nel gruppo **Export text as**: in questo modo CorelDraw genererà nel file PostScript insiemi di curve corrispondenti a ogni figura del testo.
- Attivare l'opzione **Include header** nel gruppo **Image header**.
