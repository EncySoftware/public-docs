# Importieren von Objekten aus PostScript-Dateien

Das Format **PostScript** überträgt ebene Vektor- und Rastergrafiken. Die Dateien haben gewöhnlich die Endung *.ps oder *.eps (**Encapsulated PostScript**). Das Format wird im Verlagswesen und zur Datenübertragung an Drucker mit PostScript-Schnittstelle verwendet.

*Einschränkungen: Das CAM-System importiert aus PostScript-Dateien nur Vektordaten. Eingebettete Rasterbilder werden nicht importiert. Text wird in der aktuellen Version ebenfalls nicht importiert und muss vorher in Kurven umgewandelt werden.*

Für den Import wird die Ghostscript-Bibliothek verwendet ([Installationsanleitung](10031.md)). Beim ersten Import fordert das System dazu auf, die Bibliothek bereitzustellen und ihren Speicherort anzugeben. Der Pfad kann auch in den Systemeinstellungen auf der Registerkarte **Import** festgelegt werden.

Empfehlungen für den PostScript-Export aus CorelDraw:

- Wählen Sie in der Gruppe **Export text as** den Modus **Curves**. CorelDraw erzeugt dann in der PostScript-Datei Kurven für die einzelnen Schriftzeichen.
- Aktivieren Sie in der Gruppe **Image header** die Option **Include header**.
