# Spline

![images/download/attachments/157860308/image2024-8-8_17-17-21.png](assets/images/download/attachments/157860308/image2024-8-8_17-17-21.png)

Spline is a piecewise curve interpolation with lines. Spline passes through given points and is tangential to given start and end angles.

![images/download/attachments/157860308/image2024-8-8_17-18-19.png](assets/images/download/attachments/157860308/image2024-8-8_17-18-19.png)

It is possible to input spline points directly in the graphic window. Otherwise the left inspector can be used to input number of points and point coordinates.

![images/download/attachments/157860308/image2024-8-8_17-19-0.png](assets/images/download/attachments/157860308/image2024-8-8_17-19-0.png)

Click ![images/download/attachments/157860308/image2024-8-8_17-19-50.png](assets/images/download/attachments/157860308/image2024-8-8_17-19-50.png) or double-click at last point to finish spline.
