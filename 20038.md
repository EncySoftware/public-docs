# Spline

![images/download/attachments/157860308/image2024-8-8_17-17-21.png](assets/images/download/attachments/157860308/image2024-8-8_17-17-21.png)

Ein Spline ist eine stückweise interpolierte Kurve. Er verläuft durch die angegebenen Punkte und besitzt an Anfang und Ende Tangenten mit den vorgegebenen Winkeln.

![images/download/attachments/157860308/image2024-8-8_17-18-19.png](assets/images/download/attachments/157860308/image2024-8-8_17-18-19.png)

Die Splinepunkte können direkt im Grafikfenster festgelegt werden. Alternativ können Sie die Anzahl der Punkte und ihre Koordinaten im linken Inspektor eingeben.

![images/download/attachments/157860308/image2024-8-8_17-19-0.png](assets/images/download/attachments/157860308/image2024-8-8_17-19-0.png)

Klicken Sie auf ![Spline abschließen](assets/images/download/attachments/157860308/image2024-8-8_17-19-50.png) oder doppelklicken Sie auf den letzten Punkt, um den Spline abzuschließen.
