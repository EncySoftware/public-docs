# Bohrungen

<a id="application-area"></a>

## Anwendungsbereich:

Die Gruppe **Holes** enthält Operationen zur Bohrungsbearbeitung und zur Erzeugung von Bearbeitungsprozessen aus erkannten Fertigungsmerkmalen.

<a id="operations"></a>

### Operationen:

- **Bohrungsbearbeitung.** Erzeugt Werkzeugwege einschließlich Bohr-, Ausbohr- und Gewindeschneidzyklen. [Details](10100.md)

- **FBM Mill.** Erzeugt anhand von Bearbeitungsverfahren Operationen für erkannte Merkmale. [Details](10089.md)
