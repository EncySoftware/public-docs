# Holes

## Application area:

The **Holes** group provides operations for machining holes and generating machining processes from recognized manufacturing features.

### Operations:

- **Hole machining.** Creates hole machining toolpaths, including drilling, boring, and threading cycles. [Details](10100.md)

- **FBM Mill.** Generates operations for recognized manufacturing features using machining procedures. [Details](10089.md)
