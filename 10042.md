# CADbro™-Symbolleiste

![images/download/attachments/157859588/CADbroFromAddinManager.png](assets/images/download/attachments/157859588/CADbroFromAddinManager.png)

Mit der Symbolleiste können Sie geometrische Daten aus <strong>CADBro™</strong> exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859588/image2022-3-30_11-56-7.png](assets/images/download/attachments/157859588/image2022-3-30_11-56-7.png)

Damit diese Option ordnungsgemäß funktioniert, muss die erforderliche Anwendung (CADbro™) auf Ihrem Computer installiert sein.
