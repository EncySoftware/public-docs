# Barra de ferramentas do CADbro™

![images/download/attachments/157859588/CADbroFromAddinManager.png](assets/images/download/attachments/157859588/CADbroFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do **CADBro™**. É possível consultar a versão do sistema CAD suportado. [Detalhes](10039.md)

![images/download/attachments/157859588/image2022-3-30_11-56-7.png](assets/images/download/attachments/157859588/image2022-3-30_11-56-7.png)

O CADbro™ deve estar instalado no computador para que o recurso funcione.
