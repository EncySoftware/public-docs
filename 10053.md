# ZW3D™: Symbolleiste und Import-Add-in

![images/download/attachments/157859705/ZW3DFromAddinManager.png](assets/images/download/attachments/157859705/ZW3DFromAddinManager.png)

Über die Symbolleiste können Sie geometrische Daten aus ZW3D™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859705/image2022-3-30_15-51-20.png](assets/images/download/attachments/157859705/image2022-3-30_15-51-20.png)

Mit dem Add-In können Sie ZW3D™-Projektdateien importieren.

Unterstützte Dateierweiterungen: Z3. Damit diese Option funktioniert, muss die erforderliche Anwendung (ZW3D™) auf Ihrem Computer installiert sein.
