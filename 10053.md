# Barra degli strumenti e add-in di importazione per ZW3D™

![images/download/attachments/157859705/ZW3DFromAddinManager.png](assets/images/download/attachments/157859705/ZW3DFromAddinManager.png)

La barra degli strumenti consente di esportare dati geometrici da ZW3D™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859705/image2022-3-30_15-51-20.png](assets/images/download/attachments/157859705/image2022-3-30_15-51-20.png)

L'add-in consente di importare file di progetto ZW3D™.

Estensioni di file supportate: Z3. Per il funzionamento di questa opzione, l'applicazione richiesta (ZW3D™) deve essere installata sul computer.
