# Barra de ferramentas e suplemento de importação do ZW3D™

![images/download/attachments/157859705/ZW3DFromAddinManager.png](assets/images/download/attachments/157859705/ZW3DFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do ZW3D™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859705/image2022-3-30_15-51-20.png](assets/images/download/attachments/157859705/image2022-3-30_15-51-20.png)

O suplemento permite importar arquivos de projeto do ZW3D™.

Extensão suportada: Z3. O ZW3D™ deve estar instalado no computador para que o recurso funcione.
