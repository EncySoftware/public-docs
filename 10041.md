# Autodesk Inventor™: Symbolleiste und Import-Add-in

![images/download/attachments/157859572/InventorProFromAddinManager.png](assets/images/download/attachments/157859572/InventorProFromAddinManager.png)

Mit der Symbolleiste können Sie geometrische Daten aus Autodesk Inventor Professional™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859572/image2022-3-30_11-50-5.png](assets/images/download/attachments/157859572/image2022-3-30_11-50-5.png)

Mit dem Add-In können Sie <strong>Autodesk Inventor Professional™</strong>-Projektdateien importieren.

Unterstützte Dateierweiterungen: IAM, IDW, IPT, IPN, IDE, PRT, ASM, SAT, STE, STEP, DWG, DXF, IGES, IGS.

Damit diese Option funktioniert, muss die erforderliche Anwendung (<strong>Autodesk Inventor Professional™</strong>) auf Ihrem Computer installiert sein.

Bei <strong>Autodesk Inventor Professional™ 2021</strong> können Probleme beim Aktivieren der Symbolleiste auftreten:

Wenn beim Start das folgende Fenster erscheint:

![images/download/attachments/157859572/image2020-2-7_18-12-25.png](assets/images/download/attachments/157859572/image2020-2-7_18-12-25.png)

Aktivieren Sie die Symbolleiste in <strong>Autodesk Inventor Professional™ 2021</strong> manuell. Starten Sie dazu den Add-In-Manager in diesem Fenster oder suchen Sie die Schaltfläche im Menüband:

![images/download/attachments/157859572/image2020-2-7_18-15-14.png](assets/images/download/attachments/157859572/image2020-2-7_18-15-14.png)

Wählen Sie im geöffneten Fenster die Symbolleiste des CAM-Systems aus und stellen Sie die Parameter wie im folgenden Screenshot ein:

![images/download/attachments/157859572/image2020-2-10_10-48-42.png](assets/images/download/attachments/157859572/image2020-2-10_10-48-42.png)

Dann sollte die Symbolleiste des CAM-Systems im Menüband erscheinen.
