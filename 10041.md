# Barra de ferramentas e suplemento de importação do Autodesk Inventor™

![images/download/attachments/157859572/InventorProFromAddinManager.png](assets/images/download/attachments/157859572/InventorProFromAddinManager.png)

A barra de ferramentas permite exportar dados geométricos do Autodesk Inventor Professional™. Consulte as versões suportadas do sistema CAD em [Detalhes](10039.md).

![images/download/attachments/157859572/image2022-3-30_11-50-5.png](assets/images/download/attachments/157859572/image2022-3-30_11-50-5.png)

O suplemento permite importar arquivos de projeto do **Autodesk Inventor Professional™**.

Extensões suportadas: IAM, IDW, IPT, IPN, IDE, PRT, ASM, SAT, STE, STEP, DWG, DXF, IGES, IGS.

O **Autodesk Inventor Professional™** deve estar instalado no computador para que o recurso funcione.

No **Autodesk Inventor Professional™ 2021**, podem ocorrer problemas na instalação da barra de ferramentas:

Se a seguinte janela for exibida na inicialização:

![images/download/attachments/157859572/image2020-2-7_18-12-25.png](assets/images/download/attachments/157859572/image2020-2-7_18-12-25.png)

Ative manualmente a barra de ferramentas no **Autodesk Inventor Professional™ 2021**. Abra o **Add-in Manager** nessa janela ou pelo botão correspondente na faixa de opções:

![images/download/attachments/157859572/image2020-2-7_18-15-14.png](assets/images/download/attachments/157859572/image2020-2-7_18-15-14.png)

Na janela aberta, localize a barra de ferramentas do sistema CAM e configure os parâmetros conforme a imagem a seguir:

![images/download/attachments/157859572/image2020-2-10_10-48-42.png](assets/images/download/attachments/157859572/image2020-2-10_10-48-42.png)

A barra de ferramentas do sistema CAM deverá aparecer na faixa de opções.
