# Barra degli strumenti e add-in di importazione per Autodesk Inventor™

![images/download/attachments/157859572/InventorProFromAddinManager.png](assets/images/download/attachments/157859572/InventorProFromAddinManager.png)

La barra degli strumenti consente di esportare i dati geometrici da Autodesk Inventor Professional™. È possibile visualizzare la versione del sistema CAD supportato. [Dettagli](10039.md)

![images/download/attachments/157859572/image2022-3-30_11-50-5.png](assets/images/download/attachments/157859572/image2022-3-30_11-50-5.png)

L'add-in consente di importare i file di progetto di <strong>Autodesk Inventor Professional™</strong>.

Estensioni di file supportate: IAM, IDW, IPT, IPN, IDE, PRT, ASM, SAT, STE, STEP, DWG, DXF, IGES, IGS.

Per il funzionamento di questa opzione, l'applicazione richiesta (<strong>Autodesk Inventor Professional™</strong>) deve essere installata sul computer.

L'installazione della barra degli strumenti in <strong>Autodesk Inventor Professional™2021</strong> può presentare problemi:

se all'avvio compare la finestra seguente:

![images/download/attachments/157859572/image2020-2-7_18-12-25.png](assets/images/download/attachments/157859572/image2020-2-7_18-12-25.png)

è necessario abilitare manualmente la barra degli strumenti in <strong>Autodesk Inventor Professional™2021</strong>. A tale scopo, avviare l'Add-in Manager da questa finestra oppure individuare il pulsante sulla barra multifunzione:

![images/download/attachments/157859572/image2020-2-7_18-15-14.png](assets/images/download/attachments/157859572/image2020-2-7_18-15-14.png)

Nella finestra che si apre, individuare la barra degli strumenti del sistema CAM e impostare i parametri come mostrato nella schermata seguente:

![images/download/attachments/157859572/image2020-2-10_10-48-42.png](assets/images/download/attachments/157859572/image2020-2-10_10-48-42.png)

A questo punto la barra degli strumenti del sistema CAM dovrebbe comparire sulla barra multifunzione.
