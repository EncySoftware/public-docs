# Parâmetros de geração de operações

O sistema CAM gera e atualiza operações dentro do grupo FBM Mill automaticamente à medida que você adiciona ou altera as sequências de usinagem dos recursos. A ordem das operações geradas é a mesma que a ordem dos recursos na pasta Job da árvore de recursos.

Dois parâmetros localizados na guia Strategy dos parâmetros do grupo FBM Mill afetam a geração de operações.

1. Minimize tool changes (minimizar as trocas de ferramenta).
2. Unite operations with the same tool (unir operações com a mesma ferramenta).

<strong>Minimize tool changes</strong>

Quando a opção Minimize tool changes está ativada, as operações dentro do grupo FBM Mill são ordenadas de forma que as operações que usam a mesma ferramenta fiquem juntas (desde que isso não entre em conflito com a ordem das operações dos procedimentos de usinagem).

<strong>Unite operations with the same tool</strong>

Esta opção só está disponível se a opção Minimize tool changes estiver ativada. Quando ativada, faz com que o sistema CAM una em uma única operação as operações que usam a mesma ferramenta e estão lado a lado no grupo FBM Mill. Essa união permite otimizar ainda mais o percurso da ferramenta.
