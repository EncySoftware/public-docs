# Parametri di generazione delle operazioni

Il sistema CAM genera e aggiorna automaticamente le operazioni all'interno del gruppo FBM Mill man mano che si aggiungono o si modificano le sequenze di lavorazione delle feature. L'ordine delle operazioni generate corrisponde all'ordine delle feature nella cartella Job dell'albero delle feature.

Due parametri, situati nella scheda Strategy dei parametri del gruppo FBM Mill, influiscono sulla generazione delle operazioni.

1. Minimize tool changes (riduzione al minimo dei cambi utensile).
2. Unite operations with the same tool (unione delle operazioni con lo stesso utensile).

<strong>Minimize tool changes</strong>

Quando l'opzione Minimize tool changes è attivata, le operazioni all'interno del gruppo FBM Mill vengono ordinate in modo che le operazioni che utilizzano lo stesso utensile siano raggruppate (naturalmente, se ciò non è in conflitto con l'ordine delle operazioni delle procedure di lavorazione).

<strong>Unite operations with the same tool</strong>

Questa opzione è disponibile solo se l'opzione Minimize tool changes è attivata. Quando è attiva, il sistema CAM unisce in un'unica operazione le operazioni che utilizzano lo stesso utensile e che si trovano una accanto all'altra nel gruppo FBM Mill. Questa unione consente un'ulteriore ottimizzazione del percorso utensile.
