# Named block

To create a named block, you need to select the necessary elements in the block. To do this, by pressing the mouse button and holding it down, select the elements with a rectangular frame, or sequentially select the elements with the **[Shift]** key pressed. The exclusion of elements from the block is also performed by specifying these elements with the **[Shift]** key pressed.

![images/download/attachments/157860452/image2024-8-9_17-48-17.png](assets/images/download/attachments/157860452/image2024-8-9_17-48-17.png)

Click **Save block** ![images/download/attachments/157860452/blocks10.jpg](assets/images/download/attachments/157860452/blocks10.jpg) in the inspector. This immediately creates a block and opens the **New block** editor. Set **Name** and **Insertion point**, then click **Save block** or press **[Enter]** to save, or click **Cancel**. No rotation angle is set during block creation.

In the future, you can insert this block into the sketch by hovering over the corresponding button and selecting the desired block from the drop-down menu. It is also possible to load a block from the library.

![3](assets/images/editor/20029/6834330953334715bf66179739dbcfa9.png)

Hovering over a block row shows edit and delete icons on the right. An update-from-library icon appears only when the library contains a newer version. Editing the source block updates all its inserts.

![4](assets/images/editor/20029/a15bfe0b8302416a964699a73321adbc.png)

**Angle.** Rotation of a block insert.

**Scale.** Insert scale along X | Y; a negative value mirrors it along the corresponding axis.

![images/download/attachments/157860452/image2024-8-9_17-50-46.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-46.png)

Deleting an inserted block requires confirmation and reports the number of inserts: they will be split into individual objects. A block inserted into another block or currently being edited has no delete icon.

Library files are described separately. [Details](20060.md)
