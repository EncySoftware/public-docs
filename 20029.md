# Bloco nomeado

Para criar um bloco nomeado, selecione os elementos que devem fazer parte do bloco. Para isso, mantendo pressionado o botão do mouse, selecione os elementos com uma moldura retangular ou selecione os elementos sequencialmente com a tecla <strong>[Shift]</strong> pressionada. Para excluir elementos do bloco, indique esses elementos também com a tecla <strong>[Shift]</strong> pressionada.

![images/download/attachments/157860452/image2024-8-9_17-48-17.png](assets/images/download/attachments/157860452/image2024-8-9_17-48-17.png)

Clique no botão ![images/download/attachments/157860452/blocks10.jpg](assets/images/download/attachments/157860452/blocks10.jpg) no inspetor. Se necessário, é possível digitar o nome do bloco ou definir seu ângulo de rotação.

![images/download/attachments/157860452/image2024-8-9_17-50-46.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-46.png)

Depois, é possível inserir esse bloco no desenho passando o mouse sobre o botão correspondente e selecionando o bloco desejado no menu suspenso.

![images/download/attachments/157860452/image2024-8-9_17-49-24.png](assets/images/download/attachments/157860452/image2024-8-9_17-49-24.png)

Posteriormente, você pode editar o bloco original clicando na "tesoura" no menu. Todas as cópias do bloco editado também serão alteradas.

![images/download/attachments/157860452/image2024-8-9_17-50-6.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-6.png)
