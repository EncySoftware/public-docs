# Benannter Block

Um einen benannten Block zu erstellen, wählen Sie die gewünschten Elemente aus. Ziehen Sie dazu bei gedrückter Maustaste einen rechteckigen Auswahlrahmen oder wählen Sie die Elemente nacheinander bei gedrückter **Umschalt**-Taste (**Shift**) aus. Durch erneutes Auswählen bei gedrückter **Umschalt**-Taste können Sie Elemente aus der Auswahl entfernen.

![images/download/attachments/157860452/image2024-8-9_17-48-17.png](assets/images/download/attachments/157860452/image2024-8-9_17-48-17.png)

Klicken Sie im Inspektor auf die Schaltfläche ![Block erstellen](assets/images/download/attachments/157860452/blocks10.jpg). Bei Bedarf können Sie einen Namen eingeben oder den Drehwinkel des Blocks festlegen.

![images/download/attachments/157860452/image2024-8-9_17-50-46.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-46.png)

Später können Sie diesen Block in die Zeichnung einfügen: Bewegen Sie den Mauszeiger auf die entsprechende Schaltfläche und wählen Sie den gewünschten Block aus dem Dropdown-Menü.

![images/download/attachments/157860452/image2024-8-9_17-49-24.png](assets/images/download/attachments/157860452/image2024-8-9_17-49-24.png)

Zum Bearbeiten des ursprünglichen Blocks klicken Sie auf das Scherensymbol im Menü. Die Änderungen werden auch auf alle Kopien dieses Blocks angewendet.

![images/download/attachments/157860452/image2024-8-9_17-50-6.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-6.png)
