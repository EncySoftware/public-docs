# Named block

To create a named block, you need to select the necessary elements in the block. To do this, by pressing the mouse button and holding it down, select the elements with a rectangular frame, or sequentially select the elements with the <strong>[Shift]</strong> key pressed. The exclusion of elements from the block is also performed by specifying these elements with the <strong>[Shift]</strong> key pressed.

![images/download/attachments/157860452/image2024-8-9_17-48-17.png](assets/images/download/attachments/157860452/image2024-8-9_17-48-17.png)

Click the ![images/download/attachments/157860452/blocks10.jpg](assets/images/download/attachments/157860452/blocks10.jpg) button in inspector. If necessary, you can enter its name or set the rotation angle of the block.

![images/download/attachments/157860452/image2024-8-9_17-50-46.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-46.png)

In the future, you can insert this block into the drawing by hovering over the corresponding button and selecting the desired block from the drop-down menu.

![images/download/attachments/157860452/image2024-8-9_17-49-24.png](assets/images/download/attachments/157860452/image2024-8-9_17-49-24.png)

Subsequently, you can edit the original block by clicking the "scissors" in the menu. All copies of the edited block will also change.

![images/download/attachments/157860452/image2024-8-9_17-50-6.png](assets/images/download/attachments/157860452/image2024-8-9_17-50-6.png)
