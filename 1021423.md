# Zusätzliche Software und Installationsänderungen

Das Installationsprogramm richtet die benötigten Komponenten ein und integriert sie in Windows.

<a id="required-software"></a>

## Erforderliche Software

| Komponente | Zweck |
|---|---|
| HASP-Treiber | Unterstützen HASP-Hardwarelizenzschlüssel. |
| Microsoft Visual C++ Redistributable | Laufzeitbibliotheken für mit Visual C++ erstellte Komponenten. |
| Microsoft .NET 10 Runtime | Laufzeitumgebung für .NET-10-Komponenten. |
| Microsoft ASP.NET Core 10 Runtime | Laufzeitumgebung für ASP.NET-Core-10-Web- und Serverkomponenten. |

<a id="changes-to-windows"></a>

## Änderungen an Windows

Bei einer Standardinstallation werden folgende Änderungen vorgenommen:

- **Windows-Registrierung.** Unterstützte Dateitypen und Installationsinformationen werden registriert.
- **Datei-Explorer.** Die Shell-Erweiterung der Anwendung wird registriert.
- **NVIDIA-Grafikeinstellungen.** Ein Anwendungsprofil für die leistungsfähige GPU wird erstellt.
- **Windows-Firewall.** Ausgehende Regeln für Hauptanwendung und zugehörige Komponenten wie Hilfe, Cloud-Dienste, Startseite und Projektbibliothek werden hinzugefügt.

Die portable Installation überspringt Systemänderungen, die Administratorrechte erfordern, darunter Registrierung, Shell-Erweiterung, NVIDIA-Profil und Firewallregeln.
