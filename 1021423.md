# Software aggiuntivo e modifiche apportate dall'installazione

Il programma di installazione configura i componenti software richiesti dal sistema CAM e ne imposta l'integrazione con Windows.

<a id="required-software"></a>

## Software richiesto

| Componente | Scopo |
|---|---|
| Driver HASP | Consentono al sistema CAM di utilizzare le chiavi di licenza hardware HASP. |
| Microsoft Visual C++ Redistributable | Fornisce le librerie di runtime richieste dai componenti dell'applicazione compilati con Microsoft Visual C++. |
| Microsoft .NET 10 Runtime | Esegue i componenti dell'applicazione sviluppati per .NET 10. |
| Microsoft ASP.NET Core 10 Runtime | Esegue i componenti web e server sviluppati per ASP.NET Core 10. |

<a id="changes-to-windows"></a>

## Modifiche a Windows

Durante un'installazione standard, il programma di installazione apporta le modifiche seguenti:

- **Registro di Windows.** Registra i tipi di file supportati e memorizza i dettagli dell'installazione dell'applicazione.
- **Integrazione con Esplora file.** Registra l'estensione della shell dell'applicazione.
- **Impostazioni grafiche NVIDIA.** Crea un profilo applicazione per l'utilizzo della GPU ad alte prestazioni.
- **Windows Firewall.** Aggiunge regole in uscita per l'applicazione principale e i componenti correlati, tra cui il sistema della guida, i servizi cloud, la pagina iniziale e la libreria dei progetti.

L'installazione portatile omette le operazioni di configurazione del sistema che richiedono diritti di amministratore, tra cui le modifiche al registro, all'estensione della shell, al profilo NVIDIA e al firewall elencate sopra.
