# Software adicional e alterações da instalação

O instalador configura os componentes de software necessários ao sistema CAM e sua integração com o Windows.

## Software necessário

| Componente | Finalidade |
|---|---|
| Drivers HASP | Permitem utilizar chaves físicas de licença HASP no sistema CAM. |
| Microsoft Visual C++ Redistributable | Fornece as bibliotecas de execução necessárias aos componentes desenvolvidos com Microsoft Visual C++. |
| Microsoft .NET 10 Runtime | Executa os componentes desenvolvidos para .NET 10. |
| Microsoft ASP.NET Core 10 Runtime | Executa os componentes Web e de servidor desenvolvidos para ASP.NET Core 10. |

## Alterações no Windows

Durante uma instalação padrão, o instalador realiza as seguintes alterações:

- **Registro do Windows.** Registra os tipos de arquivo suportados e as informações de instalação do aplicativo.
- **Integração com o Explorador de Arquivos.** Registra a extensão de shell do aplicativo.
- **Configurações gráficas da NVIDIA.** Cria um perfil do aplicativo para utilização da GPU de alto desempenho.
- **Firewall do Windows.** Adiciona regras de saída para o aplicativo principal e componentes relacionados, incluindo o sistema de ajuda, os serviços na nuvem, a página inicial e a biblioteca de projetos.

A instalação portátil não executa as configurações do sistema que exigem privilégios de administrador, incluindo as alterações no Registro, na extensão de shell, no perfil NVIDIA e no firewall descritas acima.
