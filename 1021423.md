# Additional software and installation changes

The installer sets up the software components required by the CAM system and configures their integration with Windows.

## Required software

| Component | Purpose |
|---|---|
| HASP drivers | Enable the CAM system to use HASP hardware license keys. |
| Microsoft Visual C++ Redistributable | Provides runtime libraries required by application components built with Microsoft Visual C++. |
| Microsoft .NET 10 Runtime | Runs application components built for .NET 10. |
| Microsoft ASP.NET Core 10 Runtime | Runs web and server components built for ASP.NET Core 10. |

## Changes to Windows

During a standard installation, the installer makes the following changes:

- **Windows registry.** Registers supported file types and records application installation details.
- **File Explorer integration.** Registers the application's shell extension.
- **NVIDIA graphics settings.** Creates an application profile for using the high-performance GPU.
- **Windows Firewall.** Adds outbound rules for the main application and related components, including the help system, cloud services, start page, and project library.

Portable installation skips the system configuration steps that require administrator rights, including the registry, shell extension, NVIDIA profile, and firewall changes listed above.
