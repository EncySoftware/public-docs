# Hauptfenster der Modellierung

![images/download/attachments/157860753/image2025-5-19_11-44-16.png](assets/images/download/attachments/157860753/image2025-5-19_11-44-16.png)

<a id="application-area"></a>

## Anwendungsbereich:

**Der Inhalt der Bedienelemente hängt davon ab, ob im 2D- oder 3D-Modus gearbeitet wird.**

Das Hauptfenster enthält den Modellbaum, die Symbolleiste, die Elementeigenschaften und das Sichtbarkeitspanel.

<a id="feature-tree"></a>

### Modellbaum.

Der Modellbaum zeigt die zeitliche Folge der Konstruktionsschritte des 3D-Modells. Die Schritte werden streng nacheinander ausgeführt. Zwei voneinander getrennte Extrusionen können daher nicht innerhalb desselben Körpers erzeugt werden; dafür muss ein neuer Körper angelegt werden.

Der Baum enthält drei Grundebenen, Skizzen, Bauteile und Konstruktionselemente.

**Sketches (Skizzen).** Zeichnungen im Modellbaum.

<details>
<summary>Weitere Informationen anzeigen</summary>

Ebenen werden über ein eingeblendetes Menü erstellt, das durch Klicken mit der rechten oder linken Maustaste auf eine Fläche oder Ebene geöffnet wird. Sein Inhalt hängt vom ausgewählten Element ab.

![images/download/attachments/157860753/image2025-5-19_12-18-20.png](assets/images/download/attachments/157860753/image2025-5-19_12-18-20.png)

Klicken Sie anschließend auf die Schaltfläche zum Zeichnen.

![images/download/thumbnails/157860753/image2025-5-20_8-46-15.png](assets/images/download/thumbnails/157860753/image2025-5-20_8-46-15.png)

Die Verfahren zur Ebenendefinition sind in einem eigenen Abschnitt beschrieben. [Details](12451.md)

Neben jeder Skizze befindet sich ein Schalter, mit dem sie im 3D-Modus ein- oder ausgeblendet werden kann.

![images/download/attachments/157860753/image2025-5-20_8-48-41.png](assets/images/download/attachments/157860753/image2025-5-20_8-48-41.png)

Geschlossene Konturen werden hervorgehoben. Dies zeigt an, dass eine boolesche Operation ausgeführt werden kann.

![images/download/attachments/157860753/image2025-5-19_12-24-4.png](assets/images/download/attachments/157860753/image2025-5-19_12-24-4.png)

**Wird eine Kontur für die Extrusion nicht hervorgehoben, prüfen Sie, ob die Skizze sichtbar und die Kontur geschlossen ist.**

</details>

**Curves (Kurven).** Räumliche Kurven wie **Helix** und **Spline**. [Details](12451.md)

**Parts (Bauteile).** Ein Modell kann aus mehreren Bauteilen bestehen; standardmäßig ist eines vorhanden. Dadurch können Baugruppen aus einzelnen Komponenten erstellt werden, beispielsweise ein Spannfutter aus Grundkörper und Backen. [Details](10283.md)

<details>

![images/download/attachments/157860753/image2025-5-19_15-14-14.png](assets/images/download/attachments/157860753/image2025-5-19_15-14-14.png)

Damit zwei Bauteile im Baum erscheinen, erstellen Sie mindestens zwei Skizzen und führen Sie für jede eine Extrusion aus.

![images/download/thumbnails/157860753/image2025-5-19_15-18-24.png](assets/images/download/thumbnails/157860753/image2025-5-19_15-18-24.png)

Die Sichtbarkeit eines Bauteils wird durch Klicken auf sein Symbol gesteuert.

![images/download/thumbnails/157860753/image2025-5-19_15-21-35.png](assets/images/download/thumbnails/157860753/image2025-5-19_15-21-35.png)

Auch die Modellfarbe kann geändert werden.

**Features (Konstruktionselemente).** Enthält die einzelnen Elemente, beispielsweise Skizzen und Extrusionen.

<a id="toolbar"></a>

### Symbolleiste.

Die Symbolleiste enthält die Funktionen des 2D-Modus ([Details](12452.md)) bzw. des 3D-Modus ([Details](12451.md)). Ihr Inhalt passt sich dem gewählten Modus an.

<a id="element-properties"></a>

### Elementeigenschaften.

In diesem Bereich werden die Eigenschaften der ausgewählten Konstruktionselemente geändert.

<a id="visibility-panel"></a>

### Sichtbarkeitspanel.

Dieses Panel steuert die Sichtbarkeit von Elementen wie Maschine, Ebenen und Skizzen.

<details>
<summary>Weitere Informationen anzeigen</summary>

**Show 3D model (3D-Modell anzeigen).** Steuert die Sichtbarkeit von 3D-Modellen, die nicht zur aktuellen Konstruktion gehören.

**Show machine (Maschine anzeigen).** Steuert die Sichtbarkeit des Maschinenmodells.

**Planes (Ebenen).** Steuert die Sichtbarkeit aller Ebenen.

**Sketches (Skizzen).** Steuert die Sichtbarkeit aller Skizzen.

**Ground plane (Bodenebene).** Steuert die Sichtbarkeit des Bodens.

**Section plane (Schnittebene).** Aktiviert oder deaktiviert die Schnittdarstellung zur Ansicht der inneren Objektstruktur. [Details](333.md)

**Edges (Kanten).** Ermöglicht die Auswahl von Modellkanten.

**Features (Konstruktionselemente).** Ermöglicht die Auswahl von Konstruktionselementen.

**Dimensions (Maße).** Steuert die Sichtbarkeit aller Bemaßungen.

**Increase PMI Font.** Vergrößert die Schrift der Bemaßungen.

**Decrease PMI Font.** Verkleinert die Schrift der Bemaßungen.

</details>

<a id="graphics-window"></a>

### Grafikfenster.

Im Grafikfenster werden Zeichnung, Modell oder Baugruppe dargestellt.
