# Requisiti di sistema

Le configurazioni PC minima e consigliata per ENCY:

| Requisiti | Minimo (progetti piccoli e medi) | Consigliato (progetti grandi) |
|---|---|---|
| Sistema operativo *, ** | Windows 10 a 64 bit | Windows 11 |
| CPU | Processore Intel® o AMD® a 64 bit, 2,4 GHz o superiore | Intel® i7/i9 Rocket Lake o successivo oppure AMD® Ryzen 7®/Ryzen 9® Zen 3 o successivo |
| Memoria | 8 GB di RAM | 32 GB di RAM |
| Scheda video | Scheda grafica compatibile con OpenGL (OpenGL 1.5) con 1 GB di memoria | Nvidia GeForce® con 4 GB di memoria dedicata o superiore |
| Archiviazione | Unità a stato solido (SSD) con almeno 5 GB di spazio libero | Unità NVMe con almeno 5 GB di spazio libero |
| Monitor | 1280×960 o superiore | 1920×1080 o 4K, doppio monitor |
| Mouse 3D | — | Compatibile con i mouse 3D 3Dconnexion |
| Internet | — | Connessione internet da 100 Mbit |

Nota: la configurazione consigliata del computer dipende in larga misura dalla complessità dei modelli da lavorare e dalla [qualità di lavorazione](100112.md). Quanto più il modello è complesso e quanto più è elevata la qualità di lavorazione richiesta, tanto maggiore è il numero di calcoli necessari per [generare il percorso utensile](69.md). Pertanto, quanto più elevate sono le specifiche del computer, tanto più rapidamente vengono eseguiti i calcoli.

*ENCY non è supportato sulle macchine basate su Apple Macintosh®. Alcuni clienti hanno eseguito con successo ENCY in un ambiente Windows virtuale su computer Mac, utilizzando Boot Camp o un qualsiasi emulatore Windows (Wine, Parallels Desktop, VirtualBox, VMware Fusion, CrossOver ecc.). Pur potendo l'utente finale scegliere di eseguire Windows su un MAC®, ciò non è supportato da ENCY.

** Software antivirus: oggi la maggior parte dei computer dispone di un software antivirus che protegge dai malware indesiderati. In alcuni casi si è constatato che questi programmi interferiscono con applicazioni come ENCY in esecuzione sul PC. Il software ENCY non raccomanda prodotti particolari, ma in caso di problemi imprevisti la causa può essere un conflitto con il software antivirus. Il nostro software viene verificato dal servizio antivirus Kaspersky, società Avast, e gode della loro fiducia. Provare a disattivare temporaneamente il software antivirus o a impostare un'eccezione per ENCY.
