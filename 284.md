# Requisitos do sistema

As configurações mínimas e recomendadas do PC para ENCY:

| Requisitos | Mínimo (pequenos e médios projetos) | Recomendado (grandes projetos) |
|---|---|---|
| SO *, ** | Windows 10 de 64 bits | Windows 11 |
| CPU | Processador Intel® ou AMD® de 64 bits, 2,4 GHz ou mais rápido | Intel® i7/i9 Rocket Lake ou posterior ou AMD® Ryzen 7®/Ryzen 9® Zen 3 ou posterior |
| Memória | 8 GB de RAM | 32 GB de RAM |
| Vídeo | Placa gráfica compatível com OpenGL (OpenGL 1.5) com 1 GB de memória | Nvidia GeForce® com 4 GB de memória dedicada ou superior |
| Armazenamento | SSD com pelo menos 5 GB de espaço livre | Unidade NVMe com pelo menos 5 GB de espaço livre |
| Monitor | 1280×960 ou superior | 1920×1080 ou 4K, monitores duplos |
| Mouse 3D | — | 3Dconnexion compatível com mouse 3D |
| Internet | — | Conexão de internet de 100 Mbit |

Nota: A configuração recomendada do computador depende muito da complexidade dos modelos a serem usinados e da [qualidade da usinagem](100112.md). Quanto mais complexo for o modelo, e quanto maior a qualidade de usinagem necessária, maior será o número de cálculos necessários para realizar, a fim [de gerar o percurso de movimento da ferramenta](69.md). Portanto, quanto maior a especificação do computador, mais rápido os cálculos serão realizados.

*ENCY não é compatível com máquinas baseadas em Apple Macintosh®. Alguns clientes demonstraram sucesso na execução ENCY em um ambiente Virtual Windows em computadores Mac usando o Boot Camp ou qualquer emulador do Windows (Wine, Parallels Desktop, VirtualBox, VMware Fusion, CrossOver, etc.). Embora o usuário final possa optar por executar o Windows em um MAC®, isso não é suportado por ENCY.

** Software antivírus: A maioria dos computadores hoje tem algum tipo de software antivírus para proteger contra malware indesejado. Em alguns casos, descobriu-se que eles interferem em aplicações como ENCY que estão sendo executados no PC. O software ENCY não recomenda produtos específicos, mas se você encontrar problemas inesperados, pode ser um conflito com o software antivírus. Nosso software é verificado pelo serviço Kaspersky Antivirus, empresa Avast, e somos confiáveis para o nosso software. Tente desativar temporariamente o software antivírus ou definir uma exceção para ENCY.
