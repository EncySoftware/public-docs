# Selection filter

**Filter** opens a panel with **Geometry**, **Line types** and **Auxiliary** groups. The button icon changes when the filter restricts selection.

**Selectable.** Available for every row. Disabling it makes objects dimmer and prevents highlighting and selection by click, selection box or **[Ctrl+A]**. Snapping remains available.

**Visible.** An additional checkbox for auxiliary objects. Disabling it prevents display, selection and snapping.

The setting is shared by all planes and is not saved in the project.
