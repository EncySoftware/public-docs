<p><br/></p>
<p>On the "<strong class="">Tool Blocks"</strong> tab, you may see that by default the added tool uses all connection points. If you want to use only some of the points, click the <strong class="">"Set same tool block for all positions in row button"</strong>. This will clear the turret, so you can place the tools as you need.</p>
