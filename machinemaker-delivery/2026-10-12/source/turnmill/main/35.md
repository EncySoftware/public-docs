<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-142647539">Multi Tool Head</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>The Multi Tool Head is made to hold any number of tool blocks, which can be easily configured and adjusted.<br/>You can build fully custom Multi Tool Head.</p>
<p>To add it you need to create a project with a milling machine.</p>
<p><a class="doc-image-link" href="images/download/attachments/142647539/image2025-5-23_14-58-18.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/image2025-5-23_14-58-18.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/142647539/image2025-5-23_14-58-18.png" style="--doc-image-width:360px"/></a>
</p>
<p><br/></p>
<p>Attach a mounting point to the rear of the<strong class=""> Multi Tool Head</strong> and identify its moving components.</p>
<p><a class="doc-image-link" href="images/download/attachments/142647539/image2025-5-23_15-6-50.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/image2025-5-23_15-6-50.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/142647539/image2025-5-23_15-6-50.png" style="--doc-image-width:750px" width="750"/></a>
</p>
<p><br/></p>
<p>Next, create a mounting point on the milling machine and slightly customize<strong class=""> Workpiece</strong> settings.</p>
<p style="text-align:center;"><a class="doc-image-link" href="images/download/attachments/142647539/settingsto4kiformultitoolhead.gif" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/settingsto4kiformultitoolhead.gif" class="confluence-embedded-image confluence-content-image-border doc-image" height="430" src="images/download/attachments/142647539/settingsto4kiformultitoolhead.gif" style="--doc-image-width:800px" width="800"/></a>
</p>
<p style="text-align:left;"><br/></p>
<p style="text-align:left;">After mounting the Multi-Tool Head on the milling machine, open the Tool Blocks View window and use it to add the new tool for installation</p>
<p style="text-align:center;"><a class="doc-image-link" href="images/download/attachments/142647539/image2025-5-23_15-32-16.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/image2025-5-23_15-32-16.png" class="confluence-embedded-image confluence-content-image-border doc-image" height="489" src="images/download/attachments/142647539/image2025-5-23_15-32-16.png" style="--doc-image-width:620px" width="620"/></a>
</p>
<p style="text-align:center;"><br/></p>
<p>When adding a tool, you may select any type listed under Supported Applications. In this case, Lathe Cutting will be used.</p>
<p><a class="doc-image-link" href="images/download/attachments/142647539/image2025-5-23_15-38-9.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/image2025-5-23_15-38-9.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/142647539/image2025-5-23_15-38-9.png" style="--doc-image-width:800px" width="800"/></a>
</p>
<p><br/></p>
<p>When adding multiple tools, ensure proper placement of each tool. To reposition a tool, adjust the location of its <strong class="">Base Connector.</strong></p>
<p><a class="doc-image-link" href="images/download/attachments/142647539/image2025-5-23_15-44-7.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/image2025-5-23_15-44-7.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/142647539/image2025-5-23_15-44-7.png" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>After exporting the project, you can test the machine equipped with the <strong class="">Multi Tool Head.</strong></p>
<p><a class="doc-image-link" href="images/download/attachments/142647539/ExportMultiToolHead.gif" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/142647539/ExportMultiToolHead.gif" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/142647539/ExportMultiToolHead.gif" style="--doc-image-width:800px"/></a>
</p>
