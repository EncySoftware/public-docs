<div id="ht-wrap-container"><div class="ht-content" id="ht-content"><div class="ht-content-header"><h1 id="src-131898650">Chuck connector</h1></div><div class="wiki-content sp-grid-section" data-index-for-search="true" id="main-content">
<p>Once you have built the machine, the next step is to add the Chuck connector.</p>
<p>When editing the model, use only rotary axis and jaw joints.</p>
<p><a class="doc-image-link" href="images/download/attachments/131898650/image2024-4-24_13-26-44.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131898650/image2024-4-24_13-26-44.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" height="558" src="images/download/attachments/131898650/image2024-4-24_13-26-44.png" style="--doc-image-width:800px" width="800"/></a>
</p>
<p>Since the Rotary axis is initially already set correctly, only the cam limits and the coordinates at which they will move should be edited.<br/><br/></p>
<p><a class="doc-image-link" href="images/download/attachments/131898650/image2024-4-24_13-46-24.png" rel="noopener" target="_blank" title="Open full-size image"><img alt="images/download/attachments/131898650/image2024-4-24_13-46-24.png" class="confluence-embedded-image confluence-content-image-border image-center doc-image" src="images/download/attachments/131898650/image2024-4-24_13-46-24.png" style="--doc-image-width:792px"/></a>
</p>
<p>The next step is to set the home position of the jaws, test that the mechanism works correctly in the simulation and apply.</p>
