# Mechanism Simulation and Validation

Select **Simulation** tab to validate the mechanism's kinematics. Use the trackbar to change the axis coordinates or enter values in the input box manually.

![Mechanism Simulation and Validation](../assets/169674e697d0e1e947f300ae6b1beebbfee6bce1f97b4bcbec621d4a86d11fc0.png)

 Click **Demo** button to check all nodes.

Click **Home** button to return the mechanism to the Home position. Use **Set As Home** button to save the current mechanism position as Home position.

![Mechanism Simulation and Validation](../assets/2f8114b492d47bd4440985f55e1439b564f9518ce96c1380ab2a4f205fc150a6.webp)

If something looks wrong in the simulation, please check the "Building a kinematic scheme".

If you see nodes collisions, please check the "Grouping elements into nodes".

Use ![Mechanism Simulation and Validation](../assets/e99feedf4a3d658647f9663d059f14b2c559fa5af79b297e31a8cd76940825e9.png) button on the "Toolbar" to validate whole assembly.
