# Building a kinematic scheme

Click **Kinematic** tab to open kinematic parameters panel.

![Building a kinematic scheme](../assets/181002605c075db8b63d0e7db7a63eb394d78e67c907f73429e2b0fa5ef6f5fa.png)

## Kinematics

MachineMaker shows the current mechanism's 3D model and kinematic scheme. It is necessary to build correct kinematic linkage by specifying connector's positions.

![Building a kinematic scheme](../assets/feb588f8b95c7f7e444c0945cc856aaaa75d45ede7f0f1945bd54215e5ea09fb.png)

![Building a kinematic scheme](../assets/b83a3c8acfb90fda72f8044ecaed65eb3947d6b587c9771ee832218fc2b215ce.png)

There are three ways to specify connector position:

- Dimensions
- Transformation panel
- Drag&Drop and snap points

### Dimensions

Click to dimension and enter new value.

![Building a kinematic scheme](../assets/cd136751c485ebd1b8147f644a5767fa8a32d0e6b9a6a5ce8199e75f31e2375e.webp)

### Transformation panel

It is also possible to set position of any connector manually. Select connector (blue bearing for rotary joints and blue dot for "assemblies") and enter move and rotate values to the **Transformation Panel** at the right bottom corner.

![Building a kinematic scheme](../assets/49dc2681156a5b4cee87710e20c1b3b037ee7ef30e5dec14ddade3cb15065f88.webp)

Use **Mouse Wheel Scroll** to change values on any inputbox or combobox. Hold **Shift** or **Ctrl** keys while scrolling values to change values faster or slower.

### Drag&Drop and snap points

Hold **Left Ctrl** key to enter Drag&Drop mode. Drag any connector (blue bearing for rotary joints and blue dot for "assemblies"). MachineMaker will show small red snap points nearby. Release mouse button to drop object.

![Building a kinematic scheme](../assets/02ef14c6dd70ec35108b4faa1f61f19506cc8d3a9739a82352a74bffc4563aaf.webp)

## Limits

It is possible to enter limits for each node. You can find this information in DataSheets.

<img src="../assets/5b94d8c33dbff5cdc855e7035caa17106b541a5d974cf4ea464cc1e34b6ad8bc.png" alt="Building a kinematic scheme" width="414" style="height:auto">

MachineMaker shows joint's minimum and maximum values.

![Building a kinematic scheme](../assets/6c59a094cd250c4fcd58e13298dabc1fa6723ba6ff1aec344458a6e3147516de.png)

Use ![Building a kinematic scheme](../assets/c45e2e07001793d6a25a758c04a1fe9d6116a1d4a21b30fc2c0f45b1f355da64.png) or ![Building a kinematic scheme](../assets/144342ce11bbcae09ab205cc57cff96225f5f7087ddf416c9b52da38688dd72c.png) buttons to change rotation or movement direction.

Use **Unlim** switcher to allow unlimited rotation for positioners.

![Building a kinematic scheme](../assets/597d827ee7204691973a2afb52a8f405d0f942d7c4665f6533c646162baf821e.png)

## Model Position

Use **Model Position** to set joint values for current position of imported 3D model. These fields allows you to use CAD files of mechanisms, saved in non-zero positions.

For example here is the zero position of Kuka robots:

![Building a kinematic scheme](../assets/04ea6d89a8e4c528484acf26cce1ff672aec9cc1e7b069563f158c592b2cda27.png)

But [Kuka download center](https://www.kuka.com/en-de/services/downloads) provides only 3D models for non-zero robot position:

![Building a kinematic scheme](../assets/73102d22d24d53fff62e8ef6b49b69cbda13bf9ad921671c1be21edc8baed996.png)

So we can just specify **Model Position** values and use 3D models provided by Kuka. It is not necessary to change them on CAD system.

<img src="../assets/8e00fe69468457b11d8f1a62eb79864def53f0a882a5f2e2409b2bd62ae717b8.png" alt="Building a kinematic scheme" width="692" style="height:auto">

**Model Position** function is also useful for mechanisms with linear axes. For example, when editing rail limits.

![Building a kinematic scheme](../assets/a613f46d52e6a2b03fa9ad125995df95e6610368bd006e0626c112cb6bfe23ff.png)
