# Getting Started

In this chapter, you will learn how to create a project, add a new mechanism, prepare and import 3D objects, group elements into nodes, construct kinematic schemes for different mechanisms, change the color of a mechanism, model and validate mechanisms, assemble mechanisms and verify them, configure assembly parameters, and export assemblies from CAM system.
