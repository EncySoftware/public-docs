# Messerschneiden

Das CAM-System bietet zwei spezielle Messerschneidoperationen:

- [Messerschneiden 2D](10241.md)
- [Messerschneiden 6D](10242.md)

Die Operationen sind zusätzliche Optionen. **Knife cutting 6D** kann in eine Konfiguration mit kontinuierlichem 5-Achs-Fräsen aufgenommen werden. [Konfigurationen](10390.md). Beide Operationen sind in der Testversion verfügbar.

Das [Messer](10240.md) muss entlang der Bewegung ausgerichtet werden. Dafür ist eine zusätzliche Drehachse erforderlich. Unterstützt das aktive Maschinenschema diese Achse nicht, wird ein fehlerhaftes Ergebnis erzeugt.
