# Elemente erstellen und bearbeiten

Fast alle Elemente werden nach demselben Ablauf erstellt: Zunächst wird der erste Knotenpunkt des Objekts festgelegt, danach die weiteren Punkte. Mit dem letzten Punkt wird die Konstruktion des Objekts abgeschlossen und die Konstruktion des nächsten Objekts desselben Typs begonnen. Um stattdessen im Bearbeitungsmodus des Elements zu bleiben, halten Sie **Umschalt** (**Shift**) gedrückt, bevor Sie den letzten Punkt festlegen.

Alternativ können Sie Punktkoordinaten oder Parameter im **Property inspector** (Eigenschafteninspektor) eingeben. Bei der Eingabe numerischer Werte werden Berechnungen unterstützt. Sie können einen Wert daher auch als einfache Formel eingeben:

![images/download/attachments/157860143/image2024-8-7_16-38-11.png](assets/images/download/attachments/157860143/image2024-8-7_16-38-11.png)

Mit **Esc** können Sie die Konstruktion eines Elements jederzeit abbrechen. Dasselbe gilt, wenn Sie erneut auf die Schaltfläche zum Erstellen des Elements klicken.

Beim Erstellen und Bearbeiten eines Elements können Sie dessen Farbe und Linientyp festlegen. Diese Parameter werden über die Schaltflächen oberhalb des Inspektors gesteuert.

![images/download/attachments/157860143/image2024-8-7_16-39-16.png](assets/images/download/attachments/157860143/image2024-8-7_16-39-16.png)

Der Linientyp kann auch mit den Tastenkombinationen **Alt+1**, **Alt+2**, **Alt+3** und **Alt+4** geändert werden.

Einige Objekte lassen sich auf verschiedene Arten erstellen. Um eine andere Methode auszuwählen, klicken Sie auf das Dreieck in der unteren rechten Ecke der Schaltfläche oder mit der rechten Maustaste auf die Schaltfläche. Wählen Sie anschließend den gewünschten Eintrag im Dropdown-Menü.

![images/download/attachments/157860143/image2024-8-7_16-39-51.png](assets/images/download/attachments/157860143/image2024-8-7_16-39-51.png)

Für Fasen, Verrundungen, Bemaßungen und Schraffuren gelten abweichende Abläufe, die in den jeweiligen Themen beschrieben werden.
