# Biblioteca de projetos

A <strong>Biblioteca de Projetos</strong> permite encontrar e abrir projetos de exemplo da nossa biblioteca on-line. A <strong>Biblioteca de Projetos</strong> pode ser acessada diretamente pelo menu "Open Project" do sistema CAM.

![images/download/attachments/157858106/image2024-6-26_17-45-17.png](assets/images/download/attachments/157858106/image2024-6-26_17-45-17.png)

A janela principal da <strong>Biblioteca de Projetos</strong> exibe todos os projetos disponíveis que podem ser carregados no sistema CAM.

![images/download/attachments/157858106/image2024-8-5_12-8-53.png](assets/images/download/attachments/157858106/image2024-8-5_12-8-53.png)

Você pode usar o <strong>seletor de origem de projetos</strong> para exibir <strong>Todos os projetos, Favoritos, Recomendados, Pessoais</strong> ou <strong>Projetos populares</strong>.

![images/download/attachments/157858106/image2023-8-17_16-16-17.png](assets/images/download/attachments/157858106/image2023-8-17_16-16-17.png)

Os projetos podem ser pesquisados por <strong>ID, Nome, Modelo da máquina, Tipo de máquina, Operações, Ferramentas</strong>, etc. Os filtros no lado esquerdo da janela permitem pesquisas mais refinadas.

![images/download/attachments/157858106/image2024-8-5_12-9-24.png](assets/images/download/attachments/157858106/image2024-8-5_12-9-24.png)

Você também pode pesquisar projetos usando o menu de pesquisa por <strong>Operações, Ferramentas, Eixos</strong> ou <strong>Tags</strong>.

![images/download/attachments/157858106/image2023-8-22_11-46-7.png](assets/images/download/attachments/157858106/image2023-8-22_11-46-7.png)

Para copiar o ID do projeto para a área de transferência, clique no botão ![images/download/thumbnails/157858106/image2023-8-17_16-56-29.png](assets/images/download/thumbnails/157858106/image2023-8-17_16-56-29.png). O ID do projeto é útil para pesquisas futuras.

![images/download/attachments/157858106/image2023-8-17_16-55-59.png](assets/images/download/attachments/157858106/image2023-8-17_16-55-59.png)

![images/download/attachments/157858106/image2023-8-22_11-35-20.png](assets/images/download/attachments/157858106/image2023-8-22_11-35-20.png)

Para salvar um projeto em sua lista de favoritos, use o ícone ![images/download/thumbnails/157858106/image2023-8-17_16-15-10.png](assets/images/download/thumbnails/157858106/image2023-8-17_16-15-10.png).

![images/download/attachments/157858106/image2023-8-17_16-14-51.png](assets/images/download/attachments/157858106/image2023-8-17_16-14-51.png)

![images/download/attachments/157858106/image2023-8-22_11-36-36.png](assets/images/download/attachments/157858106/image2023-8-22_11-36-36.png)

Todos os valores verdes no painel de detalhes do projeto são clicáveis. Clicar em um valor o adicionará à lista de filtros e clicar nele novamente no painel de filtros o removerá.

![images/download/attachments/157858106/image2023-8-17_16-49-10.png](assets/images/download/attachments/157858106/image2023-8-17_16-49-10.png) ![images/download/attachments/157858106/image2023-8-17_16-54-7.png](assets/images/download/attachments/157858106/image2023-8-17_16-54-7.png)

Clique com o botão direito do mouse em um projeto para abrir a lista de ações. Nesse menu, você pode:

- abrir o projeto;
- abrir uma versão localizada do projeto;
- baixar o arquivo do projeto.

Você também pode abrir um projeto clicando no botão <strong>Abrir Projeto</strong> ou clicando duas vezes no projeto.

![images/download/attachments/157858106/image2024-8-5_12-10-1.png](assets/images/download/attachments/157858106/image2024-8-5_12-10-1.png)

Para carregar seu próprio projeto, clique no botão <strong>Carregar projeto</strong>.

![images/download/attachments/157858106/image2023-8-22_11-55-18.png](assets/images/download/attachments/157858106/image2023-8-22_11-55-18.png)

Depois de selecionar um projeto, você o verá carregado na <strong>Biblioteca de Projetos</strong>.

![images/download/attachments/157858106/image2023-8-22_11-56-40.png](assets/images/download/attachments/157858106/image2023-8-22_11-56-40.png)

![images/download/attachments/157858106/image2024-8-5_12-10-29.png](assets/images/download/attachments/157858106/image2024-8-5_12-10-29.png)

Você pode excluir ou editar seus projetos.

![images/download/attachments/157858106/image2023-8-22_11-48-28.png](assets/images/download/attachments/157858106/image2023-8-22_11-48-28.png)

Ao editar, você pode adicionar uma descrição ou alterar o nome do projeto.

![images/download/attachments/157858106/image2023-8-22_11-53-39.png](assets/images/download/attachments/157858106/image2023-8-22_11-53-39.png)

O botão <strong>Fixar janela</strong> no canto superior esquerdo da janela alterna a <strong>Biblioteca de Projetos</strong> para o modo compacto e mantém a janela sobre as demais.

![images/download/attachments/157858106/image2023-8-22_11-42-43.png](assets/images/download/attachments/157858106/image2023-8-22_11-42-43.png)
