# Übersicht der Bearbeitungsoperationen

Die folgende Übersicht beschreibt die in dieser Version des CAM-Systems verfügbaren Operationen.

<div class="operation-catalog">

| <strong>[Struktur der Operationsgruppen](1023.md)</strong> |   |
|---|---|
| [Aufspannung](1024.md) |   |
| ![images/download/attachments/157862955/StageOp.png](assets/images/download/attachments/157862955/StageOp.png) | Definiert einen Fertigungsabschnitt, in dem das Bauteil in einer festen Aufspannung bleibt und von verschiedenen Seiten bearbeitet werden kann. Bauteil, Werkstück und weitere Objekte vorheriger Aufspannungen werden ausgeblendet, damit sie nachfolgende Aufspannungen nicht beeinflussen. Innerhalb der Gruppe können Vorrichtungen angelegt werden, die in untergeordneten Projekten vom Typ Bauteil oder Bauteilkopie berücksichtigt werden. |
|   |   |
| [Bauteilgruppe](1025.md) |   |
| ![images/download/attachments/157862955/PartOp.png](assets/images/download/attachments/157862955/PartOp.png) | Erstellt Projekte mit mehreren unterschiedlichen oder gleichartigen Bauteilen, deren Operationen nach technologischen Gesichtspunkten gegliedert werden, ähnlich einer Fertigungslinie. Auf der Registerkarte **Einrichtung** werden unter anderem Bauteillage und Koordinatensystem festgelegt. Außerdem stehen Transformationen der Werkzeugbahnkoordinaten zur Verfügung. |
|   |   |
| [Bauteilkopie](1026.md) |   |
| ![images/download/attachments/157862955/PartCopy.png](assets/images/download/attachments/157862955/PartCopy.png) | Erstellt Projekte mit mehreren identischen Bauteilen. Zunächst wird ein Musterbauteil mit den erforderlichen Operationen angelegt; anschließend wird daraus eine Bauteilkopie erzeugt. Die Kopien bleiben mit dem Muster synchronisiert: Operationen können in einer Kopie nicht eigenständig hinzugefügt oder gelöscht werden. Änderungen am Operationsbestand des Musters werden auf alle Kopien übertragen. Die Kopien berechnen keine eigenen Bahnen, sondern übernehmen die Bahnen des Musters an ihrer jeweiligen Position. Wird die Berechnung des Musters zurückgesetzt, müssen die Kopien manuell neu berechnet werden. Sofern der Postprozessor dies unterstützt, kann die Ausgabe über Unterprogrammaufrufe erfolgen. Die Registerkarte **Einrichtung** legt Lage, Werkstück und Koordinatensystem der Kopie fest. |
|   |   |
| [Vervielfältigungsgruppe](1027.md) |   |
| ![images/download/attachments/157862955/MultiplyGroup.png](assets/images/download/attachments/157862955/MultiplyGroup.png) | Definiert Regeln zum Vervielfältigen von Bahnen, die an die enthaltenen Operationen vererbt werden. Die Operationen bearbeiten einzelne Bauteilmerkmale; die Gruppe überträgt die Ergebnisse gemäß den vorgegebenen Regeln auf alle gleichartigen Merkmale. Die Regeln werden auf der Registerkarte **Transformationen** festgelegt. |
