| [Etapa de configuração](1024.md) |   |
| ![images/download/attachments/157862955/StageOp.png](assets/images/download/attachments/157862955/StageOp.png) | Esse grupo se destina a definir a etapa do processo de fabricação em que a peça permanece em uma posição fixa. Ele permite usinar a peça por lados diferentes, sem que as configurações anteriores interfiram nas seguintes, pois a peça, o bruto e outros objetos das configurações anteriores ficam ocultos. |   |   |
| [Peça](1025.md) |   |
| ![images/download/attachments/157862955/PartOp.png](assets/images/download/attachments/157862955/PartOp.png) | Esse grupo é usado para criar projetos com vários componentes: várias peças diferentes ou peças padronizadas, divididas em operações conforme a tecnologia (de forma semelhante a uma linha de produção). A aba Setup desse grupo é usada para configurar os parâmetros principais do projeto, como o posicionamento da peça no equipamento, o sistema de coordenadas da peça etc. Para esse grupo também está disponível um conjunto de transformações para converter as coordenadas do percurso da ferramenta. |
|   |   |
| [Cópia da peça](1026.md) |   |
| ![images/download/attachments/157862955/PartCopy.png](assets/images/download/attachments/157862955/PartCopy.png) | Tipo especial de grupo destinado à preparação de um projeto com várias peças idênticas. O fluxo de trabalho normalmente é o seguinte: cria-se uma Part protótipo com as operações necessárias; depois, cria-se uma Copy of Part, que usa o protótipo como modelo. As cópias são sincronizadas com o protótipo — não é possível adicionar nem excluir operações dentro de uma cópia: quando uma operação é criada ou excluída no protótipo, as cópias correspondentes das operações são criadas ou excluídas automaticamente em todas as cópias. As operações das cópias não calculam o percurso da ferramenta por conta própria, mas aplicam o percurso do protótipo à posição da cópia; ao redefinir o cálculo do protótipo, é necessário recalcular as cópias manualmente. Para as cópias, a saída pode ser configurada por meio de chamadas de subprogramas (se o pós-processador oferecer suporte). A aba Setup em Copy of Part é usada para especificar a posição, o bruto e o sistema de coordenadas da cópia. |
|   |   |
| [Grupo de multiplicação](1027.md) |   |
| ![images/download/attachments/157862955/MultiplyGroup.png](assets/images/download/attachments/157862955/MultiplyGroup.png) | Grupo que define os métodos de cópia dos percursos; essas regras são então herdadas pelas operações dentro do grupo. Assim, as operações podem processar elementos individuais de uma peça, enquanto o próprio grupo propaga automaticamente os resultados a todos os elementos padronizados conforme as regras definidas. A cópia é feita de acordo com as regras da aba Transformations. |
