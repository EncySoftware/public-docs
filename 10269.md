# Mehrkanalbearbeitung

Multitasking-Maschinen (MTM) können mit mehreren Werkzeugen gleichzeitig arbeiten. Ihr Aufbau ist unterschiedlich: Ein Dreh-Fräs-Zentrum kann beispielsweise mehrere Spindeln und Werkzeugrevolver in einem Maschinenraum besitzen. Andere Anlagen bestehen aus zwei oder mehr gleichartigen Maschinen, die gemeinsam ein Werkstück bearbeiten.

Bei der Mehrkanalbearbeitung wird jedes Werkzeug über ein eigenes Programm in einem Steuerungskanal geführt. Die Maschine besitzt entsprechend mehrere Kanäle. In einfachen Fällen lassen sich die Kanalprogramme unabhängig voneinander erstellen. Sobald ein Kanal jedoch die Bearbeitungsergebnisse eines anderen berücksichtigen muss oder mehrere Kanäle im selben Arbeitsraum zusammenarbeiten, reicht diese getrennte Betrachtung nicht aus.

Das CAM-System unterstützt die Programmierung von Mehrkanalmaschinen. Dazu muss das entsprechende [kinematische Schema geladen](341.md) werden. Zum Erproben stehen im Standardpaket Schemas für das Dreh-Fräs-Zentrum Index G160 und eine Doppel-Fräsmaschine von FPT zur Verfügung. Ein Schema für die eigene Anlage erhalten Sie über Ihren Vertriebspartner.

Auf der Registerkarte **Technology** entspricht die Programmierung weitgehend der einer Einkanalmaschine. Der ausgewählte Werkzeughalter bestimmt den Bearbeitungskanal. Bei der Planung sollten die Bearbeitungszeiten der Kanäle möglichst aufeinander abgestimmt werden.

Auf der Registerkarte **Simulation** kann bei Multitasking-Maschinen der Simulationsmodus ausgewählt werden:

![images/download/attachments/157866306/image2024-7-30_16-22-39.png](assets/images/download/attachments/157866306/image2024-7-30_16-22-39.png)

Im **Einkanalmodus** werden die Operationen nacheinander simuliert. So lässt sich die Werkzeugbahn einer einzelnen Operation unabhängig von den anderen Kanälen untersuchen.

Im **Mehrkanalmodus** läuft die Simulation wie an der realen Anlage gleichzeitig in allen Kanälen. Die Kollisionsprüfung berücksichtigt dabei deren gemeinsame Bewegungen. Erkannte Konflikte können durch geeignete Synchronisationspunkte vermieden werden.

Der **Mehrkanalmodus mit Synchronisationslinien** erleichtert das Hinzufügen, Entfernen und Bearbeiten von Synchronisationspunkten.

Synchronisationspunkte

Ein Synchronisationspunkt hält einen Kanal an, bis ein anderer Kanal den zugehörigen Programmsatz erreicht hat. Viele CNC-Steuerungen verwenden dafür M-Codes. Steht beispielsweise M500 für einen Synchronisationspunkt, muss dieser Code in mehreren Kanälen vorkommen. Der zuerst dort ankommende Kanal wartet, bis auch der andere Kanal M500 erreicht. Anschließend setzen beide die Ausführung mit den nachfolgenden Befehlen fort.

Die folgenden Schaltflächen dienen zum Einfügen und Entfernen von Synchronisationspunkten:

![images/download/attachments/157866306/image2024-7-17_17-3-1.png](assets/images/download/attachments/157866306/image2024-7-17_17-3-1.png)

Wählen Sie in jedem Kanal die Befehle aus, die gleichzeitig beginnen sollen, und klicken Sie auf **Synchronisationspunkt hinzufügen**. Vor den ausgewählten Befehlen wird **WAIT** eingefügt. In Kanälen mit kürzerer berechneter Laufzeit bis zu diesem Punkt erscheint **WAIT** rot; die Wartezeit wird in geschweiften Klammern angezeigt.

![images/download/attachments/157866306/image2024-7-17_17-6-6.png](assets/images/download/attachments/157866306/image2024-7-17_17-6-6.png)

Synchronisationspunkte werden im Projekt und nicht in einzelnen Operationen gespeichert. Dadurch können sie nach einer Neuberechnung anhand der Maschinenpositionen wieder zugeordnet werden. Nach Änderungen des Vorschubs, der Approximationstoleranz oder anderen geringfügigen Bahnänderungen bleibt die Zuordnung in der Regel erhalten. Nach wesentlichen Änderungen der Werkzeugbahn sollten die Synchronisationspunkte neu gesetzt werden.

Zum Löschen eines Synchronisationspunkts wählen Sie den zugehörigen **WAIT**-Befehl in einem beliebigen Kanal und klicken auf **Synchronisationspunkt löschen**.

Wird eine Operation nach dem Einfügen von Synchronisationspunkten gelöscht, deaktiviert oder verschoben, lassen sich einzelne Punkte möglicherweise nicht mehr in allen Kanälen zuordnen. Sie werden als ungültig markiert. Mit **Ungültige Synchronisationspunkte löschen** entfernen Sie diese Einträge.

Mit **Alle Synchronisationspunkte löschen** wird die gesamte Synchronisation entfernt.
