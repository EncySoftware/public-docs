# IronCAD™-Symbolleiste

![images/download/attachments/157859622/IronCADFromAddinManager.png](assets/images/download/attachments/157859622/IronCADFromAddinManager.png)

Über die Symbolleiste können Sie geometrische Daten aus IronCAD™ exportieren. Die unterstützten CAD-Versionen sind in der Übersicht aufgeführt. [Details](10039.md)

![images/download/attachments/157859622/image2022-3-30_12-23-41.png](assets/images/download/attachments/157859622/image2022-3-30_12-23-41.png)

Nach der Installation wird die Symbolleiste möglicherweise nicht in IronCAD™ angezeigt. Klicken Sie in diesem Fall auf die folgende Schaltfläche

![images/download/attachments/157859622/IronCADBtmAppAddin.png](assets/images/download/attachments/157859622/IronCADBtmAppAddin.png)

und aktivieren Sie die Symbolleiste im Dialogfenster:

![images/download/attachments/157859622/IronCADFrmAppAddin.png](assets/images/download/attachments/157859622/IronCADFrmAppAddin.png)

Unterstützte Dateierweiterungen: ICS, IC3D, ICSW, ICD, EXB. Damit diese Option funktioniert, muss die erforderliche Anwendung (IronCAD™) auf Ihrem Computer installiert sein.
