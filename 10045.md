# IronCAD™ toolbar

![images/download/attachments/157859622/IronCADFromAddinManager.png](assets/images/download/attachments/157859622/IronCADFromAddinManager.png)

The toolbar allows you to export geometric data from IronCAD™. You can view the version of the supported CAD system. [Details](10039.md)

![images/download/attachments/157859622/image2022-3-30_12-23-41.png](assets/images/download/attachments/157859622/image2022-3-30_12-23-41.png)

Once installed, the toolbar may not appear in IronCAD™. Then you need to press

![images/download/attachments/157859622/IronCADBtmAppAddin.png](assets/images/download/attachments/157859622/IronCADBtmAppAddin.png)

in the dialog box to activate it:

![images/download/attachments/157859622/IronCADFrmAppAddin.png](assets/images/download/attachments/157859622/IronCADFrmAppAddin.png)

Supported file extensions: ICS, IC3D, ICSW, ICD, EXB. The required application (IronCAD™) must be installed on your computer for this option to work.
