# Mehrere Projekte gleichzeitig bearbeiten

Die **Multiproject**-Oberfläche fasst mehrere Anwendungsfenster als Registerkarten zusammen. Projekte können in getrennten Instanzen erstellt und angehängt werden. Die Arbeit mit nur einem Fenster bleibt ebenfalls möglich.

<a id="optionen-zum-öffnen-eines-zusätzlichen-fensters"></a>

## Zusätzliches Projektfenster öffnen

1. **Aus dem aktuellen Fenster:** ![Ein Projekt](assets/images/download/attachments/157858893/image2023-10-13_12-4-9.png) → Benutzeraktion → ![Mehrere Projekte](assets/images/download/attachments/157858893/image2023-10-13_12-5-5.png)
   - Öffnen Sie das Menü von **New Project** ![Neues Projekt](assets/images/download/thumbnails/157858893/image2023-10-13_9-19-36.png) und wählen Sie **New Project in New Tab**.
   - Öffnen Sie das Menü von **Open Project** ![Projekt öffnen](assets/images/download/thumbnails/157858893/image2023-10-13_9-22-1.png) und wählen Sie **Open Project in New Tab**.
   - Auch ein zuletzt verwendetes Projekt im Menü ![Zuletzt verwendet](assets/images/download/thumbnails/157858893/image2023-10-13_9-22-1.png) kann über sein Untermenü in einer neuen Registerkarte geöffnet werden.
   - Für eine Maschinenvorlage wählen Sie im Menü **New Project** ![Neu](assets/images/download/thumbnails/157858893/image2023-10-13_9-19-36.png) den Eintrag **New Project with machine setup in new tab** ![Maschinenvorlage](assets/images/download/thumbnails/157858893/image2023-10-13_9-30-4.png).
2. **Aus externen Anwendungen:**

- Exportieren Sie aus einem externen CAD-System.
- Exportieren Sie aus MachineMaker.
- Öffnen Sie ein Projekt aus der Projektbibliothek.
- Doppelklicken Sie eine Projektdatei oder ziehen Sie sie in die Anwendung.

Der Ablauf ist wie folgt:

![Externes Projekt](assets/images/download/thumbnails/157858893/image2023-10-13_10-42-32.png) → ![Aktuelles Fenster](assets/images/download/attachments/157858893/image2023-10-13_12-4-9.png) → ![Mehrere Registerkarten](assets/images/download/attachments/157858893/image2023-10-13_12-5-5.png)

<a id="wichtige-punkte-beim-öffnen-eines-zusätzlichen-fensters-durch-externe-systeme"></a>

## Verhalten beim externen Öffnen

1. Ist das aktuelle Fenster leer, werden importierte Daten dort geladen.
2. Enthält es bereits Daten oder Änderungen, fragt das System nach dem Zielfenster.

![images/download/attachments/157858893/image2023-10-13_12-12-26.png](assets/images/download/attachments/157858893/image2023-10-13_12-12-26.png)

Sie entscheiden damit zwischen einer einzelnen und mehreren gleichzeitig geöffneten Projektregisterkarten.

Beim Beenden mit ungespeicherten Änderungen bietet das System das Speichern an. Es beginnt beim aktuellen Projekt und fragt nacheinander die übrigen Registerkarten ab.

![images/download/attachments/157858893/image2023-10-13_14-43-37.png](assets/images/download/attachments/157858893/image2023-10-13_14-43-37.png)

<a id="project-navigation"></a>

## Projektnavigation

**Projektliste:**

- Das Namensfeld zeigt die aktuelle Projektdatei. ![Projektname](assets/images/download/attachments/157858893/image2023-10-13_12-4-9.png)
- Die Registerkartenanzahl entspricht der Zahl zusammengefasster Projekte.
- Beim Laden einer neuen Registerkarte erscheint eine animierte Fortschrittsanzeige. ![Laden](assets/images/download/attachments/157858893/image2023-10-1_22-20-17.png)
- Das aktive Projekt ist dunkler hervorgehoben. Anklicken einer anderen Registerkarte aktiviert sie; beim Überfahren erscheint ihre Schließen-Schaltfläche. ![Registerkarten](assets/images/download/attachments/157858893/image2023-10-13_12-5-5.png)
- Laufende Berechnungen werden mit einer kurzen Beschreibung angezeigt.

![images/download/attachments/157858893/image2023-10-13_11-9-9.png](assets/images/download/attachments/157858893/image2023-10-13_11-9-9.png)

Operationen können mit **Strg+C/Strg+V** oder **Copy/Paste** zwischen Projekten kopiert werden.

**Zwei Fenster mit demselben Namen können nicht gleichzeitig geöffnet werden. Das System meldet in diesem Fall einen Fehler.**
