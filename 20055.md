# Surfaces in the sketch

The **Surface** button creates surfaces from sketch curves: planar profiles and space curves. Select the method from the button menu, then select the curves in order. Inspector buttons identify the roles (rail, profile or boundary); select a role again to replace its curve. The surface is created immediately and updates with the source curves.

## Construction methods

| Method | Selection order |
|---|---|
| **Sweep 1 rail** | Rail, then profile |
| **Sweep 2 rails** | Rail 1, rail 2, profile |
| **Revolve** | Profile, then axis |
| **Loft 2 rails** | Rail 1, rail 2, profile 1, profile 2 |
| **Ruled surface** | Two curves; straight lines join their corresponding points |
| **Loft 1 rail** | Rail, profile 1, profile 2 |
| **Coons patch** | One closed boundary |

## Method parameters

**Sweep 1 rail.** **Orientation** selects **Parallel** or **Normal to path**. **Closed sweep** closes the sweep. **Anchor** selects **Start**, **End**, **Centroid** or **Custom**. **Profile rotation** about X/Y/Z is available only with **Parallel** and a planar profile.

**Sweep 2 rails.** **Section method** selects **Scale to rails** or **Blend rails**. **Profile rotation** controls the profile rotation.

**Revolve.** **Axis** selects the plane coordinate system X/Y/Z axis or a selected line. **Angle** sets the start and end angles. **Pitch** specifies **Axial** and **Radial** advance per revolution. Both zero produce a simple revolution; nonzero axial pitch produces a helical surface, and nonzero radial pitch produces a spiral.

**Loft 2 rails.** **Model** selects **Loft** or **Coons**. **Twist profile 1** and **Twist profile 2** adjust the profiles.

**Loft 1 rail.** Provides **Orientation**, **Closed sweep**, **Twist profile 1**, **Twist profile 2** and **Anchor**.

**Coons patch.** **Corners** specifies four corners as fractions of boundary length from 0 to 1. Defaults follow boundary breaks; **Reset** restores them. **3D boundary** constructs the patch using a space boundary. Tangency is controlled by **Tangent profile 1**, **Tangent profile 2**, **Tangent rail 1** and **Tangent rail 2**.

## Display and trimming

**Isocurve density.** Values for U and V, from 0 to 200, specify additional lines beyond the knot lines.

**Shade**, **Wireframe**. Change display only.

**Trim by** shows the trimming curve with **Cut inside** and **Cut outside** buttons. Click the selected button again to remove trimming. Only a curve linked to this surface, such as a projected profile or isocurve, can trim it. A curve with broken links cannot trim the surface.
