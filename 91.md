# Criação de uma nova operação

![images/download/attachments/157861105/image2026-6-23_11-37-25.png](assets/images/download/attachments/157861105/image2026-6-23_11-37-25.png)

## Área de aplicação:

Para adicionar uma nova operação de usinagem ao processo técnico, o sistema CAM oferece uma janela de criação específica, na qual é possível navegar, pesquisar e configurar operações antes de adicioná-las ao projeto.

Há duas maneiras de trabalhar ao criar uma operação:

- A primeira é mais adequada para iniciantes que estão conhecendo o sistema.

<details>
<summary>Clique aqui para expandir..</summary>

Para abrir a janela de criação de uma nova operação de usinagem, clique no botão ![images/download/attachments/157861105/image2024-7-4_16-21-22.png](assets/images/download/attachments/157861105/image2024-7-4_16-21-22.png).

Em seguida, a janela de criação de operações será exibida. Esse modo é preferível para novos usuários, pois permite visualizar os detalhes da operação.

Há duas maneiras de criar uma operação na janela.

- Ao clicar duas vezes com o botão esquerdo do mouse sobre a operação, uma operação do tipo correspondente é adicionada ao processo técnico. A janela de criação de operações permanece aberta.
- Para criar uma operação, selecione-a na lista e clique no botão "Create"; a operação será criada e a janela será fechada.

![images/download/attachments/157861105/image2026-6-23_11-37-25.png](assets/images/download/attachments/157861105/image2026-6-23_11-37-25.png)

</details>

- A segunda é destinada a usuários mais experientes.

<details>
<summary>Clique aqui para expandir..</summary>

Há também mais uma maneira rápida e fácil de criar uma nova operação. Para criar uma operação, clique na seta ao lado de ![images/download/attachments/157861105/image2024-7-4_16-21-22.png](assets/images/download/attachments/157861105/image2024-7-4_16-21-22.png) e escolha no menu o tipo de operação desejado.

Esse método de criação de operações acelera significativamente o trabalho, pois elimina a necessidade de abrir e fechar constantemente as janelas.

![images/download/attachments/157861105/image2024-7-4_16-23-54.png](assets/images/download/attachments/157861105/image2024-7-4_16-23-54.png)

</details>

A janela de criação é dividida em três painéis:

- <strong>Painel esquerdo</strong> — lista os grupos de operações para a seleção da categoria.
- <strong>Painel central</strong> — exibe as operações que pertencem ao grupo selecionado.
- <strong>Painel direito</strong> — mostra detalhes sobre a operação destacada no momento.

![images/download/attachments/157861105/image2026-6-26_10-6-47.png](assets/images/download/attachments/157861105/image2026-6-26_10-6-47.png)

### Painel direito.

Esse painel apresenta detalhes da operação selecionada e oferece os seguintes recursos:

<strong>Definição do nome da operação.</strong> O nome pode ser definido no campo <strong>Define the operation name</strong>.

<strong>Cópia das configurações de uma operação existente.</strong> Ativada pela caixa de seleção <strong>Fill parameters by operation</strong>; a operação de origem é selecionada na lista suspensa.

<strong>Imagem explicativa com reprodução de vídeo.</strong> Fica na parte inferior do painel; um único clique inicia ou para a reprodução do vídeo.

### Barra de ferramentas.

A <strong>barra de ferramentas inferior</strong> oferece funções para gerenciar o conteúdo exibido na janela. Ela contém os seguintes elementos:

<strong>Botão de ajuda (ponto de interrogação).</strong> Abre a seção da ajuda sobre este tópico.

<strong>Customize...</strong> Define quais operações e grupos devem ficar visíveis nesta janela e no menu suspenso <strong>Create operation</strong>.

<details>
<summary>Clique aqui para expandir..</summary>

O layout atualizado da janela introduz controles avançados para gerenciar operações e grupos, conforme detalhado abaixo:

- <strong>Controles adicionais ao lado das operações e dos grupos</strong> — novos botões e caixas de seleção são exibidos ao lado dos nomes das operações e dos grupos. As caixas de seleção determinam a visibilidade das operações e dos grupos correspondentes na interface.
- <strong>Arrastar e soltar</strong> — as operações podem ser movidas entre grupos arrastando e soltando.
- <strong>Criação e exclusão de grupos</strong> — é possível criar novos grupos e excluir grupos existentes com os botões específicos na parte superior da janela.
- <strong>Alteração do nome do grupo</strong> — o nome de qualquer grupo pode ser editado clicando nele e digitando um novo nome.
- <strong>Reposicionamento e aninhamento de grupos</strong> — os grupos podem ser movidos para outros locais da hierarquia ou colocados dentro de outros grupos arrastando e soltando.

![images/download/attachments/157861105/image2026-6-26_11-49-45.png](assets/images/download/attachments/157861105/image2026-6-26_11-49-45.png)

<strong>Create configuration.</strong> Adiciona uma nova configuração; todas as propriedades são copiadas da configuração atual.

<strong>Remove configuration.</strong> Remove a configuração atual. A última configuração da lista não pode ser removida.

<strong>Add group.</strong> Adiciona um novo grupo de operações. Use-o para criar um submenu no menu suspenso "Create operation". Clique em um grupo para alterar o nome. É possível arrastar operações para qualquer grupo.

<strong>Remove group.</strong> Remove o grupo de operações selecionado.

<strong>Export current configuration.</strong> Exporta a configuração atual para um arquivo externo. Será criado um arquivo ZIP. Os <strong>User defaults</strong> do Inspector também serão exportados. [Detalhes](100159.md)

<strong>Import current configuration.</strong> Importa a configuração para o sistema.

<strong>Unavailable.</strong> Mostra as operações que não estão disponíveis no momento. As operações podem ficar indisponíveis devido ao tipo de máquina ou à disponibilidade de licença.

<details>
<summary>Clique aqui para expandir..</summary>

O motivo pelo qual uma operação não está disponível é exibido no painel direito.

![images/download/thumbnails/157861105/image2026-6-26_10-52-40.png](assets/images/download/thumbnails/157861105/image2026-6-26_10-52-40.png)

</details>

<strong>Operation preset.</strong> Mostra as operações predefinidas para a usinagem. ( Express, Cutting, Cutting 5D, 2.5X Mill, 3X Mill, 3X Mill Advanced, Rotary, 5X Mill, 5X Mill Advanced). Dependendo da predefinição selecionada, os grupos e o conjunto de operações mudam.

<strong>Options.</strong> Permite ativar opções.

<details>
<summary>Clique aqui para expandir..</summary>

Entre as opções disponíveis, há a opção <strong>3+2 mode</strong>.

Se o usuário tiver uma licença (por exemplo, 3X Mill Advanced) e essa opção estiver ativada (<strong>ON</strong>), a operação será criada com o parâmetro <strong>Local CS</strong> visível na <strong>guia</strong> <strong>Setup</strong>. [Detalhes](1022.md) Isso permite a usinagem no modo 3+2.

Se a opção estiver desativada (<strong>OFF</strong>), o parâmetro <strong>Local CS</strong> não será exibido.

Essa opção também afeta os seguintes parâmetros:

- <strong>Approximate safe motions;</strong>
- <strong>Safe surface (Cylinder, Sphere);</strong>
- <strong>Rotary Transformations.</strong>

</details>
