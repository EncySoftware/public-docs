# Neue Operation erstellen

![images/download/attachments/157861105/image2026-6-23_11-37-25.png](assets/images/download/attachments/157861105/image2026-6-23_11-37-25.png)

<a id="application-area-1"></a>

## Anwendungsbereich:

Im Erstellungsfenster können Bearbeitungsoperationen gesucht, ausgewählt und vor dem Hinzufügen zum Projekt eingerichtet werden.

Es stehen zwei Vorgehensweisen zur Verfügung:

- Das Erstellungsfenster eignet sich besonders für die Einarbeitung.

<details>
<summary>Weitere Informationen anzeigen</summary>

Öffnen Sie es mit ![Operation erstellen](assets/images/download/attachments/157861105/image2024-7-4_16-21-22.png).

Das Fenster zeigt zusätzliche Informationen zu den Operationen und erleichtert damit die Auswahl.

Eine Operation kann auf zwei Arten angelegt werden:

- Doppelklicken Sie auf den gewünschten Operationstyp. Die Operation wird hinzugefügt und das Fenster bleibt geöffnet.
- Wählen Sie den Typ und klicken Sie auf **Create**. Die Operation wird erstellt und das Fenster geschlossen.

![images/download/attachments/157861105/image2026-6-23_11-37-25.png](assets/images/download/attachments/157861105/image2026-6-23_11-37-25.png)

</details>

- Das Schnellmenü eignet sich für erfahrene Anwender.

<details>
<summary>Weitere Informationen anzeigen</summary>

Klicken Sie auf den Pfeil neben ![Operationsmenü](assets/images/download/attachments/157861105/image2024-7-4_16-21-22.png) und wählen Sie den gewünschten Operationstyp direkt im Menü.

Dadurch entfällt das wiederholte Öffnen und Schließen des Erstellungsfensters.

![images/download/attachments/157861105/image2024-7-4_16-23-54.png](assets/images/download/attachments/157861105/image2024-7-4_16-23-54.png)

</details>

Das Erstellungsfenster besitzt drei Bereiche:

- Links: Operationsgruppen zur Auswahl einer Kategorie.
- Mitte: Operationen der ausgewählten Gruppe.
- Rechts: Informationen zur markierten Operation.

![images/download/attachments/157861105/image2026-6-26_10-6-47.png](assets/images/download/attachments/157861105/image2026-6-26_10-6-47.png)

<a id="right-pane-1"></a>

### Rechter Bereich.

Hier stehen folgende Informationen und Einstellungen zur Verfügung:

**Operationsname.** Unter **Define the operation name** kann der Name vorgegeben werden.

**Einstellungen übernehmen.** **Fill parameters by operation** kopiert Parameter aus einer vorhandenen Operation, die in der Liste ausgewählt wird.

**Erläuternde Abbildung mit Video.** Ein Klick auf die Abbildung unten startet oder stoppt die Videowiedergabe.

<a id="toolbar-1"></a>

### Symbolleiste.

Die untere Symbolleiste steuert die im Fenster angezeigten Inhalte:

**Hilfeschaltfläche.** Öffnet die Hilfe zu diesem Thema.

**Customize…** Legt fest, welche Operationen und Gruppen im Fenster und im Menü **Create operation** erscheinen.

<details>
<summary>Weitere Informationen anzeigen</summary>

Im Anpassungsmodus stehen folgende Funktionen zur Verfügung:

- Schaltflächen und Kontrollkästchen neben Gruppen und Operationen steuern deren Sichtbarkeit.
- Operationen können per Drag-and-drop zwischen Gruppen verschoben werden.
- Gruppen werden über die Schaltflächen oben angelegt oder entfernt.
- Ein Klick auf einen Gruppennamen ermöglicht dessen Änderung.
- Gruppen können per Drag-and-drop umgeordnet oder ineinander verschachtelt werden.

![images/download/attachments/157861105/image2026-6-26_11-49-45.png](assets/images/download/attachments/157861105/image2026-6-26_11-49-45.png)

**Create configuration.** Erstellt eine Konfiguration als Kopie der aktuellen Einstellungen.

**Remove configuration.** Entfernt die aktuelle Konfiguration. Der letzte verbleibende Eintrag kann nicht entfernt werden.

**Add group.** Erstellt eine Operationsgruppe und damit ein Untermenü in **Create operation**. Der Name kann durch Anklicken geändert werden; Operationen werden hineingezogen.

**Remove group.** Entfernt die ausgewählte Gruppe.

**Export current configuration.** Exportiert die Konfiguration als ZIP-Archiv. Auch die Benutzervorgaben des Inspektors werden übernommen. [Details](100159.md)

**Import current configuration.** Importiert eine Konfiguration in das System.

**Beispiel einer eigenen Konfiguration:**

Erstellen Sie zunächst eine Konfiguration. Sie erscheint mit dem Namen **New Configuration**.

![images/download/attachments/157861105/image2026-6-26_12-2-41.png](assets/images/download/attachments/157861105/image2026-6-26_12-2-41.png)

Deaktivieren Sie alle Gruppen.

![images/download/attachments/157861105/image2026-6-26_12-4-12.png](assets/images/download/attachments/157861105/image2026-6-26_12-4-12.png)

Erstellen Sie mit **Add Group** eine Gruppe namens **Mill Quickly**.

![images/download/attachments/157861105/image2026-6-26_12-5-41.png](assets/images/download/attachments/157861105/image2026-6-26_12-5-41.png)

Ziehen Sie die gewünschten Operationen in diese Gruppe.

![images/download/attachments/157861105/image2026-6-26_12-6-57.png](assets/images/download/attachments/157861105/image2026-6-26_12-6-57.png)

Klicken Sie auf **Customize…**, um zur normalen Ansicht zurückzukehren. Die eigene Gruppe wird im Erstellungsfenster angezeigt.

![images/download/attachments/157861105/image2026-6-26_12-7-44.png](assets/images/download/attachments/157861105/image2026-6-26_12-7-44.png)

Sie erscheint auch im Dropdown-Menü.

![images/download/attachments/157861105/image2026-6-26_12-9-9.png](assets/images/download/attachments/157861105/image2026-6-26_12-9-9.png)

Die Konfiguration kann umbenannt werden.

![images/download/attachments/157861105/image2026-6-26_16-47-35.png](assets/images/download/attachments/157861105/image2026-6-26_16-47-35.png)

</details>

**Unavailable.** Blendet derzeit nicht verfügbare Operationen ein. Gründe können Maschinentyp oder fehlende Lizenz sein.

<details>
<summary>Weitere Informationen anzeigen</summary>

Der Grund für die fehlende Verfügbarkeit wird rechts angezeigt.

![images/download/thumbnails/157861105/image2026-6-26_10-52-40.png](assets/images/download/thumbnails/157861105/image2026-6-26_10-52-40.png)

</details>

**Operation preset.** Wählt eine Operationszusammenstellung: Express, Cutting, Cutting 5D, 2.5X Mill, 3X Mill, 3X Mill Advanced, Rotary, 5X Mill oder 5X Mill Advanced. Die Auswahl bestimmt die angezeigten Gruppen und Operationen.

**Options.** Aktiviert zusätzliche Optionen.

<details>
<summary>Weitere Informationen anzeigen</summary>

Hier steht unter anderem **3+2 mode** zur Verfügung.

Bei geeigneter Lizenz, beispielsweise 3X Mill Advanced, und aktiviertem 3+2-Modus wird **Local CS** auf der Registerkarte **Setup** neuer Operationen eingeblendet. Dies ermöglicht indexierte 3+2-Bearbeitung. [Details](1022.md)

Bei deaktivierter Option wird **Local CS** nicht angezeigt.

Die Option beeinflusst außerdem:

- **Approximate safe motions**;
- **Safe surface** mit Cylinder und Sphere;
- **Rotary Transformations**.

</details>
