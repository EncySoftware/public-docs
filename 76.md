# Aufmaß

Das Aufmaß ist eine Materialschicht auf der Bauteiloberfläche, die nach einer Operation für die weitere Bearbeitung verbleiben soll.

Ein positives Aufmaß legt die zusätzlich verbleibende Materialdicke fest. Ein negatives Aufmaß gibt an, wie viel Material über die Solloberfläche hinaus entfernt wird.

Die minimale Restmaterialdicke entspricht nur dann genau dem Aufmaß, wenn die innere Abweichung null ist. Andernfalls kann sie um den Betrag der inneren Abweichung kleiner sein.

Das Aufmaß wird auf der Seite **Parameters** (Parameter) festgelegt.
