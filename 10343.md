# Creazione di utensili sagomati

Utilizzare un utensile sagomato per eseguire lavorazioni di forma.

Per supportare questo tipo di lavorazione, il sistema CAM consente di definire un utensile sagomato mediante un contorno (sagoma).

Per gli utensili di fresatura, il contorno dell'utensile deve essere specificato come linea generatrice. È disponibile nelle operazioni [Contornatura 2D](404.md), [Contornatura 3D](700.md) e [Contornatura 5D](10129.md).

La curva può essere ricavata direttamente dal modello oppure creata con la funzione **Sketch** (schizzo).

Per creare un utensile sagomato, eseguire le fasi seguenti:

Passare alla modalità **Drawing** (disegno) ![images/download/thumbnails/157867684/image2024-7-26_15-41-18.png](assets/images/download/thumbnails/157867684/image2024-7-26_15-41-18.png) e disegnare la sagoma (profilo) dell'utensile. Se necessario, il contorno può essere parametrizzato.

![images/download/attachments/157867684/image2024-7-26_15-42-43.png](assets/images/download/attachments/157867684/image2024-7-26_15-42-43.png)

![images/download/attachments/157867684/image2024-7-26_15-45-16.png](assets/images/download/attachments/157867684/image2024-7-26_15-45-16.png)

Selezionarla nell'elenco o nella vista. Fare clic con il tasto destro del mouse sull'elemento nell'elenco per aprire il menu contestuale e fare clic su **Save as tool** (salva come utensile):

![images/download/attachments/157867684/image2024-7-26_15-50-35.png](assets/images/download/attachments/157867684/image2024-7-26_15-50-35.png)

Tutti i file delle sagome degli utensili vengono salvati nella cartella "C:\ProgramData\ENCY Software\ENCY\Version 1\Tools\MillTools".

Nella finestra di dialogo che compare, specificare il tipo della sagoma, il suo nome e lo schema dell'utensile per cui è stata definita (facoltativo):

![images/download/attachments/157867684/image2024-7-30_9-0-8.png](assets/images/download/attachments/157867684/image2024-7-30_9-0-8.png)

Nella parte sinistra della finestra si trovano il filtro per tipo di sagoma e l'elenco delle sagome create in precedenza. Se necessario, è possibile rinominare o eliminare le sagome precedenti.

**Save contour as single file** (salva il contorno come file separato) – spuntare questa opzione per salvare la geometria della sagoma separatamente dalla sua descrizione.

Nella successiva finestra di dialogo **Geometrical parameters** (parametri geometrici), specificare il nome del file del contorno. In seguito sarà possibile caricare il contorno per modificarlo.

Infine, è possibile selezionare il tipo di utensile appena creato nella [finestra Tools](38.md):

![images/download/attachments/157867684/image2024-7-26_15-59-31.png](assets/images/download/attachments/157867684/image2024-7-26_15-59-31.png)

È importante ricordare che, quando si copia la libreria utensili, i file dei contorni non vengono copiati insieme a essa. Pertanto, per copiare la libreria utensili su un altro computer, occorre copiare manualmente i file dei contorni.
