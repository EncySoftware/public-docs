# Criação de perfis de ferramenta

Use uma ferramenta de forma para realizar a usinagem de perfis de forma.

Para dar suporte a esse tipo de usinagem, o sistema CAM implementa a definição de ferramentas de forma por meio de um contorno (forma).

Para ferramentas de fresamento, o contorno da ferramenta deve ser especificado como linha geradora. Ele pode ser acessado nas operações [2D contouring](404.md), [3D contouring](700.md) e [5D contouring](10129.md).

A curva pode ser obtida diretamente do modelo ou criada usando o recurso **Sketch**.

Para criar uma ferramenta de forma, execute as seguintes etapas:

Alterne para o modo **Drawing** ![images/download/thumbnails/157867684/image2024-7-26_15-41-18.png](assets/images/download/thumbnails/157867684/image2024-7-26_15-41-18.png) e desenhe a forma (perfil) da ferramenta. O contorno pode ser parametrizado, se necessário.

![images/download/attachments/157867684/image2024-7-26_15-42-43.png](assets/images/download/attachments/157867684/image2024-7-26_15-42-43.png)

![images/download/attachments/157867684/image2024-7-26_15-45-16.png](assets/images/download/attachments/157867684/image2024-7-26_15-45-16.png)

Selecione-o na lista ou na visualização. Clique com o botão direito do mouse no item da lista para abrir o menu pop-up e clique em **Save as tool**:

![images/download/attachments/157867684/image2024-7-26_15-50-35.png](assets/images/download/attachments/157867684/image2024-7-26_15-50-35.png)

Todos os arquivos de formato de ferramenta são salvos na pasta "C:\ProgramData\ENCY Software\ENCY\Version 1\Tools\MillTools".

Na caixa de diálogo que aparece, especifique o tipo da forma, seu nome e o esquema de ferramentas para o qual ela foi definida (opcional):

![images/download/attachments/157867684/image2024-7-30_9-0-8.png](assets/images/download/attachments/157867684/image2024-7-30_9-0-8.png)

Na parte esquerda da janela, há um filtro de tipo de forma e a lista de formas criadas anteriormente. Se necessário, você pode renomear ou excluir formas anteriores.

**Save contour as single file** (Salvar contorno como arquivo único) - marque essa opção para salvar a geometria da forma separadamente de sua descrição.

Na próxima caixa de diálogo **Geometrical parameters**, especifique o nome do arquivo de contorno. Posteriormente, você pode carregar o contorno para editá-lo.

Por fim, você pode selecionar o tipo de ferramenta recém-criado na [janela Ferramentas](38.md):

![images/download/attachments/157867684/image2024-7-26_15-59-31.png](assets/images/download/attachments/157867684/image2024-7-26_15-59-31.png)

É importante lembrar que, quando a biblioteca de ferramentas é copiada, os arquivos de contorno não são copiados junto. Portanto, para copiar a biblioteca de ferramentas para outro computador, é necessário copiar os arquivos de contorno manualmente.
