# Formwerkzeuge erstellen

Formwerkzeuge ermöglichen die Bearbeitung mit einer vorgegebenen Werkzeugkontur.

Das CAM-System unterstützt die Definition solcher Werkzeuge anhand von Konturen (**Shapes**).

Bei Fräswerkzeugen wird die Kontur als Erzeugende des Werkzeugprofils angegeben. Diese Funktion steht beim [2D-Konturieren](404.md), [3D-Konturieren](700.md) und [5D-Konturieren](10129.md) zur Verfügung.

Die Kurve kann direkt aus dem Modell übernommen oder mit **Sketch** erstellt werden.

Gehen Sie zum Erstellen eines Formwerkzeugs wie folgt vor:

Wechseln Sie in den Modus **Drawing** ![Zeichenmodus](assets/images/download/thumbnails/157867684/image2024-7-26_15-41-18.png) und zeichnen Sie das Werkzeugprofil. Bei Bedarf kann die Kontur parametrisiert werden.

![images/download/attachments/157867684/image2024-7-26_15-42-43.png](assets/images/download/attachments/157867684/image2024-7-26_15-42-43.png)

![images/download/attachments/157867684/image2024-7-26_15-45-16.png](assets/images/download/attachments/157867684/image2024-7-26_15-45-16.png)

Wählen Sie die Kontur in der Liste oder im Grafikfenster aus. Öffnen Sie mit der rechten Maustaste das Kontextmenü des Listeneintrags und wählen Sie **Save as tool**:

![images/download/attachments/157867684/image2024-7-26_15-50-35.png](assets/images/download/attachments/157867684/image2024-7-26_15-50-35.png)

Die Werkzeugformdateien werden im Ordner `C:\ProgramData\ENCY Software\ENCY\Version 1\Tools\MillTools` gespeichert.

Geben Sie im folgenden Dialog den Formtyp und den Namen sowie optional das zugehörige Werkzeugschema an:

![images/download/attachments/157867684/image2024-7-30_9-0-8.png](assets/images/download/attachments/157867684/image2024-7-30_9-0-8.png)

Links befinden sich der Filter für den Formtyp und die Liste vorhandener Formen. Vorhandene Formen können bei Bedarf umbenannt oder gelöscht werden.

**Save contour as single file.** Aktivieren Sie diese Option, um die Konturgeometrie getrennt von ihrer Beschreibung zu speichern.

Geben Sie im anschließenden Dialog **Geometrical parameters** den Namen der Konturdatei an. Die Kontur kann später zur Bearbeitung erneut geladen werden.

Anschließend kann der neue Werkzeugtyp im [Werkzeugfenster](38.md) ausgewählt werden:

![images/download/attachments/157867684/image2024-7-26_15-59-31.png](assets/images/download/attachments/157867684/image2024-7-26_15-59-31.png)

Beim Kopieren einer Werkzeugbibliothek werden die Konturdateien nicht automatisch mitkopiert. Übertragen Sie diese Dateien daher separat, wenn die Bibliothek auf einem anderen Computer verwendet werden soll.
