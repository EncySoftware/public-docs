# Criação de texto

A janela de criação de texto pode ser aberta pressionando o botão ![images/download/attachments/157859917/image2024-7-3_16-16-11.png](assets/images/download/attachments/157859917/image2024-7-3_16-16-11.png) no painel **Model** ou pelo menu de contexto na [janela gráfica](169.md) ou na [janela da estrutura geométrica](718.md).

![images/download/attachments/157859917/image2024-7-3_16-16-35.png](assets/images/download/attachments/157859917/image2024-7-3_16-16-35.png) ![images/download/attachments/157859917/image2024-7-3_16-16-46.png](assets/images/download/attachments/157859917/image2024-7-3_16-16-46.png)

O texto pode ser escrito ao longo de uma linha ![images/download/thumbnails/157859917/image2024-7-3_16-17-49.png](assets/images/download/thumbnails/157859917/image2024-7-3_16-17-49.png) (padrão) ou ao longo de um círculo ![images/download/thumbnails/157859917/image2024-7-3_16-18-29.png](assets/images/download/thumbnails/157859917/image2024-7-3_16-18-29.png).

- ![images/download/attachments/157859917/image2024-7-3_16-20-30.png](assets/images/download/attachments/157859917/image2024-7-3_16-20-30.png) definem a orientação das letras.

- ![images/download/attachments/157859917/image2024-7-3_16-21-3.png](assets/images/download/attachments/157859917/image2024-7-3_16-21-3.png) - o alinhamento do texto define o posicionamento do texto em relação ao ponto inicial.

Para alterar a fonte do texto, use o botão de abertura da caixa de diálogo de fontes ![images/download/thumbnails/157859917/image2024-7-3_16-22-20.png](assets/images/download/thumbnails/157859917/image2024-7-3_16-22-20.png) ou a lista de tipos de fonte.

<strong>X,Y</strong> - define a posição do ponto inicial.

<strong>Angle</strong> - define o ângulo entre a horizontal e a linha de direção do texto, quando o texto é posicionado ao longo de uma linha, ou o ângulo inicial, quando o texto é posicionado ao longo de um círculo.

<strong>Radius</strong> - define o raio do círculo.

<strong>Height</strong> - define a altura das letras.

<strong>Width</strong> - permite alterar a largura das letras em %.

<strong>Leading</strong> - define o espaçamento vertical entre as linhas de texto.

<strong>Kerning</strong> - permite usar as tabelas de kerning da fonte selecionada para calcular a distância entre as letras.

<strong>Step</strong> - define a distância entre as letras, ignorando as informações de kerning.

<strong>Length</strong> - define a largura total do texto.

<strong>Oblique</strong> - define o ângulo de inclinação das letras em graus.

<strong>Set as default</strong> - salva os parâmetros como padrão para um novo texto.

Para visualizar o resultado, pressione o botão **Apply**. Se todos os parâmetros definidos estiverem corretos, o texto será exibido na janela gráfica. Se necessário, os parâmetros do texto podem ser corrigidos.

Depois de definir os parâmetros do texto, pressione o botão **Ok**. Uma pasta com o nome definido no campo **Folder** será criada na árvore do modelo.
