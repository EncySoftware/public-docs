# Importazione di oggetti da file SolidWorks™

ENCY consente di importare file di progetto SolidWorks™.

I file di progetto SolidWorks™ contengono una sezione Parasolid™, che viene estratta e importata.

Le estensioni standard dei file sono SLDASM; SLDPRT.

> A partire da luglio 2026, per utilizzare il modulo SolidWorks sarà necessaria una licenza separata (vedere [Modifiche alle licenze dell'integrazione ENCY–SOLIDWORKS – software CAD/CAM ENCY](https://encycam.com/news/ency-solidworks-integration-licensing/)),

> Al momento non è possibile importare file senza configurazione.
