# Importieren von Objekten aus SolidWorks™-Dateien

Das CAM-System ermöglicht den Import von SolidWorks™-Projektdateien.

SolidWorks™-Projektdateien enthalten einen Parasolid™-Abschnitt, den das System extrahiert und importiert.

Die üblichen Dateiendungen sind SLDASM und SLDPRT.

> Seit Juli 2026 ist für das SolidWorks-Modul eine separate Lizenz erforderlich. Weitere Informationen: [Änderungen an der ENCY-SOLIDWORKS-Integrationslizenzierung](https://encycam.com/news/ency-solidworks-integration-licensing/).

> Dateien ohne Konfiguration können derzeit nicht importiert werden.
