# Importação de objetos de arquivos SolidWorks™

O sistema CAM permite importar arquivos de projeto do SolidWorks™.

Esses arquivos contêm uma seção Parasolid™, que é extraída e importada pelo sistema.

As extensões padrão são SLDASM e SLDPRT.

> A partir de julho de 2026, o uso do módulo SolidWorks exige uma licença separada. Consulte [Alterações no licenciamento da integração ENCY–SOLIDWORKS](https://encycam.com/news/ency-solidworks-integration-licensing/).

> No momento, não é possível importar arquivos sem configuração.
