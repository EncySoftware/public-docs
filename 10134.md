# Benutzerdefinierte Werkzeugvektoren

![images/download/attachments/157864343/Custom_Vectors.png](assets/images/download/attachments/157864343/Custom_Vectors.png)

Vektoren legen die Werkzeugausrichtung an beliebigen Konturpunkten fest. Aktivieren Sie **Use custom tool vectors**, um sie zu bearbeiten.

Wurde statt einer Kante eine 5D-Kurve hinzugefügt, steht zunächst nur ein fester Vektor zur Verfügung. Über dieselbe Schaltfläche versucht das System, weitere Vektoren automatisch festzulegen.

![images/download/thumbnails/157864343/Custom_Vectors_panel.png](assets/images/download/thumbnails/157864343/Custom_Vectors_panel.png)

**Custom vectors** ermöglicht folgende Anpassungen der Werkzeugausrichtung:

- Ziehen mit gedrückter linker Maustaste verschiebt den Vektor entlang der Kontur.
- Bei gedrückter Strg-Taste wird eine Kopie verschoben.
- Anklicken ermöglicht die Richtungsänderung mit einer interaktiven Kugel und Kreisen längs bzw. quer zur Ausgangsfläche oder durch Eingabe zweier Winkel.
- Bei gedrückter Umschalttaste kann der Vektor auf einen Punkt der Bauteilfläche ausgerichtet werden.
- Entf löscht den ausgewählten Vektor.

![images/download/thumbnails/157864343/Custom_Vectors_size.png](assets/images/download/thumbnails/157864343/Custom_Vectors_size.png)

Beim Anklicken der Kontur erscheint ein Maß zur Änderung der dargestellten Vektorlänge. Dies betrifft nur die Bedienbarkeit, nicht die Werkzeugausrichtung.
