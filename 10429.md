# Finestra delle informazioni sulla versione

Alla finestra <strong>Version information</strong> (informazioni sulla versione) si accede dal primo pulsante in alto nella barra degli strumenti dell'applicazione.

![images/download/attachments/157858202/VersionInformation_En.png](assets/images/download/attachments/157858202/VersionInformation_En.png)

In questa finestra è possibile visualizzare:

- Il nome dell'applicazione.
- L'identificativo della build dell'applicazione.
- Link utili alle nostre risorse web.
- Le proprietà di base della licenza.
- L'elenco delle versioni di ciascun modulo dell'applicazione.
- Le informazioni sul rivenditore del software.
- Le informazioni sul copyright.
