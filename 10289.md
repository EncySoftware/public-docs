# Simulationsergebnis als Modell exportieren

<a id="application-area"></a>

## Anwendungsbereich:

Das auf der Seite **Simulation** angezeigte Ergebnis kann in einer Datei gespeichert und später als **Rohteil** in einem anderen Projekt verwendet werden. Im Format **STL** ist auch die Weiterverwendung in anderer Software möglich. Dadurch wird der bereits bearbeitete Zustand in das nächste Projekt übernommen, sodass die Bearbeitung an diesem Zustand fortgesetzt werden kann.

Typische Einsatzfälle:

- Einen längeren Bearbeitungsprozess auf mehrere Projekte aufteilen und den Rohteilzwischenstand zwischen ihnen übertragen.
- Das genaue Bearbeitungsergebnis ohne Detailverlust als Rohteil einer nachfolgenden Aufspannung verwenden.
- Das simulierte Rohteil über ein neutrales Netzformat an externe CAM- oder CAD-Software übergeben.

<a id="saving-the-simulation-result"></a>

### Simulationsergebnis speichern

Es stehen zwei Zugänge zur Verfügung. Beide öffnen den Dialog **Save As** (Speichern unter).

**Kontextmenü auf der Seite Simulation.** Klicken Sie mit der rechten Maustaste in das Simulationsfenster und wählen Sie **Save simulation result** (Simulationsergebnis speichern).

**Hauptmenü.** Öffnen Sie das Menü **Save** über das Diskettensymbol links oben. Wählen Sie unter **Export** den Eintrag **Simulation result**.

Geben Sie im Dialog **Save As** einen Dateinamen ein und wählen Sie unter **Save as type** das Format:

- **Simulation result, precise (*.camsr).** Präzises Simulationsergebnis; standardmäßig ausgewählt.

![images/download/attachments/157867281/image2026-7-30_15-33-6.png](assets/images/download/attachments/157867281/image2026-7-30_15-33-6.png)

- **Simulation result, STL with losses (*.stl).** Simulationsergebnis als STL mit Genauigkeitsverlusten.

![images/download/attachments/157867281/image2026-7-30_15-33-46.png](assets/images/download/attachments/157867281/image2026-7-30_15-33-46.png)

<a id="file-formats"></a>

### Dateiformate

**Simulation result, precise (*.camsr)**

Das native Simulationsformat speichert das **berechnete Simulationsmodell unverändert**, ohne Konvertierung.

- **Kein Genauigkeitsverlust.** Beim erneuten Import als Rohteil wird das Modell direkt verwendet, ohne zusätzliche Approximation.
- **Empfohlen für die Weiterverwendung innerhalb des CAM-Systems.** Dies ist die Standardoption.

**Simulation result, STL with losses (*.stl)**

Das standardisierte STL-Dreiecksnetz.

- **Universell verwendbar.** Kann von den meisten CAM- und CAD-Anwendungen sowie anderen STL-fähigen Programmen geöffnet werden.
- **Verlustbehaftet.** Beim Export wird das präzise Modell in ein Dreiecksnetz umgewandelt. Beim erneuten Import wird es als Netz geladen und erneut verarbeitet. Das wiederverwendete Rohteil ist daher eine **Näherung** des ursprünglichen Modells.

<a id="reusing-a-saved-result-as-a-workpiece"></a>

### Gespeichertes Ergebnis als Rohteil verwenden

Eine *.camsr-Datei kann in ein anderes Projekt als Rohteil geladen werden:

1. Wechseln Sie auf der Seite **Machining** zur Registerkarte **Workpiece** (Rohteil).
2. Klicken Sie auf **Sim result** (Simulationsergebnis).
3. Wählen Sie die *.camsr-Datei aus.

Das genaue Bearbeitungsergebnis wird als Rohteil hinzugefügt. Die Bearbeitung kann ohne erneute Voxelisierung und ohne Detailverlust fortgesetzt werden.

> **Hinweis:** Die *.camsr-Datei speichert ihre Maßeinheiten. Weichen diese von den Einheiten des aktuellen Projekts ab, wird der Import **abgebrochen**, da eine automatische Umrechnung zwischen Millimetern und Zoll noch nicht unterstützt wird. Speichern und verwenden Sie Ergebnisse daher innerhalb desselben Einheitensystems.
