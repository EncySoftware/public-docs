# Additive Fertigung

Dieses optionale Modul umfasst additive Operationen, beispielsweise flächiges Auftragsschweißen.

Die Operationen beschreiben die Prozessgeometrie unabhängig von der konkreten Technologie und Anlage. Sie erzeugen Werkzeugwege, die vorgegebene Flächen schichtweise von unten nach oben aufbauen. Die Ansteuerung einer bestimmten Anlage wird über Postprozessorbefehle angepasst. Falls dies nicht ausreicht, kann eine spezialisierte Operation auf Grundlage der allgemeinen additiven Operationen erstellt werden.

Hinweis: Die Option muss separat lizenziert werden.
