# Geometrical object properties

The **Properties** window is opened by pressing the ![images/download/thumbnails/157859763/image2022-4-26_17-19-32.png](assets/images/download/thumbnails/157859763/image2022-4-26_17-19-32.png) button on the [Model](718.md) tab or from the context menu in the [graphic window](169.md) or [model structure window](718.md) This window allows the viewing of general properties and to change visual and machining properties of objects. The window consists of four tabsheets:

- [General](725.md);
- [Visual](745.md);
- [Machining](740.md);
- [Parameters](329.md).
