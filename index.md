# Creating your own interpreter

To create your own interpreter, complete the following steps:

- Read the articles in this section that describe how the CAM system interacts with the interpreter when interpreting the NC program text.
- Create an interpreter settings file and develop a library for it as described on the following pages: [Interpreter settings file](src/interpreter-structure/interpreter-settings-file/interpreter-settings-file.md), [Interpreter library](src/interpreter-structure/interpreter-library/interpreter-library.md).
