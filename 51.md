# Anwendungssymbolleiste

Die Anwendungssymbolleiste befindet sich oben im Hauptfenster. Mehrere Schaltflächen besitzen Dropdown-Menüs mit zusätzlichen Funktionen.

![images/download/attachments/157857876/image2024-6-26_17-5-26.png](assets/images/download/attachments/157857876/image2024-6-26_17-5-26.png)

## Anwendungsmenü

![images/download/attachments/157857876/image2024-6-26_17-7-30.png](assets/images/download/attachments/157857876/image2024-6-26_17-7-30.png)

- ![Einstellungen](assets/images/download/thumbnails/157857876/image2024-6-26_17-12-51.png) **Settings:** Öffnet die [Systemeinstellungen](90.md).
- ![Info](assets/images/download/thumbnails/157857876/image2024-6-26_17-13-40.png) **About:** Zeigt den Startbildschirm. ![Startbildschirm](assets/images/download/attachments/157857876/image2024-6-27_15-43-6.png)
- ![Version](assets/images/download/thumbnails/157857876/image2024-6-26_17-13-55.png) **Version:** Öffnet die [Versionsinformationen](10429.md).
- ![Lizenzen](assets/images/download/thumbnails/157857876/image2024-6-26_17-14-8.png) **License Manager:** Öffnet den [Lizenzmanager](10025.md).

<a id="new-project-button-menu"></a>

## Menü Neues Projekt

![images/download/attachments/157857876/image2024-6-26_17-15-46.png](assets/images/download/attachments/157857876/image2024-6-26_17-15-46.png)

Verfügbare Optionen:

- **New Project:** Schließt das aktuelle Projekt und erstellt ein neues in derselben Registerkarte.
- **New Project in New Tab:** Erstellt ein Projekt in einer neuen Registerkarte.
- **Create from Machine Setup File:** Ersetzt das aktuelle Projekt durch ein neues aus einer [Maschineneinrichtungsdatei](10427.md). Zuletzt verwendete Dateien oder eine Datei vom Datenträger können gewählt werden.
- **New Project With Machine Setup In New Tab:** Erstellt das Vorlagenprojekt in einer neuen Registerkarte; das bisherige Projekt bleibt geöffnet.

<a id="open-project-button-menu"></a>

## Menü Projekt öffnen

![images/download/attachments/157857876/image2024-8-23_15-40-51.png](assets/images/download/attachments/157857876/image2024-8-23_15-40-51.png)

Verfügbare Optionen:

- **Open Project:** Öffnet ein vorhandenes Projekt über den Dateidialog.
- **Open Project In New Tab:** Öffnet es in einer neuen Registerkarte und lässt das aktuelle Projekt geöffnet.
- **[Project Library](1020141.md):** Sucht und öffnet Beispielprojekte.
- **Open ENCY Tuner Project:** Lädt ein ENCY-Tuner-Projekt. Das Untermenü bietet auch das Öffnen in einer neuen Registerkarte.
- **Import Machine Setup:** Übernimmt eine [Maschineneinrichtung](10427.md) in das aktuelle Projekt.
- Die Liste zuletzt geladener Projekte bietet je Eintrag weitere Aktionen:
  - **Load Recent Backup Versions:** Lädt [Snapshots](10424.md).
  - **Open Project in New Tab:** Öffnet das ausgewählte Projekt in einer neuen Registerkarte.
  - **Snapshots Manager:** Öffnet die [Snapshotverwaltung](10424.md).
  - **Show File in Explorer:** Öffnet den Datei-Explorer und markiert die Projektdatei.

<a id="save-project-button-menu"></a>

## Menü Projekt speichern

![images/download/attachments/157857876/image2024-6-26_17-22-28.png](assets/images/download/attachments/157857876/image2024-6-26_17-22-28.png)

Verfügbare Optionen:

- **Save Project:** Speichert die Änderungen. Für ein neues Projekt wird ein Dateiname angefordert.
- **Save As...:** Speichert unter einem neuen Namen.
- **Export Project With History:** Exportiert das Projekt einschließlich Änderungshistorie und Snapshots.
- **Save as Machine Setup:** Speichert eine [Maschineneinrichtungsdatei](10427.md).
- **Export Drill Points:** Exportiert Bohrpunkte der aktuellen Operation als DXF, sofern sie eine Bohrungsseite besitzt. Die Datei kann in ein anderes Projekt importiert werden.
