# Barra degli strumenti dell'applicazione

La <strong>Application Toolbar</strong> (barra degli strumenti dell'applicazione) si trova nel pannello superiore della finestra principale. Diversi pulsanti di questa barra includono menu a discesa associati, che ne ampliano le funzionalità.

<a id="new-project-button-menu"></a>

## Menu del pulsante New Project

![images/download/attachments/157857876/image2024-6-26_17-15-46.png](assets/images/download/attachments/157857876/image2024-6-26_17-15-46.png)

Il menu del pulsante New Project (nuovo progetto) comprende le seguenti opzioni:

- <strong>New Project:</strong> chiude il progetto corrente e avvia un nuovo progetto nella scheda corrente.
- <strong>New Project in New Tab:</strong> apre una nuova scheda e vi crea un nuovo progetto.
- <strong>Create from Machine Setup File:</strong> chiude il progetto corrente e ne crea uno nuovo da un file di [configurazione macchina](10427.md). È possibile scegliere tra i file di configurazione macchina aperti di recente oppure sfogliare le unità per selezionare un file.
- <strong>New Project With Machine Setup In New Tab</strong>: questa opzione consente di avviare un nuovo progetto in una scheda separata utilizzando un file di configurazione macchina. È possibile scegliere tra i file di configurazione usati di recente oppure sfogliare le unità per selezionare un file. Il progetto corrente resta aperto nella scheda originale, mentre il nuovo progetto viene creato in una nuova scheda.

<a id="open-project-button-menu"></a>

## Menu del pulsante Open Project

![images/download/attachments/157857876/image2024-8-23_15-40-51.png](assets/images/download/attachments/157857876/image2024-8-23_15-40-51.png)

Il pulsante Open Project (apri progetto) offre diverse opzioni:

- <strong>Open Project</strong>: carica un progetto esistente tramite una finestra standard di selezione del file.
- <strong>Open Project In New Tab</strong>: apre un progetto esistente in una nuova scheda, consentendo di tenere aperto il progetto corrente mentre si lavora contemporaneamente su un altro. Il file di progetto può essere selezionato tramite una finestra standard di selezione del file, rendendo facile passare da un progetto all'altro senza chiudere l'area di lavoro corrente.
- <strong>[Project Library:](1020141.md)</strong> apre una finestra per cercare e aprire progetti di esempio provenienti da tutto il mondo.
- <strong>Open ENCY Tuner Project:</strong> carica un progetto creato in ENCY Tuner. Tenendo il cursore su questa voce compare l'opzione per aprire il progetto in una nuova scheda.
- <strong>Import Machine Setup</strong>: importa nel progetto corrente i dati di un file di [configurazione macchina](10427.md).
- È inoltre disponibile un elenco dei progetti caricati di recente. Ciascun progetto di questo elenco dispone di un menu a discesa che offre ulteriori azioni, quali:
  - <strong>Load Recent Backup Versions ([Snapshots](10424.md)</strong><strong>):</strong> carica rapidamente le versioni di backup del progetto.
  - <strong>Open Project in New Tab</strong>: apre il progetto selezionato in una nuova scheda.
  - <strong>Snapshots Manager</strong>: apre [la finestra di gestione degli snapshot](10424.md) per gestire tutti gli snapshot (versioni di backup) del progetto.
  - <strong>Show File in Explorer</strong>: apre Esplora risorse di Windows e seleziona il file del progetto.

<a id="save-project-button-menu"></a>

## Menu del pulsante Save Project

![images/download/attachments/157857876/image2024-6-26_17-22-28.png](assets/images/download/attachments/157857876/image2024-6-26_17-22-28.png)

Il pulsante Save Project (salva progetto) offre le seguenti opzioni:

- <strong>Save Project</strong>: salva tutte le modifiche al progetto corrente. Se il progetto non è mai stato salvato, il sistema richiede un nuovo nome.
- <strong>Save As...</strong>: salva il progetto con un nuovo nome tramite una finestra di salvataggio.
- <strong>Export Project With History</strong>: esporta il progetto insieme alla sua cronologia completa delle modifiche, compresi gli snapshot creati durante il ciclo di vita del progetto.
- <strong>Save as Machine Setup</strong>: salva il modello del progetto corrente in un file di [configurazione macchina](10427.md).
- <strong>Export Drill Points</strong>: apre una finestra per esportare in un file DXF i punti di foratura dell'operazione corrente (se nelle proprietà è presente una pagina Holes). Questo file può essere importato nella pagina del modello di un altro progetto.
