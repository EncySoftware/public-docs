## Menu do botão Novo projeto

![images/download/attachments/157857876/image2024-6-26_17-15-46.png](assets/images/download/attachments/157857876/image2024-6-26_17-15-46.png)

O menu do botão Novo projeto inclui as seguintes opções:

- <strong>Novo projeto:</strong> Fecha o projeto atual e inicia um novo projeto na guia atual.
- <strong>Novo projeto na nova guia:</strong> Abre uma nova guia e cria um novo projeto dentro dela.
- <strong>Criar a partir do arquivo de instalação da máquina:</strong> Fecha o projeto atual e cria um novo a partir de um arquivo de [configuração da máquina](10427.md). Você pode escolher entre os arquivos de configuração da máquina abertos recentemente ou navegar em suas unidades para selecionar um arquivo.
- <strong>Novo projeto com configuração de máquina em nova guia</strong>: Esta opção permite que você inicie um novo projeto em uma guia separada usando um arquivo de configuração de máquina. Você pode selecionar entre os arquivos de instalação usados recentemente ou navegar em suas unidades para selecionar um arquivo. O projeto atual permanecerá aberto em sua guia original, enquanto o novo projeto é criado em uma nova.

## Abrir o menu do botão Projeto

![images/download/attachments/157857876/image2024-8-23_15-40-51.png](assets/images/download/attachments/157857876/image2024-8-23_15-40-51.png)

O botão Abrir projeto oferece várias opções:

- <strong>Abrir projeto</strong>: carrega um projeto existente por meio de uma caixa de diálogo de seleção de arquivo padrão.
- <strong>Abrir projeto em nova guia</strong>: Abre um projeto existente em uma nova guia, permitindo que você mantenha seu projeto atual aberto enquanto trabalha em outro simultaneamente. Você pode selecionar o arquivo de projeto por meio de uma caixa de diálogo de seleção de arquivo padrão, facilitando a alternância entre vários projetos sem fechar o espaço de trabalho atual.
- <strong>[Biblioteca de projetos:](1020141.md)</strong> Abre uma janela para pesquisar e abrir projetos de amostra de todo o mundo.
- <strong>Abra o Projeto ENCY Tuner:</strong> Carrega um projeto criado no ENCY Tuner. Manter o cursor sobre este item revela a opção de abrir o projeto em uma nova guia.
- <strong>Importar configuração da máquina</strong>: Importa dados de um arquivo de [configuração da máquina](10427.md) para o projeto atual.
- Além disso, uma lista de projetos carregados recentemente está disponível. Cada projeto nesta lista tem um menu suspenso que oferece outras ações, como:
  - <strong>Carregar versões de backup recentes ([instantâneos](10424.md)</strong><strong>):</strong> Carregue rapidamente as versões de backup do projeto.
  - <strong>Abrir projeto em uma nova guia</strong>: Abre o projeto selecionado em uma nova guia.
  - <strong>Gerenciador de instantâneos</strong>: Abre [a janela de gerenciamento de instantâneos](10424.md) para gerenciar todos os instantâneos (versões de backup) do projeto.
  - <strong>Mostrar arquivo no Explorer</strong>: Abre o Windows Explorer e seleciona o arquivo do projeto.

## Menu do botão Salvar projeto

![images/download/attachments/157857876/image2024-6-26_17-22-28.png](assets/images/download/attachments/157857876/image2024-6-26_17-22-28.png)

O botão Salvar projeto oferece as seguintes opções:

- <strong>Salvar projeto</strong>: salva todas as alterações no projeto atual. Se o projeto não tiver sido salvo antes, o sistema solicitará um novo nome.
- <strong>Salvar como...</strong>: Salva o projeto com um novo nome por meio de uma caixa de diálogo de salvamento.
- <strong>Exportar projeto com histórico</strong>: exporta o projeto junto com seu histórico completo de modificações, incluindo instantâneos feitos durante todo o ciclo de vida do projeto.
- <strong>Salvar como configuração da máquina</strong>: salva o modelo de projeto atual em [um arquivo de configuração da máquina](10427.md).
- <strong>Exportar pontos de perfuração</strong>: abre uma janela para exportar pontos de perfuração da operação atual (se houver uma página Furos nas propriedades) para um arquivo DXF. Este arquivo pode ser importado para a página de modelo de outro projeto.
