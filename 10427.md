# Maschineneinrichtung als Projektvorlage

Eine **Maschineneinrichtungsdatei** ermöglicht das schnelle Erstellen neuer Projekte aus einer Vorlage.

Speichern Sie das Projekt als *.stms über **Save as Machine Setup** im Speichermenü der [Anwendungssymbolleiste](51.md).

![images/download/attachments/157858164/SaveAsMachineSetup_En.png](assets/images/download/attachments/157858164/SaveAsMachineSetup_En.png)

Die gespeicherte Einrichtung kann anschließend als Projektvorlage verwendet werden.

Gespeichert werden:

- Maschine;
- Aufspannungen und Bauteilgruppen;
- Spannmittel einschließlich ihrer Positionen;
- Werkzeuge;
- An- und Rückfahrregeln;
- Werkstückkoordinatensysteme;
- Werkzeugaufnahmen und ihre Revolverpositionen.

Unter **New Project** auf der [Anwendungssymbolleiste](51.md) können zuletzt verwendete Einrichtungen gewählt werden. **Create from Machine Setup File** öffnet eine andere Vorlagendatei.

![images/download/attachments/157858164/CreateFromMachineSetupFile_En.png](assets/images/download/attachments/157858164/CreateFromMachineSetupFile_En.png)

Eine Einrichtung kann auch über **Import Machine Setup** im Öffnen-Menü der [Anwendungssymbolleiste](51.md) in ein bestehendes Projekt importiert werden.

![images/download/attachments/157858164/ImportMachineSetup_En.png](assets/images/download/attachments/157858164/ImportMachineSetup_En.png)

Dabei werden alle Daten außer der Maschine selbst hinzugefügt. Stimmen Projektmaschine und Vorlagenmaschine überein, werden deren Parameter aktualisiert. Andernfalls werden, soweit anwendbar, **Machine dimensions** und **Tooling** übernommen.

![images/download/attachments/157858164/image2024-6-26_17-48-36.png](assets/images/download/attachments/157858164/image2024-6-26_17-48-36.png)
