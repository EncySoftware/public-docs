# Configurazione macchina (modello di progetto)

Il <strong>file di configurazione macchina</strong> (machine setup file) è pensato per creare rapidamente nuovi progetti a partire da un modello.

È possibile salvare un progetto come file di configurazione macchina (*.stms) selezionando l'opzione <strong>Save as Machine Setup</strong> dal menu a discesa del pulsante di salvataggio del progetto nella [barra degli strumenti dell'applicazione](51.md).

![images/download/attachments/157858164/SaveAsMachineSetup_En.png](assets/images/download/attachments/157858164/SaveAsMachineSetup_En.png)

In questo modo è possibile creare in modo efficiente nuovi progetti utilizzando il file di configurazione salvato come modello.

Nel file di configurazione macchina vengono memorizzati i seguenti dati:

- Macchina
- Fasi e pezzo (come gruppo di operazioni)
- Attrezzature (compresa la loro posizione)
- Utensili
- Avvicinamenti/ritorni
- Sistemi di coordinate del grezzo
- Tipi di blocchi utensile e loro disposizione nella torretta

Sotto il pulsante <strong>New Project</strong> della [barra degli strumenti dell'applicazione](51.md) compare un nuovo menu a discesa che consente di selezionare uno dei file di configurazione macchina usati di recente. In alternativa, è possibile scegliere un altro file di configurazione selezionando l'opzione <strong>Create from Machine Setup File</strong>.

![images/download/attachments/157858164/CreateFromMachineSetupFile_En.png](assets/images/download/attachments/157858164/CreateFromMachineSetupFile_En.png)

È inoltre possibile importare un file di configurazione macchina nel progetto corrente. A tale scopo, utilizzare l'opzione <strong>Import Machine Setup</strong> dal menu a discesa del pulsante di apertura nella [barra degli strumenti dell'applicazione](51.md).

![images/download/attachments/157858164/ImportMachineSetup_En.png](assets/images/download/attachments/157858164/ImportMachineSetup_En.png)

Durante l'importazione tutti i dati del file di configurazione macchina vengono aggiunti al progetto corrente, ad eccezione della macchina stessa. Se la macchina del progetto coincide con quella del file di configurazione, i parametri della macchina vengono aggiornati dal file. Se le macchine sono diverse, vengono aggiornati, se applicabile, i parametri <strong>Machine dimensions</strong> e <strong>Tooling</strong>.
