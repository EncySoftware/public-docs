# Rotationsbearbeitung

<a id="application-area"></a>

## Anwendungsbereich:

Die Gruppe **Rotary** enthält Operationen zur Flächen- und Konturbearbeitung mit einer Drehachse: Schruppen, Schlichten, Wasserlinienbearbeitung, Morphing und Konturieren.

<a id="operations"></a>

### Operationen:

- **Rotary waterline.** Erzeugt Wasserlinienbahnen um eine Drehachse. [Details](10143.md)

- **Rotationsschruppen.** Entfernt Material schichtweise um eine Drehachse. [Details](10137.md)

- **Rotationsschlichten.** Schlichtet Flächen um eine Drehachse. [Details](10136.md)

- **Morph 4D.** Erzeugt vierachsige Morphingbahnen. [Details](10146.md)

- **4D-Flächenbearbeitung.** Erzeugt vierachsige Flächenbahnen. [Details](10145.md)

- **4D-Konturieren.** Erzeugt vierachsige Konturbahnen. [Details](10144.md)
