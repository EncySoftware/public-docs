# Machining result

The **Machining result** is the material leaved by an operation after machining the workpiece. The node is introduced to allow a visual control of the rest material as well as for transparence of the **Machining result of the previous operation** item of the **Workpiece** node. The node is calculated automatically while its contents can not be modified. If the toolpath of an operation is not yet calculated then the machining result of the operation is its workpiece.
