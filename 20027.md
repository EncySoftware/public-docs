# Drehen

Das Objekt wird um den angegebenen Punkt um den festgelegten Winkel gedreht. Dies kann interaktiv oder durch Eingabe der Koordinaten und des Winkels im Inspektor erfolgen. Zusätzlich können Sie die Anzahl der Kopien festlegen. Jede weitere Kopie wird gegenüber der vorherigen um den angegebenen Winkel gedreht.
