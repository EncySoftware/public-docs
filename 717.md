# Preparação do modelo geométrico

O modo de preparação do modelo geométrico é ativado com um clique do mouse na guia [Model](86.md) na janela principal do sistema.

No modo **Model**, é possível:

- [importar](109.md) arquivos de dados geométricos (CAD);
- [corrigir a estrutura](47.md) do modelo geométrico;
- realizar [transformações espaciais](116.md) dos objetos geométricos;
- gerar novos elementos a partir de elementos existentes;
- [alterar as propriedades visuais do objeto](32.md);

O acesso aos elementos do modelo é feito tanto na [janela da árvore do modelo](718.md) quanto de forma interativa na tela. Diferentes funções podem ser iniciadas por meio do menu pop-up na [janela gráfica](169.md) e na janela da árvore do modelo. Os botões das funções usadas com frequência são colocados na barra de ferramentas da guia **Model**.
