# Simulation steuern

Die Simulation zeigt den Rohteilzustand während der Bearbeitung. Damit lassen sich Oberflächenqualität, Restmaterial und unerwünschte Einschnitte beurteilen.

Beim ersten Öffnen wird das Simulationsrohteil erzeugt. Beim erneuten Öffnen bleibt sein Zustand erhalten, sodass die Simulation fortgesetzt werden kann.

Das anfängliche [Rohteil](738.md) stammt aus dem Wurzelknoten des Operationsbaums und wird bei kontinuierlicher Simulation schrittweise verändert.

Mit den Schaltflächen ![Operationszustand laden](assets/images/download/attachments/157867137/image2024-7-19_15-57-13.png) wird dagegen der Rohteilzustand der nächstgelegenen Operation geladen. Das Ergebnis kann von einer durchgehenden Simulation abweichen, wenn Operationen ein anderes Rohteil als das vorherige Bearbeitungsergebnis verwenden.

*Hinweis: Ältere Projekte enthalten möglicherweise keine vollständigen Informationen zur Rohteilfortschreibung. Wählen Sie dann die erste Operation, laden Sie mit ![Ausgangsrohteil laden](assets/images/download/attachments/157867137/image2024-7-19_15-57-30.png) das ursprüngliche Rohteil und starten Sie eine kontinuierliche Simulation.*

Mit ![Simulation zurücksetzen](assets/images/download/attachments/157867137/image2024-7-19_15-57-48.png) werden die Simulationsergebnisse verworfen und das Rohteil gemäß dem Wurzelknoten neu initialisiert.
