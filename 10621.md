# Erweiterungen über die Systemeinstellungen installieren

Gehen Sie im [Fenster der Systemeinstellungen](90.md) wie folgt vor:

- Öffnen Sie **System Setup → Extensions**.

![images/download/attachments/157867881/image2025-11-18_9-24-32.png](assets/images/download/attachments/157867881/image2025-11-18_9-24-32.png)

- Klicken Sie auf **Install** und wählen Sie die Beschreibungsdatei *.json oder das Paket *.dext. Letzteres ist ein ZIP-Archiv mit allen benötigten Dateien.

- Die ausgewählte Erweiterungsbibliothek wird in die Liste aufgenommen.

![images/download/attachments/157867881/image2025-11-18_9-27-27.png](assets/images/download/attachments/157867881/image2025-11-18_9-27-27.png)

Oben stehen die Bibliotheken, darunter ihre einzelnen Erweiterungen. Eine Bibliothek kann mehrere Erweiterungen implementieren.

Manuell installierte Bibliotheken erscheinen fett; vom System installierte Bibliotheken in normaler Schrift.

Bei Auswahl werden unten Name, Beschreibung, Version und Dateispeicherort angezeigt.

**Uninstall** entfernt die ausgewählte Bibliothek. Bei nicht entfernbaren Erweiterungen ist die Schaltfläche deaktiviert.

**Unload** beendet die Ausführung einer geladenen Bibliothek und entlädt sie aus dem Speicher.

Mit **Enabled** kann eine Erweiterung ohne Löschen deaktiviert werden. Deaktivierte Einträge erscheinen grau.

Hinweis: Je nach Erweiterungstyp ist ein Neustart des CAM-Systems erforderlich.
