# Installazione delle estensioni tramite la finestra System Setup

Per installare le estensioni tramite la [finestra System Setup](90.md), procedere come segue:

- Aprire la finestra System Setup e passare alla scheda Extensions.

![images/download/attachments/157867881/image2025-11-18_9-24-32.png](assets/images/download/attachments/157867881/image2025-11-18_9-24-32.png)

- Fare clic sul pulsante "Install" e, nella finestra di dialogo di selezione file che si apre, selezionare il file di descrizione testuale dell'estensione *.json oppure il file pacchetto dell'estensione *.dext (un archivio zip contenente tutti i file necessari al funzionamento dell'estensione);

- All'elenco del pannello Extensions viene aggiunta una voce corrispondente alla libreria di estensioni selezionata

![images/download/attachments/157867881/image2025-11-18_9-27-27.png](assets/images/download/attachments/157867881/image2025-11-18_9-27-27.png)

Il livello superiore di questa finestra mostra gli elementi corrispondenti alle librerie di estensioni. Al loro interno sono annidati gli elementi corrispondenti alle singole estensioni. Una singola libreria può implementare contemporaneamente più estensioni.

Le librerie installate manualmente dall'utente sono visualizzate in grassetto nell'elenco. Se una libreria è stata installata dal sistema, viene visualizzata con carattere normale.

Quando si seleziona una libreria o un'estensione nell'elenco superiore, nella parte inferiore della finestra vengono visualizzate le informazioni sull'elemento selezionato: nome, descrizione, numero di versione e percorso nel file system.

Per eliminare una libreria di estensioni, selezionarla nell'elenco e fare clic sul pulsante "Uninstall". Alcune estensioni potrebbero non essere rimovibili dall'utente. In questo caso, il pulsante di disinstallazione è disattivato.

Se una libreria di estensioni è caricata in memoria, è possibile interromperne forzatamente l'esecuzione e scaricarla dalla memoria facendo clic sul pulsante "Unload".

È anche possibile disattivare l'uso di un'estensione senza eliminarla. A tale scopo, è sufficiente disattivare l'interruttore Enabled. Le estensioni disattivate sono visualizzate in grigio nella finestra.

Nota – A seconda del tipo di estensione, potrebbe essere necessario riavviare il sistema CAM affinché le modifiche abbiano effetto.
