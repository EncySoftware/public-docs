# Installing extensions from a file

An extension that is not in the store can be installed from a file: a `.dext` or `.nupkg` package provided by the extension author.

1. On the **Home page**, open the **Extension Store** tab and go to the **Manage** page.
2. Click **Install from file…** and select the file. You can also drag the file onto the tab.
3. Wait for the installation message. If it asks you to restart the application, click **Restart the application**.

Besides packages, **Install from file…** accepts an extension description file `*.json`: the extension is registered in the folder where its files are located.

On the **Manage** page, you can also enable, disable and remove installed extensions. [Details](162964210.md)

You can also install an extension [using the command line](10622.md).
