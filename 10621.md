# Instalação de extensões pela janela System Setup

Para instalar extensões pela [janela System Setup](90.md), siga estas etapas:

- Abra a janela System Setup e selecione a guia Extensions.

![images/download/attachments/157867881/image2025-11-18_9-24-32.png](assets/images/download/attachments/157867881/image2025-11-18_9-24-32.png)

- Clique no botão "Install" e, na caixa de diálogo de seleção de arquivo que se abre, selecione o arquivo de texto de descrição da extensão *.json ou o arquivo de pacote da extensão *.dext (um arquivo ZIP que contém todos os arquivos necessários para o funcionamento da extensão);

- Um item correspondente à biblioteca de extensões selecionada será adicionado à lista do painel Extensions

![images/download/attachments/157867881/image2025-11-18_9-27-27.png](assets/images/download/attachments/157867881/image2025-11-18_9-27-27.png)

O nível superior dessa janela exibe os elementos correspondentes às bibliotecas de extensões. Dentro deles estão aninhados os elementos correspondentes às extensões individuais. Uma única biblioteca pode implementar várias extensões simultaneamente.

As bibliotecas instaladas manualmente pelo usuário são exibidas em negrito na lista. Se uma biblioteca foi instalada pelo sistema, ela é exibida em fonte normal.

Ao selecionar uma biblioteca ou extensão na lista superior, as informações sobre o elemento selecionado são exibidas na parte inferior da janela: nome, descrição, número da versão e localização no sistema de arquivos.

Para excluir uma biblioteca de extensões, selecione-a na lista e clique no botão "Uninstall". Algumas extensões podem não ser removíveis pelo usuário. Nesse caso, o botão de desinstalação fica desativado.

Se uma biblioteca de extensões estiver carregada na memória, é possível interromper sua execução à força e descarregá-la da memória clicando no botão "Unload".

Também é possível desativar o uso de uma extensão sem excluí-la. Para isso, basta desligar a opção Enabled. As extensões desativadas são exibidas em cinza na janela.

Observação – Dependendo do tipo de extensão, pode ser necessário reiniciar o sistema CAM para que as alterações entrem em vigor.
