# Procedimento de usinagem FBM

O procedimento FBM é uma sequência de usinagem definida para um recurso ou uma classe de recurso. Há dois tipos de procedimentos de FBM.

1. Procedimentos atômicos
2. Procedimentos completos.

O procedimento atômico faz apenas uma pequena parte da usinagem. Normalmente, consiste em apenas uma operação. Os exemplos de procedimentos atômicos incluem Spot Drilling, Rough Drilling, Chamfer Sinking, Chamfer Contouring.

O procedimento completo inclui todas as operações necessárias para usinar um recurso completamente.

Quando você seleciona um procedimento para um recurso na interface do usuário, somente os procedimentos completos são sugeridos. Quando você adiciona operações a um procedimento selecionado, apenas os procedimentos atômicos são sugeridos.

Um procedimento FMB consiste em quatro partes.

1. Os metadados do procedimento, como tipo (atômico, completo), legenda, ícone e data da última modificação.
2. As restrições de recursos.
3. A lista de consultas de ferramentas
4. A lista de operações

Restrições de recursos

As restrições de recursos são a parte que define para que tipo de recurso é o procedimento e quais parâmetros o recurso deve atender.

Os exemplos de tipos de recursos incluem Hole, Stepped Hole e Hole Groove.

Cada tipo de recurso tem seu próprio conjunto de parâmetros. Por exemplo, um furo tem parâmetros como tipo (cego, passante), diâmetro, altura, ângulo de ponta, ângulo de conicidade e outros. Um furo escalonado é um recurso composto. Consiste em dois ou mais furos e pode incluir algumas ranhuras. Uma ranhura de furo é um recorte em um furo definido por parâmetros como tipo (redondo, quadrado, trapezoidal), altura, diâmetro, ângulo de conicidade, raio de canto

Em Restrições do recurso, você define as restrições dos parâmetros que o recurso deve satisfazer para ser aplicável ao procedimento de usinagem. As restrições podem ser expressas das seguintes maneiras.

1. Apenas um valor. Por exemplo, Diameter=10.
2. Um intervalo de valores (Min..Max). Por exemplo, Diameter=10..20.
3. Expressão menor que (<). Por exemplo, Diameter<5.
4. Expressão menor ou igual (<=). Por exemplo, Diameter<=5.
5. Expressão maior que (>). Por exemplo, Diameter>5.
6. Expressão maior ou igual (>=). Por exemplo, Diameter>=5.

Quando o usuário seleciona um recurso na interface do usuário para atribuir uma sequência de usinagem a ele, o sistema CAM examina todos os procedimentos na biblioteca e compara o recurso com as restrições de recursos de cada procedimento. Toda vez que ele encontra uma correspondência, o procedimento é adicionado à lista de sugestões. Depois disso, o sistema CAM examina as listas de consulta de ferramentas dos procedimentos e procura as ferramentas na biblioteca de ferramentas.

Lista de consulta de ferramentas

A Lista de consulta de ferramentas consiste em entradas que definem as regras de seleção das ferramentas da Biblioteca de ferramentas para as operações do procedimento de usinagem.

Para cada consulta de ferramenta, são especificados o tipo de ferramenta desejado e as restrições dos parâmetros da ferramenta. As restrições de parâmetros da ferramenta são expressas da mesma forma que as restrições de recursos. O importante é que é possível usar as referências aos parâmetros do recurso nas restrições da ferramenta. Uma referência é definida pelo caminho completo para o parâmetro iniciado com o caractere #. Por exemplo, para um recurso de furo, as referências de parâmetros possíveis incluem #Hole.Diameter, #Hole.Height, #Hole.TipAngle e outros. Portanto, para um procedimento de usinagem de furos, uma consulta de ferramenta típica tem a seguinte forma:

- Tool.Type = Drill;
- Tool.Diameter=#Hole.Diameter;
- Tool.Length>=#Hole.Height.

Também é possível usar operadores matemáticos e funções matemáticas nas restrições. Por exemplo, para uma operação de usinagem de chanfro, a consulta de ferramenta tem as seguintes restrições:

- Tool.Type = Conical Mill
- Tool.TaperAngle = Hole.TipAngle/2.

Lista de operações

A lista de operações é a lista de operações de usinagem a serem usadas com o recurso.

Para cada operação, são definidos os seguintes parâmetros:

1. Id do sub-recurso.
2. Número da ferramenta.
3. Grupo tecnológico.
4. Ícone e legenda.
5. Tipo de ciclo de usinagem.
6. Parâmetros do ciclo de usinagem.
7. O Id do sub-recurso é o Id do sub-recurso de um recurso composto que essa operação específica usina. Por exemplo, um procedimento de usinagem de furo escalonado consiste em operações que usinam etapas e ranhuras específicas desse furo, de modo que o ID do sub-recurso de suas operações pode ser Step1, Step2,...StepN, Groove1, Groove2,... GrooveN.

O número da ferramenta especifica o número da ferramenta na Lista de consulta de ferramentas que a operação utiliza. Várias operações podem usar a mesma ferramenta. Nesse caso, elas terão o mesmo número de ferramenta.

O Grupo Tecnológico define a classe à qual a operação pertence. Existem os seguintes grupos tecnológicos:

- preparação;
- desbaste;
- semiacabamento;
- acabamento;
- complementar

O tipo de ciclo de usinagem define o ciclo de usinagem para a operação. Para cada tipo de recurso, há vários ciclos de usinagem disponíveis. Por exemplo, para um recurso de furo, há ciclos como furação simples, furação com quebra de cavacos, furação com remoção de cavacos e outros.

Os parâmetros do ciclo de usinagem são armazenados como uma lista de pares Parâmetro=Valor, de modo que somente os parâmetros importantes precisam ser especificados; os outros parâmetros terão os valores padrão do ciclo.
