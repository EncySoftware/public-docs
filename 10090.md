# FBM-Bearbeitungsverfahren

Ein FBM-Verfahren ist eine Bearbeitungsfolge für ein Merkmal oder eine Merkmalsklasse. Es gibt zwei Arten:

1. Atomare Verfahren.
2. Vollständige Verfahren.

Ein atomares Verfahren übernimmt nur einen Teilschritt und besteht meist aus einer Operation, beispielsweise Anbohren, Schruppen, Senken oder Kontur-Anfasen.

Ein vollständiges Verfahren enthält alle für die Fertigbearbeitung eines Merkmals erforderlichen Schritte.

Bei der ersten Zuweisung werden vollständige Verfahren angeboten. Beim Ergänzen einer vorhandenen Folge werden atomare Verfahren angeboten.

Ein FBM-Verfahren besteht aus vier Teilen:

1. Metadaten: Typ, Bezeichnung, Symbol und Änderungsdatum.
2. Merkmalsbedingungen.
3. Werkzeugabfragen.
4. Operationsliste.

**Merkmalsbedingungen**

Sie definieren, für welchen Merkmalstyp und welche Parameterwerte das Verfahren geeignet ist.

Beispiele für Typen sind Bohrung, Stufenbohrung und Bohrungsnut.

Jeder Typ besitzt eigene Parameter. Eine Bohrung hat etwa Typ, Durchmesser, Höhe, Spitzen- und Kegelwinkel. Eine Stufenbohrung besteht aus mehreren Bohrungsabschnitten und gegebenenfalls Nuten. Eine Bohrungsnut wird unter anderem durch Form, Höhe, Durchmesser, Kegelwinkel und Eckenradius beschrieben.

Die Bedingungen können wie folgt angegeben werden:

1. Einzelwert, z. B. `Diameter=10`.
2. Wertebereich, z. B. `Diameter=10..20`.
3. Kleiner als, z. B. `Diameter<5`.
4. Kleiner oder gleich, z. B. `Diameter<=5`.
5. Größer als, z. B. `Diameter>5`.
6. Größer oder gleich, z. B. `Diameter>=5`.

Bei Auswahl eines Merkmals vergleicht das System dessen Eigenschaften mit den Verfahrensbedingungen. Passende Verfahren erscheinen in der Vorschlagsliste. Anschließend wird anhand der Werkzeugabfragen nach geeigneten Werkzeugen gesucht.

**Werkzeugabfragen**

Die Liste definiert die Auswahlregeln für Werkzeuge aus der Werkzeugbibliothek.

Jede Abfrage legt Werkzeugtyp und Parameterbedingungen fest. Merkmalsparameter können über ihren mit `#` beginnenden Pfad referenziert werden, beispielsweise `#Hole.Diameter`, `#Hole.Height` oder `#Hole.TipAngle`. Eine typische Bohrwerkzeugabfrage lautet:

- Tool.Type = Drill;
- Tool.Diameter=#Hole.Diameter;
- Tool.Length>=#Hole.Height.

Auch mathematische Operatoren und Funktionen können verwendet werden. Beispiel für eine Fasenbearbeitung:

- Tool.Type = Conical Mill
- Tool.TaperAngle = Hole.TipAngle/2.

**Operationsliste**

Sie enthält die für das Merkmal auszuführenden Operationen.

Pro Operation werden festgelegt:

1. Untermerkmal-ID.
2. Werkzeugnummer.
3. Technologische Gruppe.
4. Symbol und Bezeichnung.
5. Bearbeitungszyklus.
6. Zyklusparameter.
7. Die Untermerkmal-ID identifiziert den bearbeiteten Teil eines zusammengesetzten Merkmals. Bei Stufenbohrungen können dies `Step1`, `Step2`, … `StepN` oder `Groove1`, `Groove2`, … `GrooveN` sein.

Die Werkzeugnummer verweist auf einen Eintrag der Werkzeugabfrageliste. Mehrere Operationen können denselben Eintrag verwenden.

Die technologische Gruppe klassifiziert den Bearbeitungsschritt:

- preparing – Vorbereitung;
- roughing – Schruppen;
- semi-finishing – Vorschlichten;
- finishing – Schlichten;
- completive – Abschlussbearbeitung.

Der Zyklustyp bestimmt das Bearbeitungsverfahren. Für Bohrungen stehen beispielsweise einfaches Bohren, Bohren mit Spanbrechen und Tiefbohren mit Spanabfuhr zur Verfügung.

Die Zyklusparameter werden als Parameter-Wert-Paare gespeichert. Nur abweichende Werte müssen angegeben werden; übrige Parameter erhalten die Zyklusstandardwerte.
