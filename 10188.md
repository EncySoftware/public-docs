# Drehzyklen

Der Zyklustyp bestimmt, wie der Werkzeugweg aus dem vorgegebenen Profil erzeugt wird. Für Drehoperationen stehen folgende Auftragselemente zur Verfügung:

![images/download/attachments/157865310/LatheContouringCycles.png](assets/images/download/attachments/157865310/LatheContouringCycles.png)

- **[Profile](10189.md).** Gibt das Profil ohne zusätzliche Bearbeitungsbahnen aus.
- **[Offset cycle](10191.md).** Erzeugt ISO G73 anhand des Profils.
- **[Offset Roughing](10190.md).** Erzeugt eine entsprechende Bahn wie [ISO G73](10191.md), jedoch als aufgelöste Einzelbewegungen. Dabei kann der aktuelle Rohteilzustand berücksichtigt werden.
- **[Roughing Cycle](10193.md).** Erzeugt ISO G71 oder G72 anhand des Profils.
- **[Roughing](10192.md).** Erzeugt eine entsprechende Bahn wie [ISO G71/G72](10193.md), jedoch aufgelöst. Auch hier kann der aktuelle Rohteilzustand berücksichtigt werden.
- **[Grooving](10195.md).** Erzeugt eine entsprechende Bahn wie [ISO G74/G75](10204.md), jedoch aufgelöst und mit möglicher Rohteilprüfung. Eine weitergehende Berücksichtigung der tatsächlichen Profilform ist für künftige Versionen vorgesehen.
- **[Thread cycle](10197.md).** Gewindeschneidzyklus mit mehreren Zustellungen, ausgegeben als ISO G76.
- **[Single-thread cycle](10197.md).** Gibt jeden Gewindeschneiddurchgang als eigenen ISO-G92-Zyklus aus.
- **[Threading](10197.md).** Gibt jede Bewegung als einzelnen Satz aus. Die Schnittbewegungen werden mit der Spindelrotation synchronisiert; der Modus wird mit ISO G32/G33 aktiviert. Die aufgelöste Ausgabe ermöglicht unter anderem wechselnde Konizitäten oder Stirnspiralen.
- **[4-Achs-Drehen](10202.md).** Bearbeitet schwer zugängliche Bereiche in einer Operation, indem der Werkzeugneigungswinkel während der Konturbewegung über die vierte Maschinenachse kontinuierlich geändert wird, sofern diese vorhanden ist.
