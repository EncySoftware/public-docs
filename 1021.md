# Painel de configuração da máquina

![images/download/attachments/157861574/turret.png](assets/images/download/attachments/157861574/turret.png)

## Área de aplicação:

Esta aba é necessária para configurar os parâmetros fundamentais do projeto, relacionados principalmente ao esquema cinemático do equipamento.

### Descrição.

Nome da máquina. Deve ser único.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Comment.</strong> Descrição do equipamento utilizado.

<strong>Group.</strong> O grupo da máquina é usado apenas para ordenação na biblioteca de máquinas. Há sete valores disponíveis: - Jet cutting - Wire EDM - Milling - Lathe - Turn-milling - Robotics - Other

<strong>Developer.</strong> Desenvolvedor desta máquina. Pode ser o autor do esquema XML ou o fabricante da máquina CNC.

<strong>NC System name.</strong> Nome do sistema NC.

<strong>Postprocessor file</strong>. Caminho do arquivo do pós-processador.

<strong>Interpreter file.</strong> Caminho do arquivo do interpretador (*.snci).

<strong>Measurements.</strong> Parâmetros de medição.

</details>

### Ferramentas.

Parâmetros de ferramental.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Position for tool block.</strong> Configura o conteúdo e os parâmetros dos blocos de ferramenta nas posições de ferramenta da máquina. É possível colocar um bloco de ferramenta em qualquer posição ou ocultá-lo, deixando-o vazio.

<strong>Visible</strong>. Configura os parâmetros de visualização do bloco de ferramenta. Quando a opção está ativa, o bloco de ferramenta fica visível e sua cor pode ser alterada nesse estado. Os parâmetros deste grupo são os mesmos do grupo <strong>Frame</strong>.

</details>

### Parâmetros de controle.

Parâmetros de controle da máquina.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Arcs.</strong> Parâmetros relacionados a arcos.

<strong>Use arcs.</strong> Determina se os arcos serão gerados no CLData (por exemplo, interpolação circular). Quando a opção está desativada, os arcos não são gerados e a trajetória é representada por segmentos de reta.

<strong>Use arcs in XY plane.</strong> Determina se os arcos serão gerados em um plano específico.

<strong>Use arcs in YZ plane.</strong> Determina se os arcos serão gerados em um plano específico.

<strong>Use arcs in ZX plane.</strong> Determina se os arcos serão gerados em um plano específico.

<strong>Circles division.</strong> Permite dividir círculos em segmentos (não dividir, em quadrantes, em metades). É necessário para gerar determinadas interpolações (por exemplo, interpolação circular com R).

<strong>Do not break.</strong> Os círculos não são divididos em arcos.

![images/download/attachments/157861574/Circles_division.png](assets/images/download/attachments/157861574/Circles_division.png)

<strong>Into quadrants.</strong> Os círculos são divididos em quadrantes.

![images/download/attachments/157861574/Into_quadrants.png](assets/images/download/attachments/157861574/Into_quadrants.png)

<strong>Into halves.</strong> Os círculos são divididos em metades.

![images/download/attachments/157861574/Into_halves.png](assets/images/download/attachments/157861574/Into_halves.png)

<strong>Minimal Arc Length.</strong> Se o comprimento do arco for menor que o valor definido neste parâmetro, o arco será gerado como segmentos de reta.

<strong>Maximal Arc Radius.</strong> Se o raio do arco for maior que o valor especificado neste parâmetro, o arco será gerado como segmentos de reta.

<strong>Spatial arcs.</strong> Arcos que não estão contidos em planos. O parâmetro geralmente é usado para <strong>robôs</strong>, para gerar saídas <strong>MULTIARC</strong>. O comando de movimento <strong>MULTIARC</strong> define um arco circular que passa por três pontos, com uma orientação predeterminada da ferramenta no espaço para cada um desses pontos.

<strong>Minimal distance between start and end points.</strong> Se a distância entre os pontos inicial e final de um arco espacial for menor que o valor especificado, são gerados segmentos de reta entre esses dois pontos.

<strong>Reorientation mode.</strong> A lei de interpolação em um ponto intermediário pode ser <strong>relative to path</strong> (em relação ao percurso) ou <strong>relative to base CS</strong> (em relação ao sistema de coordenadas base).

<strong>Consider middle point orientation.</strong> Controla se a orientação no ponto médio é considerada.

<strong>Singularities.</strong> Este grupo de parâmetros define a capacidade do sistema de evitar singularidades automaticamente. <strong>Vermelho — zona de singularidade</strong>. Ela ocorre quando a mesa rotativa gira e o eixo da ferramenta permanece alinhado com o eixo de rotação.

![images/download/attachments/157861574/Singularities.png](assets/images/download/attachments/157861574/Singularities.png)

<strong>Allowed axis deviation.</strong> Especifica o ângulo em que os nós da máquina ou do robô podem se desviar da posição nominal calculada para contornar a zona de singularidade.

![images/download/attachments/157861574/Allowed_axis_devation.png](assets/images/download/attachments/157861574/Allowed_axis_devation.png)

Os robôs usam parâmetros de singularidade adicionais, que especificam os desvios admissíveis para os eixos de seus componentes: <strong>Wrist</strong>, <strong>Elbow</strong>, <strong>Base</strong>. Para cada componente, é possível configurar individualmente o ângulo para evitar a singularidade.

<strong>Default machine(robot) configuration.</strong> Estado de inversão (flip) dos elementos do equipamento, conforme indicado no esquema cinemático do equipamento.

<strong>Origin list parameters.</strong> Parâmetros relacionados à exibição do sistema de coordenadas local.

<strong>Origin prefix.</strong> Determina o prefixo usado na exibição do sistema de coordenadas local (LCS).

<strong>Initial number.</strong> Define o valor inicial para a exibição do sistema de coordenadas local (LCS).

<strong>Increment value.</strong> Determina o passo para calcular o número do próximo sistema de coordenadas local (LCS).

<strong>Create new origin for part group.</strong> Determina se é necessária a criação automática de um novo sistema de coordenadas local (LCS) para o próximo grupo de peças de determinado tipo.

<strong>Radius Compensation Parameters.</strong> Define as particularidades da construção do percurso da ferramenta considerando a compensação do raio da ferramenta.

<strong>Sharp Corner.</strong> Ao considerar a compensação do raio da ferramenta em trechos do contorno com ângulos vivos, o sistema aplica algoritmos especiais para construir o percurso da ferramenta. Este parâmetro define o ângulo máximo que o sistema considerará vivo.

<strong>Rotary Transformations.</strong> Define a disponibilidade dos parâmetros de transformação rotativa na aba <strong>Transformation</strong>.

<strong>Polar interpolation is available.</strong> Quando a opção está ativa, é possível substituir um eixo linear por um eixo rotativo no fresamento simples em 3 eixos, usando o parâmetro <strong>Rotary Transformation</strong> na aba <strong>Transformations</strong>. Geralmente isso é necessário em tornos com ferramenta acionada ou em operações rotativas em máquinas de quatro ou cinco eixos.

<strong>CNC supports polar interpolation.</strong> Quando a opção está ativa, a marcação de interpolação do CNC fica disponível na aba <strong>Transformations</strong>, no grupo <strong>Rotary Transformation</strong>. Se este parâmetro estiver ativado, é possível gerar o código G com os comandos para ativar/desativar a interpolação polar.

<strong>Cylindrical interpolation is available.</strong> Quando a opção está ativa, é possível usar a função de interpolação cilíndrica por meio do parâmetro <strong>Rotary Transformation</strong> na aba <strong>Transformations</strong>. Ela permite fresar a superfície lateral de peças cilíndricas programando as curvas planificadas. O sistema programa as curvas planificadas nas coordenadas [X,Y,Z], mas a maioria dos tornos com fresamento só processa coordenadas [X,C,Z]. Por isso, a interpolação cilíndrica realiza a transformação [X,Y,Z] => [X,C,Z].

<strong>CNC supports cylindrical interpolation.</strong> Quando a opção está ativa, a marcação de interpolação do CNC fica disponível na aba <strong>Transformations</strong>, no grupo <strong>Rotary Transformation</strong>. Se este parâmetro estiver ativado, é possível gerar o código G com os comandos para ativar/desativar a interpolação cilíndrica.

<strong>Start from C=0.</strong> Quando a opção está marcada, o parâmetro Start from C=0 na aba <strong>Transformations</strong>, no grupo <strong>Rotary Transformation</strong>, fica ativo por padrão. Ele leva o eixo rotativo à posição zero antes de ativar a interpolação polar ou cilíndrica.

<strong>Tool frame output.</strong> Define o formato de saída dos parâmetros de orientação da ferramenta nos comandos CLDATA que contêm movimentos em cinco eixos.

<strong>Additional transformation.</strong> `*Base coordinate system*` define o sistema de coordenadas em relação ao qual a transformação será realizada. Pode ser: Tool CS, Workpiece CS, Global CS ou qualquer outro sistema de coordenadas geométrico criado anteriormente. Também é possível definir uma translação e uma rotação adicionais desse sistema de coordenadas no grupo de parâmetros Additional transformation.

<strong>Set machine state flags.</strong> Na programação de robôs, as coordenadas físicas em relação às coordenadas cartesianas também são determinadas pela posição de inversão (flip) das juntas. Este parâmetro especifica se devem ser gerados no CLData sinalizadores que indicam a posição de inversão das juntas.

<strong>Swap Tool and Workpiece frames.</strong> Em algumas situações, o bloco de ferramenta do robô segura a peça em vez da ferramenta. Nesses casos, os sistemas de coordenadas da ferramenta e da peça são trocados. Marque a opção se o controlador do robô não suportar essa transformação.

<strong>Set tool contact surface normal vectors.</strong> Na compensação do raio da ferramenta em cinco eixos, a ferramenta deve ser deslocada ao longo da normal à superfície a partir do ponto de contato. Quando a opção está marcada, o CLData gera um comando TLContact adicional antes de cada movimento, com os parâmetros da normal à superfície no ponto de contato entre a ferramenta e a peça. [Detalhes](102266.md)

<strong>Prefer GOTO for linear movements</strong>. Dá preferência à geração do comando GOTO no CLData, em vez de MULTIGOTO, para movimentos que contêm apenas deslocamentos ao longo das três coordenadas lineares geométricas X, Y, Z.

<strong>Indexed 5-axis machining.</strong> Especifica os parâmetros disponíveis e os modos de transformação de coordenadas para a usinagem indexada em cinco eixos.

<strong>Indexed 5Axis compensation mode.</strong> Ativa a transformação rotativa de coordenadas no modo de usinagem indexada em cinco eixos (para funções de plano inclinado). Quando essas opções estão ativadas, o <strong>sistema de coordenadas é girado automaticamente</strong> <strong>(recalculado) para acompanhar qualquer movimento dos eixos rotativos</strong> da máquina, de modo que a programação permaneça alinhada com o plano de trabalho inclinado. Esses modos de compensação são usados quando o sistema de controle da máquina não suporta funções integradas de plano de trabalho inclinado (como <strong>Siemens CYCLE800, Heidenhain PLANE/Cycle 19 ou Fanuc G68.2</strong>) nem o controle do ponto central da ferramenta com rotação (<strong>TCPM/RTCP</strong>). Nesses casos, a transformação de coordenadas não pode ser realizada pelo CNC e deve ser calculada pelo sistema CAM e incorporada ao programa gerado pelo pós-processador. Se o comando já oferece essas funções, a transformação é feita pela máquina e essas opções não são necessárias.

![images/download/attachments/157861574/Indexed_5Axis_compensation_mode..png](assets/images/download/attachments/157861574/Indexed_5Axis_compensation_mode..png)

<strong>5 Axis tooling point compensation.</strong> A opção é responsável pela rotação do ponto central da ferramenta junto com o cabeçote rotativo.

![images/download/attachments/157861574/5-Axis_Tool_Center_Point_Compensation_off.png](assets/images/download/attachments/157861574/5-Axis_Tool_Center_Point_Compensation_off.png) ![images/download/attachments/157861574/5-Axis_Tool_Center_Point_Compensation_on.png](assets/images/download/attachments/157861574/5-Axis_Tool_Center_Point_Compensation_on.png)

<strong>5 Axis workpiece zero point compensation.</strong> O ponto zero da peça gira junto com a mesa rotativa. Apenas a posição da origem acompanha a mesa, enquanto a orientação dos eixos permanece alinhada com a máquina (MCS).

![images/download/attachments/157861574/5_Axis_workpiece_zero_point_compensation_off.png](assets/images/download/attachments/157861574/5_Axis_workpiece_zero_point_compensation_off.png) ![images/download/attachments/157861574/5_Axis_workpiece_zero_point_compensation_on.png](assets/images/download/attachments/157861574/5_Axis_workpiece_zero_point_compensation_on.png)

<strong>MCS</strong> - sistema de coordenadas da máquina

<strong>WCS</strong> - sistema de coordenadas de trabalho

<strong>5 Axis coordinate system compensation.</strong> A orientação do sistema de coordenadas gira junto com a mesa rotativa. A origem permanece no lugar; apenas a orientação dos eixos acompanha a rotação da mesa.

![images/download/attachments/157861574/5_Axis_coordinate_system_compensation_off.png](assets/images/download/attachments/157861574/5_Axis_coordinate_system_compensation_off.png) ![images/download/attachments/157861574/5_Axis_coordinate_system_compensation_on.png](assets/images/download/attachments/157861574/5_Axis_coordinate_system_compensation_on.png)

<strong>MCS</strong> - sistema de coordenadas da máquina

<strong>WCS</strong> - sistema de coordenadas de trabalho

<strong>Local coordinate system (ORIGIN).</strong> Define o modo de exibição do parâmetro <strong>Local CS</strong> na aba <strong>Setup</strong> de cada operação.

<strong>Unavailable</strong>. O parâmetro <strong>Local CS</strong> não é exibido.

![images/download/attachments/157861574/Local_coordinate_system_%28ORIGIN%29.Unavailable.png](assets/images/download/attachments/157861574/Local_coordinate_system_(ORIGIN).Unavailable.png)

<strong>Off</strong>. O parâmetro <strong>Local CS</strong> é exibido, mas o valor padrão é <strong>Off</strong>.

![images/download/attachments/157861574/Local_coordinate_system_%28ORIGIN%29.off.png](assets/images/download/attachments/157861574/Local_coordinate_system_(ORIGIN).off.png)

<strong>Auto</strong>: O parâmetro <strong>Local CS</strong> é exibido e o valor padrão é <strong>Auto</strong>. Nesse modo, as transformações rotativas alinham o WCS de modo que o eixo Z coincida com o eixo da ferramenta, e a origem permanece fixa no ponto da peça selecionado pelo usuário.

![images/download/attachments/157861574/Local_coordinate_system_%28ORIGIN%29.Auto.png](assets/images/download/attachments/157861574/Local_coordinate_system_(ORIGIN).Auto.png)

<strong>Local CS positioning mode.</strong> Define o comportamento dos eixos físicos da máquina durante as transformações rotativas.

<strong>Stay</strong>. Gira o sistema de coordenadas sem mover os eixos físicos da máquina.

![images/download/attachments/157861574/Local_CS_positioning_mode_Stay.png](assets/images/download/attachments/157861574/Local_CS_positioning_mode_Stay.png)

<strong>Turn</strong>. Gira o sistema de coordenadas e, correspondentemente, os eixos físicos da máquina, sem compensar com movimento dos eixos lineares o desalinhamento entre o ponto de referência da ferramenta e a origem do sistema de coordenadas.

![images/download/attachments/157861574/Local_CS_positioning_mode_Turn.png](assets/images/download/attachments/157861574/Local_CS_positioning_mode_Turn.png)

<strong>Move</strong>. Gira o sistema de coordenadas e, correspondentemente, os eixos físicos da máquina, e compensa com movimento dos eixos lineares o desalinhamento entre o ponto de referência da ferramenta e a origem do sistema de coordenadas.

![images/download/attachments/157861574/Local_CS_positioning_mode_Move.png](assets/images/download/attachments/157861574/Local_CS_positioning_mode_Move.png)

<strong>Is spatial.</strong> Define se as transformações do sistema de coordenadas são feitas com ângulos espaciais ou com os eixos rotativos da máquina. Quando a opção está marcada, a transformação usa ângulos espaciais.

![images/download/attachments/157861574/Is_spatial_off.png](assets/images/download/attachments/157861574/Is_spatial_off.png) ![images/download/attachments/157861574/Is_spatial_on.png](assets/images/download/attachments/157861574/Is_spatial_on.png)

<strong>Euler angles type (rotation sequence).</strong> Especifica a sequência de rotações nas transformações rotativas com ângulos espaciais.

<strong>Rotations around movable axes.</strong> Determina se as rotações são feitas em torno de eixos fixos ou de eixos já girados. Quando a opção está marcada, cada rotação seguinte usa os eixos do sistema de coordenadas já girado.

![images/download/attachments/157861574/Rotations_around_movable_axes_off.png](assets/images/download/attachments/157861574/Rotations_around_movable_axes_off.png) ![images/download/attachments/157861574/Rotations_around_movable_axes_on.png](assets/images/download/attachments/157861574/Rotations_around_movable_axes_on.png)

<strong>Angles in degrees.</strong> Especifica a unidade de medida dos ângulos de rotação. Quando a opção está marcada, o sistema mede os ângulos em graus; caso contrário, em radianos.

![images/download/attachments/157861574/Angles_in_degrees_on.png](assets/images/download/attachments/157861574/Angles_in_degrees_on.png) ![images/download/attachments/157861574/Angles_in_degrees_off.png](assets/images/download/attachments/157861574/Angles_in_degrees_off.png)

<strong>Move auto LCS with table.</strong> Determina a posição do WCS durante as transformações rotativas no modo <strong>Auto Local CS</strong>. Quando a opção está marcada, o WCS fica vinculado à peça durante as transformações rotativas, alinhando o eixo Z do WCS com o eixo da ferramenta. Quando a opção está desativada, o WCS permanece na posição original e não se move com o bruto.

![images/download/attachments/157861574/Move_auto_LCS_with_table_off.png](assets/images/download/attachments/157861574/Move_auto_LCS_with_table_off.png) ![images/download/attachments/157861574/Move_auto_LCS_with_table_on.png](assets/images/download/attachments/157861574/Move_auto_LCS_with_table_on.png)

<strong>Auto LCS rotation law.</strong> Define a regra de posicionamento do Local CS quando a opção <strong>Local CS</strong> tem o valor <strong>Auto</strong> nas operações de fresamento.

<strong>Snap to Tool CS</strong>. Use em máquinas em que os eixos rotativos são realizados por rotações da ferramenta. Nesse caso, os eixos giram junto com a ferramenta.

<strong>Snap to Machine CS</strong>. A direção dos eixos é vinculada ao sistema de coordenadas global fixo da máquina.

<strong>Snap to Workpiece CS.</strong> Use em máquinas em que os eixos rotativos são realizados por rotações da peça. Nesse caso, os eixos giram junto com a peça.

<strong>Exclude Spatial Angle A</strong>. Nas transformações rotativas, o eixo X do sistema de coordenadas de trabalho permanece paralelo ao eixo X do sistema de coordenadas da máquina.

<strong>Exclude Spatial Angle B</strong>. Nas transformações rotativas, o eixo Y do sistema de coordenadas de trabalho permanece paralelo ao eixo Y do sistema de coordenadas da máquina.

<strong>Exclude Spatial Angle C</strong>. Nas transformações rotativas, o eixo Z do sistema de coordenadas de trabalho permanece paralelo ao eixo Z do sistema de coordenadas da máquina.

<strong>Turn Auto LCS rotation law.</strong> Define a regra de posicionamento do Local CS quando a opção <strong>Local CS</strong> tem o valor <strong>Auto</strong> nas operações de torneamento.

<strong>Z along turn axis, X along tool</strong>. O eixo Z do sistema de coordenadas local fica ao longo do eixo de rotação do torneamento. O eixo X é direcionado para a ferramenta.

<strong>Z along turn axis, -X along tool</strong>. O eixo Z do sistema de coordenadas local fica ao longo do eixo de rotação do torneamento. O eixo X negativo é direcionado para a ferramenta.

<strong>Z along tool, X by snap rule.</strong> O eixo Z do sistema de coordenadas local fica ao longo da direção principal da ferramenta (ao longo do seu eixo). Os eixos X e Y são posicionados de acordo com a regra <strong>Auto LCS rotation law</strong>.

<strong>Rotatable Workpiece CS.</strong> Quando a opção está marcada, é possível deslocar e também girar o sistema de coordenadas da peça no parâmetro <strong>WCS</strong> da aba <strong>Setup</strong>.

<strong>Continuous 5-axis machining.</strong> Especifica os parâmetros disponíveis e os modos de transformação de coordenadas para a usinagem contínua em cinco eixos.

<strong>TCPM mode is available.</strong> Quando a opção está ativa, habilita o parâmetro <strong>Tool center point management</strong> na aba <strong>Setup</strong>. Use-a somente quando o sistema CNC suportar essa função. Quando a opção está desativada, o sistema usa os parâmetros de transformação de coordenadas de <strong>Indexed 5Axis compensation mode</strong>.

<strong>TCPM mode default state.</strong> Quando a opção está ativada, o parâmetro <strong>Tool center point management</strong> fica ativo por padrão na aba <strong>Setup</strong>. Quando a opção está desativada, esse parâmetro fica inativo por padrão.

<strong>Disable TCPM when rotate back.</strong> Quando a opção está marcada, fica disponível a opção de desativar o modo TCPM durante as ligações, enquanto a peça gira de volta à posição original.

<strong>TCPM 5Axis compensation mode.</strong> Define os parâmetros de transformação de coordenadas para cada bloco do programa NC no modo de usinagem contínua em 5 eixos.

<strong>5 Axis tooling point compensation</strong>. A opção é responsável pela rotação do ponto central da ferramenta junto com o cabeçote rotativo.

<strong>5 Axis workpiece zero point compensation.</strong> A opção é responsável pela rotação do ponto zero da peça junto com a mesa rotativa.

<strong>5 Axis coordinate system compensation.</strong> A opção é responsável pela rotação do sistema de coordenadas da peça junto com a mesa rotativa.

</details>

<strong>Tool Change.</strong> Parâmetros de configuração do comportamento do sistema de troca de ferramenta.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Go to tool change position.</strong> Define a necessidade de recuar até a posição de troca da ferramenta.

<strong>Only if tool change is needed</strong>. O sistema recua até a posição de troca da ferramenta somente se a próxima operação exigir outra ferramenta. Se a mesma ferramenta for usada, não há recuo no final da operação.

<strong>Always in the end of operation</strong>. O recuo até a posição de troca da ferramenta ocorre independentemente da ferramenta usada na operação seguinte, seja ela uma nova ferramenta ou a mesma.

<strong>Never</strong>. Os recuos até a posição de troca da ferramenta são omitidos.

<strong>Output mode.</strong> Este parâmetro especifica como o recuo para a troca de ferramenta será gerado no programa de controle.

<strong>Tool tip coordinates.</strong> As coordenadas definidas da ponta da ferramenta em relação ao sistema de coordenadas da peça são incluídas no programa NC como ponto de troca da ferramenta.

<strong>Reference point (ISO G28).</strong> O recuo para a troca de ferramenta é realizado por meio de um movimento até o ponto de referência (comando G28).

<strong>Machine coordinates (ISO G53).</strong> A função G53 é usada para realizar os movimentos de recuo até a posição de troca da ferramenta no sistema de coordenadas da máquina.

<strong>Tool change position.</strong> Aqui são definidas as coordenadas da posição de troca da ferramenta.

<strong>Heavy axes.</strong> Define os endereços dos eixos cujo movimento deve ser evitado durante a aproximação/o recuo para a troca de ferramenta. O parâmetro é usado no cálculo automático da aproximação/do recuo até a posição de troca da ferramenta com a regra "Collision Avoidance". Quando ela está ativada, o sistema CAM otimiza os movimentos para evitar colisões usando diferentes eixos da máquina. Os eixos pesados (cujo movimento é indesejável) são listados nesta seção.

<strong>Tool change time calculation.</strong> Define o método de cálculo da duração da troca de ferramenta no sistema CAM:

<strong>Default law.</strong> Regra de cálculo padrão do projeto.

<strong>Undefined</strong>. O tempo de troca de ferramenta é predefinido no algoritmo do sistema CAM e não pode ser alterado.

<strong>Constant time</strong>. A duração da troca de ferramenta é definida manualmente pelo valor do parâmetro Constant Time.

<strong>Advanced laws.</strong> Este parâmetro permite ativar várias regras de cálculo, exibidas como lista suspensa. O número especificado determina quantas regras serão ativadas, e cada item da lista pode usar qualquer uma das regras descritas acima.

<strong>Rapid movements time calculation method.</strong> Método de cálculo do tempo dos movimentos rápidos (sem corte) da ferramenta.

<strong>Maximum axis movement time (default).</strong> O sistema calcula o tempo de deslocamento de cada eixo da máquina (X, Y, Z e eixos rotativos, se houver). O tempo do movimento rápido é determinado pelo eixo que leva mais tempo para concluir seu movimento.

<strong>Time of tool tip movement.</strong> Calcula o tempo do movimento rápido com base na trajetória real da ponta da ferramenta, considerando a soma vetorial das velocidades em todos os eixos (X, Y, Z).

</details>

### Refrigerantes.

### Simulação.

Conjunto de parâmetros que controlam o funcionamento do sistema na simulação do projeto.

<details>
<summary>Clique aqui para expandir..</summary>

Alguns grupos de parâmetros funcionam de forma semelhante ao painel <strong>[Setup](1022.md)</strong>.

<strong>Simulation Method</strong>. Determina o modo de visualização no ambiente de simulação.

<strong>Solid</strong>. Técnica de modelagem sólida que usa representação por malha para visualizar o modelo 3D. Exige mais recursos computacionais, mas oferece maior qualidade na renderização das superfícies usinadas.

<strong>Voxel5d</strong>. São usados voxels pontuais, que melhoram a renderização de volumes complexos, mas exigem recursos significativos. São aplicáveis tanto a operações em 3 eixos e de torneamento quanto a operações com grande número de eixos.

<strong>Voxel3d</strong>. São usados voxels em coluna. Eles aceleram o processo de modelagem, mas só podem ser aplicados a operações em 3 eixos.

<strong>Model resolution.</strong> Resolução de renderização da simulação do modelo. Define o número de voxels usados para dividir o modelo do bruto na simulação. Uma resolução maior melhora a qualidade de renderização do modelo.

<strong>Gouge detection tolerance.</strong> Valor mínimo de penetração para classificá-la como sobrecorte. Penetrações menores que esse limite são desconsideradas e não geram avisos de sobrecorte.

<strong>Revolution bodies simulation.</strong> Este parâmetro é usado em projetos de torneamento e é responsável por renderizar, por exemplo, as castanhas da placa do torno como um único corpo de revolução. Quando ativado, as castanhas da placa formam um único corpo em rotação durante a simulação. As colisões com outros componentes da máquina são verificadas em relação a esse corpo. Observe que o uso deste parâmetro torna a simulação mais lenta.

<strong>Check inappropriate tool and spindle direction.</strong> Controla a verificação do sentido de rotação do fuso. Garante que o sentido de rotação do fuso seja compatível com a ação de corte da fresa (por exemplo, fresa de corte à direita com rotação do fuso no sentido horário) e verifica a correspondência com a posição da ferramenta nos processos de torneamento.

<strong>Collisions to ignore.</strong> Define os pares de componentes da máquina excluídos da detecção de colisões durante a simulação. Adicionar esses componentes à lista de exclusão ajuda a evitar falsos alertas de colisão. A forma de adicioná-los no Machine Maker está descrita, por exemplo, para robôs: [Detalhes](https://docs.encycam.com/MachineMaker/1/robots/en/46.html).

<strong>Show active part only.</strong> Ao ativar esta opção, somente a peça atual é exibida. Em um projeto com várias peças, a peça atual é determinada pelo foco na árvore, ou seja, por uma peça específica ou por uma operação destinada à usinagem dessa peça. Isso permite reduzir a carga do computador ao trabalhar em diferentes modos (como <strong>Technology</strong> ou <strong>Modeling</strong>).

</details>

### Configurações do sistema.

<details>
<summary>Clique aqui para expandir..</summary>

Rotation angles (rotation sequence). Este parâmetro define o método de execução dos ângulos de rotação dos eixos de coordenadas ao aplicar sistemas de coordenadas locais.

<strong>Rotations sequence</strong>. Determina a ordem de execução das rotações em torno dos eixos de coordenadas.

<strong>Rotations around movable axes</strong>. Especifica se as rotações por ângulos espaciais ocorrerão em torno de eixos fixos ou de eixos já girados. Com a opção ativada, cada rotação seguinte ocorre em torno do eixo do sistema de coordenadas já girado.

<strong>Angles in degrees</strong>. Define o grau como unidade de medida angular.

</details>

### Parâmetros de estado da máquina.

Esta seção contém grupos que definem os valores dos parâmetros de cada eixo. A caixa de seleção na designação do eixo determina se ele será exibido na lista de eixos da aba <strong>Setup</strong> das operações.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Address. Endereço do eixo gerado no programa NC.</strong>

<strong>Axis Control.</strong> Especifica o modo de controle de movimento deste eixo.

<strong>Countinuous</strong>. O eixo opera em modo contínuo.

<strong>Indexed</strong>. O eixo se move em passos incrementais.

<strong>Manual</strong>. A coordenada deste eixo só pode ser alterada manualmente.

<strong>Force control with map</strong>. O cálculo do percurso do movimento deste eixo pode ser feito por meio do mapa de eixos. [Detalhes](1022.md).

<strong>Group</strong>. Grupo de tipo de movimento ao qual o eixo pertence: <strong>Rotary axes</strong>, <strong>Linear axes</strong> e <strong>Others</strong>.

<strong>Increment</strong>. Menor incremento de deslocamento ao longo deste eixo que o sistema de acionamento da máquina consegue executar.

<strong>Min</strong>. Limite inferior da coordenada deste eixo.

<strong>Max</strong>. Limite superior da coordenada deste eixo.

<strong>Initial value</strong>. Posição padrão da coordenada do componente.

<strong>Design time value</strong>. Valor de deslocamento que ajusta o curso <strong>Min-Max</strong> deste eixo.

<strong>Axis has brake</strong>. Quando ativado, este parâmetro inclui comandos de controle do freio no CLDATA.

<strong>Priority</strong>. Este número afeta a ordem do eixo na lista de eixos em <strong>Machine State Parameters</strong>. Quanto menor o número, mais acima o eixo aparece na lista.

<strong>Order</strong>. Número ordinal que identifica a posição do eixo na lista <strong>Machine State Parameters</strong>.

<strong>Support shortest path rotation.</strong> Define se o eixo rotativo suporta a rotação pelo caminho mais curto entre as posições inicial e final no espaço 3D.

</details>

### Frame.

Esta subseção descreve a árvore de componentes da máquina e a ordem em que os componentes estão conectados entre si. Cada componente inclui o nome e o identificador do eixo de movimento do componente móvel.

<details>
<summary>Clique aqui para expandir..</summary>

<strong>Visible.</strong> Controla os parâmetros de visualização do nó. Quando a opção está ativada, o nó fica visível e sua cor pode ser alterada nesse estado.

<strong>Metallic</strong>. Quando a opção está marcada, as superfícies do bloco de ferramenta recebem brilho metálico.

<strong>Transparent</strong>. Quando a opção está marcada, o bloco de ferramenta fica transparente. É possível ajustar o nível de transparência.

<strong>Display mode.</strong> Controla a renderização do modelo 3D do bloco de ferramenta. Por padrão, é usado o modo de exibição definido para a janela gráfica do sistema. Também é possível definir um modo de exibição próprio para este bloco de ferramenta. [Detalhes.](169.md)

<strong>Channel</strong>. Canal do sistema NC que controla o eixo ligado a este componente móvel.

<strong>Workpiece index</strong>. O eixo é atribuído para trabalhar somente com a peça indicada pelo número especificado.

<strong>Rapid feed</strong>. Define a velocidade de avanço rápido deste eixo: mm/min para eixos lineares e graus/min para eixos rotativos.

<strong>Scale</strong>. Define o tamanho relativo, ou escala, para a visualização do componente.

<strong>Inverse rotation direction</strong>. Inverte o sentido de rotação do fuso.

<strong>ID of rotary axis that is used as spindle</strong>. Identifica o eixo rotativo configurado para funcionar como fuso nas unidades de fixação da peça ou da ferramenta.

<strong>Default clamp ID</strong>. Identifica a estação de fixação específica usada para prender a peça ou a ferramenta.

<strong>Supported applications</strong>. Categorias de ferramentas disponíveis para esta unidade de fixação.

</details>

### Submáquinas.

A submáquina é uma lista de parâmetros para o par `tool holder, workpiece holder`. Isso é especialmente relevante para máquinas complexas com vários fusos, várias posições para a peça etc. [Detalhes](10410.md).

### Modo de reordenação padrão.

Os parâmetros deste grupo definem a possibilidade de reordenar a sequência da lista de operações. [Detalhes](1029.md).

<details>
<summary>Clique aqui para expandir..</summary>

<strong>No reordering</strong>. A reordenação da lista de operações está desativada.

<strong>Minimize tool changes</strong>. Se o projeto incluir mais de uma peça, a sequência real de usinagem pode ser redefinida para minimizar as trocas de ferramenta.

<strong>Swiss lathe (takeover last)</strong>. Se este modo estiver ativado, as operações da segunda peça são colocadas no início da lista reordenada.

</details>

Este conjunto de parâmetros estabelece as relações dimensionais nos nós da máquina e entre os componentes do sistema de fabricação robótico (deslocamentos etc.). Os valores iniciais são definidos no MachineMaker e podem ser redefinidos no arquivo de configuração cinemática.
