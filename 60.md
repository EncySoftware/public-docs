# Zoom para extensão

Para ajustar rapidamente a escala da vista de modo a exibir todos os objetos visíveis, use o botão ![images/download/thumbnails/157858327/Zoom_extence_25.png](assets/images/download/thumbnails/157858327/Zoom_extence_25.png) ou o item <strong>Fit Window</strong> do menu de contexto da tela gráfica.

![images/download/attachments/157858327/image2024-6-27_16-23-53.png](assets/images/download/attachments/157858327/image2024-6-27_16-23-53.png)

Esta função também pode ser ativada com um clique duplo no <strong>[botão do meio do mouse]</strong>, mas isso também ativará a [vista padrão](728.md) mais próxima.
