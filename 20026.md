# Verschieben

Verschiebt eine Gruppe von Objekten um einen angegebenen Abstand. Zusätzlich können Sie die Anzahl der Kopien festlegen. Jede weitere Kopie wird gegenüber der vorherigen um den angegebenen Wert verschoben.
