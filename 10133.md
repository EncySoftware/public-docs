# Controle de avanços

Esta função permite criar um perfil de valores de avanço. Para poder editar o valor do avanço, clique em <strong>Feed control mode</strong>.

![images/download/attachments/157864340/image2021-4-30_9-19-45.png](assets/images/download/attachments/157864340/image2021-4-30_9-19-45.png)

No painel pop-up, é possível controlar o intervalo, o tipo de avanço, a velocidade e o tipo de interpolação.

![images/download/attachments/157864340/image2021-4-30_9-20-5.png](assets/images/download/attachments/157864340/image2021-4-30_9-20-5.png)
